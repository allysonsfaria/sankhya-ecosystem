# Sankhya ERP Componentes

Observação

Os componentes apresentados são baseados em metadados do ERP Sankhya, portanto, só funcionam dentro do ambiente de desenvolvimento configurado da Sankhya.

[Snk Application

Aplicação que irá conter todos os componentes snk.](https://gilded-nasturtium-6b64dd.netlify.app/docs/components/sankhya-erp-componentes/snk-application/)
