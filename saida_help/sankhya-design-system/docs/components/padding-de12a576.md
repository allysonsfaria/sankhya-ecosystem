# Padding

A propriedade padding corresponde ao preenchimento de um elemento HTML, ou seja, o espaçamento interno do elemento.

## Como funciona

Para utilizar a propriedade padding do **EzDesign**, basta inserir a classe CSS `ez-padding`
incluindo o lado e/ou o tamanho desejado, conforme será apresentado a seguir.

Informação

Nos exemplos a seguir foram utilizadas classes CSS para destacar os espaçamentos internos ao redor do elemento,
para demonstrar o exemplo de forma mais aparente.

## Tamanhos

Os tamanhos correspondem ao espaçamento interno aplicado ao redor do elemento (left, right, top e bottom).
