# Empty Card

O Empty Card é um componente base utilizado com um container para outros conteúdos, podendo ser utilizado de base para criação
de novos componentes ou como uma forma padronizada de acomodar outros componentes.

![Imagem 1: O Empty Card é um componente base utilizado com um container para outros conteúdos, podendo ser utilizado de base para…](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)

---

## Variações

### Tamanhos

O Empty Card tem por padrão as dimensões de 335px x 155px, que podem ser modificadas através das propriedades `width` e `height`.

![Imagem 2: O Empty Card tem por padrão as dimensões de 335px x 155px, que podem ser modificadas através das propriedades width e…](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)

---

### Cores

O Empty Card possui 5 variações de cores nativas dentro da paleta de cores Design System, que podem ser definidas por meio
da propriedade `color`.
