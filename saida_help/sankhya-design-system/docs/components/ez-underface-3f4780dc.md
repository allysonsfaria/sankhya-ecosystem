# Underface

O Underface é um componente base utilizado como um fundo para outros conteúdos, podendo ser utilizado de base para criação
de novos componentes ou como uma forma padronizada de acomodar outros conteúdos.

![Imagem 1: O Underface é um componente base utilizado como um fundo para outros conteúdos, podendo ser utilizado de base para…](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)

---

## Variações

### Tamanhos

O Underface tem por padrão as dimensões de 693px x 247px, que podem ser modificadas através das propriedades `width` e `height`.

![Imagem 2: O Underface tem por padrão as dimensões de 693px x 247px, que podem ser modificadas através das propriedades width e…](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)

---

### Cores

O Underface possui 6 variações de cores nativas dentro da paleta de cores Design System, que podem ser definidas por meio
da propriedade `color`.

![Imagem 3: O Underface possui 6 variações de cores nativas dentro da paleta de cores Design System, que podem ser definidas por…](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)

---

Além disso qualquer token de cor disponível na paleta de cores do Design System está disponível para ser utilizada através da
propriedade `customColor`

![Imagem 4: Além disso qualquer token de cor disponível na paleta de cores do Design System está disponível para ser utilizada…](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)
