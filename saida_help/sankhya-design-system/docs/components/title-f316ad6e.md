# Title

A seguir será apresentada a documentação e os exemplos dos utilitários de **títulos** comuns
para controlar alinhamento, cor e tamanho.

## Como funciona

Para utilizar o estilo padrão dos títulos do **EzDesign**,
basta inserir a classe CSS `ez-title`, conforme exemplo a seguir:

![Imagem 1: Para utilizar o estilo padrão dos títulos do EzDesign , basta inserir a classe CSS ez-title , conforme exemplo a seguir:](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)
