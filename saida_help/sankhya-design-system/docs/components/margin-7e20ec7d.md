# Margin

A propriedade margin corresponde à margem de um elemento HTML, ou seja, o espaçamento externo do elemento.

## Como funciona

Para utilizar a propriedade margin do **EzDesign**, basta inserir a classe CSS `ez-margin`
incluindo o lado e/ou o tamanho desejado, conforme será apresentado a seguir.

Informação

Nos exemplos a seguir foram utilizadas classes CSS para destacar os espaçamentos externos ao redor do elemento,
para demonstrar o exemplo de forma mais aparente.

## Tamanhos

Os tamanhos correspondem ao espaçamento externo aplicado ao redor do elemento (left, right, top e bottom).
