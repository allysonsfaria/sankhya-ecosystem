# Labels

A tag `<label>` é um elemento HTML que representa uma legenda para melhorar a acessibilidade
de um item de interface do usuário. Este elemento também é conhecido como controle ou rótulo
e pode ser associado a outro elemento de controle através de um atributo.

## Como funciona

Para utilizar o estilo padrão dos labels do **EzDesign**,
basta inserir a classe CSS `ez-label`, conforme exemplo a seguir:

![Imagem 1: Para utilizar o estilo padrão dos labels do EzDesign , basta inserir a classe CSS ez-label , conforme exemplo a seguir:](https://gilded-nasturtium-6b64dd.netlify.app/img/logo-sankhya.svg)
