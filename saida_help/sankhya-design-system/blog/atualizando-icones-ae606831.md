# Atualizando Ícones

15 de março de 2023 · 2 min para ler

![Leonardo Jorge](https://gilded-nasturtium-6b64dd.netlify.app/img/authors/LeonardoJorge.png)

Leonardo Jorge

Software Architect

Os ícones são disponibilizados através se sprites SVG pelo UX, para mais informações verificar a [documentação no Figma](https://www.figma.com/file/hg4QGJMy6D1VCsGup8tjA5/Design-System?node-id=2608-12121&t=VM7OSk27XyvIeNAI-0).

Em posse do arquivo SVG de sprite, devemos acessar a pasta `\src\default\icons\svg\` do projeto, e substituir o arquivo actions-sprite.svg pelo novo arquivo de sprites.

> É importante que o novo arquivo tenha o mesmo nome do arquivo que está sendo substituído, ou seja, actions-sprite.svg

Após realizar a cópia do arquivo, deve-se fazer o build do projeto utilizando o comando `npm run build`, observe que será gerado um novo arquivo ez-icons.css na pasta dist\default\icons\fonts.

Devemos acessar esse arquivo, e copiar o seu CSS a partir da definição da classe ez-icon até o final, conforme imagem abaixo:

![alt text](https://gilded-nasturtium-6b64dd.netlify.app/assets/images/icones_copy-f1f4b8941ab204ff5a75fa3af6f7bc46.png "Image copy icons CSS")

O CSS copiado anteriormente deve substituir conteúdo entre os comentários:

/\*
START CSS GENERATED BY EZ-DESIGN ICONS, SEE MORE AT ez-design\scripts\fontsGenerator.js.
WHEN ADD NEW ICONS THIS CSS NEED TO BE UPDATED
\*/

/\*
END CSS GENERATED BY EZ-DESIGN ICONS
\*/

no arquivo ez-icon.css do projeto ez-ui.

Conforme imagem a seguir:

![alt text](https://gilded-nasturtium-6b64dd.netlify.app/assets/images/icones_paste-9fa363e736e321490da91ad2e78bc260.png "Image past icons CSS")

Após esse processo, temos os ícones atualizados tanto no projeto ez-design, quando no projeto ez-ui.

> É de extrema importância que o merge e a publicação dos dois projetos sejam feitos em sequencia: ez-design e depois o ez-ui.
