# Specialist Add-ons

A certificação **Specialist Add-ons** visa fornecer aos clientes e parceiros Sankhya a aquisição de conhecimentos e habilidades fundamentais para desenvolvimento de add-ons dentro da plataforma Sankhya.

A certificação de add-ons contempla a junção de todas as trilhas Associate para conhecimento fundamental da plataforma Sankhya + os conteúdos específicos de desenvolvimento de add-ons.

> ❗️ Importante
>
> A partir de Agosto de 2023 o termo Extensões foi renomeado como **Add-on**

<Image align="center" alt="Estrutura da certificação" border={false} caption="Estrutura trilha Specialist Add-ons" src="https://files.readme.io/7bcc4a8-20c4a96-Cpia_de_Trilhas_editveis.pptx_1.jpg" />

## Objetivo

Tem como objetivo validar que os parceiros possuem conhecimentos e as habilidades para implementar e instalar Add-ons na Plataforma Sankhya.

## Público-Alvo

Desenvolvedores de aplicações web, com experiência em desenvolvimento Full Stack.

## Pré-requisitos

* Conclusão da certificação **Associate Framework Dicionário de Dados**
* Conclusão da certificação **Associate Framework Front-end**
* Conclusão da certificação **Associate Framework Back-end**
* Conhecimento em desenvolvimento web com HTML, CSS e Javascript
* Conhecimento em desenvolvimento com o framework AngularJS
* Conhecimento em Java SE
* Conhecimento em desenvolvimento com o framework Java EE;
* Conhecimento em banco de dados relacionais;
* Conhecimento em SQL;
* Conhecimento em Git;

## Exame prático

O exame prático de certificação é composto pelas etapas descritas abaixo:

* Finalização dos estudos da certificação na universidade Sankhya

* Solicitação do exame pratico via e-mail: **<techacademy@sankhya.com.br>**

* Desenvolver um add-on nos padrões especificados no exame enviado via e-mail.

* Arquivos que devem ser enviados para correção
  * Vídeo demonstrando a utilização e funcionalidades do add-on criado
  * Arquivo .exts gerado pela task gerarAddon do Add-on Studio
  * Disponibilização do projeto desenvolvido por .zip ou via GitHub

<br />

> 🚧 Importante
>
> Vale ressaltar que o acesso à [Área do Desenvolvedor](https://areadev.sankhya.com.br/) é exclusivo para clientes Sankhya e parceiros comerciais Sankhya ([Parceiros Estratégicos](https://www.sankhya.com.br/parceiros/) e Business Partners), ou seja, a aquisição deste curso não lhe dará acesso a essas áreas, que são fundamentais para concluir a certificação.

**Observação**:

* Caso o candidato seja reprovado, deverá adquirir um novo pacote de certificação.
* Caso seja identificado que o código-fonte do add-on submetido para avaliação não foi desenvolvido pelo candidato à certificação, o mesmo será reprovado, sem direito a uma nova submissão.

## Requisitos para obter a certificação

* Concluir os cursos da trilha na Universidade Sankhya
* Ser aprovado no exame de certificação com no mínimo 90% de aproveitamento
