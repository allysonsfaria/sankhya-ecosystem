# Specialist Dashboards

A certificação **Specialist Sankhya Developer Dashboards** visa fornecer aos clientes e parceiros Sankhya a aquisição de conhecimentos e habilidades fundamentais para a criação, manutenção e desenvolvimento de dashboards dentro da plataforma Sankhya.

<Image alt="Estrutura Trilha Dashboards" align="center" src="https://files.readme.io/193644a-dash.png">
  Estrutura Trilha Specialist Dashboards
</Image>

## Objetivo

Tem como objetivo validar que os parceiros possui conhecimentos e as habilidades para implementar e personalizar dashboards na Plataforma Sankhya.

## Público-Alvo

Desenvolvedores de Dashboards na plataforma Sankhya.

## Pré-requisitos

* Conclusão da certificação **Associate Framework Dicionário de dados**
* Conhecimento em SQL;
* Conhecimento em banco de dados relacionais;

## Carga Horária Prevista

A trilha tem duração prevista de 12 horas.

## Informações Adicionais

* A trilha de treinamento é oferecida em formato EAD pela Universidade Sankhya
* A trilha de treinamento segue um modelo autodirigido, onde as dúvidas técnicas são sanadas por meio de consulta na documentação disponibilizada no [Portal Sankhya Developer](https://developer.sankhya.com.br/)

## Exame prático

O exame prático de certificação é composto pelas etapas descritas abaixo:

* Finalização dos estudos da certificação na universidade Sankhya

* Solicitação do exame pratico via e-mail: **<techacademy@sankhya.com.br>**

* Desenvolver um Dashboard nos padrões especificados no exame enviado via e-mail.

* Arquivos que devem ser enviados para correção
  * Vídeo demonstrando:
    * Funcionamento dos componentes do dashboard em todos os níveis
    * Funções onclick no SankhyaOm
    * Arquivo .xml do dashboard exportado do SankhyaOm

**Observação**:

* Caso o candidato seja reprovado, deverá adquirir um novo pacote de certificação.
* Caso seja identificado que o código-fonte da extensão submetida para avaliação não foi desenvolvido pelo candidato à certificação, o mesmo será reprovado, sem direito a uma nova submissão.
