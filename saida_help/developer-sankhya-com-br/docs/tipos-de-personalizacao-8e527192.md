# Tipos de Personalização/Customização

## Introdução

Este artigo apresenta um compilado de recursos sobre desenvolvimento de personalizações e customizações na plataforma Sankhya, como documentações de referência, artigos técnicos, cursos, dentre outros.

Na imagem abaixo, as setas indicam onde personalizações/customizações são inseridas nas diferentes camadas da plataforma Sankhya.

<Image title="arquitetura.png" alt={1343} align="center" width="80%" border={true} src="https://files.readme.io/edde005-arquitetura.png">
  Visão em camadas por tipo de personalização
</Image>

## Telas adicionais

O construtor de telas adicionais permite a criação de novas telas do tipo formulário, que podem apresentar quantidades variáveis de campos e níveis diferentes de complexidade.

Uso indicado onde há necessidade de navegação, coleta, análise, inclusão e deleção de registros visando a criação de relatórios, cubos de decisão, dashboards, regras de validação, entre outros recursos personalizados.

## Botão de ação

Botões de ação permitem a execução de rotinas de processamento mediante o acionamento manual  de um botão. Análogo à inclusão de um item.

Utilizados em ações que exigem uma lista de tarefas a serem realizadas (lançadores), em rotinas de banco de dados (procedures) e rotinas Java (criação de classes para execuções de ações).

## Gerenciador de objetos

O gerenciador de objetos permite a execução, através de uma ferramenta desenvolvida para o banco de dados,  de melhorias nos processos de criação, gerenciamento e manipulação dos elementos das telas.

Usado para criar novas regras de negócio em tabelas (objetos de banco), permite também consultar e alterar esses objetos. Também disponibiliza recursos de telemetria, para avaliação da performance dos objetos.
