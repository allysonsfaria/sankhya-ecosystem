# Comunidade

A [comunidade Sankhya Developer](https://community.sankhya.com.br/developers) conecta todas as pessoas desenvolvedoras da plataforma Sankhya, para compartilhar conhecimento, debater questões técnicas, colaborar e resolver dúvidas sobre nossas APIs, frameworks e ferramentas de desenvolvimento.

## Benefícios

* **Conhecimento**\
  Base de conhecimento compartilhado

* **Experiência**\
  Ampliação de repertório técnico

* **Colaboração**\
  Compartilhamento de ideias e criação de oportunidades

* **Agilidade**\
  Resolução rápida de problemas e rede de apoio

* **Inovação**\
  Novas formas de resolver problemas
