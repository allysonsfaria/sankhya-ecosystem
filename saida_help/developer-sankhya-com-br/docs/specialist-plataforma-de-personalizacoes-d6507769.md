# Specialist Plataforma de Personalizações

A certificação **Specialist Sankhya Developer Plataforma de personalizações** visa fornecer aos clientes e parceiros Sankhya a aquisição de conhecimentos e habilidades fundamentais para a criação, manutenção e desenvolvimento de telas adicionais, campos adicionais, eventos programados, botões de ação, ações agendadas, callback, utilização do gerenciador de objetos e de regras de negócio da plataforma Sankhya.

<Image alt="Estrutura Trilha Specialist Plataforma de personalizações" align="center" src="https://files.readme.io/4cb7047-plataforma.png">
  Estrutura Trilha Specialist Plataforma de personalizações
</Image>

## Objetivo

Tem como objetivo validar que os parceiros possui conhecimentos e as habilidades para implementar e criar telas adicionais na Plataforma Sankhya.

## Público-Alvo

Desenvolvedores que desejam personalizar a plataforma Sankhya com a criação de novas telas, botões de ação, ações agendadas, eventos programados entre outros recursos.

## Pré-requisitos

* Conclusão da certificação **Associate Framework Dicionário de Dados**

* Conclusão da certificação **Associate Framework Back-end**

* Conhecimento em Java SE

* Conhecimento em desenvolvimento com o framework Java EE;

* Conhecimento em banco de dados relacionais;

* Conhecimento em SQL;

## Carga Horária Prevista

A trilha tem duração prevista de 20 horas.

## Informações Adicionais

* A trilha de treinamento é oferecida em formato EAD pela Universidade Sankhya
* A trilha de treinamento segue um modelo autodirigido, onde as dúvidas técnicas são sanadas por meio de consulta na documentação disponibilizada no [Portal Sankhya Developer ](https://developer.sankhya.com.br/)

## Exame prático

O exame prático de certificação é composto pelas etapas descritas abaixo:

* Finalização dos estudos da certificação na universidade Sankhya

* Solicitação do exame pratico via e-mail: **<techacademy@sankhya.com.br>**

* Desenvolver uma tela personalizada nos padrões especificados no exame enviado via e-mail.

* Arquivos que devem ser enviados para correção

  * Vídeo demonstrando a utilização e funcionalidades de cada personalização criada (Campos, eventos, botões, etc )

  * Arquivo .jar com os códigos java e sql utilizados na personalizações

**Observação**:

* Caso o candidato seja reprovado, deverá adquirir um novo pacote de certificação.
* Caso seja identificado que o código-fonte da extensão submetida para avaliação não foi desenvolvido pelo candidato à certificação, o mesmo será reprovado, sem direito a uma nova submissão.
