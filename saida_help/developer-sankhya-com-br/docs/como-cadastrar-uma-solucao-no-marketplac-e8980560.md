# Como cadastrar uma solução no Marketplace via Portal do Desenvolvedor

Após criar a solução de tipo comercial no [Portal do Desenvolvedor](areadev.sankhya.com.br), o usuário deverá cadastrar o anúncio via aba **Marketplace** dentro da solução no menu **Minhas Soluções**.

Atenção: A aba **Marketplace** está disponível exclusivamente para soluções do tipo *Comercial*.

![](https://files.readme.io/d823955321cb5d2cf4f65cf5a1f354172858144dacd5c5032a452ccb2de178b9-image.png)

Na aba **Marketplace** o usuário pode:

* Criar um novo anúncio;
* Salvar como rascunho para finalizar depois;
* Publicar o anúncio da solução no Marketplace.

<Callout icon="➡️" theme="default">
  ### Criar uma solução do tipo Comercial não significa que ela ficará visível automaticamente no Marketplace.

  Para que isso aconteça, o usuário deverá cadastrar e publicar o anúncio na aba Marketplace, dentro da própria solução.
</Callout>

<br />

### Informações para anunciar no Marketplace

**Informações Básicas (obrigatórias):**

* Nome da Solução → Digite um título claro e objetivo.
* Descrição da Solução → Explique de forma resumida o que a solução faz.
* Principais Benefícios → Liste os pontos fortes.

**Imagens e Vídeo:**

* Logo da Solução (obrigatório) → Preferencialmente quadrada, fundo transparente.
* Galeria de Imagens (opcional) → Mostre telas ou materiais de apoio.
* Vídeo (opcional) → Link do YouTube que apresente a solução.

**Categoria e Tipo:**

* Categoria (obrigatório) → Defina a área do Marketplace (ex.: Financeiro, RH, Vendas).
* Tipo da Solução (obrigatório) → Ex.: aplicativo, integração ou serviço.

**Contatos:**

* E-mail Principal (obrigatório) → Preenchido automaticamente e não pode ser alterado.
* E-mails em Cópia (opcional) → Outros endereços que também receberão notificações.

<br />

### Como publicar o anúncio no Marketplace

* Salvar Rascunho → Guarda informações mesmo sem todos os campos obrigatórios.
* Salvar e Publicar → Valida os dados obrigatórios e publica a solução no Marketplace.

<br />

### Avisos importantes:

* Se algum campo obrigatório não estiver preenchido, o sistema exibirá uma mensagem indicando o que precisa ser corrigido.
* Após salvar como rascunho, o usuário pode retornar a qualquer momento para continuar.
* Após publicar com sucesso, o sistema confirmará que o anúncio já está disponível no Marketplace.

<br />

### Boas Práticas

* Utilize nomes claros e objetivos para facilitar a busca.
* Na descrição, destaque benefícios e diferenciais, não apenas características técnicas.
* Garanta que logo e imagens tenham boa qualidade.
* Se possível, adicione vídeo ou imagens extras para tornar o anúncio mais atrativo.
