# Configuração Inicial do Add-on Studio

Nesta seção, você encontrará tudo o que precisa para configurar seu ambiente de desenvolvimento e começar a criar add-ons com o Add-on Studio.

## 📚 Tópicos

1. [**Configuração do Ambiente**](./01_ambiente): Passos detalhados para instalar e configurar o Java (JDK), Gradle e outras ferramentas essenciais.
2. [**Registro do Add-on**](./02_registro_addon): Como registrar seu componente na Área do Desenvolvedor Sankhya para obter as credenciais necessárias.
3. [**Configuração do Projeto**](./03_conf_addonstudio): Um guia para ajustar o projeto baixado, incluindo o `build.gradle` e outras configurações importantes.
4. [**Testando sua Configuração**](./04_teste): Como executar um primeiro teste para garantir que seu ambiente está pronto para o desenvolvimento.
