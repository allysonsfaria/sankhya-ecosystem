# Specialist Relatórios Formatados

A certificação **Specialist Sankhya Developer Relatórios Formatados** visa fornecer aos clientes e parceiros Sankhya a aquisição de conhecimentos e habilidades fundamentais para a criação e manutenção de relatórios formatados utilizando o iReport entro da plataforma Sankhya.

<Image alt="Estrutura trilha Relatórios Formatados" align="center" src="https://files.readme.io/e5fac2c-relatorio_formatados.png">
  Estrutura trilha Specialist Relatórios Formatados
</Image>

## Objetivo

Tem como objetivo validar que os parceiros possui conhecimentos e as habilidades para implementar e personalizar relatórios formatados para criação visual dos arquivos .jrxml na Plataforma Sankhya.

## Público-Alvo

Desenvolvedores de relatórios formatados na plataforma Sankhya.

## Pré-requisitos

* Conclusão da certificação **Associate Framework Dicionário de dados**
* Conhecimento em SQL
* Conhecimento em banco de dados relacionais
* Conhecimento e vivencia com a ferramenta JasperReports - Ireport

## Exame prático

O exame prático de certificação é composto pelas etapas descritas abaixo:

* Finalização dos estudos da certificação na universidade Sankhya

* Solicitação do exame pratico via e-mail: **<techacademy@sankhya.com.br>**

* Desenvolver um relatório formatado nos padrões especificados no exame enviado via e-mail.

* Arquivos que devem ser enviados para correção
  * Vídeo demonstrando a utilização e funcionalidades do relatório criado
  * Arquivo .jxrml gerado pelo iReport
  * Arquivo .pdf do relatório exportado do SankhyaOM
  * Arquivo .xlsx Planilha exportada do relatório se estra tarefa for realizada. .

**Observação**:

* Caso o candidato seja reprovado, deverá adquirir um novo pacote de certificação.
* Caso seja identificado que o código-fonte da extensão submetida para avaliação não foi desenvolvido pelo candidato à certificação, o mesmo será reprovado, sem direito a uma nova submissão.

## Requisitos para obter a certificação:

* Concluir os cursos da trilha na Universidade Sankhya
* Ser aprovado no exame de certificação com no mínimo 90% de aproveitamento
