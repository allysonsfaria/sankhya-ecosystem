# Como obter acesso ao Portal do Desenvolvedor como Desenvolvedor Externo

E o que o cliente deve fazer para conceder acesso as soluções para desenvolvedores externos

Se você é um desenvolvedor externo e ainda não possui cadastro no **Programa Sankhya Developer** nem acesso ao **Portal do Desenvolvedor**, siga os passos abaixo:

### 1. Cadastre-se no Programa Sankhya Developer

* Acesse: <https://www.sankhya.com.br/developers/>
* Preencha os dados da empresa para criar seu cadastro.

<Callout icon="📧" theme="default">
  ### Todas as comunicações serão feitas por e-mail. O prazo de retorno é de até 5 dias úteis.
</Callout>

### 2. Acesse o Portal do Desenvolvedor

* Após a aprovação do cadastro, entre em: <https://areadev.sankhya.com.br/>
* Nesse ambiente, você poderá visualizar as soluções compartilhadas.

### 3. Solicite que o cliente crie e compartilhe a solução

O cliente (empresa contratante), por meio de um usuário com nível *Administrador*, deverá:

1. Convidar o seu usuário (empresa contratada) no menu **Gestão de Acessos**, como *Desenvolvedor externo*.
2. Criar um grupo de permissões no menu **Gestão de Acessos** e vincular seu usuário a esse grupo, atribuindo as permissões necessárias.
3. Criar a solução no menu **Minhas Soluções** e vinculá-la ao grupo ao qual você, como desenvolvedor externo, está associado.

### 4. Acesse as soluções compartilhadas

Depois do vínculo feito pelo cliente, você poderá acessar a solução pelo menu **Compartilhadas comigo** no seu Portal do Desenvolvedor, realizando a manutenção conforme as permissões concedidas.
