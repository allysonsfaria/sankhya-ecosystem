# Como Iniciar uma Integração com a Sankhya?

Para iniciar uma integração com uma solução do Ecossistema Sankhya, é necessário seguir alguns passos iniciais obrigatórios. O processo tem início na [Área do Desenvolvedor](https://areadev.sankhya.com.br/), onde deve ser registrada uma nova solução de integração. Após o registro, é preciso gerar um token de autenticação vinculado à solução criada — esse token será utilizado para autorizar as requisições às APIs da Sankhya.

<br />

> 🚧 Atenção
>
> Vale ressaltar que o acesso à [Área do Desenvolvedor](https://areadev.sankhya.com.br/) é exclusivo para clientes Sankhya, parceiros comerciais Sankhya ([Parceiros Estratégicos](https://www.sankhya.com.br/parceiros/) e Business Partners) e [Desenvolvedores Credenciados](https://go.sankhya.com.br/developers/).
>
> Para qualquer outro caso é necessário solicitar que o cliente gere as chaves (Clientes e Tokens) para que as soluções (integração e/ou add-on) sejam desenvolvidas. Ou seja, caso você seja um desenvolvedor externo e precise criar uma integração ou add-on para um cliente Sankhya, solicite que o cliente realize os procedimentos que vem a seguir.
