# Compra com base em Pedidos de venda

### Descrição

Esta funcionalidade permite que os usuários responsáveis pela análise de compras acessem relatórios específicos de sugestão de compras com base nos pedidos de venda por encomenda. O acesso é restrito a usuários autorizados.

**Relatório Disponível**

- Relatório **113 – Sugestão de compra para pedidos de venda**.

### Como instalar

1. Clique em **"Iniciar"**.
2. Selecione os usuários e/ou grupos responsáveis pela análise dos relatórios de compra com base nos pedidos de venda.
3. Clique em **"Avançar"**.
4. Revise o resumo das informações que serão configuradas.
5. Clique em **"Instalar"** para finalizar a configuração.

### Detalhes da instalação

Para cada usuário informado, o sistema realiza os acessos abaixo:

- TDDPER – Acesso a tela de relatórios de entrada e saída.
- TSIACI – Controle de Acesso dos Relatórios.
  - **113 Sugestão de compra para pedidos de venda**.

### Como simular

Para acessar os relatórios de análise de compra com base em pedidos de venda:

Vá até Comercial > Relatórios > Entradas e Saídas.

1. Clique na seta ao lado de Indicadores para abrir a árvore de opções.
2. Clique na seta de Compras.
3. Clique na seta de Análise de necessidade de compra.

Você verá o seguinte relatório:

**113 – Sugestão de compra p/ Pedido de venda**.

O controle de reposição é feito com base no estoque da empresa e na quantidade do produto nos pedidos de venda pendentes e confirmados.

Para calcular a quantidade necessária e garantir que o estoque atenda aos pedidos de venda, informe o código da empresa cadastrado no sistema.

💡 **Vale saber**

Esse relatório é ideal para quem trabalha com encomendas. Ele cruza os pedidos de venda já confirmados com o estoque atual, indicando exatamente o que precisa ser comprado. Assim, você evita compras em excesso e garante que nenhum pedido fique sem atendimento. Antes de instalar, vale revisar se os usuários selecionados têm permissão para acessar os dados de venda.
