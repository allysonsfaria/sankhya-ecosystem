# Antecipação de Recebíveis

### Descrição

A funcionalidade **Antecipação de Recebíveis** permite configurar os acessos dos usuários responsáveis por registrar operações financeiras que envolvem o recebimento antecipado de valores futuros, garantindo maior controle sobre o fluxo de caixa e a saúde financeira da empresa.

Ela oferece os seguintes recursos:

- **Gestão de Antecipação de Recebíveis**: Permite consultar, incluir, alterar e excluir registros de antecipações.
- **Liberação de Acessos**: Concede acesso à funcionalidade específica para os usuários selecionados, viabilizando o uso do recurso conforme as permissões definidas.

### Como instalar

1. Clique em **"Iniciar"**.
2. Selecione os grupos e/ou usuários responsáveis pela antecipação de recebíveis.
3. Clique em **"Avançar"** para revisar as informações.
4. Clique em **"Instalar"** para concluir a configuração.

### Detalhes da instalação

**Acessos liberados**

- **Antecipação de Recebíveis**
  **Caminho**: Financeiro >> Rotinas >> Antecipação de Recebíveis
  **Permissões:** Consultar, Incluir, Alterar, Excluir
