# 05. O que é o mapeador de função?

A criação de uma nova função no sistema consiste em preencher um questionário para mapear uma posição ou cargo. Nosso sistema possui uma base de posições criada por meio de uma pesquisa com mais de 130 mil empresas, e elas funcionarão como um fundamento da sua. Assim sendo, na primeira etapa, você deverá selecionar até 3 posições que são relacionadas ou parecidas com a sua para utilizar como base. Não tem problema se não existir exatamente a sua (é bastante improvável mesmo); o importante é escolher algumas relacionadas para que você consiga a partir delas montar a sua.

Quando você selecionar as 3 posições mais parecidas com a sua, o sistema irá guiá-lo em um processo de priorização para podermos extrair de fato as tarefas mais essenciais para que você realize o que é esperado da posição. As frases não serão totalmente específicas, mas também não serão genéricas demais.

Lembre-se, o importante é entendermos a relativa relevância das tarefas mais importantes, e não uma descrição de cargos detalhada. O processo deve demorar algo em torno de 7-10 minutos apenas.
