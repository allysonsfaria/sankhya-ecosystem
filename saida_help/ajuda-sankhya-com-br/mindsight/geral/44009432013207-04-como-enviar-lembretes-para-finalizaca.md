# 04. Como enviar lembretes para finalização dos testes

Hoje existem duas formas de filtrar os candidatos pendentes de finalizar os testes para enviar lembretes:

## Enviar lembrete de finalização dos testes

1. No **dashboard da vaga** temos a opção “pendentes de finalizar o teste” clicando aqui o sistema informa os candidatos que ainda não responderam e também da a possibilidade para o usuário enviar um lembrete aos candidatos pendentes:

   ![Imagem 1: No dashboard da vaga temos a opção “pendentes de finalizar o teste” clicando aqui o sistema informa os candidatos que…](https://ajuda.sankhya.com.br/hc/article_attachments/44009410344599)
2. O usuário também pode utilizar o campo de filtro na tela "Analisar Candidatos" para selecionar quem ainda não respondeu e enviar os testes:

   ![Imagem 2: O usuário também pode utilizar o campo de filtro na tela "Analisar Candidatos" para selecionar quem ainda não respondeu…](https://ajuda.sankhya.com.br/hc/article_attachments/44009457902231)
