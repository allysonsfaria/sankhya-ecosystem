# 08. O que as notas de Atributo indicam?

As notas de atributo indicam uma leitura mais precisa do perfil de uma pessoa. Basicamente, cada um dos atributos leva em conta tanto a nota que a própria pessoa se avaliou no teste de perfil, quanto as notas conquistadas nos testes de raciocínio fluido, social e motivacional. As cores indicam qual parte do modelo (mental, social, motivacional) o atributo tem como base.
