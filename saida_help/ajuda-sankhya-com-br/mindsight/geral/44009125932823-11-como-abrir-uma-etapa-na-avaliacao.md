# 11. Como abrir uma etapa na avaliação?

![Imagem 1](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/Vis%C3%A3o%20de%20RH%20PT-png-4.png)

A abertura de cada etapa é essencial para garantir que todos os passos da rodada de avaliação sejam realizados corretamente e que apenas as pessoas autorizadas possam visualizá-las. Abaixo, apresentamos um passo a passo para abrir uma etapa na rodada de avaliação:

1. ## Acesse o módulo de Desempenho com a visão administrativa:

   O primeiro passo é acessar a rodada de avaliação dentro do módulo de Desempenho. Certifique-se de realizar todas as etapas no ciclo correto.
2. ## Clique em "Configurações" no menu:

   Ao acessar a rodada como administrador, o sistema automaticamente direcionará você para essa opção. Caso isso não ocorra, basta localizá-la no menu superior:

   ![Imagem 2: Ao acessar a rodada como administrador, o sistema automaticamente direcionará você para essa opção. Caso isso não…](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/image-png-May-28-2025-08-14-01-8299-PM.png)
3. ## Selecione a opção "Configurar Etapas"

   Neste campo, você encontrará as opções de etapas disponíveis:

   - **Etapa de Indicações**: Nessa fase, os participantes podem indicar outras pessoas para avaliá-los, caso essa configuração tenha sido solicitada na parametrização.
   - **Etapa de Validação para Gestores**: Durante essa fase, os gestores validam as indicações para decidir se serão aprovadas ou não.
   - **Etapa de Avaliações**: Esta é uma das etapas principais, onde as avaliações são liberadas para os participantes responderem.
   - **Etapa de Calibração**: Exclusiva para administradores e RH, essa etapa envolve a revisão dos resultados para garantir um consenso nas notas e assegurar que as avaliações sejam precisas.

Quando as etapas estão fechadas, elas são apresentadas dessa forma:

![Imagem 3: Quando as etapas estão fechadas, elas são apresentadas dessa forma:](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/image-png-Mar-21-2025-03-26-03-1085-PM.png)

Para abrir, basta clicar na toggle do lado esquerdo, assim, mudará de **fechada** para **aberta**:

![Imagem 4: Para abrir, basta clicar na toggle do lado esquerdo, assim, mudará de fechada para aberta :](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/image-png-Mar-21-2025-03-26-35-0957-PM.png)

Após a finalização de todas as etapas, é possível abrir a visualização dos resultados. Para isso, você pode seguir os mesmos passos e ativar essa etapa:

![Imagem 5: Após a finalização de todas as etapas, é possível abrir a visualização dos resultados. Para isso, você pode seguir os…](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/image-png-Mar-21-2025-03-35-59-7279-PM.png)

A exibição dos resultados pode ser personalizada nas configurações de devolutiva, permitindo que os participantes vejam apenas as informações que você deseja liberar. Se tiver dúvidas sobre como realizar essa configuração, consulte o artigo: **[Como configurar as devolutivas?](https://sankhya.zendesk.com/hc/pt-br/articles/44008741190039)**

Se precisar de suporte ou tiver alguma dúvida, estamos à disposição para ajudar!
