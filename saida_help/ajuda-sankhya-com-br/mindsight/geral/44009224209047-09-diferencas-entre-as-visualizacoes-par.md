# 09. Diferenças entre as visualizações para o BP

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44009211565591)

Quando se é um(a) BP é possível transitar entre 3 tipos de acessos na etapa de resultados.

- **Visualizar como avaliado(a):** você terá a visão as informações como se fosse o(a) colaborador(a).

Nessa visão, você terá o acesso igual quando o(a) colaborador(a) acessa a plataforma, para entender e ver em detalhes, leia o artigo: **[02. Meus resultados.](https://suporte.mindsight.com.br/02.-meus-resultados)**

- **Visualizar como avaliador(a):** você terá a visão as informações como se fosse algum avaliador(a).

Nessa visão, você só terá acesso às respostas dadas pelos(as) participantes no grupo autoavaliação.

- **Visualizar como gestor(a)**: você terá a visão e os mesmos acessos às informações como se fosse o(a) o gestor do colaborador(a).

Nessa visão, você terá o acesso completo que um gestor tem quando acessa o painel do(a) colaborador(a), para entender e ver em detalhes, leia o artigo: **[03. Como visualizar os resultados da minha equipe?](https://suporte.mindsight.com.br/03.-como-visualizar-os-resultados-da-minha-equipe)**.
