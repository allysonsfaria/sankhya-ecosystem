## Como criar um novo objetivo?

Para cadastrar um objetivo:

1. Acesse a rodada de PDI;
2. Clique em +**Novo**;
3. Preencha as informações do objetivo;
4. Clique em **Incluir objetivo**.

Após a confirmação, o objetivo ficará disponível no seu painel.

## O que significa cada campo?

Ao criar um objetivo, você encontrará os seguintes campos:

- **Nome do objetivo:** título do objetivo;
- **Descrição (opcional):** detalhes adicionais sobre o objetivo;
- **Data de início:** data em que o objetivo começa;
- **Data final:** prazo previsto para conclusão;
- **Nova tarefa:** permite cadastrar tarefas relacionadas ao objetivo.

## Como adicionar uma tarefa?

Durante a criação do objetivo, clique em +**Nova tarefa** para incluir uma ou mais tarefas.

Preencha as informações da tarefa:

- **Nome:** título da tarefa;
- **Data de início;**
- **Data final;**
- **Descrição (opcional).**

Você pode adicionar quantas tarefas forem necessárias antes de salvar o objetivo.

## Como editar um objetivo ou uma tarefa?

Se precisar alterar um objetivo ou uma tarefa já cadastrados:

1. Na tela inicial do PDI, localize o objetivo desejado;
2. Clique em **Atualizar**;
3. Clique em **Editar**.

Nessa tela, você poderá alterar:

- nome do objetivo;
- descrição;
- datas do objetivo;
- informações das tarefas.

Após realizar as alterações, clique em **Salvar alterações**.

## Como adicionar uma nova tarefa a um objetivo existente?

Também é possível incluir novas tarefas em um objetivo já criado.

Para isso:

1. Acesse **Atualizar**;
2. Clique em **Editar**;
3. Selecione **Nova tarefa**;
4. Preencha as informações da nova tarefa;
5. Clique em **Salvar alterações**.

A nova tarefa será vinculada ao objetivo existente.

## Como excluir uma tarefa?

### Para remover uma tarefa:

1. Acesse **Atualizar**;
2. Clique em **Editar**;
3. Clique no ícone de exclusão da tarefa desejada;
4. Salve as alterações.

Apenas a tarefa selecionada será removida.

### Para excluir um objetivo:

1. Acesse **Atualizar**;
2. Clique em **Editar**;
3. Clique no ícone de exclusão do objetivo;
4. Confirme a exclusão.

**Atenção:** ao excluir um objetivo, todas as tarefas vinculadas a ele também serão removidas.

## Resumo das ações

| Ação | Caminho |
| --- | --- |
| Criar objetivo | +Novo → Incluir objetivo |
| Adicionar tarefa | +Novo → +Nova tarefa |
| Editar objetivo | Atualizar → Editar |
| Editar tarefa | Atualizar → Editar |
| Adicionar tarefa em objetivo existente | Atualizar → Editar → Nova tarefa |
| Excluir tarefa | Atualizar → Editar → Excluir tarefa |
| Excluir objetivo | Atualizar → Editar → Excluir objetivo |

Esse fluxo permite criar, organizar e manter seus objetivos e tarefas atualizados durante todo o acompanhamento do PDI.
