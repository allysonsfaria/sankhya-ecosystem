# 01. Como utilizar a Gestão de Acessos

A gestão de acessos permite que você gerencie as permissões de acesso dos usuários colaboradores cadastrados no ATS.

**Cadastro de usuários**

Para cadastrar novos usuários, basta enviar uma planilha com o nome e e-mail dos colaboradores que devem ter acesso ao ATS para o time de suporte da Mindsight: **[Como entrar em contato com o suporte?](https://candidato.mindsight.com.br/pt-br/02.-como-entrar-em-contato-com-o-suporte-da-mindsight)**

**Perfil de acesso**

1. Em “Configurações” temos a aba “Gestão de acessos” que permite a personalização dos acessos dos usuários cadastrados na ATS
2. Em “Perfil de acesso” teremos a lista de todos os perfis (com permissões) já criados![Imagem 1: Em “Perfil de acesso” teremos a lista de todos os perfis (com permissões) já criados](https://ajuda.sankhya.com.br/hc/article_attachments/44009516447639)
3. No botão “Novo Perfil” é possível criar diferentes perfis de acesso![Imagem 2: No botão “Novo Perfil” é possível criar diferentes perfis de acesso](https://ajuda.sankhya.com.br/hc/article_attachments/44009486052759)

## Tipos de permissões:

**Visualizar apenas vagas marcadas:**

- Usuário só consegue visualizar, alterar o status e fazer gestão dos candidatos nas vagas em que está marcado em “Time de recrutamento” como uma das opções: Recrutador responsável, Gestor da vaga ou Envolvidos;

**❗ATENÇÃO:** Se o usuário que criar a vaga tiver a permissão “**Visualizar apenas vagas marcadas”** e remover-se de um dos campos “Time de Recrutamento” ele não conseguirá acessar a vaga no futuro.

![Imagem 3: ❗ATENÇÃO: Se o usuário que criar a vaga tiver a permissão “ Visualizar apenas vagas marcadas” e remover-se de um dos…](https://ajuda.sankhya.com.br/hc/article_attachments/44009474645655)

**Visualizar todas as vagas**

- Usuário visualiza e alterar o status e faz gestão dos candidatos de todas as vagas do ATS

**Criação e Edição de Vagas**

- Usuário pode editar vagas já criadas
- Usuário pode criar novas vagas,

**Banco de talentos:**

- Acesso e gestão de todos os candidatos no Banco de Talentos

**Configurações:**

- Acesso e gestão a todas as configurações do ATS

❗ATENÇÃO: A permissão de visualizar configurações é recomendada somente para usuários administradores do sistema.

**Relatórios:**

- Acesso à tela de extração de relatórios do sistema:

❗ ATENÇÃO: O usuário só pode ter acesso à aba de relatórios se tiver a opção “Visualizar todas as vagas” marcada.

**Alterar perfil de acesso**

Em “Usuários” é possível alterar o perfil de acesso dos usuários já cadastrados no sistema:

![Imagem 4: Em “Usuários” é possível alterar o perfil de acesso dos usuários já cadastrados no sistema:](https://ajuda.sankhya.com.br/hc/article_attachments/44009503511959)

Nessa tela também é possível alterar:

- Nome do usuário
- E-mail do usuário
