# 04. Devo agregar alguma tag ao meu mapeamento?

As tags são utilizadas para restringir a visualização de algum membro. Então apenas use tags caso possua membros com tags na plataforma. Os membros com tag tem acesso somente aos mapeamentos com a mesma tag.
