# 05. Como atualizar os resultados de uma meta?

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44009649353239)

**Os passos abordados nesse artigo podem ser aplicados tanto para metas numéricas quanto para metas projetos.**

Na tela inicial do seu painel de metas, é possível você atualizar os resultados das metas que cadastro. **Desde que você esteja na etapa de acompanhamento.** Para entender a diferença entre as etapas, veja o artigo: **[O que são as etapas de Planejamento e Acompanhamento?](https://suporte.mindsight.com.br/06.-o-que-s%C3%A3o-as-etapas-de-planejamento-e-acompanhamento)**

Para atualizar os resultados é simples! Basta seguir os seguintes passos:

- Procure a meta que deseja atualizar;
- Ao do título dela, procure o botão “**Atualizar Resultado**”;

![Imagem 2: Ao do título dela, procure o botão “ Atualizar Resultado ”;](https://ajuda.sankhya.com.br/hc/article_attachments/44009647491351)

- Depois atualize o resultado da meta ou do ponto de acompanhamento conforme o seu preenchimento;
- Se quiser, é possível inserir um comentário;
- Depois clique em “**Atualizar Resultado**”

![Imagem 3: Depois clique em “ Atualizar Resultado ”](https://ajuda.sankhya.com.br/hc/article_attachments/44009647758871)

## ❗ATENÇÃO❗

SÓ É POSSÍVEL ATUALIZAR OS RESULTADOS SE A ETAPA DE ATUALIZAÇÃO FOR LIBERADA PELO ADMIN DO SISTEMA E SE VOCÊ FOR UM DOS DONOS DA META OU O(A) DATA PROVIDER DESSA META.
