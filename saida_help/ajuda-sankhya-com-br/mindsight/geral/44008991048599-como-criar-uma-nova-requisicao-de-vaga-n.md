# Como criar uma nova requisição de vaga no ATS?

A funcionalidade de requisição de vagas permite iniciar um processo estruturado de aprovação antes da criação de uma nova vaga no ATS. Veja como criar uma nova requisição:

## Passo a passo:

1. Acesse o menu horizontal do ATS e clique em **Requisições**.

![Imagem 1: Acesse o menu horizontal do ATS e clique em Requisições .](https://ajuda.sankhya.com.br/hc/article_attachments/44009005680791)

2. Clique em **Nova Requisição**.

![Imagem 2: 2. Clique em Nova Requisição . 3. Preencha os campos obrigatórios, como título da vaga, quantidade de posições e faixa…](https://ajuda.sankhya.com.br/hc/article_attachments/44009028657175)

3. Preencha os campos obrigatórios, como título da vaga, quantidade de posições e faixa salarial.

4. Selecione um **modelo de requisição** previamente configurado.

5. No campo **Envolvidos**, insira os usuários que devem acompanhar as movimentações (mesmo que não sejam aprovadores).

6. Clique em **Salvar e Iniciar Fluxo** para dar início ao processo de aprovação.

⚠️ Após iniciar o fluxo, a requisição segue para o primeiro aprovador indicado no modelo. Esse usuário receberá um e-mail com o link para aprovar ou reprovar a etapa.

![primeiro e-mail de requisição de vaga](https://ajuda.sankhya.com.br/hc/article_attachments/44009015257111)

**❓FAQ**

- **Posso mudar o modelo de requisição depois que a requisição foi criada?**
  Não. O modelo é fixado após a criação.

- **Posso editar os campos da requisição após início do fluxo?**
  Sim, mas apenas campos específicos, e o modelo não pode ser alterado.

- **O que acontece se um aprovador for desativado?**
  O sistema impede a exclusão do usuário até que ele seja desvinculado do modelo.

- **A reprovação finaliza a requisição?**
  Sim. Ela não poderá ser retomada.

- **Recebo notificação de nova etapa?**
  Sim, via e-mail automático com link direto para aprovação.
