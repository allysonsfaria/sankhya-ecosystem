# 03. O que são as tags e como posso utilizá-las?

As tags são utilizadas para restringir a visualização de certos membros ao sistema. Quando utilizada uma tag, como, por exemplo, #financeiro, este membro apenas poderá visualizar mapeamentos que possuírem a mesma tag.

As tags somente funcionam para membros Gestor e Funcionário, membros Admins conseguem acessar todos os mapeamentos independente da tags. Só será possível atribuir tag a um membro após a tag já estar cadastrada em algum mapeamento existente.
