# 02. Como abrir uma vaga com os testes da Mindsight?

Após criar uma vaga na workable, acesse a aba de Workflow para habilitar os testes.

![Imagem 1: Após criar uma vaga na workable, acesse a aba de Workflow para habilitar os testes.](https://ajuda.sankhya.com.br/hc/article_attachments/44009323497879)

Na página de configuração do assessment test, selecione o Mindmatch e a aplicação a ser dada a vaga.

![Imagem 2: Na página de configuração do assessment test, selecione o Mindmatch e a aplicação a ser dada a vaga.](https://ajuda.sankhya.com.br/hc/article_attachments/44009323658135)

Na página view job é possível visualizar candidatos e mover eles para a etapa de testes.

![Imagem 3: Na página view job é possível visualizar candidatos e mover eles para a etapa de testes.](https://ajuda.sankhya.com.br/hc/article_attachments/44009278179223)

![Imagem 4: Na página view job é possível visualizar candidatos e mover eles para a etapa de testes.](https://ajuda.sankhya.com.br/hc/article_attachments/44009324000663)
