# 06. Como aprovar ou reprovar uma solicitação de indicação sendo BP?

![Imagem 1](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/Vis%C3%A3o%20de%20RH%20PT-png-May-22-2025-08-10-18-2569-PM.png)

Neste artigo, abordaremos os seguintes tópicos:

- **[Status das Indicações](https://sankhya.zendesk.com/hc/pt-br/articles/44008717262743)**
- **[Aprovar ou reprovar solicitações](https://sankhya.zendesk.com/hc/pt-br/articles/44008717262743)**

**1 - STATUS DAS INDICAÇÕES**

Com a visão de RH, é possível realizar as seguintes movimentações dentro da etapa de indicação:

- Incluir uma indicação;
- Excluir uma indicação.
- Aprovar solicitação de indicação;
- Reprovar solicitação de indicação;
- Troca de grupo avaliativo de uma indicação.

Para realizar a inclusão de uma indicação, veja o artigo: [Como realizar a inclusão de indicações?](https://suporte.mindsight.com.br/05.-como-realizar-a-inclus%C3%A3o-de-indica%C3%A7%C3%B5es), para realizar a exclusão de uma indicação, veja o artigo: **[Como realizar a exclusão de indicações?](https://suporte.mindsight.com.br/01.-como-realizar-a-exclus%C3%A3o-de-indica%C3%A7%C3%B5es-1)** e para realizar a troca de grupo avaliativo de uma indicação, veja o artigo: **[Como realizar a troca de grupo avaliativo de indicações?](https://suporte.mindsight.com.br/03.-como-realizar-a-troca-de-grupo-avaliativo-de-indica%C3%A7%C3%B5es)**.

Para realizar a aprovação ou a reprovação da indicação, é simples. Primeiro troque para a visão de RH no menu superior.

[GIF animado: Imagem 2: Para realizar a aprovação ou a reprovação da indicação, é simples. Primeiro troque para a visão de RH no menu superior.](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/Troca%20de%20Visao-gif.gif)

Você será direcionado(a) para a tela de rodada cadastradas no sistema da sua empresa, clique na avaliação vigente e será automaticamente direcionado(a) para a tela de “**Status das Indicações**” em que fará o acompanhamento da etapa de indicação. E nesta tela, você poderá ver se existe alguma pendência de indicação ou realizar a modificação em alguma.

![Imagem 3: Você será direcionado(a) para a tela de rodada cadastradas no sistema da sua empresa, clique na avaliação vigente e…](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/status%20indica%C3%A7%C3%A3o%20avd%20RH-png.png)

Existirão duas abas para esta tela, a primeira “**Participantes**” em que poderá verificar as indicações todos os participantes e “**Gestores**” onde poderá verificar as indicações por gestor, você pode usar também a barra de busca para encontrar um usuário específico. As aprovações e reprovações ocorrem iguais aos acessos citados nos tópicos anteriores.

Existe a possibilidade de filtrar as pendências com o filtro acima da lista de participantes, e você pode configurar também a visualização das colunas em que aparecerão as informações dos gestores e/ou participantes.

[GIF animado: Imagem 4: Existe a possibilidade de filtrar as pendências com o filtro acima da lista de participantes, e você pode configurar…](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/INDICACOES%202%20avd-gif.gif)

Uma outra funcionalidade bastante interessante, é o botão “**Exportar Status das Indicações”** em que você pode exportar todas as informações sobre as etapas de indicações em formato Excel, mostrando as pendências (caso haja), quantidade de indicações aprovadas e reprovadas.

Ao realizar o download, a planilha exportada virá no seguinte formato:

![Imagem 5: Ao realizar o download, a planilha exportada virá no seguinte formato:](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/exporta%C3%A7%C3%A3o%20de%20indica%C3%A7%C3%A3o%20avd-png.png)

Perceba que neste formato, você terá acesso às respostas dadas pelos(as) participantes em cada grupo avaliativo. Sendo assim, as colunas terão as seguintes informações:

- **Chave:**Chave do(a) avaliado(a), que pode ser CPF ou E-mail;
- **Nome:**Nome do(a) avaliado(a);
- **Nome do Gestor:**Nome do(a) Gestor(a) direto daquele(a) participante;
- **Total:**Total de indicações feitas para aquele(a) participante;
- **Total de Adição:** Total de indicações adicionadas para aquele(a) participante;
- **Total de Remoção:**Total de indicações removidas para aquele(a) participante;
- **Total no Grupo Autoavaliação:**Total de indicações feitas para aquele(a) participante no grupo autoavaliação;
- **Total de Adição no Grupo Autoavaliação:**Total de indicações adicionadas para aquele(a) participante no grupo autoavaliação;
- **Total de Remoção no Grupo Autoavaliação:**Total de indicações removidas para aquele(a) participante no grupo autoavaliação;
- **Total no Grupo Time:**Total de indicações feitas para aquele(a) participante no grupo time;
- **Total de Adição no Grupo Time:**Total de indicações adicionadas para aquele(a) participante no grupo time;
- **Total de Remoção no Grupo Time:**Total de indicações removidas para aquele(a) participante no grupo time;
- **Total no Grupo Gestor:**Total de indicações feitas para aquele(a) participante no grupo gestor;
- **Total de Adição no Grupo Gestor:**Total de indicações adicionadas para aquele(a) participante no grupo par;
- **Total de Remoção no Grupo Gestor:**Total de indicações removidas para aquele(a) participante no grupo gestor;
- **Total no Grupo Par:**Total de indicações feitas para aquele(a) participante no grupo par;
- **Total de Adição no Grupo Par:**Total de indicações adicionadas para aquele(a) participante no grupo par;
- **Total de Remoção no Grupo Par:**Total de indicações removidas para aquele(a) participante no grupo par;

**2 - APROVAR OU REPROVAR SOLICITAÇÕES**

Na tela de "**Status das Indicações**", clique no nome do participante que possui alguma indicação pendente.

![Imagem 6: Na tela de " Status das Indicações ", clique no nome do participante que possui alguma indicação pendente.](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/aprovar%20reprovar%20indica%C3%A7%C3%A3o%20RH%20avd-png.png)

Ao clicar no nome do(a) participante você poderá ver em qual grupo avaliativo existe a pendência a ser aprovada ou reprovada. Clique para expandir na seta ao lado, no final da barra cinza em que o nome do grupo está escrito.

![Imagem 7: Ao clicar no nome do(a) participante você poderá ver em qual grupo avaliativo existe a pendência a ser aprovada ou…](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/analise%20de%20indica%C3%A7%C3%A3o%20RH%20avd-png.png)

Ao expandir, você poderá ver qual é a solicitação pendente e assim, poderá aprová-la ou reprová-la, além de acompanhar as outras solicitações que foram aprovadas ou rejeitadas pelos gestores ou outros BP's. E ainda é possível incluir alguma indicação.

![Imagem 8: Ao expandir, você poderá ver qual é a solicitação pendente e assim, poderá aprová-la ou reprová-la, além de acompanhar…](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/tela%20de%20indica%C3%A7%C3%A3o%20avd%20RH-png.png)

**As solicitações estão separadas por 3 grupos:** Inclusão, Remoção e Troca de grupos avaliativos.
