# 08. Ciclo de Gestão de Performance

O ciclo de gestão de performance é a trilha indicada pela a Mindsight para a melhor gestão de desempenho, o objetivo é aumentar a produtividade, atingir os objetivos esperados e implementar a melhoria contínua.

Ela pode ser definida através da imagem abaixo:

![Imagem 1: Ela pode ser definida através da imagem abaixo:](https://22633675.fs1.hubspotusercontent-na1.net/hubfs/22633675/gest%C3%A3o%20de%20performance-png.png)

Ela é iniciada pela **etapa de indicação** (leia o artigo, [01. O que é a etapa de indicação?](https://sankhya.zendesk.com/hc/pt-br/articles/44009209231639), para saber mais), seguida pela **etapa de avaliação** (leia o artigo, **[01. O que é uma Avaliação de Desempenho e quais os tipos?](https://suporte.mindsight.com.br/01.-o-que-%C3%A9-uma-avalia%C3%A7%C3%A3o-de-desempenho-e-quais-os-tipos-1)**, para saber mais). Depois, continuamos para a **etapa de calibração** (leia o artigo, [01. O que é a etapa de Calibração e quais seus benefícios?](https://sankhya.zendesk.com/hc/pt-br/articles/44009070970391), para saber mais); a seguir, essa trilha pode divergir para 3 caminhos ou para os 3 ao mesmo tempo, que são: **Feedbacks, PDI's** (leia o artigo, [01. O que é o PDI?,](https://sankhya.zendesk.com/hc/pt-br/articles/44009195377687) para saber mais) e **Reunião de Gente**.
