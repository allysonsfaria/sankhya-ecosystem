# 🧲 Como usar a Extensão Hunting do LinkedIn – Mindsight

## A Extensão Hunting da Mindsight é uma ferramenta prática que facilita a captação de candidatos diretamente pelo LinkedIn, integrando os dados automaticamente ao ATS.

#### 📥 Como instalar

1. Acesse a **Chrome Web Store**.
2. No campo de busca, digite: **Mindsight Hunting**.
3. Clique para **instalar a extensão** no seu navegador Google Chrome.
4. Após a instalação, acesse o menu lateral > **Minhas Extensões** para verificar se a extensão está ativa.

#### 🔑 Como fazer login

1. Abra a extensão.
2. Preencha os campos com:

   - **Empresa**: seu tenant (nome usado nos links do sistema Mindsight, ex: auth.mindsight.com.br/**nomedaempresa**/
   - **Usuário** e **Senha**: os mesmos utilizados no login da plataforma.

     ![huting 1](https://ajuda.sankhya.com.br/hc/article_attachments/44009248670231)

#### 🖥️ Como utilizar

- Você pode fixar a extensão na barra do navegador ou acessá-la pelo menu de extensões.
- Atalho rápido: **Ctrl + M**.

#### 👤 Capturando candidatos no LinkedIn

1. Acesse o perfil de um candidato no LinkedIn.
2. A extensão irá capturar automaticamente:

   - Nome do candidato
   - Link do perfil

> 💡 Também é possível usar o botão da extensão exibido ao lado do nome no LinkedIn.

1. Preencha os campos:

   - **E-mail** (obrigatório)
   - **Telefone** (opcional)
2. Escolha a **vaga** para a qual deseja registrar o candidato ou selecione o **Banco de Talentos**.
3. Clique em **Salvar**.

   ![hunting2](https://ajuda.sankhya.com.br/hc/article_attachments/44009257506199)

### ✅ Registro bem-sucedido

- Uma mensagem de sucesso aparecerá confirmando que o candidato foi registrado.

### ⚠️ Candidato já registrado

- Caso o candidato já exista no sistema (mesmo que não na mesma vaga), uma notificação será exibida.
- O sistema também verifica se o candidato já está vinculado a uma vaga, e neste caso **impede o novo cadastro para a mesma vaga**.

  ![hunting3](https://ajuda.sankhya.com.br/hc/article_attachments/44009244984855)

É possível ver se o candidato está cadastrado em alguma vaga através do seletor de vaga. Caso esteja cadastrado, impede a seleção daquela vaga para o candidato em questão.

           ![hunting4](https://ajuda.sankhya.com.br/hc/article_attachments/44009245131799)

#### 🔐 Acessos e permissões

- A extensão está disponível para **usuários com perfil de Recrutador** no ATS.
