# 14. Diferença entre Abertura da Etapa de Avaliação e Abertura de Grupos de Avaliação

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44008832432919)

Ao utilizar o módulo de Desempenho, é comum surgirem dúvidas sobre a diferença entre **abrir uma etapa de avaliação** e **abrir um grupo de avaliação para preenchimento**. Em alguns casos, pode ocorrer de a etapa estar aberta, mas os grupos permanecerem fechados (ou vice-versa), o que impacta diretamente no andamento do ciclo.

Neste artigo, vamos esclarecer o papel de cada abertura e seus impactos no processo:

**[Abertura da Etapa de Avaliação](https://ajuda.sankhya.com.br/hc/pt-br/articles/44008806757015-14-Diferen%C3%A7a-entre-Abertura-da-Etapa-de-Avalia%C3%A7%C3%A3o-e-Abertura-de-Grupos-de-Avalia%C3%A7%C3%A3o#rodada)**

**[Abertura de Grupos de Avaliação](https://ajuda.sankhya.com.br/hc/pt-br/articles/44008806757015-14-Diferen%C3%A7a-entre-Abertura-da-Etapa-de-Avalia%C3%A7%C3%A3o-e-Abertura-de-Grupos-de-Avalia%C3%A7%C3%A3o#avaliacao)**

## 🗓️ Abertura da Etapa de Avaliação

Abrir a **Etapa de Avaliação** é fundamental para iniciar oficialmente o ciclo. Quando essa etapa está **fechada**, os participantes **não conseguem**:

- Preencher os questionários;
- Visualizar os avaliadores e avaliados após a validação das indicações;
- Iniciar o preenchimento dos questionários.

Dessa forma, a abertura da etapa de avaliação libera o ciclo para que os participantes possam realizar suas avaliações dentro do período programado.

Se tiver dúvidas sobre como abrir a **Etapa de Avaliação**, confira o artigo: **[Como abrir uma etapa na avaliação?](https://suporte.mindsight.com.br/10.-como-abrir-uma-etapa-na-avalia%C3%A7%C3%A3o)**

## 👥 Abertura de Grupos de Avaliação

Abrir um grupo de avaliação significa liberar aquele grupo específico para preenchimento do questionário. Quando o grupo está aberto, os participantes **podem**:

- Visualizar quem faz parte daquele grupo;
- Preencher os questionários destinados ao grupo;
- Acompanhar o status das avaliações (quantas estão concluídas ou pendentes).

Se a etapa de avaliação estiver aberta, mas o grupo não, os participantes não conseguirão iniciar nem concluir as avaliações relacionadas àquele grupo.

Para saber como abrir um grupo de avaliação para preenchimento, veja o artigo: **[Como abrir um grupo de avaliação para preenchimento?](https://suporte.mindsight.com.br/09-como-abrir-um-grupo-de-avalia%C3%A7%C3%A3o-para-preenchimento)**

## Conclusões:

- Abertura da Etapa + Abertura dos Grupos = Ciclo liberado para avaliações.
- Se apenas um deles estiver aberto, o processo não estará 100% funcional.
