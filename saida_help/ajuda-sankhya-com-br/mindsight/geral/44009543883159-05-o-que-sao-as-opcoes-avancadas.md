# 05. O que são as opções avançadas?

São mais opções de configurações do mapeamento. É possível adicionar um nome público diferente do nome interno para o mapeamento e selecionar quais testes serão utilizados. A opção “Permitir novos cadastros” deverá ser ativada quando a intenção for permitir novos cadastros através do link aberto. E a opção “Prevenir candidatos duplicados” deverá ser ativada para ativar um sistema de segurança que bloqueia a realização dos testes em um mesmo IP dentro de um período de 24 horas.
