# 01. Como posso cadastrar novos membros na plataforma?

Para dar acesso a novas pessoas à plataforma, basta acessar **“Página de Acessos”** no canto superior direito, e por fim **“Novo Membro”** na lateral direita.

![print 10](https://ajuda.sankhya.com.br/hc/article_attachments/44009366122135)

![Captura de tela 2024-12-16 171539](https://ajuda.sankhya.com.br/hc/article_attachments/44009382529431)

Caso queira atribuir alguma palavra para um membro, sugerimos que preencha em **"Tags"** com a palavra desejada para restringir o acesso desse usuário a mapeamentos específicos.

![Imagem 3: Caso queira atribuir alguma palavra para um membro, sugerimos que preencha em "Tags" com a palavra desejada para…](https://ajuda.sankhya.com.br/hc/article_attachments/44009382771735)

Na opção "**Tipo de Membro para o Match**", você consegue escolher o acesso que gostaria de gerar para esse usuário específico. Recomendamos o acesso de **"Admin"** que dará permissão completa ao sistema.

![Imagem 4: Na opção " Tipo de Membro para o Match ", você consegue escolher o acesso que gostaria de gerar para esse usuário…](https://ajuda.sankhya.com.br/hc/article_attachments/44009382960407)
