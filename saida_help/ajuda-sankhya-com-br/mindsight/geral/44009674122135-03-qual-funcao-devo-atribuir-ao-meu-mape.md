# 03. Qual função devo atribuir ao meu mapeamento?

A função vinculada ao mapeamento deverá ser relacionada com a posição em questão, parar o sistema gerar a nota de match do candidato. Por exemplo, para uma vaga de vendas é possível vincular o Arquétipo de Vendas ou então para uma vaga de analista financeiro, é possível vincular o Arquétipo Analítico.
