# 02. Como disparo lembretes para os candidatos finalizarem o preenchimento dos testes?

[Vídeo: Como disparo lembretes para os candidatos finalizarem o preenchimento dos testes](https://www.youtube.com/watch?v=5frHF-B3l6g)

Para enviar lembretes àqueles candidatos que ainda não preencheram os testes, o caminho é o mesmo do envio dos e-mails. A única diferença é que para este caso é necessário selecionar a segunda opção de “Todos que ainda não finalizaram o teste”.
