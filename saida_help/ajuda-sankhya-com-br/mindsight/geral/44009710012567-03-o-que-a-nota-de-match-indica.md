# 03. O que a nota de Match indica?

A nota de match nada mais é do que o cruzamento entre os atributos que a pessoa possui e o modelo de atributos que uma posição exige. Ele explica basicamente o quanto aquela pessoa é boa para aquela posição. Um match de 100, por exemplo, é aquele onde a pessoa possui uma pontuação máxima em todos os atributos necessários para determinada posição.
