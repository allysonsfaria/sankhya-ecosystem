# 02. Qual tipo de acesso devo conceder aos membros?

- **Admin:** Cria mapeamentos e novos acessos na plataforma;
- **Gestor:** Apenas cria mapeamentos mas não pode criar novos acessos;
- **Funcionário:** Apenas pode visualizar os resultados dentro do sistema.
