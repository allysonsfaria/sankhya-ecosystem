# 06. Como disparo os testes para os candidatos?

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=2HL1E8WXTzs)

- **Enviar Emails**

![Imagem 1: Enviar Emails](https://ajuda.sankhya.com.br/hc/article_attachments/44009523959063)

- **Importação de candidatos**

Uma opção é fazer o disparo importando uma lista de candidatos para dentro do sistema. Basta acessar o mapeamento, mudar para “Pessoas” no topo da página e selecionar a opção “importar pessoas” na lateral direita. É necessário baixar um modelo de Excel e preencher as informações de nome, sobrenome, e-mail e CPF (esse último é opcional), e após importar o arquivo e fazer o upload.

Após a importação ser finalizada, é necessário selecionar “enviar e-mails”, e um modelo de comunicação já estará disponível para envio, porém, caso desejado, é possível editá-lo.

É possível adicionar os candidatos individualmente a um mapeamento, selecionando a opção “Nova pessoa” na lateral direita da página. Basta preencher as informações de nome, sobrenome, e-mail e CPF (esse último é opcional).

- **Links abertos**

Outra opção é copiar o link aberto do mapeamento e enviar aos candidatos por outro canal, como e-mail ou redes sociais. Basta copiar o link clicando nos ícones ao lado do nome do mapeamento.

O ícone do globo são todos os testes agrupados em uma única página de acesso, já os demais são os links dos testes individuais.
