# 01. O que significa a aba Base Completa?

Nesta aba é possível localizar todos os candidatos e candidatas ou colaboradores e colaboradoras que já se inscreveram em algum mapeamento da sua base. É possível exportar os dados em Excel a partir dessa aba.
