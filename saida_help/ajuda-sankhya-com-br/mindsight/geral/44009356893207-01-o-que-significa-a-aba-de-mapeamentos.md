# 01. O que significa a aba de Mapeamentos?

Mapeamentos são “pastas” onde é possível agrupar os candidatos ou pessoas testadas. Cada vaga pode ser um mapeamento diferente. Para os clientes que possuem algum ATS integrado, cada vez que uma nova vaga é criada no sistema, um novo mapeamento é aberto na Mindsight.
