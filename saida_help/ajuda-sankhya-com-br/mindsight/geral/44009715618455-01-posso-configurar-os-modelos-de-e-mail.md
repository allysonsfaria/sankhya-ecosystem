# 01. Posso configurar os modelos de e-mail?

Sim, é possível configurar todos os modelos de e-mail do Mindmatch. Você pode utilizar também os “Campos Dinâmicos” dentro dos e-mails, para ajudá-lo a ganhar eficiência no envio das informações.

Não é possível, contudo, adicionar imagens e vídeos nos templates de e-mail. Você pode editar os templates somente com texto.

Os campos dinâmicos personalizam o e-mail enviado. O link agregador de testes deve ser utilizado para enviar todos os testes do mapeamento ao mesmo tempo. Caso seja para solicitar testes específicos, utilize os demais campos dinâmicos.

A relação de testes e links é: raciocínio (fluído e adaptativo), motivacional (inferências), social (situacional), perfil (personalidade), raciocínio simplificado, perfil (personalidade), interesses profissionais e Cultura (estilos de trabalho).

**ATENÇÃO:** Não devem ser colados links fixos dos ícones do mapeamento dentro destes e-mails, somente é possível a utilização dos links por campo dinâmico.
