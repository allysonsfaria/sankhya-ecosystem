# 06. O que significa grau de maximização?

Este índice indica o quanto estamos extraindo do máximo desta pessoa nesta posição. Ou seja, ele explica o quão boa é a posição para aquela pessoa. Um grau de maximização de 100 indica que aquela posição exige exatamente os atributos que a pessoa tem de melhor. Como cálculo, ele é sempre um percentual do match máximo que a pessoa poderia ter.
