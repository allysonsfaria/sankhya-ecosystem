# 09. Como crio outras funções?

[Vídeo: Como crio outras funções](https://www.youtube.com/watch?v=BpOPr1KtBok)

Para criar uma nova função, selecione a opção “**Nova função**”, na lateral direita da tela, preencha o campo do nome e deixe a opção “**Área**” em branco.

![Imagem 1: Para criar uma nova função, selecione a opção “ Nova função ”, na lateral direita da tela, preencha o campo do nome e…](https://s3.amazonaws.com/movidesk-files/A96497F2DA558D278A59A1B4861C6963)

Uma vez criada a função, é preciso mapeá-la. Para isso, o primeiro passo é acessar o ícone “**mapear**”, à direta do nome da função.
