# 01. O que é o People Hub?

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=VH4_aN9Lw78)

- **O QUE É O FULL ANALYTICS?**

O Full Analytics permite aumentar o patamar de gestão de pessoas da empresa por meio de alertas, sugestões e visualização integrada dos dados para os gestores. Consolidando os dados das pessoas é possível, por meio de machine learning, desenvolver algoritmos preditivos e criar dashboards condessados apoiando assim os gestores para tomada de decisão mais assertiva.

- **QUANDO E COMO USAR O FULL?**

A partir de seu data lake, nosso sistema consegue entregar diversas análises para os gestores e RH. Você pode usá-lo para entender afundo as causas raízes de problemáticas como baixa performance, turnover e as relações com outras possíveis variáveis. Veja a nível estatístico as principais correlações de performance, engajamento, faixa salarial, entre outras inúmeras variáveis.

- **O QUE VOCÊ PODE ACESSAR NO FULL?**
