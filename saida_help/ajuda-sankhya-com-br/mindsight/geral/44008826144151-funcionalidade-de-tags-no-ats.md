# Funcionalidade de Tags no ATS

### ✨ O que são as tags?

As **tags** são etiquetas que você pode aplicar aos candidatos dentro do ATS para organizar, segmentar e facilitar a triagem.
Com elas, você consegue buscar perfis de forma rápida e ter uma visão mais estratégica do banco de talentos e das vagas em andamento.

---

### 🎯 Benefícios

- Organização estratégica de candidatos.
- Facilidade para buscar perfis específicos.
- Otimização do processo de triagem e análise.
- Melhor experiência para recrutadores e gestores na tomada de decisão.

---

### 💻 Como usar as tags

## 1. Gerenciar tags no sistema

1. Vá até **Configurações do ATS**.
2. Clique na nova seção **“Tags”**.
3. Digite a tag desejada no campo e pressione **Enter** para salvar.
4. Para remover, clique no ícone **X** ao lado da tag.
5. As tags são organizadas em **ordem alfabética**.

## 2. Inserir tags em candidatos

1. Acesse o **perfil do candidato** (na vaga ou no banco de talentos).
2. Clique no campo de tags e selecione as opções desejadas da lista.
3. As tags escolhidas aparecerão no **card do candidato**.
4. É possível adicionar múltiplas tags para um mesmo candidato.

## 3. Visualizar e filtrar por tags

- As tags aparecem ao lado do nome do candidato.
- Quando há muitas tags ou tags longas, o sistema as encurta com “...”, mas é possível expandir.
- Nos filtros gerais, você pode selecionar as tags para refinar sua pesquisa.

### 🔑 Acessos e permissões

- **Recrutadores, Gestores e Envolvidos**

  - Podem adicionar e remover tags nos candidatos.
  - Podem filtrar candidatos por tags.
- **Usuários com permissão de Configurações**

  - Podem criar, editar e excluir tags no sistema.

---

### ✅ Resumindo

- As tags são uma forma simples e eficiente de organizar e encontrar candidatos.
- Recrutadores e gestores usam as tags para marcar e filtrar perfis.
- Usuários de configurações são responsáveis por manter a lista de tags atualizada.
