# Configurações no coletor de WMS

Após toda a infraestrutura (rede wi-fi) montada, é necessário a configuração nos coletores, para que o mesmo identifique qual será o IP do servidor. Isto deve ser feito depois de instalado o aplicativo no coletor.

Clique no botão **“Config.”** Na tela abaixo, informe o IP do servidor, Porta de acesso. (Não será necessário digitar o protocolo, caso seja “HTTP”, ficando como opcional. Para protocolos “HTTPS” é necessário digitar na url o https).
