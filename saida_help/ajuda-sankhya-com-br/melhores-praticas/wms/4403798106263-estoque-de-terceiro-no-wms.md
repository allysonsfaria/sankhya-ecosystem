# Estoque de Terceiro no WMS

**![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/16345432693143) SITUAÇÃO:**

Foi adicionado o campo **“Atualiza Estoque de Terceiros WMS?”** na tela **“Tipos de Operação”,** aba **“WMS”**. Vale destacar que ele só irá funcionar se o campo **“Estoque com/de Terceiros”,** presente na mesma tela, mas na aba **“Estoque de Terceiros”,** estiver diferente de **“Não controla”**.

![Imagem 2](https://ajuda.sankhya.com.br/hc/article_attachments/15083027475351)

![Imagem 3](https://ajuda.sankhya.com.br/hc/article_attachments/15083079819287)

A partir desta implementação, caso opte pela regra acima só será possível enviar notas do mesmo parceiro para o recebimento. As tarefas de armazenagem serão geradas com o código do parceiro. Os estoques dos produtos serão adicionados no endereço exclusivamente para este.
