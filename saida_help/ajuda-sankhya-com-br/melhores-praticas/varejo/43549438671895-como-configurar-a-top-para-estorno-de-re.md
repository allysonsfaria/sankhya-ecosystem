# Como configurar a TOP para estorno de recebimento via PIX no PDV

Ao realizar o estorno de um recebimento via PIX no PDV, o sistema gera um lançamento financeiro de despesa para compensar a receita registrada no recebimento original.

A TOP utilizada nesse lançamento é definida pela configuração da aba **PIX**, na tela **Empresa**. Caso seja necessário utilizar uma TOP específica para essa operação, ajuste a configuração conforme as orientações abaixo.

#### **(1)**Para configurar a TOP utilizada no estorno de recebimento via PIX, siga os passos abaixo:

**(1)**Acesse a tela **Empresa (**Comercial » Preferências » Empresa).

**(2)**Localize e selecione a empresa responsável pela venda.

**(3)**Acesse a aba **PIX**.

**(4)**Localize o campo **TOP Cancelamento Pix - Financeiro**.

**(5)**Verifique a TOP configurada e altere-a conforme a necessidade da empresa.

**Observação:** A alteração se aplica aos próximos estornos. Os lançamentos financeiros gerados anteriormente não são alterados automaticamente.

**CAUSA**

Para realizar o estorno de um recebimento PIX, é necessário que a empresa possua uma **"TOP" (Tipo de Operação)** específica para este fim, devidamente configurada e vinculada aos processos de estorno.
