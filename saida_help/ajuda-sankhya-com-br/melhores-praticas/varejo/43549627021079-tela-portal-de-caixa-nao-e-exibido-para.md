# Tela Portal de Caixa não é exibido para usuários.

Em algumas situações, o usuário pode não conseguir visualizar ou acessar o **Portal de Caixa**, mesmo após a habilitação da tela. Esse comportamento pode estar relacionado às permissões de acesso, configurações do perfil ou restrições aplicadas ao grupo de usuários.

A seguir, veja como verificar as principais configurações que podem impedir o acesso.

#### **(1)** Verifique as permissões de acesso do usuário

A primeira etapa é conferir se o usuário possui permissão para acessar a tela do **"Portal de Caixa"**. Para isso:

**(1)** Acesse a tela **"Acessos"** (Configurações » Controle de Acesso » Acessos) e localize o usuário desejado.

**(2)** Na busca **"Procurar tela"**, digiter **"Portal de Caixa"**e verifique se a tela está liberada para respectivo usuário.

**(3)** Caso não esteja, selecione usuário e marque a opção de acessos.

**(4)** Se o acesso for realizado por "**Grupo de usuários**", repita o procedimento de liberação de acesso, garantindo que o grupo ao qual o usuário pertence tenha permissão para o **"Portal de Caixa"**.

#### **(1)** Outras restrições e configurações

Além das permissões e licenças, verifique se existem restrições específicas aplicadas ao usuário, como regras de certificação, bloqueios por perfil ou limitações relacionadas..

Confirme também se o usuário está vinculado a algum **grupo de usuários com restrições de acesso** ou se existem parametrizações que possam limitar a visualização ou o acesso ao **Portal de Caixa**.

**CAUSA:**

O usuário não possui as permissões ou configurações necessárias para visualizar e acessar o **Portal de Caixa**.
