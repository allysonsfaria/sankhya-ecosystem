# Ao excluir um produto na tela do PDV WEB está sendo solicitada senha do usuário liberador, veja o que fazer

Para permitir que um usuário exclua itens lançados, configure a permissão na tela **Usuários:**

![Imagem 1: Acesse a tela "Usuários" (Configurações » Controle de Acesso » Usuários) ;](https://ajuda.sankhya.com.br/hc/article_attachments/30625276775703) Acesse a tela **"Usuários"** (Configurações » Controle de Acesso » Usuários)**;**

![Imagem 2: Vá até a aba PDV WEB;](https://ajuda.sankhya.com.br/hc/article_attachments/30625283133847) Vá até a aba **PDV WEB;**

![Imagem 3: Certifique-se de que a opção "Cancelamento de itens" está marcada.](https://ajuda.sankhya.com.br/hc/article_attachments/30625276778903) Certifique-se de que a opção **"Cancelamento de itens"** está marcada.

Após essa configuração, será possível cancelar itens no PDV WEB conforme as regras definidas no sistema.

![Imagem 4: Após essa configuração, será possível cancelar itens no PDV WEB conforme as regras definidas no sistema.](https://ajuda.sankhya.com.br/hc/article_attachments/30625717964311)

**Observação:** cada marcação nessa tela define as ações que o usuário pode realizar no sistema.
