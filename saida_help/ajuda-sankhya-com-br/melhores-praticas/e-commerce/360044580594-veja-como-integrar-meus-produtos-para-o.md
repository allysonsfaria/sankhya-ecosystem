# Veja como Integrar meus Produtos para o E-commerce

Eu Pâmela no dia de hoje 18-02-25 em alinhamento com a Delbia arquivei esse artigo pois o produto e-commerce foi descontinuado.

**(1)** A exportação dos produtos do ERP para o E-commerce devem ser feitas dentro do ERP na tela **"Produtos"**, aba **"E-commerce"**.

Os 4 campos de preenchimento obrigatório para que os produtos seja exportado para o e-commerce, são:

**![Imagem 1: Nome;](https://ajuda.sankhya.com.br/hc/article_attachments/16538875943959) Nome;**

**![Imagem 2: Usado no E-commerce (marcado);](https://ajuda.sankhya.com.br/hc/article_attachments/16538859176343) Usado no E-commerce** (marcado);

**![Imagem 3: Situação no E-commerce (Disponível ou Vitrine);](https://ajuda.sankhya.com.br/hc/article_attachments/16538875950871) Situação no E-commerce** (Disponível ou Vitrine);

**![Imagem 4: Menu (neste campo coloque o código da seção filha deste produto, sem pontos e sem zero a esquerda).](https://ajuda.sankhya.com.br/hc/article_attachments/16538875954327) Menu** (neste campo coloque o código da seção filha deste produto, sem pontos e sem zero a esquerda).

![Imagem 5: Menu (neste campo coloque o código da seção filha deste produto, sem pontos e sem zero a esquerda).](https://ajuda.sankhya.com.br/hc/article_attachments/15469770114839)

Feita as configurações acima, o produto será exportado para o E-commerce em alguns minutos.

**![Imagem 6: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16538875959191) OBSERVAÇÃO:**

O campo **"Usado"** no E-commerce após marcado não poderá ser desmarcado. Caso deseje retirar o produto do E-commerce você terá que alterar o campo Situação no E-commerce para Excluído.
