# Veja como criar um novo usuário no Sankhya ID

Primeiramente, é importante ressaltar que o convite para o cadastro do Sankhya ID deve ser enviado **apenas pelo usuário SUP**.

Portanto, ao acessar o sistema com as credenciais do usuário SUP, vá para a tela **"Usuários"** (Caminho: Configurações » Controle de Acesso » Usuários), insira o endereço de e-mail a ser vinculado e, em seguida, clique no botão **"Enviar convite"**.

![Imagem 1: Portanto, ao acessar o sistema com as credenciais do usuário SUP, vá para a tela "Usuários" (Caminho: Configurações »…](https://ajuda.sankhya.com.br/hc/article_attachments/27761864649879)

Após o envio do convite, um e-mail é enviado para que você possa completar o seu cadastro. Clique em 'Criar Agora'.

![Imagem 2: Após o envio do convite, um e-mail é enviado para que você possa completar o seu cadastro. Clique em 'Criar Agora'.](https://ajuda.sankhya.com.br/hc/article_attachments/26398622817303)

Preencha as informações solicitadas e, em seguida, escolha uma senha de acesso.

![Imagem 3: Preencha as informações solicitadas e, em seguida, escolha uma senha de acesso.](https://ajuda.sankhya.com.br/hc/article_attachments/26398622820375)

Feito isso, faça login no Sankhya Om utilizando os dados do Sankhya ID (E-mail ou CPF).

![Imagem 4: Feito isso, faça login no Sankhya Om utilizando os dados do Sankhya ID (E-mail ou CPF).](https://ajuda.sankhya.com.br/hc/article_attachments/24179042671639)
