# Ocorreu um erro ao carregar registros: Informe o critério para os Executantes

**SITUAÇÃO:**

Ao acessar a tela **''Telemarketing''** e aplicar os **''Filtros Rápidos''**, na aba **''Executantes''**, o sistema exibirá uma mensagem de erro nas seguintes situações:

- Nenhum **executante válido** for informado;
- A opção **"Todos os executantes"** **não** estiver marcada;
- A opção **"Grupo"** estiver **vazia**.

**(1)** O sistema exibirá a seguinte mensagem de erro:

![Imagem 1: (1) O sistema exibirá a seguinte mensagem de erro:](https://ajuda.sankhya.com.br/hc/article_attachments/33505130027927)

**SOLUÇÃO:**

Para corrigir o erro e carregar os registros de forma adequada, é imprescindível que pelo menos uma das três condições seja atendida. Sendo:

- Selecionar um executante **válido**;
- Marcar a opção **"Todos os executantes"**;
- Preencher o campo **"Grupo"** com uma opção válida.
