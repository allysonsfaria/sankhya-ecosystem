# Como consultar produtos pendentes de entrega em notas de entrega futura?

Este artigo orienta sobre como identificar e consultar produtos que estão pendentes de entrega para clientes quando utilizado o processo de **"Venda Entrega Futura"** no sistema.

### Entendendo o processo de entrega futura

O processo de **"Venda Entrega Futura"** permite emitir uma nota fiscal de **"Simples Faturamento"** antes da entrega efetiva da mercadoria ao cliente. Neste cenário, a nota é emitida com CFOP específico para entrega futura e posteriormente deve ser substituída ou complementada por uma nota de entrega efetiva quando o produto for entregue ao cliente.

### Limitação do sistema para consultas retroativas

O sistema **não oferece nativamente** uma forma de consultar o status histórico de pendência de entrega em uma data retroativa específica. Isso ocorre porque o status da nota é atualizado automaticamente após a entrega ser efetivada, não mantendo um histórico das pendências por período.

Os campos disponíveis nativamente no sistema incluem **"Data de faturamento"**, **"Data de entrada/saída"** e outras datas relacionadas ao processo fiscal, mas não há um campo específico que registre a data de entrega para consultas retroativas.

### Recomendações importantes

**Consulte as melhores práticas:** Para garantir o correto processo de **"Venda Entrega Futura"**, consulte o artigo **"Melhores Práticas para processo Venda Entrega Futura"** disponível na Central de Ajuda.
