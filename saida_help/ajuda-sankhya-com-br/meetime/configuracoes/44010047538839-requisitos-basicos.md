# Requisitos básicos

Para garantir uma ótima experiência com a ferramenta, é importante garantir a infra mínima necessária:

- **Navegador:** Recomendamos o Google Chrome, navegador mais otimizado para a tecnologia que usamos no produto, ou o Firefox.
- **Headset adequado**: Modelos com entrada USB para o computador. (Indicamos [estes](https://suporte.meetime.com.br/hc/pt-br/articles/115000998528-Quais-os-modelos-de-microfone-mais-indicados-para-realizar-as-liga%C3%A7%C3%B5es-por-VoIP-)).
- **Internet:** Uso de rede cabeada (confere mais estabilidade ao sistema, pois ligações via VoIP e videoconferência são totalmente impactadas pela qualidade da internet).
