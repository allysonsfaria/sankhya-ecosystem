# Como alterar o tipo de usuário na Meetime?

A Meetime conta com três tipos de usuários, e cada um possui permissões específicas. Para entender as diferenças entre eles, confira este artigo: [Quais os tipos de usuários na Meetime e o acesso permitido a cada um?](https://cloudchat2.cloudhumans.com/hc/meetime/articles/1768657011-quais-os-tipos-de-usuarios-na-meetime-e-o-acesso-permitido-a-cada-um)

### Como Alterar o Tipo de Usuário na Meetime

1. Clique no seu nome no canto superior direito da tela.
2. Acesse **Empresa** > **Usuários**.

![Imagem 1: Acesse Empresa > Usuários .](https://ajuda.sankhya.com.br/hc/article_attachments/44010411393815)

```
3. Localize o usuário que deseja alterar, clique nos três pontinhos à direita e selecione **Editar**.
```

![Imagem 2: Acesse Empresa > Usuários .](https://ajuda.sankhya.com.br/hc/article_attachments/44010437281687)

```
4. Na janela que abrir, clique na seta ao lado do tipo de usuário atual, selecione a nova permissão desejada e clique em **Salvar**.
```

![Imagem 3: Acesse Empresa > Usuários .](https://ajuda.sankhya.com.br/hc/article_attachments/44010402912279)

Pronto! O tipo de usuário foi alterado com sucesso.
