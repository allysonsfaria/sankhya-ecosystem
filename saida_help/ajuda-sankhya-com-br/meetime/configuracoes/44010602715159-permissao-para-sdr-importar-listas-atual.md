# Permissão para SDR importar listas - Atualização 09/2025

Agora os Usuários Meetime (SDR's) também podem importar listas de leads diretamente para a plataforma!

Para isso, é necessário que um usuário Gestor/Administrador habilite essa permissão nas configurações.

Como funciona?

Assim que a permissão for liberada, ao acessar a página de Leads (Prospecção > Leads), o Usuário Meetime verá o botão **“Lista de Importação”** disponível. A partir dele, é possível:

- Consultar o histórico de importações já feitas;
- Adicionar novas listas de leads.

![Imagem 1: Adicionar novas listas de leads.](https://ajuda.sankhya.com.br/hc/article_attachments/44010588467863)

Como habilitar?

1. Acesse Prospecção > Ajustes > Permissões:

![Imagem 2: Acesse Prospecção > Ajustes > Permissões:](https://ajuda.sankhya.com.br/hc/article_attachments/44010639015959)

1. Ative a opção “Adicionar leads via lista de importação”

![Imagem 3: Ative a opção “Adicionar leads via lista de importação”](https://ajuda.sankhya.com.br/hc/article_attachments/44010639276311)

Pronto! A partir daí, os Usuários Meetime poderão importar listas diretamente para a plataforma, de forma simples e rápida.
