# As ligações estão apresentando atrasos/delays, o que pode causar isso?

A qualidade da ligação está relacionada a estabilidade da internet, e é possível que o delay da ligação esteja relacionado a uma instabilidade na sua conexão de rede.

Se você possuir uma equipe de tecnologia, solicite uma analise da sua rede, sugerimos muita atenção aos seguintes pontos:

1. Latência(Latency): a latência é o tempo necessário para que os dados sejam enviados e recebidos. Se a latência for muito alta, as chamadas de voz se tornam inviáveis devido ao atraso/delay.
2. Jitter: Jitter é a variabilidade da latência. Ele mede quantos pacotes de dados chegam na ordem errada. Para uma chamada de voz, é absolutamente crucial que os pacotes de dados cheguem na sequência certa.

Para verificar a sua conexão com a internet pode acessar o site [https://simet.nic.br/](https://simet.nic.br/app/?autoMeasure=true) (Para finalizar o teste você deve permanecer na página até que ele termine). Nos testes os valores aceitáveis para uma chamada voip são:

**Latência aceita para uma chamada Voip:** até 150ms.

**Jitter para um chamada Voip:** até 20ms.

![Imagem 1: Jitter para um chamada Voip: até 20ms.](https://ajuda.sankhya.com.br/hc/article_attachments/44010085074839)

Outro ponto que pode provocar atraso na ligação é utilizar uma rede Wi-fi. Conecte seu computador a um cado de rede para evitar interferências da conexão sem fio.
