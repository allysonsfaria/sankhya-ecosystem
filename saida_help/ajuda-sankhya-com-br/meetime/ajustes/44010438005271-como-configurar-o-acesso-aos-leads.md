# Como configurar o acesso aos leads

Quando esta função está habilitada, ao acessar a página de leads, no menu **Prospecção** (barra superior preta) > **Leads**, todos os usuários poderão **visualizar a lista completa de leads** da conta. Mesmo que os leads estejam atribuídos a outros usuários.

Os usuários também terão permissão de **alterar o proprietário do lead**.

Para habilitar a função Acesso aos Leads basta acessar o menu **Prospecção** (barra superior preta) > **Ajustes** > **Acesso aos Leads** e selecionar o quadrinho para **habilitar acesso aos leads de outros vendedores**.

![Imagem 1: Para habilitar a função Acesso aos Leads basta acessar o menu Prospecção (barra superior preta) > Ajustes > Acesso aos…](https://ajuda.sankhya.com.br/hc/article_attachments/44010403939863)

Caso essa opção esteja desativada\* os vendedores conseguem visualizar apenas os leads que estão sob sua responsabilidade
