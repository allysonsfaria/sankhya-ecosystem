# Como encontrar seu token de API na Meetime?

Hoje para fazer qualquer integração via API ou Webhook os clientes precisam do token da API. Esse dado só é possível ser gerado no nosso Admin.

Agora disponibilizamos para que os clientes não dependam de nenhuma interação nossa para ativarem e terem acesso ao token da API.

Para isso, basta clicar no seu nome no canto superior direito da tela > Integrações

![Imagem 1: Para isso, basta clicar no seu nome no canto superior direito da tela > Integrações](https://ajuda.sankhya.com.br/hc/article_attachments/44010060265239)

Em seguida, clique em API > Copiar

![Imagem 2: Em seguida, clique em API > Copiar](https://ajuda.sankhya.com.br/hc/article_attachments/44010072949143)
