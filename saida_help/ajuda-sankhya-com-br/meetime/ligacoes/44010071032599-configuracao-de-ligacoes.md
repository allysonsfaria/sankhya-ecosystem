# Configuração de Ligações

Para realizar as configurações de ligações você deve acessar o menu **Ligações** (barra superior preta) > **Ajustes**

Na aba **Geral** você irá definir se as ligações serão feitas através de **VoIP** e/ou pelo Telefone. Você pode selecionar uma ou as duas opções, para isso basta clicar na caixinha de seleção.

Caso você selecione as duas formas de ligações, você precisa definir qual será a forma padrão de efetuar ligações, ou seja, qual das opções aparecerá primeiro para o usuário.

Entenda a diferença de ligações via VoIP e via Telefone [neste artigo](https://suporte.meetime.com.br/hc/pt-br/articles/227320848-Como-s%C3%A3o-realizadas-as-liga%C3%A7%C3%B5es-pela-Meetime-).

![Imagem 1: Entenda a diferença de ligações via VoIP e via Telefone neste artigo .](https://ajuda.sankhya.com.br/hc/article_attachments/44010025559447)

Atualmente a Meetime trabalha com a **Bina Inteligente**, portanto ao ligar para um celular de qualquer local do país, aparecerá na bina um número com o mesmo DDD do telefone de destino, de forma automática. O número é aleatório e de posse da operadora de telefonia que está realizando a ligação. A Bina Inteligente só funciona para ligações nacionais.

Caso você não queira utilizar a Bina Inteligente, [este artigo](https://suporte.meetime.com.br/hc/pt-br/articles/4415093165721-Solu%C3%A7%C3%B5es-para-manuten%C3%A7%C3%A3o-da-escolha-de-bina) tem orientações para adquirir um número padrão que será binado nas suas ligações via VoIP.

Se você adquirir um número padrão, realizar ligações internacionais \*\*\*\*ou efetuar as ligações pelo telefone precisa cadastrar o número de telefone que será utilizado como bina ao efetuar as ligações no Meetime Flow.

Para cadastrar o número de telefone basta acessar a aba **Números**, clicar no ícone “**+**”, preencher os campos e clicar no ícone ✅

![Imagem 2: Para cadastrar o número de telefone basta acessar a aba Números , clicar no ícone “ + ”, preencher os campos e clicar…](https://ajuda.sankhya.com.br/hc/article_attachments/44010055101975)

O Meetime Flow grava automaticamente todas as ligações realizadas na plataforma, mas é possível impedir que uma ligação seja gravada.

Na aba **Gravações** você irá definir que tipo de usuário terá permissão para impedir que uma gravação ocorra e quais poderão excluir uma gravação já executada. Para isso basta selecionar a opção desejada e clicar em “**Salvar**”. Veja aqui quais são os tipos de usuários disponíveis no Meetime Flow.

![Imagem 3: Na aba Gravações você irá definir que tipo de usuário terá permissão para impedir que uma gravação ocorra e quais…](https://ajuda.sankhya.com.br/hc/article_attachments/44010077114775)

Caso opte para que todos os usuários possam impedir que uma gravação ocorra, ao realizar uma ligação no Meetime Flow, no canto inferior esquerdo da tela ele poderá selecionar se essa ligação será gravada ou não. Essa opção deve ser selecionada antes de finalizar a atividade de ligação.
