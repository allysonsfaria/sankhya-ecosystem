# Permissões para gravação de ligações

O usuário gestor tem acesso a página de permissões, onde pode decidir quem tem permissão para impedir ou deletar uma gravação. **Lembrando que por padrão todas as ligações são gravadas pelo sistema**.

Para isso basta acessar:

Ligações > Ajustes > Gravações

[GIF animado: Imagem 1: Ligações > Ajustes > Gravações](https://suporte.meetime.com.br/hc/article_attachments/4405582342681/permissoes_gravacao.gif)

Feito isso, agora os usuários já possuem as devidas permissões.

## Vamos ver como funciona!

Nos vídeos abaixo, apenas os gestores tem permissão para impedir que uma ligação seja gravada, de acordo com a configuração feita no vídeo acima.

[GIF animado: Imagem 2: Nos vídeos abaixo, apenas os gestores tem permissão para impedir que uma ligação seja gravada, de acordo com a…](https://suporte.meetime.com.br/hc/article_attachments/4405582359065/impedir_toggle.gif)

Quando um usuário não gestor efetuar uma ligação ele não poderá impedir que a gravação aconteça.

[GIF animado: Imagem 3: Quando um usuário não gestor efetuar uma ligação ele não poderá impedir que a gravação aconteça.](https://suporte.meetime.com.br/hc/article_attachments/4405582392345/ligacao_semtoggle.gif)

Depois das ligações serem ou não gravadas, mostramos aos usuários as devidas informações conforme o vídeo abaixo. Neste vídeo aparecem os possíveis casos para uma ligação.

[GIF animado: Imagem 4: Depois das ligações serem ou não gravadas, mostramos aos usuários as devidas informações conforme o vídeo abaixo. Neste…](https://suporte.meetime.com.br/hc/article_attachments/4405582397337/fluxo_gravacao.gif)

- Lembrando que o SDR conseguiu excluir a ligação devido a permissão dada.

Quando o usuário tentar excluir uma gravação mas não tiver permissão para tal ação, o botão de excluir nem irá aparecer para aquele usuário.

[GIF animado: Imagem 5: Quando o usuário tentar excluir uma gravação mas não tiver permissão para tal ação, o botão de excluir nem irá aparecer…](https://suporte.meetime.com.br/hc/article_attachments/4405582406809/no_delete.gif)
