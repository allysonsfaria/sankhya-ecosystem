# Como interpretar o Status das ligações?

Ao finalizar uma ligação pela Meetime, você precisa classificá-la. Se está com dificuldade para interpretar os status das ligações, aí vão algumas dicas:

![Imagem 1: Ao finalizar uma ligação pela Meetime, você precisa classificá-la. Se está com dificuldade para interpretar os status…](https://suporte.meetime.com.br/hc/article_attachments/360011557933/Status_calls.jpg)

**Significativa**: consegui conversar com o cliente e obtive algum resultado significativo (ex: passagem de funil, agendamento de demo, reunião, fechamento de vendas e etc).

Resultados significativos podem variar de empresa para empresa. Nossa sugestão é que o gestor comercial defina claramente o que é uma ligação significativa e passe critérios objetivos para que o vendedor possa fazer a classificação correta.
A taxa de significativas é importante para direcionar o coaching dos vendedores.\*

**Não significativa**: consegui conversar com o cliente, mas por algum motivo esta ligação não gerou resultado.

**Sem contato**: não consegui contato com o cliente (ex: a secretária atendeu a ligação, mas o cliente não estava disponível no momento).

**Cliente ocupado**: consegui conversar com o cliente, porém o mesmo não estava disponível para conversar no momento.

**Não conectada**: telefone ocupado, fora de área, chamada rejeitada ou não atendida.
