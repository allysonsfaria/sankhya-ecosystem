# As ligações telefônicas ficam gravadas?

Sim, as ligações realizadas pela Meetime são gravadas. Para isso, basta que o botão "Salvar gravação" esteja habilitado.

![Imagem 1: Sim, as ligações realizadas pela Meetime são gravadas. Para isso, basta que o botão "Salvar gravação" esteja habilitado.](https://ajuda.sankhya.com.br/hc/article_attachments/44010661163287)

As gravações podem ser acessadas no Menu **Ligações > Lista de Ligações**.

Nessa página o usuário terá acesso a uma lista com todas as ligações realizadas, e clicando no **ícone de olho** ao lado direito de cada uma delas ele poderá ouvir a gravação. Também é possível baixar ou compartilhar o link dos áudios gravados.

![Imagem 2: Nessa página o usuário terá acesso a uma lista com todas as ligações realizadas, e clicando no ícone de olho ao lado…](https://suporte.meetime.com.br/hc/article_attachments/115000702574/Liga__o_gravada.jpg)
