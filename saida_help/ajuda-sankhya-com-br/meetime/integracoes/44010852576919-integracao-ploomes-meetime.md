# Integração Ploomes - Meetime

Siga o passo a passo abaixo para ativar a integração.

1. No Meetime, acesse o menu de integrações:

![Imagem 1: No Meetime, acesse o menu de integrações:](https://ajuda.sankhya.com.br/hc/article_attachments/44010869155735)

1. Acesse a aba API e copie o token:

![Imagem 2: Acesse a aba API e copie o token:](https://ajuda.sankhya.com.br/hc/article_attachments/44010852928407)

1. No Ploomes, acesse a tela de integrações plug&play, no menu de administração:

![Imagem 3: No Ploomes, acesse a tela de integrações plug&play, no menu de administração:](https://ajuda.sankhya.com.br/hc/article_attachments/44010877110807)

1. Habilite a integração com o Meetime:

![Imagem 4: Habilite a integração com o Meetime:](https://ajuda.sankhya.com.br/hc/article_attachments/44010848638103)

1. Cole o token copiado ao autorizar a integração:

![Imagem 5: Cole o token copiado ao autorizar a integração:](https://ajuda.sankhya.com.br/hc/article_attachments/44010864401047)

1. Configure as opções da integração:

![Imagem 6: Configure as opções da integração:](https://ajuda.sankhya.com.br/hc/article_attachments/44010864551831)

1. Copie a url fornecida no fim do menu:

![Imagem 7: Copie a url fornecida no fim do menu:](https://ajuda.sankhya.com.br/hc/article_attachments/44010853690007)

1. Crie um novo webhook no Meetime:

![Imagem 8: Crie um novo webhook no Meetime:](https://ajuda.sankhya.com.br/hc/article_attachments/44010864779799)

1. Configure o webhook com a url copiada e os gatilhos desejados. Inicialmente a integração suporta os gatilhos Lead Ganho e Lead Perdido.

![Imagem 9: Configure o webhook com a url copiada e os gatilhos desejados. Inicialmente a integração suporta os gatilhos Lead Ganho…](https://ajuda.sankhya.com.br/hc/article_attachments/44010864899095)

[Aqui](https://suporte.ploomes.com/pt-BR/articles/5545962-integracao-ploomes-meetime) você consegue acessar o FAQ da Ploomes.
