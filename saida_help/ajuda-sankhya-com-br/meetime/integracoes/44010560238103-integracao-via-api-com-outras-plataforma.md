# Integração via API com outras plataformas

Acesse aqui a documentação para integrar a Meetime para receber leads, exportar dados ou então enviar leads para outras plataformas: [Documentação API Meetime](https://meetime.readme.io/reference/introdu%C3%A7%C3%A3o)

Importante: Integrações via API permitem personalizar o envio de dados de forma mais flexível, mas demanda um conhecimento avançado em programação. Por isso, indicamos contar com o apoio de um responsável técnico para o desenvolvimento.

Em sua conta da Meetime, você consegue gerar a sua chave token. É só ir em seu nome > Integrações > API > Gerar token.

O token é gerado uma única vez e permite enviar e receber dados da sua conta, mantenho-o guardado seguramente.
