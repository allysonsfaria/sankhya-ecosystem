# Glossário de Termos Técnicos - Nylas e Microsoft

- **Registro de Aplicativo Azure (Azure App Registration):** Uma identidade registrada no Microsoft Entra ID que representa o aplicativo e define as permissões que ele pode solicitar em nome dos usuários.
- **Permissão Delegada (Delegated Permission):** Um tipo de permissão do Microsoft Graph que permite ao aplicativo agir em nome de um usuário conectado, limitando-se aos próprios dados desse usuário.
- **Grant (Nylas):** Um objeto interno da Nylas que representa uma única conta de caixa de correio conectada, encapsulando os tokens OAuth e metadados.
- **Microsoft Entra ID:** Serviço de gerenciamento de acesso e identidade baseado em nuvem da Microsoft, anteriormente conhecido como Azure Active Directory (Azure AD).
- **Microsoft Graph API:** API REST unificada da Microsoft que fornece acesso aos recursos do Microsoft 365, incluindo e-mail, calendário e contatos.
- **OAuth 2.0:** Um protocolo de autorização padrão da indústria que permite que aplicativos de terceiros obtenham acesso limitado a contas de usuários sem expor credenciais.
- **OIDC (OpenID Connect):** Uma camada de identidade sobre o OAuth 2.0 que permite aos aplicativos verificar a identidade do usuário final.
- **Modo de Privacidade (Privacy Mode):** Um recurso da plataforma Nylas que restringe o registro e o armazenamento de conteúdo sensível de mensagens além do mínimo necessário para o processamento.
- **Token de Atualização (Refresh Token):** Uma credencial OAuth de longa duração usada para obter novos Tokens de Acesso sem exigir que o usuário faça login novamente.
- **Escopo (Scope):** Uma string que define uma permissão específica concedida a um aplicativo sob o modelo OAuth 2.0 (ex.: `Mail.Read`).
- **TLS:** Segurança da Camada de Transporte (Transport Layer Security) — um protocolo criptográfico para proteger dados em trânsito por redes.
- **Webhook:** Um mecanismo de callback HTTP onde a Nylas envia notificações de eventos em tempo real para uma URL registrada pelo aplicativo cliente.
