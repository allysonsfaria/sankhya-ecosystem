# Boas práticas para o uso de atividades extras

A atividade extra é uma funcionalidade Meetime Flow que permite flexibilizar a prospecção, atendendo às necessidades específicas dos leads. Imagine um lead que solicita uma ligação em um horário específico ou uma mensagem após retornar de férias. Essa funcionalidade é feita sob medida para esses cenários.

Ao utilizar essa opção de forma estratégica, você maximiza suas chances de conexão, personalizando o contato de acordo com a rotina do lead. No entanto, é fundamental seguir as melhores práticas para evitar esforços desnecessários e manter suas métricas de prospecção precisas.

## Boas práticas para agendar uma atividade extra:

### Utilize um intervalo máximo de 1 semana:

- A Atividade Extra pausa a cadência, mas mantém o lead ativo. Portanto, se o agendamento for para períodos mais longos, esses dias adicionais serão contabilizados no momento de finalizar o lead, distorcendo as métricas de eficiência da prospecção, como o tempo médio para converter ou descartar um lead.

### As atividades voltam atrasadas

- Um ponto muito importante é que, após a execução de uma atividade extra, se o lead não for finalizado (dado como ganho/perdido), a cadência volta de onde parou. No entanto, as atividades aparecerão como atrasadas, pois não foram cumpridas dentro do cronograma original.
- Quanto maior o intervalo, maior a chance de atividades atrasadas, afetando a eficiência do seu fluxo de prospecção.

### Agende com intencionalidade e estratégia

- A Atividade Extra é um recurso de apoio para casos específicos em que a cadência padrão não atende. Evite usá-la para modificar o fluxo original. Se sentir necessidade de agendar muitas atividades extras, considere revisar o fluxo com a gestão ou confie no processo estabelecido.
- Use este recurso como um diferencial estratégico, aproveitando momentos-chave para engajar leads e impulsionar suas conversões.
