# [Routing] - Pedidos

**Menu:** Pedidos

**Objetivo**: Como gerar as informações referentes aos pedidos

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Nesta tela são apresentas as informações dos pedidos. Veja um exemplo abaixo:

![Imagem 1: Nesta tela são apresentas as informações dos pedidos. Veja um exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44010977850647)

1. **Depósito**: Selecione o depósito desejado;
2. **Data do Pedido:** Informe uma data inicial;
3. **Até**: Informe uma data final;
4. **Data Importação:** Informe uma data inicial da importação do arquivo de pedido;
5. **Até:** Informe uma data final da importação do arquivo de pedido;
6. **Número**: Informe o número do pedido, caso queira fazer uma busca específica, ao utilizar o sinal de porcentagem **" % ".** Buscando os pedidos cujo inicia ou finaliza com um, determinado valor. (Ex: 123% ou %123);
7. **Roteirizados**: Selecione uma das opções: Todos, Não Roteirizados, Roteirizados;
8. **Cliente**: Selecione caso desejar pesquisar por um cliente específico;
9. **Marcador**: Informe o marcador, caso tenha;
10. **Agendamento De**: Informe a data de início do agendamento caso tenha;
11. **Agendamento Até**: Informe a data final do agendamento caso tenha;
