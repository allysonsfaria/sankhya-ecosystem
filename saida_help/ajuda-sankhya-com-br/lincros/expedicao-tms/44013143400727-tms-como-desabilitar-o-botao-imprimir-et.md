# [TMS] - Como desabilitar o botão 'Imprimir Etiquetas' na ordem de coleta

**Menu**: Expedição > Coletas > Ordem de Coleta

**Objetivo**: Como desabilitar o botão 'Impimir Etiquetas' na ordem de coleta

**Considerações**:

- O usuário deverá ter acesso às ordens de coletas;

Este botão é nativo (padrão do sistema), atualmente não é possível desabilitar para os usuários. Ele somente será exibido caso a ordem de coleta não esteja cancelada e possua nfe/pré nota/embarque informado.

Clicando neste botão será redirecionado para a tela de impressão de etiqueta. Caso possua apenas uma etiqueta para a transportadora da ordem de coleta e apenas uma impressora cadastrada, deve ser enviado a etiqueta diretamente para impressão.  Caso haja mais de uma etiqueta para a transportadora ou mais de uma impressora cadastrada, ao clicar no botão de imprimir etiquetas na ordem de coleta, será redirecionado para a tela de impressão de etiqueta com todos os dados informados, menos etiqueta e/ou impressora (caso possuam mais de uma), no qual o usuário terá que selecionar manualmente e gerar impressão.
