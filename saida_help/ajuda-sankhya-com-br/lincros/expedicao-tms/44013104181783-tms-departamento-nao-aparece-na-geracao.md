# [TMS] - Departamento não aparece na geração de ordem de descarga

**Menu**: Expedição > Descargas > Ordem de descarga

**Objetivo**: Auxiliar em como realizar ajustes para que os departamentos apareçam para escolha na Ordem de descarga.

**Considerações**:

- Possui os departamentos criados no sistema;
- Possuir ordem de descarga;

Ao criar uma ordem de descarga, no campo 'Departamento' não está aparecendo os departamentos para selecionar, conforme exemplo abaixo:

![Imagem 1: Ao criar uma ordem de descarga, no campo 'Departamento' não está aparecendo os departamentos para selecionar, conforme…](https://ajuda.sankhya.com.br/hc/article_attachments/44013112910231)

Caso algum usuário de transportadora relate que não está conseguindo escolher um determinado departamento no momento em que tenta criar uma ordem de descarga, então deve-se verificar dentro do sistema em:  Sistema > Acesso > Departamentos se a opção 'Ordens de descarga' está habilitada. Em caso tiver, basta habilitar a opção que a mesma será apresentada para seleção no momento que for criar uma nova ordem de descarga.

![Imagem 2: Caso algum usuário de transportadora relate que não está conseguindo escolher um determinado departamento no momento em…](https://ajuda.sankhya.com.br/hc/article_attachments/44013116213015)
