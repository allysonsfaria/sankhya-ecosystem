# [TMS] - Agrupar/Unificar pré-conhecimentos

**Menu:** Operacional > Cargas > Pré-conhecimentos

**Objetivo:**Agrupar/ Unificar pré-conhecimentos manualmente que não foram unificados de maneira manual.

## Considerações:

- No botão de 'Agrupar-Forçar União' podemos 'agrupar/unificar' pré-conhecimentos;
- É necessário verificar as informações dos pré-conhecimentos como transportadora, destino, origem,etc.

Em alguns casos por algum motivo pode acontecer de alguns pré-conhecimentos não se unificarem de maneira automática, seja por informações divergentes, problema no recurso,etc.

Caso isto aconteça e exista a necessidade de unificar os pré-conhecimentos é possível efetuar este processo de maneira manual. Conforme procedimentos abaixo:

1. Acessar o menu: Operacional > Cargas > Pré-conhecimentos vamos localizar os pré-conhecimentos, caso queria procurar pelo código é possível incluir mais de um código de pré-conhecimento separado por ponto-virgula;

   ![Imagem 1: Acessar o menu: Operacional > Cargas > Pré-conhecimentos vamos localizar os pré-conhecimentos, caso queria procurar…](https://ajuda.sankhya.com.br/hc/article_attachments/44012693975831)

2. Após localizar os pré-conhecimentos, é necessário ativar as suas marcações e posteriormente clicar em : Agrupar > Forçar União;

![Imagem 2: 2. Após localizar os pré-conhecimentos, é necessário ativar as suas marcações e posteriormente clicar em : Agrupar >…](https://ajuda.sankhya.com.br/hc/article_attachments/44012710253591)

3. Após este processo os pré-conhecimentos serão unificados como exemplo abaixo:
