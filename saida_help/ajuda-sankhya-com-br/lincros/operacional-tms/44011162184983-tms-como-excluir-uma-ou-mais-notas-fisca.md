# [TMS] - Como excluir uma ou mais notas fiscais de um embarque

**Menu**: Operacional > Cargas > Embarques

**Objetivo**: Como remover uma ou mais notas fiscais de um embarque dentro do TMS.

**Considerações**:

- Possuir um embarque criado dentro do TMS;
- Possuir uma ou mais notas fiscais que deseja retirar do embarque;

## Abaixo segue os procedimentos de como remover uma  NF-e vinculada ao embarque

1. Acessar o menu: Operacional > Cargas > Embarques;
2. Selecionar o embarque que deseja desvincular os documentos;

![Imagem 1: Selecionar o embarque que deseja desvincular os documentos;](https://ajuda.sankhya.com.br/hc/article_attachments/44011129375639)

3. Dentro da tela de edição de embarque, você deverá acessar a aba 'Documentos'';

![Imagem 2: 3. Dentro da tela de edição de embarque, você deverá acessar a aba 'Documentos'';](https://ajuda.sankhya.com.br/hc/article_attachments/44011129484183)

4. Para remover os documentos que deseja retirar do embarque, basta clicar no ícone 'X' em vermelho, conforme print abaixo. Após remover os documentos, basta clicar no botão salvar;

![Imagem 3: 4. Para remover os documentos que deseja retirar do embarque, basta clicar no ícone 'X' em vermelho, conforme print…](https://ajuda.sankhya.com.br/hc/article_attachments/44011129573911)

![Imagem 4: 4. Para remover os documentos que deseja retirar do embarque, basta clicar no ícone 'X' em vermelho, conforme print…](https://ajuda.sankhya.com.br/hc/article_attachments/44011137538327)
