# [TMS] - Autorizar acesso de usuário de transportadora

## Autorizar acesso de usuário de transportadora

**Objetivo:** Permitir que o embarcador autorize o acesso dos usuários das transportadoras parceiras aos dados da empresa contidos no Portal do Transportador Lincros;

**Considerações:** - Para autorizar ou rejeitar o acesso dos usuários de transportadora, o usuário da empresa precisa possuir um perfil que contenha a marcação 'Autorizar usuário de transportadora';

- Os perfis padrões da Lincros que possuem essa permissão são: Administrador, Gerencial e Analista;
- Caso desejar liberar a permissão para um perfil específico da empresa, entrar em contato com a equipe de Help Desk, através do e-mail atendimento@lincros.com[;](mailto:atendimento@lincros.com;)

Para autorizar ou rejeitar o acesso do usuário da transportadora acesse o menu: Sistema > Acesso > Usuário > Autorização de acesso para transportadoras;

Para vincular ou desvincular usuário de transportadora acesse o menu:  Sistema > Acesso > Usuário > Usuários de Transportadora;

## Autorizar ou rejeitar o acesso

1. Acesse o menu: Sistema > Acesso > Usuário > Autorização de acesso para transportadoras;
2. Selecione o usuário que deseja autorizar ou rejeitar:

   ![Imagem 1: Selecione o usuário que deseja autorizar ou rejeitar:](https://ajuda.sankhya.com.br/hc/article_attachments/44012652563863)
3. Caso seja rejeitado, o ícone será atualizado para vermelho;

   ![Imagem 2: Caso seja rejeitado, o ícone será atualizado para vermelho;](https://ajuda.sankhya.com.br/hc/article_attachments/44012640366615)
4. O transportador receberá um e-mail informando que o acesso foi negado;
5. O transportador não poderá visualizar os dados desta empresa;
6. Caso seja autorizado, o ícone será atualizado para verde:

   ![Imagem 3: Caso seja autorizado, o ícone será atualizado para verde:](https://ajuda.sankhya.com.br/hc/article_attachments/44012625447319)
7. O transportador receberá um e-mail informando que o acesso foi autorizado;
8. O transportador poderá visualizar os dados desta empresa.

## Vincular ou desvincular usuário de transportadora

1. Acesse o menu: Sistema > Acesso > Usuário > Usuários de Transportadora;
2. Clicar no usuário que deseja vincular ou desvincular;
3. Os usuários que estiverem vinculados, apresentarão o botão 'Desvincular usuário da empresa';

![Imagem 4: Os usuários que estiverem vinculados, apresentarão o botão 'Desvincular usuário da empresa';](https://ajuda.sankhya.com.br/hc/article_attachments/44012652955927)

4.  Os usuários que estiverem desvinculados, apresentarão o botão 'Vincular usuário à empresa'';

![Imagem 5: 4. Os usuários que estiverem desvinculados, apresentarão o botão 'Vincular usuário à empresa'';](https://ajuda.sankhya.com.br/hc/article_attachments/44012632711703)

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
