# [TMS] - Já foi efetuado o tratamento de erro para o conhecimento de transporte "XXXXX" e não pode ser reprocessado

**Menu**: Operacional > Importação > CT-e > Importação

**Objetivo**: Entender o motivo da crítica e o que é preciso ser feito para corrigir.

**Considerações**:

- Possuir um CT-e onde foi clicado na opção 'Tratar Erros';

Abaixo segue os procedimentos:

Caso tenha um CT-e já importado no TMS, e clica-se na opção "Tratar erros", então ao tentar reimportar o arquivo de importação para realizar algum ajuste no documento, então o sistema irá apresentar a seguinte crítica, impossibilitando que o usuário da empresa consiga dar continuidade no processo, conforme imagem abaixo: 'Já foi efetuado o tratamento de erro para o conhecimento de transporte "XXXXX" e não pode ser reprocessado'.

![Imagem 1: Caso tenha um CT-e já importado no TMS, e clica-se na opção "Tratar erros", então ao tentar reimportar o arquivo de…](https://ajuda.sankhya.com.br/hc/article_attachments/44010050301335)

A orientação para correção é que neste caso seja enviado para nosso Suporte Lincros através do e-mail: [atendimento@lincros.com](mailto:atendimento@lincros.com) o XML que está sendo importado, para que possamos realizar este procedimento de importação.

Este processo é necessário, pois nosso usuário possui uma permissão especial que acaba ignorando estes bloqueios a onde o processo de importação ocorrerá sem que seja apresentada a crítica mencionada acima.

## Atenção — quando este artigo NÃO se aplica:

- Este artigo vale somente quando a mensagem exibida for exatamente a descrita acima ("Já foi efetuado o tratamento de erro... e não pode ser reprocessado"). Outras mensagens de importação têm causas diferentes — consulte a seção 'Mensagem de importação' do CT-e (Documentos eletrônicos > CT-es) e o artigo correspondente;
- Antes de enviar o XML ao suporte, confira a situação do CT-e em Documentos eletrônicos > CT-es. Se o CT-e estiver **Cancelado** (por exemplo, substituído por outro CT-e), a análise é outra: informe no chamado se existe um CT-e de substituição ou novo documento relacionado.
