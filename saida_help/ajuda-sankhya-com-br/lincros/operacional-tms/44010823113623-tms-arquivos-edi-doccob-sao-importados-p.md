# [TMS] - Arquivos Edi (DOCCOB) são importados, porém não aparecem na tela de faturas

**Menu**: Operacional > Importação > EDI > Importação

**Objetivo**: Arquivos EDI (DOCCOB) são importados, porém não aparecem na tela de faturas, como proceder para ajustar?

**Considerações**:

- Possuir faturas cadastradas/importadas no sistema;

Os arquivos EDI são importados, porém não aparecem na tela de faturas, conforme exemplo abaixo:

![Imagem 2: Os arquivos EDI são importados, porém não aparecem na tela de faturas, conforme exemplo abaixo:](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963388704/cb99d4510ed048f892171023f199/38CE1C488C2A60CEBC5FFEF9E00AFE9B?expires=1791331200&signature=4a510051b9ef986b39f786dfcf42da979f02340e8935334098cd15c18a10c2f9&req=dSkhFcp2lYZfXfMW3nq%2BgeOa7wDJ5j2%2FEyMS6v62OmKcx3KK3zhIHzvOKdVG%0A%2FC6aiht3CQy0c0wRLOr36TmAKLk%3D%0A)
