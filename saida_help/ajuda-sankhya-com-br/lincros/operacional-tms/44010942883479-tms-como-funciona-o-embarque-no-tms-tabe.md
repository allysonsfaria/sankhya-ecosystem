# [TMS] - Como funciona o embarque no TMS (Tabela de frete)

**Menu**: Operacional > Cargas > Embarques

**Objetivo**: Apresentar como funciona o embarque no TMS através da tabela de frete

**Considerações**:

- Para que o embarque funcione corretamente, é necessário ter uma tabela de frete cadastrada e vinculada à transportadora;
- Quando um embarque é criado, o sistema busca a tabela de frete para calcular o valor do frete automaticamente.

## Como funciona o embarque

1. Acesse o menu: Operacional > Cargas > Embarques;
2. Clique em 'Novo' para criar um embarque;
3. Selecione a transportadora e a modalidade de frete;
4. Adicione as notas fiscais ao embarque;
5. O sistema calcula automaticamente o frete com base na tabela vigente;
6. Verifique o valor calculado e confirme o embarque.

Para mais informações sobre como cadastrar a tabela de frete, [clique aqui](https://intercom.help/ajudalincros/pt-BR/articles/13432703-tms-cadastro-de-tabela-de-fretes-via-tela-do-sistema).
