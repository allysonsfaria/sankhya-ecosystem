# [Lincros APP] - Release Notes 2.21

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012997879575)

## Melhorias:

- ## Processamento de parada pelo App

Adequação para que o processamento de paradas passe a ser feito pelo App Lincros ao invés de ser feito pelo sistema Tracking.

- ## Habilitar ou desabilitar a funcionalidade de Múltiplas Entregas

Realizada customização para que seja possível desabilitar ou habilitar a funcionalidade múltiplas entregas.

**Observação**: Por default todos os clientes já tem essa função habilitada para o App Lincros.

Essa funcionalidade poderá ser desabilitada/habilitada através de parâmetro "Habilitar funcionalidade múltiplas entregas". 
Caminho para acessar o parâmetro: Menu --> Cadastros --> Unidade de Negócio --> Configurações para Smartphone --> "Habilitar funcionalidade múltiplas entregas".

Exemplo de tela no App Lincros com a funcionalidade para realizar múltiplas entregas habilitada.

![Imagem 2: Exemplo de tela no App Lincros com a funcionalidade para realizar múltiplas entregas habilitada.](https://ajuda.sankhya.com.br/hc/article_attachments/44013006044055)

- ## Permitir ao motorista concluir diversas entregas de uma única vez, permitir selecionar todos os documentos com um botão selecionar todos

Inserido botão "Selecionar Todos" na funcionalidade Múltiplas Entregas, para que o motorista possa selecionar todas as entregas de uma só vez, agilizando assim o processo de entregas.

Exemplo de telas com a funcionalidade "Selecionar todos" habilitada.

![Imagem 3: Exemplo de telas com a funcionalidade "Selecionar todos" habilitada.](https://ajuda.sankhya.com.br/hc/article_attachments/44012998308119)

- ## Leitor de código de barras acoplado ao mobile (APP)

Realizada adequação, a fim de que seja possível utilizar um leitor de código de barras acoplado ao celular, para realizar a leitura dos volumes.

Exemplo de telas:

![Imagem 4: Exemplo de telas:](https://ajuda.sankhya.com.br/hc/article_attachments/44013023956247)

Link do vídeo com a simulação da leitura de volumes, utilizando o aparelho acoplado ao smartphone: <https://photos.google.com/share/AF1QipOymV8J7K2VfW96pTMG1pXYT-m9lxB5dJjqZ9hoC3mZWuTPkvw77t-MeQ2-ANqlpQ/photo/AF1QipMQrkiM_4fMVsdw5PaLclTS2ucAyVPnm90dZYO3?key=MTlTWkcyV2pnSWN5TjNLRGdlc0laZGE0VEpfR0pn>

- ## Recurso para que o Conferente E-commerce realize toda a conferência de uma só vez

Criado botão "MARCAR TODOS", para que o Conferente E-commerce, possa realizar a conferência de todos os volumes de uma só vez.

Exemplo de telas, com a nova funcionalidade:

![Imagem 5: Exemplo de telas, com a nova funcionalidade:](https://ajuda.sankhya.com.br/hc/article_attachments/44012977524119)

**Observação**: Esse botão é habilitado pelo sistema Tracking através do parâmetro "Realizar conferência geral dos volumes". Caminho: Menu --> Cadastros --> Unidade de Negócio --> Configurações para o Smartphone --> "Realizar conferência geral dos volumes".

- ## Melhorias no mapa - Fase 3

Inserido o ícone "Mapa da Rota" no menu superior do App. A partir de agora, o motorista poderá utilizar o mapa do aplicativo para visualizar a sua rota.

Exemplo de tela com a nova funcionalidade:

![Imagem 6: Exemplo de tela com a nova funcionalidade:](https://ajuda.sankhya.com.br/hc/article_attachments/44012977735319)

- ## Adequação para remover a opção de dark mode no App

Realizada adequação, para que quando celulares da marca Xiaomi estiverem com a opção "dark mode" habilitada, o visual do aplicativo não seja alterado.

- ## Alteração de Banco de Dados - MMKV

Realizada alteração do Banco de Dados do App Lincros, a fim de corrigir problemas de performance e melhorar o seu desempenho.
