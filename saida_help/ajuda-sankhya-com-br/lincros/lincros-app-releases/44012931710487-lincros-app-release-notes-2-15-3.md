# [Lincros APP] - Release Notes 2.15.3

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012902428567)

## Melhorias:

- **Enviar para central de monitoramento os dados do responsável pela coleta ao finalizar a viagem**

  - Agora é possível realizar a consulta dos dados de quem recebeu, no depósito, as coletas que foram realizadas pelo motorista. A visualização é feita utilizando o tracking, no campo “Mensagens”.

    - Dessa forma , armazenamos as informações e disponibilizamos aos nossos clientes, ajudando a melhorar os seus processos e controles de coletas efetuadas.

![Imagem 2: Dessa forma , armazenamos as informações e disponibilizamos aos nossos clientes, ajudando a melhorar os seus processos…](https://ajuda.sankhya.com.br/hc/article_attachments/44012945044759)

![Imagem 3: Dessa forma , armazenamos as informações e disponibilizamos aos nossos clientes, ajudando a melhorar os seus processos…](https://ajuda.sankhya.com.br/hc/article_attachments/44012928610327)

- **Exibir quantidade de volume previstos na coleta (motorista SFX)**

  - Ao acessar os detalhes de uma coleta parcial, fechada ou uma coleta total, é exibido a quantidade de volumes previsto para coleta

    - Trouxemos essa visualização de volumes previstos para facilitar o processo de bipagem de volumes durante coleta.

![Imagem 4: Trouxemos essa visualização de volumes previstos para facilitar o processo de bipagem de volumes durante coleta.](https://ajuda.sankhya.com.br/hc/article_attachments/44012945391255)

- **Alterar nomenclatura "volume" para "pedido" persona separador**

  - Realizamos alterações nas nomenclaturas. Onde havia o termo "volumes" substituímos por “pedidos”.

    - Essa alteração visa uma melhor compreensão de usabilidade de acordo com a rotina de trabalho do separador.

![Imagem 5: Essa alteração visa uma melhor compreensão de usabilidade de acordo com a rotina de trabalho do separador.](https://ajuda.sankhya.com.br/hc/article_attachments/44012932518295)

![Imagem 6: Essa alteração visa uma melhor compreensão de usabilidade de acordo com a rotina de trabalho do separador.](https://ajuda.sankhya.com.br/hc/article_attachments/44012945589143)
