# [Lincros APP] - Release Notes 2.20.0

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44013021991447)

## Melhorias:

- ## Exibir o CEP do endereço de uma entrega ou coleta:

  - Adicionamos um novo recurso que permite você visualizar o CEP de uma entrega ou coleta. Com esse novo recurso você consegue buscar uma entrega ou coleta digitando apenas o CEP do endereço desejado.

    Importante: Esse recurso é habilitado através de parâmetro no sistema, caso deseje habilitá-lo, entrar em contato com o Suporte

![Imagem 2: Importante: Esse recurso é habilitado através de parâmetro no sistema, caso deseje habilitá-lo, entrar em contato com o…](https://ajuda.sankhya.com.br/hc/article_attachments/44012975776151)

- **Redução de passos para apontar uma entrega/devolução:**

  - Realizada melhoria, para que quando o recebedor da entrega for a própria pessoa destinatária, os dados (nome e documento), sejam preenchidos automaticamente.

![Imagem 3: Realizada melhoria, para que quando o recebedor da entrega for a própria pessoa destinatária, os dados (nome e…](https://ajuda.sankhya.com.br/hc/article_attachments/44013038697111)

- **Desabilitar precisão mínima de GPS:**

  - Realizada adequação, para que seja possível desabilitar a precisão mínima do GPS.

    Importante: Esse recurso é habilitado através de parâmetro no sistema, caso deseje habilitá-lo, entrar em contato com o Suporte

- **Processamento de parada pelo App:**

  - Adequação para que o processamento de paradas passe a ser feito pelo App Lincros, ao invés de ser feito pelo sistema Tracking.

- **Criar mecanismo para avaliação do App:**

  - Criado mecanismo para que o App Lincros, possa ser avaliado pelos motoristas no Google Play, após a conclusão de algumas viagens
