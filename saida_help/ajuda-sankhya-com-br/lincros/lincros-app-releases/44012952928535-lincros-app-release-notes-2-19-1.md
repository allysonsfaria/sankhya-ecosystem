# [Lincros APP] - Release Notes 2.19.1

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012986536343)

## Melhorias:

- ## Redução de passos para apontar uma entrega/devolução:

  - A partir de agora, após clicar na entrega, o motorista deverá identificar o documento que deseja entregar e responder a pergunta “Foi entregue?” clicando no botão “Sim” (caso seja uma entrega), e a partir daí será confirmada a entrega, e o motorista já será direcionado para a tela de foto canhoto.

![Interface gráfica do usuário, Aplicativo, TeamsDescrição gerada automaticamente](https://ajuda.sankhya.com.br/hc/article_attachments/44012953154583)

![Interface gráfica do usuário, AplicativoDescrição gerada automaticamente](https://ajuda.sankhya.com.br/hc/article_attachments/44012961613719)

- **Respeitar a parametrização do tomador, quando clicar no botão "Entregar tudo" ou "Devolver tudo"**

  - Realizada adequação para que quando utilizadas as funcionalidades “Entregar tudo” ou “Devolver Tudo” o App considere as parametrizações do Tomador, a nível de entrega.
