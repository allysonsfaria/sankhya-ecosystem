# [Lincros APP] - Release Notes 2.17.1

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012947786007)

## Melhorias:

- ## Selecionar entregas e enviar para o ajudante através de um QR code e URL texto

  - Agora é possível que o motorista compartilhe suas entregas com um ajudante.
  - O motorista pode selecionar quais entregas que deseja repassar ao ajudante.

    - Após confirmar as entregas selecionadas ao ajudante, um QR CODE e um código alfanumérico, são gerados. Basta compartilhar uma dessas informações com o ajudante, para que ele acesse a lista de entregas que foi criada pelo motorista.
- Para que essa funcionalidade esteja disponível, é necessário que o parâmetro “Utilizar ajudante” esteja ativo no Tracking (Caminho: Configurações > Parâmetros > Mobile > Utilizar ajudante)

![Imagem 2: Para que essa funcionalidade esteja disponível, é necessário que o parâmetro “Utilizar ajudante” esteja ativo no…](https://ajuda.sankhya.com.br/hc/article_attachments/44012934264599)

- **Impossibilitar apontamento fora do raio**

  - Foi desenvolvida uma nova parametrização que impede o apontamento de uma entrega quando esta for feita fora do raio do cliente.
  - É uma medida que visa mitigar a incidência de apontamentos falsos ou incorretos, melhorando a precisão das entregas.
  - Este é um recurso que pode ser habilitado e desabilitado dentro dos parâmetros de unidade no Tracking Lincros.

![Imagem 3: Este é um recurso que pode ser habilitado e desabilitado dentro dos parâmetros de unidade no Tracking Lincros.](https://ajuda.sankhya.com.br/hc/article_attachments/44012981213079)

- **Melhoria na tela inicial de permissões ao utilizar o app pela primeira vez.**

  - Ao utilizar o Lincros App pela primeira vez, é necessário que o usuário habilite as permissões necessárias para utilizar os recursos do sistema.
  - Com esta melhoria, reduzimos a quantidade de toques necessários para realizar esta etapa, de 7 toques para apenas 4.

- **Agrupar entregas destinadas ao ajudante e exibí-las ao motorista**

  - Ao gerar uma lista de entregas para o ajudante, o motorista pode verificar quais são essas entregas e, caso necessário, retomar as entregas para si.

![Imagem 4: Ao gerar uma lista de entregas para o ajudante, o motorista pode verificar quais são essas entregas e, caso necessário,…](https://ajuda.sankhya.com.br/hc/article_attachments/44012964577047)

- **Melhoria na tela de assinatura**

  - Desenvolvemos uma nova tela de assinatura, com um design mais moderno e uma interatividade mais prática, propícia ao dia-a-dia dos motoristas.

![Imagem 5: Desenvolvemos uma nova tela de assinatura, com um design mais moderno e uma interatividade mais prática, propícia ao…](https://ajuda.sankhya.com.br/hc/article_attachments/44012981593623)

- ## Exibir ao ajudante a lista das entregas que foram selecionadas pelo motorista

  - Desenvolvemos novas telas e funcionalidades para que o ajudante possa registrar os apontamentos das entregas no app.

    - É necessário que o ajudante informe o código do canal ou QR CODE que foi gerado pelo motorista, para então acessar a sua lista de entregas e posteriormente realizar o apontamento das entregas.
    - Ainda na tela de lista de entregas do ajudante, é possível finalizar a sua viagem, ou seja, as entregas que foram repassadas a ele.ais agilidade no uso do app.
