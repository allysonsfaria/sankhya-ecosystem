# [Lincros APP] - Release Notes 2.14

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012913898647)

## [Ajustar login do aplicativo com Azure AD](https://transpobrasil.atlassian.net/browse/APP-223)

A partir de agora é possível validar o login da persona separador através do ”Azure AD” tocando sobre a opção “Login com Microsoft”, inserimos uma nova biblioteca “lib react-native-msal” para atender a necessidade do cliente Azul e aumentar a segurança na autenticação do login.

## [Apontar de forma manual a quantidade que foi entregue de um determinado item da nota](https://transpobrasil.atlassian.net/browse/APP-220)

Adicionamos essa melhoria para que o motorista possa informar a quantidade desejada de um determinado item da nota que ele entregando parcialmente. Pois no cenário antigo no app, para fazer o apontamento de quantidade entregue de um item, o motorista tinha que utilizar os botões de '+' ou '-' para determinar o valor desejado, Ex: 2.000 unidades de um item, porém o que foi entregue foi somente 200 unidades. E utilizando o botão '-' o motorista demorava muito tempo para chegar no valor desejado. Agora neste novo cenário, trouxemos também a opção para o motorista digitar manualmente o valor que deseja apontar como entregue.

## [Reproduzir um alerta sonoro ao realizar a leitura de um código de barras](https://transpobrasil.atlassian.net/browse/APP-203)

Adicionamos essa melhoria para que a persona separador seja alertado através de um alerta sonoro toda vez que bipar um volume, com isso o mesmo passa ter mais assertividade de um volume foi de fato bipado por ele.

## [Criar nova tela de "tipos de documentos" ao concluir uma entrega ou coleta](https://transpobrasil.atlassian.net/browse/APP-201)

Realizamos as alterações de layouts das telas para informar os tipos de documentos e também a escrita da frase para o cenário de uma entrega. Agora temos um padrão na exibição das telas de documentos tanto para persona motorista funcionário quanto para persona motorista SFX.

## [Agrupar entregas que estão dentro do mesmo raio de entrega](https://transpobrasil.atlassian.net/browse/APP-183)

Adicionamos essa melhoria para que o motorista possa visualizar na tela do app de maneira rápida, que um determinado raio de distancia possui varias entregas para serem realizadas. Com isso o mesmo consegue finalizar suas entregas com mais agilidade e também otimiza o seu tempo utilizando o app.

## [Criar mensagem informativa para quando motorista estiver sem conexão com a internet](https://transpobrasil.atlassian.net/browse/APP-178)

Adicionamos esse recurso para que os motoristas possam visualizar na tela de visitas concluídas ou acessando os detalhes de uma entrega, uma mensagem alertando o mesmo esta sem conexão com a internet, também criamos um ícone sinalizando que determinada entrega apontada como concluída ainda não foi enviada para central. Com base nessa melhoria o nosso suporte poderá auxiliar o cliente se necessário de forma mais eficaz e também o próprio motorista passa ter uma mensagem mais clara e objetiva sobre sua conectividade com a internet no momento.

## [Solicitar grau de parentesco ao confirmar uma entrega](https://transpobrasil.atlassian.net/browse/APP-149)

Implementamos esse recurso para que o motorista possa apontar o grau de parentesco do recebedor de uma entrega, com isso ambos se beneficiam, tanto o cliente que agora passa a ter uma informação mais detalhada sobre quem recebeu a entrega, como a persona do motorista que pode utilizar essas informações a seu favor também se necessário.
