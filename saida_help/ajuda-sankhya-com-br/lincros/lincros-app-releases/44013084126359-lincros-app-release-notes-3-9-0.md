# [Lincros APP] - Release Notes 3.9.0

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44013089054615)

## Melhorias:

## Validação de imagem por IA

A nova funcionalidade integra o Lincros APP com uma solução de Inteligência Artificial para validar automaticamente as imagens de canhotos de notas fiscais registradas pelos motoristas. Após o motorista tirar a foto, a imagem é enviada para a IA, que verifica se os critérios exigidos, como assinatura, estão presentes. Caso validada, a imagem é encaminhada diretamente ao Tracking. Se a validação falhar, o motorista é solicitado a registrar uma nova imagem, garantindo a precisão e qualidade dos documentos capturados.

## Enviar sequencia realizada

O App Lincros agora envia a sequência realizada no campo SequenciaRealizada para todas as ocorrências de Pré-Entrega, Entrega e Devolução, garantindo que a ordem das entregas seja corretamente registrada pelo sistema Tracking.

Além disso, ao confirmar uma entrega subsequente a uma Pré-Entrega ou Devolução, a sequência realizada registrada anteriormente é mantida, assegurando consistência e precisão no monitoramento das entregas.
