# [Lincros APP] - Release Notes 2.15

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012929400599)

## Melhorias:

- ## Remover background de fundo ao registrar uma foto de entrega ou uma foto de evidencia

  - Agora é possível registrar a foto do canhoto da entrega ou uma foto evidencia completa, sem cortes, a foto é exibida sem cortes e mantida na mesma posição original em que foi tirada.

![Imagem 2: Agora é possível registrar a foto do canhoto da entrega ou uma foto evidencia completa, sem cortes, a foto é exibida…](https://ajuda.sankhya.com.br/hc/article_attachments/44012914833047)

- ## Alterar a mensagem "Lido com sucesso!" para que seja exibido o número do código de barras lido

  - Ao efetuar uma coleta e realizar a bipagem de um volume, é possível visualizar na tela do dispositivo o código de barras que foi lido.
  - Com isso é possível ter mais precisão de que um volume foi de fato lido quando você faz conferência física com o que está sendo exibido na tela do dispositivo.

- **Alterar nomenclaturas nas telas de enviar foto de uma entrega ou de uma devolução**

  - Ajustes técnicos: Alteramos as nomenclaturas nos registros de foto de uma entrega e de uma devolução, com intuito de tonar mais objetivo e compreensível.
  - Ao apontar uma entrega e seguir para o registro da foto da mesma, agora é exibido a frase “Registre uma foto do canhoto”. O mesmo acontece para o cenário de apontamento de uma devolução, a frase agora exibida é a “Registre uma evidência da devolução”.

![Imagem 3: Ao apontar uma entrega e seguir para o registro da foto da mesma, agora é exibido a frase “Registre uma foto do…](https://ajuda.sankhya.com.br/hc/article_attachments/44012929978391)

## Inovação:

- ## Exibir botão com funcionalidade que permite ao motorista SFX remover um volume bipado erroneamente (Coleta aberta)

  - Ao iniciar a bipagem de volumes de uma determinada coleta, e realizar a bipagem de um volume erroneamente, agora é possível remover este volume, isso faz com que você tenha mais assertividade no processo de bipar volumes durante uma coleta e também ao transmitir informações mais precisas para central de monitoramento.

![Imagem 4: Ao iniciar a bipagem de volumes de uma determinada coleta, e realizar a bipagem de um volume erroneamente, agora é…](https://ajuda.sankhya.com.br/hc/article_attachments/44012910658967)

- ## Criada opção com funcionalidades para criar rotas no Tracking

  - Trouxemos um novo recurso para melhorar ainda mais o processo de bipagem por roteirização, pois agora é possível criar uma rota de entrega para os pedidos bipados, quando for selecionada apenas uma placa de veículo.

![Imagem 5: Trouxemos um novo recurso para melhorar ainda mais o processo de bipagem por roteirização, pois agora é possível criar…](https://ajuda.sankhya.com.br/hc/article_attachments/44012915576343)

- **Permitir ao separador informar uma data em que será executada a sessão de roteirização gerada:**

  - Agora é possível escolher uma data em que a viagem dos pedidos roteirizados será executada

![Imagem 6: Agora é possível escolher uma data em que a viagem dos pedidos roteirizados será executada](https://ajuda.sankhya.com.br/hc/article_attachments/44012926941335)

- ## Validar a bipagem de um volume de forma manual

  - Disponibilizamos esse novo recurso, para que seja possível validar a leitura de volume de forma manual, pois sabemos que muitas vezes as etiquetas estão ilegíveis para a realização da leitura, e através da validação de leitura manual do volume será possível dar continuidade ao processo de leitura sem maiores problemas.

![Imagem 7: Disponibilizamos esse novo recurso, para que seja possível validar a leitura de volume de forma manual, pois sabemos…](https://ajuda.sankhya.com.br/hc/article_attachments/44012915814423)

- ## Alterar campo de pesquisa e possibilitar ao motorista localizar uma entrega ou coleta pelo endereço ou nome do cliente

  - Foi desenvolvido esse novo campo de pesquisa, que permite localizar uma entrega ou coleta, digitando um endereço ou buscando pelo nome de um determinado cliente.

![Imagem 8: Foi desenvolvido esse novo campo de pesquisa, que permite localizar uma entrega ou coleta, digitando um endereço ou…](https://ajuda.sankhya.com.br/hc/article_attachments/44012916069527)

- **Permitir ao motorista concluir diversas entregas de uma única vez**

  - Nesse novo recurso, é possível selecionar um ou mais locais de entrega, e fazer o apontamento de conclusão das entregas de uma só vez.

![Imagem 9: Nesse novo recurso, é possível selecionar um ou mais locais de entrega, e fazer o apontamento de conclusão das entregas…](https://ajuda.sankhya.com.br/hc/article_attachments/44012944292759)

- ## Registrar apenas uma foto para entregas de notas agrupadas para um único cliente:

  - Apresentando as opções de Entregar tudo e Devolver tudo - Criamos esse funcionalidade que permite agilizar o processo de registrar fotos de comprovações das entregas e também das devoluções.
  - É possível registrar uma única foto para comprovar a entrega ou devolução de diversas notas fiscais de uma só vez, desde que todas as notas tenham o mesmo destinatário.
