# [Lincros APP] - Release Notes 2.18.1

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012935384471)

## Melhorias:

- ## Exibir o nome do tomador no card de coleta

  - Realizada adequação para que seja possível exibir o nome do tomador no card da coleta.

- Para que essa funcionalidade fique disponível é necessário habilitar o parâmetro “Exibir Nome do Tomador” no Tracking (Configurações → Parâmetros → Mobile → Parâmetros que determinam o que é exibido no mobile → “Exibir Nome do Tomador”).

![Imagem 2: Para que essa funcionalidade fique disponível é necessário habilitar o parâmetro “Exibir Nome do Tomador” no Tracking…](https://ajuda.sankhya.com.br/hc/article_attachments/44012920097943)

- **Criação de atalho para fácil acesso ao vídeo de treinamento**

  - Adicionamos um atalho na lista de entregas denominado como “Dicas”. Através desse atalho será possível visualizar o vídeo com dicas de como utilizar o app a qualquer momento.

![Imagem 3: Adicionamos um atalho na lista de entregas denominado como “Dicas”. Através desse atalho será possível visualizar o…](https://ajuda.sankhya.com.br/hc/article_attachments/44012949153687)

![Imagem 4: Adicionamos um atalho na lista de entregas denominado como “Dicas”. Através desse atalho será possível visualizar o…](https://ajuda.sankhya.com.br/hc/article_attachments/44012935896855)

- **Buscar no web service, os status de devoluções das entregas e pausas de jornadas**

  - Realizada adequação, para que o App consiga buscar no web service o status de entregas, devoluções, e pausa de jornadas, caso, por algum motivo, o usuário saia da rota.

## Inovação:

- - **Adequação para nível de tratamento de devolução do tipo "Total"**

    - Realizada adequação para bloquear a entrega parcial quando nível de Tratamento da Devolução estiver parametrizado como “Total”.
  - **Conferente - Botão de pesquisa placa e rota**

    - Você Conferente, agora é possível pesquisar a sua placa ou rota na listagem de Partida e Chegada. Mais agilidade no seu processo de conferência.

  ![Imagem 5: Você Conferente, agora é possível pesquisar a sua placa ou rota na listagem de Partida e Chegada. Mais agilidade no seu…](https://ajuda.sankhya.com.br/hc/article_attachments/44012936025879)

- - **Criar telas para bipagem e conferência de volumes - Conferente E-commerce**

    - Agora no Lincros App é possível realizar o processo de conferência de volumes. Quando os motoristas retornarem para o depósito com volumes devolvidos pelos clientes ou com volumes que foram coletados, o Conferente E-commerce poderá fazer a conferencia desses volumes (por bipagem) dentro do Lincros App.
