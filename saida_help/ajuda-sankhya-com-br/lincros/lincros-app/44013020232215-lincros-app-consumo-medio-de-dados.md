# [Lincros APP] -  Consumo médio de dados

**Menu:**Acessar menu configurações do mobile>  Apps > Gerenciar Apps > LincrosAPP > Uso de dados.
 **Objetivo**: Efetuar uma média do uso de dados nos dispositivos.

**Considerações**:

Esse artigo leva em consideração apenas o uso de dados no Lincros APP, para uma média totalitária deve ser levado em consideração os demais aplicativos utilizados pelo motorista.
Como, por exemplo: Maps, Whatsapp, entre outros... 

**Observação:** Pode haver variações das nomenclaturas dos menus de acesso, isso ocorre em decorrência de marcas e modelos de aparelhos.                      Os dados apresentados no smartphone são de responsabilidade do fabricante do aparelho, os valores não são gerados pela Lincros.

**Abaixo segue os procedimentos:**

1.Será necessário selecionar a opção 'Uso de dados':

![Imagem 1: 1.Será necessário selecionar a opção 'Uso de dados':](https://ajuda.sankhya.com.br/hc/article_attachments/44013059772311)

2.Irá abrir a tela abaixo, verifique se está listando a informação 'Este mês', caso não esteja clique em cima desta informação e a selecione.

![Imagem 2: 2.Irá abrir a tela abaixo, verifique se está listando a informação 'Este mês', caso não esteja clique em cima desta…](https://ajuda.sankhya.com.br/hc/article_attachments/44013083283095)

**Conclusão**: Após efetuar o processo acima, você obterá uma média de uso dos dados do Lincros App. Claro, também é possível repetir essa operação para os demais aplicativos utilizados no dia a dia do motorista, para obter a média mensal.

                                                                                 "Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
