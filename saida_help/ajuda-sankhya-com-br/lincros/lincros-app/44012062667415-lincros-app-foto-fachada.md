# [Lincros APP] Foto Fachada

**Menu**: Não se aplica

**Objetivo**: Agora, os motoristas poderão tirar uma foto da fachada do local de entrega como comprovação visual de que o volume foi entregue no local correto.

**Considerações**:

- Habilitar parâmetro no Tracking, o parâmetro só poderá ser alterado pelo time Lincros, solicite apoio ao time de Suporte.
  - Estar na versão WEB 4.32
- Estar na versão mínima mobile 2.22.0

A tela Foto fachada será apresentada no Lincros APP quando o parâmetro "Exigir Foto Fachada" estiver ativado no sistema Tracking.

Para ativar o parâmetro acesse:
Menu> Configurações > Parâmetros > Mobile >Exigir Foto Fachada.

![Imagem 1: Para ativar o parâmetro acesse: Menu> Configurações > Parâmetros > Mobile >Exigir Foto Fachada.](https://ajuda.sankhya.com.br/hc/article_attachments/44012076821399)

![Imagem 2: Para ativar o parâmetro acesse: Menu> Configurações > Parâmetros > Mobile >Exigir Foto Fachada.](https://ajuda.sankhya.com.br/hc/article_attachments/44012076966167)

Após habilitar o parâmetro conforme orientado na imagem acima, ao acessar a rota e apontar uma entrega após a tela de comprovante do canhoto, em seguida surgirá uma tela para que o usuário registre a foto da fachada:

![Imagem 3: Após habilitar o parâmetro conforme orientado na imagem acima, ao acessar a rota e apontar uma entrega após a tela de…](https://ajuda.sankhya.com.br/hc/article_attachments/44012031073559)

A foto fachada deverá ser exibida na aba de recebimento no ícone abaixo.
