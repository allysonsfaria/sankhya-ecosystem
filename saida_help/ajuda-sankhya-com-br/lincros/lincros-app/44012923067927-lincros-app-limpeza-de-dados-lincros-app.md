# [Lincros APP] - Limpeza de Dados Lincros App

**Menu**: Aplicativo Lincros App

**Objetivo**: Como efetuar a limpeza de dados no aplicativo Lincros App.

**Considerações**:

- Esta limpeza é muito importante para que o aplicativo seja iniciado sem informações de sessões antigas que podem conflitar em alguns processos;
- Para alterar o canal do aplicativo é necessário efetuar esta limpeza;

Abaixo segue os procedimentos para efetuar a limpeza de dados no aplicativo Lincros App:

1. Localizar no aparelho o recurso 'Configurações', e clicar para acessar o mesmo;
2. Dentro de Configurações, acessar a opção 'Aplicativos';

   ![Imagem 1: Dentro de Configurações, acessar a opção 'Aplicativos';](https://ajuda.sankhya.com.br/hc/article_attachments/44012893558551)

3. Localizar o aplicativo 'Lincros App' e entrar no mesmo;

![Imagem 2: 3. Localizar o aplicativo 'Lincros App' e entrar no mesmo;](https://ajuda.sankhya.com.br/hc/article_attachments/44012923450519)

4. Dentro do Aplicativo Lincros App, selecionar a opção 'Armazenamento';

![Imagem 3: 4. Dentro do Aplicativo Lincros App, selecionar a opção 'Armazenamento';](https://ajuda.sankhya.com.br/hc/article_attachments/44012923566615)

5. Selecionar a opção 'Limpar dados';

![Imagem 4: 5. Selecionar a opção 'Limpar dados';](https://ajuda.sankhya.com.br/hc/article_attachments/44012912620951)

6. Efetuando o processo da etapa 5 (citado acima),  o aparelho vai solicitar a confirmação se realmente deseja excluir os dados do App;

7. Clicar para confirmar a ação para finalizar a limpeza;

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
