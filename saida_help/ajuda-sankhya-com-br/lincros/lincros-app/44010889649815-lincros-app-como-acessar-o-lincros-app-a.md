# [Lincros APP] - Como acessar o Lincros App através de QR Code

**Menu:** Lincros App

**Objetivo**: Como acessar o canal no Lincros App através da leitura de QR Code

## Considerações:

- Possuir QR Code do código do canal. Caso ainda não tenha o QR Code, nós ensinamos como gerá-lo através do artigo [Como gerar QR Code de acesso ao Lincros App](https://sankhya.zendesk.com/hc/pt-br/articles/44010889649815)

Abaixo segue os procedimentos:

1. Ao acessar o aplicativo, clique em 'Ler QR Code';

   ![Imagem 1: Ao acessar o aplicativo, clique em 'Ler QR Code';](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963280818/02fb39f31e248e4073411a730d7c/F35B164BF9F69C8E14E8F67E059A9D25?expires=1791331200&signature=a5550d1d2e9a2fde1a12bd66d6f99551e3b45f3b273d313fef4e2fecfbb3baa6&req=dSkhFct2nYleUfMW3nq%2BgUO8QBwtarEIbG1RHjpDicK37qxIA4FkOR6u0xcb%0ApMWfdjGlgXC3q45sqph3XguxoQ8%3D%0A)
2. Após, escaneie o QR Code do canal;

   ![Imagem 2: Após, escaneie o QR Code do canal;](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963280829/d587c579fa27d667669ced63c508/68367C328E28FC03D42C4A3BF527F0F9?expires=1791331200&signature=5e0fb2c558f0a914295f64659e1b82fb8ab67983c8d049fca8ab31bd3e50467e&req=dSkhFct2nYldUPMW3nq%2BgfIGMjo3%2BCTWjX3bjbw6dgdBOad%2F%2B6GJSx9KTnSe%0A8rv1aj2dwtspD6P%2B%2BL72zLi63E4%3D%0A)
3. Caso não seja possível acessar o canal através do QR Code, ainda é possível utilizar a opção 'Digitar manualmente', digitando o código seguindo o formato 'https://mobile-EXEMPLO-tracking.lincros.com'
