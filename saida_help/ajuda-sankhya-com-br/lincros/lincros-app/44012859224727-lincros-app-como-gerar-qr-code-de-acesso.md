# [Lincros APP] - Como gerar QR Code de acesso ao Lincros App

**Menu:** Lincros App.

**Objetivo**: Como gerar o QR Code de acesso ao canal do Lincros App.

## Considerações:

- Possuir acesso ao Lincros App e possuir o código do canal;

Seguem abaixo os procedimentos:

1. Acessar um gerador de QR Code gratuito (exemplo [QR Code Generator](https://br.qr-code-generator.com/), [QR Code Fácil](https://www.qrcodefacil.com/) etc);
2. Inserir o código do canal no campo correspondente a URL seguindo o formado: "https://mobile-EXEMPLO-tracking.lincros.com", conforme exemplo abaixo:

![Imagem 1: Inserir o código do canal no campo correspondente a URL seguindo o formado:…](https://ajuda.sankhya.com.br/hc/article_attachments/44012886850967)

3. Gerar e fazer download do QR Code:

![Imagem 2: 3. Gerar e fazer download do QR Code:](https://ajuda.sankhya.com.br/hc/article_attachments/44012905332119)

4. O QR Code deve ser compartilhado com os motoristas para que dessa forma seja possível acessar uma viagem sem a necessidade de digitar o código canal.

 "Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
