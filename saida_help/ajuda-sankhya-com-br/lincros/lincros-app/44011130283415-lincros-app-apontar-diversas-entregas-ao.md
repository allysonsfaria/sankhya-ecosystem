# [Lincros APP] - Apontar diversas entregas ao mesmo tempo

**Lincros APP**: Clicar em uma entrega com vários documentos

**Objetivo**: Essa funcionalidade foi implementada para que o motorista realize os apontamentos de forma mais rápida

**Considerações**:

- Possuir mais de um apontamento de entrega para realizar;

Nesse novo recurso, é possível selecionar um ou mais locais de entrega e é possível fazer o apontamento de conclusão das entregas de uma só vez.

Abaixo segue os procedimentos:

1. Na tela inicial do aplicativo, clique no botão em forma de lista conforme abaixo:

   ![Imagem 1: Na tela inicial do aplicativo, clique no botão em forma de lista conforme abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011180081943)
2. A tela irá exibir os clientes com uma caixa de seleção na lateral esquerda. Será exibido 'Selecionar locais', selecione os clientes pertinentes a entrega que será apontada.

   ![Imagem 2: A tela irá exibir os clientes com uma caixa de seleção na lateral esquerda. Será exibido 'Selecionar locais', selecione…](https://ajuda.sankhya.com.br/hc/article_attachments/44011180324631)
3. Conforme selecionar os clientes, ele irá contabilizar na tela. Após selecionar todos, basta clicar em Entregar/Devolver;

   ![Imagem 3: Conforme selecionar os clientes, ele irá contabilizar na tela. Após selecionar todos, basta clicar em Entregar/Devolver;](https://ajuda.sankhya.com.br/hc/article_attachments/44011138946967)

 Essa funcionalidade é viável no momento que o motorista tenha muitas entregas para serem apontadas, nesse sentido é interessante que ele utilize essa funcionalidade.
