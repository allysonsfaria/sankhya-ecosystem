# [Lincros APP] - Adicionar Cliente para Coleta de ativos/Retirada de Cestos via App Lincros

**Menu:**Acessar a rota no APP Lincros> Adicionar cliente
 **Objetivo**: Permitir e orientar ao motorista como adicionar um cliente para coleta de ativos via aplicativo.
 
**Considerações**: 
Para poder utilizar essa funcionalidade é necessário que os parâmetros abaixo estejam ativados em sua base, lembrando que a ativação dos parâmetros é efetuada pelo time de suporte.
Verificar ser o parâmetro ‘**Habilitar Gestão de Ativos**’ se encontra ativo. Caminho: Configurações > Parâmetros > Mobile> Habilitar Gestão de Ativos;
Verificar se o parâmetro ‘**Permitir ao motorista adicionar um cliente à rota para coletar ativos**’ se encontra ativo. Caminho: Cadastros > Unidade de Negócio > Configurações para o Smartphone> Permitir ao motorista adicionar um cliente à rota para coletar ativos;

**Abaixo segue os procedimentos:** 1º Passo: Ao iniciar a rota você deverá procurar pelo ícone Adicionar Cliente;

![Imagem 1: Menu: Acessar a rota no APP Lincros> Adicionar cliente Objetivo : Permitir e orientar ao motorista como adicionar um…](https://ajuda.sankhya.com.br/hc/article_attachments/44012149386135)

2 º Passo: Clique no botão e será exibida a tela abaixo, nesta tela você deverá clicar em Continuar;

![Imagem 2: 2 º Passo: Clique no botão e será exibida a tela abaixo, nesta tela você deverá clicar em Continuar;](https://ajuda.sankhya.com.br/hc/article_attachments/44012132108055)

3º Passo: Será listada uma tela para informar o cliente no qual você gostaria de adicionar a coleta. Neste ponto você poderá informar CPF/CNPJ, nome do cliente ou código do cadastro no Tracking.

**OBS:** O cliente deverá estar cadastrado previamente na base de dados no Tracking, para poder ser indicado no app Lincros.

![Imagem 3: OBS: O cliente deverá estar cadastrado previamente na base de dados no Tracking, para poder ser indicado no app Lincros.](https://ajuda.sankhya.com.br/hc/article_attachments/44012149688471)

4º Passo: Após selecionar o cliente clique em continuar;

![Imagem 4: 4º Passo: Após selecionar o cliente clique em continuar;](https://ajuda.sankhya.com.br/hc/article_attachments/44012149838359)

5 º Passo: Pronto! Sua coleta foi adicionada a rota com sucesso;

![Imagem 5: 5 º Passo: Pronto! Sua coleta foi adicionada a rota com sucesso;](https://ajuda.sankhya.com.br/hc/article_attachments/44012111130007)

6º Passo: Agora você pode apontar a coleta de ativos conforme orientações. Clique no cliente da coleta criada no APP e será exibida a tela abaixo, é necessário clicar em adicionar;

![Imagem 6: 6º Passo: Agora você pode apontar a coleta de ativos conforme orientações. Clique no cliente da coleta criada no APP e…](https://ajuda.sankhya.com.br/hc/article_attachments/44012111246999)

7º Passo: Aberta a tela, clique em Registro de Ativos;

![Imagem 7: 7º Passo: Aberta a tela, clique em Registro de Ativos;](https://ajuda.sankhya.com.br/hc/article_attachments/44012150194071)

8º Passo: Clique na opção exibida, no caso Coleta de Ativos e será listado todos os ativos cadastrados para a empresa, como demostrado a seguir;

![Imagem 8: 8º Passo: Clique na opção exibida, no caso Coleta de Ativos e será listado todos os ativos cadastrados para a empresa,…](https://ajuda.sankhya.com.br/hc/article_attachments/44012150340247)

9º Passo: Após apontar a quantidade de cestos clique em concluir;

![Imagem 9: 9º Passo: Após apontar a quantidade de cestos clique em concluir;](https://ajuda.sankhya.com.br/hc/article_attachments/44012119924631)

10º Passo: Posterior ao lançamento da ocorrência a mesma será apresentada em tela, para finalizar clique em concluir que será enviada a informação a central;
