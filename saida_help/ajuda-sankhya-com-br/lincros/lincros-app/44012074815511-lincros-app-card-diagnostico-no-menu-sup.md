# [Lincros APP] - Card "Diagnóstico" no menu superior do APP

**Menu:**Lincros APP
**Objetivo:**Monitorar o estado do dispositivo de forma eficiente. Essa atualização proporcionará aos usuários uma melhor compreensão do status do dispositivo, garantindo uma experiência otimizada.
**Considerações**: Versão mínima do APP 2.22

Lançamos o novo card **Diagnósticos** no menu superior do aplicativo. Agora, os usuários poderão acessar informações importantes de forma rápida e conveniente.
O card **Diagnósticos** exibirá dados essenciais, como status da internet, GPS, bateria e relógio. Essas informações permitirão que os usuários monitorem o estado do dispositivo de forma eficiente.
