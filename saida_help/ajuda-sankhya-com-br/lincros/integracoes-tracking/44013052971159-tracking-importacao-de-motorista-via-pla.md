# [Tracking] - Importação de motorista via planilha

**Menu**: Cadastros > Motoristas

**Objetivo**: Orientar o usuário como realizar a importação de motoristas via planilha

**Considerações**:
       - Necessário ter configurado e ativo no sistema o serviço de **Integração para Importar Motoristas**;

- No rodapé desta página você encontrará o modelo padrão da planilha de importação;

O Tracking possibilita que seja importado motoristas no sistema, via planilha. Importante salientar que não é possível efetuar a atualização (via planilha) de cadastros de motoristas que já constem no sistema.
Ou seja, na importação, o sistema somente efetua apenas o cadastro do motorista!

Segue abaixo os procedimento que deverá ser executado:
1. Acessar Cadastros > Motoristas;
2. Clicar na opção 'Upload';

![Imagem 1: O Tracking possibilita que seja importado motoristas no sistema, via planilha. Importante salientar que não é possível…](https://ajuda.sankhya.com.br/hc/article_attachments/44013089784343)

3. Selecionar o arquivo de importação e, por fim, clicar em Salvar;

![Imagem 2: 3. Selecionar o arquivo de importação e, por fim, clicar em Salvar;](https://ajuda.sankhya.com.br/hc/article_attachments/44013089906071)

4. Para acompanhar o processo de importação, deve-se acessar o menu Integrações, e clicar em “Detalhes” do serviço de integração para importar motoristas;

![Imagem 3: 4. Para acompanhar o processo de importação, deve-se acessar o menu Integrações, e clicar em “Detalhes” do serviço de…](https://ajuda.sankhya.com.br/hc/article_attachments/44013090000535)

5. Caso o arquivo seja processado com sucesso, será apresentada a mensagem de que o arquivo foi movido para o diretório de arquivos processados;
