# [Tracking] - Entrega que não está aparecendo na rota integrada

**Menu**: Gestão de Entregas > Relatórios > Baldeios realizados

**Objetivo**: Localizar alguma entrega que tenha sido integrada a uma rota e que posteriormente não foi localizada.

**Considerações**:

- O usuário deve possuir acesso a consulta do relatório de baldeios realizados;

No exemplo abaixo, o relatório de baldeio mostra as principais informações como por exemplo: o usuário que fez a operação, veículo de origem x destino, nome do motorista de origem x motorista destino.

1. Para ter acesso ao relatório basta acessar o menu: Relatórios > Baldeios Realizados, conforme print abaixo:

   ![Imagem 1: Para ter acesso ao relatório basta acessar o menu: Relatórios > Baldeios Realizados, conforme print abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44012509712535)
2. É possível que a entrega tenha sido baldeada por um usuário ou pelo sistema, segue exemplo abaixo:

   ![Imagem 2: É possível que a entrega tenha sido baldeada por um usuário ou pelo sistema, segue exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44012518772119)
3. Sempre que o usuário notar a falta de alguma entrega na rota integrada, é interessante validar primeiro se a placa teve registro de baldeio;
4. Dessa forma o usuário poderá localizar a nova rota e dar continuidade no monitoramento.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
