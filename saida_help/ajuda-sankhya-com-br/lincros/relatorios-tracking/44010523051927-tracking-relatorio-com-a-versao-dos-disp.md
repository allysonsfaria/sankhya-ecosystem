# [Tracking] - Relatório com a versão dos dispositivos

**Menu:**Cadastros > Dispositivos

**Objetivo**: Como exportar informações do cadastro de dispositivo, como a versão do App.

**Considerações**:

- Motorista deve ter o App Gestão de Entregas instalado;

O relatório que contém as informações dos dispositivos, está disponível em Cadastros > Dispositivos.

**Obs**.: Pode-se utilizar a opção 'Excel' para exportar as informações do relatório para uma planilha, conforme exemplo abaixo:
