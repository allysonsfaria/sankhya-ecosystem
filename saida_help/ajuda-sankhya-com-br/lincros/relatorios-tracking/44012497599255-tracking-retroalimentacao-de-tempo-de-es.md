# [Tracking] - Retroalimentação de Tempo de Espera

**Menu**: No Routing -> Aba: Retroalimentação

            No Tracking -> Relatórios

**Objetivo**: Orientar o usuário como enviar a mediana do tempo de espera para o Lincros Routing;

Considerações:

- Para esta funcionalidade ser executada ela deve estar implantada dentro do Tracking;
- Para ser possível enviar o tempo de espera é necessário gerar o relatório de mediana com base nas entregas já realizadas para os clientes;

Abaixo segue os procedimentos:

## Como enviar o tempo de espera para o Routing

1. Para enviar os tempos de espera ao Routing é necessário emitir o relatório “Retroalimentação do Tempo de Espera para o Lincros Routing” no módulo Tracking, conforme imagem abaixo:

## .

![Imagem 1: .](https://ajuda.sankhya.com.br/hc/article_attachments/44012497787287)

2. Para gerar este relatório é necessário selecionar os dados, para gerar uma mediana para a unidade de negócios selecionada;

![Imagem 2: 2. Para gerar este relatório é necessário selecionar os dados, para gerar uma mediana para a unidade de negócios…](https://ajuda.sankhya.com.br/hc/article_attachments/44012489425431)

3. Após gerar o relatório, clicar na opção 'exportar' para o Roteirizador Lincros;

![Imagem 3: 3. Após gerar o relatório, clicar na opção 'exportar' para o Roteirizador Lincros;](https://ajuda.sankhya.com.br/hc/article_attachments/44012466851991)
