# [Routing] - Como atualizar as informações do pedido já importado no sistema

**Menu**: Roteirizador > Importações > Pedidos

**Objetivo**: Atualizar os dados do pedido já importado no Routing

**Considerações**:

- Possuir acesso ao Routing, e a tela de importações de pedidos;
- O pedido deve estar importado com sucesso no Routing;
- O pedido deve constar com a situação de 'Não Roteirizado';
- Esse procedimento não se aplica a importações de pedidos integrados do TMS;

Quando houver necessidade de alterar dados como quantidade de volumes, peso, itens ou até mesmo o cliente, não é necessário excluir o pedido do Routing, basta seguir os passos abaixo:

1. Acessar a tela de importações de pedidos:
2. Importações > Pedidos > Novo;
3. Selecionar o depósito;
4. Selecionar o layout de importação correspondente;
5. Selecionar o arquivo já com as devidas alterações necessárias;
6. Clicar em 'Confirmar':

![Imagem 1: Clicar em 'Confirmar':](https://ajuda.sankhya.com.br/hc/article_attachments/44013085513111)

Após seguir os passos, caso haja alteração de informações no pedido, os mesmos serão sobrepostos as informações anteriores.

Vale ressaltar, que caso não tenha alterações no novo arquivo, o sistema considerará como data da inclusão do pedido, a data do primeiro envio, e havendo alterações, será considerado a data e horário que houve a nova integração de informações.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
