# [Routing] - Release Notes 2.15

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012202247959)

**Melhorias**

---

**Obtenção de praças de pedágios**

Foi adicionado a melhoria para permitir utilizar os pedágios da base Lincros.

---

**Importação de clientes via arquivo .TXT**

Foi adicionado a melhoria para permitir informar o tipo do cliente (identificador) e a prioridade de entrega (10 - Normal, 20 - Alta, 30 - Muito Alta) via importação de arquivo '.TXT'.

---

**Filtro de usuário por e-mail**

Foi adicionado o filtro e-mail na tela de consulta de usuário.

![Imagem 2: Foi adicionado o filtro e-mail na tela de consulta de usuário.](https://ajuda.sankhya.com.br/hc/article_attachments/44012198085399)

---

**Filtrar os pedidos por período de importação**

Na tela de "iniciar uma nova sessão de roteirização" foi adicionado a melhoria para filtrar os pedidos por período de importação, sem precisar selecionar o arquivo de importação.

![Imagem 3: Na tela de "iniciar uma nova sessão de roteirização" foi adicionado a melhoria para filtrar os pedidos por período de…](https://ajuda.sankhya.com.br/hc/article_attachments/44012220574743)

---

**Melhor performance ao filtrar pedidos**

Foi realizado uma melhoria de performance ao filtrar os pedidos na tela de iniciar uma nova sessão de roteirização.

---

**Re-roteirização de baldeio do Gestão de Entregas (exclusivo para o sistema Gestão de Entregas Lincros)**

Obter a melhor sequência planejada com base coordenadas e janela de atendimento.
