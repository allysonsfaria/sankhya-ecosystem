# [Routing] - Release Notes 2.52

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012299838103)

## Melhorias:

**Novo parâmetro que permite a seleção de tabelas para Ordem de Coleta (Integração com TMS)**Foi adicionado um novo parâmetro no depósito que permite o retorno de mais de uma tabela de frete ao criar uma nova rota terceirizada/fracionada. Este novo comportamento será ativado apenas se o parâmetro estiver habilitado. Para novos depósitos, o parâmetro estará desabilitado (false) por padrão, mantendo o comportamento atual de retornar apenas uma tabela com o menor valor de frete.
