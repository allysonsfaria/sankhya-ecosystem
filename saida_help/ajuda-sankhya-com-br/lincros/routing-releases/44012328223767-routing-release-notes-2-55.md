# [Routing] - Release Notes 2.55

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44012323092375)

## Melhorias:

**Rotas de Transferência para Pontos de Apoio intercaladas com entregas para clientes finais**Com a nova funcionalidade de criar rotas de transferência entre vários pontos de apoio, adicionamos um novo parâmetro de estratégia de roteirização para habilitar a funcionalidade ao depósito.

**Tela de programação de Transferências**Introdução de uma nova funcionalidade de programação de transferências, incluindo uma interface aprimorada para sequenciar rotas entre pontos de apoio, com critérios de sucesso estabelecidos para assegurar a precisão na geração de rotas de transferência, e considerar todos os aspectos logísticos relevantes, como custos, capacidades, previsões e tempos.

## Mover atividades para rotas de Transferências

Implementamos uma nova funcionalidade de mover as atividades selecionadas para uma rota de transferência com múltiplos pontos de apoio, proporcionando flexibilidade ao usuário para definir entregas tanto antes quanto após a chegada ao último ponto de apoio.

## Arrastar atividades para rotas de Transferências

Também implementamos a funcionalidade de arrastar uma atividade selecionada para o sequenciamento de entrega em rota de transferência, com recálculo preciso da rota considerando custos, capacidades, distâncias e tempo de descarga informado.

## Exportar a rota de transferência para o Tracking como rota de Cross Docking

Agora as rotas de transferência podem ser exportadas direto ao Tracking como rotas de Cross Docking.
