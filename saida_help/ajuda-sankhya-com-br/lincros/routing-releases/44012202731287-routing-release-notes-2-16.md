## Inativar veículo associado ao setor

Ao inativar o veículo associado ao setor foi adicionado a validação para exibir o aviso de confirmação.

![Imagem 3: Ao inativar o veículo associado ao setor foi adicionado a validação para exibir o aviso de confirmação.](https://ajuda.sankhya.com.br/hc/article_attachments/44012189067287)

## TMS x Routing - Importações de pré-nota/nota

Foi adicionado a funcionalidade para o sistema considerar a série do pedido (pré-nota/nota) enviado do TMS para o Routing.

## Relatório Indicadores de Roteirização

Este relatório foi revisado para melhor desempenho na geração.

---

## Sessões em lote

Foi adicionado a regra para após criar a sessão voltar para a tela de iniciar ou pesquisar sessão.

---

## Arquivo de exportação para o sistema Tracking (Gestão de Entregas)

Foi realizado a melhoria para enviar os campos série e CNPJ do emissor no arquivo .xml.
