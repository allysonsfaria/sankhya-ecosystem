# [Routing] - Release Notes 2.36

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44010572452119)

**Melhorias**:

- ## Nível de prioridade no setor

Introduzimos um novo parâmetro do depósito que permite a atribuição de prioridade aos setores. Agora, é possível realizar a roteirização das entregas de forma estratégica, levando em consideração as prioridades definidas para cada setor. Isso proporciona uma organização mais eficiente e otimizada do processo de entrega.
O parâmetro está visível para usuários Manager (Acesso: Roteirizador> Cadastros> Depósitos> Parâmetros do depósito)
