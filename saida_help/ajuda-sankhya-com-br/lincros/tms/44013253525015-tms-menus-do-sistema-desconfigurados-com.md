# [TMS] - Menus do sistema desconfigurados com nomes estranhos

**Menu**: Vários menus do sistema TMS com nomes estranhos

**Objetivo**: Como proceder quando no TMS aparecer os menus com nomes estranhos?

**Considerações**:

- Quando tiver habilitado a opção de 'Traduções' configurado no navegador

Ao acessar o sistema TMS está aparecendo vários menus com nomes estranhos, conforme print abaixo:

![Imagem 1: Ao acessar o sistema TMS está aparecendo vários menus com nomes estranhos, conforme print abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44013270108311)

Abaixo segue os procedimentos:

1. Verificar na guia principal do navegador se nao existe nenhuma tradução configurada, conforme o print abaixo:

![Imagem 2: Verificar na guia principal do navegador se nao existe nenhuma tradução configurada, conforme o print abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44013270287383)

2. Caso tiver, basta retirar a tradução aplicada, deixar como 'Sem nenhuma tradução';

3. Após, basta clicar em F5 para atualizar a tela;

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
