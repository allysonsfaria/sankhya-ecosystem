# [TMS] Ajustar Taxa Adicional do Embarque

**Menu:** Operacional > Cargas > Embarque
**Objetivo:** Sanar a dúvida referente ao tema, além de apresentar uma solução para a correção.

**Considerações:**Houve o lançamento de um valor errado nas "Taxas Adicionais" em um embarque, porém não está sendo possível remover, porque isso ocorre? 

![Imagem 1: Menu: Operacional > Cargas > Embarque Objetivo: Sanar a dúvida referente ao tema, além de apresentar uma solução para a…](https://ajuda.sankhya.com.br/hc/article_attachments/44011610942359)

Esse comportamento ocorre, pois o sistema possui uma "trava" de segurança, a qual impede a remoção de uma taxa adicional, quando a situação do embarque é diferente de "Criado".

Essa trava existe, para que não ocorra um lançamento de uma taxa com a finalidade de "ajustar" o valor calculado, e após a integração a mesma seja removida. 

**Como posso corrigir o valor?**

Neste caso, será necessário lançar uma taxa adicional no conhecimento. 

**1-** Abra o conhecimento desejado.

**2-** Na aba "Taxas adicionais" clique em "Adicionar"

![Imagem 2: Esse comportamento ocorre, pois o sistema possui uma "trava" de segurança, a qual impede a remoção de uma taxa…](https://ajuda.sankhya.com.br/hc/article_attachments/44011640978199)

**3-** Informe a descrição da "Taxa"(Exemplo: Ajudantes de descarga) 

![Imagem 3: 3- Informe a descrição da "Taxa"(Exemplo: Ajudantes de descarga)](https://ajuda.sankhya.com.br/hc/article_attachments/44011619249303)

**4-** Selecione um componente(Neste momento precisa escolher entre os componentes já cadastrados, mas fique tranquilo a descrição vai aparecer nos "Movimentos").

![Imagem 4: 4- Selecione um componente(Neste momento precisa escolher entre os componentes já cadastrados, mas fique tranquilo a…](https://ajuda.sankhya.com.br/hc/article_attachments/44011650825367)

**5-** Informe o Valor.

**6-** Clique em Salvar.

![Imagem 5: 5- Informe o Valor. 6- Clique em Salvar.](https://ajuda.sankhya.com.br/hc/article_attachments/44011611535255)

**Conclusão:** Após este passo a passo, terá realizado a correção do valor lançando erroneamente no embarque.
