# [Tracking] - Cadastro de transportadoras

**Menu**: Gestão de entregas > Cadastros > Transportadoras

**Objetivo**: Cadastrar novos transportadores

## Considerações:

- Possuir as informações da transportadora (CNPJ, Razão Social, etc.);
- Realizar a consulta pelo CNPJ antes, para não cadastrar transportadora em duplicidade;

1. Na aba de cadastro de transportadoras, clicar na opção 'Novo';

   ![Imagem 1: Na aba de cadastro de transportadoras, clicar na opção 'Novo';](https://ajuda.sankhya.com.br/hc/article_attachments/44011438625943)
2. Após, irá abrir uma nova janela conforme abaixo:

   ![Imagem 2: Após, irá abrir uma nova janela conforme abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011424549015)

## Como preencher:

Código do negócio é opcional.

Preencha o nome da transportadora

CNPJ correto

Selecione o campo 'Ativo'

Clique na opção 'Salvar';

2. No campo de usuários, digite todos os usuários que podem ter acesso a essa transportadora, essa informação vai impactar na visualização das placas futuramente;

![Imagem 3: 2. No campo de usuários, digite todos os usuários que podem ter acesso a essa transportadora, essa informação vai…](https://ajuda.sankhya.com.br/hc/article_attachments/44011430344599)

3. Após informar todos os usuários habilitados correspondentes a transportadora, clique em 'salvar';

4. É muito importante que o usuário revise o cadastro antes de finaliza-lo, pois o cadastro incompleto pode prejudicar o monitoramento;

5. Após o preenchimento de todos os dados, os usuários vinculados ao transportador podem fazer o teste para a visualização das placas e validar o cadastro realizado.

 "Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
