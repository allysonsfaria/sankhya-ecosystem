# [Tracking] - Cadastro de Rota Manual

**Menu**: Cadastros > Rotas

**Objetivo**: Serve para o usuário criar manualmente, novas rotas de entrega ou coletas para os veículos.

**Considerações**:

- O usuário deve utilizar os filtros para refinar a rota;

Abaixo segue os procedimentos:

1. Para gerar uma nova rota de entrega ou coleta, é necessário que sejam preenchidos os campos abaixo:
2. Selecionar "Nova" Rota:

![Imagem 1: Selecionar "Nova" Rota:](https://ajuda.sankhya.com.br/hc/article_attachments/44011448559895)

3. Após isso, o usuário precisará selecionar os seguintes campos: Unidade de negócio, Transportadora, Data, Placa do Veículo e Cliente;

4. Após todos os passos, deve-se clicar no flag verde, localizado ao lado direito da tela.

![Imagem 2: 4. Após todos os passos, deve-se clicar no flag verde, localizado ao lado direito da tela.](https://ajuda.sankhya.com.br/hc/article_attachments/44011466074647)

5. Após salvo, pode acompanhar a Rota criada na Aba "Monitoramento", filtro Padrão;

![Imagem 3: 5. Após salvo, pode acompanhar a Rota criada na Aba "Monitoramento", filtro Padrão;](https://ajuda.sankhya.com.br/hc/article_attachments/44011448881687)

6. Assim estará no Mapa Sinótico para acompanhamento:

![Imagem 4: 6. Assim estará no Mapa Sinótico para acompanhamento:](https://ajuda.sankhya.com.br/hc/article_attachments/44011478809111)
