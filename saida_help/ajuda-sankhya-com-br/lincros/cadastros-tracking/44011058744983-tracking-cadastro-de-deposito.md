# [Tracking] - Cadastro de depósito

**Menu**: Cadastros > Depósitos

**Objetivo**: Cadastrar realizar o cadastro de  novo depósito no Tracking

**Considerações**:

- Possuir  cadastro da Unidade de Negócio;

Abaixo segue os procedimentos:

1. Acessar o menu 'Cadastros':

![Imagem 1: Acessar o menu 'Cadastros':](https://ajuda.sankhya.com.br/hc/article_attachments/44010998796695)

2. Selecionar a opção 'Novo';

![Imagem 2: 2. Selecionar a opção 'Novo';](https://ajuda.sankhya.com.br/hc/article_attachments/44011043214231)

3. Irá abrir uma nova tela para o preenchimento das informações deste novo depósito;

![Imagem 3: 3. Irá abrir uma nova tela para o preenchimento das informações deste novo depósito;](https://ajuda.sankhya.com.br/hc/article_attachments/44011028132375)

- **Un. Negócio:** Seleciona a unidade que esse depósito ficará vinculado;
- **Nome:** Nome do depósito;
- **Código Externo:** Código do depósito (copiar do Routing, se cliente tiver)
- **Ativo:** Habilitar para utilizar
- **Endereço, bairro, cidade, latitude, longitude e raio:** (copiar do Routing, se cliente tiver)

4. Após clicar em 'Salvar';

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
