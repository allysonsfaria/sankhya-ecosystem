# [Tracking] - Cadastrar usuário conferente

**Menu**: Cadastros > Usuários

**Objetivo**: Cadastrar usuário com tipo 'Conferente'

**Considerações**:

             - O parâmetro 'Validar Login por CPF e senha no Mobile" deve estar assinalado;
             - O cadastro do conferente é utilizado, para o conferente logar no Lincros App e fazer o controle de movimentação de ativos;

Abaixo segue os procedimentos:

1. Acessar o cadastro de usuários e clicar em "Novo":

   ![Imagem 1: Acessar o cadastro de usuários e clicar em "Novo":](https://ajuda.sankhya.com.br/hc/article_attachments/44011506983191)
2. Inserir nome do usuário e o e-mail;

    No Login, informar o CPF;

    Inserir uma senha e ativar usuário;

    Informar o tipo de usuário "Conferente":

![Imagem 2: Informar o tipo de usuário "Conferente":](https://ajuda.sankhya.com.br/hc/article_attachments/44011520186903)

3. Informar pelo menos uma Unidade de Negócio e uma Transportadora:

![Imagem 3: 3. Informar pelo menos uma Unidade de Negócio e uma Transportadora:](https://ajuda.sankhya.com.br/hc/article_attachments/44011477193367)

![Imagem 4: 3. Informar pelo menos uma Unidade de Negócio e uma Transportadora:](https://ajuda.sankhya.com.br/hc/article_attachments/44011477406871)

4. No Lincros App, informar o CPF do conferente:

![Imagem 5: 4. No Lincros App, informar o CPF do conferente:](https://ajuda.sankhya.com.br/hc/article_attachments/44011536570647)

5. Será solicitado o cadastro de uma nova senha:

![Imagem 6: 5. Será solicitado o cadastro de uma nova senha:](https://ajuda.sankhya.com.br/hc/article_attachments/44011492870807)

6. E em seguida apresentará a tela, para o lançamento de quantidade de ativos:

![Imagem 7: 6. E em seguida apresentará a tela, para o lançamento de quantidade de ativos:](https://ajuda.sankhya.com.br/hc/article_attachments/44011528279703)

 "Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
