# [Tracking] - Cadastro de Novo Usuário no Tracking

## 1 - Problema Relatado pelo Cliente:

O cliente relatou a necessidade de criar um novo usuário no sistema e configurar suas permissões de acesso. Durante a interação, o cliente não tinha claro o processo para realizar o cadastro e vincular as permissões de acesso a unidades de negócio e transportadoras.

---

## 2 - Passo a Passo para Resolver o Problema:

**Objetivo**: Realizar o cadastro de um novo usuário e definir as permissões necessárias.

**Pré-Requisitos**:

- O analista ou cliente deve ter o perfil **Manager** ou algum perfil personalizado com acesso ao menu **Cadastros** para realizar o cadastro de novos usuários.

**Caminho**:

1. **Menu > Cadastros > Usuários > Novo**.

   ![Imagem 1: Menu > Cadastros > Usuários > Novo .](https://ajuda.sankhya.com.br/hc/article_attachments/44011549357847)

   ![Imagem 2: Menu > Cadastros > Usuários > Novo .](https://ajuda.sankhya.com.br/hc/article_attachments/44011533836951)
2. **Preencher os Campos Solicitados**: Preencha os campos obrigatórios destacados com asterisco (**\***), com as informações do usuário.

   - **Perfil de Usuário :**No campo "Perfil do Usuário", selecionar qual o perfil deste usuário. Esta informação delimitará os acesso do usuário dentro do sistema
   - **Unidade de Negócio**: No aba "Unidade de Negócio", vincule a(s) unidade(s) de negócio que o usuário terá acesso. Este processo poderá ser realizado utilizando a opção "Selecionar Todas" ou digitar o nome da unidade especifica.

     ![Imagem 3: Unidade de Negócio : No aba "Unidade de Negócio", vincule a(s) unidade(s) de negócio que o usuário terá acesso. Este…](https://ajuda.sankhya.com.br/hc/article_attachments/44011518159383)
   - **Transportadoras**: No aba "Transportadoras", para transferir as transportadoras da coluna "Disponíveis" para a coluna "Selecionada", utilize a seta "**>>**" para transferir todas ou a seta "**>** " para transferir apenas as transportadoras especificas.

     ![Imagem 4: Transportadoras : No aba "Transportadoras", para transferir as transportadoras da coluna "Disponíveis" para a coluna…](https://ajuda.sankhya.com.br/hc/article_attachments/44011549995415)
3. **Salvar Cadastro**: Após preencher todas as informações necessárias, clique em **Salvar** para concluir o cadastro do novo usuário.

**Observação**: Certifique-se de que o vínculo com as unidades de negócio e as transportadoras seja feito corretamente, para garantir que o novo usuário tenha as permissões necessárias de acesso.
