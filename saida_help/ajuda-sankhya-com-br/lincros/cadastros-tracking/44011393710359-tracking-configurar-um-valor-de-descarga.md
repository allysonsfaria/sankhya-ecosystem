# [Tracking] - Configurar um valor de descarga no cadastro do cliente

**Menu:** Gestão de entregas > Cadastros > Clientes

**Objetivo**: Configurar um valor pré-aprovado de custo para descarga dentro do cadastro de cada cliente.

## Considerações:

-  Caso o motorista solicitar um custo superior ao que foi pré-aprovado para descarga, a aplicação irá registrar uma pendência de aprovação que poderá ser aprovada ou reprovada através do módulo de descargas.

Abaixo segue os procedimentos:

1. Acessar o menu: Gestão de entregas> Cadastros > Clientes;
2. Localizar o cliente em questão;
3. Verificar o campo 'Valor pré-aprovado para descarga', conforme exemplo abaixo:

![Imagem 1: Verificar o campo 'Valor pré-aprovado para descarga', conforme exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011375629207)

4.Digitar valor pré aprovado para descarga nesse cliente;

5. Após, clicar em 'Salvar';

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
