# [Tracking] - Cadastro de Motivos de Entrega Fora do Raio

**Menu**: Cadastros > Motivos de Entrega Fora do Raio

**Objetivo**: Cadastrar motivos para apontamento de entrega fora do raio

**Considerações**:  Possuir um usuário previamente cadastrado e ativo no sistema.

Abaixo segue os procedimentos:

1. Acessar o menu: Cadastros > Motivos de Entrega Fora do Raio

![Imagem 1: Acessar o menu: Cadastros > Motivos de Entrega Fora do Raio](https://ajuda.sankhya.com.br/hc/article_attachments/44011369990935)

2. Selecionar a opção 'Novo':

![Imagem 2: 2. Selecionar a opção 'Novo':](https://ajuda.sankhya.com.br/hc/article_attachments/44011403152279)

3. Uma nova tela será aberta para o preenchimento das informações deste novo motivo:

![Imagem 3: 3. Uma nova tela será aberta para o preenchimento das informações deste novo motivo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011396633751)

- **Ativo:** Marcar a flag para ativar o motivo;
- **Descrição:** descrição do motivo;

4. Após preencher as informações, clicar em 'Salvar';

Caso tenha algum motivo cadastrado na tela Motivos de Entrega Fora do Raio, quando o motorista apontar uma entrega fora do raio do cliente, obrigatoriamente ele deverá escolher um motivo do porque isto ocorreu. No app, as opções serão mostardas assim:

![Imagem 4: Caso tenha algum motivo cadastrado na tela Motivos de Entrega Fora do Raio, quando o motorista apontar uma entrega fora…](https://ajuda.sankhya.com.br/hc/article_attachments/44011388357783)

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
