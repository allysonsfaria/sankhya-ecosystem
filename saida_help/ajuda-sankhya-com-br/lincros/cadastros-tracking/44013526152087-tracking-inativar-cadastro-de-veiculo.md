# [Tracking] - Inativar Cadastro de Veículo

**Menu:** Cadastros > Veículos

**Objetivo:** Como inativar cadastro de Veículo

## Considerações:

- Possui um cadastro de veículo para ser inativado

Abaixo segue os procedimentos, lembrando que:

- O sistema não permite a exclusão do cadastro de veículo;
- A orientação é**inativar** os cadastros de veículos, conforme exemplo abaixo:

1. Acessar o menu 'Cadastro', após selecionar a opção 'Veículos':

   ![Imagem 1: Acessar o menu 'Cadastro', após selecionar a opção 'Veículos':](https://ajuda.sankhya.com.br/hc/article_attachments/44013526300311)
2. É possível consultar os veículos, através das opções de Filtros:

   ![Imagem 2: É possível consultar os veículos, através das opções de Filtros:](https://ajuda.sankhya.com.br/hc/article_attachments/44013482551447)

   ![Imagem 3: É possível consultar os veículos, através das opções de Filtros:](https://ajuda.sankhya.com.br/hc/article_attachments/44013516242839)
3. Clicar na ícone 'Lápis', na primeira coluna, para editar este cadastro e desmarcar a opção "Ativo" e salvar:

   ![Imagem 4: Clicar na ícone 'Lápis', na primeira coluna, para editar este cadastro e desmarcar a opção "Ativo" e salvar:](https://ajuda.sankhya.com.br/hc/article_attachments/44013504933271)
4. Dessa forma o veículo não aparecerá mais no monitoramento.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
