# [Tracking] - Inativar Cadastro de Motorista

**Menu:** Cadastros > Motorista

**Objetivo:** Como inativar cadastro de Motorista

## Considerações:

- Possuir um cadastro de Motorista para ser inativado no sistema;

Abaixo segue os procedimentos, lembrando que:

- O sistema permite excluir o cadastro de motorista somente se o mesmo não estiver vinculado a nenhuma rota;
- Quando o motorista estiver vinculado a uma rota, a orientação é**inativar** os cadastros de veículos, conforme exemplo abaixo:

1. Acessar o menu 'Cadastro', após selecionar a opção 'Motorista':

   ![Interface gráfica do usuário, Texto, AplicativoDescrição gerada automaticamente](https://ajuda.sankhya.com.br/hc/article_attachments/44011312220951)
2. É possível consultar os motoristas, através das opções de Filtros:

   ![Interface gráfica do usuárioDescrição gerada automaticamente com confiança baixa](https://ajuda.sankhya.com.br/hc/article_attachments/44011324876823)

   ![DiagramaDescrição gerada automaticamente com confiança média](https://ajuda.sankhya.com.br/hc/article_attachments/44011330162327)
3. Clicar na ícone do 'Lápis', na primeira coluna, para editar este cadastro e desmarcar a opção "Ativo" e salvar:

   ![Interface gráfica do usuário, Aplicativo, TabelaDescrição gerada automaticamente](https://ajuda.sankhya.com.br/hc/article_attachments/44011362408983)
4. Dessa forma o motorista não aparecerá mais no monitoramento.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
