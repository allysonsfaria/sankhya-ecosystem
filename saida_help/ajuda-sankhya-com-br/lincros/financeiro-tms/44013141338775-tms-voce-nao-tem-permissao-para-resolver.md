# [TMS] - Você não tem permissão para resolver pendências do tipo

**Menu**: Financeiro > Faturas e Operacional > Atividades > Pendências

**Objetivo**: Entender o motivo do sistema apresentar essa mensagem e o que deverá ser feito para resolver a situação.

**Considerações**:

- Possuir pendências a serem resolvidas;

Em muitos casos onde é necessário resolver alguma pendência de uma fatura, por exemplo, o sistema poderá apresentar a mensagem de que o usuário não tem permissão para resolver pendências do tipo.

Na imagem abaixo é possível constatar uma das mensagens que o sistema pode apresentar, impedindo que a pendência seja resolvida: 'Você não tem permissão para resolver pendências do tipo Cálculo divergente (Fatura)'.

![Imagem 1: Em muitos casos onde é necessário resolver alguma pendência de uma fatura, por exemplo, o sistema poderá apresentar a…](https://ajuda.sankhya.com.br/hc/article_attachments/44013078738839)

Para resolver essa situação, basta realizar os procedimentos abaixo:

1. Acessar a opção de menu: Cadastros gerais > Configurações da empresa > Workflow > Permissões de resolução;
2. No campo 'Classificação' deverá ser escolhida permissão que apresentou mensagem ao tentar realizar a resolução. No exemplo da imagem acima, é Cálculo divergente (Fatura);
3. No quadro abaixo, deve-se selecionar os perfis que terão permissão para resolver aquele tipo de pendência. Na imagem abaixo, por exemplo, somente os perfis 'Gerencial' e 'Administrador' possuem a permissão para resolver a pendência 'Cálculo divergente (Fatura)';
4. Por fim, deve-se clicar em 'Salvar', e então o sistema deverá apresentar a mensagem 'Permissão de fechamento da pendência atualizada com sucesso';

![Imagem 2: Para resolver essa situação, basta realizar os procedimentos abaixo: 1. Acessar a opção de menu: Cadastros gerais >…](https://ajuda.sankhya.com.br/hc/article_attachments/44013113596055)

Tendo realizado os 4 passos mencionados acima, ao voltar na fatura e tentar resolver a pendência, o sistema não irá mais apresentará a mensagem de permissão.

Portanto, deve-se realizar os 4 passos mencionados acima sempre que for apresentada mensagens semelhantes, no caso, selecionando qual a pendência que será liberada para aquele perfil específico.
