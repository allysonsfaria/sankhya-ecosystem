**Menu**: Financeiro > Faturas

**Objetivo**:  Como consultar a situação das faturas seja por api ou via tela do sistema

**Considerações**:

- Possui faturas cadastradas/importadas no sistema;

Existe alguma porta na API (Web Services) que podemos consultar a situação das faturas, como por exemplo: Na chamada da api enviar o número da fatura e ela retornar a situação?
