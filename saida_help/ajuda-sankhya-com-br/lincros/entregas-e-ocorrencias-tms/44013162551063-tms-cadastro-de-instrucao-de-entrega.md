# [TMS] - Cadastro de Instrução de Entrega

**Menu:**Entregas e Ocorrências> Entregas> Instruções

**Objetivo:** A instrução de entrega pode ser cadastrada para que seja enviado um e-mail de forma automática para o responsável pela entrega da NF-e, com detalhes sobre a entrega que deve ser realizada, quando a NF-e recebe a informação de transporte iniciado.

## Preenchendo os campos da Instrução de Entrega

1. Clicar em “Novo” para realizar a criação de uma nova Instrução de Entrega

![Imagem 1: 1. Clicar em “Novo” para realizar a criação de uma nova Instrução de Entrega](https://ajuda.sankhya.com.br/hc/article_attachments/44013138410135)

**Instrução**: no campo "Instrução", preencher com o texto que deve ser enviado para o e-mail

**Ordem**: caso haja mais de uma instrução cadastrada para o mesmo destinatário, esse campo se trata da ordem que a instrução deve ser enviada

**Unidade**: caso necessário, informar a unidade da empresa responsável da Instrução. Determinando a unidade, somente será enviada essa instrução quando a NF-e também for desta unidade.

**Destinatário**: Informar o destinatário da NF-e correspondente a esta instrução. Determinando o destinatário, somente será enviada essa instrução quando a NF-e também for para este destinatário.

![Imagem 2: Destinatário : Informar o destinatário da NF-e correspondente a esta instrução. Determinando o destinatário, somente…](https://ajuda.sankhya.com.br/hc/article_attachments/44013154420375)

Se a flag "utilizar e-mail da transportadora do conhecimento de frete" caso campo "Instrução" for marcada, a instrução será enviada para todos os e-mails dos usuários cadastrados na plataforma da transportadora que consta no pré-conhecimento vinculado à NF-e correspondente.

![Imagem 3: Se a flag "utilizar e-mail da transportadora do conhecimento de frete" caso campo "Instrução" for marcada, a instrução…](https://ajuda.sankhya.com.br/hc/article_attachments/44013163004823)

**Transportadora**: informar, caso necessário, a transportadora responsável que receberá a instrução de entrega

**Filial**: informar especificamente a filial da transportadora, caso necessário

**E-mails**: informar os e-mails que irão receber essa instrução de entrega

**Produto:**informar produto específico para que essa instrução seja enviada somente quando a NF-e possua este produto.

**Modal:**informar o modal caso necessário especificar

![Imagem 4: Modal: informar o modal caso necessário especificar](https://ajuda.sankhya.com.br/hc/article_attachments/44013174279703)
