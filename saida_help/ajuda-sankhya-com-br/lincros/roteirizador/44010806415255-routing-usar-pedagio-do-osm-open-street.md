# [Routing] - Usar pedágio do OSM (Open Street Maps)

**Menu**: Roteirizador > Roteirizar > Iniciar uma nova sessão

**Objetivo**: Como configurar, e utilizar os pedágios do OSM (Open Street Maps)

**Considerações**:

- Para utilizar os pedágios do OSM é necessário habilitar o parâmetro no depósito;
- Com o parâmetro ativo, é disponibilizado na sessão os pontos de pedágios e respectivos valores para cada classificação de veículo;
- Com o parâmetro ativado, as rotas utilizam o custo do pedágio no custo da rota;
- Na sessão só será mostrado o pedágio, onde houver setor cadastrado.

Orientações para utilizar os pedágios:

1. Habilitar o parâmetro "Usar pedágio do OSM" em: Roteirizador > Cadastros > Depósitos > Parâmetros de geolocalização (ADMIN) (Esse parâmetro é ativado pelo time de Help Desk - Lincros somente);
2. Para a correta utilização do pedágio, é preciso vincular no tipo de veículo a "Classificação do veículo (Utilizar para base de cálculo em pedágios)", para cadastrar ou editar o tipo de veículo [Clique aqui](https://sankhya.zendesk.com/hc/pt-br/articles/44010671611287). As opções de classificação são:

- Sem classificação (nesse caso, o valor do pedágio é de R$0,00);
- Carro;
- Caminhão;
- Moto.

Habilitando o parâmetro, e configurando o tipo de veículo corretamente, ao gerar uma sessão (em caso de dúvidas de como criar uma sessão, temos os artigos: [[Routing] - Iniciar uma nova sessão de roteirização](https://intercom.help/ajudalincros/pt-BR/articles/13439446-routing-iniciar-uma-nova-sessao-de-roteirizacao), [[Routing] - Iniciar sessão com rotas automáticas](https://sankhya.zendesk.com/hc/pt-br/articles/44010806415255)), será apresentado em tela os pedágios nos setores, representado pelo ícone:
