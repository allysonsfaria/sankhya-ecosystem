# [Routing] – Agrupamento de pedidos na Sessão

**Menu**: Roteirizador > Roteirizar> Iniciar uma nova sessão de roteirização

**Objetivo**: Como agrupar pedidos para um mesmo cliente

**Considerações**:

- Possuir pedidos importados;
- Os pedidos serem para o mesmo cliente de destino;
- O endereço de entrega precisa ser o mesmo;
- O tipo de documento (na área de filtro de pedido) sempre marcar a flag: Todos (Nota Fiscal e Pré Nota Fiscal);
- A funcionalidade de agrupar / desagrupar pedidos na sessão necessita de configuração. Para configurar, o acesso é: Cadastro> Estratégia de roteirização> Geral> Agrupar todos os pedidos do mesmo cliente em uma única atividade.

## Tela de início de nova sessão de roteirização

1. Iniciar nova sessão de roteirização;
2. Selecionar o depósito;
3. Selecionar a data do pedido;

**Obs**.: Se souber os números dos pedidos, pode ser informado no campo “números dos pedidos” conforme imagem abaixo:

![Imagem 1: Obs .: Se souber os números dos pedidos, pode ser informado no campo “números dos pedidos” conforme imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44012397605527)

4. Clicar em 'Confirmar';

5. Abrirá a tela de sessão roteirizada, automaticamente irá agrupar, mas clicando no ícone pode ser feito o desagrupamento de pedidos e vice-versa;

![Imagem 2: 5. Abrirá a tela de sessão roteirizada, automaticamente irá agrupar, mas clicando no ícone pode ser feito o…](https://ajuda.sankhya.com.br/hc/article_attachments/44012389419927)

**Obs**: O depósito precisa estar parametrizado para o agrupamento ser feito ao iniciar a sessão com os dois ou mais pedidos para o mesmo cliente e endereço. Abaixo as flags que devem estar devidamente preenchidas:

![Imagem 4: Obs : O depósito precisa estar parametrizado para o agrupamento ser feito ao iniciar a sessão com os dois ou mais…](https://ajuda.sankhya.com.br/hc/article_attachments/44012417538583)

Se houver mais de um pedido para o mesmo cliente com endereços diferentes, não será possível agrupar.
