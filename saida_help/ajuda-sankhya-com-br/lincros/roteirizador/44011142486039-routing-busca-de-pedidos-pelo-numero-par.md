# [Routing] - Busca de pedidos pelo número para iniciar uma roteirização

**Menu:** Roteirizador > Entregas

**Objetivo**: Como informar determinados pedidos de uma importação para iniciar uma sessão

## Considerações:

- Ter pedidos importados;

Para realizar a busca de pedidos pelo número para iniciar uma roteirização, segue abaixo os procedimentos:

## Tela de início de sessão

1. Realizar a parametrização para iniciar a sessão;
2. No campo Filtro Padrão, buscar os pedidos de acordo com a necessidade de busca por 'tipo de cliente' ou por 'data de pedido';
3. No campo 'Números de pedidos', informar quais os pedidos necessários para iniciar uma sessão. Os números dos pedidos podem ser informados utilizando o separador 'Vírgula' ou 'Enter';
4. Com essas informações, será disponibilizado apenas os números que foram informados nos filtros acima;

![Imagem 1: Com essas informações, será disponibilizado apenas os números que foram informados nos filtros acima;](https://ajuda.sankhya.com.br/hc/article_attachments/44011108114967)
