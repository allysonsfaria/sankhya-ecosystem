# [Routing] - Criando uma sessão para pedido com situação 'Roteirizado'

**Menu**: Não se aplica

**Objetivo**: Roteirizar o pedido já roteirizado e com a sessão bloqueada

**Considerações**:

- Não é necessário desbloquear a sessão original para criar uma sessão nova para o pedido;
- Ao criar uma segunda sessão, o referido pedido terá dois registros de sessão de roteirização no Routing, ou seja, não é eliminado o histórico;

Abaixo segue os procedimentos:

1. Acessar o menu: Roteirizador > Pedidos;
2. Informar os dados para filtrar os pedidos já roteirizados:

          a) Informar o depósito;

          b) Informar a data da importação dos pedidos;

          c) Informar o número dos pedidos (opcional);

          d) Informar os clientes (opcional);

          e) Filtrar;

3. Assim, o sistema retornará com os pedidos conforme os filtros aplicados;

![Imagem 1: 3. Assim, o sistema retornará com os pedidos conforme os filtros aplicados;](https://ajuda.sankhya.com.br/hc/article_attachments/44012455253271)

4. Todos os pedidos que serão atribuídos a uma nova sessão devem ser selecionados nesta tela, e posteriormente clicar no botão 'Marcar não roteirizado';

![Imagem 2: 4. Todos os pedidos que serão atribuídos a uma nova sessão devem ser selecionados nesta tela, e posteriormente clicar…](https://ajuda.sankhya.com.br/hc/article_attachments/44012455406999)

5. Os pedidos devem ficar conforme a imagem abaixo. Assim estarão disponíveis para uma nova sessão:

![Imagem 3: 5. Os pedidos devem ficar conforme a imagem abaixo. Assim estarão disponíveis para uma nova sessão:](https://ajuda.sankhya.com.br/hc/article_attachments/44012455527319)
