# [Routing] - Informações divergentes na Tela "Iniciar uma nova sessão de Roteirização" Cubagem e Peso

**Menu:** Roteirizador > Roteirizar > Iniciar uma nova sessão

**Objetivo:** Esse artigo tem como finalidade, configurar o navegador para as informações aparecerem completas no Routing.

## Considerações:

- Possuir acesso ao Routing;

Algumas configurações de navegador podem afetar a visualização de informações na tela do Routing, conforme exemplo abaixo:

Instruções para configuração do navegador:

1. Se certificar que está sendo usado o navegador Chrome, pois esse é o navegador correto para utilização do Routing;
2. Verificar se o navegador está atualizado [[Diversos] - Atualizar navegador Chrome](https://sankhya.zendesk.com/hc/pt-br/articles/44010810762519);
3. Fazer a limpeza de cache [[Diversos] - Como realizar a limpeza de cache do navegador](https://sankhya.zendesk.com/hc/pt-br/articles/44010810762519);
4. Fazer a limpeza de cookies [[Diversos] - Como realizar a limpeza de cookies do navegador](https://sankhya.zendesk.com/hc/pt-br/articles/44010810762519);
5. Verificar se o idioma do navegador está configurado de acordo [[Diversos] - Configurar o idioma do navegador](https://sankhya.zendesk.com/hc/pt-br/articles/44010810762519);
6. Após isso, dar um CTRL F5 para atualizar a página.

O programa apresentará as informações de Cubagem e Peso (essas informações ficam na parte inferior da tela, antes de confirmar a rota) na tela de Iniciar uma nova sessão de Roteirização.
