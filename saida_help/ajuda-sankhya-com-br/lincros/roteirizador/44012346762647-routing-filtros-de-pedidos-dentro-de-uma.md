# [Routing] - Filtros de pedidos dentro de uma sessão

**Menu**: A tela é apresentada após iniciar uma sessão

**Objetivo**: Identificar os pedidos que estão roteirizados e não roteirizados

## Considerações:

- É necessário ter uma sessão criada;

Segue abaixo o passo a passo:

- Campos do Filtro

![Imagem 1: - Campos do Filtro](https://ajuda.sankhya.com.br/hc/article_attachments/44012374311319)

1. **Botão Exibir Filtros**:  Ao clicar no botão, será exibida uma nova tela, onde é possível buscar os pedidos dentre uma faixa de peso;

   ![Imagem 2: Botão Exibir Filtros : Ao clicar no botão, será exibida uma nova tela, onde é possível buscar os pedidos dentre uma…](https://ajuda.sankhya.com.br/hc/article_attachments/44012374418967)
2. **Utilizando a tecla de atalho do teclado CTRL + F:** Será exibido uma caixa de texto onde é possível buscar os pedido, pelo número do pedido, código do cliente ou nome do cliente;

   ![Imagem 3: Utilizando a tecla de atalho do teclado CTRL + F: Será exibido uma caixa de texto onde é possível buscar os pedido,…](https://ajuda.sankhya.com.br/hc/article_attachments/44012347221015)
3. **Campo de atividade Roteirizadas / Atividades**: No campo de atividades não Roteirizadas/Atividades é possível identificar todos os pedidos e ordena-los por ordem crescente e decrescente.  No campo atividades vão apresentar todos os pedidos dentro de um rota;

   ![Imagem 4: Campo de atividade Roteirizadas / Atividades : No campo de atividades não Roteirizadas/Atividades é possível…](https://ajuda.sankhya.com.br/hc/article_attachments/44012361125527)

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
