# [Routing] - Retroalimentação

**Menu**: Retroalimentação

**Objetivo**: Como apresentar as informações de coordenadas e tempo de Espera

**Considerações**:

- Esta opção é quando utilizado a integração entre o Tracking X Router;
- É necessário ter os campos abaixo já cadastrados no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

**Menu**: Retroalimentação > Coordenadas

- É atualizada as informações da base de clientes cadastrados considerando as coordenadas do motorista;
- Esta tela serve para aprovar ou reprovar a alteração;

Para a consulta de coordenadas é necessário informar os seguintes campos:

1. **Depósito**: Selecione o depósito em questão;
2. **Situação**: Selecione uma das opções: Pendente, Reprovada, Aprovada;
3. **Tipo**: Selecione uma das opções: Todos, Gestão de Entregas, ERP;
4. **De**: Informe uma data inicial para a coordenada;
5. **Até**: Informe uma data final para a coordenada;
6. Após clique em 'Filtrar';
7. Abaixo serão apresentadas as informações, onde você pode selecionar a coordenada e 'Aprovar' ou 'Reprovar';
8. Se preferir também é possível exportar estas informações;

**Menu**: Retroalimentação > Tempo de Espera

- É atualizada as informações da base de clientes cadastrados considerando os apontamentos do motorista;
- Esta tela serve para aprovar ou reprovar a alteração;

Para a consulta de tempo de espera é necessário informar os seguintes campos:

1. **Depósito**: Selecione o depósito em questão;
2. **Situação**: Selecione uma das opções: Pendente, Reprovada, Aprovada;
3. **De**: Informe uma data inicial para o tempo de espera;
4. **Até**: Informe uma data final para o tempo de espera;
5. Após clique em 'Filtrar';
6. Abaixo serão apresentadas as informações, onde você pode selecionar a coordenada e 'Aprovar' ou 'Reprovar';
7. Se preferir também é possível exportar estas informações;
