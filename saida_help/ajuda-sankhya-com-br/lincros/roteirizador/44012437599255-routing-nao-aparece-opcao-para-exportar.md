# [Routing] - Não aparece opção para exportar sessão para o Tracking

**Menu**: Roteirizador > Roteirizar > Iniciar uma nova sessão de roteirização > Exportar sessão

**Objetivo**: Entender como corrigir caso não esteja aparecendo a opção de exportar a sessão para o Tracking

**Considerações:**
           - Possuir pedidos para serem roteirizados;
           - Ter a necessidade de exportar os pedidos para o tracking;

Caso na exportação de rotas do routing não apareça a opção de exportar para o Tracking, conforme imagem abaixo:

![Imagem 1: Menu : Roteirizador > Roteirizar > Iniciar uma nova sessão de roteirização > Exportar sessão Objetivo : Entender como…](https://ajuda.sankhya.com.br/hc/article_attachments/44012454693399)

Então deverá ser verificado em: Cadastro > Depósitos se a opção "Tracking rota completa web service" está definida no campo "Categoria".

Caso não esteja, basta selecioná-la e então será possível a exportação de rotas para o tracking.

![Imagem 2: Caso não esteja, basta selecioná-la e então será possível a exportação de rotas para o tracking.](https://ajuda.sankhya.com.br/hc/article_attachments/44012454840215)

Feito isso, então será apresentada a opção de exportar as rotas para o Tracking.

![Imagem 3: Feito isso, então será apresentada a opção de exportar as rotas para o Tracking.](https://ajuda.sankhya.com.br/hc/article_attachments/44012416400663)
