# [Routing] - Iniciar sessão com rotas automáticas

**Menu**: Roteirizador > Roteirizar> Iniciar uma nova sessão de roteirização

**Objetivo**: Como iniciar uma sessão com rota automática

**Considerações**:

- Possuir  pedidos importados;
- Utilizando o filtro padrão, não o filtro por importação (na sessão de pedidos);
- Filtre os pedidos: é necessário informar ao menos um filtro;
- Utilizar pelo menos um veículo no filtro;

## Tela de início de nova sessão de roteirização

1. Acessar a tela inicial do Roteirizador
2. Acessar a opção Roteirizador (comando 1 na figura), e em seguida Roteirizar (comando 2 na figura);

   ![Imagem 1: Acessar a opção Roteirizador (comando 1 na figura), e em seguida Roteirizar (comando 2 na figura);](https://ajuda.sankhya.com.br/hc/article_attachments/44012411433111)
3. Ao clicar no Roteirizador, você será direcionado ao ambiente abaixo, lá, deve ser selecionado a opção “Iniciar uma nova sessão de roteirização”;

   ![Imagem 2: Ao clicar no Roteirizador, você será direcionado ao ambiente abaixo, lá, deve ser selecionado a opção “Iniciar uma nova…](https://ajuda.sankhya.com.br/hc/article_attachments/44012398805655)
4. Você será direcionado para uma janela onde alguns filtros deverão ser feitos para o correto processo de roteirização;
5. Alguns campos serão obrigatórios, outros não, os não obrigatórios, estará informado no filtro:

   ![Imagem 3: Alguns campos serão obrigatórios, outros não, os não obrigatórios, estará informado no filtro:](https://ajuda.sankhya.com.br/hc/article_attachments/44012411833111)
6. Campos para preenchimento obrigatório e não obrigatório, abaixo os mesmos estão enumerados de acordo com a ordem em que aparecerão na janela de filtro:

| Obrigatório | Não obrigatório |
| --- | --- |
| - 01. Deposito: Sem esse filtro, não é possível seguir a diante; | - 03. Selecione as unidades para roteirização; |
| - 02. Selecione a data para a execução da roteirização: | - 04. Selecione os setores; |
| - 09. Data do pedido (inicial e final); | - 05. Selecione os Veículos (se não for selecionado o veículo, não será criado a rota automático pelo sistema, porém é possível criar uma sessão, sem a seleção de veículos, ou seja, não será criado as rotas automáticas, as rotas precisarão ser criadas manualmente posterior); |
| - 10. Tipo de documento: sempre colocar a opção Todos (Nota Fiscal e Pré Nota Fiscal); | - 06. Selecione os tipos de produtos; |
|  | - 07. Selecione os marcadores; |
|  | - 08. Selecione os Tipos de Cliente; |

![Imagem 10: 7. Após aplicar os filtros necessários, aparecerá os pedidos para roteirizar:](https://ajuda.sankhya.com.br/hc/article_attachments/44012405611927)

![Imagem 11: 8. Após marcar as flags dos pedidos a roteirizar é só confirmar, e será criado a sessão de roteirização dos pedidos:](https://ajuda.sankhya.com.br/hc/article_attachments/44012405828119)
