# [Routing] - Iniciar uma nova sessão de roteirização

**Menu:** Roteirizador > Roteirizar

**Objetivo:** Iniciar uma nova sessão de roteirização

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router para iniciar uma sessão de roteirização:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para iniciar uma nova sessão de roteirização é necessário informar os seguintes campos:

1. **Depósito**: Selecione o depósito desejado;
2. **Data**: Informe a data para a roteirização;
3. **Estratégia de Roteirização**: Selecione a estratégia desejada (opcional);
4. **Veículos**: Selecione os veículos para a sessão;
5. Após configurar, clique em **'Roteirizar'** para iniciar.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
