# [Tracking] - Como realizar um apontamento manual pelo monitoramento

**Menu**: Monitoramento > Mapa Sinótico

**Objetivo**: Instruir o usuário de como alterar um apontamento de entrega realizado erroneamente ou simplesmente realizar um apontamento de entrega ou devolução via monitoramento.

**Considerações**:

- Possuir um perfil de usuário com permissão para alteração de status da entrega, caso não saiba como cadastrar o perfil, verifique o artigo [Criar perfil de usuário para apontamento de entrega manual](https://sankhya.zendesk.com/hc/pt-br/articles/44010713899799);
- Para utilizar essa funcionalidade, deve-se criar um perfil que habilite essa funcionalidade ou ser usuário administrador.
- Funcionalidade disponível a partir da versão web 4.25;

Na tela de monitoramento, será possível realizar um apontamento de entrega ou devolução manualmente e importar uma foto de canhoto. O usuário que possuir o perfil com permissão de apontamento de entrega manual poderá fazer essa edição via tela.

1. Na tela do monitoramento, pegamos um exemplo de devolução apontada pelo motorista via APP, porém, vamos corrigir esse apontamento para entrega realizada, clique na bolinha vermelha, referente a entrega que foi devolvida erroneamente;

5. Após clicar em enviar, o usuário poderá consultar na tela do monitoramento que alterou de devolução para entrega realizada;

**Obs**.: Caso for uma entrega, o sistema irá deixar as coordenadas do apontamento iguais ao do PDV.

6. Como o usuário poderá verificar se a entrega foi apontamento manual? Clicando na aba de ocorrências. A última linha terá a informação que foi apontada de forma manual e que realizou o apontamento via monitoramento;

Caso o cliente realize tratamento de devoluções pelo painel de tratativas de devoluções, é importante informar que ao realizar apontamento manual, esse apontamento não ficará disponível no painel de tratativas para que seja tratado, pois o apontamento manual já confirma a devolução de forma automática.

No monitoramento, será registrada devolução na aba de ocorrências dessa forma:

![Imagem 8: No monitoramento, será registrada devolução na aba de ocorrências dessa forma:](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963296794/15491c841060c9207a64d2ac71f2/31B270DDC923193B526788384DD9BD41?expires=1791331200&signature=1602e887174d03b9ec51ff2c2bdac9b5975e4e4ce6d3f63118c6fff4d402dbb5&req=dSkhFct3m4ZWXfMW3nq%2BgcMKCUDcJ5d1yvrdi5VvJov8NwbEe15o2Y6jYtkG%0AsUKoEpiU4OwF6HiyWMV9%2Fn%2FeuLg%3D%0A)

Todos os apontamentos manuais serão exibidos no sinótico como apontamento dentro do raio.
