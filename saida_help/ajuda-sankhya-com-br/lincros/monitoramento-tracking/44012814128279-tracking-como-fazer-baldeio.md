# [Tracking] - Como fazer baldeio

**Menu**: Gestão de entregas > Campo do mapa sinótico > Baldeio

**Objetivo:** Como realizar um baldeio de forma correta

**Considerações**:

- O propósito do baldeio é transferência de uma entrega para outro veículo/viagem;
- Entende-se por entregas pendentes, entregas não realizadas ou devoluções;

Abaixo segue os procedimentos necessários:

1. Para realizar o baldeio da carga, basta localizar no mapa sinótico a placa que deseja baldear a carga, após clicar sobre a placa e clicar na opção baldeio;

   ![Imagem 1: Para realizar o baldeio da carga, basta localizar no mapa sinótico a placa que deseja baldear a carga, após clicar…](https://ajuda.sankhya.com.br/hc/article_attachments/44012797776919)

   ![Imagem 2: Para realizar o baldeio da carga, basta localizar no mapa sinótico a placa que deseja baldear a carga, após clicar…](https://ajuda.sankhya.com.br/hc/article_attachments/44012792977175)
2. Após esse processo, uma tela com as entregas pendentes será exibida;
3. Basta informar a placa na coluna 'Veículo destino' para onde você deseja baldear a carga;

   ![Imagem 3: Basta informar a placa na coluna 'Veículo destino' para onde você deseja baldear a carga;](https://ajuda.sankhya.com.br/hc/article_attachments/44012811571351)
4. Para concluir o baldeio clique em 'Enviar baldeio';
5. Após realizar este procedimento as entregas sairão da rota de origem e serão exibidas na rota destino;
6. Para consultar qualquer alteração de baldeio, o usuário pode acessar o relatório de "Baldeios realizados", filtrar pelas informações pertinentes e extrair o relatório.

   ![Imagem 4: Para consultar qualquer alteração de baldeio, o usuário pode acessar o relatório de "Baldeios realizados", filtrar…](https://ajuda.sankhya.com.br/hc/article_attachments/44012825363863)
7. Ao extrair este relatório, o usuário poderá verificar que este documento é um excelente suporte com vários registros pertinentes a operação;
8. Cabe ao usuário estudar a melhor forma de aproveitar as informações exibidas.
