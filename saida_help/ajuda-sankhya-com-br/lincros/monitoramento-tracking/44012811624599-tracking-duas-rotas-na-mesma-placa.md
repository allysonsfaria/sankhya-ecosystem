# [Tracking] - Duas rotas na mesma placa

**Menu**: Gestão de Entregas > Monitoramento

**Objetivo**: Compreender como funcionam duas ou mais rotas integradas para a mesma placa.

**Considerações**:

- O usuário pode integrar várias viagens para a mesma placa.
- Só é possível iniciar uma rota por vez.

Abaixo segue os procedimentos:

1. Acessar o menu: Gestão de Entregas > Monitoramento;
2. Conforme evidência abaixo, se uma rota está em andamento, o motorista só irá conseguir iniciar a segunda rota finalizando a primeira;

   ![Imagem 1: Conforme evidência abaixo, se uma rota está em andamento, o motorista só irá conseguir iniciar a segunda rota…](https://ajuda.sankhya.com.br/hc/article_attachments/44012822066199)
3. Basta acessar o menu de monitoramento.

   ![Imagem 2: Basta acessar o menu de monitoramento.](https://ajuda.sankhya.com.br/hc/article_attachments/44012811900183)
4. Ao finalizar uma das rotas, a outra já ficará disponível para que seja iniciada pelo usuário do smartphone.
