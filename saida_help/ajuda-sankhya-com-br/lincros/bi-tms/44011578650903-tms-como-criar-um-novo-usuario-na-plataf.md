# [TMS] - Como Criar um Novo Usuário na Plataforma de BI (Analytics)

**1 - Problema Relatado pelo Cliente:**
O cliente solicitou a criação de um novo usuário na plataforma de BI (Business Intelligence) Analytics, mencionando a necessidade de acesso para um novo colaborador. Link: <https://analytics.lincros.com/>

![Imagem 1: 1 - Problema Relatado pelo Cliente: O cliente solicitou a criação de um novo usuário na plataforma de BI (Business…](https://ajuda.sankhya.com.br/hc/article_attachments/44011565850903)

## 2 - Passo a Passo para Resolver o Problema:

1. ## Solicite o e-mail do novo usuário:

   - Para criar o usuário, é necessário um endereço de e-mail válido.
   - Abra um chamado com o suporte técnico da Lincros e informe o e-mail.
2. ## Oriente o novo usuário sobre o primeiro acesso:

   - O suporte entrará em contato com o setor responsável para dar continuidade à criação do usuário solicitado.
   - Assim que o usuário for criado pelo time responsável, o sistema enviará automaticamente um e-mail para o endereço informado.
   - Esse e-mail conterá instruções para criação de senha e ativação da conta.
   - Peça que o novo usuário verifique a caixa de entrada e o spam/lixo eletrônico.
3. ## Valide o acesso:

   - Após a criação da senha, o usuário poderá acessar normalmente a plataforma.
   - Caso ocorra qualquer erro no acesso inicial, revise o e-mail cadastrado ou entre em contato com o suporte técnico.
