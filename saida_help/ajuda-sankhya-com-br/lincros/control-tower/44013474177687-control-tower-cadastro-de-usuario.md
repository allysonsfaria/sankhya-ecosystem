# [Control Tower] - Cadastro de Usuário

**Menu**: Cadastro > Usuários

**Objetivo**: O processo de criação de usuário no Control Tower tem como objetivo permitir acesso aos usuários.

**Considerações**:

- É necessário que o usuário o qual realizará o processo de criação de usuário tenha acesso com perfil de administrador;

Abaixo segue os procedimentos:

1. Na tela inicial, ao clicar na aba 'Cadastros' será apresentada todas as opções de cadastro, entre elas a opção Usuários, conforme imagem abaixo:

   ![Imagem 1: Na tela inicial, ao clicar na aba 'Cadastros' será apresentada todas as opções de cadastro, entre elas a opção…](https://ajuda.sankhya.com.br/hc/article_attachments/44013511138967)
2. Sendo assim, será apresentado a área de cadastro;

   ![Imagem 2: Sendo assim, será apresentado a área de cadastro;](https://ajuda.sankhya.com.br/hc/article_attachments/44013502963351)

- Selecione um usuário: deve conter o nome do usuário usuário o qual terá acesso ao perfil
- Tipo de usuário: Perfil pré definido que o usuário irá utilizar
- Nome completo: Nome completo do usuário em questão
- E-mail: E-mail do usuário que terá acesso ao perfil criado no control tower

3. Ao clicar na opção 'Salvar' o usuário terá acesso aos campos de cadastro de senha;

![Imagem 3: 3. Ao clicar na opção 'Salvar' o usuário terá acesso aos campos de cadastro de senha;](https://ajuda.sankhya.com.br/hc/article_attachments/44013503102487)

4. Ao clicar em criar usuário o cadastro terá sido concluído;

![Imagem 4: 4. Ao clicar em criar usuário o cadastro terá sido concluído;](https://ajuda.sankhya.com.br/hc/article_attachments/44013525167767)

**Importante**: Somente usuários administradores terão permissão para cadastramento de outros usuários e em outros casos deve ser solicitado o cadastramento para o Suporte da Lincros.

  "Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
