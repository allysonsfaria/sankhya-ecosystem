# [Control tower] - Sub-Paradas

**Menu**: Sub-Paradas

**Objetivo**: Este documento tem por objetivo de instruir a como criar Sub-Parada no Control Tower.

**Considerações**:

- A partir da versão 1.6.0 do Lincros Control Tower, é possível criar áreas internas de um determinado ponto de parada;
- Essa área interna é denominada no CT como “Sub-Parada”;

Abaixo segue os procedimentos:

Para cadastrá-la, as seguintes premissas são necessárias:

- O ponto de parada principal deve possuir uma área cadastrada;
- A área da sub-parada deve estar contida na área do ponto de parada principal;

1. Acesse o módulo “Sub-Paradas”;
2. Informe o código ou nome do ponto de parada;
3. Clique em “Nova Sub-Parada” e preencha as informações. É importante ressaltar que o campo “Componente” determina o agrupamento das entradas e saídas de uma Sub-Parada;
4. Desenhe a área clicando no mapa com o botão esquerdo do mouse;
5. Clique com o botão direito do mouse para finalizar a edição da área;
6. Clique com o botão esquerdo do mouse dentro da área que você criou para criar um PIN com as coordenadas daquele componente;
7. Clique em “Salvar” para concluir a criação da Sub-Parada;

![Imagem 1: Clique em “Salvar” para concluir a criação da Sub-Parada;](https://ajuda.sankhya.com.br/hc/article_attachments/44011292673431)

Para consultar as Sub-Paradas de um determinado ponto de parada, basta navegar pelo campo “Selecione uma sub-parada”.

## Como funciona?

Uma vez que as Sub-Paradas estejam devidamente cadastradas, todas as posições que forem associadas terão um atributo além do tempo de pátio, sendo retroalimentado.

Para consultar os tempos dos veículos dentro das Sub-Paradas, na modal “Informações”, acesse o módulo “Áreas”. As entradas e saídas são agrupas por “Componente”.
