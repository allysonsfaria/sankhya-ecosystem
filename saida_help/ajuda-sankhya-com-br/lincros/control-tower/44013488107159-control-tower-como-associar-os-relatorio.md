# [Control Tower] - Como associar os relatórios a um Grupo de Usuário

**Menu**: Cadastros > Grupos de Usuários

**Objetivo**: A partir da versão 1.8 do Lincros Control Tower, os usuários precisam ter a visibilidade dos relatórios reconfigurada;

Abaixo segue os procedimentos:

1. Acesse o módulo “Cadastros”;
2. Clique em “Grupos de Usuários”;
3. Selecione o grupo que você deseja liberar os relatórios;
4. Clique em “Funcionalidades”;
5. Marque como ativo, os relatórios desejados;
6. Clique em “Salvar”.
