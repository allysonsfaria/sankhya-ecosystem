# [TMS] – Solicitação de liberação ao usuário de transportadora para acessar o aplicativo transpoFrete

**Menu**: Sistema > Acesso > Usuário > Usuários de transportadora

**Objetivo**: Solicitar liberação de acesso ao aplicativo TranspoFrete ao usuário de transportadora

**Considerações**:

- Necessário que o usuário de transportadora esteja cadastrado e autorizado o acesso à empresa;
- Necessário que o cliente tenha o módulo contratado;

Abaixo segue os procedimentos:

1. Acessar menu: Sistema > Acesso > Usuário > Usuários de transportadora;
2. Localizar  pelo usuário desejado;
3. Tomar nota “código” e “e-mail”;
4. Enviar  e-mail para  'atendimento@lincros.com' a solicitação de liberação de acesso ao aplicativo, informando o “código” e “e-mail” do usuário desejado, conforme o item '3' citado acima;
5. Aguardar o retorno de conclusão pelo suporte;

"Em atenção ao comprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
