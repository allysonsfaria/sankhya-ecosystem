# [TMS] - Como configurar para não serem enviados os e-mails informativos (E-mails de autorização de frete complementar)

**Menu**: Não se aplica

**Objetivo**: Como configurar para não serem enviados os e-mails informativos como, por exemplo: E-mails de autorização de frete complementar para alguns usuários

**Considerações**:

- Possuir perfil de 'Administrador' liberado no cadastro do usuário da empresa;

Abaixo segue os procedimentos:

Como o 'perfil' de usuário de empresa é 'Administrador', realmente vai acabar recebendo esses e-mails informativos, pois o perfil em questão participa destes processos nativamente no TMS;

Neste caso, sugerimos para que o cliente crie um novo 'perfil' ou adicione o usuário em questão em um outro perfil já existente no usuário de empresa.
