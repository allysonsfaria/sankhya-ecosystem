# [TMS] - Liberação de Acesso para Usuário de Transportadora

1 -**Problema Relatado pelo Cliente:**

O cliente solicitou a verificação e liberação de acesso para um novo usuário de transportadora 'Usuário X'. A transportadora desse novo usuário não estava vinculada à empresa/cliente, e isso impediu que o novo usuário seguisse com o processo de solicitar autorização de acesso para o o cliente aprovar.

2 - **Passo a Passo para Resolver o Problema:**

Passo 1: **Vinculação da Transportadora à Empresa**

Responsabilidade da equipe de Suporte do TMS, verificar se a transportadora mencionada está vinculada à empresa correta no sistema. Para isto o usuário do Suporte deve seguir para a tela Cadastros gerais > Transportadoras > Transportadora (empresa) > Cadastro em seguida verificar se a transportadora consta nas Transportadoras apresentadas.

Caso a transportadora não esteja vinculada, na tela de Cadastros gerais > Transportadoras > Transportadora (empresa) > Selecione a opção 'Vincular' no canto superior direito da tela > em seguida localizei a transportadora, selecione a transportadora e utilize a opção OK para vincular.

Passo 2: **Solicitação de Acesso pelo Usuário da Transportadora**

Solicite que o usuário da transportadora acesse o sistema.

O usuário deve navegar até a tela: Sistema > Autorização de acesso por empresas.

Na tela, o usuário deve clicar em 'Solicitar autorização'.

O usuário precisa informar a empresa desejada para solicitar a autorização e fornecer a justificativa para o pedido de acesso.

Após inserir as informações necessárias, o usuário deve clicar em 'Solicitar acesso'.

Passo 3: **Aprovação ou Rejeição da Solicitação de Acesso**

O usuário da empresa a qual foi solicitado o acesso deve acessar a tela: Sistema > Acesso > Usuário > Autorização de acesso para transportadoras.

O usuário da empresa deve localizar a requisição do 'Usuário X' na lista de solicitações pendentes.

O usuário da empresa deve então selecionar a solicitação e decidir se aprova ou rejeita o pedido de acesso.
