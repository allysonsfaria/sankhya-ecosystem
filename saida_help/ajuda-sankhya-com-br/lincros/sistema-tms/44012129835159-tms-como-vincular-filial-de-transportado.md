# [TMS] - Como Vincular Filial de Transportadora a um usuário da transportadora

## 1 - Problema Relatado pelo Cliente

O cliente solicitou a vinculação de uma filial de transportadora a um usuário específico da transportadora no sistema. O problema se refere à necessidade de garantir que o usuário tenha acesso à filial para poder realizar suas operações de forma correta.

---

## 2 - Passo a Passo para Resolver o Problema

**Passo 1:**
Acesse o menu de administração do sistema, localizado em **"Sistema > Acesso > Usuário > Usuários de Transportadora"**.

**Passo 2:**
Na tela de **"Usuários de Transportadora"**, clique no código do usuário que você deseja vincular à filial. Isso abrirá a tela de **"Edição de Usuário Transportador"**.

**Passo 3:**
Na tela de edição, desça até a seção **"Filiais"**, localizada na parte inferior da tela. Selecione a filial que você deseja vincular ao usuário.

**Passo 4:**
Clique na opção **"ADD"** para adicionar a filial selecionada ao usuário.

![Imagem 1: Passo 4: Clique na opção "ADD" para adicionar a filial selecionada ao usuário.](https://ajuda.sankhya.com.br/hc/article_attachments/44012164187031)

**Passo 5:**
Após selecionar a filial, clique em **"Salvar"**, localizado no canto superior da tela, para confirmar a alteração.

**OBSERVAÇÃO**: Caso deseje vincular múltiplas filiais ao usuário de uma vez, mantenha pressionada a tecla **"CTRL"** do teclado enquanto seleciona as filiais desejadas. Depois, clique em **"Add"** e em **"Salvar"** para concluir o processo.

                           Se você desejar vincular todas as filiais de uma única vez, basta selecionar a opção **"Add All"** e, em seguida, clicar em **"Salvar"** para concluir a ação:

![Imagem 2: Se você desejar vincular todas as filiais de uma única vez, basta selecionar a opção "Add All" e, em seguida, clicar em…](https://ajuda.sankhya.com.br/hc/article_attachments/44012148428951)

Com esses passos, o usuário terá acesso à(s) filial(is) associada(s) e poderá realizar as operações necessárias dentro do sistema.
