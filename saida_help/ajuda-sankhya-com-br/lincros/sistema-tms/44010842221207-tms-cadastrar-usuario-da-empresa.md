# [TMS] - Cadastrar Usuário da  Empresa

**Menu**: Sistema > Acesso > Usuário > Usuários da empresa

**Objetivo**: Como cadastrar usuário da empresa;

## Considerações:

- Somente Usuário com perfil de Administrador consegue realizar este cadastro;
- Ter realizado o [Cadastro de Pessoa](https://sankhya.zendesk.com/hc/pt-br/articles/44010842221207), para posteriormente vincular a pessoa no cadastro do usuário;

Abaixo segue os procedimentos de como realizar o cadastro do usuário (empresa):

1. Acessar o menu: Sistema > Acesso > Usuário > Usuários da empresa;
2. Clicar na opção 'Novo';
3. Preencher os campos obrigatórios (marcados com asterisco), como, por exemplo: pessoal, e-mail, login;
4. Adicionar ao menos um perfil à este usuário;
5. Adicionar uma 'Unidade' se necessário. Se não for selecionado uma ou mais unidades o usuário terá acesso a informações de todas as unidades existentes, até mesmo as futuras que serão cadastradas no sistema;
6. Clicar em 'Salvar';
7. Acessar o e-mail de 'Confirmação de endereço', enviado para o e-mail correspondente a conta de usuário;
8. Clicar no link para realizar a 'Confirmação';
9. Definir a nova senha;
10. Confirmar a nova senha;
11. Marcar a opção 'Não sou robô';
12. Clicar na opção 'Salvar';
13. Pronto, agora é possível acessar o sistema com a conta criada;

**Importante**: O perfil 'Webservice' não deve ser adicionado ao usuário comum de empresa, pois caso seja adicionado, este perfil serve para configurações de integrações entre sistemas.

Caso não consiga visualizar o e-mail de confirmação de endereço, verifique outros lugares onde ele possa estar, como sua pasta de lixo eletrônico, spam, social ou outras.
