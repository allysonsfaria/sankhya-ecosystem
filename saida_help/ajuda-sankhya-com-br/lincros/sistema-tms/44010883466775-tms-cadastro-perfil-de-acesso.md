# [TMS] - Cadastro perfil de acesso

**Menu:** Sistema > Acesso > Perfis

**Objetivo:** Como realizar o cadastro de um novo perfil de acesso

## Considerações:

- Possuir um usuário, ou grupo de usuários no(s) qual(is) você deseja criar um perfil de acesso personalizado;

## Cadastrando um novo perfil de acesso

1. Acessar o menu: Sistema > Acesso > Perfis;
2. Clicar em 'Novo';
3. Ao clicar em 'Novo' a seguinte tela será demonstrada:

![Imagem 1: Ao clicar em 'Novo' a seguinte tela será demonstrada:](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963597470/96010fac1340fb462ea73351a851/4040335B6A244B2D1BF1FE1C175E62A9?expires=1791331200&signature=9cc69e38a50b0b434eb1724c1acccbcaf7daa5dd8776b21a8afdad47e0739d87&req=dSkhFcx3moVYWfMW3nq%2BgaHLGd%2FYW0F7aBzJv2yckPej15hnn2XZzv%2BFnv5n%0AYlGQHcPYpDO9kvV7u4DWAednj3Y%3D%0A)

- Nome: É o campo onde o preenchimento é obrigatório, é nesse campo que você irá definir um nome para aquele perfil;
- Alterar unidade: Permite alterar unidades da empresa;
- Administrador: O perfil terá todos os privilégios de um usuário Administrador (padrão Lincros);
- Criar usuários Webservice: Permite criar usuários webservice;
- Autorizar usuário de transportadora: Permite ao perfil autorizar usuários de transportadora que solicitam acesso via portal do transportador (Para mais informações, acessar o artigo **[[TMS] - Autorizar acesso de usuário de transportadora](https://sankhya.zendesk.com/hc/pt-br/articles/44010883466775)**);
- Autorizar usuário de cliente: Permite ao perfil autorizar usuários de cliente que solicitam acesso via portal do cliente.

**Obs:** Para realizar as liberações de permissões de acesso as telas do sistema ver artigo **[[TMS] - Permissões](https://sankhya.zendesk.com/hc/pt-br/articles/44010883466775).**
