# [Routing] - Rodízio de Placas

**Menu:** Cadastros > Rodízio de Placas

**Objetivo:** Como realizar o cadastro de Rodízio de Placas

## Considerações:

- Com o rodízio de placas, é possível realizarmos o cadastro dos dias em que determinado final de placa não poderá realizar rotas;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento dos rodízios de placas:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro de rodízio de placas é necessário informar os seguintes campos:

1. **Depósito**: Para o cadastro de rodízio de placas é necessário vincular ele à um depósito;
2. **Nome:** Informe o nome para este rodízio de placas;

## Bloqueios

Nele é possível informar o dia, início e fim dos períodos de bloqueios.
