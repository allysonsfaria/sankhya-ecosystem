# [Routing] - Cadastro de Transportadora

**Menu:** Cadastros > Transportadoras

**Objetivo:** Como realizar o cadastro de transportadoras

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de transportadoras:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de transportadoras é necessário informar os seguintes campos:

1. **Depósito:** Para o cadastro de uma transportadora é necessário vincular ela à um depósito;
2. **Nome:** Informe o nome da transportadora;
3. **CNPJ:** Informe o CNPJ da transportadora;
4. **Código Externo:** Informe o código externo para integração.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
