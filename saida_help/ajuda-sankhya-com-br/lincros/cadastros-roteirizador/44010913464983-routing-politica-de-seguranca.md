# [Routing] - Política de Segurança

**Menu:** Cadastros > Política de Segurança

**Objetivo:** Como realizar o cadastro de política de segurança para os usuários do Routing

## Considerações:

- A política de segurança define as regras de senha para os usuários do sistema, como tamanho mínimo, complexidade e prazo de validade;
- É necessário ter ao menos uma política de segurança cadastrada antes de criar usuários no Router;
- É necessário ter o campo abaixo já cadastrado no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de política de segurança é necessário informar os seguintes campos:

1. **Nome:** Informe o nome para esta política de segurança;
2. **Tamanho mínimo da senha:** Informe a quantidade mínima de caracteres para a senha;
3. **Requer letras maiúsculas:** Defina se a senha deve conter letras maiúsculas;
4. **Requer letras minúsculas:** Defina se a senha deve conter letras minúsculas;
5. **Requer números:** Defina se a senha deve conter números;
6. **Requer caracteres especiais:** Defina se a senha deve conter caracteres especiais;
7. **Validade (dias):** Informe por quantos dias a senha será válida antes de exigir troca. Informe 0 para sem validade.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
