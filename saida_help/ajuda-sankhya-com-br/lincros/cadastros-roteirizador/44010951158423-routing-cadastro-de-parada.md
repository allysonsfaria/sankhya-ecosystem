# [Routing] - Cadastro de Parada

**Menu:** Cadastros > Parada

**Objetivo:** Como realizar o cadastro de parada

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de paradas:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro de paradas é necessário informar os seguintes campos:

- **Depósito**: Para o cadastro de parada é necessário vincular ele à um depósito;
- **Nome**: Informe o nome para esta parada;
- **Hora início**: Informe a hora de início da parada;
- **Hora fim**: Informe a hora de fim da parada;
- **Tempo de parada**: Selecione o tempo de parada cadastrado previamente;
- **Dias de semana**: Selecione os dias da semana em que a parada será aplicada.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
