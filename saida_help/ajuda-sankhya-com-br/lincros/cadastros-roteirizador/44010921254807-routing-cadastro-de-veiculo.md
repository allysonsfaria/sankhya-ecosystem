# [Routing] - Cadastro de Veículo

**Menu:** Cadastros > Veículos

**Objetivo:** Como realizar o cadastro de veículos

**Considerações:** É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento dos veículos:

- [Motorista](https://intercom.help/ajudalincros/pt-BR/articles/13438712-routing-cadastro-de-motorista)
- [Tipo de Veículo](https://sankhya.zendesk.com/hc/pt-br/articles/44010671611287)
- Ponto de Apoio
- [Transportadora](https://intercom.help/ajudalincros/pt-BR/articles/13438672-routing-cadastro-de-transportadora)
- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de veículos é necessário informar os seguintes campos:

1. **Depósito:** Para o cadastro de um veículo é necessário vincular ele à um depósito;
2. **Motorista:** Para o cadastro de veículo é necessário vincular um motorista;
3. **Tipo de veículo:** Ao vincular o tipo de veículo, todas as características, serão passadas para o veículo;
4. **Transportadora:** Para realizar o vínculo do veículo à uma transportadora, é necessário ter realizado com antecedência este cadastro. Para o uso de integração com o Router e o Tracking é necessário ter uma transportadora vinculada;
5. **Ponto de apoio:** Ao informar um ponto de apoio, o início das entregas terão como origem o ponto de apoio informado e não será considerado mais o depósito como ponto de partida;
6. **Placa:** Informe a placa do veículo, o padrão é da MERCOSUL com 7 dígitos;
7. **Código Externo/Auxiliar Integração:** Este campo é utilizado quando à necessidade de informar algum código durante a integração;
8. **Ativo:** Este campo informa se o veículo estará ativo para ser roteirizado;
9. **Rota de vários dias:** Ao habilitar está opção a rota criada com este veículo será feita com mais de um dia quando ultrapassar o horário de atendimento do motorista (pernoites);
10. **Volta para o depósito no término das entregas:** Ao habilitar está opção o veículo utilizará o horário do motorista para o retorno do depósito;

1. **Ignorar rotas deste veículo nos indicadores:** Ao habilitar está opção este veículo não será utilizado nos indicadores;
