# [Routing] - Prioridade Pedido

**Menu:** Cadastros > Prioridade Pedido

**Objetivo:** Como realizar o cadastro de prioridade de pedidos

## Considerações:

- A prioridade de pedidos serve para informar qual a prioridade para a entrega;
  - Ao criar uma importação de pedido, você pode informar a prioridade de acordo com o código criado, quando esse pedido for importado o sistema vai olhar o grau de importância e prioriza na posição de entrega;
  Por exemplo: este cadastro, na importação do pedido vai informado o valor A, e quando esse pedido entra na tela para roteirizar aparece do lado do pedido a letra A.
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de prioridade de pedidos:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de prioridade de pedidos é necessário informar os seguintes campos:

1. **Depósito**: Para o cadastro de uma prioridade de pedidos é necessário vincular ele à um depósito;
2. **Código**: Informe o código para esta respectiva prioridade de pedido;
3. **Identificador**: Informe o código identificador desta prioridade de pedido;
4. **Importância**: Selecione o grau de importância desta prioridade de pedido. Quando maior o número, mais importante é a prioridade;
5. **Descrição**: Informe uma descrição para esta prioridade de pedido;
6. **Cor**: Informe uma cor para esta prioridade de pedido;
7. **Validade (em dias)**: Informe a quantidade de dias que esta prioridade de pedidos irá ter;
