# [Routing] - Grupo de Rotas

**Menu:** Cadastros > Grupo de Rotas

**Objetivo:** Como realizar o cadastro de grupo de rotas

## Considerações:

O Grupo de Rotas nós permite a criação de um grupo de rotas exclusivas, onde todos os clientes que estiverem cadastrados neste grupo serão roteirizados na mesma rota independente do setor.

É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de grupos de rotas:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro de grupo de rotas é necessário informar os seguintes campos:

- **Depósito**: Para o cadastro de grupo de rotas é necessário vincular ele à um depósito;
- **Nome:** Informe o nome para este grupo de rotas;
- **Veículos exclusivos**: Informe as placas para os veículos exclusivos;
- **Tipos de Veículos exclusivos:** Informe quais são os tipos e veículos exclusivos;
