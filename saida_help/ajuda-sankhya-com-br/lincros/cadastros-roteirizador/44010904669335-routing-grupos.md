# [Routing] - Grupos

**Menu:** Cadastros > Grupos

**Objetivo:** Como realizar o cadastro de grupos

## Considerações:

- Os grupos de rotas serão utilizados para informarmos que determinados setores podem fazer parte do mesmo grupo;
- Isso fará com que no momento da roteirização setores pertencentes ao mesmo grupo sejam roteirizados juntamente;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de grupos:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de grupos é necessário informar os seguintes campos:

1. **Depósito**: Para o cadastro de uma prioridade de pedidos é necessário vincular ele à um depósito;
2. **Nome:** Informe um nome para este grupo;
