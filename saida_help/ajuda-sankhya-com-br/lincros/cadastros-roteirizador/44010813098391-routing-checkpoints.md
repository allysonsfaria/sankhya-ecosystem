# [Routing] - Checkpoints

**Menu:** Cadastros > Checkpoints

**Objetivo**: Como realizar o cadastro de Checkpoints

## Considerações:

- O cadastro de Checkpoints são pontos cadastráveis no mapa onde, no momento da criação da roteirização os veículos serão direcionados a passarem por eles durante o percurso realizado até o cliente;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de checkpoints:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro de Checkpoints é necessário informar os seguintes campos:

- **Depósito**: Para o cadastro de checkpoints é necessário vincular ele à um depósito;
- **Descrição**: Informe uma descrição para este checkpoint;
- **Ida e Volta**: Informe se o checkpoint será utilizado para ida e volta. Desenha no mapa o setor do checkpoint;

## Como realizar o cadastro

Para utilizar o checkpoint, primeiro deve ser desenhado dois setores, ao finalizar o segundo setor o Routing traça como sugestão um caminho entre eles, podendo ser alterado utilizando o botão 'Adicionar Checkpoint', informando no mapa o caminho que o veículo deve seguir para chegar o setor.
