# [Routing] - Cadastro de Motorista

**Menu:** Cadastros > Motoristas

**Objetivo:** Como realizar o cadastro de motoristas

## Considerações:

- Este cadastro é indispensável;
- As informações do motorista são essenciais para limitar o tempo disponível para execução de uma viagem e, se cadastrado, gera alertas sobre o vencimento de CNH;
- Se todos os Motoristas da frota possuírem o mesmo perfil de jornada diária, basta cadastrar um único Motorista com este perfil e atrelar este Motorista a todos os Veículos;
- A roteirização respeita o tempo de jornada cadastrado para cada motorista;
- Para cada rota criada é informado o tempo previsto em rota, previsão de saída e retorno do veículo;
- É possível cadastrar diversos motoristas/perfis para atender jornadas específicas de cada um;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento dos motoristas:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de motoristas é necessário informar os seguintes campos:

1. **Depósito:** Para o cadastro de um veículo é necessário vincular ele há um depósito;
2. **Nome:** Informe o nome do motorista. É possível atribuir o mesmo motorista a vários veículos;
3. **Código:** Ao informar o valor, a informação será disponibilizada durante a integração;
4. **CPF:** Informe o número do CPF do motorista, com 11 dígitos;
5. **CNH:** Informe o número da CNH do motorista, para gerar alertas sobre o vencimento da mesma;
6. **Vencimento:** Informe a data de vencimento da CNH do motorista;
7. **Hora início / Hora Término:** Este campo será utilizado para criar as rotas, obedecendo o horário informado, ou seja, determina o tempo disponível para a execução de uma viagem;
8. **Inativar:** Para inativar um cadastro este antes deve ser removidos dos vínculos dos motoristas.
