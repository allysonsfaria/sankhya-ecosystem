# [Routing] - Cadastro Tipos de Ponto de Interesse

**Menu**: Routing> Cadastros> Tipos de Ponto de Interesse

**Objetivo**: Como criar tipos de ponto de interesse, para posteriormente poder cadastrar o ponto de interesse.

**Considerações**:

- É necessário ter acesso à tela Menu > Cadastros;
- É necessário possuir acesso à Depósito;
- O cadastro do tipo de ponto de interesse é importante, porque, para cadastrar um ponto de interesse, é preciso ter cadastrado previamente o tipo de ponto de interesse;

Abaixo segue os procedimentos:

1. No Routing acessar o menu: Cadastros > Tipos de ponto de interesse;
2. Clicar na opção 'Novo';
3. Na tela haverá campos para preenchimento, conforme exemplo abaixo:

![Imagem 1: Na tela haverá campos para preenchimento, conforme exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011458755351)

     4. Selecionar o depósito;

     5. Informar o nome do tipo de ponto de interesse. Exemplo: Posto de combustível, pedágio, farmácia, etc.;

     6. Informar o 'ícone', nesse campo deve ser inserido um código copiado do site: [Fonte incrível - Clique aqui](https://fontawesome.com/v5/search), conforme orientações abaixo:

- Procurar o ícone que deseja, no exemplo foi utilizado o Fuel (combustível), clicar sobre o ícone, e copiar o texto que fica entre aspas " ", nesse caso: "fas fa-gas-pump":

![Imagem 2: Procurar o ícone que deseja, no exemplo foi utilizado o Fuel (combustível), clicar sobre o ícone, e copiar o texto que…](https://ajuda.sankhya.com.br/hc/article_attachments/44011501346455)

    7. Ao colar o texto no roteirizador, atentar que só o que estiver nas aspas deve ser colado, sem as aspas, aparecerá a imagem do ícone copiado, para finalizar selecione a opção 'Confirmar':
