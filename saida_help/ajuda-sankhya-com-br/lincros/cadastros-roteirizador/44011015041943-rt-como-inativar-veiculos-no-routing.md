# [RT] - Como Inativar Veículos no Routing

**1. Problema Relatado pelo Cliente:**
O cliente solicita a exclusão de veículos listados na plataforma de roteirização, mencionando que a ação é necessária para o enquadramento de um serviço contratado. A exclusão foi solicitada sem considerar possíveis impactos no processo de roteirização, como o vínculo dos veículos com rotas já exportadas.

**2. Passo a Passo para Resolver o Problema:**
Como a plataforma não permite a exclusão de veículos, uma alternativa segura e eficiente é a inativação destes, que podem ser feitas apenas por usuários que está com as permissão **Manager**vinculado ou possuem acesso ao **Menu de Cadastros**. Siga os passos abaixo para inativar os veículos de maneira adequada:

**1. Acesse o menu principal:**
Navegue até o menu "Cadastros" e clique na opção "Veículos".

![Imagem 1: 1. Acesse o menu principal: Navegue até o menu "Cadastros" e clique na opção "Veículos".](https://ajuda.sankhya.com.br/hc/article_attachments/44011028381207)

**2. Filtre o veículo:**
Se necessário, utilize a ferramenta de filtro para localizar o veículo que deseja inativar.

**3. Edite o veículo:**
Após localizar o veículo desejado, clique no ícone de lápis, localizado na lateral direita da tela, para editar as informações.

![Imagem 2: 3. Edite o veículo: Após localizar o veículo desejado, clique no ícone de lápis, localizado na lateral direita da tela,…](https://ajuda.sankhya.com.br/hc/article_attachments/44011059621271)

**4. Altere o status para inativo:**
Na tela de edição, desmarque a opção "Ativo" e clique em "Confirmar" para salvar as alterações.
