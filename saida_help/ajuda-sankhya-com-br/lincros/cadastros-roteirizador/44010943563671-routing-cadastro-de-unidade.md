# [Routing] - Cadastro de Unidade

**Menu:** Cadastros > Unidade

**Objetivo:** Como realizar o cadastro de unidades no Routing

## Considerações:

- As unidades são utilizadas para segmentar o acesso dos usuários no sistema, vinculando cada usuário às unidades para as quais tem permissão;
- Uma unidade pode estar vinculada a um ou mais depósitos no Routing;
- É necessário ter o campo abaixo já cadastrado no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de unidades é necessário informar os seguintes campos:

1. **Nome:** Informe o nome para esta unidade;
2. **Depósitos:** Selecione os depósitos que serão vinculados a esta unidade. Um usuário vinculado a esta unidade terá acesso apenas aos depósitos aqui informados.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
