# [Routing] - Cadastro Tipo de Veículos

**Menu:** Cadastros > Tipo de Veículos

**Objetivo:** Como realizar o cadastro dos tipos de veículos

## Considerações:

- O tipo de veículo é utilizado para associarmos um determinado veículo a ele;
- Nele definimos como os carros serão identificados, exemplo: Carreta, Truck, Toco, etc.;
- Aqui no tipo de veículos, definimos também as capacidades de carga de cada tipo de veículo (m3, kg);
- É necessário ter os campos abaixo já cadastrados no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de tipos veículos é necessário informar os seguintes campos:

1. **Depósito:** Para o cadastro de um tipo veículo é necessário vincular ele à um depósito;
2. **Descrição:** Informe uma descrição para este veículo;
3. **Capacidade:** Informe qual a capacidade de carga deste veículo;
4. **Peso:** Informe qual o peso deste veículo;
5. **Quantidade de Eixos:** Informe a quantidade de eixos deste veículo;
6. **Classificação Veículo**: Informe a classificação do veículo. Exemplo: Sem classificação, Carro, Caminhão, Moto;
7. **Máximo de Atividades na Rota**: Informe a quantidade de atividades que poderão ser atendidos por este veículo;
8. **Tempo de recarga entre as rotas**: Informe o tempo para realizar a recarga neste veículo;
9. **Código TMS**: Informe o código do tipo de veículo cadastrado no TMS;

**Gaveteiro**: É um tipo de veículos composto por várias gavetas, onde podemos transportar vários tipos de produtos, servindo para separar produtos dentro de um mesmo veículo em gavetas. Por exemplo: Caminhão de combustível, na primeira gaveta transportarmos álcool, na segunda gasolina e na terceira diesel.

**1. Nome**: Informe o nome para esta gaveta;

**2. Tipo de Veículo:** Informe o nome deste tipo de veículo;

**3. Quantidade de gavetas**: Informe a quantidade de gavetas deste tipo de veículo;

**4. Peso**: Informe o peso deste tipo de veículo;

**5. Cubagem**: Informe a cubagem deste tipo e veículo;

**6. Tipo de produto pré-definido:** Selecione o tipo de produto para este gaveteiro. Dessa forma nenhum outro tipo de produto será inserido na gaveta. O tipo do produto deve vir informado no pedido na sua importação para o Router.

**7. Pedido Único**: Informe se uma gaveta pode ou não receber mais de um pedido, marcando a flag dentro da gaveta. Dessa forma, apenas um pedido entrará na gaveta, mesmo que essa ainda possua espaço livre.
