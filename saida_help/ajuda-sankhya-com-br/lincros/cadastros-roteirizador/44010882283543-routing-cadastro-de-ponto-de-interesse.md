# [Routing] - Cadastro de Ponto de Interesse

**Menu**: Routing> Cadastros > Ponto de Interesse

**Objetivo**: Como criar ponto de interesse, para posterior visualização do referido ponto, no mapa da sessão do roteirizador.

**Considerações**:

- É necessário ter acesso à tela Menu> Cadastros;
- Possuir acesso à Depósito;
- Possuir o cadastro previamente o tipo de ponto de interesse - orientações para criação: [[Routing] - Cadastro Tipos de Ponto de Interesse](https://intercom.help/ajudalincros/pt-BR/articles/13438292-routing-cadastro-tipos-de-ponto-de-interesse);

Abaixo segue os procedimentos.

1. No Routing acessar o menu: Cadastros > Ponto de Interesse;
2. Clicar na opção 'Novo';
3. Preencher os campos:

- **Depósito**: Selecionar o depósito desejado;
- **Tipo**: Selecionar o tipo de interesse desejado;
- **Nome**: Definir um nome que descreva o ponto de interesse;
- **Endereço**: Informar o endereço do ponto de interesse;
- **Buscar**: Localizar a geolocalização conforme o endereço informado;
- **Confirmar**: Salvar o ponto de interesse que está sendo criado.
