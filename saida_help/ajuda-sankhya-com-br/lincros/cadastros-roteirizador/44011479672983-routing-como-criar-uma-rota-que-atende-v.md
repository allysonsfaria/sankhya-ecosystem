# [Routing] - Como criar uma rota que atende vários setores

**Menu**: Cadastros > Grupos & Cadastros > Setor

**Objetivo**: criar grupos de setores para possibilitar de criar rotas automáticas atendendo vários setores

**Considerações**:

- Possuir permissão no menu de 'Cadastros';
- Para que você possa criar uma rota que contemple vários setores é necessário a criação de um grupo;
- O grupo tem a finalidade de unificar os setores;

Abaixo segue os procedimentos:

1. Acessar o menu: Cadastros > Grupos;

   ![Imagem 1: Acessar o menu: Cadastros > Grupos;](https://ajuda.sankhya.com.br/hc/article_attachments/44011419041047)
2. Clicar na opção 'Novo';

   ![Imagem 2: Clicar na opção 'Novo';](https://ajuda.sankhya.com.br/hc/article_attachments/44011467891607)
3. Após abrir a tela de Cadastro de Grupo, Em depósito selecione o depósito de origem para aquele grupo de setores;
4. Em nome, colocar um nome ao grupo para fácil identificação, após essa informação clique em confirmar;

   ![Imagem 3: Em nome, colocar um nome ao grupo para fácil identificação, após essa informação clique em confirmar;](https://ajuda.sankhya.com.br/hc/article_attachments/44011452637463)
5. Acessar o menu: Cadastro > Setor

   ![Imagem 4: Acessar o menu: Cadastro > Setor](https://ajuda.sankhya.com.br/hc/article_attachments/44011468247831)
6. Dentro de Setor, localize os setores que pretende agrupar e clique na opção ao lado editar;

   ![Imagem 5: Dentro de Setor, localize os setores que pretende agrupar e clique na opção ao lado editar;](https://ajuda.sankhya.com.br/hc/article_attachments/44011470059159)
7. Na tela de edição 'Alteração de Setor', é necessário validar se a (opção) 'Setor exclusiv'o está desabilitada, caso contrário não permitira que adicione o setor ao grupo;
8. Na opção Grupo, você adiciona o grupo criado no passo 3;

   ![Imagem 6: Na opção Grupo, você adiciona o grupo criado no passo 3;](https://ajuda.sankhya.com.br/hc/article_attachments/44011468714903)
9. Para adicionar outros setores repetir o passo 5;
10. Através dessa informação, é possível abranger uma rota maior, aumentando o atendimento a diversas regiões.
