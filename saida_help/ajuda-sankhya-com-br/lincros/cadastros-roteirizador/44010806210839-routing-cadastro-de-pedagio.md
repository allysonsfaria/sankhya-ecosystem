# [Routing] - Cadastro de pedágio

**Menu:** Cadastros > Pedágios

**Objetivo:** Como realizar o cadastro de pedágios

## Considerações:

- O cadastro de pedágios nos permite cadastrar e identificar pedágios que possam ser listados durante o processo de roteirização;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento dos veículos:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro de pedágios é necessário informar os seguintes campos:

- **Depósito**: Para o cadastro de pedágios é necessário vincular ele à um depósito;
- **Nome**: Informe o nome para este cadastro de pedágios;
- **Ativo**: Informe se este pedágio está ativo ou não;
- **Valor Por Eixo - Caminhão**: Informe o valor do pedágio cobrado por eixo (caminhão);
- **Valor Por Eixo - Carro**: Informe o valor do pedágio por eixo (carro);
- **Valor Por Eixo - Motocicleta**: Informe o valor do pedágio por eixo (motocicleta);
- **Endereço**, **Complemento**, **Cidade**, **Estado**, **Bairro**, **CEP**, **País**: Informe os dados de localização;
- **Latitude / Longitude**: Informe as coordenadas ou arraste a localização no Google Maps para preenchimento automático;
- **Impedir que as coordenadas sejam alteradas via integração**: Ao setar esta opção, você irá impedir que as coordenadas sejam alteradas via integração.
