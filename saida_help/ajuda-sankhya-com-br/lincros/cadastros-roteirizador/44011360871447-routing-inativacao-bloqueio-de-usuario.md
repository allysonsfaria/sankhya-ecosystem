# [Routing] - Inativação/Bloqueio de Usuário

**Menu:** Cadastros > Usuários

**Objetivo:** Inativar usuário no sistema

## Considerações:

- Logar no sistema com Usuário Administrador;

## Inativando usuário

1. Acessar o menu: Cadastros > Usuários;
2. Clicar na opção 'Filtrar';
3. Selecionar o depósito desejado;
4. Informar o 'Nome';
5. Clicar na opção 'Filtrar';
6. Clicar no ícone 'Lápis' para editar;
7. Desmarcar a caixa de seleção 'Ativo' (conforme imagem abaixo);
8. Clicar em 'Confirmar';

![Imagem 1: Clicar em 'Confirmar';](https://ajuda.sankhya.com.br/hc/article_attachments/44011311814679)

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
