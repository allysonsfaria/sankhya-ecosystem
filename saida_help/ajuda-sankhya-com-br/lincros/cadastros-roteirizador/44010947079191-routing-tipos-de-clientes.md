# [Routing] - Tipos de Clientes

**Menu:** Cadastros > Tipos de Clientes

**Objetivo:** Como realizar o cadastro de tipos de clientes

## Considerações:

- Os tipos de clientes permitem segregar os clientes pelos tipos, neles adicionamos marcadores que facilitam a identificação dos tipos de clientes durante a roteirização;
- Filtro por tipos de clientes, que possibilita roteirizar tipos de clientes específicos, que tenham alguma particularidade ou restrição;
- Fácil identificação dos tipos de cientes no mapa de roteirização;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento dos tipos de clientes:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro de tipos clientes é necessário informar os seguintes campos:

- **Depósito**: Para o cadastro de tipos de clientes é necessário vincular ele à um depósito;
- **Nome**: Informe o nome deste tipo de cliente;
- **Identificador**: Informe o código identificador para este tipo de cliente;
- **Cor**: Seleciona cor para este tipo de cliente.
- **Tempo de Espera:** Informe o tempo de espera para este tipo de cliente;
- **Desconsiderar o tempo de descarga**: Ao setar está opção, o Router irá desconsiderar o tempo de descarga;
- **Código TMS**: Informe o código desse tipo de cliente no TMS;
