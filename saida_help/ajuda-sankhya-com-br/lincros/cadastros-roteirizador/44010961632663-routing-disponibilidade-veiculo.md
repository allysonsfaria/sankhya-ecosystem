# [Routing] - Disponibilidade Veículo

**Menu:** Cadastros > Disponibilidade Veículo

**Objetivo:** Como realizar o cadastro Disponibilidade de Veículo

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de Disponibilidade Veículo:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de disponibilidade de veículos é necessário informar os seguintes campos:

1. **Depósito**: Para o cadastro de uma disponibilidade de veículo é necessário vincular ele à um depósito;
2. **Nome**: Informe o nome dessa disponibilidade de veículo;
3. **Data de início**: Informe a data de início que o veículo já está sendo utilizado para a transportadora e que não poderá ser roteirizado;
4. **Data final**: Informe a data final da indisponibilidade do veículo para ser roteirizado dentro das sessões;
5. **Lista Placas**: Selecione a(s) placa(s) desejadas para disponibilidade. Exemplo: Vou criar um novo cadastro com 5 veículos e colocamos o nome de 'DispVeic'; Quando for criar a sessão e apenas informo o 'DispVeic', ao invés de ficar procurando pelos 5 veículos. O usuário escreve apenas o nome da disponibilidade. Neste caso, ao utilizar o 'DispVeic' aparecerá apenas os 5 veículos cadastrados.
