# [Routing] - Cadastro de tempo de parada de refeição

**Menu:** Cadastros > Tempos de Parada

**Objetivo:** Entender como parametrizar o sistema para que no processo de roteirização, já seja informado o tempo de parada para refeição do motorista.

**Considerações:**

- Possuir acesso ao menu: Cadastros > Tempos de Parada;

Abaixo segue os procedimentos:

1. Para que no processo de roteirização o sistema já defina o tempo de parada de refeição do motorista, deve-se obrigatoriamente acessar a opção de menu: Cadastros > Tempos de parada, e ali definir qual será este tempo;

   ![Imagem 1: Para que no processo de roteirização o sistema já defina o tempo de parada de refeição do motorista, deve-se…](https://ajuda.sankhya.com.br/hc/article_attachments/44011521471383)
2. Na tela de cadastro podemos:

   - Definir a qual **Depósito** irei vincular aquele tempo de parada;
   - Definir um **Nome** para aquela parada. Mas aqui é importante salientar que na roteirização esta parada será identificada por um símbolo com a letra "R" no mapa, identificando que aquela é uma parada para refeição;
   - **Tempo mínimo para parada:** Aqui definimos o mínimo de horas seguidas que o motorista poderá trabalhar até que tenha que fazer uma parada para refeição;
   - **Tempo máximo para parada:** Aqui definimos o máximo de horas seguidas que o motorista poderá trabalhar até que tenha que fazer uma parada para refeição;
   **- Tempo da parada:** Aqui definimos o tempo da parada para refeição;
3. Tendo parametrizado no sistema estes tempos para a parada, então quando for realizar a roteirização dos seus pedidos, o sistema irá definir de forma automática o tempo de parada para refeição para o motorista daquela rota. Além disso, claro, o sistema respeitará a jornada do motorista, definida no cadastro do motorista, para definir o horário de parada para refeição do mesmo;
