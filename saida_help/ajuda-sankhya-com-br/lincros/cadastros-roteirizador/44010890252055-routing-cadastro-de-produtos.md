# [Routing] - Cadastro de Produtos

**Menu:** Cadastros > Produtos

**Objetivo:** Como realizar o cadastro de produtos

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de produtos:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de produtos é necessário informar os seguintes campos:

1. **Depósito**: Para o cadastro de um produto é necessário vincular ele à um depósito;
2. **Nome:** Informe o nome deste produto;
3. **Código:** Informe o código deste produto;
4. **Tipo de Produto:** Selecione o tipo de produto previamente cadastrado;
5. **Cubagem:** Informe a cubagem deste produto;
6. **Peso:** Informe o peso deste produto.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
