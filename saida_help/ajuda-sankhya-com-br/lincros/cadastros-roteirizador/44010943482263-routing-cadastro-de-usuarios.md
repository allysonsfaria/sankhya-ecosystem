# [Routing] - Cadastro de Usuários

**Menu:** Cadastros > Usuários

Objetivo: Como realizar o cadastro de usuários

## Considerações:

- O cadastro deste usuário deverá ser intransferível;
- Somente os usuários manager podem realizar os cadastros de usuários;
- Só é possível liberar depósitos que o usuário tem liberado;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de tipos de produtos:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)
- [Política de Segurança](https://intercom.help/ajudalincros/pt-BR/articles/14447735-routing-politica-de-seguranca)
- [Unidade](https://intercom.help/ajudalincros/pt-BR/articles/14447736-routing-cadastro-de-unidade)

Para o cadastro de usuários é necessário informar os seguintes campos:

1. **Nome:** Informe o nome completo deste usuário;
2. **E-mail:** Informe o e-mail deste usuário;
3. ## Política de Segurança:
4. **Depósito**: Para o cadastro de um usuário é necessário vincular ele à um depósito;
5. **Unidades**: Informe as unidades que este usuário terá acesso. Estas unidades utilizamos no cadastro do depósito;
6. **Bloqueado**: Ao selecionar o checkbox é porque este usuário estará bloqueado e não terá mais acesso ao Router;
7. **Permissões**: Selecione as permissões que esse usuário terá acesso;
8. **Senha**: Informe a senha que este usuário terá, seguindo a política de segurança;
9. **Repetir Senha**: Digite novamente a senha que este usuário terá;

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
