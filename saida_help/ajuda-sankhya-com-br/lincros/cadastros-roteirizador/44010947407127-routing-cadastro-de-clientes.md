# [Routing] - Cadastro de Clientes

**Menu:** Cadastros > Clientes

**Objetivo:** Como realizar o cadastro de clientes

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de clientes:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Para o cadastro de clientes é necessário informar os seguintes campos:

1. **Depósito:** Para o cadastro de um cliente é necessário vincular ele à um depósito;
2. **Nome:** Informe o nome do cliente;
3. **Tipo:** Informe o tipo de cliente;
4. **Código:** Informe o código do cliente para integração;
5. **Endereço:** Informe o endereço do cliente;
6. **Cidade:** Informe a cidade do cliente;
7. **Estado:** Informe o estado do cliente;
8. **CEP:** Informe o CEP do cliente;
9. **Latitude/Longitude:** Coordenadas do cliente. Arraste o marcador no Google Maps para preenchimento automático;
10. **Tempo de Parada:** Informe o tempo de parada padrão para este cliente;
11. **Janela de atendimento:** Informe os horários de início e fim do atendimento.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
