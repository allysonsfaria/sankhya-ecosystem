# [Routing] - Cadastro de Tempos de Parada

**Menu:** Cadastros > Tempos de Parada

**Objetivo:** Como realizar o cadastro de tempos de parada

## Considerações:

- O tempo de parada, nos permite realizarmos o cadastro dos tempos mínimos e máximos para que o motorista realize a parada de Refeição;
- Nele definimos também o tempo total que o motorista poderá se manter nesta parada;
- É necessário ter os campos abaixo já cadastrados no Router para iniciar o cadastramento de tempos de paradas:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito);

Para o cadastro dos tempos de paradas é necessário informar os seguintes campos:

- **Depósito**: Para o cadastro de tempos de parada é necessário vincular ele à um depósito;
- **Nome**: Informe o nome para este tipo de parada;
- **Tempo mínimo para a parada**: Informe o tempo mínimo para início da parada;
- **Tempo máximo para a parada**: Informe o tempo máximo para o início da parada;
- **Tempo da parada**: Informe o tempo total da parada;
