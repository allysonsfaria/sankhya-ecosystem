# [TMS] - Relação de Conhecimentos por Valor

**Menu**: Relatórios > Auditoria de fretes > Conhecimentos por valor

**Objetivo**: O relatório de Conhecimentos por valor tem como objetivo extrair os dados contidos nos pré-conhecimentos do sistema.

## Considerações:

- Para gerar o relatório acessar o menu: Relatórios > Auditoria de fretes > Conhecimentos por valor
- Os campos de data de emissão da nota fiscal são obrigatórios;
- Para gerar um relatório com dados mais específicos, filtre os dados desejados antes de gerar o relatório;

## Abaixo os filtros disponíveis para geração do relatório:

## Filtros

- **Unidade:**Informar se deseja filtrar por unidades específicas;
- **Tipo:**Informar se deseja filtrar por tipos específicos de conhecimento;
- **Data de emissão da nota fiscal:** Informar o intervalo da data de emissão das notas fiscais (Campo obrigatório);
- **Emissão do CT-e:**Informar o intervalo da data de emissão dos CT-es;
- **Transportadora:**Informar caso queira filtrar por transportadoras específicas;
- **Fatura:** Informar caso queira filtrar por uma fatura específica;
- **Remetente:**Informar caso queira filtrar por um remetente específico;
- **Destinatário:**Informar caso queira filtrar por um destinatário específico;
- **Tomador:**Informar caso queira filtrar por um tomador específico;
- **Marcador por cliente:**Informar caso queira filtrar por marcadores que sejam vinculados a pessoas;
- **Calculadora de frete para projeto:**Informar caso queira filtrar por PEP (Projeto de frete) para trazer conhecimentos os quais a nota fiscal esteja vinculada a uma pré-nota que contenha projeto de frete;
- **Localização origem:** Informar caso queira filtrar por uma origem específica;
- **Localização destino:** Informar caso queira filtrar por um destino específico;
- **Produto:** Informar caso queira filtrar por um produto específico, caso informado um produto pai, todos os produtos vinculados a ele serão trazidos no relatório;
- **Somar ICMS ao frete:** Informar caso queira que seja somado o ICMS ao frete;
- **Somar PIS ao frete:**Informar caso queira que seja somado o PIS ao frete;
- **Somar COFINS ao frete:**Informar caso queira que seja somado COFINS ao frete;
- **Exibir apenas totalizadores:** Quando selecionado, apresenta apenas os valores totais para cada transportadora;
- **Exibir apenas conhecimentos:** Quando selecionado, não apresenta as notas fiscais;
- **Exibir resumo por tipo de pré-conhecimento:**Será exibido ao final do relatório os totalizadores separados por tipo de conhecimento;
- **Exibir o nome completo do destinatário:**Marcar a opção se desejar que seja exibido o nome completo do destinatário;
- **Exibir o nome completo da cidade:**Marcar a opção se desejar que seja exibido o nome completo da cidade;
- **Tipo de operação:**Informar o tipo de operação que deseja filtrar: **Venda, Compra ou Todos**;
- **Tipo de CT-e:** Informar caso queira filtrar por um tipo específico de CT-e;
- **Exibir coluna medida:** Informar qual tipo de medida aparecerá no relatório: **Cubagem ou Peso nominal;**
- **Forma de negociação:** Informar se deseja filtrar por um tipo de negociação específico;
- **Natureza da operação: I**nformar caso queira filtrar por conhecimentos de naturezas de operação específicas;
- **Departamento:** Informar caso queira filtrar por departamentos específicos;
