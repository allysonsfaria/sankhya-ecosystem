# [TMS] Como Corrigir a Cubagem de Itens que estão apresentando valores altos.

## 1. Problema Relatado pelo Cliente:

O cliente informou que ao calcular a cotação de alguns itens, a cubagem retornada está muito alta, o que está gerando divergências nas cotações e também nas auditorias de frete. Os itens mencionados pelo cliente são: **DS600031**, **DS540059** e **DS600030**. O erro ocorre devido ao cálculo da cubagem, resultante da configuração inadequada das dimensões dos produtos no sistema.

## 2. Passo a Passo para Resolver o Problema:

Para resolver o problema de cubagem incorreta, siga os passos abaixo:

Acesse **Cadastros Gerais > Produtos > Cadastro:**

![Imagem 1: Acesse Cadastros Gerais > Produtos > Cadastro:](https://ajuda.sankhya.com.br/hc/article_attachments/44013436518679)

Na tela de cadastro de produtos procurar e acessar o produto pelo código:

![Imagem 2: Na tela de cadastro de produtos procurar e acessar o produto pelo código:](https://ajuda.sankhya.com.br/hc/article_attachments/44013436638615)

No cadastro do produto, localize as dimensões do item (altura, largura e profundidade):

![Imagem 3: No cadastro do produto, localize as dimensões do item (altura, largura e profundidade):](https://ajuda.sankhya.com.br/hc/article_attachments/44013453803927)

Nos campos altura, largura e profundidade basta informar o número correto, lembrando que o sistema calcula por metros:

![Imagem 4: Nos campos altura, largura e profundidade basta informar o número correto, lembrando que o sistema calcula por metros:](https://ajuda.sankhya.com.br/hc/article_attachments/44013447102615)

Após ajustar as dimensões corretamente, clique em **Salvar** para atualizar as informações do produto:

![Imagem 5: Após ajustar as dimensões corretamente, clique em Salvar para atualizar as informações do produto:](https://ajuda.sankhya.com.br/hc/article_attachments/44013437165463)

Após salvar as alterações, o sistema irá calcular a cubagem corretamente para novas importações de documento, com base nas dimensões ajustadas.
