# [TMS] - Cadastro de Regiões por faixa de CEP

**Menu**: Cadastros Gerais > Modelo de distribuição > Faixas de cep

**Objetivo:** Auxiliar o usuário como realizar o cadastro de uma faixa de CEP que atenda uma região específica.

## Considerações:

- O cadastro de 'Faixa de CEP', tem o intuito de criar uma localização específica para que seja inclusa no cadastro de Regiões;
- O cadastro pode facilitar a cobrança de algumas taxas que são cobradas apenas em algumas áreas determinadas da cidade, como TDA, TRT, TDE, etc.;

## Cadastrando uma Faixa de CEP

1. Para cadastrar uma nova faixa de CEP, acessar o menu: Cadastros Gerais > Modelo de distribuição > Faixas de cep, e clicar em 'Novo';

   ![Imagem 1: Para cadastrar uma nova faixa de CEP, acessar o menu: Cadastros Gerais > Modelo de distribuição > Faixas de cep, e…](https://ajuda.sankhya.com.br/hc/article_attachments/44010824420375)
2. Após clicar em 'Novo', preencher os campos obrigatórios do cadastro, sendo estes:

- CEP inicial;
- CEP final;
- Nome (o nome listado é o mesmo que será apresentado na busca do cadastro da região);

**Obs:** o campo "ID Localização" será preenchido automaticamente após salvar o cadastro.

Para descobrir as faixas de CEP, pode-se consultar no site dos correios, **[Busca Faixa CEP Correios](https://www2.correios.com.br/sistemas/buscacep/resultadoBuscaFaixaCEP.cfm)**

![Imagem 2: Para descobrir as faixas de CEP, pode-se consultar no site dos correios, Busca Faixa CEP Correios](https://ajuda.sankhya.com.br/hc/article_attachments/44010780324503)

3. Após o cadastro, você pode criar a região e selecionar a faixa criada (para mais detalhes de como criar uma região, acesse **[[TMS] - Cadastro de Regiões](https://intercom.help/ajudalincros/pt-BR/articles/13432697-tms-cadastro-de-regioes)**);
