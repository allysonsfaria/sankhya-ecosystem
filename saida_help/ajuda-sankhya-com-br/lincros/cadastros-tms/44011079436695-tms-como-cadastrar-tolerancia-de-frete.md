# [TMS] - Como Cadastrar Tolerância de Frete

## 1 - Problema Relatado pelo Cliente:

O cliente informou que está com dificuldades para cadastrar a tolerância de R$ 0,50 nos CT-es. Relatou que, atualmente, o sistema está aplicando essa tolerância apenas em alguns casos, de forma inconsistente. A solicitação foi para entender como configurar corretamente essa tolerância para que seja aplicada uniformemente.

---

## 2 - Passo a Passo para Resolver o Problema:

**Objetivo:** Cadastrar a tolerância de frete no sistema para que seja aplicada corretamente em todos os CT-es emitidos.

**Passos:**

Acesse o sistema com um usuário que possua permissões de edição nos cadastros de transportadoras.

No menu principal, vá até: **Cadastros Gerais > Transportadoras > Transportadora (Empresa) > Cadastro**

![Imagem 1: No menu principal, vá até: Cadastros Gerais > Transportadoras > Transportadora (Empresa) > Cadastro](https://ajuda.sankhya.com.br/hc/article_attachments/44011054886295)

Localize a transportadora desejada e acesse pelo código:

![Imagem 2: Localize a transportadora desejada e acesse pelo código:](https://ajuda.sankhya.com.br/hc/article_attachments/44011038179735)

Na tela de edição, role até encontrar o campo **"Tolerância Frete":**

![Imagem 3: Na tela de edição, role até encontrar o campo "Tolerância Frete":](https://ajuda.sankhya.com.br/hc/article_attachments/44011079930519)

Insira o valor desejado para a tolerância (ex: **0,50**).

Clique em **"Salvar"** para aplicar a configuração.

![Imagem 4: Clique em "Salvar" para aplicar a configuração.](https://ajuda.sankhya.com.br/hc/article_attachments/44011065950231)
