# [TMS] - Cadastro de Pessoa

**Menu**: Cadastros gerais > Pessoas > Cadastro

**Objetivo**: Uma pessoa no TMS refere-se a todo e qualquer stakeholder do processo de transporte: sejam clientes, centros de distribuição, transportadoras ou relacionados. O sistema utiliza o cadastro de pessoa para obter o endereço ou coordenada geográfica para definir o ponto de interesse de entrega ou coleta. Desta forma, é necessário que o cadastro das pessoas esteja o mais completo possível

## Considerações:

- O usuário que realizará o cadastro de pessoas precisa ter o menu liberado;
- Há somente alguns campos obrigatórios, porém é importante que seja preenchido o maior número de informações possível.

## Passo a passo

Abaixo segue os procedimentos de como realizar o cadastro de pessoa:

1. Acessar o menu: Cadastros gerais > Pessoas > Cadastro;
2. Clicar na opção 'Novo';
3. Preencher os campos obrigatórios (marcados com asterisco), como por exemplo: Documento, tipo de documento, razão social;
4. Clicar na opção 'Salvar;
