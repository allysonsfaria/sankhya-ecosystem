# [TMS] - Como criar uma nova Visão específica para uma tela de pesquisa de documentos

**1. Problema Relatado pelo Cliente:**usuário quer criar uma visão de tela. Esse artigo mostra como o usuário pode criar uma visão de tela para ter um layout específico para futuras consultas, sem precisar ficar incluindo ou tirando colunas na tela de pesquisa.

**Considerações**:

- A visão é um recurso que fará com que o sistema grave as configurações de exibição da tela definidas pelo usuário logado;
- Usuário alterou as colunas a serem exibidas e quer salvar este layout para sua busca diária;

## 2. Passo a Passo para Resolver o Problema:

Abaixo segue os procedimentos de como configurar uma nova Visão de tela. Neste exemplo iremos cadastrar uma nova visão na tela de "Ordem de Coleta", porém, a visão pode ser criada em outras telas como Notas Fiscais, NF-e, CT-e, Embarques, Pré-conhecimentos, Pedidos, Pré-notas Fiscais e Acompanhamento de Entregas.

Passo 1: Acessar o menu: Expedição > Coletas > Ordem de Coleta;

Passo 2: Primeiramente iremos configurar as colunas da nossa visão, basta acessar o botão ‘Colunas’;

![Imagem 1: Passo 2: Primeiramente iremos configurar as colunas da nossa visão, basta acessar o botão ‘Colunas’;](https://ajuda.sankhya.com.br/hc/article_attachments/44013464899735)

Passo 3: Adicionar os campos desejados, por exemplo, irei adicionar o campo 'Usuário Criação’;

![Imagem 2: Passo 3: Adicionar os campos desejados, por exemplo, irei adicionar o campo 'Usuário Criação’;](https://ajuda.sankhya.com.br/hc/article_attachments/44013465006871)

Passo 4: Verificar que o campo acima ficou adicionado ao filtro das pesquisas;

![Imagem 3: Passo 4: Verificar que o campo acima ficou adicionado ao filtro das pesquisas;](https://ajuda.sankhya.com.br/hc/article_attachments/44013476825367)

Passo 5: Após, clicar na opção 'Visão';

![Imagem 4: Passo 5: Após, clicar na opção 'Visão';](https://ajuda.sankhya.com.br/hc/article_attachments/44013483634071)

Passo 6: Após, clicar na opção 'Salvar Como';

![Imagem 5: Passo 6: Após, clicar na opção 'Salvar Como';](https://ajuda.sankhya.com.br/hc/article_attachments/44013465395223)

Passo 7: Informar um nome para esta visão;

Passo 8: O ‘Tipo da Visão’ pode ser Perfil ou Usuário. Se selecionar "Perfil", essa visão vai ficar disponível para todos os usuários vinculado a esse perfil. Se selecionar "Usuário", essa visão para ficar disponível somente para o usuário que está criando ela.

![Imagem 6: Passo 8: O ‘Tipo da Visão’ pode ser Perfil ou Usuário. Se selecionar "Perfil", essa visão vai ficar disponível para…](https://ajuda.sankhya.com.br/hc/article_attachments/44013457311895)

Passo 9: Clicar na opção 'Salvar';

Passo 10: Verificar se o sistema emitiu a mensagem que a visão foi criada com sucesso;

![Imagem 7: Passo 10: Verificar se o sistema emitiu a mensagem que a visão foi criada com sucesso;](https://ajuda.sankhya.com.br/hc/article_attachments/44013465570711)

Passo 11: Após sair do sistema e logar novamente para que esta nova visão seja aplicada;

Passo 12: Verificar que a nova visão foi inserida no menu Expedição > Coletas > Visão coleta;

![Imagem 8: Passo 12: Verificar que a nova visão foi inserida no menu Expedição > Coletas > Visão coleta;](https://ajuda.sankhya.com.br/hc/article_attachments/44013491129879)
