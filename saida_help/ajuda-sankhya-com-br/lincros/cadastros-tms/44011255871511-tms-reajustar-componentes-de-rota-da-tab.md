# [TMS] - Reajustar Componentes de Rota da Tabela

**1 - Problema Relatado pelo Cliente:**
O cliente entrou em contato relatando que a opção "reajustar" para reajustar os valores de todos os componentes de rotas da tabelas simultaneamente não estava funcionando corretamente. A funcionalidade falhou ao tentar aplicar ajustes em massa, tornando inviável a alteração dos valores de componente em componente. O cliente solicitou ajuda urgente para resolver a questão, uma vez que o processo manual estava afetando a eficiência da operação.

---

**2 - Passo a Passo para Resolver o Problema:**
Para solucionar a questão do reajuste de todas as tabelas de uma vez, siga os seguintes passos detalhados:

1. ## Acessar a tela de Tabela de Frete:

   - Navegue até a tela de Negociações de Frete : **Cadastros Gerais > Transportadoras > Negociações > Tabelas de Frete**.
   - Selecione a tabela de frete desejada, para acessar a tela de edição.
2. ## Selecionar a Opção de Reajuste:

   - Selecione a opção **Reajustar**localizada no canto superior direito da tela.
3. ## Aplicar o Reajuste Desejado:

   - Insira o percentual de reajuste desejado (por exemplo, 4%) no campo Percentual ou o valor desejado, no campo Valor.
4. ## Pré-visualizar os Ajustes:

   - Clique na opção **Pré-visualizar**, para verificar as alterações antes de salvar.
5. ## Marcar a Opção "Selecionar Todos":

   - Marque a opção **Selecionar Todos**, para aplicar o reajuste a todos os componentes de rotas ou selecionar alguns componentes específicos
6. ## Reajustar a Rota Selecionada:

   - Após selecionar a rota, clique em **Reajustar** para aplicar o reajuste individualmente a essa rota.
7. ## Salvar as Configurações:

   - Após realizar todos os ajustes necessários, clique em **Salvar** para registrar as alterações nas tabelas de componentes por rota.
