# [TMS] - Erro ao Importar Tabela: Como Resolver Problemas de Nome de Arquivo

**1 - Problema Relatado pelo Cliente:**O cliente informou que não está conseguindo importar nenhuma tabela de frete no sistema. O problema pode estar relacionado ao nome da planilha utilizada na importação.

## 2 - Passo a Passo para Resolver o Problema:

1. ## Verificar o nome da planilha:

   - No módulo de Negociações de fretes: Cadastros gerais > Transportadoras > Negociações > Tabelas de frete
   - Antes de importar a planilha, verifique o nome do arquivo.
   - Certifique-se de que ele não contém caracteres especiais, como: `! @ # $ % ^ & * ( ) - _ = + [ ] { } \ | ; : ' " , < > . ? /`
2. ## Renomear a planilha:

   - Caso o nome contenha algum dos caracteres mencionados, renomeie a planilha.
   - Utilize apenas letras, números e sublinhados (`_`) para evitar erros.
3. ## Tentar a importação novamente:

   - Após renomear o arquivo, realize a importação novamente pelo sistema.
   - ![Imagem 1: Após renomear o arquivo, realize a importação novamente pelo sistema.](https://ajuda.sankhya.com.br/hc/article_attachments/44013476345879)
4. ## Caso o erro persista:

   - Se o problema continuar, faça uma captura de tela da mensagem de erro e envie para o suporte técnico para análise detalhada.
5. ## Consultar o status de importação:

   - Para acompanhar a importação da planilha pode ser acessado: Operacional> Importação> Excel> Log
