# [TMS] - Erro ao importar arquivo de Rotas (Regiões) - Região de destino não encontrada

**Menu:** Cadastros gerais > Transportadoras > Negociações > Rotas > Transportadora

**Objetivo:** Como corrigir o erro 'Região de destino não encontrada' ao realizar a importação das rotas/regiões

## Considerações:

**-** As rotas são cadastros separados das tabelas de frete e transportadoras, apenas são vinculadas. Desta maneira é possível utilizar a mesma rota para vários casos.

Para efetuar uma importação de rotas é necessário utilizar o template padrão que esta disponível no menu**:** Cadastros gerais > Transportadoras > Negociações > Rotas > Transportadora.

![Imagem 1: Para efetuar uma importação de rotas é necessário utilizar o template padrão que esta disponível no menu : Cadastros…](https://ajuda.sankhya.com.br/hc/article_attachments/44010911346199)

Dentro do Template possuimos algumas abas auxiliares que são pontos de atenção.

**Aba Exemplo:** É um exemplo de como a tabela deve ser preenchida de maneira correta para referência.

![Imagem 2: Aba Exemplo: É um exemplo de como a tabela deve ser preenchida de maneira correta para referência.](https://ajuda.sankhya.com.br/hc/article_attachments/44010919825047)

**Aba Códigos IBGE**: É uma lista apontando os códigos do IBGE para facilitar a busca caso seja necessária.

![Imagem 3: Aba Códigos IBGE : É uma lista apontando os códigos do IBGE para facilitar a busca caso seja necessária.](https://ajuda.sankhya.com.br/hc/article_attachments/44010932811031)

Para efetuar a importação das informações da tabela, realizar o processo de importação através do menu: Cadastros gerais > Transportadoras > Negociações > Rotas > Transportadora.

![Imagem 4: Para efetuar a importação das informações da tabela, realizar o processo de importação através do menu: Cadastros…](https://ajuda.sankhya.com.br/hc/article_attachments/44010932955159)

Abaixo segue um exemplo da mensagem de erro 'Região de destino não encontrada' ao realizar esta importação das rotas/regiões:

![Imagem 5: Abaixo segue um exemplo da mensagem de erro 'Região de destino não encontrada' ao realizar esta importação das…](https://ajuda.sankhya.com.br/hc/article_attachments/44010929343511)

Neste caso em específico o problema 'Região de destino não encontrada' acontece, pois nas colunas '**Região Origem'** ou '**Região Destino'** foram informadas regiões que não foram previamente cadastradas no sistema ou com algum erro na nomenclatura.

**Obs:** As nomenclaturas das regiões são definidas pelo usuários no ato de criação então indicamos que sejam criadas da maneira mais intuitiva possível e as mesmas nomenclaturas devem serem utilizadas na planilha.

Neste caso, é necessário corrigir os campos de Região na tabela ou criar caso não existam. Segue abaixo um Artigo sobre o cadastro das regiões: [[TMS] - Cadastro de Regiões](https://intercom.help/ajudalincros/pt-BR/articles/13432697-tms-cadastro-de-regioes)
