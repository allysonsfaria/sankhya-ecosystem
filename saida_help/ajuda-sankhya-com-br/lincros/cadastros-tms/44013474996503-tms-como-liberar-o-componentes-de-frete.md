# [TMS] Como Liberar o componentes de frete para a faixa de calculo

1 - Problema Relatado pelo Cliente:

O cliente informou que ao cadastrar a tabela da transportadora o componente "Ad Valorem" para o valor da mercadoria não está disponível para preenchimento nos componentes da rota dentro de determinada faixa de peso. O cliente questiona se é possível liberar esse campo para que o cadastro seja realizado corretamente.

(Este artigo serve para disponibilização/ativação de qualquer componente na faixa de peso, não apenas para o componente AdValorem)

2 - Passo a Passo para Resolver o Problema:

Acesse a tela de "Componentes de Frete":

Cadastros gerais>Configurações da empresa>Componentes de frete

Procure pelo componente de frete desejado:

Na tela de componentes de frete, busque pelo componente desejado que está sendo configurado para a rota, como exemplo AdValorem, TDE, TDA, Frete valor entre outros.

Verifique a opção "Utilizar em rotas":

No componente de frete, verifique se a opção "Utilizar em rotas" está marcada.

Caso não esteja, selecione a opção para ativá-la. Isso permitirá que o componente seja utilizado nas rotas.

![Imagem 1: Caso não esteja, selecione a opção para ativá-la. Isso permitirá que o componente seja utilizado nas rotas.](https://ajuda.sankhya.com.br/hc/article_attachments/44013448365975)

Verifique a faixa do componente de frete:

Identifique o tipo de faixa que será utilizada pelo cliente para este componente (por exemplo, peso cubado, peso nominal, valor da mercadoria etc.).

Assim, marque os tipos de faixa nas quais esse componente será utilizado:

![Imagem 2: Assim, marque os tipos de faixa nas quais esse componente será utilizado:](https://ajuda.sankhya.com.br/hc/article_attachments/44013448507671)

Salve as alterações:

Após realizar as alterações necessárias, clique em "Salvar" para garantir que as configurações sejam aplicadas corretamente.

![Imagem 3: Após realizar as alterações necessárias, clique em "Salvar" para garantir que as configurações sejam aplicadas…](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1962967086/814581bd0c4d5ef65067ea6b072f/48DB9AC31F305B1A2EC3719122FC8D6B?expires=1791331200&signature=d449a1b21f7db2dfcfab9eb950fd334fddc53ed013aba702a76634b33d096030&req=dSkhFMB4moFXX%2FMW3nq%2BgeJw98VJQaDTs2665tK%2Bp0YQFffOjEhww9y01g6O%0A8MICIdwfmK8j12%2BJhf5WrR1YnTM%3D%0A)

Após salvar, volte ao cadastro da rota e verifique se o componente desejado está agora visível e disponível para inserção.
