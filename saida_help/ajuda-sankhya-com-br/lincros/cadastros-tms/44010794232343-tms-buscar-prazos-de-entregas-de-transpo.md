# [TMS] - Buscar prazos de entregas de transportadoras por localização

**Menu**: Cadastros Gerais > Transportadoras > Negociações > Prazos de Entregas > Transportadoras

**Objetivo**: Como realizar a busca de prazos de entregas das transportadoras pela localização

## Considerações:

- Para realizar a busca de prazos de entregas das transportadoras pela localização, é necessário ter os cadastros abaixo:

- [Prazos de Entrega - Transportadora](https://sankhya.zendesk.com/hc/pt-br/articles/44010794232343)

Abaixo segue os procedimentos para realizar a busca:

1. Acessar o menu: Cadastros Gerais > Transportadoras > Negociações > Prazos de Entregas > Transportadoras;
2. Caso não saiba o número da rota poderá ainda buscar por Código, Nome da rota, Origem, Faixa, Destino, Prazo, Modal, Transportadora;
3. Neste exemplo, vamos localizar pelo código '393080' (rota Blumenau X Capital : Blumenau / Osasco);

![Imagem 1: Neste exemplo, vamos localizar pelo código '393080' (rota Blumenau X Capital : Blumenau / Osasco);](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963102862/0755350b3c2f386dd3b926a0efdf/7605F6E8D0AB816944B58A40B56237AA?expires=1791331200&signature=26bbe72fdfef447c780c30148d065cf7f70fa8591a7d2ba5046b79cf1e4d51bd&req=dSkhFch%2Bn4lZW%2FMW3nq%2BgXKbJrfhEXgEbNR9pDuTBRAMi8s9S1MT7hTqUgu%2F%0ALQzEC32pKdXseeO%2F2XymdqfWrTk%3D%0A)

4. Após, entrar na tela da rota, na aba 'Cadastro' localize a opção 'Localização' e clique no botão 'Detalhar';

![Imagem 2: 4. Após, entrar na tela da rota, na aba 'Cadastro' localize a opção 'Localização' e clique no botão 'Detalhar';](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963102885/6d1a21574993583b2c641ceb6252/0C16E8960294AAAB07E45622B006A6B8?expires=1791331200&signature=2345c8ca5d8d3a06c97a3325ccfeaf0446868c3f3a6bb5c222efbc309cc94559&req=dSkhFch%2Bn4lXXPMW3nq%2BgQhM37S8E4qZ4KQE96dYiaQWBHK%2B5Zp9qk6XabZa%0AkksunL7ZmU%2BX8jAK5FIJVMrHPxU%3D%0A)
