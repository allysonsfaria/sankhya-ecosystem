# [TMS] - Erro 'no transaction is in progress' ao importar tabela de negociações de frete

**Menu**: Cadastros Gerais > Transportadoras > Negociações > Tabelas de Frete

**Objetivo**: Como corrigir o erro 'no transaction is in progress' ao realizar a importação da tabela de negociações de frete

**Considerações**:

- É necessário ter o cadastro da transportadora, regiões, rotas no sistema;

Segue abaixo os procedimentos:

1. Acessar o menu: Cadastros Gerais > Transportadoras > Negociações > Tabelas de Frete;
2. Clicar na opção 'Importar';
3. Adicionar a planilha no qual será importada;
4. Clicar em 'upload';
5. Verificar que irá apresentar a mensagem abaixo:

![Imagem 1: Verificar que irá apresentar a mensagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44013313378199)

 6. Para corrigir este problema, deve-se verificar na planilha se não existe nenhum componente com falta de informação (onde o campo seja de preenchimento obrigatório);

 7. No exemplo abaixo o componente que está incorreto é o 'TDA'; Neste caso, deve-se orientar o cliente a preencher corretamente a coluna com as informações;
