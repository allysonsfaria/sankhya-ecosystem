# [TMS] - Como Adicionar a Opção de Frete Peso - Valor Mínimo na Tabela de Frete

## 1º Problema Relatado pelo Cliente:

O cliente relatou que, ao tentar cadastrar uma tabela de frete, não encontrou a opção para adicionar o componente "Frete Peso - Valor Mínimo". A dificuldade estava em localizar essa opção na configuração da tabela de frete para poder aplicá-la corretamente.

## 2º Passo a Passo para Resolver o Problema:

## 1. Acessar a Tela de Configuração de Componentes de Frete:

Acesse: "Cadastros Gerais > Configurações da Empresa > Componentes de Frete".

Isso abrirá a tela de Componentes de Frete, onde todos os componentes disponíveis para adição serão exibidos.

![Imagem 1: Isso abrirá a tela de Componentes de Frete, onde todos os componentes disponíveis para adição serão exibidos.](https://ajuda.sankhya.com.br/hc/article_attachments/44013444205207)

Na tela de Componentes de Frete, localize o campo "Código". Utilize o filtro para buscar o componente "fretepeso".

![Imagem 2: Na tela de Componentes de Frete, localize o campo "Código". Utilize o filtro para buscar o componente "fretepeso".](https://ajuda.sankhya.com.br/hc/article_attachments/44013459208727)

Após selecionar o componente desejado, a tela de Edição de Componente de Frete será aberta, permitindo que você faça as alterações necessárias.

## 2. Parametrizar o Componente:

Na tela de Edição de Componente de Frete, localize as opções "Tipo de Faixa" e "Valores".

![Imagem 3: Na tela de Edição de Componente de Frete, localize as opções "Tipo de Faixa" e "Valores".](https://ajuda.sankhya.com.br/hc/article_attachments/44013451017367)

a. Em "Tipo de Faixa", selecione o tipo de faixa em que o componente será aplicado na tabela de frete.

b. Em "Valores", defina o tipo de valor que o componente utilizará, como "Mínimo", "Máximo" ou "Percentual".

## 3. Salvar a Configuração:

Após parametrizar o componente de frete, clique em "Salvar" para aplicar as alterações.

Verifique se o componente configurado aparece corretamente na tabela de frete.
