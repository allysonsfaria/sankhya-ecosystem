# [TMS] - Como Adicionar mais de um  Componentes com restrição nas Tabelas de Frete

## 1 - Problema Relatado pelo Cliente:

O cliente informou que precisa adicionar mais de um componente idêntico nas tabelas de frete na aba componentes com restrição, mas encontrou dificuldades ao tentar usar a opção "Adicionar Componente" ao lado da barra de pesquisa. O cliente relatou que a solução desejada era a possibilidade de incluir múltiplos componentes do mesmo tipo, o que não estava sendo possível com a funcionalidade disponível.

## 2 - Passo a Passo para Resolver o Problema:

1. Acesse a Tabela de Frete:

   - Acesse o caminho > Cadastros gerais > Transportadoras > Negociações > Tabelas de Frete.

2. Selecione a Tabela de Frete:

   - Clique na tabela de frete desejada.

3. Acesse a Aba de Componentes com Restrição:

   - Dentro da tabela selecionada, vá até a aba '**Componentes com restrição**'.

4. Utilize a Barra de Pesquisa:

- Clique na barra de pesquisa, e digite o nome ou código do componente que deseja adicionar (por exemplo, "TDE").
- Selecione o componente desejado na lista que aparecerá.

  ![Imagem 1: Selecione o componente desejado na lista que aparecerá.](https://ajuda.sankhya.com.br/hc/article_attachments/44013434499863)

5. Defina o Valor para o Componente:

   - Após adicionar o componente, informe o valor que deseja atribuir a ele no campo correspondente.

![Imagem 2: - Após adicionar o componente, informe o valor que deseja atribuir a ele no campo correspondente.](https://ajuda.sankhya.com.br/hc/article_attachments/44013445056663)

6. Informe as Pessoas para Cobrança:

   - Defina as "Pessoas" que devem ser consideradas para a cobrança deste valor, conforme necessário.

![Imagem 3: - Defina as "Pessoas" que devem ser consideradas para a cobrança deste valor, conforme necessário.](https://ajuda.sankhya.com.br/hc/article_attachments/44013434734871)

7. Evite Usar a Opção de "Adicionar Componente":

- Para adicionar mais de um mesmo componente, não utilize a opção de "Adicionar Componente" ao lado da barra de pesquisa.
- Em vez disso, sempre utilize a barra de pesquisa para selecionar o componente e adicioná-lo novamente.

Este procedimento garante que múltiplos componentes idênticos sejam adicionados corretamente à tabela de frete para que possa ser utilizado 'Valores' e 'Pessoas' diferentes para o mesmo componente, sem erros e sem a utilização da opção errada.
