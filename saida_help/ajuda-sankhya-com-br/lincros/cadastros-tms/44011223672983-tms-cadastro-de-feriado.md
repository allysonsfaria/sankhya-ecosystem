# [TMS] - Cadastro de Feriado

**Menu**: Cadastros Gerais > Configurações de Empresa > Gerais > Feriados

**Objetivo**: Como realizar o cadastro de feriados

**Considerações**:

- Possui acesso ao respectivo menu;

Abaixo segue os procedimentos:

1. Acessar o menu: Cadastros Gerais > Configurações de Empresa > Gerais > Feriados;
2. Clicar na opção 'Novo';
3. Preencher os seguintes campos que são de preenchimento obrigatório:

**Descrição**: Informar o nome do feriado;

**Data**: Informar qual a data do feriado;

**Localização**: Informar a onde será localizado o feriado;

Obs.: Ao marcar a opção Permanente, o sistema irá considerar o feriado para todos os anos seguintes, não havendo portanto necessidade de atualizar anualmente.
