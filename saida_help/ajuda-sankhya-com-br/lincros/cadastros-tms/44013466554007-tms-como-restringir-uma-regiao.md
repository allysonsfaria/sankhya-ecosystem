# [TMS] - Como restringir uma região

## 1 - Problema Relatado pelo Cliente:

O cliente solicitou orientações sobre como restringir uma região dentro da tabela de fretes no sistema. A dúvida envolvia como limitar a cobertura de frete para uma cidade específica dentro de uma região cadastrada.

---

## 2 - Passo a Passo para Resolver o Problema:

**Considerações Importantes:**

- É necessário ter o cadastro de regiões previamente configurado no sistema.

**Procedimento:**

1. Acesse o menu: **Cadastros gerais > Transportadoras > Negociações > Regiões**.
2. Localize a região onde você deseja aplicar a restrição de cidade.
3. Na aba **“Restrições”**, informe a cidade que deseja restringir.
4. Clique no campo que consta a lupa, informe a cidade que deseja restringir e clique no botão de mais (+)

   ![Imagem 1: Clique no campo que consta a lupa, informe a cidade que deseja restringir e clique no botão de mais (+)](https://ajuda.sankhya.com.br/hc/article_attachments/44013445949335)
5. Após o processamento, verifique se a cidade foi adicionada corretamente na aba **“Restrições”**.
6. Clique em **“Salvar”** para finalizar o processo.

**Resultado Esperado:**
Após salvar, a cidade estará restrita dentro da região selecionada na tabela de fretes.
