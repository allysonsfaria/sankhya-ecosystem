# [TMS] - Tipos de Documentações

**Menu**: Cadastros gerais > Documentação > Tipos de documentação

**Objetivo**: Cadastrar um tipo de documentação para ser possível realizar o cadastro de documentações atreladas a este tipo;

**Considerações**:

- Possuir a necessidade de cadastrar documentações;

## Como cadastrar um tipo de documentação

1. Acesse o Menu: Cadastros gerais > Documentação > Tipos de documentação;
2. Clique em "Novo";

   ![Imagem 1: Clique em "Novo";](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1964964919/dbe21fd92531f59718e18edc3f96/F10BEFF797885043FB585B90911FC109?expires=1791331200&signature=8f7d2eb66cb1910232d9fd58df9503305ced140c08cdde66c94bfcd4371eb7d6&req=dSkhEsB4mYheUPMW3nq%2BgRJR7Lqpd9%2BwLCnU%2F9ediLUlXhHC4DPU3f6Fm92I%0AoRzxq2q1Emx1TQ0lWNEbNMTJjGo%3D%0A)
3. Deve ser informado o código, nome e abrangência, e na opção escopo, informar se este tipo de documentação será vinculado a documentação de motorista, de veículo, ou de transportadora;

   ![Imagem 2: Deve ser informado o código, nome e abrangência, e na opção escopo, informar se este tipo de documentação será…](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1964964931/8d4f5383e979db814bb8df1beb7b/1BB5FF4362BD62E6AA2E4816EAF99A2E?expires=1791331200&signature=1ca4cdd5c04f648c1e7cf61a2dcd39547101606c1124d3592a33b90e6a744a88&req=dSkhEsB4mYhcWPMW3nq%2BgTZ8rg9mGWNemC6sQRGThgxWedZaKi%2BYrbvsbInU%0AYUOfxuIcR0GhYqdgluKvM5c17P0%3D%0A)
4. Em seguida, clique em "Salvar" para finalizar o cadastro do tipo de documentação.

**Obs**: Após esse cadastro, já será possível realizar o **[Cadastro de Documentações](https://sankhya.zendesk.com/hc/pt-br/articles/44010855668375)** e vincular à este tipo de documentação.

Os campos marcados com '\*' são de preenchimento obrigatório
