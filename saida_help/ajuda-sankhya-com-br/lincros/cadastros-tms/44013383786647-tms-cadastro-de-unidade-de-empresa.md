# [TMS] - Cadastro de Unidade de Empresa

**Menu**: Cadastros Gerais > Unidades da Empresa > Unidades

**Objetivo**: Como realizar o cadastro de uma unidade na empresa

**Considerações**:

- É necessário possuir o campo 'Pessoa' já cadastrados no TMS para o cadastro da nova unidade;

## Passo a passo

Para o cadastro de unidade é necessário informar os seguintes campos:

1. **Código**: Informe um código para esta unidade;
2. **Sigla**: Informe uma sigla para esta unidade;
3. **Pessoa**: Informe uma pessoa que será vinculada a unidade;

Abaixo segue os procedimentos de como realizar o cadastro de unidade:

1. Acessar o menu: Cadastros gerais > Unidades da Empresa > Unidades;
2. Clicar na opção 'Novo';
3. Preencher os campos obrigatórios (marcados com asterisco);
4. Clicar na opção 'Salvar;
