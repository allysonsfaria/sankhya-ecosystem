# [TMS] - Cadastro de portaria

**Menu**: Cadastros gerais > Portaria > Cadastro

**Objetivo:** Como realizar o cadastro de uma nova portaria no sistema.

## Considerações:

- Possuir a necessidade de cadastrar uma nova portaria, para utilizá-la em rotinas da operação;
- Possuir permissão de acesso ao menu;

Abaixo segue os procedimentos:

## Cadastrando uma nova portaria

1. Para cadastrar um nova portaria, acessar o menu: Cadastros gerais > Portaria > Cadastro, e clicar em 'Novo';

   ![Imagem 1: Para cadastrar um nova portaria, acessar o menu: Cadastros gerais > Portaria > Cadastro, e clicar em 'Novo';](https://ajuda.sankhya.com.br/hc/article_attachments/44011303746071)
2. Após clicar em 'Novo', preencher os campos obrigatórios do cadastro, sendo estes:

- Nome;
- Unidade (Determina a qual Unidade essa portaria pertencerá);

Os demais campos não são de preenchimento obrigatório, sendo opcional a inclusão de informações.

![Imagem 2: Os demais campos não são de preenchimento obrigatório, sendo opcional a inclusão de informações.](https://ajuda.sankhya.com.br/hc/article_attachments/44011283984663)

3. Logo abaixo temos o campo 'Operação', que informa se a portaria será somente de entrada/saída de veículos, ou ambas as opções:

![Imagem 3: 3. Logo abaixo temos o campo 'Operação', que informa se a portaria será somente de entrada/saída de veículos, ou ambas…](https://ajuda.sankhya.com.br/hc/article_attachments/44011286631831)

4. Em seguida temos o campo 'Configurações da portaria' que define se a portaria poderá operar sem a necessidade de docas cadastradas, e se ela estará apta para validar os pedidos de carga e descarga pela alçada de aprovação:

![Imagem 4: 4. Em seguida temos o campo 'Configurações da portaria' que define se a portaria poderá operar sem a necessidade de…](https://ajuda.sankhya.com.br/hc/article_attachments/44011296037655)

5. Abaixo temos o campo 'Balança', pode ser vinculado a portaria caso a empresa utilize essa ferramenta, lembrando que a balança deve estar previamente cadastrada no sistema para ser vinculada a portaria:

![Imagem 5: 5. Abaixo temos o campo 'Balança', pode ser vinculado a portaria caso a empresa utilize essa ferramenta, lembrando que…](https://ajuda.sankhya.com.br/hc/article_attachments/44011271523351)

 6. Em seguida temos o campo 'Docas'. Uma portaria pode estar vinculada a várias docas. lembrando que as docas devem estar previamente cadastrada no sistema para ser vinculada a portaria:

![Imagem 6: 6. Em seguida temos o campo 'Docas'. Uma portaria pode estar vinculada a várias docas. lembrando que as docas devem…](https://ajuda.sankhya.com.br/hc/article_attachments/44011284421655)

 7. Logo abaixo temos o campo 'Operadores', esse campo você determina quais são os funcionários da empresa que terão acesso as informações dessa portaria;

**Importante**: Lembrando que os usuários devem estar previamente cadastrada no sistema para ser vinculada a portaria.

![Imagem 7: Importante : Lembrando que os usuários devem estar previamente cadastrada no sistema para ser vinculada a portaria.](https://ajuda.sankhya.com.br/hc/article_attachments/44011296463511)

8. Finalizando o preenchimento de todos os campos obrigatórios e os demais que se fizerem necessários, basta clicar em 'Salvar'.

 "Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos"
