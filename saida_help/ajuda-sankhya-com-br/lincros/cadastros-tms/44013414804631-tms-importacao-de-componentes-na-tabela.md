# [TMS] - Importação de componentes na tabela de fretes

## 1 - Problema Relatado pelo Cliente:

O cliente informou a necessidade de assistência para importar as taxas de TDE, TDA e TVD na tabela de fretes, que são atualizadas semanalmente conforme um arquivo de novos clientes recebido. O objetivo é atualizar as taxas complementares para os clientes presentes na tabela de fretes.

## 2 - Passo a Passo para Resolver o Problema:

1.Acessar a Tabela de Fretes:

Navegue até o menu Cadastros Gerais>  Transportadoras >Negociações >Tabelas de Frete.

2.Selecionar a Transportadora:

Na tela de tabelas de frete, selecione a transportadora que deseja atualizar.

Clique na opção Exportar para gerar o arquivo da tabela de frete da transportadora.

3.Exportar a Tabela:

Após selecionar a transportadora, confirme a exportação clicando em **Sim**.

O arquivo será enviado para o e-mail cadastrado, permitindo a edição.

![Imagem 1: O arquivo será enviado para o e-mail cadastrado, permitindo a edição.](https://ajuda.sankhya.com.br/hc/article_attachments/44013397916439)

![Imagem 2: O arquivo será enviado para o e-mail cadastrado, permitindo a edição.](https://ajuda.sankhya.com.br/hc/article_attachments/44013442105111)

4.Editar as Informações:

Abra o arquivo recebido por e-mail.

![Imagem 3: Abra o arquivo recebido por e-mail.](https://ajuda.sankhya.com.br/hc/article_attachments/44013415235479)

Insira as taxas de TDE, TDA e TVD conforme os dados necessários.

5.Finalizar a Importação:

Após a edição, salve o arquivo e importe os dados para o sistema, garantindo que as taxas estejam corretamente atualizadas.

![Imagem 4: Após a edição, salve o arquivo e importe os dados para o sistema, garantindo que as taxas estejam corretamente…](https://ajuda.sankhya.com.br/hc/article_attachments/44013398251543)

Observação:  Caso precise de apoio para preenchimento da planilha, tem um modelo que fornece um formato pré-estabelecido para facilitar a inserção das informações
