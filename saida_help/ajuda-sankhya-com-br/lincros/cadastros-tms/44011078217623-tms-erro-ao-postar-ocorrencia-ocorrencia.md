# [TMS]  Erro ao Postar Ocorrência: Ocorrência Não Encontrada para a Transportadora Específica.

1 - Problema Relatado pelo Cliente: O cliente relatou que, ao tentar postar ocorrências para uma Nota Fiscal, a ocorrência não estava disponível para seleção. Mesmo após a NF aparecer corretamente no sistema, a ocorrência necessária não era localizada. Esse artigo serve para todas as ocorrências, não limitada a uma ocorrência específica.

![Imagem 1: 1 - Problema Relatado pelo Cliente: O cliente relatou que, ao tentar postar ocorrências para uma Nota Fiscal, a…](https://ajuda.sankhya.com.br/hc/article_attachments/44011048496791)

2 - Passo a Passo para Resolver o Problema:

1. Acessar o Cadastro de Ocorrências da Transportadora:

   - No menu principal, vá até: **Cadastros gerais > Transportadoras > Ocorrências > Transportadora**
2. Verificar se a Transportadora Possui a Ocorrência Cadastrada:

   - Localize a transportadora no sistema.
   - Confira se o número da ocorrência está disponível.
   - Se a ocorrência não estiver cadastrada, prossiga com os próximos passos.
   - ![Imagem 2: Se a ocorrência não estiver cadastrada, prossiga com os próximos passos.](https://ajuda.sankhya.com.br/hc/article_attachments/44011037126295)
3. Copiar Ocorrências de Outra Empresa:

   - Clique na opção **"Copiar empresa"**.
   - ![Imagem 3: Clique na opção "Copiar empresa" .](https://ajuda.sankhya.com.br/hc/article_attachments/44011064686359)
   - Na tela que abrir, utilize o filtro para localizar a transportadora que você deseja adicionar a ocorrência.
   - Escolha as ocorrências que deseja adicionar.
   - ![Imagem 4: Escolha as ocorrências que deseja adicionar.](https://ajuda.sankhya.com.br/hc/article_attachments/44011078814487)
4. Salvar e Validar a Configuração:

   - Após selecionar as ocorrências, clique em **Salvar**.
   - Retorne à funcionalidade de postagem de ocorrências e verifique se a ocorrência está disponível.
   - ![Imagem 5: Retorne à funcionalidade de postagem de ocorrências e verifique se a ocorrência está disponível.](https://ajuda.sankhya.com.br/hc/article_attachments/44011049050903)
   - Caso o problema persista, entre em contato com o suporte técnico para análise mais detalhada.

Este artigo orienta sobre a solução para o erro ao postar a ocorrência em uma NF, quando a ocorrência não é localizada para uma transportadora específica. O problema ocorre porque a transportadora não possui a ocorrência cadastrada. Para resolver, é necessário acessar o cadastro de ocorrências da transportadora e copiar as ocorrências desejadas de outra empresa como base.
