# [TMS] - Ajuste da Alíquota de ISS para Municípios no TMS

## 1 - Problema Relatado pelo Cliente:

O cliente relatou que o sistema está calculando incorretamente a alíquota de ISS da transportadora para entregas no município de Embu das Artes com a taxa de X%, quando, na realidade, a taxa municipal vigente é de Y%.

## 2 - Passo a Passo para Alterar a Taxa Municipal de ISS:

Siga as etapas abaixo para corrigir a alíquota de ISS de no TMS:

**Acesse as configurações:**

- No menu principal, clique em **Cadastros Gerais >** **Configurações da Empresa > Taxas > Taxas Municipais**

![Imagem 1: No menu principal, clique em Cadastros Gerais > Configurações da Empresa > Taxas > Taxas Municipais](https://ajuda.sankhya.com.br/hc/article_attachments/44013458024983)

**Filtre pelo município:**

- Utilize os campos de Código ou Cidade para localizar o município em questão.
- ![Imagem 2: Utilize os campos de Código ou Cidade para localizar o município em questão.](https://ajuda.sankhya.com.br/hc/article_attachments/44013443414295)
- Selecione o município desejado, clicando no código dele, o que o redirecionará para a tela de **Edição de taxa municipa**l.

**Ajuste a alíquota municipal:**

- Na tela de edição, localize o campo **Alíquota Município**.
- Altere o valor da alíquota de "X%" para "Y%", conforme a alíquota correta para o município desejado.

![Imagem 3: Altere o valor da alíquota de "X%" para "Y%", conforme a alíquota correta para o município desejado.](https://ajuda.sankhya.com.br/hc/article_attachments/44013419589911)

**Salve as alterações:**

- Após inserir o valor correto, clique em **Salvar** para finalizar a atualização da alíquota.
