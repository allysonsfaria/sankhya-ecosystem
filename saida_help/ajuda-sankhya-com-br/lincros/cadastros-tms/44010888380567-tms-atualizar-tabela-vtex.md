# [TMS] - Atualizar tabela VTEX

Este é um artigo complementar. Para saber mais sobre a integração Lincros com VTEX acesse [este artigo](https://sankhya.zendesk.com/hc/pt-br/articles/44010754196759).

## Objetivo:

Este artigo tem como objetivo instruir como atualizar valores de uma tabela de frete já cadastrada na plataforma VTEX

## Pré-requisitos:

Possuir habilitada a funcionalidade da Integração VTEX.

Possuir a integração com a VTEX configurada.

Possuir tabela previamente cadastrada na plataforma VTEX (saiba como realizar [clicando aqui](https://sankhya.zendesk.com/hc/pt-br/articles/44010804994711))

---

## Instruções:

- No TMS caso ocorra alteração da tabela de fretes é possível efetuar a atualização diretamente pelo botão 'Atualizar tabela VTex' disparando a integração, sem a necessidade de exportar a tabela para o e-mail e importá-la novamente de forma manual na VTex.
- Para atualizar a Tabela VTEX, incialmente é preciso cadastrar, dentro da tabela de fretes, o Id Política Envio Vtex, que deve ser preenchido com o mesmo ID cadastrado na política na VTex.
- Após preencher essa informação, é necessário salvar a tabela.
- Após disparar a integração é possível consultar o andamento na tela de Log de integração VTex (Sistema > Envios de Integração > Log de integração Vtex).
