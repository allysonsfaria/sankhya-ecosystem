# [TRK] - Ajuste do Raio de Atendimento de um Cliente no Sistema

## 1. Problema Relatado pelo Cliente

O cliente questionou sobre a possibilidade de ajustar o Metros Raio de um cadastros de cliente específico no Tracking. O cliente deseja alterar o valor do raio para atender a uma necessidade específica de localização de entrega de pedido.

## 2. Passo a Passo para Resolver o Problema

Para ajustar o raio de atendimento de um cliente, é importante que seu usuário possua o perfil **Manager**ou algum outro perfil personalizado com acesso aos cadastros. Em seguida, realize os seguintes passos:

1. **Acesso ao Cadastro do Cliente**:

   - Acesse o sistema e vá até **Menu > Cadastros > Cliente**.
2. **Localização do Cliente**:

   - Utilize os filtros por nome ou código, para localizar o cliente desejado.
3. **Alteração do Raio de Atendimento**:

   - Na lateral esquerda, seleciona o ícone do lápis, para editar o cadastro
   - Já no cadastro do cliente, localize o campo **Metros Raio**.
   - Insira o novo valor desejado para o raio de atendimento.
4. **Salvar as Alterações**:

   - Após inserir o novo valor, clique na opção **Salvar** para garantir que as modificações sejam aplicadas corretamente.
