# [Tracking] Lacrar Coordenadas

## Objetivo

Este artigo tem como a finalidade mostrar como lacrar as coordenadas de determinado cliente que está deslacrado.

## Caminho

No sistema gestão de entregas, acessar em:  **Menu > CADASTROS > CLIENTES**

![Imagem 1: No sistema gestão de entregas, acessar em: Menu > CADASTROS > CLIENTES](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1965145157/c4ec72887c181695ab261deffedd/825C4BAAE890E727153CC931FE3A514B?expires=1791331200&signature=bf47c4d88c3f0395f6a4b27a9a2d99f27e0fd4a7d51840d54bad9fa0757f80e5&req=dSkhE8h6mIBaXvMW3nq%2Bgfw5p07h9ScaWKN%2FlP7zIuW7LMz1M8RjQ8nniNLA%0A%2FAawGpPlhEJ8m42TEgJrovg8ZQ0%3D%0A)

## Passo a Passo

 Ao identificar que um cliente está deslacrado, acessar o cadastro do mesmo,

![Imagem 2: Ao identificar que um cliente está deslacrado, acessar o cadastro do mesmo,](https://ajuda.sankhya.com.br/hc/article_attachments/44011038784535)

É possível acessar o cadastro do cliente pelo caminho informado anteriormente ou pelo atalho clicando diretamente no cliente dentro de qualquer entrega,

![Imagem 3: É possível acessar o cadastro do cliente pelo caminho informado anteriormente ou pelo atalho clicando diretamente no…](https://ajuda.sankhya.com.br/hc/article_attachments/44011066439063)

Uma vez no cadastro do cliente, editar o mesmo clicando no seguinte ícone

![Imagem 4: Uma vez no cadastro do cliente, editar o mesmo clicando no seguinte ícone](https://ajuda.sankhya.com.br/hc/article_attachments/44011066566039)

Já na tela de edição, inserir as coordenadas juntamente com o raio e validar clicando no botão **SALVAR.**

Ao salvar, o sistema irá confirmar o procedimento com uma mensagem de validação.

![Imagem 5: Ao salvar, o sistema irá confirmar o procedimento com uma mensagem de validação.](https://ajuda.sankhya.com.br/hc/article_attachments/44011066752279)

## Importante

Para que a funcionalidade de lacrar coordenadas de clientes funcione normalmente, é necessário que o parâmetro **"Habilitar lacrar localização do cliente"** esteja habilitado.

![Imagem 6: Para que a funcionalidade de lacrar coordenadas de clientes funcione normalmente, é necessário que o parâmetro…](https://ajuda.sankhya.com.br/hc/article_attachments/44011084585751)

Caso contrário a funcionalidade não ficará ativa para o usuário.
