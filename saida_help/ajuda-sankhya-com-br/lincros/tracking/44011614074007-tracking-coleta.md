# [Tracking] Coleta

## Objetivo

Este artigo tem como a finalidade descrever o que seria uma operação de coleta e como utilizar a mesma no sistema Gestão de Entregas.

## Conceito

A Coleta significa coletar algo em determinado cliente, isto é, o motorista irá recolher determinado item em local específico.

## Como utilizar?

A integração de coletas é realizada via integração de planilha ou XML (caso utilizar webservice), e existem duas modalidades de integração de coletas, a que já sabemos que a rota do motorista irá realizar coleta (neste caso, enviando a coleta no arquivo de rotas MDM001) e a que o motorista já se encontra em rota, e lhe informam que será necessário realizar a coleta (neste outro caso, se envia a coleta através do arquivo MDM014).

## Pontos importantes

- Para uma importação aconteça corretamente, é necessário que o parâmetro "IMPORTAR COLETAS" esteja ativo.

- Para coletas do tipo com rota em andamento, é necessário que se envie a mesma através da seguinte integração,

![Imagem 4: Para coletas do tipo com rota em andamento, é necessário que se envie a mesma através da seguinte integração,](https://ajuda.sankhya.com.br/hc/article_attachments/44011621678231)
