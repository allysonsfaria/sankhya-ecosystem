# [Tracking] - Como realizar a redefinição de senha do usuário

**Menu**: Tela inicial do sistema

**Objetivo**: Como realizar a redefinição de senha do usuário

**Considerações**:

- Possuir um usuário previamente cadastrado e ativo no sistema

Abaixo segue os procedimentos:

1. Acessar a página inicial do sistema;
2. Selecionar a opção 'Esqueci minha senha';

   ![Imagem 1: Selecionar a opção 'Esqueci minha senha';](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963130786/2a4677c84b8e01700f8a9819ef0a/D48AE7D75A01E5B09AFC6BBAA951FAD1?expires=1791331200&signature=8f9a7664f2a153e9f968cb7e86bc62cb3cd73bb7b09f96c59ba76a7ce9cc4807&req=dSkhFch9nYZXX%2FMW3nq%2BgcdNc72zVj0SRW3e5XpVp2%2B4XbfBWCbSdF2PZUMo%0AgbSdjxbekn6%2FnzK9OFJWjgALa%2B0%3D%0A)
3. Informar o endereço de e-mail do usuário que precisa de redefinição de senha;

   ![Imagem 2: Informar o endereço de e-mail do usuário que precisa de redefinição de senha;](https://ajuda.sankhya.com.br/hc/article_attachments/44010215284887)
4. Após, será enviado um e-mail com as instruções para redefinir a senha;
5. No e-mail constará um link para redirecionar ao site para cadastro de uma nova senha;

   ![Imagem 3: No e-mail constará um link para redirecionar ao site para cadastro de uma nova senha;](https://ajuda.sankhya.com.br/hc/article_attachments/44010183614871)
6. O link direcionará o usuário para o ambiente, na página de redefinição de senha;
7. Após criar a nova senha, e confirmar a mesma é só confirmar, e acessar novamente o ambiente;

   ![Imagem 4: Após criar a nova senha, e confirmar a mesma é só confirmar, e acessar novamente o ambiente;](https://ajuda.sankhya.com.br/hc/article_attachments/44010230213783)

## Login não reconhecido mesmo com o cadastro correto

Se o e-mail informado não for reconhecido mesmo com o usuário previamente cadastrado e ativo, verifique se o login está sendo digitado exatamente como foi cadastrado, incluindo maiúsculas e minúsculas. O campo de login diferencia maiúsculas de minúsculas (case-sensitive).
