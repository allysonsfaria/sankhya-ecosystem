# [Tracking] - Retroalimentação de Tempo de Espera não sobe ao Routing

## 1. Problema Relatado pelo Cliente

O cliente informou que a retroalimentação de tempo de espera dos clientes do Tracking para o Routing, não está sendo direcionada para os devidos depósitos.

## 2. Passo a Passo para Resolver o Problema

**Observação:**Caso não utilize a Retroalimentação de Tempo de Espera integrada com o Routing e deseje passar a utilizá-la, por gentileza, entre em contato com o Time de Suporte para que sejam realizadas as devidas configurações. Caso já tenha a funcionalidade configurada e, mesmo assim, não esteja integrando com o Routing, por favor, siga os passos abaixo.

Para corrigir a retroalimentação do tempo de espera e garantir que os depósitos recebam essas informações, é necessário ajustar o **Código Externo** no cadastro de depósito do sistema Tracking, utilizando o mesmo código de depósito do Routing.

Antes de seguir os passos abaixo, certifique-se de que seu usuário possui o perfil **Manager**ou outro perfil personalizado com acesso ao menu de cadastros no Tracking.

1. **Acesso ao Cadastro no Routing**:

   - No menu do sistema, vá para **Cadastros** e selecione **Depósito**.
   - Utilize o filtro para localizar o depósito correto caso possua mais de um depósito cadastrado em sua empresa.
2. **Obtenção do Código do Depósito no Routing**:

   - Ao localizar o depósito desejado, copie o código exibido ao lado do nome do depósito.

     ![Imagem 1: Ao localizar o depósito desejado, copie o código exibido ao lado do nome do depósito.](https://ajuda.sankhya.com.br/hc/article_attachments/44012474424855)
3. **Acesso aos Cadastros no Tracking**:

   - No menu do sistema, vá para **Cadastros** e selecione **Depósitos** no módulo **Tracking**.
4. **Identificação do Depósito Correspondente no Tracking**:

   - Localize o depósito que precisa ser informado/alterado o **Código Externo**.
5. **Edição do Depósito no Tracking**:

   - Clique no ícone de lápis ao lado do nome do depósito correspondente, para editá-lo.
6. **Alteração do Código do Depósito**:

   - No campo Código Externo do depósito no Tracking, informe ou substitua pelo código coletado no Routing

     ![Imagem 2: No campo Código Externo do depósito no Tracking, informe ou substitua pelo código coletado no Routing](https://ajuda.sankhya.com.br/hc/article_attachments/44012466285975)
7. **Salvar as Alterações**:

   - Após a atualização do código, clique em **Salvar** para confirmar as alterações feitas.

**Observação:**

Após concluir os passos acima, você poderá gerar novamente o relatório de Retroalimentação de Tempo de Espera para comunicação com o Routing.

Caso encontre dificuldades no processo, entre em contato com o time de suporte ao cliente da Lincros.
