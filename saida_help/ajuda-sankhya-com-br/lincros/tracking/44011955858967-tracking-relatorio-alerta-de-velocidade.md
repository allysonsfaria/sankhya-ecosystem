# [Tracking] - Relatório Alerta de Velocidade

**Menu:**Relatórios > Alerta de Velocidade

**Objetivo:** Como gerar o relatório de Alerta de Velocidade

## Considerações:

- Possuir veículos cadastrados;

Abaixo segue os procedimentos:

1. Na tela dos filtros do Relatório Alerta de Velocidade, possuímos os seguintes campos:

- **Unidade de Negócio**: Neste campo pode ser selecionado o CD específico ou Todos os CDs;
- **Transportadora**: Neste campo pode ser selecionados as transportadoras que vão ser informadas no relatório;
- **Data Inicial**: Data Inicial do período;
- **Data Final**: Data Final do período;
- **Motorista:** Caso desejar um motorista específico;
- **Veículo:** Caso desejar um veículo específico;

![Imagem 1: Veículo: Caso desejar um veículo específico;](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1963710411/f9416290c46f21c8a2d57dc373f0/73783E692B1E255C6DA4669FADFDF4B8?expires=1791331200&signature=f82187a3a8d6939a695a81475589e19e233c7f3173b5c34bf529b4c7d5e89fe6&req=dSkhFc5%2FnYVeWPMW3nq%2BgRqx4SllHE9FGrHmlCvKbVyrYqB3mXXmkSyQ2TJ6%0AHN5v%2BEeK8VQLHwPYvErZ%2FliIbTg%3D%0A)

**Obs.:** Quando se deixa os campos de busca em branco, eles buscam todas as informações

2. Após informar todos os campos, é possível visualizar o relatório na própria tela ou Exportar para um arquivo Excel ou CSV.

![Imagem 2: 2. Após informar todos os campos, é possível visualizar o relatório na própria tela ou Exportar para um arquivo Excel…](https://ajuda.sankhya.com.br/hc/article_attachments/44011942521367)
