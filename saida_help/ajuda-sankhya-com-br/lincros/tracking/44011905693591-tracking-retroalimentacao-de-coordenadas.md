# [Tracking] Retroalimentação de coordenadas para o Router

## Retroalimentação de Coordenadas

**Objetivo:**Enviar uma coordenada atualizada para o Routing

## Considerações:

- Para esta funcionalidade ser executada ela deve estar implantada dentro do Tracking.
- Para ser possível lacrar/deslacrar é necessário que tenha o parâmetro “Habilitar lacrar localização do cliente” ativado no Tracking.

## Enviar uma coordenada atualizada para o Routing.

Basta o usuário acessar o cadastro do cliente ou clicar sobre o cadeado na tela de monitoramento, editar, e salvar, e então será enviado para o Routing
