# [Tracking] - Dashboard

**Menu:** Tracking> Dashboard

**Objetivo**: Como interpretar o dashboard.

## Considerações:

- Possuir acesso aos dashboard;
- Para todos os gráficos, você tem disponível a opção de extração dos relatórios no formato .csv ou .xlsx;
