# [Tracking] Cadastro de Usuário Tracking

## Objetivo

Realizar cadastros de Novos usuários, definindo o que usuário poderá acessar.

Definir quais permissões poderá ser atribuído para cada usuário

## Caminho

Menu > Cadastros > Usuários

## Pré- Requisitos

Possuir perfil Administrador para ser possível cadastrar Novos Usuários

## Cadastro de Usuários

É possível cadastrar um Novo usuário pela tela de Cadastros de Usuários, onde pode ser definido o que usuário pode acessar e suas permissões.
