# [Tracking] Versão 4.9

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44011789315863)

## Release 4.9

## NOVIDADES

## Adicionar o campo CNPJ do cliente no Webservice de StatusRotasDetalhado

Disponibilizado do retorno do WebService StatusRotasDetalhado, na estrutura da entrega, abaixo do campoCdClienteNegocio, a informação “CNPJCliente”.

## Adicionar função "Baldeio" para ser configurado por "Perfil de usuário"

Disponibilizada nova permissão chamada “Autoriza Baldeio“ no perfil de usuário, onde será possível configurar o acesso à funcionalidade “Baldeio”. Com esta nova permissão de acesso, será possível disponibilizar a funcionalidade de Baldeio para perfis com acesso “Monitoramento-Somente Leitura.”

## MELHORIAS

## Tela Histórico de Nota Fiscal não carrega as informações

Para deixar mais claro o objetivo de uso da funcionalidade, alteramos o nome da mesma para “Histórico de Baldeio de Notas Fiscais” pois essa função serve única e exclusivamente para isso.

## Alterar horário de atendimento cadastro de Cliente em Massa

Cliente necessita realizar alteração do horário de atendimento dos cadastros de clientes de forma Massiva, no entanto, demos mais valor a essa funcionalidade, com possibilidade de integrar estes dados com o Lincros Routing posteriormente. Foi adicionado no sistema um recurso para alteração de dados de clientes em massa na tela de cadastro de clientes. Esta alteração estará concentrada nos seguintes atributos: Raio, LacrePDV, HorarioMatutinoInicial, HorarioMatutinoFinal, HorarioVespertinoInicial, HorarioVespertinoFinal, DiasRestricao, Ativo, Potencial.

![Imagem 4: Cliente necessita realizar alteração do horário de atendimento dos cadastros de clientes de forma Massiva, no entanto,…](https://ajuda.sankhya.com.br/hc/article_attachments/44011789779095)

## Criar um parâmetro para habilitar a notificação de parada para refeição

Criado parâmetro ("TempoNotificarMotoristaRefeicao") que possibilita habilitar a configuração por Unidade de Negócio em minutos, para que o aplicativo passe a gerar alertas para parada de refeição.

Na tela, no acordeão de Configurações Mobile, foi incluída a respectiva configuração com o texto: “Tempo para notificar parada de refeição” e o detalhe no ícone correspondente: “Define o tempo em rota que fará com que o motorista realize a parada para refeição. Quando vazio, não notificará o motorista.” A aplicação não deve permitir informar um valor inferior à 4hrs.

OBS.: Esta implementação ainda não tem efeito no Mobile pois, há alterações que precisam ser atualizadas no aplicativo do motorista; temos como previsão de implementar: final de Março.

## Criar referência de foto-evidência e Recebedor a uma Nota Fiscal

Para associar uma foto-evidência de entrega a uma nota fiscal fez-se necessário a criação do relacionamento entre uma foto-evidência a uma nota fiscal. A estrutura que armazena a foto à entrega já existia, portanto, apenas criamos o relacionamento com a nota fiscal através da mesma estrutura de dados.

OBS.: Esta implementação ainda não tem efeito no Mobile pois, há alterações que precisam ser atualizadas no aplicativo do motorista; temos como previsão de implementar: final de Março.

## CORREÇÕES

## Informações do relatório de Histórico de Nota Fiscal não estão corretas

Realizado os seguintes ajustes no relatório:

- Rotas não expurgadas não serão mais listadas;
- Quando selecionado os critérios de filtragem “Nota fiscal” ou “Pedido”, a data inicial e final não serão mais consideradas na busca;
- Alterada a ordem das colunas da seguinte forma:

  - Rota
  - Unidade Negócio
  - Data Rota
  - Nome
  - Placa
  - NF
  - Pedido
  - Cd Cliente Negócio
  - Nome Cliente
  - Peso
  - Valor Venda
  - Status
  - Valor Devolução
  - Data Início Parada Entrega
  - Data Entrega Realizada
  - Data Devolução
  - Motivo Devolução
  - Descrição Motivo
  - Área Responsável
- Alterada a descrição da coluna “Cd Cliente Negócio” para “Código do Cliente”;
- Alterada a descrição da coluna “Área Responsável” para “Área Responsável pela Devolução”;
- Alterada a descrição da coluna “Status” para “Situação da entrega”;
- Alterada a coluna “Nome” para “Nome do Cliente”;
- Alterada a colune “NF” para “Nota Fiscal”;

## Baldeio para coleta

Removido a obrigatoriedade de exibição de entregas para considerar também as coletas, com isso, sistema mostrará as coletas para realizar as baldeio.
