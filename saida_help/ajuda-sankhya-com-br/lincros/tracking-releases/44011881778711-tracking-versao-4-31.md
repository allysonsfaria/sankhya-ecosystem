# [Tracking] - Versão 4.31

![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/44011881947415)

**Melhorias**

**Carregamento da tela de monitoramento**

Realizada melhoria no carregamento da tela de Monitoramento. Para que quando o usuário tentar acessar a tela de Monitoramento, antes de ter acesso, seja exibida a tela de "Filtros.
A fim de que o  possa realizar um filtro mais detalhado, evitando assim possíveis impactos na aplicação geral.

## Criar parâmetro para habilitar ou desabilitar a funcionalidade de Múltiplas Entregas no App Lincros

Criado o parâmetro "Habilitar funcionalidade múltiplas entregas", para que seja possível habilitar ou desabilitar a funcionalidade de realizar múltiplas entregas pelo App Lincros.

Observação: O parâmetro irá vir por default como habilitado.

Caminho para acessar o parâmetro: Menu --> Cadastros --> Unidade de Negócio --> Configurações para Smartphone --> "Habilitar funcionalidade múltiplas entregas".

**Adicionar nome e documento do Tomador no Relatório de Devoluções Registradas**

Adicionadas as colunas "Nome do Tomador" e "Documento do Tomador" no Relatório de Devoluções Registradas.

---

**Parâmetro para permitir que o Conferente E-commerce realize toda a conferência de uma só vez**

Criado o parâmetro "Realizar conferência geral dos volumes", para que seja possível habilitar ou desabilitar a funcionalidade de conferência geral dos volumes pelo Conferente E-commerce.

Observação: Esse parâmetro irá vir por default desabilitado.

Caminho para acessar o parâmetro: Menu --> Cadastros --> Unidade de Negócio --> Configurações para o Smartphone --> "Realizar conferência geral dos volumes".

**Conclusão reescrita de importação de rotas**

Melhoria de performance na importação de rotas:

- Divisão em contextos de execução;
- Paralelização de atividades;
- Remoção de validações desnecessárias ou descontinuadas;
- Controle de status de importação (Importando/Concluído);
- Alteração nas consultas de rota para que considere somente rotas que estejam com status de importação Concluído.

---

**Retornar ao App informações necessárias para gerar a Parada**

Realizadas adequações para que sejam retornadas ao App Lincros as informações dos parâmetros "MetrosRaioParadaDesligado" e "MinutosParadaDesligado". O App precisa dessas informações para gerar uma parada ao utilizar o novo modelo de processamento de paradas.
