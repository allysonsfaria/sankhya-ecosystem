# [Routing] - Relatório de Integrações Automáticas

**Menu:** Relatórios > Integrações Automáticas

**Objetivo**: Como gerar as informações do relatório de integrações automáticas

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Neste relatório são apresentas as informações de integrações automáticas. Veja um exemplo abaixo:

![Imagem 1: Neste relatório são apresentas as informações de integrações automáticas. Veja um exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44010900033559)

1. **Depósito**: Selecione o depósito desejado;
2. **Data Início**: Informe uma data inicial;
3. **Data Fim:** Informe uma data final;
4. **Tipo**: Selecione um tipo: pedido, cliente, coordenadas, veículo, tipo de veículo, motorista;

## Exemplo do Relatório Integrações Automáticas

![Imagem 2: Exemplo do Relatório Integrações Automáticas](https://ajuda.sankhya.com.br/hc/article_attachments/44010884627735)

Caso houver necessidade, é possível exportar este relatório clicando no ícone 'Exportar'. O mesmo irá abrir em 'Excel'.

**Obs.:** Os campos que aparecem em vermelho são de preenchimento obrigatório.

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
