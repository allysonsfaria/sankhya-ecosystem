# [Routing] - Relatório Indicadores de Roteirização

**Menu:** Relatórios > Indicadores de Roteirização

**Objetivo**: Como gerar as informações do relatório de indicadores de roteirização

## Considerações:

- É necessário ter os campos abaixo já cadastrados no Router:

- [Depósito](https://intercom.help/ajudalincros/pt-BR/articles/14443341-routing-cadastro-de-deposito)

Neste relatório são apresentas as informações de indicadores de roteirização. Veja um exemplo abaixo:

![Imagem 1: Neste relatório são apresentas as informações de indicadores de roteirização. Veja um exemplo abaixo:](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1965172267/fe57e4c0e38c85ca2c7efdcbfda7/88E4F21E80F5E18F7A00A29AC4455E49?expires=1791227700&signature=66a9d5ce9b6353ba4ead4ac924e5361477f1daa2ae7eb4ab780a554eaa7da5ae&req=dSkhE8h5n4NZXvMW1HO4zSbODKos4o7KsrWvuwM4AQIANoI6DhBeDYtP6wxS%0ADoqH%0A)

1. **Depósito**: Selecione o depósito desejado;
2. **Data Início:** Informe uma data inicial;
3. **Data Fim**: Informe uma data final;

![Imagem 2: Exemplo do Relatório de Indicadores de Roteirização](https://lincros-20.intercom-attachments-7.com/i/o/xa2fv75n/1965172308/fe1fccffa5b69a67459d9dbacc75/A3DFFFE33BD1DBB9B07BCF7D32B7BE31?expires=1791227700&signature=d325f121267eb9f453a98eaebcff233cd42f9d0848ac2e49518cf52b558d1386&req=dSkhE8h5n4JfUfMW1HO4zTybL6JN4jxFnDrNxb8dxK%2FdiGnx1nJYgqj%2BuyWr%0AtjxN%0A)
