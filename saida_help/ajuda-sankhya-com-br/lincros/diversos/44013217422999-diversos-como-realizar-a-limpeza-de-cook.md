# [Diversos] - Como realizar a limpeza de cookies do navegador

**Objetivo:** Como realizar a limpeza de cookies do navegador

## Considerações:

Os procedimentos abaixo são relacionados a limpeza de cookies do navegador Chrome;

1. Na URL do navegador, clicar no ícone de exclamação, conforme imagem abaixo:

   ![Imagem 1: Na URL do navegador, clicar no ícone de exclamação, conforme imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44013217576855)
2. Selecionar a opção 'Cookies', conforme imagem abaixo:

   ![Imagem 2: Selecionar a opção 'Cookies', conforme imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44013244621079)
3. Irá abrir uma nova tela, clicar em cada link, conforme imagem abaixo;

   ![Imagem 3: Irá abrir uma nova tela, clicar em cada link, conforme imagem abaixo;](https://ajuda.sankhya.com.br/hc/article_attachments/44013265414423)
4. E depois clicar no botão remover (um link por vez), até remover todos, conforme imagem abaixo:

   ![Imagem 4: E depois clicar no botão remover (um link por vez), até remover todos, conforme imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44013232419863)
5. Para finalizar, clicar no botão 'Concluído'.

   ![Imagem 5: Para finalizar, clicar no botão 'Concluído'.](https://ajuda.sankhya.com.br/hc/article_attachments/44013245005463)
6. Pressione os botões CTRL + F5 do teclado para recarregar a página;

"Em atenção ao cumprimento de nossas políticas de segurança da informação e privacidade, alguns dados serão ocultados e protegidos".
