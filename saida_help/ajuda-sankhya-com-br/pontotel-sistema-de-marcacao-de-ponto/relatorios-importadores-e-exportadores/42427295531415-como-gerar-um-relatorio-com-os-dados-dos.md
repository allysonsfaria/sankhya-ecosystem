# Como gerar um relatório com os dados dos Locais de Trabalho

No site Pontotel Gestão é possível gerar um relatório dos dados dos locais de trabalho. Essa opção é essencial para a **gestão** da estrutura organizacional da sua empresa na plataforma. Este relatório gera um inventário detalhado de todos os locais de trabalho cadastrados, permitindo que você audite informações como código, empregador, endereço e status de sincronização com o REP-P.

---

## Como gerar o Relatório

1. No menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), selecione a opção **Relatórios e Registros**.
2. Na nova tela, clique no botão **"gerar relatório"**.

   ![Imagem 1: Na nova tela, clique no botão "gerar relatório" .](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_145g8r0.png)
3. No menu de navegação, clique no **ícone de sino** (Notificações), para acompanhar o arquivo ser gerado.
4. Quando chegar a "100%", o relatório será baixado automaticamente.
5. O relatório conterá todas as informações cadastrais dos locais de trabalho ativos na plataforma.

![Imagem 2: O relatório conterá todas as informações cadastrais dos locais de trabalho ativos na plataforma.](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_7p4exv.png)
