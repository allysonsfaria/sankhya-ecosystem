# Entenda sobre o arquivo E02 (Arquivo para importação de apontamentos)

O **E02 - Arquivo para importação de apontamentos** é um relatório vital para empresas que precisam integrar a plataforma Pontotel com outros sistemas, como o seu software de **folha de pagamento**.
Diferente de relatórios visuais como o R01 (Espelho de Ponto), o E02 gera um **arquivo de texto** (.TXT ou .CSV) formatado exatamente no **layout** que o outro sistema precisa para ler e importar os dados.

## Qual o objetivo do E02?

O objetivo principal do E02 é automatizar o **futuro** do seu fechamento de mês. Em vez de digitar manualmente os apontamentos (horas extras, adicionais noturnos, atrasos, faltas, etc.) no seu sistema de folha, você simplesmente exporta o arquivo E02 da Pontotel e o importa no seu outro software.
Isso torna o processo de **gestão** mais ágil, **simples** e reduz drasticamente a chance de erros manuais.

---

## Como é feita a configuração (parametrização) do E02?

Para que a plataforma Pontotel possa gerar o arquivo no formato exato que o seu sistema de folha de pagamento espera, é necessário um processo chamado **Parametrização**.
Essa parametrização (ou configuração do layout) é um serviço especializado realizado exclusivamente pela nossa equipe de Suporte.

### O que precisamos para configurar o E02?

Para que nossa equipe possa realizar a parametrização, é essencial que você forneça os seguintes documentos:

1. **O layout do seu sistema de folha de pagamento:**

   - Este é o documento técnico mais importante e deve ser fornecido pela equipe do seu software de folha (como Domínio, Senior, Totvs, entre outros). Alguns layouts já estão configurados na Pontotel, portanto, antes de iniciar a parametrização, verifique com o Analista se o layout desejado já está disponível.
   - O layout descreve exatamente o que o seu sistema espera em cada linha e coluna do arquivo de importação.
2. **O "de/para" das Verbas (rubricas):**

   - Uma lista ou planilha que correlaciona os apontamentos da Pontotel com os códigos (rubricas) do seu sistema de folha.
     - Exemplo:
       - "Hora Extra 50%" na Pontotel = Código "101" no seu sistema.
       - "Adicional Noturno" na Pontotel = Código "102" no seu sistema.
       - "Faltas" na Pontotel = Código "201" no seu sistema.
   - Solicite a planilha modelo ao Analista da Pontotel para preenchê-la conforme as instruções fornecidas.

   ⚠️ **Importante:** A parametrização do exportador E02 é um serviço personalizado e possui **custos adicionais**. Para sua configuração, é necessário informar o layout da folha de pagamento e os códigos/verbas que deverão ser utilizados na integração. Entre em contato com nossa equipe para consultar valores e solicitar a parametrização.

## Como solicitar a configuração do E02?

A configuração do arquivo E02 é um serviço personalizado que exige análise técnica, validação do layout da folha de pagamento e horas de desenvolvimento para adequação do arquivo às necessidades da empresa, portanto, possui custos adicionais.
Para consultar os valores, verificar a viabilidade do seu layout e dar os próximos passos para a integração com sua folha de pagamento, entre em contato conosco pelo chat integrado ao [site Pontotel Gestão](https://gestao.pontotel.com.br/#/cognito/login) ou pelo [WhatsApp](https://api.whatsapp.com/send/?phone=551131852700&text&type=phone_number&app_absent=0)
