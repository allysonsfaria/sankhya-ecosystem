# R13 - Como gerar o relatório com informações cadastrais dos funcionários

O relatório R13 é uma ferramenta fundamental para o RH e gestores que precisam ter uma visão consolidada das informações cadastrais de todos os colaboradores da empresa. Com ele, é possível exportar uma planilha com os principais dados registrados de cada funcionário, facilitando conferências, auditorias, integrações e atualizações internas.

Confira abaixo como gerar o relatório e como interpretar os dados apresentados.

---

## Como gerar o relatório R13

1. No menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), selecione a opção **Relatórios e Registros**.
2. Selecione a opção "**R13 - Relatório com informações dos empregados**".
3. Configure os filtros.

![Imagem 1: Configure os filtros.](https://storage.crisp.chat/users/helpdesk/website/-/1/3/8/d/138d0bb63cad5f00/c5ce7fd6-4045-44e8-aec2-96071c_11z3p8.png)

- Escolha os critérios de filtro conforme a sua necessidade. Você pode selecionar por locais de trabalho, empregadores, empregados ou grupos.
- Em seguida, informe se deseja consultar os empregados:
- Ativos: que estão ativos na plataforma
- Demitidos: Que já foram desligados
- Que já registraram ponto: ativos ou demitidos que registraram algum ponto
- Todos: Inclui os dados cadastrais de todos os colaboradores, sem exceção
- Em "campos", selecione dentre as 31 opções quais deseja considerar no relatório. Há possibilidade de selecionar todos os campos.
- Se desejar, marque a opção "enviar os resultados do relatório por e-mail" para receber o arquivo diretamente no endereço de e-mail cadastrado em seu usuário.

4. Clique em "gerar excel" para iniciar o processamento do relatório.
5. No menu de navegação, clique no **ícone de sino** (Notificações), para acompanhar o arquivo ser gerado.
6. Quando chegar a "100%", o relatório será baixado automaticamente.

---

## Entenda o relatório

Feito o download, você receberá um arquivo compactado (.zip), contendo três arquivos:

- **Sucesso (relatório principal)**: Relatório que apresenta os dados cadastrais de todos os colaboradores. Cada coluna da planilha corresponde a um campo de cadastro preenchido no sistema. Os cadastros dos colaboradores podem ser consultados e gerenciados no menu **cadastros > empregados** do site [Pontotel Gestão](https://gestao.pontotel.com.br/#/).

![Imagem 2: Sucesso (relatório principal) : Relatório que apresenta os dados cadastrais de todos os colaboradores. Cada coluna da…](https://storage.crisp.chat/users/helpdesk/website/-/e/7/3/1/e731cc72de381000/03bce3c3-03e2-47cd-a03e-3fc4a0_1y7ethb.png)

- **Status**: Planilha que resume o status do processamento por colaborador, informando se o colaborador foi considerado na geração do relatório.
- **Erros**: Planilha que lista as inconsistências ou problemas identificados durante o processamento, que impediram a inclusão de determinados colaboradores no relatório. Dessa forma, é possível analisar e corrigir os registros necessários antes de uma nova tentativa.

---

O relatório R13 é essencial para a gestão das informações dos colaboradores, oferecendo uma visão completa e atualizada dos dados cadastrais registrados na plataforma. Utilize este recurso sempre que precisar conferir, atualizar ou auditar informações de funcionários.
