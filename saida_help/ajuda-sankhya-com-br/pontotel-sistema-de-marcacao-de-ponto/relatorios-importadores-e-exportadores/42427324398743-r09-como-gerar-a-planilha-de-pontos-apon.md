# R09 - Como gerar a planilha de pontos, apontamentos e informações dos empregados

O relatório R09 é uma ferramenta completa para acompanhar todos os pontos batidos, informações cadastrais, jornadas esperadas e os apontamentos diários (no formato HH:MM) pelos colaboradores dentro de um determinado período. Com esse relatório, é possível identificar detalhes como horários, dispositivos utilizados, além de outras informações importantes para a gestão de pessoas e do controle de jornada.

---

## Passo a passo para gerar o relatório R09

1. No menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), selecione a opção **Relatórios e Registros**.
2. Selecione a opção "**R09 - Planilha de pontos, apontamentos e informações dos empregados**".
3. Configure os filtros.

![Imagem 1: Configure os filtros.](https://storage.crisp.chat/users/helpdesk/website/-/3/e/2/0/3e20fbd2c1e7bc00/4739aa49-4442-4e80-9ca9-3193aa_62pbf6.png)

- Escolha os critérios de filtro conforme a sua necessidade. Você pode selecionar por locais de trabalho, empregadores, empregados ou grupos.
- Em seguida, informe o período desejado selecionando a data inicial e data final.
- O período deve ser de, no máximo, 186 dias.
- Marque as opções desejadas para exibição de detalhes, como mostrar todos os pontos do dia, endereço do ponto, considerar empregados demitidos, mostrar códigos dos dispositivos, entre outros.
- Se desejar, marque a opção "enviar os resultados do relatório por e-mail" para receber o arquivo diretamente no endereço de e-mail cadastrado em seu usuário.

4. Clique em "gerar excel" para iniciar o processamento do relatório.
5. No menu de navegação, clique no **ícone de sino** (Notificações), para acompanhar o arquivo ser gerado.
6. Quando chegar a "100%", o relatório será baixado automaticamente.

---

## Entenda o relatório

Feito o download, você receberá um arquivo compactado (.zip), contendo três arquivos:

- **Sucesso (relatório principal)**: o arquivo principal permite uma análise detalhada por colaborador, considerando todos os registros do período filtrado, inclusive apontamentos múltiplos em um mesmo dia ou pontos fora do local cadastrado.

Também apresenta as seguintes informações:

- Nome e código dos colaboradores
- Local de trabalho cadastrado e em qual local cada ponto foi registrado
- Dispositivo utilizado para cada marcação
- Endereço e localização do ponto registrado (caso a opção esteja marcada)
- Jornada esperada
- Saldos dos apontamentos feitos no dia
- Datas, horários, tipo de marcação e status de cada apontamento
- Informações complementares como status de travamento, motivo de marcações, entre outros dados de controle

![Imagem 2: Informações complementares como status de travamento, motivo de marcações, entre outros dados de controle](https://storage.crisp.chat/users/helpdesk/website/-/9/2/5/5/9255cd515bb3d000/7283a30e-8132-4a7b-b4bf-e33432_n9udsp.png)

- **Status**: Planilha que resume o status do processamento por colaborador, informando se o colaborador foi considerado na geração do relatório.
- **Erros**: Planilha que lista as inconsistências ou problemas identificados durante o processamento, que impediram a inclusão de determinados colaboradores no relatório. Dessa forma, é possível analisar e corrigir os registros necessários antes de uma nova tentativa.
