# Como gerar o relatório de usuários

Gerenciar as permissões e acessos dos usuários é uma tarefa vital para o RH. Para facilitar essa auditoria, a **Pontotel** permite a emissão de uma planilha completa com todos os dados dos usuários cadastrados, seus níveis de acesso e status de segurança.

Neste artigo, você aprenderá:

- Como emitir a planilha de usuários;
- O que significa cada coluna do relatório.

---

## Como emitir o Relatório

1. No menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), abra o menu **Admin** e clique na opção **Usuários**.
2. No canto superior direito da tela, clique no botão "**Planilha de usuários**".

   ![Imagem 1: No canto superior direito da tela, clique no botão " Planilha de usuários ".](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_10ij15i.png)
3. O sistema gerará o arquivo em formato Excel (.xlsx) contendo todos os usuários da base.

---

## Entendendo as colunas da Planilha

Ao abrir o arquivo, você encontrará diversas colunas que detalham as configurações de cada conta. Veja o que cada uma significa:

| Coluna | Descrição |
| --- | --- |
| **NOME** | Nome completo do usuário cadastrado. |
| **EMAIL** | E-mail utilizado para login e recebimento de comunicações. |
| **PERMISSAO** | Define o [nível de acesso](https://sankhya.zendesk.com/hc/pt-br/articles/42427306327575) (ex: RH, Gerente, Funcionário). |
| **ATIVO** | Indica se o usuário possui acesso liberado (**Sim**) ou bloqueado (**Não**). |
| **LOCAIS DE TRABALHO** | Quais unidades ou locais este usuário tem permissão para visualizar. |
| **ACESSO A** | Filtros de visibilidade (ex: "Todos" ou grupos específicos). |
| **CPF** | Documento de identificação do usuário. |
| **EMPREGADO ASSOCIADO** | Mostra qual cadastro de colaborador está vinculado a este usuário. |
| **CÓDIGO** | Identificador único ou PIN do usuário no sistema. |
| **LÍDER DIRETO** | Indica quem é o superior imediato vinculado a este perfil. |
| **TELEFONE** | Número de contato cadastrado. |
| **ATIVAR MFA** | Indica se a Autenticação de Dois Fatores (Segurança Extra) está ativa. |
| **PERMISSÃO PESSOAL** | Campo específico para empresas que utilizam o módulo de **Duplo Perfil**. Serve para usuários que tem funções de gestor e utilizam o mesmo usuário para registro de ponto. |

---

> 💡 Dicas:

- **Auditoria de Acessos:** Utilize esta planilha periodicamente para conferir se ex-colaboradores ainda constam como "Ativos" e realize a inativação no menu de usuários se necessário.
- **Segurança (MFA):** Fique de olho na coluna de MFA. Recomendamos que usuários com permissão de **RH** e **Administrador** sempre tenham essa opção ativa para garantir a proteção dos dados da empresa. Para ativar, acesse as configurações avançadas durante a edição do usuário.

---

A planilha de usuários é uma ferramenta essencial para manter a **segurança** da sua conta e a organização do seu RH. Com ela, você tem um "raio-x" completo de todos os acessos em um único lugar, garantindo que as permissões estejam sempre alinhadas com as diretrizes da sua empresa e facilitando auditorias rápidas.
