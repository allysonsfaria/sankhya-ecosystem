# Onde encontrar o código do coletor no aplicativo BatePonto

Para fazer o gerenciamento de coletores, buscar dispositivos em relatórios ou abrir um chamado para um determinado dispositivo com nosso time de suporte, o código do coletor é uma informação essencial para identificar o coletor correto.

---

## Passo a passo para visualizar o código no app BatePonto

1. **Acesse o menu lateral pela tela inicial**

   - Após fazer o login no aplicativo, você chegará na tela inicial.
   - Clique no ícone de três linhas (menu), no canto superior esquerdo da tela, para abrir o menu lateral.

   ![Imagem 1: Clique no ícone de três linhas (menu), no canto superior esquerdo da tela, para abrir o menu lateral.](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_2zzgyz.png)
2. **Veja o código**

   - No menu que abrirá, logo abaixo do nome do coletor, você verá o código do coletor.
   - Para copiá-lo, basta tocar nele.

   ![Imagem 2: Para copiá-lo, basta tocar nele.](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_q1d7ku.png)

---

## Como consultar o código do dispostitivo no Site Gestão

1. O código do coletor é utilizado para identificação do dispositivo cadastrado e para o gerenciamento do mesmo através da tela **Gestão de Coletores**. Para encontrar o coletor no [site Gestão](https://gestao.pontotel.com.br/#/), no menu de navegação, clique em **Admin**, e selecione **Coletores**.
2. Na nova tela, altere a categoria para "**aplicativo de registro**" para visualizar os coletores criados a partir do app BatePonto.

![Imagem 3: Na nova tela, altere a categoria para " aplicativo de registro " para visualizar os coletores criados a partir do app…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_2sf3pw.png)

---

> ⚠️ Atenção: O código é exclusivo para cada coletor cadastrado. Caso desinstale o app, ao instalar e fazer um novo login, será gerado um novo código único.

---

Acompanhar e gerenciar o código do coletor garante a integridade do registro de ponto e facilita a administração dos dispositivos da empresa.
