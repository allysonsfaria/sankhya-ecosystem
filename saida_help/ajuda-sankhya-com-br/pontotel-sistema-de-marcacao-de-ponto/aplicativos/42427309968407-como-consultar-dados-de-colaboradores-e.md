# Como consultar dados de colaboradores e locais de trabalho pelo Aplicativo Gestão

O aplicativo Pontotel Gestão permite consultar facilmente os dados cadastrais de locais de trabalho e dos colaboradores, facilitando o acesso a informações essenciais sobre cada unidade da empresa e seus funcionários, de onde você estiver.

---

## Consultando os dados de um local de trabalho

1. **Acesse o menu**

   Faça login e toque no ícone com a foto de perfil, no canto superior direito da tela inicial, para acessar o menu do app.

   ![Imagem 1: Faça login e toque no ícone com a foto de perfil, no canto superior direito da tela inicial, para acessar o menu do app.](https://storage.crisp.chat/users/helpdesk/website/-/1/7/3/0/1730fe95dbae190/cb6cde94-f182-492d-b508-3bf197_wj2jtf.png)
2. **Selecione “locais de trabalho”**

   No menu, escolha a opção locais de trabalho para visualizar todas as unidades cadastradas na empresa.

   ![Imagem 2: No menu, escolha a opção locais de trabalho para visualizar todas as unidades cadastradas na empresa.](https://storage.crisp.chat/users/helpdesk/website/-/e/8/c/3/e8c32e6ed8d37000/3349f065-eba7-4f72-9b30-e4b902_58559b.png)
3. **Busque e selecione o local desejado**

   Use a barra de busca para localizar rapidamente o local de trabalho que você deseja consultar.

   ![Imagem 3: Use a barra de busca para localizar rapidamente o local de trabalho que você deseja consultar.](https://storage.crisp.chat/users/helpdesk/website/-/b/5/e/4/b5e442cd0e124000/3b1d9182-31aa-4010-ac46-d55474_1uv0rh9.png)
4. **Visualize os dados cadastrais do local**

   Ao selecionar um local, o app exibirá:
   \* Nome do local de trabalho
   \* Cidade
   \* Mapa com localização geográfica
   \* Contato (se houver)
   \* Código identificador do local
   \* Status (ativo/inativo)

   ![Imagem 4: Ao selecionar um local, o app exibirá: * Nome do local de trabalho * Cidade * Mapa com localização geográfica * Contato…](https://storage.crisp.chat/users/helpdesk/website/-/9/2/2/f/922f9842265e9800/22acf532-2c3b-4628-b1a1-f6149c_1wq978t.png)

## Consultando os dados cadastrais de um colaborador

1. **No menu lateral, selecione “funcionários”**

   Ainda no menu do app, toque em funcionários para ver a lista de colaboradores.

   ![Imagem 5: Ainda no menu do app, toque em funcionários para ver a lista de colaboradores.](https://storage.crisp.chat/users/helpdesk/website/-/1/d/f/2/1df26983375ef900/20d5b4cc-c01d-4998-beb8-0a5b81_h5tb48.png)
2. **Busque e selecione o colaborador desejado**

   Localize o colaborador desejado utilizando a busca ou rolando a lista.

   ![Imagem 6: Localize o colaborador desejado utilizando a busca ou rolando a lista.](https://storage.crisp.chat/users/helpdesk/website/-/3/b/0/e/3b0e4a0ec9d0f200/dccd7305-a556-4022-8e5a-8190ee_szpv9h.png)
3. **Visualize os dados cadastrais do colaborador**

   Ao tocar no nome, serão exibidos detalhes como:
   \* Nome completo
   \* Senha de acesso (para registro de ponto)
   \* Local de trabalho vinculado
   \* Empregador
   \* Data de admissão
   \* Cargo e departamento (quando cadastrados)
   \* Data de início da folha
   \* Escala atribuída
   \* E-mail cadastrado (se houver)
   \* Opções rápidas para acessar a folha, ligar ou enviar mensagem no **WhatsApp** (caso tenha adicionado o número de telefone no cadastro do empregado).

   ![Imagem 7: Ao tocar no nome, serão exibidos detalhes como: * Nome completo * Senha de acesso (para registro de ponto) * Local de…](https://storage.crisp.chat/users/helpdesk/website/-/7/1/6/d/716dff677652b000/7bd5d1c9-ccb9-49c9-bbf3-b32d3f_ufwnmm.png)

   ![Imagem 8: Ao tocar no nome, serão exibidos detalhes como: * Nome completo * Senha de acesso (para registro de ponto) * Local de…](https://d33v4339jhl8k0.cloudfront.net/docs/assets/574ca4e4c6979138ff609a77/images/687a46208846474f1e1f51f1/file-j0el3qihTR.png)
