# Como reativar um usuário no sistema

Na Pontotel, “excluir” um usuário não significa apagá-lo permanentemente: ele permanece listado entre os usuários desligados. Dessa forma, todos os registros anteriores, como folhas de ponto e apontamentos, ficam guardados. Para usá-lo novamente, é preciso reativá-lo.
Pensando nisso, preparamos este artigo para mostrar como é simples reativar um usuário na nossa plataforma. O melhor de tudo é que o histórico do colaborador é totalmente preservado! Neste artigo, você verá passo a passo como localizar usuários desligados e reativá-los.

---

## Como reativar um usuário

1. No menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), abra o menu **Admin** e clique na opção **Usuários**.
2. Na categoria "mostrar", Selecione a opção **"desligados"** para listar os usuários que estão inativos

   ![Imagem 1: Na categoria "mostrar", Selecione a opção "desligados" para listar os usuários que estão inativos](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_8n6fy5.png)
3. Entre os usuários desligados listados, clique no nome do colaborador que você deseja reativar
4. No menu que abrirá, pressione o botão **Reativar**

   [GIF animado: Imagem 2: No menu que abrirá, pressione o botão Reativar](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/reativar-usuario_544m9g.gif)
5. O sistema irá movê-lo da lista de “Desligados” para **Ativos.**

---

> ⚠️ Atenção:

- Mesmo após a “exclusão”, o usuário permanece listado na seção “Desligados” do sistema.
- A exclusão não apaga dados do usuário, mas apenas o desativa para que não possa acessar ou ser usado ativamente enquanto estiver nessa condição.
- Ao reativar, o histórico de ações, permissões e vínculos anteriores do usuário é retomado conforme configurado antes da desativação.
- É possível ajustar os campos do usuário antes de efetivar a reativação
- Certifique-se de que o usuário tem perfil e permissões adequadas após a reativação.

---

Reativar usuários no Pontotel é simples e seguro: você apenas precisa encontrá-los na lista de desligados e ativar novamente. Esse fluxo permite manter todos os registros intactos enquanto controla o acesso e a utilização dos usuários de forma estruturada.
