# Conheça o novo BatePonto Web

A Pontotel apresenta o novo [BatePonto Web](https://bateponto.pontotel.com.br/#/), uma versão atualizada e moderna do site de registro de ponto, desenvolvida para proporcionar uma experiência mais fluida, intuitiva e acessível para todos os usuários.

Com um **layout totalmente reformulado** e um **menu de navegação lateral**, o novo design facilita o acesso às principais funcionalidades e oferece uma visualização mais clara das informações, garantindo praticidade tanto para colaboradores quanto para gestores.

Além da nova interface, o sistema continua mantendo toda a segurança e confiabilidade já conhecidas da Pontotel, permitindo o registro de ponto de forma simples, rápida e precisa.
