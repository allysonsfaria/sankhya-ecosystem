# Agora é possível integrar Feriados e Sobreavisos entre sistemas através da API Pública V4

Na **Pontotel**, sabemos que a agilidade na troca de dados entre plataformas é fundamental para uma **gestão** eficiente. Pensando nisso, expandimos as capacidades da nossa **API Pública V4**, trazendo novos endpoints que permitem a gestão autônoma e automatizada de dois recursos muito importantes: **Feriados** e **Sobreavisos**.
Neste artigo, você entenderá os detalhes dessas novas rotas e como elas podem otimizar a operação da sua empresa.

---

## Quem pode utilizar?

Estas novidades estão disponíveis para empresas que possuem o serviço de integração via API ativo e utilizam a nossa documentação técnica na versão mais recente (V4).

### 1. Gestão de Feriados via API

Anteriormente, a criação e a edição de feriados eram restritas à interface do sistema Pontotel Gestão. Agora, disponibilizamos uma estrutura completa de CRUD (Create, Read, Update, Delete) para o domínio de feriados na API V4.

**O que é possível fazer:**

- Criar novos feriados de forma automatizada;
- Consultar os feriados já cadastrados;
- Atualizar informações ou deletar registros diretamente pelo seu sistema interno.

### 2. Gestão de Sobreavisos via API

O gerenciamento de escalas de sobreaviso, que antes se limitava à versão legada da API ou à interface web, agora faz parte da nossa tecnologia mais moderna.
Foi implementada uma nova rota de integração, seguindo todos os padrões e otimizações de comunicação da V4.

**Principais características e validações:**

- **Ciclo completo:** A rota permite as ações de criação (POST), leitura (GET) e exclusão (DELETE).
- **Segurança inteligente:** O novo endpoint de criação herda e aplica rigorosamente todas as validações de segurança que já existem na nossa plataforma web.
- **Prevenção inteligente:** O sistema bloqueia automaticamente a criação de sobreavisos para colaboradores inativos e impede conflitos de horário nas escalas enviadas.
