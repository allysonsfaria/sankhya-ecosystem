# O que significa quando meu sistema consta como expirado?

Se o seu sistema está aparecendo como expirado, isso significa que ainda não identificamos o pagamento da(s) sua(s) fatura(s)/boleto(s).

Mas não se preocupe, estamos aqui para te ajudar! 😊

---

1. **Como regularizar a situação?**

   Para reativar o seu sistema, realize o pagamento das faturas/boletos pendentes ou em atraso. Você pode consultá-las a qualquer momento através deste link:

   🔗 [Acesse suas faturas em aberto](https://otiosam.com.br/api/boletos)

   ⚠ Importante! Esse link só funciona com o(s) e-mail(s) cadastrados para recebimento dos boletos.
2. **Já realizou o pagamento?**

   Se já efetuou o pagamento do seu boleto, envie o comprovante para [faturamento@pontotel.com.br](mailto:faturamento@pontotel.com.br) para que possamos verificar o que pode ter ocorrido, ou aguarde a liberação automática do sistema em até 2 dias úteis, após a compensação do pagamento.

---

Caso tenha mais alguma dúvida, estamos à disposição para ajudar! Entre em contato sempre que precisar 😃
