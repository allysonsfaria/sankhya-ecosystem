# Como editar ou alterar o cadastro de um empregado

Manter os dados dos colaboradores atualizados é essencial para uma **gestão** correta. Seja para ajustar a escala, alterar o nome, ou trocar a regra de cálculo, o processo de edição do cadastro do empregado é **simples** e rápido.

> ⚠️ Atenção: Este artigo foca em como acessar a tela de edição. Para uma explicação detalhada sobre o que significa cada campo de preenchimento, consulte nosso guia completo de cadastro: [Como cadastrar um empregado](https://sankhya.zendesk.com/hc/pt-br/articles/42427347938839)

---

## Como editar um empregado

1. No menu principal, acesse **Cadastros** e clique em **Empregados**.
2. Na tela de listagem, utilize os filtros de busca para encontrar o colaborador que deseja editar.
3. Clique na linha do colaborador e, no menu que abrirá, clique no ícone de **lápis** (Editar)

   ![Imagem 1: Clique na linha do colaborador e, no menu que abrirá, clique no ícone de lápis (Editar)](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_1kdqat4.png)
4. Após concluir todas as edições, clique em **salvar**.

---

> 💡 Dica: Se quiser saber como preencher cada campo do cadastro do empregado, consulte o artigo: [Como cadastrar um empregado](https://sankhya.zendesk.com/hc/pt-br/articles/42427347938839).
