# Como excluir/desativar um motivo padrão

Não é possível **excluir** um motivo padrão cadastrado na plataforma, mas podemos desativá-lo para que não apareça mais na lista de motivos padrão que podem ser utilizados.

Vamos ver abaixo como desativar um motivo padrão.

---

## Como desativar um motivo padrão

1. No menu de navegação do[site Gestão](https://gestao.pontotel.com.br/), clique em **Regras** e selecione a opção **Motivos padrão**.
2. Localize o motivo que deseja desativar.
3. Ao selecionar o motivo, clique no ícone correspondente no menu para desativar o motivo.

![Imagem 1: Ao selecionar o motivo, clique no ícone correspondente no menu para desativar o motivo.](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_at83jw.png)
> 💡 Dica: você pode visualizar os motivos desativados selecionando a opção “desativados” no campo “mostrar”. Ao selecionar um motivo desativado, basta clicar no botão “Ativar” para reativá-lo.

![Imagem 2: 💡 Dica: você pode visualizar os motivos desativados selecionando a opção “desativados” no campo “mostrar”. Ao…](https://storage.crisp.chat/users/helpdesk/website/-/2/e/1/b/2e1bb2cac0bcb600/89aaf1fe-dc2c-4291-8ff4-7ec19f_1omgi0k.png)
