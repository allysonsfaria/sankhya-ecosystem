# Como desligar um empregado

O desligamento de um colaborador deve ser registrado corretamente no sistema para garantir que sua folha de ponto não tenha faltas em dias indevidos e que todas as informações legais e administrativas fiquem organizadas.
Esse processo pode ser feito diretamente no site Pontotel Gestão, dentro do cadastro do empregado.

---

## Como desligar um empregado

1. No menu de navegação do[\_\_ site Gestão\_\_](https://gestao.pontotel.com.br/), clique em **Cadastros**. Depois selecione **Empregados**.
2. Na listagem de empregados ativos, selecione o colaborador que deseja desligar. No menu que abrirá, clique no botão "desligar empregado".

   [GIF animado: Imagem 1: Na listagem de empregados ativos, selecione o colaborador que deseja desligar. No menu que abrirá, clique no botão…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/desligar-empregado_rc78ti.gif)
3. Preencha os campos:

   - **Jornada de trabalho no dia de desligamento**: Caso marcado, o sistema irá considerar normalmente a jornada esperada no dia do desligamento. Se não marcado, o colaborador não terá jornada esperada nesse dia.
   - **Agendar desligamento para uma data futura**: Permite programar o desligamento para uma data ainda não ocorrida. Útil quando já há uma data oficial definida, mas deseja-se registrar antecipadamente no sistema.
   - **Anular pontos reais após desligamento**: Caso marcado, os pontos registrados pelo colaborador após a data de desligamento serão desconsiderados. \*\*
   - **Motivo da anulação**: Campo de texto obrigatório quando a opção acima é selecionada, para justificar a anulação desses pontos.
   - **Data de desligamento**: Campo principal onde deve ser informada a data efetiva em que o colaborador deixou a empresa.
   - **Motivo do desligamento**: Lista suspensa onde é possível selecionar o motivo (desligamento, falecimento, pediu desligamento ou outro). Esses motivos ajudam no controle administrativo. Ao selecionar a opção "outro", é possível adicionar um motivo personalizado.

   ![Imagem 2: Motivo do desligamento : Lista suspensa onde é possível selecionar o motivo (desligamento, falecimento, pediu…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_cxu967.png)
4. Para concluir, clique no botão "**Desligar**". A solicitação será registrada e, a partir da data informada, as jornadas referentes ao desligamento serão exibidas automaticamente na folha de ponto do colaborador.

---

> 💡 Dicas:

- Ao desligar um empregado, seus dados e folhas de ponto permanecem salvos no sistema. Para visualizá-los, basta alterar a seção "mostrar" para **desligados**.

![Imagem 3: Ao desligar um empregado, seus dados e folhas de ponto permanecem salvos no sistema. Para visualizá-los, basta alterar…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_19wcjv7.png)

- É possível gerar o espelho de ponto de um colaborador desligado, mas o caminho a ser seguido é diferente do tradicional. Para saber mais, veja o artigo: [Como gerar espelhos de ponto de um colaborador desligado](https://sankhya.zendesk.com/hc/pt-br/articles/42427316300439).

---

Registrar o desligamento no sistema garante maior controle e evita inconsistências nas folhas de ponto. Sempre confirme a data informada antes de salvar.
