# Como criar um usuário para registro de ponto coletivo

Registrar o ponto de forma coletiva é uma solução prática para empresas que utilizam dispositivos compartilhados em ambientes presenciais, como escritórios ou fábricas. Para isso, é necessário fazer login na plataforma com um usuário específico, com perfil/permissão de **cadastro de coletores**.

Neste artigo, você aprenderá como criar esse usuário.

---

## Como criar um usuário coletivo

1. No menu de navegação do[site Gestão](https://gestao.pontotel.com.br/), clique em **Admin**. Depois selecione **Usuários**.
2. Para adicionar um novo usuário, clique em **Criar novo usuário**.
3. Preencha os campos:

   - **Nome do usuário:** Digite "Cadastro de coletores" ou algum termo que consiga identificar como um usuário coletivo
   - **E-mail:** Informe o e-mail que será usado para fazer login na plataforma. Pode ser um e-mail real ou fictício, caso não haja necessidade de comunicação direta. Nossa sugestão de e-mail é: coletores@nomedaempresa.com.br.
   - **Senha de acesso ao sistema:** Cadastre uma senha de pelo menos 8 caracteres. Esta senha será utilizada para o acesso ao sistema e pode ser alterada posteriormente.
   - **Telefone:** informe o número de telefone da pessoa que utilizará este usuário. Esse dado é indispensável quando o usuário for o ponto de contato com o suporte da Pontotel. Como se trata de um usuário coletivo que será usado para registrar pontos, não há necessidade de preencher este campo.
   - **CPF:** Número do CPF do usuário, usado como dado de identificação. Para a criação de um usuário coletivo, deixe em branco.
   - **Permissão geral:** Define o nível de acesso do usuário, controlando quais módulos ele poderá visualizar. Selecione a opção "**Cadastro de Coletores**".
   - **Permissão pessoal**: Permite atribuir regras específicas de acesso ao usuário, caso possua um empregado vinculado ao usuário. Neste caso, deixe em branco.
   - **Código:** Atribua um código único para organizar e identificar o usuário no sistema. Este campo pode facilitar a consulta e o gerenciamento dos registros.
   - **Líder desse usuário**: Campo para vincular um líder responsável pelo usuário, caso seja aplicável. Neste caso, deixe em branco.

   ![Exemplo de preenchimento correto dos campos](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_zs9rrk.png)

   Exemplo de preenchimento correto dos campos
4. Configure as **opções avançadas** (opcional)

   - **Gerar senha aleatória e enviar por e-mail**: Quando selecionado, gera automaticamente uma senha e envia para o e-mail cadastrado do usuário.
   - **Exigir troca de senha no primeiro acesso**: Obriga o usuário a redefinir a senha assim que acessar a plataforma pela primeira vez.
   - **Ativar fator de dupla autenticação (MFA)**: Recurso de segurança adicional que exige um segundo fator de autenticação no login (como código enviado por e-mail ou app autenticador).
   - **Considerar este usuário como ponto de contato para o suporte:** ao ativar essa opção, o usuário passa a ser definido como o contato principal da empresa junto ao suporte da Pontotel. Isso significa que seus dados, como telefone e e-mail, poderão ser utilizados nos chamados abertos, facilitando a comunicação e agilizando o atendimento quando houver necessidade de suporte. Por ser um usuário coletivo, recomendamos não habilitar esta opção.

   ![Imagem 2: Considerar este usuário como ponto de contato para o suporte: ao ativar essa opção, o usuário passa a ser definido como…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_fygigh.png)
5. Clique no botão **Salvar** para finalizar a criação ou alteração.
