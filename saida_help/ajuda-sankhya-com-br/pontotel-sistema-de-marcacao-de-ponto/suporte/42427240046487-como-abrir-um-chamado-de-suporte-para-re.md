# Como abrir um chamado de suporte para registro de ponto pelo computador (site BatePonto)

Antes de abrir um chamado, recomendamos realizar a **limpeza de cache do navegador**, pois muitos problemas de acesso ou visualização são resolvidos apenas com essa ação simples. Confira neste artigo como limpar o cache e forçar a atualização do site.

Se o problema persistir após a limpeza de cache, reúna o máximo de informações ao relatar um erro com o registro de ponto no site [BatePonto](https://bateponto.pontotel.com.br/#/). Quanto mais detalhes você enviar, mais rápido será o diagnóstico e a solução.

Inclua no seu chamado:

- Código de ativação da empresa
- Código do coletor
- **Prints de tela** mostrando o erro ou a situação encontrada no momento do registro
- **Nome do(s) colaborador(es)**
- **Descrição** detalhada do problema
- Exemplo: não consegue registrar o ponto, mensagem de erro, página não carrega, registro não aparece, etc.
- Qual **navegador** está utilizando
- Exemplo: Chrome, Firefox, Edge
- Mensagem de erro apresentada, se houver.
- Passos já realizados para tentar resolver
- Exemplo: troca de navegador, limpeza de cache, etc.

Essas informações vão ajudar nossa equipe de suporte a entender o cenário e propor a melhor solução de forma mais rápida.
