# O que é a API da Pontotel e como ela pode integrar outros sistemas

Gerenciar colaboradores em múltiplos sistemas ao mesmo tempo gera retrabalho. Quem já precisou cadastrar um novo funcionário separadamente no sistema de RH e na plataforma de ponto sabe bem o que isso significa. A API da Pontotel existe para resolver esse problema, criando uma ponte de comunicação direta entre a Pontotel e os sistemas que a sua empresa já utiliza.
Neste artigo, você vai entender o que é essa API, o que ela integra e como ela funciona na prática.

---

## O que é uma API?

API é a sigla para Application Programming Interface, ou seja, uma interface que permite que dois sistemas diferentes se comuniquem de forma automática. Pense como uma ponte: o que acontece em um sistema pode ser refletido automaticamente no outro, sem que ninguém precise fazer isso manualmente.
No contexto da Pontotel, a API permite que seu sistema envie ou consulte informações diretamente na plataforma, como admitir um colaborador, registrar um ponto ou lançar um afastamento, tudo de forma automatizada.

---

## Para que serve a API da Pontotel?

A API da Pontotel foi desenvolvida para eliminar o trabalho manual de manter cadastros sincronizados entre diferentes sistemas. Com ela, sua empresa pode:

- **Integrar o sistema de RH ou ERP com a Pontotel**, automatizando a admissão, atualização e demissão de colaboradores.
- **Enviar batidas de ponto** coletadas em outros REPs diretamente para a folha na Pontotel.
- **Lançar férias, afastamentos e dispensas** automaticamente, sem precisar acessar a plataforma manualmente.
- **Consultar dados** como posição de banco de horas, regras de cálculo e muito mais.
  O resultado é menos retrabalho, menos erros e um processo de gestão de jornada muito mais eficiente.

## O que a API da Pontotel integra?

A API cobre as principais entidades da plataforma. Veja o que é possível gerenciar:
**Cadastros:**

- Empregados
- Empregadores e locais de trabalho
- Usuários e permissões
- Escalas e jornadas
- Motivos padrão
  **Lançamentos:**
- Férias, afastamentos, dispensas e sobreavisos
- Pontos
- Banco de horas
  **Consultas:**
- Regras de cálculo
- Regras de banco de horas
- Permissões cadastradas

---

## Como funciona na prática?

A integração funciona em dois sentidos: a Pontotel pode receber dados do seu sistema, e o seu sistema pode consultar dados da Pontotel. O fluxo básico é o seguinte:

1. O seu sistema (ou o parceiro de integração) consome os endpoints disponíveis na API da Pontotel.
2. As informações são enviadas ou consultadas diretamente na plataforma, sem intervenção manual.
3. As atualizações são refletidas em tempo real, mantendo os dois sistemas sempre sincronizados.

A Pontotel é responsável por disponibilizar e sustentar os endpoints. A construção e manutenção do fluxo de integração fica a cargo da sua equipe técnica ou de um parceiro de integração.
