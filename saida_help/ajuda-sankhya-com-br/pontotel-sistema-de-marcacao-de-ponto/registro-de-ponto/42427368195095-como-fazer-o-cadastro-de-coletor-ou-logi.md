# Como fazer o cadastro de coletor ou login no Site BatePonto (web)

Para registrar o ponto pelo computador, você não precisa instalar nenhum programa. Basta acessar o [Site BatePonto](https://bateponto.pontotel.com.br/#/marcacao) pelo seu navegador (recomendamos o [Google Chrome](https://www.google.com/intl/pt-BR/chrome/)).
No primeiro acesso, você precisará realizar um breve cadastro para "ativar" esse computador como um coletor de ponto seguro e autorizado.

---

## Passo a Passo: Cadastro e Primeiro Acesso

1. Abra o seu navegador e acesse o link: [bateponto.pontotel.com.br](https://bateponto.pontotel.com.br/).
2. Na tela de login, digite seu **E-mail** e **Senha** de usuário (criados pelo RH ou gestor).

![Imagem 1: Na tela de login, digite seu E-mail e Senha de usuário (criados pelo RH ou gestor).](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_pcem07.png)
> ⚠️ Atenção: Pode acontecer de, após digitar o e-mail, você ser redirecionado para o site Gestão para concluir o login por lá. Basta inserir sua senha e clicar em "Entrar". Se estiver tudo certo, você será direcionado novamente ao site BatePonto para finalizar o cadastro do coletor.

![Imagem 2: ⚠️ Atenção: Pode acontecer de, após digitar o e-mail, você ser redirecionado para o site Gestão para concluir o login…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_1ey9u0l.png)

3. Agora você verá a etapa de ativação do dispositivo. Os campos que aparecem para preenchimento podem variar de acordo com as permissões do usuário.

**Usuário pessoal**

- Um usuário pessoal possui a [permissão de funcionário](https://sankhya.zendesk.com/hc/pt-br/articles/42427218638871) e um empregado associado. Nesse tipo de acesso, somente o colaborador vinculado ao usuário pode registrar o ponto, caso o cadastro do dispositivo seja realizado com ele.

![Exemplo de preenchimento de usuário pessoal](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_10xwzr2.png)

Exemplo de preenchimento de usuário pessoal

- Com um usuário pessoal, após inserir o login e a senha, será solicitado o **nome do coletor**. Defina um nome que facilite a identificação do dispositivo no dia a dia.
- O **perfil de coletor** utilizado será o padrão do sistema. Nesse tipo de usuário não é possível escolher outro perfil durante o cadastro, porém o RH da empresa pode realizar a alteração posteriormente pelo **site Pontotel Gestão**.
- Lembre-se de que **somente o empregado associado a esse usuário** poderá registrar o ponto nesse coletor.

![Imagem 4: Lembre-se de que somente o empregado associado a esse usuário poderá registrar o ponto nesse coletor.](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_1xvr339.png)

**Usuário impessoal/coletivo**

- Um usuário coletivo, por padrão, **não possui empregado associado**. Por isso, recomendamos utilizar um usuário que tenha a [permissão](https://sankhya.zendesk.com/hc/pt-br/articles/42427306327575) de **cadastro de coletores** para realizar essa configuração. Essa permissão padrão do sistema existe justamente para permitir o cadastro de dispositivos que serão utilizados por **várias pessoas** ou até mesmo por **uma única pessoa**, quando não se deseja fornecer um usuário individual para que ela faça o processo sozinha. Nesses casos, utiliza-se um usuário impessoal, sem vínculo com nenhum empregado.
- Caso exista um usuário com permissão de **gestão** que também permita cadastrar coletores, ele pode ser utilizado para fazer o login e configurar o dispositivo. Assim, sua equipe poderá registrar o ponto normalmente no coletor cadastrado.

![Imagem 5: Caso exista um usuário com permissão de gestão que também permita cadastrar coletores, ele pode ser utilizado para…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_1aytmno.png)

Preencha as informações solicitadas:

- **Nome do coletor:** Este é o nome "apelido" que você dará ao computador ou tablet.
- **Selecione a configuração de coletor desejada**: Defina qual perfil de coletor será utilizado para gerir as regras do coletor que está sendo cadastrado.
- Para quem: Defina que registrará o ponto no coletor:
  - Ao selecionar "Somente um empregado", haverá uma lista suspensa para selecionar o colaborador.
  - Ao selecionar "Um grupo de empregados", será possível selecionar o(s) local(is) de trabalho desejado(s). Os colaboradores lotados nos locais selecionados estarão aptos a registrar o ponto no coletor.
  - Ao selecionar "Todos os empregados", qualquer empregado cadastrado e sincronizado no sistema poderá registrar o ponto.

4. Finalize o cadastro do coletor clicando em **"Salvar"**.
5. Ao chegar na tela abaixo, significa que o coletor foi cadastrado corretamente e já está pronto para receber os registros de ponto. Acesse o o artigo a seguir e veja como registrar o ponto no BatePonto Web: [Como registrar o ponto no site BatePonto](https://sankhya.zendesk.com/hc/pt-br/articles/42427333839383)

![Imagem 6: Ao chegar na tela abaixo, significa que o coletor foi cadastrado corretamente e já está pronto para receber os…](https://storage.crisp.chat/users/helpdesk/website/-/c/e/8/7/ce87d16ae4000000/image_17hjrjl.png)

---

> ⚠️ Atenção: O Site BatePonto utiliza cookies para lembrar que o seu computador está cadastrado. Se você limpar os dados do navegador ou usar uma guia anônima, terá que refazer o processo de cadastro acima toda vez que acessar. Para garantir que o site funcione sempre sem pedir configuração, veja como configurar seu navegador corretamente [neste artigo](https://sankhya.zendesk.com/hc/pt-br/articles/42427322908823).
