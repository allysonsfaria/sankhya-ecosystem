# Como limpar o cache e os dados dos aplicativos Pontotel (BatePonto e Gestão)

Com o uso diário, os aplicativos (como o BatePonto ou o Gestão) armazenam arquivos temporários, conhecidos como cache, para carregar mais rápido. Com o tempo, esses dados podem ficar desatualizados e causar comportamentos inesperados, como lentidão, travamentos ou pequenas falhas de sincronização.
Limpar o **cache** ou os **dados** é uma ação simples de manutenção que força o aplicativo a baixar as informações mais recentes, garantindo a melhor performance e a evolução da sua experiência de uso.

---

## Qual a diferença: Limpar Cache vs. Limpar Dados?

Antes de começar, é importante entender a diferença entre as duas opções que você encontrará no seu dispositivo (principalmente Android):

- **Limpar Cache:** Remove apenas os arquivos temporários. É a primeira opção que você deve tentar. Esta ação **não apaga** seus dados de login ou pontos que estavam pendentes de sincronização.
- **Limpar Dados (ou Limpar Armazenamento):** Remove **todos** os dados do aplicativo, redefinindo-o para o estado de "recém-instalado". Esta ação **apagará** seu login, e você precisará se logar novamente. (Pontos registrados offline que não foram sincronizados podem ser perdidos com esse procedimento)
  **Recomendação:** Sempre tente "Limpar Cache" primeiro. Se o problema persistir, utilize "Limpar Dados".

## 3. Como limpar o cache (iPhone/iPad - iOS)

O sistema da Apple (iOS) funciona de forma diferente e não possui um botão "Limpar Cache" para a maioria dos aplicativos.
A **evolução** do sistema da Apple gerencia o cache automaticamente. No entanto, se o aplicativo apresentar instabilidade, a solução recomendada é "Desinstalar" o aplicativo:

1. Acesse **Ajustes > Geral > Armazenamento do iPhone**.
2. Aguarde a lista de aplicativos carregar e localize o app (Pontotel BatePonto ou Pontotel Gestão).
3. Toque em **Desinstalar App**. (Isso mantém seus dados, mas remove o app).
4. Após desinstalar, toque em **Reinstalar App**.
   Se isso não resolver, a última opção é apagar o aplicativo e baixá-lo novamente na App Store.
