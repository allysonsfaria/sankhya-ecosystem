# Como aprovar um computador como coletor para registrar o ponto

Precisa usar um computador para registrar pontos na Pontotel? Antes de iniciar os registros, pode ser necessário aprovar o equipamento como coletor no sistema. Este procedimento garante a segurança, evita fraudes e permite que o computador seja reconhecido de forma adequada pela plataforma.

---

> ⚠️ Atenção: Em alguns casos, a aprovação do coletor pode ocorrer automaticamente, dependendo das configurações do perfil de coletor selecionado ao fazer login no site BatePonto pelo dispositivo.

Se for necessário que a aprovação dos coletores seja feita manualmente, é importante garantir que a opção destacada abaixo esteja **desativada** no perfil de coletor utilizado. Assim, toda solicitação de novo coletor desse tipo precisará ser aprovada por um responsável antes de liberar o uso.

## Passo a passo

1. Faça o login no site BatePonto:

   - No computador que será utilizado como coletor, faça (ou solicite) o login inicial na plataforma. Esse primeiro acesso já cria a solicitação de aprovação do coletor.
   - Confira o passo a passo detalhado neste [artigo](https://sankhya.zendesk.com/hc/pt-br/articles/42427368195095).
   - Caso a aprovação automática do coletor esteja desativada, a seguinte mensagem aparecerá para o usuário após efetuar o login:

   ![Imagem 2: Caso a aprovação automática do coletor esteja desativada, a seguinte mensagem aparecerá para o usuário após efetuar o…](https://storage.crisp.chat/users/helpdesk/website/-/f/c/6/1/fc613b57a9a69800/f7df669b-0dab-4f31-a63f-2ffeab_xq4dgz.png)
2. Feito o login no site [Gestão](https://gestao.pontotel.com.br/#/) com um usuário com [permissão](https://sankhya.zendesk.com/hc/pt-br/articles/42427306327575) de gestor (Ex. RH, Gerente, Supervisor), no menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), vá em **Admin** e clique em **Coletores**.
3. A tela será dividida em duas seções:

   - **Coletores:** Para visualizar e configurar os dispositivos já registrados.
   - **Perfis de Coletores:** Para gerenciar as configurações aplicadas aos dispositivos.
   - Selecione a opção "coletores".

   ![Imagem 3: Selecione a opção "coletores".](https://storage.crisp.chat/users/helpdesk/website/-/6/5/0/0/65008a97bc074000/29763fe1-dbd6-4c8a-9919-2d7a8a_25rar.png)
4. Em ambas as seções, você encontrará três categorias, cada uma representando um tipo de coletor:

   - **Dispositivo para registro via web:** Configurações relacionadas ao **Site BatePonto**, ideal para registros feitos em computadores ou notebooks.
   - **Aplicativo de registro:** Referente ao **Aplicativo BatePonto**, utilizado exclusivamente para o registro de ponto em dispositivos móveis.
   - **Aplicativo gestão:** Configurações do **Aplicativo Pontotel Gestão**, que combina o registro de ponto com funcionalidades administrativas para gestores.

   ![Imagem 4: Aplicativo gestão: Configurações do Aplicativo Pontotel Gestão , que combina o registro de ponto com funcionalidades…](https://storage.crisp.chat/users/helpdesk/website/-/9/e/1/a/9e1a1dc691a1e000/7bc4b901-b112-475a-82cd-dcc23d_17fi14v.png)

- Como estamos aprovando um computador que utilizará o site BatePonto, selecione a opção "dispositivo para registro via web".

5. Localize na listagem o coletor. Se ele estiver com o status "pendente de aprovação", aparecerá com o ícone indicado abaixo na coluna "status".

   ![Imagem 5: Localize na listagem o coletor. Se ele estiver com o status "pendente de aprovação", aparecerá com o ícone indicado…](https://storage.crisp.chat/users/helpdesk/website/-/3/8/e/c/38ec67113b110800/69b66f4b-c623-462a-81b7-f62ebb_2prfz6.png)
6. Selecione a linha correspondente e, no menu que abrirá, clique no botão indicado para aprovar o coletor.

![Imagem 6: Selecione a linha correspondente e, no menu que abrirá, clique no botão indicado para aprovar o coletor.](https://storage.crisp.chat/users/helpdesk/website/-/6/8/f/d/68fd7041f0d04c00/f06ac786-7ecd-455b-a025-f56119_35cxoy.png)
> 💡 Dica: Você também pode excluir um coletor clicando no ícone da lixeira. Dessa forma, o usuário que fez a solicitação não conseguirá mais utilizar o site BatePonto para registrar o ponto naquele dispositivo, a menos que realize um novo login, o que irá gerar uma nova solicitação de aprovação para o coletor.

---

A aprovação do computador como coletor garante a autenticidade dos registros de ponto e a segurança das informações da sua empresa. É recomendado fazer esse procedimento antes de liberar o uso do equipamento para a equipe.
