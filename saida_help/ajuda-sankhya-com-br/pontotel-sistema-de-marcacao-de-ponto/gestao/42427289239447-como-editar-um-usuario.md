# Como editar um usuário

Editar as informações de um usuário é fundamental para manter os dados sempre atualizados na Pontotel, seja para corrigir dados pessoais, alterar permissões, redefinir senhas ou atualizar o e-mail de acesso. O procedimento é simples e rápido.

---

## Passo a passo

1. No menu de navegação do [site Gestão](https://gestao.pontotel.com.br/), abra o menu **Admin** e clique na opção **Usuários**.
2. Use a barra de busca ou os filtros disponíveis para encontrar o usuário que deseja editar.

   ![Imagem 1: Use a barra de busca ou os filtros disponíveis para encontrar o usuário que deseja editar.](https://storage.crisp.chat/users/helpdesk/website/-/e/3/b/f/e3bf88369bc6a000/da11e806-1261-45c6-8e26-fc9afc_187n5v1.png)
3. Ao selecionar o usuário, um menu se abrirá. Clique no ícone de lápis para abrir a tela de edição.

   ![Imagem 2: Ao selecionar o usuário, um menu se abrirá. Clique no ícone de lápis para abrir a tela de edição.](https://storage.crisp.chat/users/helpdesk/website/-/e/b/b/2/ebb2a92a13f57800/2a72473b-28b1-431d-ac2d-8aef05_apwpac.png)
4. Na tela de edição, ajuste os campos conforme necessário:

   - Nome, e-mail, CPF ou senha de acesso
   - Permissões de acesso (rh, gerente, supervisor, funcionario etc.)
   - Saiba mais sobre permissões [neste artigo](https://sankhya.zendesk.com/hc/pt-br/articles/42427310963095).
   - Vínculo com locais de trabalho ou departamentos
   - Associação de um cadastro de empregado ao usuário

   ![Imagem 3: Associação de um cadastro de empregado ao usuário](https://storage.crisp.chat/users/helpdesk/website/-/6/a/7/3/6a73e96e145a7800/dc0d3cf4-3ffd-4013-b74c-83ab67_1ndb4vv.png)
5. Após conferir e alterar os dados, clique em “**salvar**” para aplicar as mudanças.

![Imagem 4: Após conferir e alterar os dados, clique em “ salvar ” para aplicar as mudanças.](https://storage.crisp.chat/users/helpdesk/website/-/1/4/9/8/149851aab4321d00/068b6270-8692-4a5a-820a-2ba12a_bg9iz6.png)

---

> ⚠️ Atenção: Alterações feitas nos dados do usuário têm efeito imediato. Ao atualizar o e-mail, lembre-se de informar o novo endereço ao colaborador para evitar problemas de acesso.

---

Manter o cadastro dos usuários atualizado é uma prática importante para garantir segurança e agilidade no uso da plataforma.
