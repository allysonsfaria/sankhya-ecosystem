# Como eu programo o aplicativo CND para receber notificações?

Para receber notificações sobre vencimento das certidões você acessa a opção <Notificações>, é possível determinar o tipo de notificação (se a certidão está vencida, próxima ao vencimento ou se até mesmo foi alterado o status da certidão), a origem, as empresas e qual usuário ficará responsável de acompanhar.

Através da opção**<Notificação>** é possível configurar para que receba a notificação da certidão em seu e-mail.
