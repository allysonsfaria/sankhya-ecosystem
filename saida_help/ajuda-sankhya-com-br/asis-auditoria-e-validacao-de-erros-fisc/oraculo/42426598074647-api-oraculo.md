# API (Oráculo)

## Interface de Programação de Aplicativos

O que é: Muitas empresas necessitam possuir todos os documentos fiscais em um diretório interno, para efeito de auditoria seja interna ou externa, e partir dessa necessidade surge a API que consiste na integração entre sistemas, que tem como objetivo facilitar o acesso a todos os documentos que o Oráculo captura e armazena.

Quais opções: Documentos XML de NFe

Como fazer: Para a configuração da API a empresa precisa possuir ou contratar um profissional de TI, para que ele possa desenvolver uma aplicação que consuma a API disponibilizada pelo Oráculo. E não se preocupe, a equipe do Oráculo possui uma documentação a qual o profissional de TI irá utilizar nesse desenvolvimento.

**Documentação:** <https://oraculo.asisprojetos.com.br/docs/api/v2>
