# Qual obrigação acessória usar?

Para as opções:

- Fornecedores com maior crédito de (ICMS)
- Fornecedores com maior crédito de (IPI)
- Fornecedores com maior valor contábil (EFD/ICMS/IPI)

**É necessário o SPED Fiscal.**

Para essas opções:

- Fornecedores com maior crédito de (PIS/COFINS)
- Fornecedores com maior valor contábil (EFD Contribuições)

**É necessário EFD contribuições.**
