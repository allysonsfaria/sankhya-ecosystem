# Quais informações preciso para consultar um CNPJ?

Para realizar uma consulta no Consulta Cadastrar de CNPJ você precisa das seguintes informações:

- RECEITA FEDERAL DO BRASIL: CNPJ;
- SINTEGRA: CNPJ ou CPF + UF;
- SIMPLES NACIONAL: CNPJ
- SUFRAMA: CNPJ + UF + Inscrição Suframa (IS)
