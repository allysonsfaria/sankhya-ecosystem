# Requisitos mínimos dos aplicativos da Vidya Code para Android e IOS.

**Android**:
**Requisito mínimo:** Smartphone com Android 10+ e Memória RAM de 3GB
**Melhor desempenho:** Recomendamos uma memória RAM de 4GB.

**IOS**:
**Versão mínima do sistema operacional:** 13.0 ou superior 
**Modelo do dispositivo:** Iphone 8 ou superior.
