# Campo Empresa vazio no Vidya Force

1. Acesse o Navegador Sankhya e siga para a tela : Configurador de Layout da Nota
2. Selecione o layout - Layout Vidya Force e clique na opção Empresa
3. Modifique o Tipo de valor padrão para: Literal
4. Modifique o Valor padrão para o mesmo numero do código da sua Empresa

   ![Imagem 1: Modifique o Valor padrão para o mesmo numero do código da sua Empresa](https://ajuda.sankhya.com.br/hc/article_attachments/42956828977687)
5. Retorne para o Vidya Force, siga para o menu Atualizar Dados e selecione a opção Atualizar Cabeçalho para receber a nova informação modificada.
