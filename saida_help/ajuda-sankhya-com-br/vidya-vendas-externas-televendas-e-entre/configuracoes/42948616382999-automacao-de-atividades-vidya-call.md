# Automação de Atividades - Vidya Call

Esta tela permite configurar as automações de consulta para o lançamento de atividades na agenda.

**Dias para Consulta**: Define o período, em dias, sem atividade antes que o cliente entre na automação para um contato ativo.

**Dias Úteis para Agendar Atividade:** Considera o início da agenda, verificando no Sankhya se sábados, domingos e feriados são contados como dias úteis.

**Dias sem Atividade para Cliente Inativo:** Determina o número de dias sem atividade após o qual o cliente será considerado inativo pela automação.

**Horário de Início das Agendas:** Define o horário a partir do qual os agendamentos de contato ativo com o cliente podem ser inseridos na agenda.

**Horário de Encerramento das Agendas:** Define o horário máximo para agendamentos.

**Tempo Padrão da Atividade (Minutos):** Estabelece a duração padrão, em minutos, para cada agendamento.
