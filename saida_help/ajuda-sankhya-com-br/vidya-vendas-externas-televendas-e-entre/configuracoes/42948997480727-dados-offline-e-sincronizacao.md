# Dados Offline e Sincronização

## 📌 O que é esta tela?

Acessada pelo menu principal do **Perfil** ou tocando no botão **"Modo Offline"**, esta central gerencia as capacidades de operação sem internet do aplicativo. É a tela responsável por coordenar a importação prévia de dados e o envio em lote de documentos salvos localmente na memória do aparelho.

## 👀 O que você vê

- **Toggle "Modo Offline":** Chave de acionamento que prepara o aplicativo para trabalhar sem sinal de internet.
- **Toggle "Sincronizar ao iniciar":** Interruptor que automatiza o download de dados atualizados toda vez que o software é aberto.
- **Botão "Sincronizar Manualmente":** Comando de download acompanhado do carimbo de data e hora do último procedimento de sucesso.
- **Botão "Visualizar Movimentos Off-line":** Painel com contadores numéricos divididos por categorias (Clientes, Pedidos, Check-in) que indica quantos documentos estão criados e retidos no celular.
- **Botão "Enviar Dados Manualmente":** Comando que força o upload de todos os documentos represados na fila offline para o servidor.
- **Botão "Excluir registros offline":** Opção de segurança para limpeza de cache.
- **Painel de Resultados pós-envio:** Tela gerada após a transmissão de dados contendo:

  - Sinalizadores Coloridos: Verde (sucesso total), Laranja (sucesso parcial) ou Vermelho (erro de transmissão).
  - Mensagens Descritivas: Como "Todos os dados foram enviados com sucesso" ou "Alguns dados não foram enviados".
  - Abas de Filtro: Separação detalhada das listas de cadastros, vendas ou check-ins processados.

## ⚙️ O que dá para fazer aqui?

- **Ativação Preventiva:** Ligar ou desligar o modo offline do aplicativo.
- **Carga de Contingência:** Baixar de forma concentrada novas tabelas de mercadorias, saldos e clientes antes de ir a campo.
- **Auditoria de Documentos Retidos:** Abrir a listagem de movimentos offline para inspecionar pedidos ou check-ins que estão salvos apenas no celular.
- **Despache em Lote:** Forçar a transmissão manual de todos os cadastros e vendas salvos offline assim que reencontrar um sinal Wi-Fi ou rede celular.
- **Limpeza e Depuração:** Apagar o banco de dados temporário para liberar espaço interno ou corrigir travamentos.

## 💡 Observações e Dúvidas Comuns

> 📶 **Planejamento Obrigatório:** O Modo Offline não faz mágica. Você precisa ativá-lo e realizar a sincronização manual dos dados enquanto ainda tiver internet estável antes de entrar em áreas sem sinal de operadora. Não é possível importar tabelas de produtos se o celular já estiver desconectado.
>
> 🔄 **Bloqueio do Botão de Carga:** O comando "Sincronizar Manualmente" ficará cinza/desabilitado se o seu celular estiver conectado a uma rede online ativa e estável, uma vez que o aplicativo realiza as atualizações de forma automática em segundo plano nessas condições.
>
> 🛑 **Ação Irreversível:** Clicar em **"Excluir registros offline"** é uma operação de alto risco. Ela apagará permanentemente todos os pedidos finalizados e cadastros de clientes novos guardados no aparelho que ainda não tenham sido transmitidos para a matriz. Use este comando apenas sob orientação do suporte técnico.
