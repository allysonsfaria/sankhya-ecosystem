# Parâmetro - Permite alterar a data de Negociação

Em casos de pedidos que foram criados em uma data e enviado em outro, podemos deixar desmarcado o parâmetro :Permite alterar a data de Negociação, fazendo com que a data de Movimentação sejam mantidas diferentes dentro do aplicativo Vidya FORCE.

Do contrário, marcado, a data será modificada para igualar ambas.
