# Cadastros Básicos - Usuário Vidya Force

Para realizar o **cadastramento de um novo usuário vendedor** no ERP Sankhya, é necessário seguir alguns passos essenciais que envolvem:

1. Criação do **usuário no sistema**.
2. Associação ao **parceiro (vendedor)**.
3. Atribuição de **permissões** e, se necessário, **papéis** no Sankhya.

## ✅ Passo a Passo para Cadastrar um Novo Usuário Vendedor

---

### 🔹 1. Criar o Vendedor

**Tela:** `Vendedores/Compradores`
**Caminho:** `Configurações >``Cadastros > Vendedores/Compradores`

1. Localize o vendedor ou crie um novo.
2. Preencha os campos necessários.
3. Salve o cadastro.

⚠️ Importante: essa associação é necessária para que o sistema reconheça o usuário como vendedor, especialmente em filtros e relatórios de vendas.

### Imagem 1: 🔹 2. Criar o Usuário no Sistema 🔹 2. Criar o Usuário no Sistema

**Tela:** `Usuários`
**Caminho:** `Configurações > Segurança > Usuários`

1. Clique em **"Novo"** para criar um novo usuário.
2. Preencha os campos obrigatórios:

   - **Nome do usuário**
   - **Login**
   - **Senha**
   - **E-mail** (se necessário para notificações ou Sankhya Om)
   - **Empresa Padrão**
3. Marque a opção **"Ativo"**.
4. Vincule ao Vendedor anteriormente cadastrado.
5. Clique em **Salvar**.

   ![Imagem 2: Clique em Salvar .](https://ajuda.sankhya.com.br/hc/article_attachments/42956810902295)

### 🔹 3. Criar carteira do vendedor Tela: `Parceiros` Caminho: `Configurações >``Cadastros >``Parceiros`

    Caso os parceiros ainda não estejam vinculados à carteira do vendedor, existem duas formas de realizar essa associação:

1. Via tela de Vendedores/Compradores
   - Acesse novamente a tela "Vendedores/Compradores".
   - Vá até a aba "Parceiros".
   - Adicione os parceiros que fazem parte da carteira do vendedor

     ![Imagem 3: Adicione os parceiros que fazem parte da carteira do vendedor](https://ajuda.sankhya.com.br/hc/article_attachments/42956827978519)
2. Via cadastro do parceiro
   - Acesse o cadastro do parceiro desejado.
   - Na aba "Identificação", preencha o campo "Vendedor Preferencial" com o nome ou código do vendedor.

     ![Imagem 4: Na aba "Identificação", preencha o campo "Vendedor Preferencial" com o nome ou código do vendedor.](https://ajuda.sankhya.com.br/hc/article_attachments/42956850655255)
