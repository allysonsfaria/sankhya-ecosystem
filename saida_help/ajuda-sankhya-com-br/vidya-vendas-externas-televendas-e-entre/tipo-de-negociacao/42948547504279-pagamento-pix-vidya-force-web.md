# Pagamento PIX - Vidya Force WEB

**Obs.:** as configurações e telas se aplicam também aos nossos outros produtos, não apenas ao Force WEB

**Configurações**

No Sankhya, o pagamento via PIX deve estar configurado mediante as informações únicas, geradas pelo Adquirente e passadas para á nossa equipe, e associado a um tipo de negociação específico. Essa configuração é feita na tela de Configuração PIX.

![Imagem 1: No Sankhya, o pagamento via PIX deve estar configurado mediante as informações únicas, geradas pelo Adquirente e…](https://ajuda.sankhya.com.br/hc/article_attachments/42956981994007)

**Como Gerar o PIX**

Ao utilizar esse tipo de negociação, é possível gerar um código PIX de duas formas:
- Copia e cola
- QR Code

Para isso, acesse o pedido referente, clique nos três pontos na tela de vendas e selecione a opção "PIX".

![Imagem 2: Para isso, acesse o pedido referente, clique nos três pontos na tela de vendas e selecione a opção "PIX".](https://ajuda.sankhya.com.br/hc/article_attachments/42956944849943)

**Requisitos para Gerar o QR Code**

O QR Code só pode ser gerado se o status do pedido estiver como "Confirmado". Caso o pedido não tenha sido confirmado, o QR Code não será gerado.

**Status do PIX no Sankhya**

No Sankhya, na tela de Portal de vendas, a coluna "Status do PIX" ficará como "PIX Não Gerado" se o pedido não estiver confirmado e como "PIX Pago" quando houver a conclusão com sucesso do pagamento do pedido pelo PIX. Se essa coluna estiver em branco, significa que o tipo de negociação selecionado não está vinculado ao PIX.

**Telas Importantes para o Controle do PIX**

**1. Configuração PIX - Vidya:** Essa tela permite configurar as opções de pagamento via PIX, desde tempo de expiração do QR Code/Copia e Cola e Tipo de Negociação que estará atrelado o PIX.

**2. Lançamentos PIX:** Essa tela registra todos os links de pagamento PIX gerados. Ao clicar no ícone de raio dentro dessa tela, você pode:
- Visualizar o pedido na central de vendas.
- Atualizar o status do pagamento manualmente.

![Imagem 4: 1. Configuração PIX - Vidya: Essa tela permite configurar as opções de pagamento via PIX, desde tempo de expiração do…](https://ajuda.sankhya.com.br/hc/article_attachments/42956945306135)

(Obs.: Dentro do Vidya Force Web, na própria tela de exibição do QR Code, existe um botão de "Atualizar", onde o vendedor pode validar e atualizar o status do pagamento de forma manual.)

**Ações Agendadas**

Além disso, há uma tela de Ações Agendadas, onde o sistema realiza consultas automáticas ao banco de dados a cada 5 minutos para verificar o status do pagamento via PIX.

Essas funcionalidades ajudam a garantir que os pagamentos via PIX sejam gerenciados de maneira eficiente, mantendo o status sempre atualizado e permitindo um controle preciso das transações.
