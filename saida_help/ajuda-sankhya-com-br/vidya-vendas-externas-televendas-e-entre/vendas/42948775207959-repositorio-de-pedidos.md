# Repositório de pedidos

O Repositório é uma ferramenta responsável por recuperar pedidos que foram perdidos. Isso pode ocorrer quando um pedido é salvo offline e por algum motivo(aplicativo fecha sozinho, celular desligou ou até mesmo uma exclusão acidental) é perdido

Essa ferramenta tem dois botões:

- Restaurar: ao clicar neste botão, o pedido volta para a tela de Vendas, na aba Não Enviados com os mesmo itens que ele possuía anteriormente
- Compartilhar: este botão permite baixar o pedido ou enviar via WhatsApp, e-mail e etc.
