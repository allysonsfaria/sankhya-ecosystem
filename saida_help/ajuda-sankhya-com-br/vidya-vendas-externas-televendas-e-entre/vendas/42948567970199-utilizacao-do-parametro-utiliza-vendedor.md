# Utilização do Parâmetro "Utiliza Vendedor do Parceiro para Venda"

##

No contexto das operações de vendas, é importante configurar corretamente os parâmetros do sistema para garantir que as transações sejam atribuídas aos vendedores corretos. Um dos parâmetros cruciais é o "Utiliza vendedor do parceiro para venda". Este artigo explica a funcionalidade deste parâmetro e como configurá-lo adequadamente.

### Descrição do Parâmetro

**Parâmetro: Utiliza vendedor do parceiro para venda?**

Este parâmetro determina qual vendedor será atribuído a uma venda específica. Ele possui duas configurações possíveis:

- **Sim**: Quando esta opção está ativada, o vendedor vinculado ao parceiro será utilizado para a venda.
- **Não**: Quando esta opção está desativada, o vendedor que emitiu a venda será utilizado.

### Exemplos de Utilização

Para ilustrar o uso deste parâmetro, considere o seguinte cenário:

**Cenário: Venda Realizada pelo Gerente**

Imagine que um gerente deseja realizar uma venda, mas quer que a venda seja registrada como se fosse feita por um vendedor específico vinculado a um parceiro. Para que isso aconteça, o gerente deve seguir estes passos:

1. **Ativar o Parâmetro**: Acesse as configurações do sistema e ative o parâmetro "Utiliza vendedor do parceiro para venda".
2. **Atualizar o Aplicativo**: Certifique-se de que o aplicativo está atualizado com as configurações mais recentes.
3. **Realizar a Venda**: Prossiga com a venda. Com o parâmetro ativado, a venda será registrada sob o vendedor vinculado ao parceiro, e não sob o gerente que a realizou.

Esta funcionalidade é particularmente útil em situações onde a comissão ou o crédito pela venda precisa ser atribuído a um vendedor parceiro, independentemente de quem realizou a transação.

### Conclusão

Configurar corretamente o parâmetro "Utiliza vendedor do parceiro para venda" é essencial para a correta atribuição de vendas e comissões. Ao entender e utilizar este parâmetro, as empresas podem garantir que as vendas sejam registradas de acordo com suas políticas de atribuição de vendedores, proporcionando uma gestão mais eficiente e transparente das operações de venda.
