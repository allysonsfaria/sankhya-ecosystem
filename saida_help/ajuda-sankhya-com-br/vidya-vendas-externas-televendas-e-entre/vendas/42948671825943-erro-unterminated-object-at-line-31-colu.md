# Erro: 'Unterminated Object at Line 31 Column 25' ao enviar venda.

**Unterminated Object at Line 31 Column 25"**
![Imagem 1: Unterminated Object at Line 31 Column 25"](https://ajuda.sankhya.com.br/hc/article_attachments/42957102513431)

Esse erro aponta para algo malformado, como um objeto JSON incompleto, geralmente no backend. A solução? Atualizar o serviço no AWS.

## Passos Rápidos:

1. Verifique os logs e identifique a origem do problema.
2. Acesse o console AWS, reimplante o backend e aplique as atualizações necessárias.
3. Teste a aplicação para garantir que o problema foi resolvido.
