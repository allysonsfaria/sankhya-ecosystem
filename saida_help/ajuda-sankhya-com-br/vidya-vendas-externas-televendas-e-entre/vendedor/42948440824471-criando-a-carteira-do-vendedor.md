# Criando a carteira do Vendedor

1. Para criar a carteira de clientes/parceiros do vendedor, basta acessar a Tela de Cadastro de Parceiros, escolher um Parceiro e incluir o Vendedor Preferencial.

   ![Imagem 1: Para criar a carteira de clientes/parceiros do vendedor, basta acessar a Tela de Cadastro de Parceiros, escolher um…](https://ajuda.sankhya.com.br/hc/article_attachments/42956759996951)
2. Caso deseje vincular outros vendedores para os mesmos parceiros, siga para a tela de Vendedores / Compradores, selecione o vendedor, e na tela de Parceiros, você conseguirá vincular clientes, e qualquer vendedor com esses clientes cadastrados podem realizar vendas.
