**- Calcular imposto ICMS/ST quando tiver Pauta:** Foi criada uma funcionalidade para utilizar o valor da tabela vindo da requisição de alíquota, em vez do valor do produto vendido. (Melhoria para clientes específicos que utilizam essa rotina)

**Correções e Ajustes**
**- Valor de item CX divergente:**Foi adicionado uma funcionalidade para que o valor das unidade de medidas seja exibido o valor de tabela somado ao IPI. (Ajuste para clientes específicos)

**- Lentidão na inserção de item:**A verificação dos produtos sugeridos foi restringida. Antes, ela era realizada para todos os produtos, mas agora ocorre apenas para aqueles que realmente possuem produtos sugeridos.

Além disso, outro fator que está causando lentidão é o alto valor do delay do debounce da quantidade, atualmente configurado em 700ms(ATRASOALTQD). Quando o usuário altera rapidamente a quantidade de um produto e passa para outro para realizar uma nova alteração, o debounce do produto anterior ainda não foi executado, resultando em lentidão. O ideal seria reduzir esse valor para algo entre 300ms e 450ms.
