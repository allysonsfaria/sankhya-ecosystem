# Atualização de Versão - Link no App

Nesse artigo mostraremos como Disponibilizar uma nova versão para os usuários, dentro do app Vidya Force.

Utilizaremos a tela **'Configurações - Vidya Code/Force'** dentro do Sankhya para realizar a configuração, onde preencheremos os seguintes campos:

**• Link Última Versão (Android):** Preenchido com o Link disponibilizado pela Vidya com a versão para dispositivos Androids;

**• Link última Versão (iOS):** Preenchido com o Link disponibilizado pela Vidya com a versão para dispositivos IOS;

**• Número da Versão Atual:** Número da Versão do aplicativo disponibilizado

![Imagem 1: • Número da Versão Atual: Número da Versão do aplicativo disponibilizado](https://ajuda.sankhya.com.br/hc/article_attachments/42957090203543)

Após o preenchimento, realizar a Sincronização do Aplicativo e seguir para a tela de Perfil, e no campo Versão, estará disponivel o botão 'Atualizar Versão', clicavel ao lado direito.

![Imagem 2: Após o preenchimento, realizar a Sincronização do Aplicativo e seguir para a tela de Perfil, e no campo Versão, estará…](https://ajuda.sankhya.com.br/hc/article_attachments/42957104830359)

Clicando no botão, o app irá redirecionar para o link da versão configurado anteriormente no Sankhya, em seguida o usuário poderá atualizar a versão fazendo o download.

![Imagem 3: Clicando no botão, o app irá redirecionar para o link da versão configurado anteriormente no Sankhya, em seguida o…](https://ajuda.sankhya.com.br/hc/article_attachments/42957060811927)

Dessa forma irá facilitar o envio das versões atualizadas e facilitar também a atualização por parte dos usuários.
