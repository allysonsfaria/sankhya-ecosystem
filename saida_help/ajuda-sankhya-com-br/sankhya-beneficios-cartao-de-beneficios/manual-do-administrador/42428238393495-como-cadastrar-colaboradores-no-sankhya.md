# Como cadastrar colaboradores no Sankhya Benefícios

O cadastro de colaboradores é o primeiro passo para iniciar as configurações da plataforma. Na aba “Pessoas”, você poderá cadastrá-los adicionando um a um ou por meio de importações.

## Cadastro manual

1. Acesse o menu **Pessoas**;
2. Clique em **Adicionar Pessoa**;
3. Preencha os dados solicitados:

   - Nome
   - Sobrenome
   - CPF
   - E-mail
   - Telefone
   - Endereço

![Imagem 1: Endereço](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73214418966/original/kgUQ_I0T40YLUEYeIor34swC5O_5s3VB1A.png?1770658318)

## Importação de colaboradores via planilha

Além do cadastro manual, é possível adicionar colaboradores via **planilha de carga**.

## Como importar

1. Acesse o menu **Pessoas**;
2. Baixe o modelo de planilha disponibilizado;
3. Preencha os dados conforme o padrão;
4. Faça a importação do arquivo;
5. Escolha se os colaboradores receberão e-mail para criação de senha.

**Atenção**

- Os dados devem estar **idênticos aos da Receita Federal**;
- Evite abreviações;
- Certifique-se de que e-mail e telefone estejam corretos.

![Imagem 2: Certifique-se de que e-mail e telefone estejam corretos.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73214419676/original/jroBcnRLObrcNq7iAnLbZDgg1FUjXSZAgA.png?1770658463)

## Análise e aprovação dos cadastros

Todos os cadastros passam por uma **análise automática** para validação dos dados com a Receita Federal.

O administrador pode:

- Acompanhar o status do cadastro;
- Realizar correções, se necessário.

> Apenas colaboradores com cadastro **Aprovado** podem:

- Ser vinculados a times;
- Receber pedidos de saldo.
