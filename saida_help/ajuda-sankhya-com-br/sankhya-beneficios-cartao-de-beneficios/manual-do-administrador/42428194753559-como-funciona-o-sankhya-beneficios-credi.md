# Como funciona o Sankhya Benefícios Crédito

O **Sankhya Benefícios Crédito** é a **carteira da empresa** dentro da plataforma.
Esse saldo **não vai automaticamente para os cartões dos colaboradores**.

Ele funciona como um **saldo central**, que o administrador utiliza depois para **pagar os pedidos de benefícios** (recargas) que serão distribuídos conforme as regras e configurações feitas na plataforma.

## Em resumo

- O crédito fica **na conta da empresa**;
- O saldo só é distribuído aos colaboradores **quando um pedido é criado e pago**;
- A distribuição respeita:

  - As **regras de saldo** configuradas;
  - Os **benefícios/categorias** contratados;
  - Os **times** (se aplicável).

## Como recarregar o Sankhya Benefícios Crédito

1. Acesse o menu **Sankhya Benefícios Crédito**;
2. Escolha a forma de recarga:

   - **PIX**
   - **Boleto bancário**;
3. Aguarde a compensação do pagamento;
4. O valor ficará disponível como **saldo da empresa** na plataforma.

## Como esse saldo é distribuído aos colaboradores

Após a recarga, o saldo **não é liberado automaticamente**.

Para distribuir o valor aos cartões/benefícios dos colaboradores, é necessário:

1. Criar um **pedido** (recarga):

   - Recarga única,
     **ou**
   - Pedido baseado em **regras de saldo**;
2. Selecionar:

   - Os colaboradores ou times;
   - A categoria do benefício (alimentação, refeição, mobilidade etc.);
3. No momento do pagamento do pedido, escolher o **Sankhya Benefícios Crédito** como forma de pagamento.

Somente após o pedido ser **confirmado e pago**, o saldo será:

- Distribuído entre os benefícios configurados;
- Disponibilizado nos **cartões dos colaboradores**, conforme as regras definidas.

Saiba mais em: [Como criar pedidos de recarga para cartões dos colaboradores](https://sankhya.zendesk.com/hc/pt-br/articles/42428214220951)
