# Problemas de impressão notas/pedidos

**(1)** Algumas situações podem causar falhas ao imprimir documentos no sistema. Com base nos cenários mais comuns, listamos algumas verificações iniciais que podem ser realizadas:

Para mais detalhes: Navegador Sankhya. Atente-se em utilizar uma versão desse navegador atualizada, conforme versões disponibilizadas em: [Downloads Sankhya](https://downloads.sankhya.com.br/)

![Imagem 2: Realize o teste por mais de um usuário . Caso a impressão ocorra normalmente com o usuário SUP, certifique-se que os…](https://ajuda.sankhya.com.br/hc/article_attachments/16142571945623) Realize o teste por **mais de um usuário**. Caso a impressão ocorra normalmente com o usuário SUP, certifique-se que os demais usuários possuem os acessos necessários para impressão do respectivo arquivo.

**![Imagem 3: Desvincule Impressoras:](https://ajuda.sankhya.com.br/hc/article_attachments/16142541322007) Desvincule Impressoras:**

Disponibilizado no menu de contexto, a opção Desvincular Impressoras, uma vez acionada irá apresentar o questionamento se deseja desvincular as impressoras. Clicando em Sim, o sistema desfaz o salvamento das impressoras para a impressão de lançamentos, no qual é possível salvar alteração no momento de selecionar a impressora.

Realizado o processo acima, realize um novo teste, caso problema persista siga para o próximo tópico.
