# Sistema não refaz o desconto promocional por quantidade quando fatura pedidos agrupados para uma nota

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26513695115543) **MENSAGEM:**

Sistema não refaz o desconto promocional por quantidade quando fatura pedidos agrupados.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26513712030359)SOLUÇÃO:**

Essa situação é um comportamento do sistema, pois ele não refaz o desconto quando são faturados pedidos agrupados, mantendo a soma dos pedidos. O sistema respeita o que foi negociado nos pedidos.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26513712031127)CAUSA:**

O erro acontece quando se trabalha com descontos promocionais por quantidade e são feitos pedidos que entraram na promoção, mas depois são faturados agrupados, gerando uma única nota.
