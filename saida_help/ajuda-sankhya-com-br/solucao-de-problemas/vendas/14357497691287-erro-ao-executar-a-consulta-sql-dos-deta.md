# Erro ao executar a consulta SQL dos detalhes adicionais de preço: O comando SELECT está em formato inválido

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16866565258007) MENSAGEM:**

[COM\_E00177]: Erro ao executar a consulta SQL dos detalhes adicionais de preço: O comando SELECT está em formato inválido.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16866565269911)SOLUÇÃO:**

![Imagem 3: Acesse a Consulta de produtos - Comercial » Consulta » Consulta de Produtos , clique no botão "Configuração Consulta de…](https://ajuda.sankhya.com.br/hc/article_attachments/16866579992343) Acesse a **Consulta de produtos -** Comercial » Consulta » Consulta de Produtos, clique no botão **"Configuração Consulta de Produto"**.

![Imagem 4: Acesse a Consulta de produtos - Comercial » Consulta » Consulta de Produtos , clique no botão "Configuração Consulta de…](https://ajuda.sankhya.com.br/hc/article_attachments/14357562229015)

![Imagem 5: Clique na aba "Detalhes Adicionais de Preço" e confira o campo "Expressão SQL" para detalhes adicionais de preço, se…](https://ajuda.sankhya.com.br/hc/article_attachments/16866565287831) Clique na aba **"Detalhes Adicionais de Preço"** e confira o campo **"Expressão SQL"** para detalhes adicionais de preço, se possui expressão e se esta está com espaço.

Caso tenha algum espaço na expressão é necessário retirar.

![Imagem 6: Caso tenha algum espaço na expressão é necessário retirar.](https://ajuda.sankhya.com.br/hc/article_attachments/16866580007063)

**![Imagem 7: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16866580011799)CAUSA:**

Ocorre quando o comando contém sintaxe errada, quando o comando possui algum espaço vazio.
