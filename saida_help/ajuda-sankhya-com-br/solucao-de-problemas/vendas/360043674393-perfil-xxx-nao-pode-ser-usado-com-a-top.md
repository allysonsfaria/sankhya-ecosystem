# Perfil 'XXX' não pode ser usado com a TOP XXXX

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16309752610455) MENSAGEM:**

[CORE\_E02941] Perfil 'XXX' não pode ser usado com a TOP XXXX.

[CORE\_E02940] Usuário 'xxxx' não pode usar a TOP xxxx.

![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16309722002839) **CAUSA:**

Ocorre quando o lançamento está utilizando Perfil Principal que tenha restrições e/ou validações em relação a TOP utilizada.

![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16309752615575) **SOLUÇÃO:**

![Imagem 4: Anote o Tipo de Operação (TOP) que está sendo utilizado e siga com as orientações abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/16309752619415) Anote o Tipo de Operação (TOP) que está sendo utilizado e siga com as orientações abaixo:

**(2)** Acesse o cadastro de TOP’s (Caminho de acesso: Comercial » Arquivo » Cadastros » [**Tipos de Operação - TOP**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP)).

**(2)** Acione o botão **"Outras Opções"** » [**Restrições/Exceções**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP#restricoeseexcecoes).

![Imagem 5: Verifique se existem regras vinculadas para "Perfil Principal": Caso positivo, realize os ajustes, de forma que o…](https://ajuda.sankhya.com.br/hc/article_attachments/16309752626839) Verifique se existem regras vinculadas para **"Perfil Principal":** Caso positivo, realize os ajustes, de forma que o perfil desejado seja incluído, ou certifique se outro perfil deverá ser utilizado no lançamento.

**OBSERVAÇÃO:**

Caso a mensagem seja (Usuário 'xxxx' não pode usar a TOP xxxx) verifique se há restrições/exceções para o usuário.
