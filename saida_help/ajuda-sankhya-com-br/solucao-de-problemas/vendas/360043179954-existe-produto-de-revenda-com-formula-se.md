# Existe Produto de Revenda com Fórmula sem digitação das Mat.Primas

[CORE\_E02090] Existe Produto de Revenda com Fórmula sem digitação das Mat.Primas.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16162088848535) SOLUÇÃO:**

![Imagem 3: Verifique para os itens inseridos no respectivo lançamento se algum deles está configurado com o campo "Usado Como" da…](https://ajuda.sankhya.com.br/hc/article_attachments/16162088850199) Verifique para os itens inseridos no respectivo lançamento se algum deles está configurado com o campo **"Usado Como"** da aba **"Geral"** = **Revenda (Por fórmula)**:

**(2)** Para tal acesse a tela **"[Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Cadastro-de-Produtos-)"** (Caminho de acesso: Configurações » Cadastros » Produtos » Produtos).

![Imagem 4: (2) Para tal acesse a tela " Produtos " (Caminho de acesso: Configurações » Cadastros » Produtos » Produtos) .](https://ajuda.sankhya.com.br/hc/article_attachments/14676274420375)

Considere o processo da empresa e ajuste a informação acima corretamente. Após ajustes redigite o cabeçalho do lançamento e teste sua confirmação.

![Imagem 5: Se definido = Revenda (Por fórmula) revise as configurações desse processo. Caso trate-se de vendas por KIT, será…](https://ajuda.sankhya.com.br/hc/article_attachments/16162106242455) Se definido = Revenda (Por fórmula) revise as configurações desse processo. Caso trate-se de vendas por KIT, será possível analisar detalhes das configurações necessárias através dos artigos abaixo, de acordo com o planejado para sua empresa:

**(2)** Venda de Kits de Produtos: **"**[**Suporte a Venda de Kits de Produtos"**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045111433)

**(2)** Configuração para Kit Independente: **"[Configuração de Kit](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596554)"**

Ressaltamos que essa configuração deverá ser validada com os Consultores de sua Filial/Franquia.
