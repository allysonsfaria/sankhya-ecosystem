# Rejeição NFS-e E030: Item da lista de serviço inexistente

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16137550845847) MENSAGEM:**

E030: Item da lista de serviço inexistente
Possível solução: Consulte a legislação vigente para saber o item da lista de serviço que deverá ser informado neste campo. (RPS Número: X Série: A)

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16137587109783) SITUAÇÃO:**

Ao gerar lote de uma NFS-e, é apresentada a mensagem de rejeição.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16137550853783) SOLUÇÃO:**

![Imagem 4: Entre em contato com a Prefeitura para verificar a relação de Lista de Serviço.](https://ajuda.sankhya.com.br/hc/article_attachments/16137587118231) Entre em contato com a Prefeitura para verificar a relação de Lista de Serviço.

![Imagem 5: Acesse Comercial » Arquivo » Cadastros » Lista de Serviços:](https://ajuda.sankhya.com.br/hc/article_attachments/16137550860823) Acesse Comercial » Arquivo » Cadastros » Lista de Serviços:

- Identifique se o serviço prestado possui uma relação com a Lista de Serviço. Caso não, faça o cadastro de acordo com a lista adquirida na Prefeitura.

![Imagem 6: Identifique se o serviço prestado possui uma relação com a Lista de Serviço. Caso não, faça o cadastro de acordo com a…](https://ajuda.sankhya.com.br/hc/article_attachments/12121784125079)

![Imagem 7: Acesse Configurações » Cadastros » Produtos » Serviço:](https://ajuda.sankhya.com.br/hc/article_attachments/16137550862487) Acesse Configurações » Cadastros » Produtos » Serviço:

- Aba: **Impostos**
- Campo **"Tipo de Serviço"**: informe o código correto neste campo

![Imagem 8: Campo "Tipo de Serviço" : informe o código correto neste campo](https://ajuda.sankhya.com.br/hc/article_attachments/14635194007959)

![Imagem 9: Acesse o Portal de Vendas e gere novo lote de envio para esta NFS-e.](https://ajuda.sankhya.com.br/hc/article_attachments/16137587125527) Acesse o Portal de Vendas e gere novo lote de envio para esta NFS-e.

![Imagem 10: Acesse o Portal de Vendas e gere novo lote de envio para esta NFS-e.](https://ajuda.sankhya.com.br/hc/article_attachments/14635200305047)

**![Imagem 11: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16137550866199) CAUSA:**

Esta mensagem é apresentada, pois o item da lista de serviço utilizado não está cadastrado no site da Prefeitura em questão.
