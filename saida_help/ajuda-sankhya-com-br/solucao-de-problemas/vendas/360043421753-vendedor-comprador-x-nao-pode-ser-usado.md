# Vendedor/Comprador 'X' não pode ser usado com a TOP 'Y'

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16309685388951) MENSAGEM:**

[CORE\_E02943]: Vendedor/Comprador 'X' não pode ser usado com a TOP 'Y'.

![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16309670188439) **SOLUÇÃO:**

![Imagem 3: Anote o Tipo de Operação (TOP) que está sendo utilizado e siga com as orientações abaixo.](https://ajuda.sankhya.com.br/hc/article_attachments/16309685392791) Anote o Tipo de Operação (TOP) que está sendo utilizado e siga com as orientações abaixo.

Acesse o cadastro de TOP’s (Caminho de acesso à tela: Comercial » Arquivo » Cadastros» [**Tipos de Operação - TOP**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP)).

Acione o botão **Outras Opções » [Restrições/Exceções](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP#restricoeseexcecoes)**.

![Imagem 4: Verifique se existem regras vinculadas para "Vendedor/Comprador" :](https://ajuda.sankhya.com.br/hc/article_attachments/16309685400855) Verifique se existem regras vinculadas para **"Vendedor/Comprador"**:

![Imagem 5: Verifique se existem regras vinculadas para "Vendedor/Comprador" :](https://ajuda.sankhya.com.br/hc/article_attachments/14340064550935)

Para utilização dessa TOP com esse Vendedor/Comprador, essa linha deverá ser excluída de exceções.

Caso a marcação fosse para Restrições (só pode ser usado com), o Vendedor/Comprador desejado deverá constar nessa lista.

![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16309685405463) **CAUSA:**

Ocorre ao vincular determinado Vendedor/Comprador a lançamentos com Tipos de Operação que possuem restrições relacionadas ao código vendedor/comprador inserido.
