# Há diferença entre a base do PIS e COFINS para itens da nota com número único XXX

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19067571497623) MENSAGEM:**

[CORE\_E04467] Há diferença entre a base do PIS e COFINS para itens da nota com número único XXX. Favor, entre em contato com a Sankhya.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19067571504023) SITUAÇÃO:**

Ao tentar confirmar uma nota a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19067608765079) CAUSA:**

Ocorre quando não existe uma alíquota de PIS e COFINS cadastrada para a TOP utilizada no lançamento.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19067608773015) SOLUÇÃO:**

É necessário que exista uma alíquota de COFINS configurada para TOP utilizada. Para isso, acesse a tela **Alíquotas de COFINS** (Caminho de acesso à tela: Comercial » Arquivo » Cadastros » Alíquotas » Alíquotas de COFINS) e cadastre a alíquota para a TOP utilizada no lançamento.
