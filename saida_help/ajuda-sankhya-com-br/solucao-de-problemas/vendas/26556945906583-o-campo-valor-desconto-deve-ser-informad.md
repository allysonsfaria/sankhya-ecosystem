# O campo 'Valor desconto' deve ser informado

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26556945879703) **MENSAGEM:**

[CORE\_E03236] O campo 'Valor desconto' deve ser informado. Código:

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26556945880599)SOLUÇÃO:**

Preencha o campo **"Valor desconto"** na grade de itens antes de salvar o item. Caso não deseje aplicar descontos no item, o campo deve ser preenchido com o valor 0.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26556961083927)CAUSA:**

O erro ocorre ao tentar salvar um item na grade e o campo Valor Desconto não tem nenhum valor informado. O sistema preenche automaticamente com o valor 0, mas se for apagado, o erro será apresentado.
