# Não foi encontrado produto com o código de barras: 'X'

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16161969260823) MENSAGEM**:

[COM\_E00025] Não foi encontrado produto com o código de barras: 'X'.

[COM\_E00026] Não foi encontrado produto cadastrado com o código: XXXXX e Cód. barras: XXXXX.

**![Imagem 2: SITUAÇÃO :](https://ajuda.sankhya.com.br/hc/article_attachments/16161970671639) SITUAÇÃO**:

Ao bipar ou digitar o código de barras dos produtos para realizar uma conferência, pela tela 'Fila de Conferência' ocorre a mensagem.

**![Imagem 3: CAUSA :](https://ajuda.sankhya.com.br/hc/article_attachments/16161969271063) CAUSA**:

Ocorre quando o sistema não consegue identificar esse código de acordo com os cadastros atuais de produtos.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16161970672663) SOLUÇÃO:**

![Imagem 5: Certifique-se de que o código de barras inserido na Fila de Conferência está correto.](https://ajuda.sankhya.com.br/hc/article_attachments/16161970674583) Certifique-se de que o código de barras inserido na Fila de Conferência está correto.

![Imagem 6: Caso o código esteja correto, verifique na tela de " Produtos " (Caminho de acesso: Configurações » Cadastros »…](https://ajuda.sankhya.com.br/hc/article_attachments/16161969267479) Caso o código esteja correto, verifique na tela de **"[Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Cadastro-de-Produtos-)"** (Caminho de acesso: Configurações » Cadastros » Produtos) se o código de barras digitado corresponde ao registrado/cadastrado nos campos abaixo:

**(2)** Referência

**(2)** Cód. Barras (aba Código de Barras)

**(2)** Código de Barras (aba Unidade Alternativa)

**(2)**Cód. de Barras (aba Estoque)

![Imagem 7: Caso o cadastro esteja incorreto, realize os devidos ajustes e retorne ao processo de conferência.](https://ajuda.sankhya.com.br/hc/article_attachments/16161969270295) Caso o cadastro esteja incorreto, realize os devidos ajustes e retorne ao processo de conferência.
