# Erro interno: XML de retorno para consulta de situação de lote com formato inesperado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16305814132119) MENSAGEM:**

[CORE\_E00590] Erro interno: XML de retorno para consulta de situação de lote com formato inesperado.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16305838727575) SITUAÇÃO:**

Ao tentar enviar a nota para a prefeitura a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16305838730775) SOLUÇÃO:**

Provavelmente as notas ficaram travadas devido alguma indisponibilidade momentânea da Prefeitura. Sendo assim, caso essa mensagem seja apresentada, entre em contato com o Suporte para uma análise e possíveis ajustes.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16305814139159) CAUSA:**

Ocorre quando a NFS-e fica "Travada" na Integração com a Prefeitura e ao Tentar Buscar Autorização da NFS-e essa Mensagem é retornada.
