# O tipo de negociação não foi informado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16939068423447) MENSAGEM:**

[CORE\_E03960]: Tipo de negociação não foi informado.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16939023084183) SOLUÇÃO:**

Informe um tipo de negociação para os lançamentos, pois esse campo não permite nulo.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16939023086743) CAUSA:**

Ocorre quando o campo Tipo de negociação fica sem informação.
