# Algumas telas ou recursos do sistema estão indisponíveis por problema na licença de uso 

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16625021846423) MENSAGEM:**

LU0005: Algumas telas ou recursos do sistema estão indisponíveis por problema na licença de uso.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16625021849239) SOLUÇÃO:**

Realize os seguintes passos:

**(1)** Verifique se o servidor possui acesso à internet;

**(1)** Verifique data e hora do servidor;

**(1)** Reinicie o servidor para que algum possível serviço travado volte a funcionar;

**(1)** Reinicie o serviço do SAS.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16625011631511) CAUSA:**

Mensagem é apresentada assim que o usuário faz o login no Jiva G1, ao clicar em Ok o sistema fecha, impossibilitando o acesso às telas.

Os motivos mais comuns que geram o erro são:

Data e hora do servidor divergentes, serviço do SAS parado, servidor sem acesso a internet.
