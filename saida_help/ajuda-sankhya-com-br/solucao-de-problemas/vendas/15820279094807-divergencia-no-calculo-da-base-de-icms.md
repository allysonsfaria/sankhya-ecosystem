# Divergência no calculo da base de ICMS

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/15820279085591) MENSAGEM:**

[CORE\_E04875] Problema no cálculo da base de ICMS.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15820233042967) CAUSA:**

Ocorre quando a TOP está definida para proporcionalizar o ICMS.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15820263376535) SOLUÇÃO:**

Verifique no cadastro do **Tipos de Operação - TOP -** Financeiro » Arquivos » Cadastros » Tipos de Operação - TOP se o campo 'ICMS proporcional para Destaque' está selecionado.
