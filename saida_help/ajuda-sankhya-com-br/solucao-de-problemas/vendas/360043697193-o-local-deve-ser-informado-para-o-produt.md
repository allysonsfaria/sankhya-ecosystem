# O local deve ser informado para o produto

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16165414555927) MENSAGEM:**

[CORE\_E00778] O local deve ser informado para o produto.

**![Imagem 2: SOLUÇÃO PARA PRODUTOS:](https://ajuda.sankhya.com.br/hc/article_attachments/16165414564119)SOLUÇÃO PARA PRODUTOS:**

![Imagem 3: Na tela "Produtos" ( Caminho de acesso: Configurações » Cadastros » Produtos) , verifique dentre os itens do lançamento…](https://ajuda.sankhya.com.br/hc/article_attachments/16165462871703) Na tela **"Produtos"** (Caminho de acesso: Configurações » Cadastros » Produtos), verifique dentre os itens do lançamento realizado quais possuem a marcação "Usa Local":

- Aba **Medidas e Estoque** » Sub-Aba **Estoque »** Campo **"Usa Local"**:

![Imagem 4: Aba Medidas e Estoque » Sub-Aba Estoque » Campo "Usa Local" :](https://ajuda.sankhya.com.br/hc/article_attachments/14335100028695)

![Imagem 5: Para os itens que possuem a marcação acima, o campo "Local origem" da grade de itens deverá ser preenchido no…](https://ajuda.sankhya.com.br/hc/article_attachments/16165414571799) Para os itens que possuem a marcação acima, o campo **"Local origem"** da grade de itens deverá ser preenchido no lançamento realizado na respectiva **Central**:

![Imagem 6: Para os itens que possuem a marcação acima, o campo "Local origem" da grade de itens deverá ser preenchido no…](https://ajuda.sankhya.com.br/hc/article_attachments/14335161979031)

![Imagem 7: Preenchido o campo acima, será possível salvar o lançamento.](https://ajuda.sankhya.com.br/hc/article_attachments/16165414573719) Preenchido o campo acima, será possível salvar o lançamento.

**![Imagem 8: SOLUÇÃO PARA SERVIÇOS:](https://ajuda.sankhya.com.br/hc/article_attachments/16165414564119) SOLUÇÃO PARA SERVIÇOS:**

Na tela **"Serviço"** (Caminho de acesso: Configurações » Cadastros » Produtos » Serviço), verifique dentre os itens do lançamento realizado quais possuem a marcação "Usa Local":

- Aba **Controle estoque** » Sub-Aba **Controle Adicional**» Campo **"Usa Local"**:

![Imagem 9: Aba Controle estoque » Sub-Aba Controle Adicional » Campo "Usa Local" :](https://ajuda.sankhya.com.br/hc/article_attachments/14335252936343)

**![Imagem 10: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16165462877463)CAUSA:**

Ocorre quando existem itens configurados com controle de estoque por local e esse local não foi informado no respectivo lançamento.
