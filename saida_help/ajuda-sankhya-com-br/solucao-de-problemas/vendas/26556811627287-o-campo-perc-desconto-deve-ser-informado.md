# O campo 'Perc. desconto' deve ser informado

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26556811613207) **MENSAGEM:**

[CORE\_E03235] O campo 'Perc. desconto' deve ser informado.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26556811615127)SOLUÇÃO:**

Preencha o campo '% desconto' na grade de itens antes de salvar o item. Caso não deseje aplicar descontos no item, o campo deve ser preenchido com o valor 0.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26556795244055)CAUSA:**

O erro ocorre ao tentar salvar um item na grade e o campo '% Desconto' não tem nenhum valor informado. O sistema preenche automaticamente com o valor 0, mas se for apagado, o erro será apresentado.
