# Usuário possui restrição para realizar liberação para XX da nota

**![Imagem 1: Mensagem:](https://ajuda.sankhya.com.br/hc/article_attachments/16161511508759)Mensagem:**

[CORE\_E00255] Usuário possui restrição para realizar liberação para XX da nota.

**![Imagem 2: Solução:](https://ajuda.sankhya.com.br/hc/article_attachments/16161511511319)Solução:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse a tela " Usuários " (Caminho de acesso: Configurações » Controle de Acesso):](https://ajuda.sankhya.com.br/hc/article_attachments/16161511511959) Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874)"** (Caminho de acesso: Configurações » Controle de Acesso):

- Selecione o usuário que está sendo validado
- Na aba "**Validações**" identifique o código da Regra vinculada ao usuário

![Imagem 4: Na aba " Validações " identifique o código da Regra vinculada ao usuário](https://ajuda.sankhya.com.br/hc/article_attachments/14523612754455)

![Imagem 5: Acesse a tela " Central de Certificações " (Caminho de acesso: Comercial » Avançado » Certificações) :](https://ajuda.sankhya.com.br/hc/article_attachments/16161481316503) Acesse a tela **"[Central de Certificações](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110053)"** (Caminho de acesso: Comercial » Avançado » Certificações):

- Pesquise pelo código da regra vinculado ao usuário e identifique a restrição imposta.

![Imagem 6: Pesquise pelo código da regra vinculado ao usuário e identifique a restrição imposta.](https://ajuda.sankhya.com.br/hc/article_attachments/14523604154903)

![Imagem 7: Verifique com o gestor sobre a restrição e se realmente ela é válida para o usuário.](https://ajuda.sankhya.com.br/hc/article_attachments/16161511516951) Verifique com o gestor sobre a restrição e se realmente ela é válida para o usuário.

![Imagem 8: Revise as restrições e após os ajustes efetue o procedimento novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/16161481359255) Revise as restrições e após os ajustes efetue o procedimento novamente.

**![Imagem 9: Causa:](https://ajuda.sankhya.com.br/hc/article_attachments/16161511519127)Causa:**

Ocorre quando o usuário possui restrição pela regra da Central de Certificação, vinculado ao seu cadastro.
