# Sistema está validando o estoque do kit independente

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26747257948183) **MENSAGEM:**

Sistema está validando o estoque do kit independente.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26747241813015)SOLUÇÃO:**

O kit é um agrupado e nesse caso não se controla o estoque do kit e sim dos componentes. Assim, o kit precisa ter um grupo de produto separado, com a marcação de não valida estoque.

![Imagem 3: O kit é um agrupado e nesse caso não se controla o estoque do kit e sim dos componentes. Assim, o kit precisa ter um…](https://ajuda.sankhya.com.br/hc/article_attachments/26890754152727)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26747241816983)CAUSA:**

O KIT é apenas um facilitador de lançamentos, ele não existe de verdade e pode ter diversos produtos como componentes. Desse modo, o grupo de produtos não pode validar o estoque.

Primeiro é importante entender que isso não é um processo produtivo. Então, os saldos dos componentes devem ser realizados através de uma nota de entrada no portal de compras, alimentando o estoque dos componentes.
