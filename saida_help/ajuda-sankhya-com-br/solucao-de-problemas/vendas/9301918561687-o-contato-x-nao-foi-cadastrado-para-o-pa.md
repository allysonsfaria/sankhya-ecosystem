# O contato x não foi cadastrado para o parceiro xxxx

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18603933340183) MENSAGEM:**

[CORE\_E00900]  O contato x não foi cadastrado para o parceiro xxxx.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603933341207) SITUAÇÃO:**

Ao lançar uma nota de venda a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18603922158359) CAUSA:**

Quando não existe nenhum contato devidamente configurado no cadastro do parceiro.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603922161815) SOLUÇÃO:**

Ocorre quando não há um contato cadastrado em = tela **Parceiros** (Configurações » Cadastros » Parceiros) aba 'Contatos'. Nesse caso, verifique na tela citada se há um contato cadastrado para o parceiro selecionado na nota na qual a mensagem aparece.

![Imagem 5: Ocorre quando não há um contato cadastrado em = tela Parceiros (Configurações » Cadastros » Parceiros) aba 'Contatos'.…](https://ajuda.sankhya.com.br/hc/article_attachments/9301740986519)
