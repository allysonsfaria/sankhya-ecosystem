# Valor acima do permitido

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16117523095191) MENSAGEM:**

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16117523099159) SITUAÇÃO:**

Ao tentar efetuar a liberação de limites, ocorre a mensagem.

**![Imagem 3: CAUSA :](https://ajuda.sankhya.com.br/hc/article_attachments/16117515708567) CAUSA**:

Ocorre quando o usuário definido como liberador não possui alçada suficiente para conceder a liberação de limites do respectivo evento.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16117523106455) SOLUÇÃO:**

Para solução será necessário acionar um superior que tenha maiores limites para liberação, para que o mesmo efetue a ação ou conceda um limite superior ao que o liberador possui atualmente.

Para ajustar as alçadas do liberador:

![Imagem 5: Acesse a tela " Usuários " (Caminho de acesso: Configurações » Controle de Acesso » Usuários) ;](https://ajuda.sankhya.com.br/hc/article_attachments/16117515689239) Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios)"** (Caminho de acesso: Configurações » Controle de Acesso » Usuários);

![Imagem 6: Selecione o usuário que receberá os ajustes de limites.](https://ajuda.sankhya.com.br/hc/article_attachments/16117523111063) Selecione o usuário que receberá os ajustes de limites.

![Imagem 7: Acione o botão "Outras Opções" » "Limites para Liberação" ;](https://ajuda.sankhya.com.br/hc/article_attachments/16117515696407) Acione o botão **"Outras Opções"** » **"Limites para Liberação"**;

![Imagem 8: Selecione o evento que ocasionou a mensagem e edite o campo "Valor limite" para o desejado.](https://ajuda.sankhya.com.br/hc/article_attachments/16117515699223) Selecione o evento que ocasionou a mensagem e edite o campo **"Valor limite"** para o desejado.

**(2)**Feito isso, tente realizar a liberação novamente.

![Imagem 9: (2) Feito isso, tente realizar a liberação novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/14607250966551)

![Imagem 10: (2) Feito isso, tente realizar a liberação novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/12096667978263)

Valide com os responsáveis pela alçada de liberação na empresa, se esse valor deve ser ajustado, seguindo com a liberação após ajustes.  Caso o limite não possa ser aumentado, redefina o usuário liberador para um com alçada suficiente.

Para redefinir o usuário liberador utilize a opção "Outras Opções..."/"Ver solicitações de liberação" dentro da Central de Notas, no PopUP Liberações solicitadas selecione um liberador pelo campo de pesquisa conforme imagem.

![Imagem 11: Para redefinir o usuário liberador utilize a opção "Outras Opções..."/"Ver solicitações de liberação" dentro da Central…](https://ajuda.sankhya.com.br/hc/article_attachments/16474190132503)
