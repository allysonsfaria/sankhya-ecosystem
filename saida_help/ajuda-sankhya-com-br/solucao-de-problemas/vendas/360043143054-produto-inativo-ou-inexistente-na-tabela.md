Para correção, siga os passos abaixo:

![Imagem 3: Verifique para os itens do lançamento quais são os locais utilizados.](https://ajuda.sankhya.com.br/hc/article_attachments/16135935749271) Verifique para os itens do lançamento quais são os locais utilizados.

![Imagem 5: Para os locais constatados no Item 1, verifique na tela " Locais " se existe algum deles com o campo "Ativo" desmarcado:](https://ajuda.sankhya.com.br/hc/article_attachments/16135935753239) Para os locais constatados no Item 1, verifique na tela "Locais" se existe algum deles com o campo **"Ativo"** desmarcado:

![Imagem 6: Para os locais constatados no Item 1, verifique na tela " Locais " se existe algum deles com o campo "Ativo" desmarcado:](https://ajuda.sankhya.com.br/hc/article_attachments/14658611259031)

![Imagem 7: Em caso positivo, ative tal local para conseguir concluir o lançamento.](https://ajuda.sankhya.com.br/hc/article_attachments/16135935755287) Em caso positivo, ative tal local para conseguir concluir o lançamento.

![Imagem 8: Acesse também a tela "Produtos" , vá até a aba "Estoque" e verifique na linha correspondente aos dados do lançamento se…](https://ajuda.sankhya.com.br/hc/article_attachments/24650636325143) Acesse também a tela **"Produtos"**, vá até a aba **"Estoque"**e verifique na linha correspondente aos dados do lançamento se o botão **"Ativo"**está marcado. Caso não esteja, faça a marcação.

![Imagem 9: Acesse também a tela "Produtos" , vá até a aba "Estoque" e verifique na linha correspondente aos dados do lançamento se…](https://ajuda.sankhya.com.br/hc/article_attachments/24650671948439)

**![Imagem 10: Acesse também a tela "Produtos" , vá até a aba "Estoque" e verifique na linha correspondente aos dados do lançamento se…](https://ajuda.sankhya.com.br/hc/article_attachments/17803688246295) IMPORTANTE:**

Ao inativar determinado local é imprescindível que seja analisado se existe algum estoque nesse, em caso positivo esse estoque deve ser transferido para um Local Ativo, evitando que a situação acima ocorra.

**![Imagem 11: CAUSA :](https://ajuda.sankhya.com.br/hc/article_attachments/16135935758231) CAUSA**:

Ocorre quando existem Itens vinculados a locais inativos ou inexistentes.
