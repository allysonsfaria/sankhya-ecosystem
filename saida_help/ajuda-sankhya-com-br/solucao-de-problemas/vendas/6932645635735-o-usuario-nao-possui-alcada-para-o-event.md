# O usuário não possui alçada para o evento com o valor solicitado de ''

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16476144628503) MENSAGEM:**

[CORE\_E02842] O usuário não possui alçada para o evento com o valor solicitado de ''.

[CORE\_E02844] O evento X não está cadastrado para o usuário.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16476187815959)CAUSA:**

Mensagem apresentada quando o usuário definido para liberação do evento não possui limite suficiente para tal.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16476144635927)SOLUÇÃO:**

![Imagem 4: Acesse o cadastro do "Usuário" responsável pela liberação, selecione: "Outras Opções", depois clique em: "Limites para…](https://ajuda.sankhya.com.br/hc/article_attachments/16476187807895) Acesse o cadastro do **"Usuário"** responsável pela liberação, selecione: **"Outras Opções",** depois clique em:**"Limites para Liberação"**:

**(1)** Verifique se para o Evento a ser liberado, o 'Limite' configurado para esse usuário é suficiente para concluir a operação.

![Imagem 5: (1) Verifique se para o Evento a ser liberado, o 'Limite' configurado para esse usuário é suficiente para concluir a…](https://ajuda.sankhya.com.br/hc/article_attachments/16476144647703)

Valide com os responsáveis pela alçada de liberação na empresa, se esse valor deve ser ajustado, seguindo com a liberação após ajustes.  Caso o limite não possa ser aumentado, redefina o usuário liberador para um com alçada suficiente.

Para redefinir o usuário liberador clique em: "Outras Opções..."/"Ver solicitações de liberação", dentro da Central de Notas, no PopUP Liberações solicitadas, selecione um liberador pelo campo de pesquisa conforme imagem.

![Imagem 6: Para redefinir o usuário liberador clique em: "Outras Opções..."/"Ver solicitações de liberação", dentro da Central de…](https://ajuda.sankhya.com.br/hc/article_attachments/16474179906839)
