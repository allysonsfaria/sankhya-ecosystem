# Não devem ser informados documentos anteriores para CT-e com o tipo de serviço normal

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19276688855959) MENSAGEM:**

[CORE\_E04429] Não devem ser informados documentos anteriores para CT-e com o tipo de serviço normal.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19276688872855) SITUAÇÃO:**

Ao confirmar CT-e de Complemento a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19276700495639) CAUSA:**

Ocorre quando é informado um Documento anterior para um CT-e com tipo de serviço Normal.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19276700499351) SOLUÇÃO:**

Quando o tipo de serviço do CT-e for normal, realmente não é possível informar documentos anteriores.

Diante disso, retire o documento anterior e gere o lote.

![Imagem 5: Diante disso, retire o documento anterior e gere o lote.](https://ajuda.sankhya.com.br/hc/article_attachments/19276688888343)
