# O registro 1400 para modelo 57 ou 08

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16419449367959) SOLUÇÃO:**

Nativamente o sistema não gera o 1400 para documentos que estão nos livros de ISS, somente para os lançamentos do livro de ICMS/IPI, e que foram gerados no D100.

Sendo assim, deverá ser feitas todas as configurações mencionadas nos manuais abaixo:

[Registro 1400 - EFD ICMS/IPI - MG. Saiba Mais !](https://ajuda.sankhya.com.br/hc/pt-br/articles/360049367053-Registro-1400-EFD-ICMS-IPI-MG-Saiba-Mais-)
[Códigos de itens (IPM) por UF no registro 1400](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045116093-C%C3%B3digos-de-itens-IPM-por-UF-no-registro-1400)

Além disso as configurações precisam ser analisadas:

![Imagem 2: TOP aba LIVRO FISCAL deve estar marcada para atualizar LIVRO ICMS :](https://ajuda.sankhya.com.br/hc/article_attachments/16511928586647) **TOP** aba **LIVRO FISCAL** deve estar marcada para atualizar **LIVRO ICMS**:

![Imagem 3: TOP aba LIVRO FISCAL deve estar marcada para atualizar LIVRO ICMS :](https://ajuda.sankhya.com.br/hc/article_attachments/16511821386263)

Na aba **NF-e/NFC-e/CF-e**, se estiver marcado como modelo **57** o campo NF-e deve estar marcado como **CONVENCIONAL (NÃO USA NF-E)**:

![Imagem 4: Na aba NF-e/NFC-e/CF-e , se estiver marcado como modelo 57 o campo NF-e deve estar marcado como CONVENCIONAL (NÃO USA…](https://ajuda.sankhya.com.br/hc/article_attachments/16511815617687)

O registro 1400 para modelo 57 ou 08 é gerado se a nota estiver no C100 / C170 / D100 / D110 / D510.

Após realizar as configurações acima o arquivo será gerado normalmente conforme exemplo abaixo:

![Imagem 5: Após realizar as configurações acima o arquivo será gerado normalmente conforme exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/16511898230807)
