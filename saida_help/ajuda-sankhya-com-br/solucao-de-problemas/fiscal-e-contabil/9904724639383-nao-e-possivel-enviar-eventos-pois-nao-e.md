# Não é possível Enviar Eventos, pois não existem registros com status "Pendente" para a sequência atual

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19297441607063) MENSAGEM:**

[LIV\_E00039] Não é possível Enviar Eventos, pois não existem registros com status "Pendente" para a sequência atual.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19297441615127) SITUAÇÃO:**

Ao tentar enviar eventos do Reinf em referência sem movimento a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19297441618583) CAUSA:**

Ocorre quando se clica em enviar sem ter nenhum evento a ser enviado.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19297419700247) SOLUÇÃO:**

Nos casos de referência sem movimento, envie somente o R-2099, já que o R-1000 é criado com o status 'Finalizado'.

Para isso, gere os eventos e, em seguida, clique em 'Fechar referência' para o sistema enviar o evento R-2099.
