# 951 - Rejeicao: Chave de Acesso referenciada com codigo numerico zerado nao permitida para finalidade diferente de normal.[nOcor: 1]

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26163391470103) **MENSAGEM:**

951 - Rejeicao: Chave de Acesso referenciada com codigo numerico zerado nao permitida para finalidade diferente de normal.[nOcor: 1]

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26163391472151)SOLUÇÃO:**

Para corrigir, atualize o valor preenchido no campo da **"Chave NF-e Referenciada"**, que fica disponível na **Central de notas**.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26163421434519)CAUSA:**

Essa rejeição ocorre quando é informada uma NF-e referenciada por Chave de Acesso com código numérico zerado.

Caso não localize o campo Chave NF-e Referenciada na central, siga as orientações do artigo: [Como inserir um campo no layout da nota?](https://ajuda.sankhya.com.br/hc/pt-br/articles/360043058973-Como-inserir-um-campo-no-layout-da-nota)
