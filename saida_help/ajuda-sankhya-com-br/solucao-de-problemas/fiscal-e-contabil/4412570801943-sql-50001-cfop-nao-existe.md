# SQL-50001 CFOP não existe

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16177400463127) MENSAGEM**:

"SQL-50001 CFOP não existe."

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16177400467607)SOLUÇÃO:**

Para a resolução do incidente, siga os passos abaixo:

![Imagem 3: Na tela 'Configurações de Ajustes de Apuração', analise se o campo CFOP está preenchido como é mostrado no Print abaixo.](https://ajuda.sankhya.com.br/hc/article_attachments/16177400472087) Na tela 'Configurações de Ajustes de Apuração', analise se o campo CFOP está preenchido como é mostrado no Print abaixo.

![Imagem 4: Na tela 'Configurações de Ajustes de Apuração', analise se o campo CFOP está preenchido como é mostrado no Print abaixo.](https://ajuda.sankhya.com.br/hc/article_attachments/16177400475671)

![Imagem 5: Na Aba "ajuste de apuração ICMS/ICMS ST" o campo, "Inserir ajuste por" deve estar como mostrado abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/16177414766359)  Na Aba **"ajuste de apuração ICMS/ICMS ST"** o campo, **"Inserir ajuste  por"** deve estar como mostrado abaixo:

![Imagem 6: Na Aba "ajuste de apuração ICMS/ICMS ST" o campo, "Inserir ajuste por" deve estar como mostrado abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/16177400482967)

**![Imagem 7: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16177414773911)CAUSA:**

Na geração do livro também e feita a geração dos ajustes automáticos. Essa geração dos ajustes vem das configurações da tela  [Configurações de Ajustes de Apuração](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110593-Configura%C3%A7%C3%B5es-de-Ajustes-de-Apura%C3%A7%C3%A3o?source=search&auth_token=eyJhbGciOiJIUzI1NiJ9.eyJhY2NvdW50X2lkIjo5NjE4MTY4LCJ1c2VyX2lkIjo0MDYxMTM2Njk4NTQsInRpY2tldF9pZCI6MTQxNjgxLCJjaGFubmVsX2lkIjo2MywidHlwZSI6IlNFQVJDSCIsImV4cCI6MTYzODk3NDAwNn0.CO6IyUuEby8Dtse74CUKBQKk4k7Zsb_Yp1gp0yTX7-U) e nessas configurações quando o filtro está por CFOP, a forma de inserção do ajuste não pode ser por nota, tem que ser por CFOP.
