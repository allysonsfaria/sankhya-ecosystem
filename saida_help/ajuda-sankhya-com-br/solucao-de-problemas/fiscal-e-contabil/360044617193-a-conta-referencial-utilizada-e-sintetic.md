# A conta referencial utilizada é sintética. O mapeamento deve ser com uma conta referencial analítica

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16415433042583) MENSAGEM:**

A conta referencial utilizada é sintética. O mapeamento deve ser com uma conta referencial analítica.
