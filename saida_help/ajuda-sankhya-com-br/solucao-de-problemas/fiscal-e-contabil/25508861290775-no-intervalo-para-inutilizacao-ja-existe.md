# No intervalo para inutilização já existem números de notas inutilizados

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/25508861284759) MENSAGEM:**

[CORE\_E04913] No intervalo para inutilização já existem números de notas inutilizados.

![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/25508823651607) **SOLUÇÃO:**

Acesse o **Portal de vendas** (Comercial » Consulta » Portal de Vendas) e exclua a nota que está inutilizada no sistema da SEFAZ.

![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/25508861287319) **CAUSA:**

O erro é apresentado quando uma nota inutilizada na SEFAZ permanece no sistema Sankhya e não é excluída.
