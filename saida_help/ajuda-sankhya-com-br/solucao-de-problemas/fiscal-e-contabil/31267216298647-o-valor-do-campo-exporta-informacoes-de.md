# O valor do campo exporta (Informações de exportação) informado não é valido

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/31267216290327) **MENSAGEM:**

O valor do campo exporta (Informações de exportação) informado não é valido.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/31934843549207) SITUAÇÃO:**

Ao gerar o lote de uma **NF-e de exportação** o erro é apresentado.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/31267216293143)SOLUÇÃO:**

No cabeçalho da nota, preencha o campo **"Local do Embarque"**.

Se o cabeçalho da **NF-e de exportação em questão,** não possuir este o campo, coloque-o pela tela de **"Configurador de Layout da Nota"** e, então, preencha-o.

![Imagem 4: Se o cabeçalho da NF-e de exportação em questão, não possuir este o campo, coloque-o pela tela de "Configurador de…](https://ajuda.sankhya.com.br/hc/article_attachments/31934841683735)

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/31267232487063)CAUSA:**

A mensagem é apresentada quando se está gerando o lote de uma NF-e de exportação e o campo Local do Embarque não está preenchido.
