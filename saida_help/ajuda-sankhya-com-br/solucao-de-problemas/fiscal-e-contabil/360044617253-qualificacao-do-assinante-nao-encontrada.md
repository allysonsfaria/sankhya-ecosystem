# Qualificação do assinante não encontrada na Tabela de Qualificação do Assinante

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16416288366999) MENSAGEM:**

Qualificação do assinante não encontrada na Tabela de Qualificação do Assinante.

Registro J930 – Campo 4 vazio.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16416288370839) SOLUÇÃO:**

Para correção, siga os passos abaixo:

**(1)** Acesse: Contabilidade » Preferências » Empresa

- Aba: **"Signatários"**
- Campo **"Cód. DNRC"**: informe o código DNRC conforme Instrução Normativa nº. 107, de 23 de maio de 2008

![Imagem 3: Campo "Cód. DNRC" : informe o código DNRC conforme Instrução Normativa nº. 107, de 23 de maio de 2008](https://ajuda.sankhya.com.br/hc/article_attachments/360061077773)

- Tabela disponível no Manual da ECD, para download [clique aqui](http://sped.rfb.gov.br/pasta/show/1569).

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16416288378903) CAUSA:**

Ocorre quando os signatários que estão declarados no arquivo ECD não possuem a informação do Código DNRC devidamente configurada no sistema.
