# Parâmetro para máscara de hierarquia 'MASCPLANCTA' não encontrado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16337616243735)  MENSAGEM:**

[CORE\_E04372] Parâmetro para máscara de hierarquia 'MASCPLANCTA' não encontrado.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16337593832983) CAUSA:**

Ocorre quando não é encontrado na tela **Preferências** (Configurações » Avançado » Preferências) o parâmetro **MASCPLANCTA.**

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16337584248727) SOLUÇÃO:**

Acesse a tela **Preferências** (Configurações » Avançado » Preferências) e acrescente o parâmetro, conforme informações abaixo:

Chave: MASCPLANCTA
Descrição: Máscara para Plano de Contas
Módulos do sistema: configurações
Menu: Diversas
Aba: Diversas
Tipo: Texto
Texto: 99\.99\.99\.99\.99999;1
