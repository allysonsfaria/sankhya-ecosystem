# Código Sit.Trib.IPI Entrada deve ser informado

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16306547927831) **MENSAGEM:**

[CORE\_E05034] Código Sit. Trib. IPI Entrada deve ser informado.

[CORE\_E05029] Código Sit Trib IPI Entrada deve ser informado.

### Para tela "Empresa"

![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16306547931159) **SITUAÇÃO:**

Ao tentar salvar as alterações na tela [**Empresa**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045114893-Prefer%C3%AAncias-da-Empresa) deixando o campo **"Código Sit. Trib. IPI Entrada"** sem informação a mensagem é apresentada.

![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16306574189335) **SOLUÇÃO:**

Acesse a tela Empresa (Caminho de acesso: Comercial » Preferências » Empresa), vá até a aba "**Propriedades"** e preencha o campo Código Sit. Trib. IPI Entrada.

![Imagem 4: Acesse a tela Empresa (Caminho de acesso: Comercial » Preferências » Empresa), vá até a aba " Propriedades" e preencha…](https://ajuda.sankhya.com.br/hc/article_attachments/14330601139863)

### Para tela "Produto"

**![Imagem 5: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16306574189335) SOLUÇÃO:**

Acesse a Tela **"Produto",** vá até a aba **"Impostos"**e configure os campos **"Cód. Sit. Trib. IPI Entrada" e "Cód. Sit. Trib. IPI Saída"** de acordo com a situação tributária de entrada e saída.

![Imagem 6: Acesse a Tela "Produto", vá até a aba "Impostos" e configure os campos "Cód. Sit. Trib. IPI Entrada" e "Cód. Sit. Trib.…](https://ajuda.sankhya.com.br/hc/article_attachments/23341732772503)

![Imagem 7: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16306547935127) **CAUSA:**

Ocorre quando o campo Código Sit. Trib. IPI Entrada está vazio.
