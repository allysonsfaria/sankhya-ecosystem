# Campo "Repassar para o cliente" não pode ter mais de uma opção marcada

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/25906479116055) **MENSAGEM:**

[CORE\_E02113] Campo **"Repassar para o cliente"** não pode ter mais de uma opção marcada

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/25916224527511) SOLUÇÃO:**

Podem haver duas causas para essa mensagem do sistema:

![Imagem 3: Marcar dois campos da seção "Repassar para o cliente" conforme explicado pela mensagem e estar com o parâmetro "…](https://ajuda.sankhya.com.br/hc/article_attachments/25906479125783) Marcar dois campos da seção **"Repassar para o cliente"**  conforme explicado pela mensagem e estar com o parâmetro **"HABFORMASREPRED"** ativado.

![Imagem 4: Marcar dois campos da seção "Repassar para o cliente" conforme explicado pela mensagem e estar com o parâmetro "…](https://ajuda.sankhya.com.br/hc/article_attachments/25917048790167)

![Imagem 5: Trabalhar com o parâmetro HABFORMASREPRED desligado e informar algum valor no campo " % a Base ICMS "](https://ajuda.sankhya.com.br/hc/article_attachments/25906503442071) Trabalhar com o parâmetro HABFORMASREPRED desligado e informar algum valor no campo "**% a  Base ICMS**"

![Imagem 6: Trabalhar com o parâmetro HABFORMASREPRED desligado e informar algum valor no campo " % a Base ICMS "](https://ajuda.sankhya.com.br/hc/article_attachments/25917109695639)

**(1)** Para o primeiro cenário, escolha apenas uma marcação de fato, pois na atual estrutura apenas uma é suportada pela aplicação.

**(1)**Para o segundo cenário, não se pode alimentar o campo citado estando com o parâmetro desabilitado.
