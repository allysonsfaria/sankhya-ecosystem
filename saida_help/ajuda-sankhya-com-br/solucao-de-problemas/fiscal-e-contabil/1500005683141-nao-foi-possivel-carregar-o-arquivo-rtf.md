Para a resolução do incidente, siga  os passos abaixo:

![Imagem 3: Acesse a tela "Empresa" (Caminho de acesso: Contabilidade » Preferências » Empresa);](https://ajuda.sankhya.com.br/hc/article_attachments/16335956196503) Acesse a tela**"Empresa"** (Caminho de acesso: Contabilidade » Preferências » Empresa);

![Imagem 4: Localize a aba "ECD" - Outras Informações (J800);](https://ajuda.sankhya.com.br/hc/article_attachments/16335949228823) Localize a aba **"ECD"** - Outras Informações (J800);

![Imagem 5: Nesta aba se tem os dados pertinentes aos Arquivos Anexos para ECD; informações que irão alimentar o registro J800 da…](https://ajuda.sankhya.com.br/hc/article_attachments/16335956200343) Nesta aba se tem os dados pertinentes aos Arquivos Anexos para ECD; informações que irão alimentar o registro J800 da ECD. Realiza-se também nesta aba o upload de um arquivo com extensão ".rtf" para o Repositório de Arquivos.
