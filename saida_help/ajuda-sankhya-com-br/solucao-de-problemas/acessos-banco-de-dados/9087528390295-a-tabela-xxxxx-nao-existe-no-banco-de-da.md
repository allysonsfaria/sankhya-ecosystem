# A tabela 'xxxxx' não existe no banco de dados

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16673889537815) MENSAGEM:**

[CORE\_E02859]:  A tabela 'xxxxx' não existe no banco de dados.

[CORE\_05916]

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16673905574551) CAUSA:**

Pode ter sido gerada por algum problema no momento da atualização do sistema, erro de importação de base de dados ou intervenção indevida no banco de dados.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16673905572503) SOLUÇÃO:**

Como as causas podem ser variadas, quando essa mensagem for apresentada, acione o suporte para que a equipe de banco de dados faça as análises e intervenções necessárias.
