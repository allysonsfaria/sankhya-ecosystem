# ORACLE DATA BLOCK CORRUPTED

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16283695863703) MENSAGEM**:

[ORA-01578]: ORACLE DATA BLOCK CORRUPTED.

ou

[ORA-01578]: BLOCO DE DADOS ORACLE DANIFICADO

ou

[ORA-01578]: ORACLE data block corrupted (file # ORA-01578: ORACLE data block corrupted (file # X, block # yyyyy)

[ORA-01110]: data file 3: 'E:\ORA12C\ORADATA\DBPROD\zzzz.DBF'.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16283695868695) CAUSA:**

Ocorre quando o Banco de Dados foi corrompido.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16283695865111) SOLUÇÃO:**

Considere o Comportamento da Aplicação, conforme abaixo:

Solicite que a área de TI da empresa ou terceiro acione o respectivo DBA, para que o mesmo tome as providências para restauração do banco.
Caso a empresa não tenha um DBA ou não faça uso de serviço de terceiro, entre em contato com a Unidade competente, para que seja contratado serviços de um DBA da Sankhya.

**Solução paliativa:** Não tem, pois o banco de dados foi danificado.
