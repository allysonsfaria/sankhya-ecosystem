# Error #2035

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/18585483678103) MENSAGEM**:

Error #2035.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19033777772567) CAUSA:**

Incidente causado por falha no carregamento da pagina devido a cache do navegador.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18585483696407) SOLUÇÃO:**

Geralmente essa mensagem é apresentada no carregamento de telas (nenhuma especifica), junto a barra de carregamento. Nesse caso, recomendamos:

![Imagem 4: Limpe o cache do navegador (todo período);](https://ajuda.sankhya.com.br/hc/article_attachments/18585451439639) Limpe o cache do navegador (todo período);

- Com o navegador aberto, pressione as teclas CT+ SHIFT + DELETE

  ![Imagem 5: Com o navegador aberto, pressione as teclas CT+ SHIFT + DELETE](https://ajuda.sankhya.com.br/hc/article_attachments/360083796814)

![Imagem 6: Feito isso, acesse o sistema novamente e teste o acesso.](https://ajuda.sankhya.com.br/hc/article_attachments/18585483709335) Feito isso, acesse o sistema novamente e teste o acesso.

**Observação:**

Uma solução paliativa, que dispensa a limpeza de cache, é acessar o sistema pelo navegador em "Janela Anônima".
