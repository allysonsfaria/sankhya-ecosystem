# Não é possível remover uma tabela adicional que contenha registros

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16913358688919) MENSAGEM:**

[CORE\_E03108]: Não é possível remover uma tabela adicional que contenha registros.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16913341998871)CAUSA:**

Ocorre ao tentar excluir uma tabela que já contém registros.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16913358690711)SOLUÇÃO:**

Essa demanda deverá ser avaliada pelo criador da mesma, não sendo portanto da matriz de responsabilidade do Service Desk.
