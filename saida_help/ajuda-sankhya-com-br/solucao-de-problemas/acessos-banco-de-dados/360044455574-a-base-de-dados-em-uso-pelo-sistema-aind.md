# A base de dados em uso pelo sistema ainda não foi registrada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18603127407383) MENSAGEM:**

Registro de Base de Dados
A base de dados em uso pelo sistema ainda não foi registrada.
O registro é necessário para um melhor controle e segurança das informações por parte do sistema.
Realize o registro assim que possível para evitar a indisponibilidade do sistema, que pode ocorrer a partir de 15 dias.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18603132458903) CAUSA:**

Ao atualizar o sistema para versão 3.31 ou superior no primeiro acesso será necessário registrar a base atualizada, informando um apelido e o 'Tipo da Base'.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603127415319) SOLUÇÃO:**

![Imagem 4: Logado com o usuário SUP, clique em "Registrar Base Agora" :](https://ajuda.sankhya.com.br/hc/article_attachments/18603127418903) Logado com o usuário SUP, clique em **"Registrar Base Agora"**:

![Imagem 5: Logado com o usuário SUP, clique em "Registrar Base Agora" :](https://ajuda.sankhya.com.br/hc/article_attachments/360081090793)

**Nota**: Se após 15 dias o registro não for feito, ao acessar o sistema, apresentara a seguinte mensagem: O período de tolerância para o registro da base de dados terminou, algumas funcionalidades estarão travadas

**Observação:**

- Caso a mensagem acima não apresente a opção 'Registrar Base Agora', basta acessar 'Administração do Servidor' >> Aba 'Registro de base de dados' [Logar com usuário SUP].
