# Ocorreu uma falha de comunicação, a verificação da base de dados não pôde ser feita

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/15916479552535) MENSAGEM**:

Ocorreu uma falha de comunicação, a verificação da base de dados não pôde ser feita.

Realize o registro assim que possível para evitar a indisponibilidade do sistema que pode ocorrer a partir de 29 dias.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15916479555991) CAUSA:**

Ao atualizar o sistema para versão 3.31 ou superior no primeiro acesso será necessário registrar a base atualizada, informando um apelido e o 'Tipo da Base'.
