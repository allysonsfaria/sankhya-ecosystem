# Problemas na geração das notas de devolução, verifique a quantidade a devolver

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/25514690869143) **MENSAGEM:**

[WMS\_E00703] Problemas na geração das notas de devolução, verifique a quantidade a devolver.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/25514690871447)SOLUÇÃO:**

Verifique a quantidade a ser devolvida e informe no campo **"Qtde a Devolver",** na tela **"Recebimento de mercadorias"**. Caso tenha mais de uma nota no mesmo recebimento, selecione a nota e informe a quantidade corresponde a mesma.
