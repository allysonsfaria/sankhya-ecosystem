# O pedido número único: XXXX não está liberado para faturamento

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19357259161623) MENSAGEM:**

[CORE\_E05083] O pedido número único: XXXX não está liberado para faturamento. Existem itens que não foram enviados para Separação no WMS.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357253915543) SITUAÇÃO:**

Ao tentar faturar um pedido de venda a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19357259180311) CAUSA:**

Quando algum item do pedido esta pendente e não foi enviado para o WMS.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357253937815) SOLUÇÃO:**

Verifique no pedido se todos os itens foram enviados para o WMS, caso tenham sido enviados parcialmente, realize o envio da quantidade restante do pedido.

Caso não seja necessário o envio da quantidade restante para a expedição, realize o corte no pedido.
