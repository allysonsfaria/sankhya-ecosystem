# Quais configurações necessárias para que a nota de entrada seja confirmada após a conferencia pela rotina da tela registro de conferência de entrada?

![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/21657124283031) **SITUAÇÃO:**

O que é necessário para que a nota de entrada seja confirmada ao conferir pela Tela Registro de Conferência de Entrada?

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/21630217919255)SOLUÇÃO:**

**Necessário habilitar o parâmetro: "Confirma Nota no Registro de Conferência de Entrada - WMSCONFNOTARCE": quando ligado, ao realizar a conferência pela tela "Registro de Conferência de Entrada", o sistema tenta confirmar as notas envolvidas no recebimento.**
