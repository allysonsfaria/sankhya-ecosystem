# Acesso expirado, para continuar usando o aplicativo, é necessário liberar uma licença. Entrar em contato com o administrador

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/34548400106903) **MENSAGEM:**

Acesso expirado, para continuar usando o aplicativo, é necessário liberar uma licença. Entrar em contato com o administrador.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/34548371718167)SOLUÇÃO:**

**(1)** Acesse a tela **"Administração de licença"** (Contratos e Serviços » Administração de licença)

**(2)** Vá até a aba **"Solicitações Pendentes"**, busque pelo App **"Coletor WMS TotalCross"** e **libere a licença do equipamento.**

**Observação:** a partir da versão 4.35, o sistema está **validando a licença do aparelho TotalCross**. Portanto, é **necessário liberar a licença por equipamento.**

![Imagem 3: Observação: a partir da versão 4.35, o sistema está validando a licença do aparelho TotalCross . Portanto, é necessário…](https://ajuda.sankhya.com.br/hc/article_attachments/34548682124439)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/34548400114455)CAUSA:**

O erro acontece quando um equipamento logado com um usuário não teve a licença liberada e expirou o prazo de 48 horas de utilização.
