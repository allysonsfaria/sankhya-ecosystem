# Configurações para validar endereço de DOCA

**![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/20651067554839) SITUAÇÃO:**

Quais configurações corretas para o sistema validar um determinado endereço como doca?

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/20648185354263)SOLUÇÃO:**

![Imagem 3: Acesse a tela Endereço de armazenamento (WMS » Cadastros » Endereço de Armazenamento) e configure os campos abaixo da…](https://ajuda.sankhya.com.br/hc/article_attachments/20651048378647) Acesse a tela **Endereço de armazenamento** (WMS » Cadastros » Endereço de Armazenamento) e configure os campos abaixo da seguinte forma:

- **Endereço Ativo -** Marcado
  **Exclusivo para conferência -** Desmarcado
  **Analítico -** Marcado

![Imagem 4: Endereço Ativo - Marcado Exclusivo para conferência - Desmarcado Analítico - Marcado](https://ajuda.sankhya.com.br/hc/article_attachments/20651048386455)

Aba Geral:

- **Campo Multi Produto -** Marcado
  **Campo Permite fragmentar estoque -** Marcado

![Imagem 5: Campo Multi Produto - Marcado Campo Permite fragmentar estoque - Marcado](https://ajuda.sankhya.com.br/hc/article_attachments/20821834661015)

- **Permite expedição -** Desmarcado
  **Picking -** Desmarcado
  **Situação do Estoque -** Disponível

![Imagem 6: Permite expedição - Desmarcado Picking - Desmarcado Situação do Estoque - Disponível](https://ajuda.sankhya.com.br/hc/article_attachments/20651067599255)
