# Aguardando liberação para variação do vlr. unitário acima do permitido (WMS)

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/28948004490775) **MENSAGEM:**

Aguardando liberação para variação do vlr. unitário acima do permitido (WMS).

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/28948004491543)SOLUÇÃO:**

Ative o parâmetro **'PEDLIBENVRECWMS' 'Sempre solicitar lib. no envio recebimento WMS'** para que o sistema solicite a liberação de limite após a conferêcia de entrada do WMS, caso haja uma liberação pendente a ser realizada no momento da confirmação da nota ao finalizar a conferencia no coletor.
