# Impossibilidade de usar o gerenciador de folha com o usuário SUP, saiba como proceder

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19067730334999) SOLUÇÃO:**

O usuário SUP é utilizado para configuração/ parametrização de liberação de acessos.
O usuário SUP não é utilizado pra acessar a tela Gerenciador de Folhas. Para o acesso a esta tela tem que ser usuário de DP, que tenha esta liberação feita para seus acessos.

Caso deseje, poderá criar um usuário tipo (mestre) e realizar a liberação de todas as permissões no sistema. Para isso, inclua este usuário como DP e vincule ele no **Grupo de Decisores.**
E este grupo de decisores criado tem que estar vinculado aos processos na configuração de permissões.

**Ressaltamos que esta configuração está na tela painel de configurações e pode consultar o passo a passo no Guia Pessoal +.**
