# Alteração não permitida. Existe alteração de Cargo, com data anterior a data de admissão informada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18796058296855) MENSAGEM:**

[CORE\_E02523] Alteração não permitida. Existe alteração de Cargo, com data anterior a data de admissão informada. Para alterar a data de admissão corrija os dados.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18796071277335) SITUAÇÃO:**

Ao tentar alterar a data de admissão de um colaborador a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18796071286295) CAUSA:**

Ocorre ao tentar alterar a data de admissão de um colaborador depois de enviar o S-2200 ao eSocial.

![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18796071289879) **SOLUÇÃO:**

Como o S-2200 já foi enviado ao eSocial não é possível alterar a data de admissão. 
Nesse caso, primeiro exclua o S-2200 e depois realize a alteração da data.
