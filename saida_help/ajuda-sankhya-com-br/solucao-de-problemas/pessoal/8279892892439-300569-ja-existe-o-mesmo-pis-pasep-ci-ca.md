# 300569 - Já existe o mesmo PIS/PASEP/CI cadastrado com Código de Ocorrência que não permite Múltiplos Vínculos. Como resolver?

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16592314147607) MENSAGEM**:

300569 - Já existe o mesmo PIS/PASEP/CI cadastrado com Código de Ocorrência que não permite Múltiplos Vínculos.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16592314154007) SITUAÇÃO:**

Ao importar a SEFIP ocorre o erro.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16592324336535)SOLUÇÃO:**

**Pessoal G**

Acesse o cadastro do colaborador, aba **"Admissão"**, sub aba **"Dados p/ FGTS"**, altere o campo **"Tabela de Ocorrência FGTS"** para 05

![Imagem 4: Acesse o cadastro do colaborador, aba "Admissão" , sub aba "Dados p/ FGTS" , altere o campo "Tabela de Ocorrência FGTS"…](https://ajuda.sankhya.com.br/hc/article_attachments/8441614018967)

**Pessoal W**

Acesse o cadastro do funcionário, aba **"Contrato",** altere o campo **"Tabela de Ocorrência FGTS"** para 05

![Imagem 5: Acesse o cadastro do funcionário, aba "Contrato", altere o campo "Tabela de Ocorrência FGTS" para 05](https://ajuda.sankhya.com.br/hc/article_attachments/8441554291223)

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16592324342551)CAUSA:**

Este erro ocorre quando há movimentação para o colaborador em 2 cadastros ou mais na mesma referência.
