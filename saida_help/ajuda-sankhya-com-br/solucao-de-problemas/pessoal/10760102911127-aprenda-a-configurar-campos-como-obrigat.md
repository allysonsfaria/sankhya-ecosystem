# Aprenda a configurar campos como obrigatórios na requisição de admissão

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18796525159063) SOLUÇÃO:**

Para validar o campo como obrigatório, faça a marcação de campo obrigatório. Para isso, acesse a tela CONFIGURAÇÃO DE FUNCIONÁRIOS e clique no botão "Configuração da Tela (engrenagem)". Em seguida, clique na setinha do campo que deseja ajustar a configuração e marque a opção "Campo Obrigatório"

![Imagem 2: Para validar o campo como obrigatório, faça a marcação de campo obrigatório. Para isso, acesse a tela CONFIGURAÇÃO DE…](https://ajuda.sankhya.com.br/hc/article_attachments/18796517436183)

![Imagem 3: Para validar o campo como obrigatório, faça a marcação de campo obrigatório. Para isso, acesse a tela CONFIGURAÇÃO DE…](https://ajuda.sankhya.com.br/hc/article_attachments/18796525170839)

Assim, o campo ficará como obrigatório, para os anexos. Vale destacar que apenas é possível fazer a marcação de obrigatório no cadastro da ocorrência. Para admissão deve ser aberto uma sugestão de melhoria para fixá-lo como obrigatório.
