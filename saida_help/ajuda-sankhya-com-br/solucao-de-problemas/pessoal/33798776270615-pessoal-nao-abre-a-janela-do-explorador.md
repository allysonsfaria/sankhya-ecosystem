# Pessoal + não abre a Janela do Explorador de Arquivos não abre ao tentar baixar Holerites

Para realizar a integração de novos parceiros no sistema, siga as instruções detalhadas abaixo para garantir que os dados estejam corretamente configurados.

### Passo a passo para cadastro de parceiros

Acesse a tela **"Parceiros"** (Comercial >> Cadastros >> Parceiros) e execute os procedimentos conforme a ordem descrita:

Clique no botão **"Novo"** para iniciar um registro em branco.

Preencha os campos obrigatórios na aba **"Identificação"**, garantindo que o **"Nome"** e o **"CGC/CPF"** estejam validados.

Selecione o tipo de parceiro e marque o **"Botão Confirmar"** para salvar as alterações realizadas no cadastro.

Após finalizar o procedimento, certifique-se de que todas as abas complementares foram revisadas para evitar inconsistências nas futuras emissões de notas fiscais.
