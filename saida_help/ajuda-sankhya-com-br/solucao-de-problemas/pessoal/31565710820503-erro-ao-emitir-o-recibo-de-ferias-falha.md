# Erro ao emitir o Recibo de Férias: Falha Não foi possível gerar o relatório solicitado

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/31565725515799) **MENSAGEM:**

Erro ao emitir o Recibo de Férias: Falha Não foi possível gerar o relatório solicitado. Motivo: null

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/31565710819351)SOLUÇÃO:**

Acesse a tela **"Preferências"** (Configurações » Avançado » Preferências) e localize o parâmetro **"FPRELATRECFE"**. Ao encontrá-lo, deixe o campo **"Inteiro"** completamente em branco para que o sistema utilize o relatório padrão.
