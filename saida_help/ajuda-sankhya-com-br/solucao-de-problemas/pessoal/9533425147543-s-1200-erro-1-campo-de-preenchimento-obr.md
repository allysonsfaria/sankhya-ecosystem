# S-1200 | Erro 1 - Campo de preenchimento obrigatório: indicador de contribuição substituída

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16747908658711) MENSAGEM:**

[Erro 1] - Campo de preenchimento obrigatório: Indicador de Contribuição Substituída.Elemento: /eSocial/evtRemun/dmDev/infoPerApur/ideEstabLot/remunPerApur/indSimples[null]

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16747908662423) SITUAÇÃO:**

Ao enviar o S-1200 a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16747908663959) SOLUÇÃO:**

Acesse: Empresas (Configurações » Cadastros » Pessoal » Empresas) e preencha a informação do campo **"Indicador de Contribuição Substituída"**.

![Imagem 4: O preenchimento deve ser feito de acordo com cada empresa.](https://ajuda.sankhya.com.br/hc/article_attachments/16747897255447) O preenchimento deve ser feito de acordo com cada empresa.

![Imagem 5: O preenchimento deve ser feito de acordo com cada empresa.](https://ajuda.sankhya.com.br/hc/article_attachments/16747897261719)

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16747897262871) CAUSA:**

Cadastro incorreto das informações de substituição previdenciária para as empresas que são desoneradas.
