# PesquisaContent.lblNenhumRegistro, saiba como proceder 

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19571957820695) MENSAGEM:**

PesquisaContent.lblNenhumRegistro.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19571957825559) SITUAÇÃO:**

Ao tentar realizar a integração contábil pelo usuário SUP, o sistema não apresenta as empresas para escolher e gerar.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19571986501399) CAUSA:**

Ocorre ao fazer a integração contábil com usuário SUP.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19571957830807) SOLUÇÃO:**

- Faça a integração contábil pelo usuário DP ou outro que tenha essa liberação.
- O usuário SUP é administrador, não foi desenvolvido para essas funcionalidades.
- O SUP é para consultas, liberar acessos e rotinas nesse sentido.
