# Erro 700 - O campo deverá ser preenchido sempre que existir uma Admissão Preliminar para o trabalhador para a qual não exista uma Admissão correspondente. Como resolver?

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18610920645143) MENSAGEM:**

Erro 700 - O campo deverá ser preenchido sempre que existir uma Admissão Preliminar para o trabalhador para a qual não exista uma Admissão correspondente.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18610946630807) SITUAÇÃO:**

Ao registrar uma preliminar a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18610920654871) CAUSA:**

Ocorre quando a preliminar está informada no portal com data incorreta.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18610920660119) SOLUÇÃO:**

Verifique se a preliminar está devidamente informada no portal. Caso esteja basta excluir e inserir a mesma novamente com nova data.
