# O Vínculo Trabalhista não foi localizado. Ação Sugerida: Utilize o evento de admissão para cadastramento do vínculo trabalhista

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16981653294871) SOLUÇÃO:**

(1)** Pessoal +**

![Imagem 3: Acesse o cadastro na tela "Ambiente de Trabalho", aba "Funcionários que desempenham suas atividades neste ambiente" e…](https://ajuda.sankhya.com.br/hc/article_attachments/16981653297943) Acesse o cadastro na tela **"Ambiente de Trabalho",** aba **"Funcionários que desempenham suas atividades neste ambiente"** e verifique a data que está no campo **"Data Inicio Condição"** para o funcionário que está com o erro.

Ocorre quando é configurado com data anterior a admissão do funcionário.

**Exemplo:** Funcionário com data de admissão 07/04/2022 e a data de início condição está 01/04/2022.
