# Crédito do Trabalhador - Não há funcionário cadastrado com o CPF, matrícula e data admissão informados.

**SITUAÇÃO:**

Durante o processamento do Crédito do Trabalhador, foi identificada uma divergência entre a data de admissão cadastrada no sistema e a data informada no arquivo do eSocial/Emprega Brasil, o que impediu o lançamento automático do crédito.

![Imagem 1: Durante o processamento do Crédito do Trabalhador, foi identificada uma divergência entre a data de admissão cadastrada…](https://ajuda.sankhya.com.br/hc/article_attachments/36102426488855)

**SOLUÇÃO:**

**(1)** **Valide a data de admissão:**

- Acesse o ''**e-Social''** e verifique a data de admissão cadastrada para o trabalhador;
- Compare com a data registrada no **sistema Sankhya**.

**(2)** **Identifique a origem da divergência:**

- Se a data de admissão estiver incorreta no sistema será necessário ajustar essa data para que a importação ocorra corretamente.
- Se a data estiver correta tanto no eSocial quanto no sistema de folha, contate diretamente a instituição Emprega Brasil para verificar a causa da divergência no arquivo, registrar o protocolo de atendimento e acompanhar o retorno até a completa regularização das informações.
