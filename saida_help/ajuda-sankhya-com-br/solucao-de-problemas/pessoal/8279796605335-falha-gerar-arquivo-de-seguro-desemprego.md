# Falha gerar arquivo de seguro desemprego! Motivo: String index out of range: 0

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16592448262295) MENSAGEM**:

Falha gerar arquivo de seguro desemprego!

Motivo: String index out of range: 0

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16592448266263) SITUAÇÃO:**

Ao tentar gerar o arquivo do seguro desemprego ocorre o erro.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16592478311959) SOLUÇÃO:**

Acesse o cadastro do funcionário e verifique se o campo de telefone foi informado, se sim, precisa ser um número válido e no formato correto.

- Para mais informações, acesse o [Manual do Layout do Seguro desemprego.](http://suporte.quarta.com.br/LayOuts/Governo/Layout_Seguro-Desemprego.pdf)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16592478315415)CAUSA:**

O erro ocorre quando o telefone no cadastro do colaborador está preenchido incorretamente.
