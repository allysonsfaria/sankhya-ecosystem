# O Vínculo Trabalhista já se encontra encerrado na data do evento

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16504039194391) MENSAGEM**:

Erro 181 - O Vínculo Trabalhista já se encontra encerrado na data do evento.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16504039201303) CAUSA:**

Ocorre quando tentamos enviar algum evento com data posterior ao desligamento.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16504060059287) SOLUÇÃO:**

Para a resolução do erro, siga os passos abaixo:

![Imagem 4: Verifique se a data do registro que está tentando enviar é posterior a data do desligamento do colaborador no eSocial.…](https://ajuda.sankhya.com.br/hc/article_attachments/16504060061847) Verifique se a data do registro que está tentando enviar é posterior a data do desligamento do colaborador no eSocial. Caso seja, não será aceito.

![Imagem 5: Verifique se é devido o envio deste registro, caso seja, ajuste para uma data anterior ao desligamento.](https://ajuda.sankhya.com.br/hc/article_attachments/16504060063895) Verifique se é devido o envio deste registro, caso seja, ajuste para uma data anterior ao desligamento.

**Para verificar as movimentações do colaborador no site do eSocial siga o passo a passo abaixo:**

Acesse o [site do eSocial](https://login.esocial.gov.br/login.aspx) e efetue a consulta pelo CPF desse colaborador (Empregado->Gestão de empregados).

Em seguida, clique em Movimentações trabalhistas e verifique as movimentações e suas respectivas  datas.
