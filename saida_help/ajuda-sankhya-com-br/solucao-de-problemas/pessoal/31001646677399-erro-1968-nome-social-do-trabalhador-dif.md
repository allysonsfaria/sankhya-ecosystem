# Erro 1968 - Nome Social do Trabalhador diferente do valor no Sistema da RFB

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/31081598680343) MENSAGEM:**

Erro 1968 - O Nome Social do Trabalhador está diferente do valor encontrado no Sistema da RFB. Valor no Sistema = Indefinido.
Ação sugerida: Procure unidade conveniada da RFB e efetue a regularização.
Elemento: /eSocial/evtAltCadastral/alteracao/dadosTrabalhador/nmSoc

 **SOLUÇÃO:**

(1)** Verifique se este funcionário possui nome social cadastrado no Sistema da RFB e, se possuir, qual é este nome:**

**(2)** **Se o funcionário possuir nome cadastrado na RFB:** acesse a tela **"Configuração Funcionário",** localize o campo **"Nome Social"** e valide a informação contida nele, garantido que o nome cadastro no RFB e no Sankhya sejam o mesmo.

**(2)** **Se o funcionário NÃO possuir nome cadastrado na RFB:**acesse a tela Configuração Funcionário, localize o campo Nome Social e retire a informação que estiver cadastrada nele, deixando-o em branco. Pois, **esse campo só pode ser preenchido quando o funcionário possui nome social cadastrado no Sistema da RFB.**
