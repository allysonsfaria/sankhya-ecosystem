# Os seguintes produtos estão com a data de limite vencida: Produto xxx, Local xxx, Cotação xxx

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16474630631319) MENSAGEM**:

Os seguintes produtos estão com a data de limite vencida: Produto xxx, Local xxx, Cotação xxx.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16474630634263) SOLUÇÃO:**

Essa mensagem se refere ao campo **"Data limite",** na aba **"Itens de cotação",** encontrado na opção **"Adicionar Produtos da tela cotação".**Para a resolução deste caso, siga os passos abaixo:

![Imagem 3: Abra a cotação informada no erro e clique no botão "Adicionar Produtos" ;](https://ajuda.sankhya.com.br/hc/article_attachments/16474913653911) Abra a cotação informada no erro e clique no botão **"Adicionar Produtos"**;

![Imagem 4: Na aba itens de cotação, altere a data limite para a atual ou superior para que possa aprovar a cotação sem maiores…](https://ajuda.sankhya.com.br/hc/article_attachments/16474913656727) Na aba itens de cotação, altere a data limite para a atual ou superior para que possa aprovar a cotação sem maiores problemas;

![Imagem 5: Na aba itens de cotação, altere a data limite para a atual ou superior para que possa aprovar a cotação sem maiores…](https://ajuda.sankhya.com.br/hc/article_attachments/16474630638999)

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16474660178455) CAUSA:**

Ao clicar no botão Aprovar, na tela de **"Cotação"**, caso algum dos produtos da cotação esteja com a data limite inferior a data atual o erro mencionado ocorre.
