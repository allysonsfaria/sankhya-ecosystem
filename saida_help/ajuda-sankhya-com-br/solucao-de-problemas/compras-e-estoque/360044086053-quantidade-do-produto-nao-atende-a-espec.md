# Quantidade do produto não atende a especificação de múltiplo para compra deste produto/parceiro

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16175724063127) MENSAGEM:**

[CORE\_E02652] Quantidade do produto não atende a especificação de múltiplo para compra deste produto/parceiro.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16175739911191) SOLUÇÃO:**

Ao realizar movimentações de entrada, quando inserido uma quantidade para determinado item, que não seja múltipla do valor definido no campo **"Qtd. multiplicador Compra"** (Aba **Geral** da tela **"Produtos"**) será apresentada a mensagem.

![Imagem 3: Caso para o Tipo de Operação utilizado não seja necessário realizar essa validação, o campo abaixo deverá estar marcado:](https://ajuda.sankhya.com.br/hc/article_attachments/16175739913879) Caso para o **Tipo de Operação** utilizado não seja necessário realizar essa validação, o campo abaixo deverá estar marcado:

- Tela **"[Tipos de Operação - TOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114)"** (Caminho de acesso: Configurações » Cadastros » Produtos » Tipos de Operação - TOP)
  Aba **Estoque**
  Campo **"Ignorar agrupamento mínimo de compra"**:

![Imagem 4: Tela " Tipos de Operação - TOP " (Caminho de acesso: Configurações » Cadastros » Produtos » Tipos de Operação - TOP )…](https://ajuda.sankhya.com.br/hc/article_attachments/14687145649815)
