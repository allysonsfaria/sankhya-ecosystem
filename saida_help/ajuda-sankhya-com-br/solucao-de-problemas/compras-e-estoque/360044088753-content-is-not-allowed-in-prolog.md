# Content is not allowed in prolog

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16414131045015) MENSAGEM:**

[CORE\_E02284] Content is not allowed in prolog.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16414143457047) SITUAÇÃO:**

**![Imagem 10: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16414143465111) CAUSA:**

Ao realizar a importação de XML no sistema, a mensagem poderá ser apresentada nas situações a seguir:

- XML a ser importado não está no formato esperado.
- XML a ser importado possui caracteres inválidos.
