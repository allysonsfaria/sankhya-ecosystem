# Produto não está permitido para compra

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16478270066967) MENSAGEM:**

[CORE\_E03240] Produto não está permitido para compra.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16478315343639)CAUSA:**

Mensagem apresentada ao tentar lançar item que não está permitido para compra em um lançamento com tipo de movimento compra.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16478270070679) SOLUÇÃO:**

![Imagem 4: Verifique no cadastro do produto, no aba "Geral" , se o campo "Permite comprar este produto?" está marcado](https://ajuda.sankhya.com.br/hc/article_attachments/16478270074263) Verifique no cadastro do produto, no aba **"Geral"**, se o campo **"Permite comprar este produto?"** está marcado

- Tela **"Produtos"** (Caminho de acesso: Configurações » Cadastros » Produtos » Produtos)
- Aba **"Geral"**
- Campo **"Permite comprar este produto"**

![Imagem 5: Campo "Permite comprar este produto"](https://ajuda.sankhya.com.br/hc/article_attachments/16478270080791)

Feita a marcação, siga com o lançamento.
