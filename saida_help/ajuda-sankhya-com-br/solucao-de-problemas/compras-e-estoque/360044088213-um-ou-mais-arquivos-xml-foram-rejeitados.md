# Um ou mais arquivos XML foram rejeitados na importação do lote

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16169046538263) MENSAGEM:**

Um ou mais arquivos XML foram rejeitados na importação do lote. Para consultar quais arquivos e quais problemas veja no Repositório de Arquivos no seguinte caminho:
Comercial/Importação de XML/XML Rejeitados.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16169046541463) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse: Configurações » Avançado » Repositório de Arquivos](https://ajuda.sankhya.com.br/hc/article_attachments/16169022317847) Acesse: Configurações » Avançado » Repositório de Arquivos

Vá até o caminho indicado pela mensagem de erro: Comercial/Importação de XML/XML Rejeitados.

![Imagem 4: Identifique o arquivo de erro, que estará relacionado ao XML Importado que apresentou alguma rejeição.](https://ajuda.sankhya.com.br/hc/article_attachments/16169046548375) Identifique o arquivo de erro, que estará relacionado ao XML Importado que apresentou alguma rejeição.

![Imagem 5: Abra este arquivo em um bloco de notas, para que seja possível identificar o erro que ocasionou a rejeição.](https://ajuda.sankhya.com.br/hc/article_attachments/16169022322455) Abra este arquivo em um bloco de notas, para que seja possível identificar o erro que ocasionou a rejeição.

![Imagem 6: Efetue o ajuste ou busque orientações de como resolver a rejeição.](https://ajuda.sankhya.com.br/hc/article_attachments/16169022326935) Efetue o ajuste ou busque orientações de como resolver a rejeição. 

![Imagem 7: Após os ajustes, efetue a importação do XML novamente pelo ' Comercial » Rotinas » Portal de importação de XML'.](https://ajuda.sankhya.com.br/hc/article_attachments/16169046556055) Após os ajustes, efetue a importação do XML novamente pelo 'Comercial » Rotinas » Portal de importação de XML'.

**![Imagem 8: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16169046558359) CAUSA:**

Quando ocorrer alguma rejeição na importação do XML por qualquer motivo, será apresentado o 'log' com informações no repositório de arquivos, onde será necessário analisá-lo para resolver os problemas.
