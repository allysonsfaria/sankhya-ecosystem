# Este tipo de título só pode ser usado pela rotina de compensação

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16176034693143) MENSAGEM:**

[CORE\_E03478] Este tipo de título só pode ser usado pela rotina de compensação.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16176034696343) SOLUÇÃO:**

![Imagem 3: Verifique na tela " Preferências " ( Caminho de acesso: Configurações » Avançado » Preferências ) se a chave…](https://ajuda.sankhya.com.br/hc/article_attachments/16176019211799) Verifique na tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834)"** (Caminho de acesso: Configurações » Avançado » Preferências) se a chave **"TIPTITCREDCLI"** encontra-se configurada com o tipo de título **"Crédito de Cliente"**. Em caso negativo, realize os devidos ajustes.

![Imagem 4: Certifique-se então, que o lançamento realizado que gerou essa mensagem de validação não esteja utilizando o mesmo tipo…](https://ajuda.sankhya.com.br/hc/article_attachments/16176034701079) Certifique-se então, que o lançamento realizado que gerou essa mensagem de validação não esteja utilizando o mesmo tipo de título configurado em tal parâmetro (**"TIPTITCREDCLI"**).

![Imagem 5: Certifique-se então, que o lançamento realizado que gerou essa mensagem de validação não esteja utilizando o mesmo tipo…](https://ajuda.sankhya.com.br/hc/article_attachments/14605117806103)

**![Imagem 6: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/17855062483351) IMPORTANTE:**

Para verificar qual o tipo de título usado em seu lançamento, acesse a tela **"[Tipos de Negociação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109173)"** (Caminho de acesso: Comercial » Arquivo » Cadastros » Tipos de Negociação), na aba **Parcelas** identifique a informação cadastrada em **"Tipo de título"** de cada parcela.

![Imagem 7: Para verificar qual o tipo de título usado em seu lançamento, acesse a tela " Tipos de Negociação " ( Caminho de…](https://ajuda.sankhya.com.br/hc/article_attachments/14605133305367)

**![Imagem 8: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16176034708631) CAUSA:**

Ocorre ao realizar um lançamento com um tipo de título definido para Compensação de Crédito.
