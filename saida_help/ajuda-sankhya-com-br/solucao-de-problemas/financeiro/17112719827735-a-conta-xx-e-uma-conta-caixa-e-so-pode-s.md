# A conta 'XX' é uma conta caixa e só pode ser usada por um usuário caixa

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/17112719820183) **MENSAGEM:**

[CORE\_E01358] A conta 'XX' é uma conta caixa e só pode ser usada por um usuário caixa.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/17112691065751)CAUSA:**

O aviso é apresentado quando a conta é Caixa e está sendo utilizada por um usuário que não é Caixa.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17112700083863)SOLUÇÃO:**

Acesse a tela '**Contas'** (Caminho de acesso: Configurações » Cadastros » Bancários » Contas), Aba Cadastros, no campo '**Tipo de Conta**', caso a marcação esteja como **Caixa (PDV)**, a ação somente será permitida com um usuário também configurado como "Caixa", importante identificar na tela 'Contas', no campo **Operador Exclusivo** se existe um usuário específico para essa conta, caso tenha, necessário que esse usuário acesse o sistema e realize o processo.
