# O Caixa XX está aberto! Somente o usuário que está logado no caixa tem permissão para excluir este Movimento Bancário

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16780033502487) MENSAGEM:**

[CORE\_E04077]: O Caixa XX está aberto! Somente o usuário que está logado no caixa tem permissão para excluir este Movimento Bancário.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16780038784535) SOLUÇÃO:**

De fato não será possível realizar a exclusão, uma vez que a conta caixa é bem limitada, específica e exclusiva, é o comportamento padrão do sistema ter essas travas para manter a segurança e a rastreabilidade das informações.
Nesse caso, o recomendado é realizar um lançamento de suprimento nesse caixa (um lançamento contrário a esse) para que seja feita a correção.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16780033510167) CAUSA:**

Ocorre ao tentar excluir um lançamento na conta caixa.
