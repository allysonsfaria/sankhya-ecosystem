# A baixa agrupada não está preparada para títulos de empresas diferentes

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16912674956311) MENSAGEM:**

[CORE\_E03694]: A baixa agrupada não está preparada para títulos de empresas diferentes.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16912674958359)SOLUÇÃO:**

**(1)** A baixa agrupada permitirá apenas títulos de uma mesma empresa;
**(1)** A baixa para empresas diferentes ainda não é possível, pois não foram tratadas questões como conciliação, contabilização e partes fiscais.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16912674961047)CAUSA:**

Ocorre ao tentar fazer a baixa agrupada em empresas diferentes.
