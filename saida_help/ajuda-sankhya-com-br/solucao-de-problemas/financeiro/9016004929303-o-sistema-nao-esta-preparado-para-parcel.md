# O sistema não está preparado para parcelar em 100 ou mais vezes

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16597581014679) MENSAGEM:**

[CORE\_E02686] O sistema não está preparado para parcelar em 100 ou mais vezes.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16597581018391) SITUAÇÃO:**

**(1)** Ao tentar fazer um parcelamento em mais de 99 vezes;

**(1)** Gerar tipo de negociação com mais de 99 vezes ou;

**(1)** Fazer um adiantamento/empréstimo em mais de 99 vezes.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16597592743703)CAUSA:**

Parcelamentos acima de 100 vezes não estão preparados pelo sistema.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16597581021591) SOLUÇÃO:**

De fato o sistema ainda não está preparado para fazer parcelamentos maiores que 100 vezes.
Para que seja permitido é necessário executar os scripts no seu banco de dados, para isso, entre em contato com o suporte do Service Desk para auxílio nessa intervenção.
