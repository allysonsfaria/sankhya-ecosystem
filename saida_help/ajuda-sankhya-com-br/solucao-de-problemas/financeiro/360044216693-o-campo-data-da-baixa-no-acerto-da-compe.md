# O campo Data da Baixa no Acerto da Compensação Financeira não fica disponível para digitação

**![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16193202397975) SITUAÇÃO:**

Foi acessado a rotina de Compensação Financeira para fazer um acerto, porém o campo **"Data da Baixa"** não está disponível para digitação.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16193188424599) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse: Configurações » Avançado » Preferências](https://ajuda.sankhya.com.br/hc/article_attachments/16193188431767) Acesse: Configurações » Avançado » Preferências

Parâmetro **"DIGDTBAIXACF- Digitar data da baixa na Compensação Financeira?":**ligado

![Imagem 4: Acesse: Financeiro » Rotinas » Compensação Financeira](https://ajuda.sankhya.com.br/hc/article_attachments/16193188433943) Acesse: Financeiro » Rotinas » Compensação Financeira

- Exemplo do Acerto com o Parâmetro DIGDTBAIXACF: desligado

![Imagem 5: Exemplo do Acerto com o Parâmetro DIGDTBAIXACF : desligado](https://ajuda.sankhya.com.br/hc/article_attachments/14611715313047)

- Exemplo do Acerto com o Parâmetro DIGDTBAIXACF: ligado

![Imagem 6: Exemplo do Acerto com o Parâmetro DIGDTBAIXACF : ligado](https://ajuda.sankhya.com.br/hc/article_attachments/14611716523415)

![Imagem 7: Com este parâmetro ligado é possível alterar a Data da Baixa.](https://ajuda.sankhya.com.br/hc/article_attachments/16193188439063) Com este parâmetro ligado é possível alterar a Data da Baixa.

**![Imagem 8: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16193188440983) CAUSA:**

Ocorre quando o parâmetro DIGDTBAIXACF está desligado e com isso a Data da Baixa é a data atual do acerto. Para alterar a Data da baixa é necessário ligar o parâmetro DIGDTBAIXACF.
