# Não é permitido transferir esse título pois o mesmo foi lançado no caixa de outro usuário.

**MENSAGEM:**

"Não é permitido transferir esse título pois o mesmo foi lançado no caixa de outro usuário"
 Nro Nota/Cheque:
 Nro único Mov.Bco:
 Nro Único Fin:
 Código: FIN\_E00103

![Imagem 1: MENSAGEM: "Não é permitido transferir esse título pois o mesmo foi lançado no caixa de outro usuário" Nro Nota/Cheque:…](https://ajuda.sankhya.com.br/hc/article_attachments/43702045169175)

##### SITUAÇÃO:

Este bloqueio ocorre ao tentar realizar a transferência de um cheque ou título entre contas de usuários diferentes que operam como caixas.

##### SOLUÇÃO:

Para permitir a movimentação do título e corrigir o erro, siga os passos abaixo:

**(1)** Acesse a tela Configurações » Avançado » Preferências

**(1)**Pesquise pelo parâmetro **TRANSFCHQLIVRE** (Permitir transf. cheque mesmo de outros caixas).

**(1)**Ative este parâmetro.

**(1)**Salve as alterações e tente realizar a transferência do título novamente.

![Imagem 2: (1) Salve as alterações e tente realizar a transferência do título novamente. CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/43814763679767)

 **CAUSA:**

Por padrão de segurança e controle, o sistema restringe a movimentação de títulos que foram lançados no caixa de terceiros. Para que essa operação seja possível, é necessário que o sistema esteja explicitamente configurado para aceitar a transferência livre entre caixas.
