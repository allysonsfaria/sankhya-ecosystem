# Aviso: As credenciais inseridas apresentaram erro no teste de integração

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16305317526423) MENSAGEM:**

[CORE\_E07141] Aviso: As credenciais inseridas apresentaram erro no teste de integração. Por favor, tente novamente.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16305301190935) SITUAÇÃO:**

Ao realizar a configuração de API do banco de brasil na tela de contas a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16305317541015) SOLUÇÃO:**

O **Sankhya OM** está preparado para trabalhar somente em ambiente de produção, portanto ao solicitar as credenciais ao banco deve ser realizado nesse ambiente. Sendo assim, as credenciais precisam ser de Produção. Precisa seguir os passos de enviar as Credenciais para Produção e quando tiver aprovado vai aparecer na aba Produção, as credenciais.
