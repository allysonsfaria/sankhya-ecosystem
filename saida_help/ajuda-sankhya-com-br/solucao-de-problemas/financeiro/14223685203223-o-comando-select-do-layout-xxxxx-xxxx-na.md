# O comando SELECT do Layout: "XXXXX - xxxx" não encontrou informações no Banco de dados

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16913392907799) MENSAGEM:**

[CORE\_E04727]: O comando SELECT do Layout: "XXXXX - xxxx" não encontrou informações no Banco de dados!

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16913370869015)SOLUÇÃO:**

Por se tratar de uma inconsistência no layout utilizado para a geração da remessa, solicite a pessoa responsável pela configuração do layout que o revise para identificar qual o campo que está com o SELECT incorreto.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16913392913047)CAUSA:**

Ocorre pois algum SELECT definido no layout não está conseguindo localizar a informação necessária.
