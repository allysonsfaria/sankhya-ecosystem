# Só é permitida uma parcela com Tipo de Título PIX a cada baixa. Se necessário, utilize a Baixa Parcial

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19140317437463) **MENSAGEM:**

Só é permitida uma parcela com Tipo de Título PIX a cada baixa. Se necessário, utilize a Baixa Parcial.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19140329303319)CAUSA:**

Ao tentar realizar a baixa com a opção: **Pagamento com vários títulos**, informando o Tipo de Título PIX mais de uma vez.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19140329299735)SOLUÇÃO:**

Acesse a tela **Movimentação Financeira** (Caminho: Financeiro » Rotinas » Movimentação Financeira) localize o lançamento, e selecione o botão **Baixar**, informe no campo **Pagamento com vários títulos**, o primeiro valor a ser baixado com o Tipo de Título PIX e selecione Baixar, será apresentado a mensagem:

**Uma das parcelas apontada está com tipo de Título PIX. Deseja gerar um QRCode para recebimento com PIX ou apenas Baixar?**

Selecione a forma que prefere baixar o lançamento e posteriormente selecione a opção **Pendência** para que o valor da diferença fique disponível para que o processo seja realizado novamente.
