# Data da baixa fora do período permitido. A data limite para Lançamentos Futuros é xx/xx/xxxx

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16192842894999) MENSAGEM**:

[CORE\_E02192] Data da baixa fora do período permitido. A data limite para Lançamentos Futuros é xx/xx/xxxx.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16192806471703) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse a tela " Usuários " (Caminho de acesso: Configurações » Controle de Acesso » Usuários ):](https://ajuda.sankhya.com.br/hc/article_attachments/16192842900503) Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874)"** (Caminho de acesso: Configurações »  Controle de Acesso » Usuários):

- Botão: **"Outras Opções"**, opção **"Configurações Usuário"**
- Campo **"Dias para Lançamentos Futuros":** alterar o valor deste campo

![Imagem 4: Campo "Dias para Lançamentos Futuros": alterar o valor deste campo](https://ajuda.sankhya.com.br/hc/article_attachments/14608625374359)

![Imagem 5: Campo "Dias para Lançamentos Futuros": alterar o valor deste campo](https://ajuda.sankhya.com.br/hc/article_attachments/14608701892759)

![Imagem 6: Após o ajuste, efetue a baixa novamente dos títulos.](https://ajuda.sankhya.com.br/hc/article_attachments/16192806476183) Após o ajuste, efetue a baixa novamente dos títulos.

**![Imagem 7: CAUSA :](https://ajuda.sankhya.com.br/hc/article_attachments/16192842902935) CAUSA**:

Ocorre quando um usuário tenta efetuar a baixa de um título com data futura maior que o permitido em suas configurações, sendo necessário aumentar o valor neste campo.
