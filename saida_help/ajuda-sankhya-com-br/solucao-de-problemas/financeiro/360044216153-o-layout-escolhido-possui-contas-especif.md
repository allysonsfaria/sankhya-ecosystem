# O layout escolhido possui contas específicas e a conta xx não consta entre essas

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/17285548660503)  MENSAGEM:**

[CORE\_E00743]: O layout escolhido possui contas específicas e a conta xx não consta entre essas.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/17285591667735) CAUSA:**

Ocorre quando uma das contas não esta devidamente configurada no Layout de Geração do arquivo de remessa.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17285548666903) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 4: Acesse: Financeiro » EDI Bancário » Configuração Arquivo de Remessa](https://ajuda.sankhya.com.br/hc/article_attachments/17285548673687) Acesse: Financeiro » EDI Bancário » Configuração Arquivo de Remessa

Selecione o Layout que é utilizado para a remessa.

Acesse a aba: **"Detalhes para geração de arquivo"**
Sub-Aba: "**Contas para geração"**

Informe a conta, que está na 'critica' do erro e salve o registro.

![Imagem 5: Informe a conta, que está na 'critica' do erro e salve o registro.](https://ajuda.sankhya.com.br/hc/article_attachments/15413940127383)

![Imagem 6: Acesse: Financeiro » EDI Bancário » Geração Arquivo de Remessa e efetue o processo de geração do arquivo novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/17285591661463) Acesse: Financeiro » EDI Bancário » Geração Arquivo de Remessa e efetue o processo de geração do arquivo novamente.
