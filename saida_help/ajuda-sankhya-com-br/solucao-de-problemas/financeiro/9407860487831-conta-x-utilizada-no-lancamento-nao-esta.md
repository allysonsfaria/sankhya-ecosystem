# Conta X -  utilizada no lançamento, não está configurada para emissão de boletos

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18972499593239) MENSAGEM:**

[CORE\_E07262] Conta X - utilizada no lançamento, não está configurada para emissão de boletos. VERIFIQUE (Configurações Cadastros Bancários Contas » ABA: boletos/duplicatas: campo: EMITE).

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18972515982615) SITUAÇÃO:**

Ao tentar realizar a emissão de boletos ou emitir nota configurada para emissão de BOLETA a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18972499602583) CAUSA:**

Tentar emitir um boleto usando uma conta que não está configurada para emitir boleto.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18972499607575) SOLUÇÃO:**

Acesse o cadastro de **Contas** (Caminho de acesso: Configurações » Cadastros » Bancários » Contas), vá até a aba Boleto(s)/Duplicatas, marque a opção "Boleto Avançado/Duplicatas". Em seguida, flegue o campo "Emite". Também informe o modelo de cobrança e na aba Intercâmbio Eletrônicos de Dados (EDI), configure os campos carteira, convênio, modalidade, etc. conforme instrução do banco.
