# For input string: "XXXXX-X"

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/30375660472343) **MENSAGEM:**

For input string: "XXXXX-X"

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/30375694906519)SOLUÇÃO:**

Acesse a tela **Contas** (Caminho: Configurações » Cadastros » Bancários » Contas), localize a conta utilizada para a impressão do boleto, remova o hífen ("-") no campo **Conta** e salve a alteração.

![Imagem 3: Acesse a tela Contas (Caminho: Configurações » Cadastros » Bancários » Contas), localize a conta utilizada para a…](https://ajuda.sankhya.com.br/hc/article_attachments/30418609635863)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/30375694907671)CAUSA:**

Ocorre quando é inserido hífen no código da conta bancária utilizada na Impressão de Boleto(s).
