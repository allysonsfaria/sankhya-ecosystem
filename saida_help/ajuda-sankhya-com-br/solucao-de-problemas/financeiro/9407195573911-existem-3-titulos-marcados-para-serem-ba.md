# Existem 3 títulos marcados para serem baixados

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19035738387095) MENSAGEM:**

[FIN\_E00060] Existem 3 títulos marcados para serem baixados.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19035738408599) SITUAÇÃO:**

Ao tentar realizar o fechamento de ordem de carga a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19035738410647) CAUSA:**

Ao tentar fechar o caixa do acerto sem marcar as notas corretamente.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19035738423319) SOLUÇÃO:**

Acesse a tela **Acerto de Ordem de carga** (Caminho de acesso à tela: Financeiro » Rotinas » Acertos » Acerto de Ordem de Carga)

 --Financeiro da nota 
Aba > venda 
Campo > Retornado
Todas as notas marcadas como Entregue com Tipo de titulo Boleto >> devem estar marcadas na aba abaixo como Retornado Sim, pois isso mostra que foi retornado o boleto corretamente.
