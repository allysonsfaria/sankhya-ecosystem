# Conta padrão do usuário não foi informada. Informe através do parâmetro 'CONTAPADRAO'

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16490891853591) MENSAGEM:**

[FIN\_E00052] Conta padrão do usuário não foi informada. Informe através do parâmetro 'CONTAPADRAO'.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16490901183511) CAUSA:**

Mensagem apresentada ao tentar realizar processo de baixa, sem que exista conta padrão informada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16490948313239) SOLUÇÃO:**

![Imagem 4: Acesse a tela "Usuários" , selecione o usuário responsável pela baixa:](https://ajuda.sankhya.com.br/hc/article_attachments/16490948314775) Acesse a tela **"Usuários"**, selecione o usuário responsável pela baixa:

- Outras Opções >> Configurações do Usuário
- Informe o **'Número da conta padrão na baixa'**

![Imagem 5: Informe o 'Número da conta padrão na baixa'](https://ajuda.sankhya.com.br/hc/article_attachments/15938796705943)

![Imagem 6: Caso não seja realizada a configuração por usuários, conforme item 1, acesse a tela "Preferências" (Caminho de acesso:…](https://ajuda.sankhya.com.br/hc/article_attachments/16490979500439) Caso não seja realizada a configuração por usuários, conforme item 1, acesse a tela **"Preferências"** (Caminho de acesso: Configurações » Avançado) e configure o parâmetro abaixo com a conta padrão para baixa.

- Chave **"CONTAPADRAO":** Número da conta padrão na baixa
