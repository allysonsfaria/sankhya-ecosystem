# Não existem movimentações no arquivo informado ou todos os registros já foram importados em outra importação usando outro arquivo

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19277262535191) MENSAGEM:**

[FIN\_E00318]  Não existem movimentações no arquivo informado ou todos os registros já foram importados em outra importação usando outro arquivo. Talvez ele não seja um arquivo OFX válido.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277262540311) SITUAÇÃO:**

Ao tentar processar um arquivo OFX a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19277284777239) CAUSA:**

Ocorre normalmente quando a extensão do arquivo importado não é OFX, não possui transações no arquivo ou já tenha sido importado anteriormente.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277262547351) SOLUÇÃO:**

Inicialmente, confira se a extensão do arquivo é de fato OFX. Pois, não serão permitidos, por exemplo, arquivos com extensão TXT.

![Imagem 5: Inicialmente, confira se a extensão do arquivo é de fato OFX. Pois, não serão permitidos, por exemplo, arquivos com…](https://ajuda.sankhya.com.br/hc/article_attachments/19277262549783)

Caso a extensão esteja correta, abra o arquivo e verifique se ele possui de fato transações. Caso tenha se certificado de que esse arquivo não tenha sido importado anteriormente.
