# Perda de receita, veja como configurar

Para se realizar a baixa de uma receita como perda, siga os passos abaixo:

![Imagem 1: Entre na tela: Configurações >> Cadastros >> Bancários >> Contas , e inclua uma conta bancaria de controle;](https://ajuda.sankhya.com.br/hc/article_attachments/16490590626455) Entre na tela: **Configurações >> Cadastros >> Bancários >> Contas**, e inclua uma conta bancaria de controle;

![Imagem 2: implante o saldo para essa conta com data retroativa de 01 ano a data de seu cadastro em Outras Opções / Implanta Saldo…](https://ajuda.sankhya.com.br/hc/article_attachments/16490598817431) implante o saldo para essa conta com data retroativa de 01 ano a data de seu cadastro em Outras Opções / Implanta Saldo Bancário, fazer a baixa desses títulos usando essa conta;

**![Imagem 3: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16490598826647) OBSERVAÇÃO:**

**(1)** Essa conta deverá ser desconsiderada para geração de relatórios e análise gerenciais que levam em consideração saldo bancário;

**(1)** Ideal que seja criada uma regra, através do módulo Central de Certificações, para que permita a utilização dessa conta por pessoas chave na empresa, evitando baixas indevidas de títulos para a conta que na verdade deveria entrar em contas custo que os saldos são considerados para análises gerenciais.

**(1)** A TOP utilizada na baixa deve ser diferente da TOP utilizada em uma baixa convencional por conta das configurações contábeis.
