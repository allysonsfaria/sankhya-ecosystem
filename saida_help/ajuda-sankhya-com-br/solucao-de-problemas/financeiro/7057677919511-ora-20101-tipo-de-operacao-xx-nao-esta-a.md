# ORA-20101: Tipo de Operação xx não está ativo para a nota de Nro Único:xxxx

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16480666985495)  MENSAGEM**:

ORA-20101: Tipo de Operação xx não está ativo para a nota de Nro Único:xxxx.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16480667004439) SOLUÇÃO:**

Para a resolução do erro, siga os passos abaixo:

![Imagem 3: Verifique se o campo " Ativo" está desmarcado para a TOP que está utilizando no lançamento, na tela: Comercial >>…](https://ajuda.sankhya.com.br/hc/article_attachments/16480673891863) Verifique se o campo **"Ativo"** está desmarcado para a TOP que está utilizando no lançamento, na tela: Comercial >> Arquivo >> Cadastros >> Tipos de Operação - TOP;

![Imagem 4: Caso esteja desmarcado, analise se a TOP foi descontinuada e tem uma substituta ou desmarcada indevidamente, nesse caso…](https://ajuda.sankhya.com.br/hc/article_attachments/16480673899031) Caso esteja desmarcado, analise se a TOP foi descontinuada e tem uma substituta ou desmarcada indevidamente, nesse caso ative-a e repita o lançamento.

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16480667026455)CAUSA:**

Ocorre quando o campo **ativo** está desmarcado para a TOP que está utilizando no lançamento na tela: Comercial >> Arquivo >> Cadastros >> Tipos de Operação - TOP.
