# ORA-20101: A data de conciliação não pode ser anterior a data de lançamento

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18584884327319) MENSAGEM:**

ORA-20101: A data de conciliação não pode ser anterior a data de lançamento.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18584884344343) CAUSA:**

Ao tentar realizar a conciliação bancária de títulos com data de conciliação anterior a data do lançamento do título, a mensagem será apresentada.

**![Imagem 3: SOLUÇÃO](https://ajuda.sankhya.com.br/hc/article_attachments/18584884347159) SOLUÇÃO**

Verifique e ajuste a data informada para conciliação bancária, onde:

- **Data da Conciliação NÃO pode ser uma data ANTERIOR a data do lançamento**, conforme exemplo abaixo:

![Imagem 4: Data da Conciliação NÃO pode ser uma data ANTERIOR a data do lançamento , conforme exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/18584868700567)

Realizado o ajuste, a conciliação será permitida.
