# Todas as parcelas do tipo de negociação devem permitir digitar data e valor para que este parcelamento possa ser utilizado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16170878209815) MENSAGEM:**

[COM\_E00253] Todas as parcelas do tipo de negociação devem permitir digitar data e valor para que este parcelamento possa ser utilizado. Campo 'Opção de Digitação' da aba Parcelas do Tipo de Negociação.
