# Para realizar a Edição de Lote a Ordem de Produção deve estar Criada ou Em andamento

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/23641126165271) MENSAGEM:**

[PROD\_E00180] Para realizar a Edição de Lote a Ordem de Produção deve estar Criada ou Em andamento.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/23641126168087) CAUSA:**

Ao tentar digitar o lote correto no processo produtivo de terceiro já finalizado a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/23641155695383) SOLUÇÃO:**

Quando uma OP está finalizada de forma nativa não é possivel fazer a alteração do lote, como sugestão orientamos fazer o [ajuste de estoque](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045117633-Ajuste-de-Estoque) ou processo de desmonte.
