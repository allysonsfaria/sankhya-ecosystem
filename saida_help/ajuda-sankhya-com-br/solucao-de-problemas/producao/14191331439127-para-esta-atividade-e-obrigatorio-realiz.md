# Para esta atividade é obrigatório realizar apontamentos de Produto acabado (PA)

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16914125601047) MENSAGEM:**

[PROD\_E00420]: Para esta atividade é obrigatório realizar apontamentos de Produto acabado (PA).

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16914154045975)SOLUÇÃO:**

É necessário realizar o apontamento da atividade, pois foi configurado no roteiro que esse apontamento é obrigatório.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16914125606039)CAUSA:**

Acontece quando a marcação "Exige apontamento de PA" está marcada na tela Produção » Cadastros » Processo Produtivo - Nova - botão Roteiro, dentro da aba Apontamento.
