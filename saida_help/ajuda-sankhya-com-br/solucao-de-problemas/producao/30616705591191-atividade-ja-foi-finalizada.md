# Atividade já foi finalizada

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/30616705585943) **MENSAGEM:**

[PROD\_E00049] Atividade já foi finalizada!

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/30616734815895)SOLUÇÃO:**

Caso a atividade já esteja finalizada, a Ordem de Produção não poderá mais ser alterada, garantindo assim a integridade das informações.

Nesse caso, a depender do processo temos três alternativas:

**(1)** Criar uma nova Ordem de Produção para atender a quantidade faltante do apontamento;

**(1)** Fazer o processo de desmonte e gerar uma nova Ordem de Produção com a quantidade total;

**(1)** Cancelar a OP com atividade finalizada e lancar uma nova Ordem de Produção.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/30616705587863)CAUSA:**

Ocorre ao tentar apontar ou alterar uma atividade já finalizada.
