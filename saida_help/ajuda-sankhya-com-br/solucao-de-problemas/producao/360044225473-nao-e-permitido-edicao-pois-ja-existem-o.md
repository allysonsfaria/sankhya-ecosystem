# Não é permitido edição, pois já existem Ordens de Produção lançadas para este Produto (PA)

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16363597066775) MENSAGEM:**

[PROD\_E00265] Não é permitido edição, pois já existem Ordens de Produção lançadas para este Produto (PA). Crie uma nova versão para realizar edição.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16363597072279) SOLUÇÃO:**

![Imagem 3: Não será possível realizar edição em processos produtivos, quando já existirem ordens de produção em andamento para o…](https://ajuda.sankhya.com.br/hc/article_attachments/16363597076631) Não será possível realizar edição em processos produtivos, quando já existirem ordens de produção em andamento para o processo. Dessa forma, aconselha-se a utilização do botão **"Versionar":**

- Tela **"Processo Produtivo"** (Caminho de acesso: Produção » Cadastros » Processo Produtivo)
- Botão Versionar:

![Não](https://ajuda.sankhya.com.br/hc/article_attachments/15817932646423)

Existem determinados momentos nas indústrias em que modificações simples no Processo Produtivo precisam ser realizadas, como por exemplo, a existência de novas atividades de produção, novas operações de estoque, novas listas de materiais etc. Porém, como já existem Ordens de Produção em andamento para o processo, essas alterações devem surtir efeito apenas para as ordens criadas posteriormente às alterações.

Esta é a função do botão Versionar; ele irá criar uma nova versão para o processo produtivo selecionado, de modo que as 'Ordens de Produção' que se encontram em andamento terão suas características e configurações mantidas e a nova versão estará apta a receber as modificações necessárias.

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16363597082903)CAUSA:**

Não é permitido realizar edição em processos produtivos, quando já existirem ordens de produção em andamento para o processo. Se esse procedimento for realizado, a mensagem será apresentada.
