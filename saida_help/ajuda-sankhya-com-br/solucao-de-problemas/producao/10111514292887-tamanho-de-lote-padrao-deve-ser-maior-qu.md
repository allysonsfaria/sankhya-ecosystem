# Tamanho de Lote Padrão deve ser maior que zero para o PRODUTO

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19260267171735) MENSAGEM:**

[PROD\_E00516] Tamanho de Lote Padrão deve ser maior que zero para o PRODUTO.

[PROD\_E00517]

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19260295625751) SITUAÇÃO:**

Ao tentar salvar o tamanho do lote como 0 na tela de "Composição do produto" a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19260267184919) CAUSA:**

Ocorre quando é informado o tamanho de lote 0, na tela Composição do Produto.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19260267192983) SOLUÇÃO:**

Acesse a tela '**Composição do Produto'** (Caminho de acesso à tela: Produção » Cadastros » Composição do Produto), vá até o campo "Tamanho de lote padrão" e o preencha com uma quantidade diferente de zero.
