# Erro ao buscar processamento do lote: Não foi selecionado MDF-e(s) com status de Aguardando Autorização

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19030036404247) MENSAGEM:**

[CORE\_E03550] Erro ao buscar processamento do lote: Não foi selecionado MDF-e(s) com status de Aguardando Autorização.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19030036412055) SITUAÇÃO:**

Ao gerar lote do MDF-e a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19030036416279) CAUSA:**

Ocorre quando o documento selecionado está com o Status diferente de "Aguardando Autorização".

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19030036421527) SOLUÇÃO:**

Primeiro, consulte a chave do MDF-e, observe se a mesma existe na base de dados da SEFAZ, caso exista busque autorização no sistema.

Se ainda não aprovar deverá entrar em contato com o suporte para análise.
