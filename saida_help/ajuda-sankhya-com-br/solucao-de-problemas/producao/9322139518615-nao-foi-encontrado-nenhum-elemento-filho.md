# Não foi encontrado nenhum elemento filho para a Raia 'XXX

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19277324391063) MENSAGEM:**

[PROD\_E00204]  Não foi encontrado nenhum elemento filho para a Raia 'XXX.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277319328791) SITUAÇÃO:**

Ao tentar validar o processo produtivo a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19277319330199) CAUSA:**

Quando não possui atividade cadastrada na raia.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277324402199) SOLUÇÃO:**

Verifique se na tela **"Processo Produtivo Nova"** (Caminho de acesso: Produção » Cadastros » Processo Produtivo - Nova) existe atividade configurada com raia. Se não tiver, arraste a atividade para a raia e configure o processo.
