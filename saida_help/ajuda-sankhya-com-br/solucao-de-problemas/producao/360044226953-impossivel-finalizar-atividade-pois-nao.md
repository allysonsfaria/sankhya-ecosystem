# Impossível finalizar atividade, pois não existe apontamento para o(s)subproduto(s): [999-XXXXXXXXXX]

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/17290216946199) MENSAGEM:**

[PROD\_E00287]: Impossível finalizar atividade, pois não existe apontamento para o(s)subproduto(s): [999-XXXXXXXXXX]

[PROD\_E00176]: Impossível finalizar atividade, pois não existe apontamento para o(s)subproduto(s): [999-XXXXXXXXXX]

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17290216952087) SOLUÇÃO:**

Para correção, siga o passo abaixo:

![Imagem 3: Acesse a rotina "Processo Produtivo" ( Caminho de acesso: Produção » Cadastros)](https://ajuda.sankhya.com.br/hc/article_attachments/17290256428439) Acesse a rotina **"Processo Produtivo"** (Caminho de acesso: Produção » Cadastros)

Botão: **"Roteiro"**
Aba: **"Produtos (PA)"**;
Sub-Aba: **"Lista de Subprodutos"**

- Opção **"Exige Apontamento"**: marcado. A marcação desse campo determina a obrigatoriedade do apontamento para essa matéria-prima.

Considere avaliar se o sub-produto participará do apontamento, então, aponte o. Caso contrário, desmarque e salve a atividade para efetuar um novo lançamento de produção.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/17290256435607) CAUSA:**

Ocorre quando não há apontamento do sub-produto e o processo produtivo está com a opção Exige apontamento marcada, nas configurações da atividade, sub-aba Lista de Subprodutos.
