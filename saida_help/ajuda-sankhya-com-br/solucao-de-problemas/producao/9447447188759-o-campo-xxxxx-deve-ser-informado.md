# O campo 'XXXXX' deve ser informado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/15816200705431) MENSAGEM:**

[CORE\_E03237] O campo 'xxxxxx' deve ser informado.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15816200706711) CAUSA:**

Ocorre quando o ultimo custo da MP está zerado, com isso não é possível calcular o custo do PA.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15816200707735) SOLUÇÃO:**

Acesse a tela **Atualização de custos** (Caminho de acesso: Comercial » Rotinas » Atualização de Custos ) e verifique se a MP está com o último custo zerado. Caso esteja, corrija para que seja calculado o custo do PA.
