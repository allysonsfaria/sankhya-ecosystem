# Valor Limite deve ser maior que zero

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16311240771095) MENSAGEM:**

[CORE\_E04460] Valor Limite deve ser maior que zero.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16311240774039) SOLUÇÃO:**

Para o respectivo usuário, na tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios)"** (Caminho de acesso: Configurações » Controle de Acesso), botão **"Outras Opções"** » **"Limites para liberação"**, verifique se para algum evento foi inserido um **"Valor limite"** igual ou menor que zero. Em caso positivo, realize os devidos ajustes, visto que o valor limite deverá ser maior que zero.
