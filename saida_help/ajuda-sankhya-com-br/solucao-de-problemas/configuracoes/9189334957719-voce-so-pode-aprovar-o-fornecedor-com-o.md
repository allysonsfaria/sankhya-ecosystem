# Você só pode aprovar o fornecedor com o melhor resultado, caso os fornecedores  ainda não possuam resultado calculado, clique na opção 'Calcular melhor fornecedor' no botão de outras opções

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18666994160535) MENSAGEM:**

[COTC\_E00003]:  Você só pode aprovar o fornecedor com o melhor resultado, caso os fornecedores ainda não possuam resultado calculado, clique na opção 'Calcular melhor fornecedor' no botão de outras opções.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18666970124055) SITUAÇÃO:**

Ao tentar aprovar uma cotação a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18666970129175) CAUSA:**

Tentar aprovar cotação que não foi sugerida como a melhor. Porém, no cadastro do usuário a configuração está definida para que seja a com melhor resultado.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18666994178839) SOLUÇÃO:**

Valide a configuração no Cadastro de **usuários** (Configurações » Controle de Acesso » Usuários) no campo **"Aprovar cotação"** configura-se a permissão ao usuário para aprovar cotações. Temos como tipos de permissões o **"Melhor Resultado"**, **"Não Aprova"** e **"Qualquer Resultado"** selecione a que se adequa e tente novamente.
