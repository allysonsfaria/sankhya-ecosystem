# Você não possui acesso para alterar o 'Cód. Usuário B2B'

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16583179798167) MENSAGEM:**

[CORE\_E05253] Você não possui acesso para alterar o 'Cód. Usuário B2B'.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16583179802519) CAUSA:**

Ocorre quando o usuário não tem acesso a alterar o usuário B2B.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16583179801111) SOLUÇÃO:**

Na tela **"Acessos**", procure pela tela de **"Parceiros"** e ative o acesso ao **"Manutenção usuário B2B".**

![Imagem 4: Na tela "Acessos ", procure pela tela de "Parceiros" e ative o acesso ao "Manutenção usuário B2B".](https://ajuda.sankhya.com.br/hc/article_attachments/15360858381591)
