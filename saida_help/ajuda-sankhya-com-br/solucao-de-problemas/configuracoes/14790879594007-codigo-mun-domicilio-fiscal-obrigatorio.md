#  Código Mun. Domicílio Fiscal obrigatório, ver tabela do IBGE

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16645153006999) MENSAGEM:**

[CORE\_E04854]: Código Mun. Domicílio Fiscal obrigatório, ver tabela do IBGE.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16645196163607) CAUSA:**

Ocorre sempre que não informar o campo Mun. domicílio fiscal no cadastro da cidade.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16645196161431) SOLUÇÃO:**

O campo**"Mun. domicílio fiscal"** será utilizado para informar o código do Município Domicílio Fiscal da cidade conforme item 3.2.1 do ATO COTEPE/ICMS Nº 9, de 18 de ABRIL de 2008. O sistema efetuará uma validação do código informado e o registro só será salvo se o código estiver de acordo com a tabela de municípios do IBGE.

Informe no campo citado anteriormente o "**Mun. domicílio fiscal**" conforme tabela do IBGE, disponível no link:

[http://www.ibge.gov.br/home/geociencias/areaterritorial/area.shtm.](http://www.ibge.gov.br/home/geociencias/areaterritorial/area.shtm)
