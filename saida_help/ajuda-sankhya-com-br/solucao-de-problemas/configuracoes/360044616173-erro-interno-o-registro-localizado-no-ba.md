# Erro interno: O registro localizado no banco não contém informações de layout 

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16806847447575) MENSAGEM:**

[COM\_E00545]: Erro interno: O registro localizado no banco não contém informações de layout.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16806879192727) SOLUÇÃO:**

Na maioria dos casos, a mensagem é retornada quando o layout utilizado no respectivo lançamento foi corrompido. Dessa forma, será necessário seguir os passos abaixo para criação de um novo layout:

![Imagem 3: Acesse a tela "Configurador de Layout da Nota" (Caminho de acesso: Comercial » Configuração) .](https://ajuda.sankhya.com.br/hc/article_attachments/16806879194903) Acesse a tela **"Configurador de Layout da Nota"** (Caminho de acesso: Comercial » Configuração).

![Imagem 4: Localize o layout utilizado atualmente para o respectivo lançamento.](https://ajuda.sankhya.com.br/hc/article_attachments/16806847457047) Localize o layout utilizado atualmente para o respectivo lançamento.

![Imagem 5: Verifique e/ou tire um 'print screen' das informações contidas no botão "Visualizar TOPs" .](https://ajuda.sankhya.com.br/hc/article_attachments/16806847461143) Verifique e/ou tire um 'print screen' das informações contidas no botão**"Visualizar TOPs"**.

![Imagem 6: Verifique e/ou tire um 'print screen' da marcação "Usar como padrão para este tipo de movimento?".](https://ajuda.sankhya.com.br/hc/article_attachments/16806847462807) Verifique e/ou tire um 'print screen' da marcação **"Usar como padrão para este tipo de movimento?".**

Com os dados acima,**duplique o layout atual**, criando um novo layout.

![Imagem 7: Desmarque a opção Usar como padrão para este tipo de movimento? (caso ela esteja marcado) e faça essa marcação no novo…](https://ajuda.sankhya.com.br/hc/article_attachments/16806879201943) Desmarque a opção Usar como padrão para este tipo de movimento? (caso ela esteja marcado) e faça essa marcação no novo layout criado.

![Imagem 8: Desvincule as TOP'S selecionadas no layout antigo e vincule as mesmas no novo layout (Botão "Visualizar TOPs" ).](https://ajuda.sankhya.com.br/hc/article_attachments/16806879203607) Desvincule as TOP'S selecionadas no layout antigo e vincule as mesmas no novo layout (Botão **"Visualizar TOPs"**).

![Imagem 9: Finalizadas as configurações acima, o layout "corrompido" poderá ser excluído e um novo lançamento poderá ser realizado…](https://ajuda.sankhya.com.br/hc/article_attachments/16806879205655) Finalizadas as configurações acima, o layout **"corrompido"** poderá ser excluído e um novo lançamento poderá ser realizado utilizando o novo layout.
