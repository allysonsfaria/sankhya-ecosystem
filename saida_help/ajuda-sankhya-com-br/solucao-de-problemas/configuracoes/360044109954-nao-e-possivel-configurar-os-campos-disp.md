# Não é possível configurar os campos disponíveis e significativos na tela Configuração da Estrutura de Metas/Orçamentos

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16310890549015) MENSAGEM:**

Não é possível configurar os campos disponíveis e significativos na tela Configuração da Estrutura de Metas/Orçamentos.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16310890556055) SOLUÇÃO:**

Para correção siga os passos abaixo:

![Imagem 3: Acesse a tela " Preferências " ( Caminho para acesso: Configurações » Avançado » Preferências ):](https://ajuda.sankhya.com.br/hc/article_attachments/16310832460951) Acesse a tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias)"** (Caminho para acesso: Configurações » Avançado » Preferências):

**(2)** Parâmetro: **"CONFIGFORMHTML5"** = Por usuário

![Imagem 4: Acesse a tela " Configuração da Estrutura de Metas/Orçamentos " (Caminho para acesso: Metas e Orçamentos » Configuração…](https://ajuda.sankhya.com.br/hc/article_attachments/16310893687447) Acesse a tela **"[Configuração da Estrutura de Metas/Orçamentos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044609794-Configura%C3%A7%C3%A3o-da-Estrutura-de-Metas-Or%C3%A7amentos)"** (Caminho para acesso: Metas e Orçamentos » Configuração da Estrutura de Metas/Orçamentos):

**(2)** Selecione o botão de Configuração da Tela » Layout do Formulário

**(2)** Escolha  a primeira opção de Configuração de Colunas e salve as alterações.

[GIF animado: Imagem 5: (2) Escolha a primeira opção de Configuração de Colunas e salve as alterações.](https://ajuda.sankhya.com.br/hc/article_attachments/14398695284887)

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16310849018391) CAUSA:**

Ocorre quando a configuração de colunas, está com a opção do tipo **"Coluna Única Normal"**, causando alteração na estrutura do layout das telas.
