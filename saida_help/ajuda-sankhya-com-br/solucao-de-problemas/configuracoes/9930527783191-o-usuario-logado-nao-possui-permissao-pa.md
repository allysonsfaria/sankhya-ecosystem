# O usuário logado não possui permissão para exportar o XML

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19357770216727) MENSAGEM:**

[ECOM\_E00001] O usuário logado não possui permissão para exportar o XML.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357710880663) SITUAÇÃO:**

Ao tentar exportar arquivos a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19357710885783) CAUSA:**

Ocorre quando o usuário não possui permissão para exportar relatórios.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357770232727) SOLUÇÃO:**

Acesse o cadastro de usuários (Caminho de acesso à tela: Configurações » Controle de Acesso » Usuários), vá até a aba segurança e marque o campo "Permite exportar relatórios?"
