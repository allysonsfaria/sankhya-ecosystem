# O usuário logado não possui permissão para confirmar um documento " " 

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16590062022423) MENSAGEM:**

[CORE\_E01229]: O usuário logado não possui permissão para confirmar um documento " ".

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16590075538455) SOLUÇÃO:**

Acesse a tela **"Acessos"** (Caminho de acesso: Configurações » Controle de Acesso » Acessos) e marque as permissões que o determinado usuário deverá ter:

![Imagem 3: Acesse a tela " Acessos" (Caminho de acesso: Configurações » Controle de Acesso » Acessos) e marque as permissões que o…](https://ajuda.sankhya.com.br/hc/article_attachments/15272578507159)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16590075540375) CAUSA:**

Ocorre quando o usuário não tem permissão concedida corretamente.
