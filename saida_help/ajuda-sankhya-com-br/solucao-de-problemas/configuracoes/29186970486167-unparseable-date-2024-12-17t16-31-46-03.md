# Unparseable date: "2024-12-17T16:31:46-03:00"

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/29186970461847) **MENSAGEM:**

Unparseable date: "2024-12-17T16:31:46-03:00".

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/29186970468375)SOLUÇÃO:**

Analisando o XML é possível ver que existem espaços no início e no fim da tag <dHEmi> como mostrado no exemplo abaixo

![Imagem 3: Analisando o XML é possível ver que existem espaços no início e no fim da tag <dHEmi> como mostrado no exemplo abaixo](https://ajuda.sankhya.com.br/hc/article_attachments/29556303507095)

Para a correção abra o arquivo XML com o notepad++ ou bloco de notas e faça o ajuste na tag e realize o reprocessamento do XML.

**OBSERVAÇÃO:** O string `"2024-12-17T16:31:46-03:00"` segue o formato ISO 8601, que é um padrão para datas e horas. Algumas bibliotecas ou funções podem não reconhecer o formato completo (especialmente o offset `-03:00` do fuso horário).

- **Solução**: Certifique-se de que a biblioteca suporta o formato ISO 8601 ou ajuste o formato da string para o esperado.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/29186970475031)CAUSA:**

Ocorre quando uma data ou hora fornecida como string não pode ser analisada (parseada) pelo código, geralmente devido a um formato incompatível. Esse problema é comum em linguagens como Java, Python ou outras que utilizam bibliotecas para lidar com datas.
