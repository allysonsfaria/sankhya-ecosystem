# Valores de opções ambíguos detectados. Não foi possível importar o campo.

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18796446143767) MENSAGEM:**

[CORE\_E03116] Valores de opções ambíguos detectados. Não foi possível importar o campo.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18796434927767) SITUAÇÃO:**

Ao criar um campo adicional do tipo lista a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18796446160279)SOLUÇÃO:**

![Imagem 4: Ao criar um campo do tipo lista - na tela ' Dicionário de Dados' (Caminho de acesso à tela: Configurações » Avançado »…](https://ajuda.sankhya.com.br/hc/article_attachments/18796446167319) Ao criar um campo do tipo lista - na tela '**Dicionário de Dados'**(Caminho de acesso à tela: Configurações » Avançado » Dicionário de Dados), em sua devida tabela - e informar no campo 'Opções' valores repetidos, a mensagem será apresentada.

![Imagem 5: Assim, verifique as listas, se elas possuírem informações repetidas no campo 'Opções', substitua em cada local o nome…](https://ajuda.sankhya.com.br/hc/article_attachments/18796446175383) Assim, verifique as listas, se elas possuírem informações repetidas no campo 'Opções', substitua em cada local o nome para que não haja repetições.

![Imagem 6: Assim, verifique as listas, se elas possuírem informações repetidas no campo 'Opções', substitua em cada local o nome…](https://ajuda.sankhya.com.br/hc/article_attachments/11911225292183)

![Imagem 7: Assim, verifique as listas, se elas possuírem informações repetidas no campo 'Opções', substitua em cada local o nome…](https://ajuda.sankhya.com.br/hc/article_attachments/11911056083351)

**![Imagem 8: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18796446179863)CAUSA:**

Ocorre ao informar valores repetidos em campo adicional do tipo lista.
