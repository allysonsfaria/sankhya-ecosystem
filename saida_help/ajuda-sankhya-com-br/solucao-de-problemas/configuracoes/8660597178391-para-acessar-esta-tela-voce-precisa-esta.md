# Para acessar esta tela você precisa estar vinculado ao Sankhya ID, o usuário SUP não pode ser vinculado a nenhum Sankhya ID

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16596969537559) SOLUÇÃO:**

Acesse o sistema com um **usuário que difere do usuário SUP,** vinculado a um SankhyaID.

**Detalhes:**

Considerando os parâmetros (Configurações » Avançado » Preferências) abaixo:

- **"Habilitar Sankhya ID?-** **HABILITAACCOUNT":** ligado
- **"Exige Sankhya ID e seleção de empresa para criar personalizações?- EXIGESKIDPNZ":** ligado

**Tem-se o seguinte comportamento :**

![Imagem 2: Se não estiver logado previamente no Sankhya Om com um usuário que não tenha vínculo com o Sankhya ID , ao acessar a…](https://ajuda.sankhya.com.br/hc/article_attachments/16596969538839) Se não estiver logado previamente no Sankhya Om com um usuário que não tenha vínculo com o Sankhya ID, ao acessar a tela será solicitado que você realize o login com o Sankhya ID.

![Imagem 3: Caso o Sankhya ID logado possua vínculo com mais de um parceiro, será exibido o pop-up solicitando a seleção do…](https://ajuda.sankhya.com.br/hc/article_attachments/16596969541655) Caso o Sankhya ID logado possua vínculo com mais de um parceiro, será exibido o pop-up solicitando a seleção do parceiro responsável pela personalização.

Observe abaixo um exemplo desta situação na tela [**"Empacotador"**](https://ajuda.sankhya.com.br/hc/pt-br/articles/1500007352061-Publica%C3%A7%C3%A3o-dos-seus-pacotes-):

[GIF animado: Imagem 4: Observe abaixo um exemplo desta situação na tela "Empacotador" :](https://ajuda.sankhya.com.br/hc/article_attachments/16596974141463)

Realizada a conexão com o Sankhya ID, ao acessar novamente a tela Empacotador, selecione o parceiro responsável pela personalização:

[GIF animado: Imagem 5: Realizada a conexão com o Sankhya ID, ao acessar novamente a tela Empacotador , selecione o parceiro responsável pela…](https://ajuda.sankhya.com.br/hc/article_attachments/16596969546391)

Com o parceiro selecionado, clique em **"Conectar"**, assim, será aberta a tela.

**Observação:** Caso algum dos parâmetros esteja inativo, o login com o Sankhya ID e a seleção de parceiro não serão exibidos ao acessar a tela.

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16596969549207) CAUSA:**

Caso você esteja logado com o usuário SUP não será possível acessar as telas, pois este usuário não é vinculado ao Sankhya ID.
