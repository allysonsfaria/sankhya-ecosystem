# Não é possível enviar a notificação com as solicitações de liberação pois o liberador 'X' não possui e-mail cadastrado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16609862840343) MENSAGEM:**

[CORE\_E03071]:  Não é possível enviar a notificação com as solicitações de liberação pois o liberador ' 'não possui e-mail cadastrado. Verifique se está cadastrado na tela de Destinatários e preencha o campo "e-mail".

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16609862844055) SOLUÇÃO:**

![Imagem 3: Na tela "Usuários" selecione o usuário que foi definido como liberador do evento solicitado.](https://ajuda.sankhya.com.br/hc/article_attachments/16609910024727) Na tela **"Usuários"** selecione o usuário que foi definido como liberador do evento solicitado.

![Imagem 4: Na aba "Identificação" preencha o campo "Email p/ solicitação liberação" com os dados de e-mail do usuário:](https://ajuda.sankhya.com.br/hc/article_attachments/16609910025495) Na aba **"Identificação"** preencha o campo **"Email p/ solicitação liberação"** com os dados de e-mail do usuário:

![Imagem 5: Na aba "Identificação" preencha o campo "Email p/ solicitação liberação" com os dados de e-mail do usuário:](https://ajuda.sankhya.com.br/hc/article_attachments/15021407398935)

![Imagem 6: Realizado esse cadastro de e-mail, teste o envio de solicitação de liberação de limites novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/16609862849943) Realizado esse cadastro de e-mail, teste o envio de solicitação de liberação de limites novamente.

**![Imagem 7: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/16609910027543) IMPORTANTE:**

Caso não deseje trabalhar com o envio de solicitações por e-mail, desmarque a opção abaixo para os usuários liberadores.

- Tela 'Usuários' » Outras Opções » Limites para liberação » **Enviar e-mail**

![Imagem 8: Tela 'Usuários' » Outras Opções » Limites para liberação » Enviar e-mail](https://ajuda.sankhya.com.br/hc/article_attachments/15021445412247)

**![Imagem 9: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16609910033687)CAUSA:**

Ao enviar solicitação para liberação de limites, caso não exista e-mail configurado para tal, será apresentada a mensagem.
