# Cód.Mot.Desoneração ICMS" só pode ser informado se o campo "Repassar para o cliente" for "Redução do imposto" ou "ICMS" 

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16416470807063) MENSAGEM:**

[CORE\_E02112] Cód.Mot.Desoneração ICMS" só pode ser informado se o campo "Repassar para o cliente" for "Redução do imposto" ou "ICMS".

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16416482758039) SOLUÇÃO:**

![Imagem 3: Se preenchido o campo "Cód.Mot.Desoneração ICMS" , na seção "Repassar para o cliente" deve-se marcar a opção " Redução…](https://ajuda.sankhya.com.br/hc/article_attachments/16416482762903) Se preenchido o campo **"Cód.Mot.Desoneração ICMS"**,  na seção "Repassar para o cliente" deve-se marcar a opção "**Redução do imposto**" ou a opção"**ICMS**":

- Tela **"Alíquotas de ICMS"** (Caminho de acesso: Comercial » Arquivo » Cadastros » Alíquotas)
  Aba **"Geral"** » Campo **'Repassar para o cliente'**
  Aba **"Geral"** » Campo **'Cód.Mot.Desoneração ICMS'**

![Imagem 4: Tela "Alíquotas de ICMS" (Caminho de acesso: Comercial » Arquivo » Cadastros » Alíquotas) Aba "Geral" » Campo 'Repassar…](https://ajuda.sankhya.com.br/hc/article_attachments/14684058239767)

![Imagem 5: Atente-se as configurações acima, conforme necessidade da respectiva alíquota de ICMS. Após ajustes salve o cadastro.](https://ajuda.sankhya.com.br/hc/article_attachments/16416482771095) Atente-se as configurações acima, conforme necessidade da respectiva alíquota de ICMS. Após ajustes salve o cadastro.

**![Imagem 6: OBSERVAÇÕES:](https://ajuda.sankhya.com.br/hc/article_attachments/16416470825111) OBSERVAÇÕES:**

Para mais detalhes sobre configurações relacionados a desoneração de ICMS veja o artigo: [Desoneração do ICMS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597834).

**![Imagem 7: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16416470830487) CAUSA:**

Caso na seção Repassar para o cliente esteja marcada a opção Redução da BASE e o campo Cód.Mot.Desoneração ICMS  esteja preenchido, o sistema deverá apresentar a mensagem.
