# Você possui registros de notas ou financeiros que infringem as regras e condições de uso do SankhyaOM e podem comprometer a integridade e segurança do EIP

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16473693806103) MENSAGEM:**

[CORE\_E07654]: Você possui registros de notas ou financeiros que infringem as regras e condições de uso do SankhyaOM e podem comprometer a integridade e segurança do EIP.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16473647544343) SOLUÇÃO:**

Para que as movimentações sejam normalizadas exclua os documentos sem origem reconhecida ou comunique o administrador da aplicação para que o padrão de governança seja seguido.

![Imagem 3: Comunique o Administrador/Implantador do SankhyaOm: Se você encontrar integrações ou registros fora dos padrões,…](https://ajuda.sankhya.com.br/hc/article_attachments/18791024855575) **Comunique o Administrador/Implantador do SankhyaOm:** Se você encontrar integrações ou registros fora dos padrões, informe o administrador ou a equipe responsável para que essas integrações sejam adequadamente ajustadas.

![Imagem 4: Utilize o Gateway API: Para garantir a integridade e segurança do SankhyaOm, siga o modelo de integração com o uso do…](https://ajuda.sankhya.com.br/hc/article_attachments/18791024864535) **Utilize o Gateway API:** Para garantir a integridade e segurança do SankhyaOm, siga o modelo de integração com o uso do Gateway API, disponível no artigo [API de Serviços Gateway](https://developer.sankhya.com.br/reference/api-de-integra%C3%A7%C3%B5es-sankhya). O Gateway API é o portão de acesso que gerencia as requisições recebidas e redireciona para os serviços correspondentes, facilitando a integração de serviços externos e garantindo a segurança no uso das APIs Sankhya.
