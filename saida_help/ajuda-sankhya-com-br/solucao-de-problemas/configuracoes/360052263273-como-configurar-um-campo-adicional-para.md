# Como configurar um campo adicional para que ele seja apresentado no cadastro de Funcionários

![Imagem 1: Acesse MGE Configuração (ou Jiva Conf) e selecione a opção Utilitários >> Manutenção de campos adicionais;](https://ajuda.sankhya.com.br/hc/article_attachments/18849881675543) Acesse MGE Configuração (ou Jiva Conf)  e selecione a opção Utilitários >> Manutenção de campos adicionais;

![Imagem 2: Busque a tabela TFPFUN (Tabela de Funcionários);](https://ajuda.sankhya.com.br/hc/article_attachments/18849853987351) Busque a tabela TFPFUN [Tabela de Funcionários];

![Imagem 3: Clique em adicionar (+);](https://ajuda.sankhya.com.br/hc/article_attachments/18849881683479) Clique em adicionar (+);

![Imagem 4: Informe o nome do campo, descrição, tipo e demais configurações de acordo com os critérios desejados para esse campo.](https://ajuda.sankhya.com.br/hc/article_attachments/18849881683991) Informe o nome do campo, descrição, tipo e demais configurações de acordo com os critérios desejados para esse campo.

**Exemplo:** Ao criar um campo CNS que receberá "números", o campo Tipo deverá ser configurado = Inteiro.

![Imagem 5: Exemplo: Ao criar um campo CNS que receberá "números", o campo Tipo deverá ser configurado = Inteiro.](https://ajuda.sankhya.com.br/hc/article_attachments/18849881688087)
