# Local de Destino não pode ser informado para o produto

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18603982781207) MENSAGEM:**

[CORE\_E00777]  Local de Destino não pode ser informado para o produto XXX.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603982787479) SITUAÇÃO:**

Ao tentar realizar uma transferência entre empresas a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18603950953879) CAUSA:**

Ocorre quando o local de origem/destino não está informado.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603982795159) SOLUÇÃO:**

Verifique a configurações da TOP > Impressão > Tipo de Numeração = ?.

Caso esteja somente como "Empresa" poderá apresentar a mensagem citada, sendo assim, poderá ajustar para Empresa/Série.

Verifique se no cadastro do produto possui local de origem/destino e se o campo 'Usa Local' está selecionado.
