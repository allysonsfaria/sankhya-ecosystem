# Os imposto do produto X não forma configurados

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/36911200102295) **MENSAGEM:**

Os imposto do produto X não foram configurados

![Imagem 2: Os imposto do produto X não foram configurados](https://ajuda.sankhya.com.br/hc/article_attachments/36911200102935)

**SITUAÇÃO:**

Ao acessar o **Sankhya Checkout**, pode ocorrer uma mensagem de erro informando que a **sincronização dos impostos não foi concluída**.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/36911216532247)SOLUÇÃO:**

**(1)** Acesse a tela [**''Administração de Checkout''**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360050978053-Administra%C3%A7%C3%A3o-de-Checkout) (Configurações » Sankhya Checkout » Administração de Checkout).

- O **Sankhya Checkout** depende das informações fiscais configuradas no [**''Sankhya W''**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596394-Sankhya-Web-Connection) para funcionar corretamente.

**(2)** Certifique-se de que a sincronização de impostos seja concluída para que os produtos carreguem as regras fiscais corretamente.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/36911216533655)CAUSA:**

Quando a sincronização dos impostos **não ocorre** ou é **interrompida**, o Checkout não consegue carregar as regras fiscais, resultando na mensagem exibida ao usuário.
