# Falha ao executar a procedure Stp_Set_Session2. Erro: O log de transações do banco de dados 'NOMEDOBANCO' está cheio devido a 'LOG_BACKUP'

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16784393017751) MENSAGEM:**

[CORE\_E01003]: Falha ao executar a procedure Stp\_Set\_Session2. Erro: O log de transações do banco de dados 'NOMEDOBANCO' está cheio devido a 'LOG\_BACKUP'.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16784365316375) SOLUÇÃO:**

 Considere o Comportamento da Aplicação conforme abaixo:

Acione imediatamente a Equipe de TI (DBA) da sua empresa ou terceiro que presta serviços de Banco de Dados. Caso não tenha, verifique um DBA da Unidade para que possa analisar o Servidor de Banco de Dados, a fim de liberar espaço no disco rígido.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16784393037975) CAUSA:**

Ocorre quando o Disco Rígido (HD), do servidor de Banco de Dados, está completamente cheio.
