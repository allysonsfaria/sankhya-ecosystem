# Critério inválido para um tipo numérico: %

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16968306028823) MENSAGEM:**

[CORE\_E01960]: Critério inválido para um tipo numérico: %.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16968306041239) CAUSA:**

Ocorre ao buscar o parceiro pelo nome, porém na tela de pesquisa a linha no Campo selecionou Cód. Parceiro.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16968327985687) SOLUÇÃO:**

![Imagem 4: Se a linha "Campo" da tela de pesquisa estiver definida como Cód. Parceiro, só permite realizar a busca pelo código do…](https://ajuda.sankhya.com.br/hc/article_attachments/16968306033559) Se a linha **"Campo"** da tela de pesquisa estiver definida como Cód. Parceiro, só  permite realizar a busca pelo código do parceiro. Caso queira pesquisar o nome do parceiro, escolha  a opção Nome Parceiro e digite o nome desejado, sendo uma forma nativa do sistema.

![Imagem 5: Se a linha "Campo" da tela de pesquisa estiver definida como Cód. Parceiro, só permite realizar a busca pelo código do…](https://ajuda.sankhya.com.br/hc/article_attachments/16968306037143) Uma outra opção seria usar a tela HTML5, pois nela tem a opção de pesquisar pelo nome do parceiro sem precisa fazer nenhuma alteração.
