# Código Suframa deve ter 9 caracteres numéricos xxxxx

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16588842625559) MENSAGEM:**

[CORE\_E04223]: Código Suframa deve ter 9 caracteres numéricos xxxxx.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16588827770903) CAUSA:**

Ocorre ao tentar informar letras no campo código SUFRAMA.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16588842628247) SOLUÇÃO:**

O Código Suframa (Superintendência da Zona Franca de Manaus) é composto por 9 caracteres numéricos.

Ele é utilizado para identificar empresas que operam na Zona Franca de Manaus, uma área de livre comércio localizada no estado do Amazonas, Brasil.

O formato do Código Suframa é geralmente XXXXXXXXX, onde cada "X" representa um dígito numérico de 0 a 9. Por exemplo, um código válido pode ser "123456789". É importante ressaltar que o Código Suframa é único para cada empresa registrada na Zona Franca de Manaus.
