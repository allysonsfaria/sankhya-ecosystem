# O usuário logado não possui permissão para exportar relatórios.

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19357806554263) MENSAGEM:**

O usuário logado não possui permissão para exportar relatórios.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357806570391) SITUAÇÃO:**

Usuário esta tentando exportar um relatório ou gerar xml de notas, porem apresenta a mensagem.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19357832123159) CAUSA:**

Ocorre quando o usuário não possui a permissão de exportar relatórios devidamente configurado.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357806583447) SOLUÇÃO:**

Para correção seguir os passos abaixo:

![Imagem 5: Configurações » Controle de Acesso » Usuários](https://ajuda.sankhya.com.br/hc/article_attachments/19357832134551) Configurações » Controle de Acesso » Usuários

- Aba: Segurança
- Campo: 'Permite exportar relatórios'

Selecione o usuário e marque a opção indicada acima.

![Imagem 6: Volte na rotina desejada e exporte o relatório novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/19357806603159) Volte na rotina desejada e exporte o relatório novamente.

**Observação:**

O erro pode ocorrer também ao gerar um arquivo de remessa, onde o arquivo é gerado em PDF, causando a mensagem: 'Adobe Acrobat Reader não pôde abrir 'nomedoarquivo.pdf' porque não há suporte a esse tipo de arquivo ou ele foi danificado'.
