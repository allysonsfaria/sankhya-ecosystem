# Ativação do ID e cadastro de contatos no Place

**![Imagem 1: Como ativar o seu Sankhya ID ?](https://ajuda.sankhya.com.br/hc/article_attachments/16337386055447) Como ativar o seu Sankhya ID ?**

O Sankhya ID nasceu com o propósito de aprimorar a experiência de uso das soluções no EIP Sankhya, unificando e centralizando as informações e acessos de cada pessoa e possibilitando uma jornada única de navegação a partir de um único login para todos os usuários que acessam alguma aplicação Sankhya. Para ativar o seu Sankhya ID, você possui dois caminhos:

**(1)** Ao receber uma permissão em alguma das aplicações Sankhya você receberá um convite no e-mail para que você preencha os dados pessoais e profissionais, ativando assim o seu ID.

![Imagem 2: (1) Ao receber uma permissão em alguma das aplicações Sankhya você receberá um convite no e-mail para que você preencha…](https://ajuda.sankhya.com.br/hc/article_attachments/1500020080061)

**(1)** Caso não encontre o convite acima em seu e-mail, tente logar no link: <https://login.sankhya.com.br/> para que a aplicação direcione você na ativação do seu Sankhya I

**![Imagem 3: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16337347444119) OBSERVAÇÃO:**

Caso você digite o e-mail no link: <https://login.sankhya.com.br/> e o ID informe a mensagem “Não foi possível localizar este ID”, isso significa que você ainda não recebeu permissões em nenhuma aplicação Sankhya.

Diante desta mensagem, procure o responsável pelas permissões de sua empresa (geralmente é o implantador Sankhya, TI) e solicite as devidas permissões que o seu cargo e setor permitem nas aplicações (Sankhya Om, Place, Universidade entre outros) para que você receba um convite de preenchimento dos seus dados no e-mail para a ativação do seu ID.

Lembre-se que o Sankhya ID é o registro de identificação de cada pessoa que atua nas soluções do ecossistema Sankhya. Portanto, o Sankhya ID é pessoal e intransferível de maneira que você é o dono do ID e a empresa para a qual você trabalha apenas libera permissões e acessos a partir do ID.

**DICA:** informe um e-mail pessoal para que você mantenha o seu ID, mesmo que venha a mudar de empresa no futuro.

**Vamos a prática:**

![Imagem 4: Vamos a prática:](https://ajuda.sankhya.com.br/hc/article_attachments/1500020081281)

**(1)** Acesse o seu e-mail corporativo, o qual foi utilizado para lhe conceder permissões em alguma das aplicações Sankhya;

**(1)** Abra o e-mail enviado a você, intitulado como “Complete seu cadastro no Sankhya ID” e clique em “Criar agora”;

**(1)** Preencha os dados pessoais e profissionais;

**(1)** Defina uma senha, informe um e-mail pessoal para manter o seu ID e clique em Concluir.

![Imagem 5: (1) Defina uma senha, informe um e-mail pessoal para manter o seu ID e clique em Concluir.](https://ajuda.sankhya.com.br/hc/article_attachments/1500020083641)

A partir daqui você já terá o seu Sankhya ID disponível. Viu como é fácil?

Lembre-se, ao fazer o login uma única vez com seu ID, você poderá navegar nas diversas aplicações por meio do botão colmeia e estas aplicações ficarão disponíveis de acordo com as permissões de cada usuário.

![Imagem 6: Lembre-se, ao fazer o login uma única vez com seu ID, você poderá navegar nas diversas aplicações por meio do botão…](https://ajuda.sankhya.com.br/hc/article_attachments/1500020084201)

**![Imagem 7: Como cadastrar e editar os usuários no Place?](https://ajuda.sankhya.com.br/hc/article_attachments/16337347445015) Como cadastrar e editar os usuários no Place?**

Se você for o usuário com a permissão de Administrador do Place, após ativar o seu Sankhya ID você conseguirá entrar no Sankhya Place e cadastrar os demais usuários de sua empresa, cada um com as suas devidas permissões.

Quanto às **edições dos contatos no Place** somente o ADM do Place de cada cliente tem permissão para realizá-las, elas se restringem a adição ou remoção de permissões e são feitas no menu de **"Dados cadastrais"**. Caso seja necessária a **edição dos dados pessoais do usuário**, como telefone, estas devem **ser feitas no Sankhya ID pelo próprio usuário.** Vale destacar que, **no Sankhya ID, os gestores conseguem alterar somente o e-mail** do usuário, os demais dados pessoais são alterados apenas pelo próprio usuário.

![Ativação](https://ajuda.sankhya.com.br/hc/article_attachments/15532792057239)

Cada permissão libera acesso a determinadas funcionalidades e processos relacionados a Sankhya.

![Imagem 9: Cada permissão libera acesso a determinadas funcionalidades e processos relacionados a Sankhya.](https://ajuda.sankhya.com.br/hc/article_attachments/1500020084521)

**![Imagem 10: Atente-se para alguns pontos importantes:](https://ajuda.sankhya.com.br/hc/article_attachments/16337386060695) Atente-se para alguns pontos importantes:**

**(1)** É imprescindível que haja pelo menos uma pessoa com a permissão “Financeiro” para que seja o contato responsável por receber notas, boletos e demais comunicações relacionadas ao contrato do cliente com a Sankhya.

**(1)** Também é necessário que sempre tenha um usuário com a permissão de “Administrador” para que este possa manter atualizadas as permissões da equipe, logo, caso o primeiro usuário do cliente saia, é necessário que um novo usuário tenha a permissão de “Administrador do place”. Se tiver dúvidas quanto a essa nova definição, procure seu Gerente de Projetos Sankhya.
