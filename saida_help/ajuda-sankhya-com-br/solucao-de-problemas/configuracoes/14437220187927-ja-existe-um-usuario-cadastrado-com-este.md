# Já existe um usuário cadastrado com este nome

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16859681106711) MENSAGEM:**

[CORE\_E03459]: Já existe um usuário cadastrado com este nome!

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16859697387799)SOLUÇÃO:**

Não é permitido cadastrar um usuário com mesmo nome mais de uma vez no sistema. Sempre que isso ocorrer a mensagem será apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16859681115927)CAUSA:**

Ocorre quando se tenta cadastrar um usuário utilizando um nome que já existe no cadastro.
