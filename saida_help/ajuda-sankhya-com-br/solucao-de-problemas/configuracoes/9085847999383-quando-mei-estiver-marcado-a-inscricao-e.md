# Quando MEI estiver marcado a inscrição estadual/identidade NÃO deve ser informada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19575841176983) MENSAGEM:**

[CORE\_E05369] Quando MEI estiver marcado a inscrição estadual/identidade NÃO deve ser informada.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19575850364823) SITUAÇÃO:**

Ao tentar cadastrar um parceiro que tenha as seguintes condições; MEI e tenha inscrição estadual.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19575850369047) CAUSA:**

Inserir IE no cadastro do parceiro definido como MEI.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19575841189143) SOLUÇÃO:**

Ao habilitar a marcação Micro empresário individual, o sistema só permitirá o preenchimento do campo Inscrição Estadual/Identidade se o parâmetro **"Permitir IE para MEI ? - PERIEPARAMEI"** estiver ligado. Do contrário, o sistema exibirá uma mensagem avisando que o referido campo não deve ser informado.
