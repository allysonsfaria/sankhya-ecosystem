# Informação de 'Contato de Entrega' obrigatória

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19112815467287) MENSAGEM:**

[CORE\_E01837] Informação de 'Contato de Entrega' obrigatória.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19112779836055) SITUAÇÃO:**

Ao tentar lançar uma NF-e a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19112779839639) CAUSA:**

Quando a marcação "**Exigir contato de entrega no cabeçalho**" está selecionado no cadastro do parceiro e o campo "contato de entrega" não está preenchido.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19112815477911) SOLUÇÃO:**

No cadastro do parceiro possui um campo que se chama "**Exigir Contato de Entrega no cabeçalho**", se esse campo estiver marcado, no lançamento de um pedido e/ou nota de venda, o sistema irá exibir no [Cabeçalho da Nota](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612414-Central-de-Vendas#gradecabealho) o campo **"Contato de Entrega"**. Este campo deverá ser preenchido com um contato previamente configurado na aba [Contatos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494-Cadastro-de-Parceiros#abacontatos).

![Imagem 5: No cadastro do parceiro possui um campo que se chama " Exigir Contato de Entrega no cabeçalho ", se esse campo estiver…](https://ajuda.sankhya.com.br/hc/article_attachments/19112815483671)

Caso esse campo não esteja visível, acesse o configurador de layout da nota através da tela **Configurador de Layout da Nota** (Caminho de acesso à tela: Comercial » Configuração » Configurador de Layout da Nota), selecione o layout para o tipo de movimento realizado e torne o campo visível, arrastando ele para o cabeçalho.
