# Veja como editar a Data de Validade na Aba Produtos

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16345168057239) SOLUÇÃO:**

Para editar Data de Validade na tela **"Produtos"**, realize o seguinte procedimento:

**(1)** Verifique no cadastro do **Usuário >> Segurança  >> Permite editar data de validade na aba estoque**

**(1)** Marque a opção **"Permite editar data de validade",** na aba **"Estoque".** Ao fazer essa marcação será possível alterar a data de validade do produto na aba Estoque da tela de cadastro de produtos.
