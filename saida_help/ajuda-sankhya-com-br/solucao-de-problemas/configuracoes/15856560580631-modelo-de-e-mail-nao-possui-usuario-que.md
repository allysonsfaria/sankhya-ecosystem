# Modelo de E-mail  não possui usuário que contenha e-mail para resposta

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/15856560564247) MENSAGEM:**

[CORE\_E04067] Modelo de E-mail " não possui usuário que contenha e-mail para resposta.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15856545171479) CAUSA:**

Ocorre ao não informar um usuário no campo 'Cód. Usuário Remetente' no modelo de E-mail.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15856514605847) SOLUÇÃO:**

Acesse a tela **Modelo de E-mail** (Configurações » Cadastros » Modelo de E-mail) aba geral, informe um usuário no campo 'Cód. Usuário Remetente'.
