# CORE_F00006: para fazer o download desta solução é necessário estar logado com o Sankhya ID

**MENSAGEM**

[CORE\_F00006] Para fazer o download desta solução é necessário estar logado com o Sankhya ID. Faça o login ou procure o seu gestor de TI para a criação do seu acesso.

**SITUAÇÃO**

Ao tentar instalar um pacote do **"Sankhya Place"** através do menu de pesquisa do **"Sankhya Om"**, a mensagem de erro é exibida e o download não é concluído.

**SOLUÇÃO**

**(1)**  Realize o login diretamente na tela **"Sankhya Place"** com seu **"Sankhya ID"** e faça o download da solução desejada.

**(2)**  Recomenda-se que o **"Sankhya ID"** seja vinculado ao seu usuário do **"Sankhya Om"**.

- Esse vínculo proporciona uma **melhor experiência de uso**, permitindo acessar o Place diretamente pelo Om sem necessidade de logins adicionais.

**(3)**  Caso não possua um **"Sankhya ID"**, solicite ao **gestor de TI** a criação do seu acesso.

**CAUSA**

O erro ocorre quando o usuário logado no **"Sankhya Om"** não possui um **"Sankhya ID"** vinculado ao seu cadastro. Como o Sankhya ID é **obrigatório para validação de identidade** e para o acesso ao conteúdo do **"Sankhya Place"**, a ausência desse vínculo impede o download direto.
