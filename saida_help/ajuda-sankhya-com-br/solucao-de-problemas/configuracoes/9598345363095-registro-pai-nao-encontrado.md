# Registro pai não encontrado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/15819247347863) MENSAGEM:**

[CORE\_E04997] Registro pai não encontrado.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15819264336407) CAUSA:**

Ocorre ao alterar máscara ou não marcar um novo registro filho como analítico.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15819247350295) SOLUÇÃO:**

Se foi criada uma máscara para **grupo de produtos** (Caminho de acesso à tela: Configurações » Cadastros » Produtos » Grupos de Produtos/Serviços) e ela foi alterada depois de já ter grupos cadastrados será necessário criar um grupo de produtos pai para conseguir fazer novos cadastros.

![Imagem 4: Se foi criada uma máscara para grupo de produtos (Caminho de acesso à tela: Configurações » Cadastros » Produtos »…](https://ajuda.sankhya.com.br/hc/article_attachments/9598338654615)

Ao criar um registro filho para um novo **projeto** (Caminho de acesso à tela: Configurações » Cadastros » Gerencial » Projetos) é necessário marcar o mesmo como analítico.

![Imagem 5: Ao criar um registro filho para um novo projeto (Caminho de acesso à tela: Configurações » Cadastros » Gerencial »…](https://ajuda.sankhya.com.br/hc/article_attachments/15819246068375)
