# Campos Vlr. Vendas e % Total Vendas ficam  zerados na Analise:  "Desempenho de Produtos" (Gerente on line)

![Imagem 2: Filtre o respectivo produto na tela 'Gerência de produtos' e analise na aba 'Extrato' se houve movimentações para esse…](https://ajuda.sankhya.com.br/hc/article_attachments/16343684652055) Filtre o respectivo produto na tela 'Gerência de produtos' e analise na  aba 'Extrato' se houve movimentações  para esse produto no período analisado;

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16343684659223) CAUSA:**

Se o campo Bonificação estiver marcado = 'S', o GOL desconsidera o **valor de venda** nas análises, porém,  considera os valores de **custo** dos produtos nas análises (RENTABILIDADE).

**![Imagem 6: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16343684661015) OBSERVAÇÃO:**

- Caso essa marcação seja indevida, será necessário ajustá-la, mas lembramos que essa marcação é histórica, desta forma, o ajuste só valerá para novos lançamentos.
- Caso seja necessário ajustar configurações anteriores, este **deverá ser realizado via banco por um profissional com conhecimento para tal**, de forma a evitar possíveis intervenções incorretas que possam afetar demais lançamentos.
