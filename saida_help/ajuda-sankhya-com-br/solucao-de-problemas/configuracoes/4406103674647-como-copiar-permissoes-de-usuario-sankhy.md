# Como copiar permissões de usuário Sankhya Om

Para realizar a copia de permissões, acesse a tela **"Usuários",** clique em **"**[**Outras Opções"**.](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#outrasop%C3%A7%C3%B5es) Depois, acesse  "**Cópia Permissões/Conf. de um usuário para outro(s)".**

![Imagem 1: Para realizar a copia de permissões, acesse a tela "Usuários", clique em " Outras Opções" . Depois, acesse " Cópia…](https://ajuda.sankhya.com.br/hc/article_attachments/15935088769175)

Inicialmente, acione a opção Cópia Permissões/Conf. de um usuário para outro(s) a partir do qual será aberto um pop-up para que você informe no campo **"Usuário Origem"**, o usuário que terá suas configurações e permissões copiadas para os demais integrantes.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16371050264087)SOLUÇÃO:**

Para o preenchimento do campo Usuário Origem, existem as seguintes possibilidades:

![Imagem 3: Ao clicar em um usuário e, em seguida, selecionar a opção Cópia Permissões/Conf. de um usuário para outro(s) o campo…](https://ajuda.sankhya.com.br/hc/article_attachments/16371004164119) Ao clicar em um usuário e, em seguida, selecionar a opção Cópia Permissões/Conf. de um usuário para outro(s) o campo Usuário Origem ficará preenchido com o usuário indicado inicialmente, porém, você poderá alterá-lo.

![Imagem 4: Ao abrir a tela e, em seguida, acionar a opção Cópia Permissões/Conf. de um usuário para outro(s ), ou seja, sem…](https://ajuda.sankhya.com.br/hc/article_attachments/16371004167575) Ao abrir a tela e, em seguida, acionar a opção Cópia Permissões/Conf. de um usuário para outro(s), ou seja, sem carregar os registros na tela e selecionar um deles, o campo Usuário Origem será apresentado vazio, para que você possa preenchê-lo manualmente.

Depois, no lado esquerdo desta tela, será apresentada uma lista com todos os usuários disponíveis e que poderão receber as configurações. Assim, selecione um ou mais usuários e clique em ![Imagem 5: Depois, no lado esquerdo desta tela, será apresentada uma lista com todos os usuários disponíveis e que poderão receber…](https://ajuda.sankhya.com.br/hc/article_attachments/15935088774167). Dessa forma, eles serão transferidos para a lista localizada ao lado direito, referente aos usuários indicados.

**Nota:** O sistema não permitirá que você selecione o seu próprio usuário para receber essas configurações.

Na próxima tela, informe o que deseja copiar deste usuário. É possível copiar somente **"Personalizações (telas, grades, filtros, etc.)"**, ou seja, qualquer tela que possibilite a cópia de Configurações, somente Acessos (permissões de acessos nas telas) ou Ambos (todos os acessos e configurações).

**![Imagem 6: IMPORTANTE: O sistema copiará apenas o filtro principal da tela, os que são informados nos painéis não serão copiados.…](https://ajuda.sankhya.com.br/hc/article_attachments/16371004169751) IMPORTANTE:** O sistema copiará apenas o filtro principal da tela, os que são informados nos painéis não serão copiados. De modo geral, as telas de Cadastros têm este filtro principal e, em alguns casos, telas de Movimentações como por exemplo, a [Movimentação Financeira](https://ajuda.sankhya.com.br/hc/pt-br/articles/360025240934-Movimenta%C3%A7%C3%A3o-Financeira).

**Nota:** O utilitário de cópia de configuração não é capaz de identificar todos os filtros de todas as telas, portanto, isto configura-se uma limitação técnica.

**![Imagem 7: OBSERVAÇÃO: Quando escolhida a opção Ambos , a caixa de marcação "Incluir configurações de segurança?" (aba Segurança )…](https://ajuda.sankhya.com.br/hc/article_attachments/16371004172439) OBSERVAÇÃO:** Quando escolhida a opção Ambos, a caixa de marcação **"Incluir configurações de segurança?"** (aba [Segurança](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#abasegurana)) ficará disponível. Esta marcação possibilita que as configurações pertinentes à aba Segurança também sejam incluídas.

Efetuando a marcação**"Incluir configurações da TOP?"**, o sistema habilita as opções **"Copiar Restrições da TOP"** e **"Copiar Exceções da TOP"**. Se o usuário informar que deseja incluir configurações da TOP não será possível avançar sem marcar ao menos uma das duas opções desta seção. Ao marcar estas opções o sistema verificará quais TOP's o usuário do cadastro possui como restrição e exceção e copiará estas informações para os usuários selecionados, conforme marcação, mantendo ou removendo configurações pré-existentes da TOP, de acordo com a necessidade do usuário.

**Nota:** Para restaurar as configurações, acesse a opção **"Restaurar configurações"**, disponível também neste botão. O processo de restauração deverá ser realizado pelo usuário SUP.

Será aberta uma tela com todas as configurações salvas. Para identificar se houve alteração em TOP, procure na coluna **"Configurações de TOP"** o valor Sim. Ao clicar em restaurar, a ação será finalizada.

**![Imagem 8: OBSERVAÇÃO: Não é possível copiar acessos do usuário SUP, sendo somente permitido a cópia das personalizações. Dentre…](https://ajuda.sankhya.com.br/hc/article_attachments/16371004172439) OBSERVAÇÃO:** Não é possível copiar acessos do usuário SUP, sendo somente permitido a cópia das personalizações. Dentre as referidas personalizações temos alguns exemplos de tela, grades, filtros, entre outras abrangidas pelo sistema.

Além destas opções, é possível manter ou remover configurações pré-existentes:

**Manter configurações Pré-existentes:** mantém as configurações dos usuários selecionados e copia as configurações do usuário atual.

**Remover configurações pré-existentes:** remove as configurações dos usuários selecionados e copia as configurações do usuário atual.

Ainda sobre as opções de cópia, temos a opção **"Ambos"** que, ao ser acionada, exibe a marcação **"Incluir configurações de segurança?"**. Esta marcação possibilita que as configurações pertinentes a aba [Segurança](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#abasegurana) sejam copiadas.

As personalizações da tela também poderão ser copiadas, para isso, acione a opção **"Selecionar telas individualmente"**. Deste modo, o próximo passo será escolher a tela pela qual se deseja copiar as personalizações.

Caso seja necessário restaurar as configurações anteriores do usuário, ou seja, retirar todas as cópias de acessos, personalizações e/ou configurações realizadas, o mesmo será possível porque ao final do procedimento de cópia, mas antes da efetiva cópia, é criado um backup com todas as configurações dos usuários e um histórico com as opções selecionadas.

**![Imagem 9: IMPORTANTE: As configurações do usuário destino somente serão mantidas se os usuários origem e destino tiverem…](https://ajuda.sankhya.com.br/hc/article_attachments/16371004169751) IMPORTANTE:** As configurações do usuário destino somente serão mantidas se os usuários origem e destino tiverem configurações diferentes, por exemplo: um tem configuração de tela e o outro, de filtro. Se os dois usuários tiverem filtro configurado, o usuário destino terá seus filtros substituídos pelos filtros do usuário origem e, assim, será para as demais opções de configurações.
