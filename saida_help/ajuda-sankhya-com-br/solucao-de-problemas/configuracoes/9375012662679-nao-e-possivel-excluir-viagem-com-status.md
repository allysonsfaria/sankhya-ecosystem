# Não é possível excluir viagem com Status Doc.: Confirmada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18603727232663) MENSAGEM:**

[CORE\_E02968]  Não é possível excluir viagem com Status Doc.: Confirmada.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603743233559) SITUAÇÃO:**

Ao tentar excluir a viagem a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18603716204439) CAUSA:**

Tentar excluir uma viagem já confirmada.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18603692063767) SOLUÇÃO:**

Não é possível excluir o cabeçalho de uma viagem confirmada pelo fato de ser gravações históricas.

É possível excluir o MDF-e e a Ordem de carga, quando necessário, porém, o cabeçalho da viagem continua no sistema.
