# Tamanho do CNPJ/CPF inválido para pessoa Jurídica

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16531451963415) MENSAGEM:**

[CORE\_E05367]: Tamanho do CNPJ/CPF inválido para pessoa Jurídica!

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16531451969047) SOLUÇÃO:**

Se o campo **"Tipo de pessoa"** for: **física**,  preencha o campo **"CNPJ/CPF"** com 11 dígitos (CPF) 
Se o campo Tipo de pessoa  for: **jurídica**, preencha o campo CNPJ/CPF  com 14 dígitos (CNPJ)

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16531438885911)CAUSA:**

Ocorre quando inserimos no campo CNJP/ CPF uma quantidade de dígitos  que não corresponde ao campo "Tipo de Pessoa".
