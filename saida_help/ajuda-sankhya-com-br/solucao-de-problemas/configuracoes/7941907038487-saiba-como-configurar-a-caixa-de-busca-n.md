# Saiba como configurar a Caixa de Busca na Tela Consulta de produtos

Configurações disponíveis para o campo **"Busca"** dentro da Consulta de Produtos:

Para que sejam apresentadas as opções de critérios de busca, na **"Configuração a caixa de busca",** da tela **"Consulta de Produto"**, segue as configurações no cadastro de Produto » Outras Opções » Consulta indexada por termos:

![Saiba](https://ajuda.sankhya.com.br/hc/article_attachments/15747870887575)

Marque a opção **"Utiliza na Consulta de Produtos"**.

![Saiba](https://ajuda.sankhya.com.br/hc/article_attachments/15747870890135)

Assim é apresentado as opções para configurar os critérios:

![Imagem 3: Assim é apresentado as opções para configurar os critérios:](https://ajuda.sankhya.com.br/attachments/token/EkbEShnFCIcfQ03fQOwfsFvBO/?name=image.png)

Se a opção Utiliza na Consulta de Produtos, no Cadastro de Produtos estiver marcada, não serão apresentadas as opções de critérios, conforme imagem abaixo:

![Imagem 4: Se a opção Utiliza na Consulta de Produtos, no Cadastro de Produtos estiver marcada, não serão apresentadas as opções…](https://ajuda.sankhya.com.br/attachments/token/nWVAXgCNOtOnSSXQTpeUonfeJ/?name=image.png)

O campo **"Tipo de Busca"**permite que você alterne o tipo da busca entre **"Contendo..."** e **"Começando com...",** de forma que a primeira opção faz com que a busca inclua resultados que contenham o texto digitado. Por exemplo, utilizando a primeira opção, a busca com o texto**"Azul"** retornaria resultados como:

- Pasta Azul;
- Caderno Azul;
- Azul Marinho.

Já a busca com a segunda opção denominada **"Começando com..."** mostrará apenas os resultados que comecem com o texto digitado, ou seja, ainda nesse exemplo, a busca do texto **"Azul"** só retornaria o resultado:

- Azul Marinho.

**![Imagem 5: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16361680191383) OBSERVAÇÃO:**

As opções **"Contendo..."** e **"Começando com..."** não são aplicáveis em buscas efetuadas em campos do tipo numérico, como por exemplo, o campo código.
