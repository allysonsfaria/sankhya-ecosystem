# Informação - O gateway para operações TEF não está ativo

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/23130143547543) **MENSAGEM:**

Informação - O gateway para operações TEF não está ativo.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/23130143555863)SOLUÇÃO:**

![Imagem 3: Verifique se o Web Connection embarcado ou externo esta iniciado:](https://ajuda.sankhya.com.br/hc/article_attachments/23156960571927) Verifique se o Web Connection embarcado ou externo esta iniciado:

No Navegador Sankhya, clique sobre o botão **"Configurações"** ![Imagem 4: No Navegador Sankhya, clique sobre o botão "Configurações" (ou comando Ctrl + F6), aba " Web Connection" , a opção…](https://ajuda.sankhya.com.br/hc/article_attachments/23130181766295) (ou comando Ctrl + F6), aba "**Web Connection"**, a opção **"Iniciar Web Connetion junto com o navegador"** deverá estar marcada.

[GIF animado: Imagem 5: No Navegador Sankhya, clique sobre o botão "Configurações" (ou comando Ctrl + F6), aba " Web Connection" , a opção…](https://ajuda.sankhya.com.br/hc/article_attachments/23130181768727)

**Observação:** em alguns caso após marcar a opção será necessário fechar e abrir novamente o navegador para que o Web Connection seja inicializado.

Caso seja utilizado o Web Connection externo, deverá ser verificado na opção **"Mostrar ícones ocultos"** da barra de tarefas se o mesmo está iniciado. Se não localizar o ícone, você poderá iniciá-lo através do atalho que normalmente se encontra na área de trabalho do computador.

![Imagem 6: Caso seja utilizado o Web Connection externo, deverá ser verificado na opção "Mostrar ícones ocultos" da barra de…](https://ajuda.sankhya.com.br/hc/article_attachments/27885948728599)

![Imagem 7: Na tela " Preferências" (Configurações » Avançado » Preferências) verifique se o parâmetro "TEFGATEWAY" está…](https://ajuda.sankhya.com.br/hc/article_attachments/23156991410071) Na tela **"Preferências"** (Configurações » Avançado » Preferências) verifique se o parâmetro **"TEFGATEWAY"** está configurado corretamente com o TEF utilizado.

![Imagem 8: Verifique se o programa do TEF está inicializado na máquina.](https://ajuda.sankhya.com.br/hc/article_attachments/23156960590231) Verifique se o programa do TEF está inicializado na máquina.

**Observação:** os programas de TEF variam de acordo com o sistema utilizado (Pay&Go, Sitef, Auttar). Caso não localize o software do TEF na máquina ou não consiga inicializá-lo, entre em contato com o suporte dos mesmos.
