# Notas não permite alterar campos de ICMS no item

![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17151444992407) **SITUAÇÃO:**

Notas não permite alterar campos de ICMS no item.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17124964825623)SOLUÇÃO:**

Na Nota Complemento é necessário verificar se as opções dos impostos também estão marcadas no Parceiro, Produto, TOP.
Pois caso em uma delas não esteja a opção do importo marcada, o sistema não faz a validação e não consegue digitá-lo.
Mesmo com Todas configurações realizadas conforme artigo [Melhores práticas para emissão de nota fiscal de complemento [Emissão Própria]](https://ajuda.sankhya.com.br/hc/pt-br/articles/360043190874-Melhores-pr%C3%A1ticas-para-emiss%C3%A3o-de-nota-fiscal-de-complemento-Emiss%C3%A3o-Pr%C3%B3pria-?source=search&auth_token=eyJhbGciOiJIUzI1NiJ9.eyJhY2NvdW50X2lkIjo5NjE4MTY4LCJ1c2VyX2lkIjoxMjY1NjI0Njc2MDU5OSwidGlja2V0X2lkIjozMDk2ODgsImNoYW5uZWxfaWQiOjYzLCJ0eXBlIjoiU0VBUkNIIiwiZXhwIjoxNjk1OTI1Mzg3fQ.RlXgXyV4GBzYDNOaQtS7jV-dY5CJkWoaUd95wRleGkU)a nota de Complemento não deixa alterar campos.

Acontece tanto para notas de complemento, quanto para notas de venda/compra.
Verifique se as opções dos impostos ''Tem ICMS'' também estão marcadas no Parceiro, Produto, TOP.
