# Não é possível marcar o campo 'Não Visualizar', pois a regra  possui 'Instância Secundária' informada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16532157913495) MENSAGEM:**

[CORE\_E04457]: Não é possível marcar o campo 'Não Visualizar', pois a regra possui 'Instância Secundária' informada.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16532145537175) SOLUÇÃO:**

Só é permitido marcar a opção quando a regra não tem instância secundária. Se a regra não tiver instância secundária, automaticamente o sistema marca a opção ao setar a regra no usuário.

![Imagem 3: Só é permitido marcar a opção quando a regra não tem instância secundária. Se a regra não tiver instância secundária,…](https://ajuda.sankhya.com.br/hc/article_attachments/15585869418519)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16532145538711) CAUSA:**

Ocorre ao informar uma REGRA que possui instância secundária e setar o campo **"Não visualizar"** no cadastro de **Usuários**, aba **Validações**.
