# Código Sit.Trib.IPI Saída deve ser informado

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16306503680407) **MENSAGEM:**

[CORE\_E05035] Código Sit. Trib. IPI Saída deve ser informado.

[CORE\_E05029] "Código Sit.Trib.IPI Entrada deve ser informado

[CORE\_E05030] "Código Sit.Trib.IPI Saída deve ser informado

![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16306548558103) **SITUAÇÃO:**

Ao tentar salvar alterações na tela Empresa deixando o campo **"Código Sit. Trib. IPI Saída"** sem informação a mensagem é apresentada.

![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16306548570647) **CAUSA:**

Ocorre quando o campo Código Sit. Trib. IPI Saída está vazio.

![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16306548566039) **SOLUÇÃO:**

Acesse a tela **"Empresa"** (Caminho de acesso: Comercial » Preferências » Empresa), vá até a aba Propriedades e preencha o campo Código Sit. Trib. IPI Saída.
