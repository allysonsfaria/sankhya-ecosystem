# Proibido alterar Título de Compensação Financeira

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/18587098883351) MENSAGEM**:

Proibido alterar Título de Compensação Financeira.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18587098893335) CAUSA:**

A mensagem é apresentada pois o 'Tipo de Título' original do lançamento, é o mesmo configurado em um dos parâmetros de compensação de crédito/débito.

![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18587098900247) **SOLUÇÃO:**

A mensagem é apresentada pois o 'Tipo de Título' original do lançamento, é o mesmo configurado em um dos parâmetros abaixo:

- TIPTITCREDCLI: Define o Tipo de título para compensação de Crédito;
- TIPTITDEBFOR: Define o Tipo de título para compensação de Débito;

É possível conferir os parâmetros citados, acessando a tela 'Preferências' (Configurações » Avançado » Preferências).

![Imagem 4: Caso o tipo de título vinculado aos parâmetros esteja incorreto , realize os devidos ajustes, informando o tipo de…](https://ajuda.sankhya.com.br/hc/article_attachments/18587084893335) Caso o **tipo de título vinculado aos parâmetros esteja incorreto**, realize os devidos ajustes, informando o tipo de título correto, e após isso será possível realizar a alteração desejada.

![Imagem 5: Caso o tipo de título a ser alterado, de fato deva ser utilizado como tipo de título para compensação(TIPTITCREDCLI ou…](https://ajuda.sankhya.com.br/hc/article_attachments/18587098912279) Caso o tipo de título a ser alterado, de fato deva ser utilizado como tipo de título para compensação[TIPTITCREDCLI ou TIPTITDEBFOR], compreenda que a alteração desejada no lançamento, é PROIBIDA.
