# Usuário expirou

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/17147519613079) MENSAGEM:**

Usuário expirou.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17147549054743) SOLUÇÃO:**

Nesse caso, acesse a tela **"Usuários",** com algum usuário que não tenha tal restrição (Ex : SUP), procure pelo usuário que está com o erro e acesse a aba **"Identificação"**, nela irá encontrar o campo **"Data limite de acesso"**, ajuste o campo com uma data posterior para liberar acesso ao sistema para o usuário em questão;

Também, poderá limpar o seu conteúdo para liberar acesso por tempo indeterminado ao sistema.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/17147549056919) CAUSA:**

Erro ocorre ao tentar realizar o login em uma data posterior a data definida no campo Data limite de acesso no cadastro do Usuário;
