# Projeto deve ser analítico

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19573031372695) MENSAGEM:**

[CORE\_E00847]  Projeto deve ser analítico!

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19573031377303) SITUAÇÃO:**

Ao informar um projeto a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19573031383831) CAUSA:**

Informar um projeto pai nos lançamentos.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19573031385751) SOLUÇÃO:**

Os projetos que deverão ser utilizados são os filhos, eles deverão estar com a marcação Analítico selecionada. Para isso, caso tenha alguma dúvida, acesse a tela de **Projetos** (Caminho de acesso à tela: Configurações » Cadastros » Gerencial » Projetos) e confira os cadastros.
