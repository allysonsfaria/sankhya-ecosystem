# Modelo de Documento 66 - Nota Fiscal de Energia Elétrica Eletrônica

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19258275757463) SOLUÇÃO:**

O modelo 66 foi criado no cadastro da TOP com finalidade de preencher adequadamente a EFD Contribuições (C500) para as empresas que escrituram ou tomam créditos de operações com energia elétrica modelo 66 (NF-e).

Para mais informações sobre a geração do C500, acesse: [O que é necessário para um documento ser apresentado no Registro C500 - EFD Contribuições ?](https://ajuda.sankhya.com.br/hc/pt-br/articles/360051122833)

**Importante:**

Notas com modelo 66 "Nota Fiscal de Energia Elétrica Eletrônica", não são exportadas para o arquivo Sintegra , visto que não está previsto no manual do SINTEGRA esse modelo de nota;
