# Seu ID está bloqueado

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/27803930367511) **MENSAGEM:**

Seu ID está bloqueado.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/27803930369559)SOLUÇÃO:**

Para reativar usuários ID que estão com status de bloqueados basta logar com o e-mail ou CPF desses usuários no link do [Sankhya ID](https://login.sankhya.com.br/), colocar qualquer informação no campo senha.

Ao clicar em "Prosseguir" o sistema vai identificar que esse ID está com bloqueio e disparar de forma automático um e-mail para esse remetente com o passo a passo para desbloquear o acesso.

Na tela vai apresentar a seguinte mensagem:

![Imagem 3: Na tela vai apresentar a seguinte mensagem:](https://ajuda.sankhya.com.br/hc/article_attachments/27803930371095)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/27803960708247)CAUSA:**

Ocorre quando estoura o máximo de tentativas de login e o acesso é bloqueado.
