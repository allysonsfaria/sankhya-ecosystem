# Preenchimento da Aba Deficiência - eSocial no cadastro do Funcionário no MGE

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19572077761175) SOLUÇÃO:**

Em **Arquivos/Cadastros/ Funcionários/ Aba Pessoais** informe no campo Deficiência qual o tipo de deficiência o funcionário possui, ou se são múltiplas.

![Imagem 2: Em Arquivos/Cadastros/ Funcionários/ Aba Pessoais informe no campo Deficiência qual o tipo de deficiência o funcionário…](https://ajuda.sankhya.com.br/hc/article_attachments/19572101612311)

Para atender ao eSocial para informação das múltiplas deficiências foi disponibilizada a aba **Deficiência - eSocial,** destinada ao cadastro de deficiências do funcionário.

![Imagem 3: Para atender ao eSocial para informação das múltiplas deficiências foi disponibilizada a aba Deficiência - eSocial,…](https://ajuda.sankhya.com.br/hc/article_attachments/19572077768599)

Este campo **"Preenche Cota Deficiente"** é para marcar caso o funcionário se enquadre na cota de Pessoas com Deficiência (PCD) da empresa. E logo abaixo estão os campos para informar o tipo de deficiência.

Ao acionar o botão **"Cadastrar deficiências do funcionário"**, você poderá cadastrar vários tipos de deficiências para o mesmo funcionário.

No campo **"Observação deficiência"**, descreva as possíveis limitações para os casos de múltiplas deficiências ou qualquer informação relevante sobre qualquer tipo de deficiência.
