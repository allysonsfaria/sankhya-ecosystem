# Veja como adicionar e remover organizações do usuário no Sankhya ID

Para adicionar e remover organizações do usuário no Sankhya ID, siga os passos abaixo:

![Imagem 1: Entre no menu lateral "Minhas permissões" do Sankhya ID (login.sankhya.com.br);](https://ajuda.sankhya.com.br/hc/article_attachments/16474406924823) Entre no menu lateral **"Minhas permissões"** do Sankhya ID (login.sankhya.com.br);

![Imagem 2: O usuário poderá visualizar todas as permissões que possui na organização e até mesmo retirá-la caso seja necessário.…](https://ajuda.sankhya.com.br/hc/article_attachments/16474386345751) O  usuário poderá visualizar todas as permissões que possui na organização e até mesmo retirá-la caso seja necessário. Para excluir, clique no botão desvincular permissões.

![Imagem 3: O usuário poderá visualizar todas as permissões que possui na organização e até mesmo retirá-la caso seja necessário.…](https://ajuda.sankhya.com.br/hc/article_attachments/16474485286167)

**Observação:** o vínculo de uma nova organização é realizado pelo administrador do **Place (place.sankhya.com.br) -> Informações cadastrais -> Dados cadastrais -> + Novo contato.** Ao incluir um novo contato o Place, irá integrar as informações da empresa ao cadastro do usuário no Sankhya ID e demais portais.

![Imagem 4: Observação: o vínculo de uma nova organização é realizado pelo administrador do Place (place.sankhya.com.br) ->…](https://ajuda.sankhya.com.br/hc/article_attachments/16474485287191)
