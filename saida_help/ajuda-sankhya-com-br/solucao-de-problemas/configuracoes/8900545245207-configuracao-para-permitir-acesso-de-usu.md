# Configuração para permitir acesso de usuários à Central de ajuda e para abertura de tickets

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16597510898071) MENSAGEM**:

Aviso! Usuário não possui acesso a aplicação e será redirecionado para o login do Sankhya ID.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16597510900119)SOLUÇÃO:**

A Gestão de acessos para a Central de Ajuda deverá ser realizada pelo **Administrador do Place** (toda empresa possui um usuário que é definido como Admin do Place);

![Imagem 3: Administrador do Place loga em:](https://ajuda.sankhya.com.br/hc/article_attachments/16597521130775) Administrador do Place loga em:

- Sankhya:<http://place.sankhya.com.br/>
- Jiva:[http://place.jiva.com.br/](http://place.sankhya.com.br/)

![Imagem 4: Uma vez logado, localiza o menu 'Informações Cadastrais' >> Dados Cadastrais;](https://ajuda.sankhya.com.br/hc/article_attachments/16597510903831) Uma vez logado, localiza o menu 'Informações Cadastrais' >> Dados Cadastrais;

![Imagem 5: Selecione o contato ao qual deseja conceder o acesso;](https://ajuda.sankhya.com.br/hc/article_attachments/16597521134615) Selecione o contato ao qual deseja conceder o acesso;

![Imagem 6: Através da opção editar marque a opção "Suporte" :](https://ajuda.sankhya.com.br/hc/article_attachments/16597510910871) Através da opção **editar** marque a opção **"Suporte"**:

![Imagem 7: Através da opção editar marque a opção "Suporte" :](https://ajuda.sankhya.com.br/hc/article_attachments/16597496495895)

![Imagem 8: Clique em "Salvar" ;](https://ajuda.sankhya.com.br/hc/article_attachments/16597521143063) Clique em **"Salvar"**;

Após este procedimento, o usuário/Contato da empresa estará liberado para acessar a central de ajuda e realizar abertura de tickets quando necessário.
