# O usuário ZERO não pode liberar ou negar limites

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18586909933207) MENSAGEM:**

[CORE\_E03927]  O usuário ZERO não pode liberar ou negar limites.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18586926436375) SITUAÇÃO:**

Ao tentar liberar ou negar uma liberação de limites informando usuário zero (SUP) a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18586909943703) CAUSA:**

Tentar fazer liberação de limites com usuário SUP.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18586909946263) SOLUÇÃO:**

O usuário zero (SUP) é o usuário master para configurações e tem acesso a tudo portanto, ele não pode ser usado para fazer nenhuma liberação de limites, sendo assim, é necessário logar no sistema com outro usuário.
