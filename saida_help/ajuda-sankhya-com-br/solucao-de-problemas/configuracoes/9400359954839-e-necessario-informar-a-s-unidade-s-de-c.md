# É necessário informar a(s) unidade(s) de carga na aba Unidades de Medida

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18614090328983) MENSAGEM:**

[CORE\_E04427]: É necessário informar a(s) unidade(s) de carga na aba Unidades de Medida.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18614090342167) SITUAÇÃO:**

Ao realizar o lançamento de um CT-e ou nota a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18614064824727) SOLUÇÃO:**

Caso esse campo não esteja visível para preenchimento verifique no **Configurador de Layout da Nota** (Comercial » Configuração » Configurador de Layout da Nota).

![Imagem 4: Caso esse campo não esteja visível para preenchimento verifique no Configurador de Layout da Nota (Comercial »…](https://ajuda.sankhya.com.br/hc/article_attachments/9400260284183)

![Imagem 5: Caso esse campo não esteja visível para preenchimento verifique no Configurador de Layout da Nota (Comercial »…](https://ajuda.sankhya.com.br/hc/article_attachments/9400322509591)

![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18790507242647) **CAUSA:**

Mensagem é apresentada quando a informação de Unidades de Medida não está preenchida no rodapé da nota.
