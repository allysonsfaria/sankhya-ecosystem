# Não foi possível criar o diretório. Acesso negado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19277343486999) MENSAGEM:**

[CORE\_E01754] Não foi possível criar o diretório. Acesso negado.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19277297983511) CAUSA:**

Ocorre quando o usuário tenta criar uma nova pasta no Repositório de Arquivos e por falta de acesso do usuário retorna a mensagem.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277343496471) SOLUÇÃO:**

Esse erro ocorre por conta do acesso ao servidor por usuário. Libere esse acesso para o usuário em questão. Solicite auxílio a sua equipe de TI responsável.
 
Sobre a opção 'Configurar Acessos da pasta', a mesma só estará disponível para subpastas da pasta 'Repositório', assim que for possível criar uma subpasta o ícone de cadeado será liberado para configuração.
