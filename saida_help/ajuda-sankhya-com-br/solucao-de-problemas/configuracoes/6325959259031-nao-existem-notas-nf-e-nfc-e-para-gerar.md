# Não existem notas NF-e/NFC-e para gerar o arquivo

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16449132825495) MENSAGEM:**

[ECOM\_E00076]  Não existem notas NF-e/NFC-e para gerar o arquivo.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16449140722839) SOLUÇÃO:**

![Imagem 3: Revise todos os filtros inseridos na tela:](https://ajuda.sankhya.com.br/hc/article_attachments/16449140729879) Revise todos os filtros inseridos na tela:

1.1 Tipo Arquivo
1.2 Empresa
1.3 Parceiro
1.4 Entra/Saída
1.5 Período
1.6 TOP

Certifique se **existem informações nos respectivos filtros que estão impedindo a geração do arquivo necessário**. Após ajustes, refaça a geração.

![Imagem 4: Certifique se existem informações nos respectivos filtros que estão impedindo a geração do arquivo necessário . Após…](https://ajuda.sankhya.com.br/hc/article_attachments/6326121244823)

**Importante:**

O filtro trará apenas "Notas Aprovadas" ou "Canceladas". Qualquer outro tipo de status de NF-e ou NFS-e não serão filtrados.

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16449140731671)CAUSA:**

Para downloads de filtros que não retornam arquivos apresenta-se uma mensagem ao usuário que não foi localizado o XML de notas para o filtro informado.
