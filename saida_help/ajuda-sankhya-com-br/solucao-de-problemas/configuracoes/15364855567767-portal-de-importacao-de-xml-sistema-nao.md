# Portal de Importação de XML - Sistema não esta preparado para importar CTe de Substituição como Emissão Própria

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16969145835799) MENSAGEM:**

[COM\_E00239]: Sistema não está preparado para importar CT-e de Substituição como Emissão Própria.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16969145837975) CAUSA:**

Quanto tenta processar/ importar um arquivo XML de CT-e de Substituição na tela de Portal de Importação de XML.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16969145837335) SOLUÇÃO:**

Essa mensagem é na verdade um aviso, pois de fato o sistema não está preparado para importar CT-e de Substituição. No entanto, para lançamento desse CT-e, o mesmo não será possível pela tela de **"Portal de Importação de XML"**, deverá ser lançado manualmente pela tela de **"Central de Compra"**.
