# Fora do horário de acesso previsto para esse usuário 

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16842968501783) MENSAGEM:**

[CORE\_E01433]: Fora do horário de acesso previsto para esse usuário.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16842968508183)CAUSA:**

Ocorre quando o usuário tentar acessar o sistema fora do horário definido no cadastro do mesmo.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16842915453079)SOLUÇÃO:**

Uma vez configurada e associada a Carga Horária ao usuário, a validação de tempo de uso do **Sankhya OM** será ativada. Dessa forma, caso o usuário solicite acesso ao sistema fora do horário definido, seu login não será validado e o sistema apresentara a mensagem: 'Fora do horário de acesso previsto para esse usuário'. Essa validação ocorre tanto para acesso com horário anterior ao início da CH, quanto para horários posteriores ao fim da mesma.

Para mais informações acesse o manual da rotina: [Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#abaacessoaosistema).
