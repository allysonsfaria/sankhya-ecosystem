# Não foi possível converter o arquivo para um jrxml válido

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16458020649367) MENSAGEM:**

 [CORE\_E02496] Não foi possível converter o arquivo para um jrxml válido

**![Imagem 2: SOLUÇÂO:](https://ajuda.sankhya.com.br/hc/article_attachments/16458032015511) SOLUÇÂO:**

Para a resolução do erro apresentado, existem dois cenários mapeados atualmente:

**1° Cenário**

**Erro:** O relatorio do Ireport não está sendo gerado pelo Sankhya;

A mensagem está sendo ocasionada por algum problema na estrutura do relatório. Nesse caso, revise o mesmo para entender onde está o ponto exato de inconsistência.

**Atenção:** Este tipo de avaliação não é feita no Service Desk, por se tratar da análise no próprio relatório

**2° Cenário**

**Erro:** Erro de layout ao tentar emitir NFS-e de VV, com jrxml disponibilizado pela Sankhya.

**Atenção:** Realize a atualização da versão do IReport

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16458032017431)CAUSA:**

O erro é causado por problemas na estruturação do relatório ou na versão do IReport em que o mesmo foi salvo.
