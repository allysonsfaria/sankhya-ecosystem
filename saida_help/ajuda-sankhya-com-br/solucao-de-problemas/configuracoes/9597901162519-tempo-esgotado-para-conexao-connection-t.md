# Tempo esgotado para conexão (Connection timed out)  Não é possível finalizar uma ordem de serviço Simples já finalizada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19358215174551) MENSAGEM:**

[CORE\_E03688] Tempo esgotado para conexão (Connection timed out) Não é possível finalizar uma ordem de serviço Simples já finalizada! Parâmetro nulo: XXXX
Linha do Script: XXX

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19358215183383) SITUAÇÃO:**

Ao encerrar OS ou executar a rotina de baixa a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19358194396823) CAUSA:**

Executar rotina customizada.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19358194405527) SOLUÇÃO:**

Mensagem é apresentada quando a rotina executada tem envolvimento com algum botão de ação customizado ou a própria rotina utilizada foi customizada. Nesse caso, acione o responsável pela personalização, pois o suporte não tem alçada para dar manutenção em criações.
