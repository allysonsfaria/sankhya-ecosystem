# Limite de data para reabertura de OS excedido

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16310381531671) MENSAGEM:**

Limite de data para reabertura de OS excedido.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16310381533079) SITUAÇÃO:**

Mensagem apresentada ao tentar reabrir Ordens de Serviço.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16310381534999) SOLUÇÃO:**

Para correção siga os passos abaixo:

![Imagem 4: Ajuste o parâmetro abaixo conforme necessidade atual de limite de dias para retroação de lançamento/reabertura de O.S,…](https://ajuda.sankhya.com.br/hc/article_attachments/17378748239511) Ajuste o parâmetro abaixo conforme necessidade atual de limite de dias para retroação de lançamento/reabertura de O.S, para isso:

**(2)** Acesse a tela de **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias)"** (Caminho de acesso: Configurações » Avançado » Preferências).

**(2)** Busque a chave **"SERVDIASRETRO - Limite de dias para lançamentos retroativos de sub-OS"** preencha devidamente.

![Imagem 5: (2) Busque a chave "SERVDIASRETRO - Limite de dias para lançamentos retroativos de sub-OS" preencha devidamente.](https://ajuda.sankhya.com.br/hc/article_attachments/14394630079895)

![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16310381546903) **CAUSA:**

Mensagem apresentada ao reabrir Ordem de serviço com data de retroação maior que o definido no parâmetro SERVDIASRETRO.
