# Usuário não possui acesso a aplicação e será redirecionado para o login do Sankhya ID

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18508032031511) **MENSAGEM:**

Usuário não possui acesso a aplicação e será redirecionado para o login do Sankhya ID.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18508039831959)SOLUÇÃO:**

A Gestão de acessos deverá ser realizada pelo **Administrador do Place** (toda empresa possui um usuário que é definido como Admin do Place);

![Imagem 3: Administrador do Place loga em:](https://ajuda.sankhya.com.br/hc/article_attachments/18508008472855) Administrador do Place loga em:

- Sankhya: <http://place.sankhya.com.br/>

![Imagem 4: Localize o menu Informações Cadastrais » Dados Cadastrais;](https://ajuda.sankhya.com.br/hc/article_attachments/18508025009047) Localize o menu Informações Cadastrais » Dados Cadastrais;

![Imagem 5: Selecione o contato ao qual deseja conceder o acesso;](https://ajuda.sankhya.com.br/hc/article_attachments/18508039836823) Selecione o contato ao qual deseja conceder o acesso;

![Imagem 6: Através da opção " EDITAR" , marque a opção " SUPORTE" :](https://ajuda.sankhya.com.br/hc/article_attachments/18508046247447) Através da opção "**EDITAR"**, marque a opção "**SUPORTE"**:

![Imagem 7: Através da opção " EDITAR" , marque a opção " SUPORTE" :](https://ajuda.sankhya.com.br/hc/article_attachments/18508032044439)

**![Imagem 8: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18852615621271) OBSERVAÇÃO:**

Para atribuir a permissão de Administrador do Place, alinhe com Gerente de Contas da sua empresa.

**![Imagem 9: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18508039842071)CAUSA:**

Ocorre quando usuário não possui acesso como Suporte dentro do Sankhya Place.
