# Configuração inválida. Forneça uma configuração de mapeamento entre impressoras locais e impressoras remotas no formato local@remota ou locat#host.port/remota

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/24021099067799) **MENSAGEM:**

[CORE\_E01146] Configuração inválida. Forneça uma configuração de mapeamento entre impressoras locais e impressoras remotas no formato local@remota ou local#host.port/remota

![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/24021099070615) **SOLUÇÃO:**

Conforme os prints abaixo, acesse as configurações do sistema, clique no botão **"Configurações"**e veja se a opção **"Web Connection"**está flegada. Caso não esteja, ative essa marcação. Após ativar, reinicie o navegador.

A mensagem é apresentada ao tentar fazer a impressão de um arquivo por um usuário que não possui as devidas configurações no sistema.
