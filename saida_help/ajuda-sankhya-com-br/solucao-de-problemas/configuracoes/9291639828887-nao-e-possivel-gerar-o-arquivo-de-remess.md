# Não é possível gerar o arquivo de remessa, a query utilizada na geração em lote não retornou resultados

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16693701628055) MENSAGEM:**

[CORE\_E04036]: Não é possível gerar o arquivo de remessa, a query utilizada na geração em lote não retornou resultados.

**![Imagem 2: SITUAÇÃO: Ao fazer a geração de Arquivo de Remessa pela tela 'Geração Arquivo de Remessa' com configuração por query a…](https://ajuda.sankhya.com.br/hc/article_attachments/17961667083159) SITUAÇÃO:**
Ao fazer a geração de Arquivo de Remessa pela tela 'Geração Arquivo de Remessa' com configuração por query a mensagem é apresentada.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16693652690583) SOLUÇÃO:**

Acesse a tela 'Configuração de Arquivo Remessa' do módulo equivalente (Financeiro ou Comercial) e verifique a configuração da geração que está configurada para executar query.
Verifique se a query está retornando os dados desejados, se os parâmetros foram informados corretamente ou se a query precisa ser ajustada.
