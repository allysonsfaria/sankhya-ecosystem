# Código do tipo de operação não pode ser Zero, no Sankhya Chekout

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16271996475543) MENSAGEM**:

Ao acessar a tela Configurações » Sankhya Checkout » Administração de Checkout existem registros com a mensagem abaixo:

**Código do tipo de operação não pode ser Zero.**

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16271983926679) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse o cadastro de TOP em: Comercial » Arquivo » Cadastros » Tipos de Operação - TOP :](https://ajuda.sankhya.com.br/hc/article_attachments/16271983927319) Acesse o cadastro de TOP em: Comercial » Arquivo » Cadastros » Tipos de Operação - TOP:

- Verifique se existe uma TOP devidamente cadastrada, ativo para ser usado para Sangria

![Imagem 4: Acesse o "Preferências" do Checkout, aba: "Integração" :](https://ajuda.sankhya.com.br/hc/article_attachments/16271996483223) Acesse o **"Preferências"** do Checkout, aba: **"Integração"**:

- Opção **"Código da TOP para sangria":** insira o código da TOP

![Imagem 5: Opção "Código da TOP para sangria": insira o código da TOP](https://ajuda.sankhya.com.br/hc/article_attachments/14627763153943)
