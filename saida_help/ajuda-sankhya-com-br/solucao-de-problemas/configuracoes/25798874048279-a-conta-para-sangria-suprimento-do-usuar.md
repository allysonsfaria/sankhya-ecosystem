# A conta para sangria/suprimento do usuário 8 não foi configurada. Verifique!

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/25798874040343) **MENSAGEM:**

[COM\_E00859] A conta para sangria/suprimento do usuário 8 não foi configurada. Verifique!

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/25798874044311)SOLUÇÃO:**

Para que seja possível realizar a 'Sangria' na rotina **PDV WEB** (Novo layout / Na tela **"Portal de Caixa"**), por meio do Botão Outras opções em Funções do Caixa, é necessário que exista a configuração da conta para Sangria/Suprimento.

Para isso, vá até a tela **"Usuários",** busque e acesse o usuário em questão, em seguida, clique no botão **"Outras Opções"** depois em **"Configuração do Usuário"** e, por fim, no campo **"Conta para Sangria/Suprimento"** faça a configuração da  Conta.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/25798874046103)CAUSA:**

Mensagem é apresentado quando tenta-se realizar uma Sangria ou Suprimento e não existe a conta vinculada ao usuário caixa logado.
