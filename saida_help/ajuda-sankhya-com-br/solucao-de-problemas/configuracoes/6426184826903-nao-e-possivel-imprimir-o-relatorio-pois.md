# Não é possível imprimir o relatório, pois ele excede o limite de páginas

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16457937315863) MENSAGEM:**

[CORE\_E05210] Não é possível imprimir o relatório, pois ele excede o limite de páginas.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16457937321495) SOLUÇÃO:**

Para solucionar esse erro, redefina o limite de páginas.

Para realizar tal alteração, use o parâmetro **"MAXPAGRELATORIO",** na tela de **"Preferências"** e delimite o número de páginas. 

![Imagem 3: Para realizar tal alteração, use o parâmetro "MAXPAGRELATORIO", na tela de "Preferências" e delimite o número de…](https://ajuda.sankhya.com.br/hc/article_attachments/15861738477207)

MAXPAGRELATORIO**:** esse parâmetro possibilita limitar a quantidade de páginas por relatório, impedindo que relatórios com grande volume de informações prejudiquem o desempenho do servidor de aplicação.
