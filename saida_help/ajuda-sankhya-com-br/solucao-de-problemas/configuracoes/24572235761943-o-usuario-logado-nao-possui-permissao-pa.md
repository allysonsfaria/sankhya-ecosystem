# O usuário logado não possui permissão para alterar documentos do tipo "XXXXX"

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/24572235747735) **MENSAGEM:**

[CORE\_E02774] O usuário logado não possui permissão para alterar documentos do tipo "XXXXX"

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/24572235750807)SOLUÇÃO:**

Entre na tela **"Acessos"**(Caminho: Configurações » Controle de Acesso » Acessos), busque pela rotina desejada, selecione o usuário em questão e conceda a ele a permissão necessária para executar a ação interrompida pelo erro.

![Imagem 3: Entre na tela "Acessos" (Caminho: Configurações » Controle de Acesso » Acessos), busque pela rotina desejada, selecione…](https://ajuda.sankhya.com.br/hc/article_attachments/24572235754007)

![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/24572219300247)**CAUSA:**

O erro é apresentado ao usuário quando ele tenta realizar uma ação para a qual ele não possui a devida permissão na tela Acessos.
