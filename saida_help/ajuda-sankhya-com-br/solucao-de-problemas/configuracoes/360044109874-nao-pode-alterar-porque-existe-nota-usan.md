![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15533915613847) **SITUAÇÃO:**

Ao tentar alterar limites na tela **"[Limites de Bonificação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044599894-Limites-de-Bonifica%C3%A7%C3%A3o)"** é apresentada a mensagem.

![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15533915619095) **SOLUÇÃO:**

![Imagem 5: Caso seja necessário uma nova liberação com valores acima do estabelecido, crie um novo limite para o usuário. Se o usuário possuir duas linhas de limites ou mais, ao solicitar a liberação o sistema vai perguntar qual dos limites o usuário deseja utilizar.
