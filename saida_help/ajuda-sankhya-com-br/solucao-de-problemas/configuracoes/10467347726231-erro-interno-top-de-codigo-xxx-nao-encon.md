# Erro interno: TOP de código XXX não encontrada

**MENSAGEM:**

[CORE\_E01089] Erro interno: TOP de código XXX não encontrada.

**SITUAÇÃO:**

Ao informar a TOP no lançamento a mensagem é apresentada.

**CAUSA:**

Ocorre quando a TOP não está ativa ou não possui o mesmo tipo de movimento do lançamento.

**SOLUÇÃO:**

Acesse o cadastro do **Tipo de operação** (Caminho de acesso à tela: Comercial » Arquivo » Cadastros » Tipos de Operação - TOP) e ative a TOP utilizada no lançamento.

![Imagem 1: Acesse o cadastro do Tipo de operação (Caminho de acesso à tela: Comercial » Arquivo » Cadastros » Tipos de Operação -…](https://ajuda.sankhya.com.br/hc/article_attachments/19033498458519)

Caso a TOP já esteja ativa, verifique se o tipo de movimento está correto.
