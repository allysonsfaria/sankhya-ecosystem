# Não é possível faturar mais de uma nota, com moedas diferentes

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18694872026647) MENSAGEM:**

[COM\_E00149] Não é possível faturar mais de uma nota, com moedas diferentes.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18694834520983) SITUAÇÃO:**

Ao selecionar mais de uma nota para faturar a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18694834528023) CAUSA:**

Ocorre ao selecionar notas com moedas diferentes.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18694834535063) SOLUÇÃO:**

Acesse o **Portal de Vendas** (Caminho de acesso à tela: Comercial » Consulta » Portal de Vendas) e verifique a moeda nas notas que deseja faturar juntas. Pois, não é possível selecionar notas com moedas diferentes para realizar o faturamento.
