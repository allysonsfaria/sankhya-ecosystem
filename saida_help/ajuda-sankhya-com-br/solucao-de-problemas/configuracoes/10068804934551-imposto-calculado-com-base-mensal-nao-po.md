# Imposto calculado com Base Mensal não pode ser digitado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19067858631959) MENSAGEM:**

[CORE\_E03270] Imposto calculado com Base Mensal não pode ser digitado.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19067872269591) SITUAÇÃO:**

Ao adicionar outros impostos a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19067872275991) CAUSA:**

Ocorre quando a opção **"Calcular com Base Mensal?"**está selecionada e deseja digitar os impostos manualmente.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19067858663575) SOLUÇÃO:**

Verifique na tela **Impostos** (Caminho de acesso à tela: Configurações » Cadastros » Impostos) a configuração do imposto. Caso a opção **"Calcular com Base Mensal?"** esteja marcada, não será possível digitar manualmente.

![Imagem 5: No lançamento de notas e movimentação financeira, quando houver "Outros impostos" o sistema não permite que o usuário…](https://ajuda.sankhya.com.br/hc/article_attachments/19067799430935)

No lançamento de notas e movimentação financeira, quando houver **"Outros impostos"** o sistema não permite que o usuário inclua um imposto que tenha base de cálculo mensal, já que este tipo de imposto é calculado automaticamente na baixa de títulos.
Acesse o artigo [Cálculo de Outros Impostos com Base Mensal Considerando Raiz do CNPJ dos Parceiros e Empresas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596874-Outros-Impostos-com-Base-Mensal-Considerando-Raiz-do-CNPJ-), e confira mais detalhes sobre este tipo de configuração.

Caso queira digitar em "Outros impostos", o imposto não pode estar marcado para Calcular com Base mensal.
