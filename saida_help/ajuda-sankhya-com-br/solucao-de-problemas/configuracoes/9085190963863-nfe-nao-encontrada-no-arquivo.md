# NFe não encontrada no arquivo

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19259007655831) MENSAGEM:**

[CORE\_E03809] NF-e não encontrada no arquivo.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19259007657879) SITUAÇÃO:**

Ao tentar importar um XML no portal de Importação de XML a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19259007663767) CAUSA:**

Tentar importar um XML em formato diferente de NF-e.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19259023225495) SOLUÇÃO:**

Verifique se o XML está no formato de NF-e.  Para conseguir importar o arquivo, o despachante deverá encaminhar o arquivo XML no mesmo formato da NF-e, porém, com as tags específicas do processo de importação.

Caso tenha alguma dúvida em relação a esse formato, confira mais informações no artigo abaixo:

[Importar dados da DI-Declaração da Importação via XML - Nota de Nacionalização. – Sankhya Gestão de Negócios](https://ajuda.sankhya.com.br/hc/pt-br/articles/360043796574-Importar-dados-da-DI-Declara%C3%A7%C3%A3o-da-Importa%C3%A7%C3%A3o-via-XML-Nota-de-Nacionaliza%C3%A7%C3%A3o-)
