# Para imprimir uma nota na modalidade RPS é necessário configurar o modelo de impressão na TOP XXX

[CORE\_E05228]: Para imprimir uma nota na modalidade RPS é necessário configurar o modelo de impressão na TOP XXX.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16583358800663) CAUSA:**

Ocorre ao não informar um modelo de impressão para a modalidade RPS no cadastro da TOP.
