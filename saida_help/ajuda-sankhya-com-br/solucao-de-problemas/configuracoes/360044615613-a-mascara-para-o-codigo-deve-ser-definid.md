# A máscara para o código deve ser definida primeiro

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16310657743127) MENSAGEM**:

A máscara para o código deve ser definida primeiro.

![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16310672735383) **SOLUÇÃO:**

Para correção siga os passos abaixo:

![Imagem 3: Acesse a tela " Preferências " (Caminho de acesso: Configurações » Avançado » Preferências) :](https://ajuda.sankhya.com.br/hc/article_attachments/16310672742039) Acesse a tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias)"** (Caminho de acesso: Configurações » Avançado » Preferências):

**(2)** Pesquise pelo parâmetro: **"FPMASCDEP - Máscara para Departamentos"**.

**(2)** Insira no campo Texto o formato esperado para cadastro de Departamento.

**(2)** Exemplo de Máscara para departamento: 99\.99\.99\.99;0

![Imagem 4: Após o ajuste, salve a alteração no parâmetro e volte a efetuar o lançamento.](https://ajuda.sankhya.com.br/hc/article_attachments/16310657766551) Após o ajuste, salve a alteração no parâmetro e volte a efetuar o lançamento.

![Imagem 5: CAUSA :](https://ajuda.sankhya.com.br/hc/article_attachments/16310657770391) **CAUSA**:

No **MGEImobilizado** é necessário o correto cadastro da Máscara para departamento, que deve ser cadastrado no parâmetro FPMASCDEP.
