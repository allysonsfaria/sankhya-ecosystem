# Tarefa de Usuário deve ter pelo menos um Formulário

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/28659748805655) **MENSAGEM:**

Tarefa de Usuário deve ter pelo menos um Formulário (Embarcado/Formatado/Nativo) ou Tela Nativa. Id: UserTask\_0sid4ml

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/28659760694423)SOLUÇÃO:**

Para corrigir o problema, primeiro descubra onde está ocorrendo o erro. Para isso, pesquise pelo Id que consta na mensagem de erro ('UserTask\_0sid4ml'), na aba **"Geral",** na **"Tarefa do Usuário",** na tela **"Processos de negócio"**.

![Imagem 3: Para corrigir o problema, primeiro descubra onde está ocorrendo o erro. Para isso, pesquise pelo Id que consta na…](https://ajuda.sankhya.com.br/hc/article_attachments/28659760697623)

Após identificar a tarefa, clique em **"Formulários/Tela"**, nesse exemplo, na aba **"Nativo",** informe a tabela e os campos necessários. Caso não informe os campos e somente a tabela, será apresentado o erro: 'O Formulário Parceiro não foi definido as configurações dos campos.'

![Imagem 4: Após identificar a tarefa, clique em "Formulários/Tela" , nesse exemplo, na aba "Nativo", informe a tabela e os campos…](https://ajuda.sankhya.com.br/hc/article_attachments/28659760703255)

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/28659748822551)CAUSA:**

Esse erro ocorre quando não é informada a tabela e os campos necessários para a tarefa.
