# Nenhuma empresa padrão para utilização do certificado digital foi cadastrada no parâmetro EMPPADCERTDIG

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16311022042775) MENSAGEM:**

[CORE\_E01601]: Nenhuma empresa padrão para utilização do certificado digital foi cadastrada no parâmetro EMPPADCERTDIG.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16311022050967) CAUSA:**

Ao Importar dados cadastrais da SEFAZ a mensagem será apresentada, se o parâmetro **"EMPPADCERTDIG - Empresa padrão para utilização do certificado digital"**. não estiver configurado.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16311029858711) SOLUÇÃO:**

![Imagem 4: Acesse a tela " Preferências " (Caminho de acesso: Configurações » Avançado ).](https://ajuda.sankhya.com.br/hc/article_attachments/17378804914455) Acesse a tela [**"Preferências"**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias) (Caminho de acesso: Configurações » Avançado).

![Imagem 5: Busque pela chave "EMPPADCERTDIG - Empresa padrão para utilização do certificado digital" .](https://ajuda.sankhya.com.br/hc/article_attachments/17378787994391) Busque pela chave **"EMPPADCERTDIG - Empresa padrão para utilização do certificado digital"**.

![Imagem 6: No campo "Inteiro" insira o código da empresa padrão para utilização do certificado digital.](https://ajuda.sankhya.com.br/hc/article_attachments/17378788006039) No campo **"Inteiro"** insira o código da empresa padrão para utilização do certificado digital.
