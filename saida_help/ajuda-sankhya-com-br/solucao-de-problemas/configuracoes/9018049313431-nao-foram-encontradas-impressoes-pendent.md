# Não foram encontradas impressões pendentes

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/15819724079511) MENSAGEM:**

[CORE\_E05132]  Não foram encontradas impressões pendentes.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15819707728663) CAUSA:**

Ocorre quando alguma configuração não está compatível com a emissão de nota e/ou boletos.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15819707731095) SOLUÇÃO:**

- Verificar se a TOP está configurada para fazer a impressão.

![Imagem 4: Verificar se a TOP está configurada para fazer a impressão.](https://ajuda.sankhya.com.br/hc/article_attachments/15819651206551)

- Se o tipo de título está configurado para **NÃO** realizar impressão do boleto.

![Imagem 5: Se o tipo de título está configurado para NÃO realizar impressão do boleto.](https://ajuda.sankhya.com.br/hc/article_attachments/15819715342615)

- Se o tipo de negociação está configurada para imprimir boleto/duplicata.

![Imagem 6: Se o tipo de negociação está configurada para imprimir boleto/duplicata.](https://ajuda.sankhya.com.br/hc/article_attachments/15819692208663)

- Se a conta bancária está configurada para emitir boletos.

![Imagem 7: Se a conta bancária está configurada para emitir boletos.](https://ajuda.sankhya.com.br/hc/article_attachments/15819693647127)
