# Sistema permite alterar nota após confirmada, mesmo com a marcação na TOP "Permitir Alteração após confirmar" desmarcada

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16865893704855) SOLUÇÃO:**

![Imagem 2: Verifique na tela de "Usuários" , se o usuário que realizou o lançamento possui a marcação "Altera registros…](https://ajuda.sankhya.com.br/hc/article_attachments/16865903004183) Verifique na tela de **"Usuários"**, se o usuário que realizou o lançamento possui a marcação **"Altera registros confirmados"**, na aba **"Segurança".** Mesmo que a TOP não permita alterações após confirmação, o sistema concederá a alteração do movimento.

![Imagem 3: Se a TOP permitir alteração, o sistema não usa esta marcação do cadastro de usuários e permite que todos os usuários…](https://ajuda.sankhya.com.br/hc/article_attachments/16865903008919) Se a TOP permitir alteração, o sistema não usa esta marcação do cadastro de usuários e permite que todos os usuários alterem notas confirmadas.

![Imagem 4: A marcação Altera registros confirmados , na aba Segurança do cadastro de usuários permite que mesmo a top estando…](https://ajuda.sankhya.com.br/hc/article_attachments/16865893716759) A marcação Altera registros confirmados, na aba Segurança do cadastro de usuários permite que mesmo a top estando contrária, o sistema aceite a alteração dos movimentos já confirmados.
