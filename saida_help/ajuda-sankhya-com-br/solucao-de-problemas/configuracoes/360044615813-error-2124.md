# Error #2124

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16807576748055) MENSAGEM:**

Error #2124.

**![Imagem 2: Solução:](https://ajuda.sankhya.com.br/hc/article_attachments/16807576750871) Solução:**

O erro pode estar relacionado a 'travamentos' de plugins como Adobe Flash Player e outros.

![Imagem 3: Mantenha os navegadores sempre atualizados e cache dos navegadores limpos;](https://ajuda.sankhya.com.br/hc/article_attachments/16807584336407) Mantenha os navegadores sempre atualizados e cache dos navegadores limpos;

![Imagem 4: O erro deve ser verificado pela Equipe de TI, quanto a extensões, plugins e infra da empresa, para resolução.](https://ajuda.sankhya.com.br/hc/article_attachments/16807576754455) O erro deve ser verificado pela Equipe de TI, quanto a extensões, plugins e infra da empresa, para resolução.

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16807576755607)CAUSA:**

- Plugin Adobe Flash Player instalado no Navegador com mal funcionamento;
- Navegador desatualizado (Chrome/Firefox/Navegador Sankhya);
- Cache do Navegador, recomenda-se limpar.
