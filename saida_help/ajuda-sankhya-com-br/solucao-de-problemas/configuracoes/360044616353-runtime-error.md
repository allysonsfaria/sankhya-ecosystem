# Runtime error

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/18586330962327) MENSAGEM:**

Runtime error XXX at XXXXXXX.

![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18586347451927) **CAUSA:**

Ocorre quando nas estações  não consta a impressora Generic Text instalada e definida como padrão.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18586330978455) SOLUÇÃO:**

Para correção seguir os passos abaixo:

Proceda, com apoio de seu T.I. a instalação e definição da impressora Generic como padrão.

Abaixo seguem orientações, baseadas em uma estação Windows 10 Pro, apenas para apoiá-los de uma forma "geral", caso existam dúvidas nesse processo, ou para a sua máquina as orientações abaixo não existam, busque por apoio de um técnico na empresa.

- Através do Menu Iniciar busque por 'Painel de Controle'
- Selecione a opção 'Dispositivos e Impressoras'
- Caso seja apresentada a Impressora Generic Text clique com botão direito : "Definir impressora como padrão".
- Caso essa não tenha sido instalada siga as orientações abaixo:
