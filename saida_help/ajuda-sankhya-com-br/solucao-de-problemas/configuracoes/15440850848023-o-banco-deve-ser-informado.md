# O banco deve ser informado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16539031230743) MENSAGEM:**

[CORE\_E01082] O banco deve ser informado.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16539031237015) CAUSA:**

Ocorre ao tentar cadastrar uma conta bancária e informar o banco zero.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16539031234071) SOLUÇÃO:**

Não é simples a retirada dessa validação, uma vez que toda a estrutura nativa do sistema está preparada para esperar a informação do banco. Portanto, informe um banco genérico, como exemplo o Banco "999-Caixa".
