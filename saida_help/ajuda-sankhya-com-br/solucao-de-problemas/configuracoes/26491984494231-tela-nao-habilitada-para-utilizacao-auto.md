# Tela não habilitada para utilização - Autorização de customização

**![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26491984477975) SITUAÇÃO:**

Ao abrir a tela **"Autorização de Customização"** a mensagem de erro é apresentada.

![Imagem 2: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26492008891415) **MENSAGEM:**

Tela não habilitada para utilização

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26491984483351)SOLUÇÃO:**

Para que o erro deixe de ser apresentando, siga toda a configuração do help: [Autorização de Customizações](https://ajuda.sankhya.com.br/hc/pt-br/articles/21517622604567-Autoriza%C3%A7%C3%A3o-de-Customiza%C3%A7%C3%B5es)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26491984484631)CAUSA:**

A mensagem de erro é apresentada quando a base não tem as configurações de autorização de customização.
