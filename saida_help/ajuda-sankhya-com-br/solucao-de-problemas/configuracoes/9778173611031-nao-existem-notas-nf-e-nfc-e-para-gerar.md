# Não existem notas NF-e/NFC-e para gerar o arquivo

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19277316082967) MENSAGEM:**

[ECOM\_E00067] Não existem notas NF-e/NFC-e para gerar o arquivo.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277316084759) SITUAÇÃO:**

Ao importar uma nota e tentar baixar o XML na tela Gerar Arquivo XML de NFe/NFSe/SAT a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19277316086679) CAUSA:**

Quando a nota não foi importada através da tela **Portal de Importação de XML** (Caminho de acesso a tela: Comercial » Rotinas » Portal de importação de XML).

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19277287798935) SOLUÇÃO:**

Os downloads de XML de Compras Importadas são realizados quando a nota for importada através da tela **Portal de Importação de XML** (Caminho de acesso à tela: Comercial » Rotinas » Portal de importação de XML), na qual terá a informação se a nota possui XML e se foi importada.
