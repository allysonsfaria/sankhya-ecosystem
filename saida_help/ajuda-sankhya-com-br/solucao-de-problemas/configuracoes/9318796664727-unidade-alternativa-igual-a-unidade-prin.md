# Unidade Alternativa igual a Unidade Principal deve ter quantidade 1

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/15854013644055) MENSAGEM:**

[CORE\_E00469]  Unidade Alternativa igual a Unidade Principal deve ter quantidade 1.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/15854013645207) SOLUÇÃO:**

Para duplicar produtos que possuem unidades alternativas é necessário ir no cadastro de **produtos** (Configurações » Cadastros » Produtos » Produtos) botão "**Configurar cópia**" e desmarcar a opção "**Unidades Alternativas**":

![Imagem 3: Para duplicar produtos que possuem unidades alternativas é necessário ir no cadastro de produtos (Configurações »…](https://ajuda.sankhya.com.br/hc/article_attachments/15854001001495)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/15854013644567) CAUSA:**

Ocorre quando se tenta lançar uma quantidade diferente de 1 para a unidade alternativa que é igual à unidade principal.
