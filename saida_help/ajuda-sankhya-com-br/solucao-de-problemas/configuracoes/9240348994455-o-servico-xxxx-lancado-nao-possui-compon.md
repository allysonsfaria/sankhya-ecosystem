# O serviço xxxx lançado não possui componente cadastrado. Favor definir algum componente para este serviço

![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16309388118807) **MENSAGEM**:

O serviço xxxx lançado não possui componente cadastrado. Favor definir algum componente para este serviço.

![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16309373617047) **SOLUÇÃO:**

Acesse a tela **"Serviço"** (Caminho de acesso: Configurações » Cadastros » Produtos » Serviço) e vincule no campo **"Componentes de Serviço"**, na aba **"Geral"**, um componente de serviço.

![Imagem 3: Acesse a tela "Serviço" (Caminho de acesso: Configurações » Cadastros » Produtos » Serviço) e vincule no campo…](https://ajuda.sankhya.com.br/hc/article_attachments/14330916202391)

Caso não haja um componente de serviço cadastrado, realize o cadastro do mesmo na tela Componentes de Serviço.

![Imagem 4: Caso não haja um componente de serviço cadastrado, realize o cadastro do mesmo na tela Componentes de Serviço .](https://ajuda.sankhya.com.br/hc/article_attachments/14331231403159)

![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16309388124055) **CAUSA:**

O erro ocorre quando não possui o componente de serviço vinculado no campo Componentes de Serviço na tela Serviço.
