# Já existe este feriado cadastrado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19147435359127) MENSAGEM:**

[CORE\_E03807] Já existe este feriado cadastrado.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19147435380759) SITUAÇÃO:**

Ao tentar cadastrar um feriado a mensagem é apresentada.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19147430011159) CAUSA:**

Ocorre ao tentar cadastrar o mesmo feriado mais de uma vez.

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19147435425303) SOLUÇÃO:**

Não é permitido configurar mais de um registro na tela "Feriados" tendo o campo "Data do feriado" preenchido com a mesma informação. Nessa situação, a mensagem é apresentada, indicando que o feriado em questão já existe para a data informada.
