# O parâmetro Sempre usar uma nota por pedido (OBRUMANOTAPED) está ligado, então a opção de Uma nota por pedido deve estar marcada

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16589842211351) MENSAGEM:**

[COM\_E00538]: O parâmetro Sempre usar uma nota por pedido (OBRUMANOTAPED) está ligado, então a opção de Uma nota por pedido deve estar marcada.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16589827386135) SOLUÇÃO:**

Quando o parâmetro **"Sempre usar uma nota por pedido? - OBRUMANOTAPED"** estiver ligado, o faturamento dos pedidos só será permitido se a marcação **"Uma nota para cada"**estiver acionada.

Ao realizar a devolução de várias notas, caso o parâmetro **"Sempre usar uma nota por pedido? - OBRUMANOTAPED"** se encontre ligado, a devolução só ocorrerá se a marcação Uma nota para cada estiver acionada.

Ao realizar o faturamento consignado de várias notas, caso o parâmetro "**Sempre usar uma nota por pedido? - OBRUMANOTAPED"** se encontre ligado, o faturamento só ocorrerá se a marcação Uma nota para cada estiver acionada.

Para mais informações, verifique o artigo [Portal de Vendas - Botão Outras Opções](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044604014-Portal-de-Vendas-Bot%C3%A3o-Outras-Op%C3%A7%C3%B5es#faturamentodevriospedidos)

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16589842216727) CAUSA:**

Ocorre sempre que o parâmetro **"Sempre usar uma nota por pedido? - OBRUMANOTAPED"** estiver ligado e a marcação Uma nota para cada não estiver acionada.
