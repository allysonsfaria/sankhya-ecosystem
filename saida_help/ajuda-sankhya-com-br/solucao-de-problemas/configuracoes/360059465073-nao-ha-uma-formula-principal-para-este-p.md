# Não há uma fórmula principal para este produto/controle/local

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16252168326423) MENSAGEM**:

[CORE\_E04980] Não há uma fórmula principal para este produto/controle/local.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16252168337559) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse o cadastro da TOP em (Comercial » Arquivo » Cadastros » Tipos de Operação - TOP) Aba: "Produção" Campo "Gerar…](https://ajuda.sankhya.com.br/hc/article_attachments/16252168340759) Acesse o cadastro da TOP em (Comercial » Arquivo » Cadastros » Tipos de Operação - TOP)
Aba: **"Produção"**
Campo **"Gerar plano de produção"**: desmarcado

**![Imagem 4: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16252168344727) OBSERVAÇÃO:**

Considere desmarcar esta opção, caso o pedido não faça parte da rotina de [Programação de Carga](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044611534)

![Imagem 5: Após os ajustes, confirme o pedido novamente, considere lançar novamente o pedido, pois a marcação na TOP é histórica.](https://ajuda.sankhya.com.br/hc/article_attachments/16252168348055) Após os ajustes, confirme o pedido novamente, considere lançar novamente o pedido, pois a marcação na TOP é histórica.

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16252161176215) CAUSA:**

Ocorre quando na TOP de Pedido está marcada a opção **"Gerar plano de produção",** porém não faz parte da rotina de programação de carga.
