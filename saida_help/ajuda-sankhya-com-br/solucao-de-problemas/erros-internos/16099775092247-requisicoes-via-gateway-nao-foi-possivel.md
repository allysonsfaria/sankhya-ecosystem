# Requisições via Gateway - Não foi possível realizar login com ERP

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16099775083159) MENSAGEM:**

Não foi possível realizar login com ERP.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16099797364375) SITUAÇÃO:**

Erro ocorre ao realizar a requisição via Gateway. No caso impossibilitando que a integração realize a comunicação.

**![Imagem 3: SOLUÇÃO](https://ajuda.sankhya.com.br/hc/article_attachments/16099813173783) SOLUÇÃO**

De acordo com as possíveis causas da mensagem, listamos os procedimentos para correções:

![Imagem 4: Acesse a tela " Configurações Gateway " e verifique se possui um usuário Sankhya informado no campo " Cod. Usuário ",…](https://ajuda.sankhya.com.br/hc/article_attachments/16099791513111) Acesse a tela "**Configurações Gateway**" e verifique se possui um usuário Sankhya informado no campo "**Cod. Usuário**", para a aplicação desejada.

![Imagem 5: Esse usuário Sankhya deve possuir vinculo com Sankhya ID . O e-mail informado no " Username " na requisição deve estar…](https://ajuda.sankhya.com.br/hc/article_attachments/16099797367703) Esse usuário Sankhya deve possuir vinculo com **Sankhya ID**. O e-mail informado no "**Username**" na requisição deve estar vinculado neste usuário Sankhya.

![Imagem 6: Esse usuário Sankhya deve possuir vinculo com Sankhya ID . O e-mail informado no " Username " na requisição deve estar…](https://ajuda.sankhya.com.br/hc/article_attachments/16107762556567)

![Imagem 7: Esse usuário Sankhya deve possuir vinculo com Sankhya ID . O e-mail informado no " Username " na requisição deve estar…](https://ajuda.sankhya.com.br/hc/article_attachments/16107791509527)

**![Imagem 8: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16099813175831) CAUSA:**

Ocorre pelo fato do USERNAME que está sendo usado na requisição ter vínculo com um usuário Sankhya e esse usuário vinculado ao SANKHYA ID. Esse usuário também deve ser informando no campo Cod. Usuário da tela Configurações Gateway, para a aplicação desejada.
