# Consulte o manual do Sankhya-W para obter informações de como utilizar esta opção

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26556184291863) **MENSAGEM:**

Consulte o manual do Sankhya-W para obter informações de como utilizar esta opção.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26556184292631)SOLUÇÃO:**

Para que o email de recuperação seja enviado, configure o parâmetro **"ENDACESSEXTWGE"** com o endereço do sistema para acesso externo.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26556216178455)CAUSA:**

A mensagem é apresentada quando o usuário tenta recuperar a senha de acesso ao sistema clicando na opção 'Esqueci minha senha' e o parâmetro ENDACESSEXTWGE - endereço para acesso externo ao WGE está vazio ou inválido.
