# A data do computador está anterior a data da última execução do sistema

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16422103800087) MENSAGEM:**

A data do computador está anterior a data da última execução do sistema.

O sistema só funcionará com data igual ou posterior a data da última execução.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16422086993559) SITUAÇÃO:**
