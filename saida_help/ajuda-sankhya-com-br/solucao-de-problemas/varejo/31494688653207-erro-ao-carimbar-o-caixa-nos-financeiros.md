# Erro ao carimbar o caixa nos financeiros, verifique se o PDV ou usuário possui caixa aberto

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/31494688642839) **MENSAGEM:**

[COM\_E00962] Erro ao carimbar o caixa nos financeiros, verifique se o PDV ou usuário possui caixa!

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/31494699036311)SOLUÇÃO:**

Para realizar **vendas** ou **recebimentos** no **PDV WEB** é necessário estar logado com um **usuário do tipo CAIXA**.

O sistema precisa dessa informação para garantir a **rastreabilidade** financeira através do **CODPDV**.

**Assim, faça login com um usuário que tenha permissão de CAIXA para continuar.**

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/31494699038999)CAUSA:**

Ao tentar realizar um recebimento no PDV WEB utilizando um usuário que **não é do tipo CAIXA**, o sistema exibirá uma mensagem de aviso impedindo a operação.
