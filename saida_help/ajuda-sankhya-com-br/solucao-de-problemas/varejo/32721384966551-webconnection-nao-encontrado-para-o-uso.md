# WebConnection não encontrado (Para o uso do PDV Web e obrigatório um WebConnection atualizado)

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/32721378352023) **MENSAGEM:**

WebConnection não encontrado (Para o uso do PDV Web e obrigatório um WebConnection atualizado)!

**SITUAÇÃO:**

Ao tentar acessar a tela **''PDV WEB'**' pode ser exibida uma mensagem de erro que impede o acesso.

![Imagem 2: Ao tentar acessar a tela ''PDV WEB' ' pode ser exibida uma mensagem de erro que impede o acesso.](https://ajuda.sankhya.com.br/hc/article_attachments/32721384958231)

**SOLUÇÃO:**

Para corrigir o erro e garantir o acesso ao **PDV WEB**, é fundamental que o **Web Connection** esteja **atualizado e instalado na máquina**. Siga os passos abaixo para verificar e realizar a atualização:

(1)**Como verificar e atualizar o Web Connection:**

**(1)** Verifique a versão atual:

No Sankhya, acesse **''Configurações do Sankhya'**' e verifique a versão atual do **Web Connection** instalada.

![Imagem 3: No Sankhya, acesse ''Configurações do Sankhya' ' e verifique a versão atual do Web Connection instalada.](https://ajuda.sankhya.com.br/hc/article_attachments/33201243880343)

**(2)** Realize a atualização, caso necessário:

**(1)**Se você utiliza o **Web Connection externo**, acesse [Sankhya Downloads](https://downloads.sankhya.com.br/) ;

- Selecione a opção ''**Navegadores'';**
- Nesta seção, estão disponíveis as versões mais recentes para download. Baixe e instale a versão mais atual do Web Connection.

Para mais informações sobre instalação do Web Connection externo: [Artigo Web Connection](https://ajuda.sankhya.com.br/hc/pt-br/articles/36452312790423-Web-Connection-n%C3%A3o-encontrado-Erro-em-impress%C3%B5es-ou-no-login-de-usu%C3%A1rio-com-acesso-apenas-por-computadores-liberados)

**(1)** Se você utiliza o **Web Connection embarcado (integrado) ao Navegador Sankhya:**

Certifique-se de que o navegador esteja sempre atualizado, pois a atualização do Web Connection é realizada juntamente com ele.

Ao garantir que o Web Connection está atualizado, a mensagem de erro será resolvida e você poderá acessar o PDV WEB normalmente.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/32721378354199)CAUSA:**

Esse erro ocorre quando o **Web Connection** não está atualizado para a versão mais recente.
