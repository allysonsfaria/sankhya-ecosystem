# Não informada a empresa no modelo de cupom informado para o usuário logado

**![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/16422945270807) MENSAGEM:**

Não informada a empresa no modelo de cupom informado para o usuário logado.

**![Imagem 2](https://ajuda.sankhya.com.br/hc/article_attachments/16422945275927) SITUAÇÃO:**

Ao acessar o FAST a mensagem é apresentada.

**![Imagem 3](https://ajuda.sankhya.com.br/hc/article_attachments/16422945280791) SOLUÇÃO:**

![Imagem 4](https://ajuda.sankhya.com.br/hc/article_attachments/16422945285271) Acesse o Fast Service com o Usuário SUP.

![Imagem 5](https://ajuda.sankhya.com.br/hc/article_attachments/16422967474199) Acesse: Avançado » Preferências » Todas as preferências

- Na tela **"Cupom Modelo"**, parte inferior da tela, verifique se existe uma linha inserida para o Usuário que esta tentando Abrir o Caixa e um Modelo inserido no campo "**Num.Modelo Cupom**".

Vamos considerar o Usuário CX02AS abaixo, veja que para ele consta vinculado o Modelo Cupom 81:

![Imagem 6: Na tela "Cupom Modelo" , parte inferior da tela, verifique se existe uma linha inserida para o Usuário que esta…](https://ajuda.sankhya.com.br/hc/article_attachments/360058911074)

![Imagem 7: Na tela "Cupom Modelo" , parte inferior da tela, verifique se existe uma linha inserida para o Usuário que esta…](https://ajuda.sankhya.com.br/hc/article_attachments/16422967477015) Feito esse vínculo, confira no Sankhya W ou MGe se existe esse Modelo devidamente configurado:

Tela: Comercial » Consulta » **"[Modelo de Notas e Pedidos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360051706514)"**

- Localize o Número único vinculado ao usuário e confira se as informações principais estão devidamente configuradas. (Parceiro/Empresa/TOP/Natureza/Centro de Resultado)

![Imagem 8: Localize o Número único vinculado ao usuário e confira se as informações principais estão devidamente configuradas.…](https://ajuda.sankhya.com.br/hc/article_attachments/16422945294359) Caso o Modelo não exista, realize as devidas parametrizações, diante dúvidas pontuais o Service Desk Especializado estará à disposição. Caso seja necessário apoio para realizar a configuração de forma completa, acionaremos um consultor de sua Franquia.

**![Imagem 9: Localize o Número único vinculado ao usuário e confira se as informações principais estão devidamente configuradas.…](https://ajuda.sankhya.com.br/hc/article_attachments/16422945297943) CAUSA:**

Ocorre ao acessar o FAST com usuário que não possui um Modelo vinculado nas preferências do Fast.
