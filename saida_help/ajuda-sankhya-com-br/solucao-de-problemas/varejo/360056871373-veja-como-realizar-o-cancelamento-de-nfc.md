# Veja como realizar o cancelamento de NFC-e através do Sankhya Checkout

![Imagem 1: Logue no Sankhya Checkout com usuário que possui liberação de acesso para Cancelamento:](https://ajuda.sankhya.com.br/hc/article_attachments/16940845544343) Logue no Sankhya Checkout com usuário que possui liberação de acesso para Cancelamento:

![Imagem 2: Logue no Sankhya Checkout com usuário que possui liberação de acesso para Cancelamento:](https://ajuda.sankhya.com.br/hc/article_attachments/360095604753)

![Imagem 3: Acesse a opção de "Menu" (lado esquerdo do topo da tela):](https://ajuda.sankhya.com.br/hc/article_attachments/16940857703831) Acesse a opção de **"Menu"** (lado esquerdo do topo  da tela):

![Imagem 4: Acesse a opção de "Menu" (lado esquerdo do topo da tela):](https://ajuda.sankhya.com.br/hc/article_attachments/16940845553943)

![Imagem 5: Selecione a opção 'Gerenciamento NFC-e':](https://ajuda.sankhya.com.br/hc/article_attachments/16940857712407) Selecione a opção **'Gerenciamento NFC-e':**

![Imagem 6: Selecione a opção 'Gerenciamento NFC-e':](https://ajuda.sankhya.com.br/hc/article_attachments/16940845564183)

![Imagem 7: Será apresentado a Tela de Gerenciamento NFC-e:](https://ajuda.sankhya.com.br/hc/article_attachments/16940857717911) Será apresentado a Tela de Gerenciamento NFC-e:

![Imagem 8: Será apresentado a Tela de Gerenciamento NFC-e:](https://ajuda.sankhya.com.br/hc/article_attachments/16940845570199)

![Imagem 9: Assim que a tela for apresentada, clique no botão atualizar e selecione o registro a ser cancelado.](https://ajuda.sankhya.com.br/hc/article_attachments/16940845573783) Assim que a tela for apresentada, clique no botão atualizar e selecione o registro a ser cancelado.

![Imagem 10: Pressione a tecla CTRL + (D) ou clique no botão "Editar registro", no topo da tela lado direito, em seguida, será…](https://ajuda.sankhya.com.br/hc/article_attachments/16940857728919) Pressione a tecla **CTRL + (D)** ou clique no botão **"Editar registro",** no topo da tela lado direito, em seguida, será apresentado a tela 'Detalhes da NFC-e 2.0'

![Imagem 11: Clique no botão "Cancelar":](https://ajuda.sankhya.com.br/hc/article_attachments/16940857732759) Clique no botão **"Cancelar":**

![Imagem 12: Clique no botão "Cancelar":](https://ajuda.sankhya.com.br/hc/article_attachments/16940857734935)

![Imagem 13: Informe o motivo:](https://ajuda.sankhya.com.br/hc/article_attachments/16940857738647) Informe o motivo:

![Imagem 14: Informe o motivo:](https://ajuda.sankhya.com.br/attachments/token/Gyg338olPjC4OQC0M0SHWU4Wb/?name=inline-545679605.png)

![Imagem 15: Pressione a tecla <F12> ou clique no botão '(F12) OK';](https://ajuda.sankhya.com.br/hc/article_attachments/16940857740567) Pressione a tecla <F12> ou clique no botão '(F12) OK';

- Após processar, o sistema retornará para a tela de **"Gerenciamento NFC-e"** e poderá constatar que a NFC-e foi devidamente cancelada;

![Imagem 16: Após processar, o sistema retornará para a tela de "Gerenciamento NFC-e" e poderá constatar que a NFC-e foi devidamente…](https://ajuda.sankhya.com.br/hc/article_attachments/16940845602583)

![Imagem 17: Para encerrar pressione '(ESC ) Fechar' ou clique no botão '(ESC ) Fechar';](https://ajuda.sankhya.com.br/hc/article_attachments/16940857747351) Para encerrar pressione '(ESC ) Fechar' ou clique no botão  '(ESC ) Fechar';

**![Imagem 18: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/16940845608855) IMPORTANTE:**

- A opção de cancelamento da nota vai estar presente na tela somente se a venda não foi integrada com o ERP;
- Se ela já foi integrada, o cancelamento tem que ser feito pelo ERP.
