# Não existe Tipo de Titulo configurado para o PDV WEB com esse Subtipo

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/37027237749143) **MENSAGEM:**

Não existe Tipo de Titulo configurado para o PDV WEB com esse Subtipo

![Imagem 2: Não existe Tipo de Titulo configurado para o PDV WEB com esse Subtipo](https://ajuda.sankhya.com.br/hc/article_attachments/37027222823959)

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/37027222824215)SOLUÇÃO:**

**(1)** Acesse a tela [**''Tipos de Título''**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044606494-Tipos-de-T%C3%ADtulo) (Financeiro » Arquivos » Cadastros » Tipos de Título » Tipos de Título).

**(2)** Localize e edite o **Tipo de Título** que está sendo utilizado causando o erro no PDV Web.

**(3)** Na aba **''Fast Service"**, localize e marque o campo **''Utiliza no Fast Service?''**.

**(4)** Salve as alterações.

**(5)** Feche e reabra o PDV Web.

**(6)** Em seguida, realize a operação novamente com o subtipo ou tipo de título corrigido.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/37027222825751)CAUSA:**

O erro ocorre porque o Tipo de Titulo utilizado no PDV Web não possui a opção ''Utiliza no Fast Service?''  marcada em sua aba de configuração, que é obrigatória para que o sistema reconheça o título corretamente.
