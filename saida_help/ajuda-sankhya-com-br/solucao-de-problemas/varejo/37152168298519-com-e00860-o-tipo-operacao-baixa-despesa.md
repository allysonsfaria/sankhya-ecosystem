# [COM_E00860] O Tipo Operacao Baixa Despesa não foi definida para o usuário X. Verifique no cadastro de usuários!

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/37152168289815) **MENSAGEM:**

[COM\_E00860] O Tipo Operacao Baixa Despesa não foi definida para o usuário X. Verifique no cadastro de usuários!

**SITUAÇÃO:**

Ao realizar o lançamento de despesas pelo **PDV WEB**, em **“Outras Opções”**, selecionando **“Funções de Caixa”**, é apresentada a mensagem de erro acima.

**SOLUÇÃO:**

**(1)** Acesse a tela [**''Usuários''**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios) (Configurações » Controle de Acesso » Usuários).

**(2)** Na aba **''Identificação''** no campo **''Tipo Operação Baixa Despesa''** informe a TOP de despesa correspondente.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/37152168293015)CAUSA:**

O erro ocorre quando a **TOP de Baixa de Despesa** não foi configurada no cadastro do usuário que está realizando o lançamento da despesa.
