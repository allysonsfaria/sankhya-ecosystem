# Usuário não autorizado a realizar o serviço. Correção: Informe os dados de um usuário autorizado a executar o serviço

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16429384887319) MENSAGEM**:

Código: E138
Descrição: Usuário não autorizado a realizar o serviço.
Correção: Informe os dados de um usuário autorizado a executar o serviço.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16428917308055) CAUSA:**

Ao emitir uma nota de **serviço** é apresentada a mensagem, isso ocorre porque a empresa emissora não está autorizada na prefeitura para emissão de forma automática (via integração/WebService).

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16428961145623) SOLUÇÃO:**

Verifique se a empresa está credenciada na Prefeitura em questão. Se estiver utilizando o ambiente de produção deve estar credenciado para este ambiente, ou se estiver utilizando o ambiente de homologação deve estar credenciado para este ambiente. Entre em contato com o setor de fiscalização da prefeitura solicitando essa liberação no cadastro da empresa.

**![Imagem 4: ATENÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16428917312919) ATENÇÃO:**

Essa é uma informação que o próprio cliente (contador) ou consultor que está implantando deve verificar, não é escopo do SD acionar a prefeitura para solicitar tal informação.
