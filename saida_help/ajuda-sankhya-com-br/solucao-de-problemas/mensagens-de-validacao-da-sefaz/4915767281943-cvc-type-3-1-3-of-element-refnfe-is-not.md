# cvc-type.3.1.3: of element 'refNFe' is not valid

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16347104020375) MENSAGEM**:

cvc-type.3.1.3: The value 'xxxxxxxxxxx' of element 'refNFe' is not valid.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16347104027543) CAUSA:**

Este problema ocorre quando o campo **"Chave NF-e Referenciada das Centrais"**, foi preenchido com uma 'Chave NF-e' não válida.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16347119906839) SOLUÇÃO:**

Para a resolução do incidente, preencha o campo Chave NF-e Referenciada corretamente com os dados da chave de origem, sendo uma chave válida.

![Imagem 4: Para a resolução do incidente, preencha o campo Chave NF-e Referenciada corretamente com os dados da chave de origem,…](https://ajuda.sankhya.com.br/hc/article_attachments/4915570827799)

Em geral este campo fica disponível na **"Aba NF-e"** ou **"Cabeçalho da nota".**
