# cvc-type.3.1.3: The value 'XX' of element 'fone' is not valid

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16483381477143)  MENSAGEM:**

cvc-pattern-valid: Value 'XX' is not facet-valid with respect to pattern '[0-9]{6,14}' for type '#AnonType\_foneTEndereço'.
cvc-type.3.1.3: The value 'XX' of element **'fone'** is not valid.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16483358493719) SOLUÇÃO:**

Para correção, siga os passos abaixo:

![Imagem 3: Acesse: Configurações » Cadastros » Parceiros](https://ajuda.sankhya.com.br/hc/article_attachments/16483381487511) Acesse: Configurações » Cadastros » Parceiros

- Aba: **"Endereço"**
- Campo **"Telefone":** efetue o ajuste do número do telefone do parceiro

![Imagem 4: Após o ajuste, redigite o parceiro na nota e gere lote novamente.](https://ajuda.sankhya.com.br/hc/article_attachments/16483358503191) Após o ajuste, redigite o parceiro na nota e gere lote novamente.

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16483358504855) CAUSA:**

Ocorre quando o número do telefone do parceiro está preenchido incorretamente ou incompleto.
