# Tipo de serviço inválido para o tomador informado

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16371166745239) MENSAGEM:**

Rejeição: Tipo de serviço inválido para o tomador informado.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16371157156247) SOLUÇÃO:**

A transportadora que está contratando, deve emitir um CT-e, informando a outra Transportadora como Redespacho e utilizando este CT-e para emitir um CT-e de Subcontratação.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16371157157655) CAUSA:**

Esta rejeição significa que o Tomador de Serviço informado no Conhecimento também é uma transportadora. Porém a SEFAZ não permite que uma Transportadora seja tomadora de serviço em um CT-e, há menos que este CT-e seja de Subcontratação.
