# Chave de acesso de CT-e inválida (UF inválida)

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16444250631831) MENSAGEM:**

[588-Rejeição]: Chave de acesso de CT-e inválida (UF inválida).

**![Imagem 2: SOLUÇÃO: Para correção desta mensagem, siga os passos abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/16444250633239) SOLUÇÃO:**
Para correção desta mensagem, siga os passos abaixo:

**(1)** Acesse "**[Viagens de Transporte (MDF-e)](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612514)"**(Caminho de acesso à tela: Comercial » Rotinas), vá até a aba: "**MDF-e",** depois à sub-aba: "**Documentos MDF-e"** e nela:

**(2)** Verifique, pelo Número Único, os CT-e's vinculados a este MDF-e.

**(2)**Confira para cada documento (CT-e) vinculado a esse MDF-e, se a chave de acesso do mesmo foi inserida corretamente.

**(2)** Realize o ajuste de chaves inseridas incorretamente.

**(2)** Após o ajuste reenvie o MDF-e

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16444250635671) CAUSA:**

Quando for emitido um MDF-e e for informada Chave de Acesso de CT-e com trecho correspondente ao Código da UF inválido, será retornado a rejeição.
