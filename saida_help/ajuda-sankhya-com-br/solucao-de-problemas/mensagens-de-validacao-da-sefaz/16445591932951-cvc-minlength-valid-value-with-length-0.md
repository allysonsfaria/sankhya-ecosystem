# cvc-minLength-valid: Value with length = 0 is not facet-valid with respect to minLength 1 for type tsNumeroEndereco

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16445563178391)  MENSAGEM:**

cvc-minLength-valid: Value with length = 0 is not facet-valid with respect to minLength 1 for type tsNumeroEndereco.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16445583940503) CAUSA:**

Ocorre quando há erro no numero do endereço cadastrado, ou quando há um erro no Cód. município DMS da cidade.

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16445578230551) SOLUÇÃO:**

Acesse o cadastro da Empresa e do Parceiro, validar o campo Numero dos endereços cadastrados:

![Imagem 4: Acesse o cadastro da Empresa e do Parceiro, validar o campo Numero dos endereços cadastrados:](https://ajuda.sankhya.com.br/hc/article_attachments/16446755984535)

![Imagem 5: Acesse o cadastro da Empresa e do Parceiro, validar o campo Numero dos endereços cadastrados:](https://ajuda.sankhya.com.br/hc/article_attachments/16446790646679)

**![Imagem 6: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16447016584471) OBSERVAÇÃO:**

Caso tenha outros endereços, devem ser validados também.

Uma outra possibilidade para ocorrer o erro é o Cód. município DMS preenchido de maneira errada, deve ser acessado a tela Cidades, e buscar pela cidade do prestador ou tomador, validando o campo.

![Imagem 7: Uma outra possibilidade para ocorrer o erro é o Cód. município DMS preenchido de maneira errada, deve ser acessado a…](https://ajuda.sankhya.com.br/hc/article_attachments/16446823821847)

Deve ser verificado junto a prefeitura qual o código correto para cada cidade.

Caso deseje poderá visualizar maiores informações no artigo:

[Cód. município DMS para a cidade do prestador](https://ajuda.sankhya.com.br/hc/pt-br/articles/10135818887703)
