# O campo 'Produto' deve ser informado - Portal de Importação de XML

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/23967741524375)  **MENSAGEM:**

[CORE\_E03230] O campo 'Produto' deve ser informado

![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/23967729530391) **CAUSA:**

Ao tentar fazer a importação de uma nota a mensagem é apresentada.

![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/23967729532951) **SOLUÇÃO:**

Para solucionar o problema siga os passos abaixo:

![Imagem 5: Em seguida, clique no botão "Outras opções", depois em "Preferências da empresa para importação NF-e" e verifique se o…](https://ajuda.sankhya.com.br/hc/article_attachments/23967729537047) Em seguida, clique no botão **"Outras opções",**depois em **"Preferências da empresa para importação NF-e"** e verifique se o campo **"Permite vínculo manual para NF-e Venda"** está flegado, caso esteja desfaça a marcação;
