# É necessário informar o atributo 'value'

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19069080578967) **MENSAGEM:**

É necessário informar o atributo 'value'

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19069075571095)SOLUÇÃO:**

Informe o campo **Frequência** com o período que será pago o parcelamento feito, para este campo temos as seguintes opções :

- 30, 60, 90, 120...;
- Anual;
- Bimestral;
- Dezena;
- Diária;
- Mensal;
- Quadrimestral;
- Quinzenal;
- Semanal;
- Semestral;
- Trimestral;
- Personalizada.

Optando-se pela opção Personalizada, será aberto o campo para definição do **"Intervalo de dias"** para a frequência de parcelamento.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19069080586903)CAUSA:**

Ao confirmar o parcelamento de um título na movimentação financeira ou renegociação de títulos e o campo **Frequência**não estar informado.
