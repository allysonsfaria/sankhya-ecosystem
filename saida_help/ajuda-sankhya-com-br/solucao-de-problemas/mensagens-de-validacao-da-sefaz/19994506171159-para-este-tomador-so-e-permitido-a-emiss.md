# Para este tomador só é permitido a emissão de notas fiscais com a situação tributária "Substituição tributária".  Correção: Favor entrar em contato com a Prefeitura para maiores informações

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/19994553404183) **MENSAGEM:**

Para este tomador só é permitido a emissão de notas fiscais com a situação tributária "Substituição tributária". Correção: Favor entrar em contato com a Prefeitura para maiores informações.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19994553404823)SOLUÇÃO:**

Dentro da tela **Central de vendas**, no rodapé, acesse a aba **"Impostos"** e nela ative a marcação **"ISS Retido na fonte"** e reprocesse a nota, que deverá ser autorizada.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/19994506164759)CAUSA:**

Esta é uma mensagem de erro da prefeitura e diz que quando o tomador for substituto tributário, é necessário que o imposto seja retido.
