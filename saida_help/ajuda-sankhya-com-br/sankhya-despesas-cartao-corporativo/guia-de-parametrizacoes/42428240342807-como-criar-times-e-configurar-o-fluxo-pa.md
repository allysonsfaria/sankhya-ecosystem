## Como funciona

A funcionalidade de **Time e aprovações** permite organizar usuários em grupos e definir responsáveis pelas aprovações dos processos.

Após criar um time, é possível associar usuários e configurar os aprovadores responsáveis pelo **fluxo padrão**, utilizado nos processos disponíveis.

Além disso, a funcionalidade disponibiliza o histórico de ações realizadas para acompanhamento das alterações.

##

## Passo a passo

### Criar um novo time

1. Acesse **Configurações**.
2. Clique em **Time e aprovações**.
3. Clique no botão **+** localizado no canto inferior direito da tela.
4. Digite o nome do time.
5. Clique em **Salvar**.

Pronto! O time será criado.

### [GIF animado: Imagem 1: Pronto! O time será criado.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73238160169/original/3jFPvhEZLKzPRypBN08TarRMcal0A2PPsA.gif?1782933905)

### Adicionar usuários ao time

1. Acesse o time criado.
2. Clique no botão **+** para adicionar o primeiro usuário.
3. Selecione o usuário desejado.
4. Confirme a inclusão.

### Para adicionar novos usuários posteriormente:

1. Clique em **Associar usuários**.
2. Selecione os usuários que deseja incluir.
3. Confirme a associação.

## Configurar aprovadores

1. Dentro do time, acesse **Fluxo padrão**.
2. Adicione os usuários que serão responsáveis pelas aprovações.
3. Salve as alterações.

Pronto! Os aprovadores passarão a compor o fluxo configurado.

## [GIF animado: Imagem 2: Pronto! Os aprovadores passarão a compor o fluxo configurado.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73238161191/original/RXaxwZLbaA2iA7ew6_r4Y1X6XQzlPrbT-A.gif?1782934167)

## Informações Importantes

- Os times criados serão utilizados no Fluxo padrão para relatórios e adiantamentos.
- É possível adicionar ou remover usuários conforme necessidade da empresa.
- Os aprovadores definidos impactam diretamente o processo de aprovação configurado.
- O histórico de ações fica disponível para consulta e acompanhamento das alterações realizadas.

##

## Perguntas Frequentes

### Posso criar mais de um time?

Sim. É possível criar diferentes times conforme a estrutura da empresa.

### Como adiciono mais usuários depois da criação?

Após incluir o primeiro usuário, utilize a opção Associar usuários.

### Onde configuro quem aprova os processos?

Os aprovadores devem ser definidos dentro da opção Fluxo padrão.

### Os times funcionam para quais processos?

Os times ficam disponíveis no Fluxo padrão utilizado para relatórios e adiantamentos.

### Consigo acompanhar alterações realizadas?

Sim. O histórico de ações permite visualizar alterações feitas dentro da configuração.
