## Como funciona

A funcionalidade de Classificação de despesas permite criar subcategorias para melhorar a organização dos lançamentos realizados pelos usuários.

Durante a criação, é possível definir se a subcategoria ficará disponível para todos os usuários ou apenas para usuários específicos.

As opções disponíveis são:

- **Pública** — todos os usuários poderão visualizar e lançar despesas nessa subcategoria.
- **Restrita** — apenas os usuários selecionados poderão utilizar essa subcategoria.

## Passo a passo

1. Acesse **Configurações**.
2. Clique em **Classificação de despesas**.
3. Selecione a **categoria** na qual deseja criar a subcategoria.
4. Clique no botão **+**, localizado no canto inferior da tela.
5. Escolha o tipo de subcategoria:

### Pública

- Todos os usuários poderão visualizar e lançar despesas nessa subcategoria.

### Restrita

- Apenas os usuários selecionados poderão visualizar e lançar despesas nessa subcategoria.

6. Informe o nome da subcategoria.
7. Clique em **Salvar**.

Pronto! A subcategoria ficará disponível conforme as permissões definidas.

## Informações Importantes

- A criação está disponível apenas para subcategorias.
- Não é possível criar novas categorias nessa funcionalidade.
- Subcategorias restritas ficam disponíveis somente para os usuários associados.
- A escolha entre pública e restrita impacta diretamente quem poderá utilizar a subcategoria nos lançamentos.

## Perguntas Frequentes

### Posso criar uma nova categoria?

Não. Nesta funcionalidade é possível criar apenas subcategorias.

### Qual a diferença entre subcategoria pública e restrita?

A subcategoria pública fica disponível para todos os usuários. Já a restrita pode ser utilizada apenas pelos usuários selecionados.

### Posso alterar uma subcategoria depois de criada?

As alterações dependem das permissões disponíveis na configuração da plataforma.

### Os usuários conseguem visualizar subcategorias restritas?

Somente os usuários associados àquela subcategoria terão acesso para utilizá-la.
