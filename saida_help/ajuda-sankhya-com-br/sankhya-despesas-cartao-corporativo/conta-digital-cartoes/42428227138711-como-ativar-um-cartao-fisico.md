# Como ativar um cartão físico?

Nesse artigo ensina como ativar um cartão físico do Sankhya Despesas pelo aplicativo.

## Como funciona

Após receber o cartão físico, é necessário realizar sua ativação antes de utilizá-lo. O processo é feito diretamente pelo aplicativo e leva apenas alguns minutos.

## Passo a passo

1. Abra o aplicativo **Sankhya Despesas**.
2. Na tela inicial, toque no banner **Meu Cartão Espresso**.
3. Selecione a opção **Recebi meu cartão**.
4. A câmera do celular será aberta para leitura do QR Code.
5. Escaneie o **QR Code localizado no verso do cartão**.
6. Cadastre a senha que será utilizada nas compras.
7. Confirme a senha.
8. Pronto! Seu cartão estará ativado e disponível para uso.

## Atenção

- **Escaneie apenas o QR Code localizado no verso do cartão.**
- **Não escaneie o QR Code da carta berço (folha que acompanha o cartão)**, pois ele não é utilizado para ativação e causará erro durante o processo.
- A senha cadastrada será utilizada para compras presenciais realizadas com o cartão físico.
- Após a ativação, o cartão já poderá ser utilizado conforme as permissões configuradas pela empresa.

## Perguntas frequentes

### Qual QR Code devo escanear?

O QR Code correto é o que está **impresso no verso do cartão físico**.

### Escaneei o QR Code da carta berço e apareceu erro. O que fazer?

Volte para a tela de ativação e escaneie o **QR Code do verso do cartão**. O QR Code da carta berço não é válido para ativação.

### Posso alterar a senha depois da ativação?

Sim. A senha do cartão pode ser alterada posteriormente pelo aplicativo, na área de configurações da conta.

### O cartão pode ser utilizado imediatamente após a ativação?

Sim. Assim que a ativação for concluída com sucesso, o cartão estará pronto para utilização.
