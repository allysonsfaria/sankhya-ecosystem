# Como classificar uma despesa realizada com pagamento via Pix?

**ÍNDICE**

- [Opção 1: Pela tela de detalhes do Pix](https://espressoapp-help.freshdesk.com/a/solutions/articles/73000670989?portalId=73000094355#Op%C3%A7%C3%A3o-1%3A-Pela-tela-de-detalhes-do-Pix%E2%80%8B)
- [Opção 2: Pelo menu de Despesas](https://espressoapp-help.freshdesk.com/a/solutions/articles/73000670989?portalId=73000094355#Op%C3%A7%C3%A3o-2%3A-Pelo-menu-de-Despesas%E2%80%8B)
- [Importante](https://espressoapp-help.freshdesk.com/a/solutions/articles/73000670989?portalId=73000094355#Importante)

Após a realização de um pagamento via Pix utilizando a Conta Digital Sankhya Despesas, uma despesa será criada automaticamente no aplicativo para que você possa realizar a comprovação e a prestação de contas à sua empresa.

Você pode classificar a despesa de duas formas:

## Opção 1: Pela tela de detalhes do Pix

1. Acesse o menu Pix no aplicativo.
2. Localize a transação desejada.
3. Abra os detalhes da transação.
4. Clique na opção Classificar Despesa.
5. Você será direcionado para a tela de classificação de despesas do Sankhya Despesas, onde poderá preencher as informações necessárias e anexar os comprovantes.

![Imagem 1: Você será direcionado para a tela de classificação de despesas do Sankhya Despesas, onde poderá preencher as…](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73235265873/original/D-RhiItOz_ZiMFNwQRxZ6qs4D8n-MSgEAw.jpeg?1781542282)

## Opção 2: Pelo menu de Despesas

1. Acesse o menu Despesas no aplicativo.
2. Localize a despesa gerada a partir do pagamento via Pix.
3. Identifique a despesa com a tag Comprovar.
4. Clique sobre a despesa.
5. Você será direcionado para a tela de classificação de despesas do Sankhya Despesas para concluir a prestação de contas.

![Imagem 2: Você será direcionado para a tela de classificação de despesas do Sankhya Despesas para concluir a prestação de contas.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73235278379/original/GFw0O-HhJTDFNl4BvSKscJrVr9gqkAU8nQ.jpeg?1781544742)

## Importante

A classificação da despesa é necessária para que a empresa consiga identificar a finalidade do gasto e realizar o processo de prestação de contas conforme as políticas internas definidas.
