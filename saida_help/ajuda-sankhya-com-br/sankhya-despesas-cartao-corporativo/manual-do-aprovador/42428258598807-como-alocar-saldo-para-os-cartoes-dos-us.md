## Como funciona

O Sankhya Despesas permite gerenciar o saldo dos cartões corporativos de duas formas:

- **Alocação em massa:** para vários usuários ao mesmo tempo.
- **Alocação individual:** para um usuário específico.

Também é possível consultar o histórico de movimentações realizadas em cada subconta.

## Alocar saldo em massa

Essa opção permite realizar operações para todos os usuários ou apenas para um grupo específico de subcontas.

## Passo a passo

1. Acesse **Subcontas**.
2. Clique em **Definir saldo em massa**.
3. Escolha uma das operações disponíveis:

   - **Adicionar saldo**
   - **Ajustar saldo**
   - **Resgatar tudo**
4. Informe o valor desejado (quando aplicável).
5. Selecione as subcontas que participarão da operação.

   - Para aplicar a todos os usuários, mantenha todas as subcontas selecionadas.
   - Para aplicar apenas a alguns usuários, selecione somente as subcontas desejadas.
6. Clique em **Confirmar**.

Pronto! A operação será realizada para todas as subcontas selecionadas.

[GIF animado: Imagem 1: Pronto! A operação será realizada para todas as subcontas selecionadas.](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73242282649/original/dTfYTwyjHo1OokCrpJ-g2DjOdXc01g941g.gif?1784923990)

## O que faz cada opção?

### Adicionar saldo

Adiciona o valor informado ao saldo atual do cartão.

### Ajustar saldo

Define exatamente qual será o saldo final do cartão, substituindo o saldo existente pelo valor informado.

### Resgatar tudo

Remove todo o saldo disponível das subcontas selecionadas, retornando os valores para a conta principal da empresa.

## Alocar saldo para um único usuário

Caso seja necessário alterar o saldo de apenas um colaborador, o processo é ainda mais simples.

## Passo a passo

1. Acesse **Subcontas**.
2. Selecione o usuário desejado.
3. Clique em **Definir saldo**.
4. Escolha a operação desejada:

   - **Adicionar saldo**
   - **Ajustar saldo**
   - **Resgatar tudo**
5. Informe o valor (quando aplicável).
6. Clique em **Confirmar**.

Pronto! O saldo do cartão do usuário será atualizado.

## Consultar movimentações da subconta

Dentro da subconta de cada usuário também é possível acompanhar todo o histórico financeiro do cartão.

Na opção **Movimentações**, você poderá visualizar:

- Transações realizadas com o cartão;
- Recargas de saldo;
- Resgates de saldo;
- Histórico de atividades da subconta.

Essa consulta facilita o acompanhamento de todas as movimentações realizadas pelo usuário.

## Informações Importantes

- A alocação em massa permite atualizar uma, várias ou todas as subcontas simultaneamente.
- A alocação individual altera apenas o saldo do usuário selecionado.
- A opção **Adicionar saldo** soma um valor ao saldo atual.
- A opção **Ajustar saldo** substitui o saldo existente pelo valor informado.
- A opção **Resgatar tudo** remove todo o saldo disponível da subconta.

## Perguntas Frequentes

### Posso adicionar saldo para apenas alguns usuários?

Sim. Na opção Definir saldo em massa, basta selecionar somente as subcontas desejadas.

### Posso realizar a operação para todos os usuários de uma vez?

Sim. Basta manter todas as subcontas selecionadas antes de confirmar a operação.

### Qual a diferença entre adicionar e ajustar saldo?

- **Adicionar saldo:** soma um valor ao saldo atual.
- **Ajustar saldo:** define exatamente qual será o saldo final do cartão.

### O que acontece ao utilizar "Resgatar tudo"?

Todo o saldo disponível do cartão é removido e retorna para a conta principal da empresa.

### Onde posso consultar as movimentações do cartão?

Acesse a Subconta do usuário e clique em Movimentações para visualizar transações, recargas, resgates e o histórico de atividades.
