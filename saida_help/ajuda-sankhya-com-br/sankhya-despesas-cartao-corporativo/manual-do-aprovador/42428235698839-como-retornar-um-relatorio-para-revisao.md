# Como retornar um relatório para revisão do colaborador?

Nesse artigo ensina como utilizar a funcionalidade **Retornar relatório** para solicitar que o colaborador realize correções antes que o relatório siga no fluxo de aprovação.

## Como funciona

A funcionalidade **Retornar relatório** permite devolver um relatório ao colaborador para que ele realize as alterações necessárias e o envie novamente para aprovação.

Esse recurso é indicado quando o relatório apresenta informações incorretas, como:

- Valor da despesa;
- Categoria ou subcategoria;
- Data da despesa;
- Descrição;
- Outras informações que precisam ser corrigidas pelo colaborador.

Após o retorno, o relatório ficará disponível para edição pelo usuário e deverá ser reenviado para continuar o fluxo de aprovação.

## Passo a passo

1. Acesse o relatório que deseja retornar.
2. Clique em **Mais opções**.
3. Selecione **Retornar relatório**.
4. No campo **Justificativa**, informe o motivo pelo qual o relatório está sendo devolvido.
5. No campo **CONFIRMO**, digite exatamente a palavra **CONFIRMO** em letras maiúsculas.
6. Clique em **Retornar**.

Pronto! O relatório será devolvido ao colaborador para que ele realize as correções necessárias.

**O que acontece após o retorno?**

Após a ação:

- O relatório passa para o status **Em revisão**;
- O colaborador poderá visualizar o motivo do retorno;
- Após realizar as correções, o relatório deverá ser enviado novamente para aprovação.

Ao abrir o relatório, será possível consultar:

- Quem realizou o retorno;
- Data do retorno;
- Justificativa informada pelo aprovador.

**Informações Importantes**

- Utilize essa funcionalidade sempre que for necessário que o próprio colaborador realize ajustes no relatório.
- A justificativa é obrigatória e ajuda o colaborador a entender quais alterações devem ser realizadas.
- Para confirmar a ação, é obrigatório digitar **CONFIRMO** em letras maiúsculas.
- Enquanto o relatório estiver em revisão, ele permanecerá aguardando as correções do colaborador.

## Perguntas Frequentes

### Quando devo utilizar a opção "Retornar relatório"?

Quando o colaborador precisar corrigir informações do relatório antes que ele seja aprovado.

### O que acontece com o relatório após o retorno?

Ele passa para o status **Em revisão**, permitindo que o colaborador faça as alterações necessárias.

### O colaborador consegue visualizar o motivo do retorno?

Sim. Ao acessar o relatório, ele poderá consultar a justificativa, a data do retorno e o usuário que realizou a ação.

### Preciso confirmar a ação?

Sim. É obrigatório informar a palavra **CONFIRMO** em letras maiúsculas para concluir o retorno do relatório.
