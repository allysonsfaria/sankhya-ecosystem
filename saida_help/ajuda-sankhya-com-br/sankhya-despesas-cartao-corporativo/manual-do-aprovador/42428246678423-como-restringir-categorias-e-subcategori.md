# Como restringir categorias e subcategorias de despesas

Nesse artigo ensina como restringir o acesso a categorias e subcategorias para controlar quais usuários poderão visualizar e realizar lançamentos de despesas.

## Como funciona

A funcionalidade de Classificação de despesas permite restringir categorias e subcategorias para que apenas usuários específicos tenham acesso durante o lançamento de despesas.

Ao aplicar uma restrição, somente os usuários associados poderão visualizar e utilizar aquela categoria ou subcategoria.

Usuários que não estiverem associados não terão acesso a essas opções.

## Passo a passo

Como restringir uma categoria

1. Acesse **Configurações > Classificação de despesas**.
2. Selecione a categoria que deseja restringir.
3. Clique em **Tornar restrito**.
4. Clique no botão **+**, localizado no canto inferior da tela.
5. Selecione os usuários que terão acesso à categoria.
6. Clique em **Associar**.

Pronto! A categoria ficará disponível apenas para os usuários associados.

## Como restringir uma subcategoria

1. Acesse **Configurações > Classificação de despesas**.
2. Selecione a subcategoria que deseja restringir.
3. Clique em **Tornar restrito**.
4. Clique no botão **+**, localizado no canto inferior da tela.
5. Selecione os usuários que terão acesso à subcategoria para realizar lançamentos.
6. Clique em **Associar**.

Pronto! Apenas os usuários associados poderão utilizar essa subcategoria.

## Informações Importantes

- As restrições podem ser aplicadas tanto para categorias quanto para subcategorias.
- Apenas usuários associados terão acesso às opções restritas.
- Usuários não associados não visualizarão as categorias ou subcategorias durante o lançamento das despesas.
- Revise periodicamente os usuários associados para manter os acessos atualizados.

## Perguntas Frequentes

### O que acontece quando uma categoria é restrita?

Somente os usuários associados poderão visualizar e utilizar essa categoria.

### Usuários sem associação conseguem ver categorias restritas?

Não. Apenas usuários vinculados terão acesso.

### Posso restringir apenas subcategorias?

Sim. A restrição pode ser aplicada separadamente em categorias ou subcategorias.

### Posso alterar os usuários associados depois?

Sim. Os usuários vinculados podem ser ajustados conforme a necessidade da empresa.
