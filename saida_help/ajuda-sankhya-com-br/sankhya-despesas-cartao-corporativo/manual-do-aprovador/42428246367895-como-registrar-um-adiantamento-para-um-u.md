# Como registrar um adiantamento para um usuário

Ensinar como registrar um adiantamento para um colaborador utilizando a versão Web da plataforma.

Para que essa funcionalidade esteja ativada é necessário o perfil ser **financeiro.**

## Como funciona

A funcionalidade Registrar adiantamentos permite que usuários com perfil Financeiro realizem o lançamento de adiantamentos para colaboradores.

Durante o registro, é possível informar o usuário que receberá o valor, a data de utilização, o valor do adiantamento, o motivo da solicitação e, quando aplicável, o time ao qual o colaborador pertence.

## Passo a passo

1. Acesse **Adiantamentos**.
2. Clique em **Registrar adiantamentos**.
3. Selecione o usuário que receberá o adiantamento.
4. Informe a **data de utilização**.
5. Digite o **valor** do adiantamento.
6. Informe o **motivo** da concessão.
7. Se necessário, selecione o **time** correspondente.
8. Clique em **Salvar**.

Pronto! O adiantamento será registrado para o colaborador.

## Informações Importantes

- A funcionalidade Registrar adiantamentos está disponível apenas para usuários com perfil Financeiro.
- O preenchimento correto das informações facilita o controle e a prestação de contas do adiantamento.
- A seleção do time é opcional e deve ser utilizada quando aplicável às configurações da empresa.

## Perguntas Frequentes

### Quem pode registrar um adiantamento?

Somente usuários que possuem o perfil Financeiro.

### Quais informações são obrigatórias?

É necessário informar o colaborador, a data de utilização, o valor e o motivo do adiantamento.

### O campo Time é obrigatório?

Não. Esse campo deve ser preenchido apenas quando utilizado pela empresa.

### Posso registrar adiantamentos para qualquer colaborador?

Sim, desde que o colaborador esteja cadastrado na plataforma e você possua permissão para realizar o registro.
