## Como funciona

A funcionalidade **Alocação em Projetos** permite organizar e classificar despesas por projetos, facilitando o acompanhamento dos gastos e o gerenciamento financeiro.

Ao criar um projeto, você pode definir se ele ficará disponível para todos os usuários ou apenas para colaboradores específicos.

## Passo a passo

### Ativar a funcionalidade de projetos

1. Acesse **Configurações**.
2. Clique em **Funcionalidades**.
3. Acesse **Classificação de despesas**.
4. Ative a opção **Alocação em projetos**.

[GIF animado: Imagem 1: Ative a opção Alocação em projetos .](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73241268558/original/9VPd5vpPJs4lP3rwRLSVJF25lgMlMbMg2g.gif?1784572872)

### Criar um projeto

1. Acesse **Configurações > Classificação de despesas > Projetos**.
2. Clique no botão **+**, localizado no canto inferior direito da tela.
3. Escolha o tipo de projeto:

   - **Público:** disponível para todos os usuários.
   - **Restrito:** disponível apenas para os usuários que forem associados ao projeto.
4. Informe o **nome do projeto**.
5. Se desejar, preencha o campo **Código**.
6. Clique em **Salvar**.

Pronto! O projeto estará disponível para utilização conforme as permissões configuradas.

## Informações Importantes

- Antes de criar projetos, é necessário ativar a funcionalidade **Alocação em projetos**.
- Projetos públicos podem ser utilizados por todos os usuários da plataforma.
- Projetos restritos ficam disponíveis apenas para os usuários associados.
- O campo **Código** é opcional e pode ser utilizado para facilitar a identificação do projeto, especialmente em empresas que utilizam integrações.

## Perguntas Frequentes

### Qual a diferença entre um projeto público e um projeto restrito?

Projetos públicos ficam disponíveis para todos os usuários. Já os projetos restritos podem ser utilizados apenas pelos usuários associados a eles.

### O código do projeto é obrigatório?

Não. O preenchimento do código é opcional.

### Posso criar um projeto sem ativar a funcionalidade?

Não. A opção **Alocação em projetos** deve estar habilitada para que seja possível criar projetos.

### Posso alterar um projeto depois de criado?

Sim. Caso necessário, as informações do projeto podem ser atualizadas posteriormente.
