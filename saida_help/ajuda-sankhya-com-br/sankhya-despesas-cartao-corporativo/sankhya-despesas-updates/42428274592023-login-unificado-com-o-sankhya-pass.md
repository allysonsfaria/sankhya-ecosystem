# Login unificado com o Sankhya Pass!

Agora você acessa o **Sankhya Despesas** e o **ERP Sankhya** com o mesmo login. Com o Sankhya Pass, não é mais preciso guardar duas senhas diferentes para transitar entre os sistemas — um único acesso já leva você de uma plataforma à outra.

![Imagem 1: Agora você acessa o Sankhya Despesas e o ERP Sankhya com o mesmo login. Com o Sankhya Pass, não é mais preciso guardar…](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73240698777/original/DwXFzEsez-oUeuclrrHz9WQ2uv8u6AhpbA.png?1784212356)

## O que muda?

- O **Sankhya Pass** é o mecanismo de login único (SSO) que conecta nativamente o Sankhya Despesas ao ERP Sankhya.
- Com um mesmo acesso, você navega entre as telas do ERP e do Sankhya Despesas sem precisar fazer login de novo a cada troca.
- Acaba a necessidade de manter **duas senhas distintas** — a jornada fica mais fluida e transparente entre as duas plataformas.

**Importante:** o login pelo Sankhya Pass usa exatamente os mesmos dados (e-mail ou CPF) com que você já está cadastrado no ERP Sankhya. Não é criado um cadastro novo nem uma senha separada para o Sankhya Despesas.

## Como funciona na prática

Para usar o login unificado, acesse o Sankhya Despesas pela **plataforma web** e clique em **"Entrar com Sankhya Pass"**. Você será direcionado à tela do Sankhya Pass para confirmar seu **e-mail ou CPF** — use exatamente as mesmas informações do seu cadastro no ERP Sankhya.

Depois de confirmar, você já estará autenticado no Sankhya Despesas, sem precisar preencher senha novamente.

## Perguntas Frequentes

**Preciso criar uma senha nova para o Sankhya Pass?**

Não. Use o mesmo e-mail ou CPF já cadastrado no ERP Sankhya.

**Isso muda a forma como acesso o Sankhya Despesas hoje?**

Sim: em vez de duas senhas separadas, um único acesso passa a valer para as duas plataformas.

**E se eu tiver problema para confirmar meu e-mail ou CPF no Sankhya Pass?**

Verifique se está digitando exatamente os mesmos dados cadastrados no ERP Sankhya. Se o problema continuar, fale com o suporte.
