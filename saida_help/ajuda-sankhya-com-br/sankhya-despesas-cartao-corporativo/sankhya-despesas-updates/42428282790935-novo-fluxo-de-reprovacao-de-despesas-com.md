# Novo fluxo de reprovação de despesas com solicitação de devolução

Agora, quando uma despesa de cartão corporativo é reprovada, o aprovador pode solicitar formalmente a devolução do valor direto pelo Sankhya Despesas — sem perder o rastreamento e sem precisar de controle externo.

![Imagem 1: Agora, quando uma despesa de cartão corporativo é reprovada, o aprovador pode solicitar formalmente a devolução do…](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73240691992/original/z83y_QKyBC1ZD3YSXivwLFbgrIRhNCzPww.png?1784211074)

## O que muda ?

- Ao reprovar uma despesa (total ou parcialmente), o aprovador escolhe se quer ou não solicitar a devolução do valor
- O colaborador é notificado por e-mail e push, e recebe os dados bancários da empresa para fazer o acerto
- Mesmo reprovada, a despesa continua sendo considerada normalmente para fins de integração — já que o gasto de fato aconteceu

## Como funciona na prática

- No relatório, o aprovador reprova a(s) despesa(s) normalmente
- No último nível de aprovação, aparece a opção de gerar ou não a devolução
- Se optar por gerar, o colaborador recebe uma pendência no app para anexar o comprovante da devolução

**Importante:** essa funcionalidade de reprovar e decidir sobre a devolução está disponível para todos os clientes. Já para fins de integração com Sankhya, é necessário atualizar os modelos de integração para que a devolução gere corretamente o lançamento no financeiro. Nesse caso, entre em contato com o nosso suporte para fazer essa atualização.
