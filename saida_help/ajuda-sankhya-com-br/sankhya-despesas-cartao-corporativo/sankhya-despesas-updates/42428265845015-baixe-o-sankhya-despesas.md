## Atenção, time!

No dia 25/08 realizamos a migração para o novo app Sankhya Despesas.

- É simples: a partir de agora, ao acessar o app atual, você será redirecionado automaticamente para a loja de aplicativos.
- Baixe o Sankhya Despesas, faça login com seus dados iguais aos do Espresso e continue usando normalmente.

Confira [neste vídeo](https://www.youtube.com/shorts/-z1MBnrLH4M) como funciona o processo de migração.
