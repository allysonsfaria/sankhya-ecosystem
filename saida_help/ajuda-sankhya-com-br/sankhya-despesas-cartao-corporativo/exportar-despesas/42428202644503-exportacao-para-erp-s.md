## Quando utilizar essa exportação

A funcionalidade de **Exportação para ERP** é ideal para empresas que precisam integrar dados de despesas aprovadas ao sistema contábil ou financeiro. O Sankhya Despesas permite gerar um arquivo padronizado com as informações necessárias para importação em ERPs externos.

## Onde acessar

No menu lateral, vá até **Exportação > Para ERP**.

## Como configurar a exportação

Para gerar o arquivo, você deve configurar os seguintes parâmetros:

- Tipo de data de referência:

  - Data de envio do relatório;
  - Data de aprovação;
  - Data de conclusão;
- Período: selecione o intervalo de tempo correspondente à apuração desejada (ex.: despesas aprovadas no mês anterior);
- Status dos relatórios:

  - Em aprovação;
  - Aprovados;
  - Concluídos.
- Formato do arquivo: por padrão, a exportação é feita em .CSV

## Dica de uso comum

A forma mais frequente de uso dessa funcionalidade é para exportar todas as despesas **aprovadas no mês anterior**. Para isso:

- Selecione **"Aprovado"** como status;
- Escolha **"Data de aprovação"** como tipo de data;
- Defina o período correspondente ao mês anterior;
- Gere o arquivo.
