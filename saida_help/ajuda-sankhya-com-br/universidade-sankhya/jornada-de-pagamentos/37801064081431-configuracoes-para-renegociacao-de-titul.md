# Configurações para renegociação de títulos de despesa

As preferências que podem impactar a rotina de **renegociação de títulos de despesa**.

1. **Preferências:**

- Acesse a tela **Preferências**
  Menu: Configurações » Avançado » Preferências
- No lado esquerdo da tela, no campo (Chave ou descrição e tecle **ENTER**):
- Digite a chave e pressione **ENTER** para carregar as informações.
- **RENEGPARCDIF**: Habilite se quiser permitir renegociação com parceiros diferentes. No campo **Ligado/Desligado**, selecione a opção **Ligado** para a execução do passo a passo.
- **RENDESCMAIOR**: Habilite se quiser permitir renegociação com descontos maiores. No campo **Ligado/Desligado**, selecione a opção **Desligado** para a execução do passo a passo.
- Clique em **Salvar** para registrar.
