# Configurações necessárias para realizar a emissão da carta de correção

Vamos validar algumas informações importantes para realizar a emissão da carta de correção.

1. **Configurações para a Carta de Correção:**

- Acesse a tela **“Modelo de Impressão (Nota/Pedido)”**
  Menu: Comercial » Avançado » Cadastros  » Modelo de Impressão (Nota/Pedido)
- No painel esquerdo, utilize os **filtros** para buscar modelos já cadastrados.
- Clique em **Aplicar** para carregar os modelos disponíveis ou selecione **Baixar Modelos Padrões**.
- Em seguida, escolha a opção **Carta de Correção** e localize o modelo correspondente.

2. **Empresa:**

- Acesse a tela **“Empresa”**
  Menu: Comercial » Preferências » Empresa
- Na Aba **Documentos Fiscais Eletrônicos**, sub-Aba **NF-e/NFC-e**, seção **NF-e**, campo **Relatório de carta de correção**, vincule a carta de correção cadastrada anteriormente.
- Após preencher o campo, clique em **"Salvar"** para registrar a informação.
