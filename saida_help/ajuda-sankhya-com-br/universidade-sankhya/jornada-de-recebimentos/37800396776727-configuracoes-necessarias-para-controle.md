# Configurações necessárias para controle de liberação de crédito com limites por alçada mensal

1. **Configuração de limite mensal para o cliente:**

- Acesse a tela **Parceiros**
  Menu: Configurações » Cadastros » Parceiros
- Localize o cliente desejado.
- Preencha o campo Limite de Crédito Mensal na aba "**Crédito**".
- Salve as alterações.

2. **Configuração de usuário com permissão para liberação:**

- Acesse a tela **Usuários**
  Menu: Configurações » Controle de Acessos » Usuários
- Na tela Usuários, clique no botão Outras Opções **“...”.**
- Selecione a opção Limites para Liberação.
- No pop-up **"Limites para Liberação - <Nome do usuário>"**, clique em Incluir.
- Adicione o **Evento 15 - Limite de Crédito Mensal** e configure os campos de permissão.
- Tipo evento: Valor.
- Limite: O valor do limite R$.
- Tipo de Limite: Mensal.
- Salve a configuração.
