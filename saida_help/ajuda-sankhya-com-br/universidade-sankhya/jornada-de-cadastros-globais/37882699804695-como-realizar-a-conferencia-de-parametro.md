# Como realizar a conferência de Parâmetros

#### O que são os parâmetros do sistema?

As preferências de parâmetros são configurações fundamentais que controlam o comportamento do sistema em diferentes aspectos, desde impressão até integrações com outros módulos. Esta configuração é essencial para o funcionamento adequado do sistema e deve ser feita com atenção aos detalhes e necessidades específicas da empresa.

#### Verifique se os parâmetros estão configurados conforme a sugestão de uso. Caso contrário, ajuste-os para a preparação das jornadas

1. Configuração de **Preferências**

Acesse a tela **Preferências**

Menu: Configurações » Avançado » Preferências

- No campo de pesquisa **“Chave ou descrição e tecle ENTER**” copie a chave **“CONFIGFORMHTML5”**, no campo “**Valor**” selecione “Por usuário (Padrão)”.
- Clique em **“Salvar”** para concluir a alteração.

#### Faça o processo de pesquisa e configuração para os parâmetros destacados abaixo:

- **ENDACESSEXTWGE - Endereço para acesso externo ao WGE** - Informe o link de sua base, exemplo: <https://universidade.sankhya.com.br/mge>
- **DESCRREF - Descrição para Referência** - Informe EAN/GTIN
- **CUSTOPORCONT - Controla Custos por Controle? -** Selecione a opção **Ligado**
- **DIASLIMALTCUSTO - Dias limite para excluir custos -** Informe 360
