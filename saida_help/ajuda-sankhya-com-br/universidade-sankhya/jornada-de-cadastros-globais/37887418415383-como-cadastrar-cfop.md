# Como cadastrar CFOP

## O que é CFOP?

O CFOP (Código Fiscal de Operações e Prestações) é estabelecido pela Receita Federal e é essencial para a impressão de notas fiscais e geração dos livros fiscais. Ele identifica a natureza de circulação da mercadoria ou prestação de serviços, tanto em operações de entrada quanto de saída.

#### Siga o passo a passo para cadastrar CFOP em sua base

1. Acesse a tela **CFOP**

**Menu:** Comercial » Arquivo  » Cadastros » CFOP

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha os campos no Painel Principal

- **Código**: insira o código do CFOP.
- **Observação**: códigos acima de 8000 são tratados como CFPS (serviços sujeitos a ISS).
- **Descrição do CFOP**: informe uma descrição sucinta da operação.

4. Identifique o tipo de CFOP

- Para operações **dentro do estado**: utilize CFOPs que iniciam com **1** e  **5**.
- Para operações **fora do estado**: utilize CFOPs que iniciam com **2** e  **6**.
- **Dica**: Consulte o contador responsável para confirmar a utilização correta conforme cada operação.

5. Finalize o cadastro

- Clique no botão **Salvar** para concluir.
