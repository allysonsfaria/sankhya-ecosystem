# Como cadastrar Endereço

## Qual a importância do cadastro de Endereço?

O cadastro de endereço é essencial para garantir a localização correta de clientes, fornecedores e unidades da empresa, impactando diretamente na eficiência logística, no faturamento, na emissão de documentos fiscais e no atendimento. Um cadastro preciso evita erros operacionais, retrabalho e atrasos em processos como entregas e cobranças.

#### Siga o passo a passo para cadastrar endereços em sua base

1. Acesse a tela **Endereços**

**Menu:** Financeiro » Consultas » Endereços

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha os campos obrigatórios no Painel Principal

- **Código do Endereço** (manual ou automático).
- **Nome do endereço** (descrição para identificação).

4. Preencha os campos na Aba Geral

- **Endereço completo** (nome da via).
- **Tipo do logradouro** (Rua, Avenida, Praça, Alameda etc.).

5. Finalize o cadastro

- Clique no botão **Salvar** para concluir.

#### Observações importantes

- O endereço é independente do cadastro de cidades.
- Não é necessário cadastrar o mesmo endereço para diferentes cidades.
- Uma vez definido o padrão de cadastro, mantenha-o para evitar duplicidades.
- A data de alteração é registrada automaticamente pelo sistema.

#### Recomendações

- Mantenha uma padronização nas abreviações.
- Verifique se o endereço já existe antes de criar um novo.
- Certifique-se de preencher todos os campos obrigatórios.
- Mantenha os dados sempre atualizados.
