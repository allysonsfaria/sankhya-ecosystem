# Como cadastrar Unidades de Medidas

## O que são Unidades de Medidas?

O cadastro de unidades é essencial para padronizar as medidas utilizadas nos produtos do sistema. É possível utilizar várias unidades de medida para um mesmo produto ou serviço, que podem ser empregadas em todos os tipos de movimentação.

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/845374629)

#### Siga o passo a passo para cadastrar Unidades de Medidas em sua base

1. Acesse a tela **Unidades**

**Menu:** Configurações » Cadastros »  Produtos » Unidades

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha os campos no Painel Principal

- **Sigla da Unidade:** informe até 2 caracteres (ex: UN, KG, LT).
- **Descrição**: insira o nome da unidade, facilitando sua identificação nas rotinas do sistema.

4. Configure a Aba Geral (se necessário)

- Marque “**Utiliza no Registro de Volumes WMS**”, se aplicável. Este campo ficará disponível apenas se a preferência da empresa estiver habilitada para **registro de volumes no faturamento**.
- Se a unidade for utilizada em **conferência por peso**, marque a opção “**Utiliza Conferência por peso**”.

5. Finalize o cadastro

- Clique no botão **Salvar** para concluir.

#### Observações importantes

**Uma unidade pode ser configurada como**

- **Unidade Padrão**: utilizada nas movimentações de saída.
- **Unidade de Compra**: representa a forma de compra do produto (quilos, litros, metros, peças, etc.).
- Caso não seja configurada uma unidade de compra, o sistema utilizará a Unidade padrão automaticamente.
