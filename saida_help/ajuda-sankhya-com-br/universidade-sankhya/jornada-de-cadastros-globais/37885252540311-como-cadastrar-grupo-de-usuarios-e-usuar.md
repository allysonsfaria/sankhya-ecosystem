# Como cadastrar Grupo de Usuários e Usuários

## O que são usuários e grupos de usuários no sistema?

O cadastro de usuários é fundamental para garantir a segurança e o controle de acesso ao sistema Sankhya. Os usuários representam os colaboradores que irão executar tarefas no sistema, como rotinas administrativas, financeiras ou comerciais.

Já o cadastro de grupos de usuários permite organizar esses colaboradores conforme o perfil de uso do sistema. Agrupar usuários com funções semelhantes facilita a padronização e a gestão de permissões, garantindo que cada colaborador tenha acesso apenas às funcionalidades necessárias para sua atuação.

#### Realize o cadastro dos Grupos de Usuários

1. Cadastro de **Grupo de Usuários**

- Acesse a tela **Grupo de Usuários**

**Menu:** Configurações » Controle de Acesso » Grupo de Usuários

- Clique em **+ Novo Registro** para iniciar o cadastro e preencha as informações abaixo:
- **Nome**: Defina um nome para o grupo (ex: Vendas, Financeiro, Diretoria, Contábil).
- Marque a opção "**Ativo**" para habilitar o grupo e permitir o uso.

#### Realize o cadastro dos Usuários

1. Cadastro de **Usuários**

- Acesse a tela **Usuários**

**Menu:** Configurações » Controle de Acesso » Usuários

- Clique em **+ Novo registro** para iniciar o cadastro e preencha os campos:
  **Aba Principal**
- **Nome:** Informe o nome do usuário que será utilizado no login.

**Aba Identificação**

- **Senha**: Defina uma senha inicial para o usuário.
- **Grupo**: Selecione o grupo de usuários ao qual ele pertencerá.
- **Empresa**: Informe a empresa vinculada ao usuário.
- **Campos opcionais:** Preencha, se necessário, os dados complementares como:
- **E-mail**
- **Nome completo**
- **CPF**
- **RG**

**Aba Segurança**

- **Marque a opção:** O usuário deve alterar a senha no próximo logon.
- Configure as restrições de acesso, se necessário.
- Clique em **Salvar** (F7) para registrar o novo usuário.

**Configurações adicionais**

- Se o usuário for um vendedor vincule ao cadastro correspondente de vendedor no campo “**Vendedor”**.
- Se for usuário caixa: marque a opção **"Caixa".**
