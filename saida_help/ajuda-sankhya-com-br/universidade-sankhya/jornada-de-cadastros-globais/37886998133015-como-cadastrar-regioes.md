# Como cadastrar Regiões

## O que é cadastro de regiões?

O cadastro correto das regiões é fundamental para uma boa gestão comercial e logística da empresa.

O cadastro de regiões permite segmentar o mercado de atuação em áreas distintas, facilitando:

- Definição de áreas de atuação de vendedores
- Cobrança de frete por região
- Organização da distribuição geográfica
- Gestão de rotas de entrega

#### Siga o passo a passo para cadastrar regiões em sua base

1. Acesse a tela **Máscara para Região**

**Menu:** Configurações » Avançado » Máscaras

- Configure o parâmetro "**Máscara para Região**".
- Defina a **quantidade de níveis** e os **dígitos por nível**. Exemplo: máscara 1.2.2 (nível 1 com 1 dígito, níveis 2 e 3 com 2 dígitos).

2. Acesse a tela **Regiões**

**Menu:** Configurações » Cadastros » Endereços » Regiões

- Clique em **+ Novo Registro**

3. Preencha os campos no painel principal

- **Código**: siga a máscara configurada (use pontos para separar os níveis).
- **Nome**: descreva a região de forma clara.
- Marque como **Ativa**, caso deseje disponibilizar para uso.
- Campo **Analítica**:
- **Marque** se a região **não terá subdivisões**.
- **Desmarque** se ela **possuirá subníveis**.
- Marque o campo "**Último nível**", se a região for terminal na hierarquia.

4. Finalize o cadastro

- Clique no botão **Salvar** para concluir.

#### Observações importantes

- A estrutura de regiões é hierárquica.
- Para alterar a máscara, é necessário excluir todo o cadastro existente.
- O sistema já possui uma estrutura padrão que pode ser aproveitada ou modificada.

#### As regiões impactam em

- Área de atuação de vendedores.
- Definição de preços por região.
- Roteirização de entregas.
- Análises gerenciais.
