# Como cadastrar Critérios de Rateio

## O que é um critério de rateio?

Os critérios de rateio são fórmulas que definem como as despesas e receitas serão divididas entre os centros de resultados da empresa, facilitando a rotina ao evitar a necessidade de digitar novamente todos os dados em cada rateio.

#### Vídeo de demonstração prática no sistema

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/837635876)

#### Siga o passo a passo para cadastrar os critérios de rateio em sua base

1. Acesse a tela **Critérios de Rateio**

**Menu:** Financeiro » Avançado » Critérios de Rateio

2. Inicie um novo cadastro

- Clique em **+ Cadastrar Critério de Rateio**.

3. No Painel Principal

- Preencha o campo **Descrição** com um nome representativo para o critério.
- Clique em **Salvar** para gerar automaticamente o código do rateio.

4. Configure a Sub-Aba Manutenção

- Clique no botão **+** para adicionar uma nova regra (receita/despesa).
- No campo **Cód. Centro Resultado**, defina as regras de divisão entre os centros de resultado.

Finalize clicando em **Confirmar**.

#### Observações importantes

**O critério cadastrado ficará disponível para uso nas telas de:**

- Movimentação financeira
- Central de compras
- Central de vendas
- Movimentações internas

**Ao utilizar um critério cadastrado:**

- As informações são preenchidas automaticamente.
- Podem ser alteradas caso necessário.
- A distribuição pode ser visualizada na aba "**Resultado**".
