# Como cadastrar Produtos

## Por que o cadastro de produtos é importante e o que deve ser considerado ao realizá-lo?

O cadastro de produtos é uma tarefa fundamental no processo de implantação e na rotina das empresas. É importante realizar este cadastro com atenção aos campos obrigatórios e principais configurações para garantir o correto funcionamento do sistema.

#### Vídeo de demonstração prática no sistema

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/838317096)

#### Cadastre os seus produtos conforme passo a passo abaixo, lembre-se de preencher os dados conforme perfil de uso de cada tipo de produto

1. Cadastro de produtos

- Acesse a tela **Produtos**

**Menu:** Comercial » Configuração » Cadastros » Produtos

- Clique em **+ Novo registro** e preencha os campos:

**Aba Geral**

- **Descrição**: Preencha o nome do produto (obrigatório).
- **Ativo**: Marque para permitir que o produto seja movimentado.
- **Complemento**: Informe uma descrição adicional, se necessário.
- **Grupo de Produtos**: Selecione o grupo correspondente.
- **Unidade Padrão**: Defina a unidade principal usada nas vendas.
- **Usado como**: Escolha a aplicação do produto:

Revenda

Fabricação própria

Consumo

Imobilizado

- **Referência do Fornecedor:** Preencha conforme aplicável.
- **Marca**: Informe a marca do produto cadastrada anteriormente.

**Código de Barras**

- **Fornecedor Preferencial:** Defina, se necessário.
- **Origem do Produto:** Selecione se é nacional ou importado.
- **Local Padrão:** Informe o local de armazenagem desse produto no estoque.

**Aba Impostos**

- Marque a opção "**Calcular ICMS**?" conforme a regra fiscal do produto.
- **NCM**: Informe o código NCM (obrigatório para emissão de nota fiscal).
- **Código Sit.Trib.IPI Entrada:** Informe o Código Sit.Trib.IPI Entrada.
- **Código Sit.Trib.IPI Saída:** Informe o Código Sit.Trib.IPI Saída.

**Aba Medidas e Estoque**

- Ative o controle de estoques, se o produto for gerenciado no estoque.
