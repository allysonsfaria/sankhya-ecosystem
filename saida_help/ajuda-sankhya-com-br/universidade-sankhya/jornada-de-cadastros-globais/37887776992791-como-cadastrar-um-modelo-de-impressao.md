# Como cadastrar um Modelo de impressão

## Configuração do Modelo de Impressão

#### Qual o objetivo deste cadastro?

O objetivo do cadastro do Modelo de Impressão é configurar o formato em que documentos como orçamentos, notas fiscais e pedidos serão gerados e impressos no ERP Sankhya. Essa definição garante que a apresentação dos documentos atenda ao padrão visual e às necessidades da empresa, impactando diretamente a forma como essas informações chegam aos clientes.

#### Acompanhe o passo a passo e realize as movimentações no ERP Sankhya

1. **Acesse a tela "Modelo de Impressão Nota/Pedido".**
   Comercial » Arquivo » Cadastros » Modelo de Impressão Nota/Pedido

- Clique no botão "**+**” (**Cadastrar Relatório**)
- Informe a descrição do modelo.
- Classifique em uma categoria se desejar.
- Adicione os arquivos necessários através do botão "Adicionar Arquivo".
- Selecione os arquivos formatados via IReport.

2. Acesse a tela **"Modelos de Nota Fiscal/Duplicatas/Boleto(s)"**
   Configurações » Avançado » Modelos de Nota Fiscal/Duplicatas/Boleto(s)

- Clique no botão “**+**” (**Cadastrar Modelo Nota Fiscal Estoque**)
- Informe o Nome do documento no campo indicado
- Informe o **Número do relatório modelo** correspondente no campo indicado.
- Para modelos personalizados, informe o **Caminho** do arquivo.
  Caso possua um modelo de impressão cadastrado informe “**?**” no campo **Caminho**.
- Selecione **OUTRAS** no campo **Tipo de impressora**.
- Clique no botão “**Salvar**”.

#### Informações complementares

**Verifique se já existe um modelo adequado para orçamentos, caso não exista, você pode:**

- Baixar modelos padrões disponíveis no sistema.
- Utilizar layouts disponíveis no Sankhya Place.
- Criar um novo modelo personalizado.
- Cadastro de Novo Modelo (se necessário).
