# Como cadastrar Grupos de Produtos/Serviços

## O que são Grupos de Produtos/Serviços?

O cadastro de grupos de produtos é essencial para organizar e classificar produtos com características semelhantes, facilitando operações como atualização de preços, análises gerenciais e impressão de listas de preços.

Para que os grupos de produtos/serviços sejam cadastrados corretamente, é necessário configurar previamente a **Máscara para Grupo de Produtos**.

#### Siga o passo a passo para cadastrar grupos de produtos/serviços em sua base

1. Acesse a tela **Grupos de Produtos/Serviços**

**Menu:** Configurações » Cadastros  » Produtos » Grupos de Produtos/Serviços

2. Crie um novo registro

- Clique no botão **+ Novo registro** para iniciar o cadastro.

3. Preencha as informações principais

- Informe o **código do grupo**, respeitando a máscara configurada.
- Descreva o **nome do grupo**.
- Marque o campo **Ativo** para liberar o uso do grupo no sistema.

4. **Aba Geral**

- Defina se o grupo será:

  - **Analítico**: não aceita subgrupos.
  - **Sintético**: permite criação de subgrupos.

5. **Aba Estoque**

- Na seção **Validação**, configure:

  - Campo **Válida Estoque**.
  - Tipo de validação (por empresa, local etc.).

6. **Finalização**

- Clique no botão **Salvar** para concluir o cadastro.

#### Observações importantes

- Apenas grupos ativos podem ser vinculados a produtos.
- Somente grupos analíticos podem receber produtos.
- A estrutura da máscara é fundamental para a organização.
- É possível criar hierarquias de grupos quando necessário.
