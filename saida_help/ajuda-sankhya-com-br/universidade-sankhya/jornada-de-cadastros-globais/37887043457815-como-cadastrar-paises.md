# Como cadastrar Países

## O que é cadastro de Países?

O correto cadastro de países é essencial para o funcionamento adequado de diversas funcionalidades do sistema, especialmente em operações internacionais e integrações governamentais. 

#### Vídeo de demonstração prática no sistema de como cadastrar Países

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/845360017)

#### Siga o passo a passo para cadastrar países em sua base

1. Acesse a tela **Países**

**Menu:** Configurações » Cadastros » Endereços » Países

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.
- Preencha o **código do país**.
- Informe a **descrição** (nome do país).

3. Preencha a Aba Geral

- Campo **País Domicílio Fiscal**: utilize a **tabela do BACEN** baseando-se no **Anexo IX** (Tabela de UF, Município e País).
- Verifique se todas as informações seguem as normas **vigentes**.
- Preencha também o campo **Abreviatura** do país.

4. Finalize o cadastro

- Clique no botão Salvar para concluir o registro.

#### Observações importantes

- O cadastro correto do país é fundamental para operações internacionais.
- As informações devem seguir o padrão BACEN.
- Este cadastro é pré-requisito para estados e cidades do exterior.
- O código do país deve ser único no sistema.
