# Como cadastrar vendedores/compradores

## O que é o cadastro de vendedores/compradores?

O cadastro de vendedores/compradores permite registrar vendedores, compradores, gerentes, representantes, executantes de serviços e supervisores das empresas e filiais. Este cadastro é fundamental para controle de pagamento de comissões e acompanhamento de desempenho de vendas e compras.

#### Siga o passo a passo para cadastrar vendedores/compradores em sua base

1. Acesse a tela **Vendedores/Compradores**

Menu: Configurações » Cadastros » Vendedores/Compradores

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**;
- No campo **Código**, preencha manualmente com o código desejado (ex.: 1, 2, 3.);
- Informe o **Apelido** do vendedor/comprador;
- Marque a opção **Ativo** para habilitar lançamentos.

3. **Aba Geral**

- **Região**: selecione a região cadastrada em que o profissional atuará.
- Preencha os campos:
- **Comissão Venda e Comissão do Gerente**
- **Carga horária**
- **Empresa** vinculada
- **Tipo** (cargo do colaborador)
- **Parceiro**: vincule o cadastro de parceiro já existente.
- Se for utilizado **módulo de folha**, informe também o **código do funcionário**.
- Defina o **Centro de Resultado Padrão**, se necessário.

4. Configurações adicionais (opcionais)

- **Aba Comissão por Grupo/Perfil**: configure comissões por tipo de produto.
- **Aba Parceiros**: vincule os parceiros comerciais.
- **Aba Sequência de Visita**: defina rotas de visita para clientes (caso o recurso esteja habilitado).
- **Aba Grupo de Produtos**: selecione os grupos de produtos comercializados pelo vendedor/comprador.

5. Finalização

- Clique em **Salvar** para concluir o cadastro.

#### Observações importantes

- Apesar de haver muitos campos disponíveis, apenas o apelido e o tipo já são suficientes para identificar um vendedor nas vendas. As demais informações podem ser complementadas posteriormente conforme necessidade.
