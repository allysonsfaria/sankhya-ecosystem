# Como cadastrar Tipos de Títulos

## O que é Tipos de Títulos?

Os **Tipos de Títulos** são cadastros que representam as formas de pagamento ou recebimento utilizadas nos lançamentos financeiros da empresa, como boletos, duplicatas, cheques, dinheiro, cartão de crédito, entre outros.

#### Vídeo de demonstração prática no sistema

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/849463449)

#### Veja abaixo os campos necessários de preenchimento para cadastro de Tipos de Títulos

1. Acesse a tela **Tipo de Títulos**

**Menu:** Financeiro » Arquivo » Cadastros » Tipos de Título

- No **Painel Principal** preencha os campos:
- Configure o campo **"Subtipo"** conforme a natureza do título
- Defina as **características básicas** do tipo de título

**Aba Geral**

- Marque a opção **"Ativo"** para habilitar o uso
- Selecione a **"Espécie"** do título
- Configure a **"Forma de Pagamento TEF"**, se for utilizado cartão
- Defina o **"Tipo de pagamento para NFC-e / NF-e / CF-e"**
- Salve as informações

#### Observações importantes

- O título deve estar ativo para ser utilizado nas operações.
- As configurações de integração são essenciais para o funcionamento correto.
- Verifique a compatibilidade com as formas de pagamento que serão utilizadas.
- Certifique-se que todas as parametrizações obrigatórias foram preenchidas.
