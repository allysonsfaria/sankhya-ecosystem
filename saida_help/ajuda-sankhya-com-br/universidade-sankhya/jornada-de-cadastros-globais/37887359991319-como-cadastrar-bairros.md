# Como cadastrar Bairros

## Qual a importância do cadastro de Bairros?

O cadastro de bairros é importante porque permite a correta identificação e segmentação geográfica dos endereços, o que é essencial para a eficiência das operações logísticas, definição de rotas, atendimento ao cliente e análise territorial. Um cadastro bem estruturado contribui para a precisão nas entregas, redução de erros e melhor organização dos dados cadastrais da empresa.

#### Siga o passo a passo para cadastrar bairros em sua base

1. Acesse a tela **Bairros**

**Menu:** Configurações » Cadastros » Endereços » Cidades

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha os campos obrigatórios no Painel Principal

- **Código do Bairro** (preenchimento automático ou manual).
- **Nome do bairro**.

4. Complete a Aba Geral

- Informe a **Região**, quando aplicável (relacionamento com a hierarquia geográfica).

5. Finalize o cadastro

- Clique no botão **Salvar** para concluir.

#### Observações importantes

- Um bairro serve para todas as cidades (ex: "Centro" é cadastrado apenas uma vez).
- O sistema não permite cadastros duplicados.
- É possível fazer um cadastro rápido de bairro através do Cadastro de Parceiros.
- A busca é independente de letras maiúsculas ou minúsculas.
