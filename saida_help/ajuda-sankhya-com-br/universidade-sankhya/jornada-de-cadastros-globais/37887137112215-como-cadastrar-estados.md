# Como cadastrar Estados

## O que é cadastro de Estados?

O Cadastro de Unidades Federativas (Estados) é fundamental para as operações no sistema, especialmente para comunicação com a SEFAZ e processos comerciais.
O cadastro correto dos estados é essencial para o funcionamento adequado das operações fiscais e comerciais no sistema. 

#### Vídeo de demonstração prática no sistema de como cadastrar Estados

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/845296948)

#### Siga o passo a passo para cadastrar/conferir estados em sua base

1. Acesse a tela **Estados**

**Menu:** Configurações » Cadastros » Endereços  » Estados

2. Visualize os dados principais

- Os **27 estados brasileiros** já vêm **pré-cadastrados** no sistema.
- Cada registro apresenta:
- **Sigla do estado**
- **Nome completo**
- **Código da UF**
- **Código do IBGE**

3. Verifique os dados

- Para cada estado, **confira se as informações estão corretas** com base nas tabelas oficiais da Receita Federal e IBGE.
- Se necessário, **corrija manualmente**.

#### Observações importantes

- Não é necessário cadastrar novos estados, pois todos os estados brasileiros já estão previamente cadastrados.
- Esta configuração é fundamental para outras funcionalidades do sistema, como emissão de documentos fiscais e cadastro de endereços.
- A correta configuração dos estados é especialmente importante para operações que envolvem GNRE e outras obrigações fiscais entre estados.
