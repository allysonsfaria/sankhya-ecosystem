# Como cadastrar NCM

## O que é NCM?

O NCM (Nomenclatura Comum do Mercosul) é um código que identifica a natureza das mercadorias e é fundamental para a emissão correta de notas fiscais.

#### Vídeo de demonstração prática no sistema

[Vídeo: tutorial do artigo](https://player.vimeo.com/video/845285184)

#### Siga o passo a passo para cadastrar NCM em sua base

1. Acesse a tela **Cadastro NCM**

**Menu:** Configurações  »  Cadastros »  Cadastro NCM

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha os dados no Painel Principal

- Digite o **código NCM** (até 8 dígitos), conforme a tabela TIPI vigente.
- Preencha a **descrição do NCM**, de acordo com a nomenclatura oficial.
- Mantenha as informações **verídicas e atualizadas**.

4. Aba Geral (quando necessário)

- Para inativar um NCM, preencha o campo **Data Fim Vigência** com uma **data anterior à atual**.
- Essa ação deve seguir as notas técnicas da SEFAZ.

5. Finalize o cadastro

- Clique no botão **Salvar** para concluir.

#### Observações importantes

- Mantenha os dados sempre atualizados conforme publicações oficiais.
- A inativação de NCMs deve ser feita com cautela para manter o histórico.
- Verifique a vigência antes de utilizar em documentos fiscais.
