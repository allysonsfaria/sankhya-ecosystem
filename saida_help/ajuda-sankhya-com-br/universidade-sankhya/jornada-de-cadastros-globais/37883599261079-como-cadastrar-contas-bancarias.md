# Como cadastrar Contas bancárias

## O que é cadastro de contas bancárias?

O cadastro de contas bancárias é essencial para gerenciar as movimentações financeiras no sistema, permitindo o controle de contas correntes, aplicações e contas internas.

**Observações Importantes:**

- É necessário ter o **banco** e a **agência** previamente cadastrados
- Para contas tipo caixa, configure:
- Tipo de Conta: Caixa(PDV)
- Exclusiva da Empresa: Ativado
- Vincule a empresa e operador quando necessário

##### Siga o passo a passo para cadastrar as contas bancárias em sua base

1. Acesse a tela **Contas**

**Menu:** Configurações » Cadastros » Bancários » Contas

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha os campos obrigatórios no painel principal

- O campo **Código da conta** será gerado automaticamente.
- No campo **Conta**, informe o número completo da conta (incluindo o dígito).
- No campo **Descrição**, insira um nome que facilite a identificação.

Na aba **Cadastros**

- Selecione o **Banco** correspondente.
- Informe a **Agência bancária**.
- Indique a **Empresa** vinculada.
- Marque a opção **Ativa** para liberar o uso da conta.
- Selecione o **Tipo de conta** (Corrente, Poupança etc.).

Configurações adicionais (se necessário)

- Marque a opção **Exclusiva da Empresa**, se aplicável.
- Para contas do tipo **Caixa (PDV)**, defina o **Operador Exclusivo**.

4. Finalize o cadastro

- Clique no botão **Salvar** para concluir o registro.

##### Observações importantes

- Todos os campos com asterisco (**\***) são de preenchimento obrigatório.
- Certifique-se que a agência bancária já esteja cadastrada no sistema.
- Para contas novas, pode ser necessário implantar o saldo inicial.
- Após salvar, o código da conta será gerado automaticamente pelo sistema.
