# Como cadastrar Perfil

## O que são Perfis?

O cadastro de perfil é uma ferramenta importante para segmentação e classificação de clientes e contatos, permitindo uma melhor gestão do relacionamento com clientes e potencializando as atividades de vendas e marketing.
Esta configuração permitirá que o cadastro se torne uma ferramenta estratégica para alavancar as vendas e melhorar o relacionamento com os clientes.

#### Veja abaixo os campos necessários de preenchimento para cadastro de perfil

1. Acesse a tela **Perfil**

**Menu:** Configurações » Cadastros » Perfil

- Clique em **"+ Novo registro"** e preencha:
- **Cód. Perfil**: número identificador (manual ou automático)
- **Descrição**: nome do perfil
- **Analítico**: marque se for um perfil filho
- Para perfil sintético, desmarque a opção "**Analítico**"
- Se o campo "**Ativo**" estiver desmarcado, o perfil não será exibido nos demais cadastros
- Ao criar perfil sintético, as abas **Produtos**, **Parceiros** e **Contatos** ficam desabilitadas

#### Observações importantes

- Perfis analíticos são os únicos aceitos em lançamentos.
- Um parceiro pode estar vinculado a diversos perfis.
- Perfis também são usados para classificar **contatos**.
- Servem para agrupar características como:

Padrões de consumo
Potencial de compra
Interesses específicos
