# Como cadastrar Agência Bancária

## Qual importância do cadastro de agência bancária?

O cadastro de agências bancárias é um requisito essencial para o funcionamento das operações bancárias no sistema, sendo necessário para cadastro de contas, emissão de boletos e intercâmbio de dados.
Esta configuração é fundamental para o correto funcionamento das operações bancárias no sistema, portanto é importante realizar o cadastro com atenção aos detalhes fornecidos pelo banco.

#### Siga o passo a passo para cadastrar as agências bancárias em sua base

1. Acesse a tela **Agências Bancárias**

**Menu:** Configurações » Cadastros » Bancários » Agências Bancárias

2. Inicie um novo cadastro

- Clique em **+ Novo Registro**.

3. Preencha as informações principais

- No campo **Agência**, informe o número com o **dígito verificador**.
- Selecione o **Banco** correspondente (usando código ou nome).
- Preencha o **Nome da Agência** para facilitar a identificação nos cadastros.

4. Adicione informações de contato (opcional)

- Informe os dados do **gerente**.
- Adicione **telefone**, **fax** e **e-mail** **de contato**, se desejar.

5. Preencha os dados de endereço

- Informe o **CEP** (pode usar a lupa para pesquisar).
- Complete os **demais campos de endereço físico** da agência.

6. Finalize o cadastro

- Clique no botão **Salvar** para concluir.

#### Observações importantes

- O código da agência e banco não podem ser alterados após salvar.
- Caso precise corrigir estas informações, será necessário excluir e cadastrar novamente.
- Para contas internas, é necessário cadastrar uma agência fictícia.
- O número da agência deve seguir o padrão definido pelo banco, incluindo zeros à esquerda quando necessário.
