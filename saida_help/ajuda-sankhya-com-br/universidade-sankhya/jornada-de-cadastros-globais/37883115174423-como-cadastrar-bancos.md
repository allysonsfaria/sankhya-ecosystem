# Como cadastrar Bancos

## O que é cadastro de bancos?

É um cadastro fundamental que permite registrar as instituições financeiras que serão utilizadas nos diversos processos do sistema, como contas bancárias, boletos e movimentações financeiras.

Este cadastro serve como base para outras configurações bancárias como agências, contas e integrações, sendo fundamental para o correto funcionamento do módulo financeiro do sistema.

#### Veja abaixo os campos necessários de preenchimento para cadastro de bancos

1. Acesse a tela **Bancos**

**Menu:** Configurações » Cadastros » Bancários » Bancos

- Clique em "**+ Novo Registro**"
- Informe o código do banco conforme o padrão BACEN (3 dígitos)
- Preencha o campo **Abreviatura**
- Na **Descrição** adicione nome oficial do banco
