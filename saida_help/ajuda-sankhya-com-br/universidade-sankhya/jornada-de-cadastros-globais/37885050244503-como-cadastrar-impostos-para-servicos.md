# Como cadastrar Impostos para serviços

## Por que o cadastro de impostos é importante e o que deve ser considerado ao realizá-lo?

O cadastro de impostos é uma etapa crucial na configuração do sistema ERP Sankhya, pois permite que as alíquotas de impostos sejam calculadas automaticamente. Isso inclui impostos como ISS, IRF, PIS, COFINS, CSLL, entre outros. A correta configuração garante que as notas fiscais sejam emitidas com os valores corretos e que as obrigações fiscais sejam cumpridas.

#### Cadastre os impostos conforme passo a passo abaixo. As informações devem ser peenchidos conforme os dados fornecidos.

1. Cadastrar Impostos

- Acesse a tela **IMPOSTOS**

**Menu:** Comercial » Configuração » Cadastros » Impostos

- Clique em **+ Cadastrar imposto** e preencha os campos:
- **Nome:** ex: (IR RETIDO)
- **Ativo:** Marcado
- **Descrição:** IR RETIDO
- **Tipo:** Todos, EXCETO, os com a coluna “calcular” DESMARCADA
- **Tipo Imposto:** IRF
- Clique no botão **Salvar**, para registrar o cadastro.
