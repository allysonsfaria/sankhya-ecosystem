# Configuração de Tipos de Veículo

A tela de **"Tipo de Veículo"** (Logística » Gestão de Frotas » Veículos » Tipo de Veículo) permite classificar os veículos (próprios, terceiros, agregados, etc.) e vincular informações importantes, como naturezas financeiras e percentuais de comissão.

### Campos principais

- **Cód. Tipo Veículo:** este campo é preenchido automaticamente pelo sistema e serve como um identificador único para o registro.
- **Descrição:** este campo deve ser preenchido com uma descrição clara e objetiva para o tipo de veículo. Por exemplo: "PRÓPRIO", "TERCEIRO", "AGREGADO". Esta descrição será usada para identificar o tipo de veículo em outras telas do sistema.

### Aba Geral

- **Natureza:** campo para vincular uma **Natureza** a este tipo de veículo.  O vínculo da natureza é importante para a classificação contábil e financeira das operações, como apropriação de receitas e despesas relacionadas à frota.

### Aba Comissão

Esta aba é utilizada para configurar a política de comissão para o tipo de veículo em questão.

- **Vigência Inicial:** data de início da vigência da regra de comissão. A partir desta data, a regra definida será considerada para os cálculos.
- **Média:** este campo deve ser preenchido com a média de comissão, se aplicável, para o tipo de veículo.
- **% Comissão:** percentual de comissão que será aplicado. Este valor é crucial para o cálculo automático das comissões no módulo de gestão de frotas.
