# Cadastro de Eventos do Pneu

A tela de "**Cadastro de Eventos do Pneu"** (Logística » Gestão de Frotas » Pneus » Motivos p/ Evento de Pneu) é utilizada para registrar os motivos de movimentação ou eventos relevantes no ciclo de vida de um pneu. Essa parametrização é essencial para controlar o histórico, a manutenção e a rastreabilidade dos pneus na frota.

### Funcionalidade da Tela

- **Alimentação Automática:** ao instalar a SOP, a tela é **automaticamente populada** com alguns registros de eventos padrão, como "ENVIO PARA RESSOLAGEM", facilitando o início da operação.
- **Inclusão Manual:** além dos registros pré-carregados, o usuário pode **inserir novos motivos manualmente** conforme a necessidade da empresa, garantindo que todos os eventos relevantes (ex: "MANUTENÇÃO", "DESCARTE", "TROCA") possam ser devidamente registrados.

### Campos Principais

- **Motivo:** este campo exibe o código único atribuído ao evento no sistema. Ele serve como um identificador numérico para o registro.
- **Descrição:** **campo obrigatório** para inserção de uma descrição clara e objetiva para o evento (ex: "ENVIO PARA RESSOLAGEM", "PNEU CALIBRADO", "PNEU DANIFICADO").
