# Cadastro de marca de pneus

A tela de "**Cadastro de Marca"** (Logística » Gestão de Frotas » Pneus » Marca de Pneus) é utilizada para gerenciar e registrar as diferentes marcas especificamente de pneus, que a empresa comercializa ou utiliza. Esta funcionalidade é essencial para categorizar o estoque e facilitar a gestão de produtos por fabricante ou marca.

### Funcionalidade da Tela

- **Alimentação Automática:** ao instalar SOP de logística no sistema Sankhya, alguns registros de marcas de pneus é  **automaticamente importados e preenchidos** na tela, agilizando o processo inicial.
- **Inclusão Manual:** além da alimentação automática, o usuário tem a flexibilidade de **inserir novos registros de marcas manualmente**, caso necessite cadastrar marcas que não foram importadas inicialmente ou que sejam específicas para suas operações.

### Campos Principais

- **Cód. Marca:** este campo exibe o código único atribuído à marca no sistema. Ele serve como identificador principal para o registro.
- **Marca:** campo obrigatório para inserção do nome da marca que está sendo cadastrada (ex: "MICHELIN", "PIRELLI", "GOODYEAR", etc.). É o principal descritor da marca.
