# Cadastro de modelo de pneus

A tela de "**Cadastro de Modelo"** é utilizada para registrar e gerenciar os diferentes modelos de pneus que a empresa utiliza ou comercializa. Esta funcionalidade é fundamental para detalhar ainda mais a classificação do estoque, complementando o cadastro de marcas e permitindo uma gestão mais granular dos produtos.

### Funcionalidade da Tela

Assim como a tela de **"Cadastro de Marca"**, esta tela também conta com um mecanismo de alimentação de dados:

- **Alimentação Automática:** ao instalar a SOP de logística, alguns registros de modelos de pneus podem ser **automaticamente importados e preenchidos** nesta tela, o que acelera o processo de configuração inicial do sistema.
- **Inclusão Manual:** além dos dados importados automaticamente, o usuário tem a flexibilidade de **inserir novos registros de modelos manualmente**, conforme a necessidade.

### Campos Principais

- **Cód. Modelo:** este campo exibe o código único atribuído ao modelo de pneu no sistema. Ele serve como um identificador numérico para o registro.
- **Modelo:** campo obrigatório para inserção do nome ou a descrição completa do modelo de pneu que está sendo cadastrado (ex: "PILOT SPORT 4 S", "DYNAPRO AT2", etc.). É o principal descritor do modelo.
