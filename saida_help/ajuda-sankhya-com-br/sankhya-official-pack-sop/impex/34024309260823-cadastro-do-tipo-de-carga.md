# Cadastro do tipo de carga

A tela de "**Cadastro de Tipo Carga"** é utilizada para definir e registrar os diferentes tipos de carga que a sua empresa opera ou transporta. Essa parametrização é essencial para processos que envolvem o transporte e armazenamento de mercadorias.

### Campos Principais

Na parte superior da tela, estão os campos de identificação do tipo de carga:

- **Carga:** campo que exibe o código único atribuído ao tipo de carga que está sendo cadastrado ou visualizado;
- **Descrição:** nome ou uma breve descrição do tipo de carga (ex: "PALLET", "CAIXA", "GRANEL", etc.). Este é um **campo obrigatório** para a identificação.

###

### Aba Geral

A aba **"Geral"** concentra informações importantes sobre o registro e as características dimensionais do tipo de carga:

- **Usuário:** este campo registra automaticamente o código do usuário que realizou a criação ou a última alteração no registro do tipo de carga;
- **Dt. Alter:** apresenta a data e a hora da última alteração feita neste cadastro. Isso permite um acompanhamento do histórico de modificações.
- **Tamanho:** campo obrigatório para informar o tamanho padrão ou uma dimensão de referência para este tipo de carga (ex: altura, largura, ou um valor representativo de volume/espaço).
- **Capacidade:** campo obrigatório para definir a capacidade associada a este tipo de carga. Pode representar capacidade de peso (em unidades configuradas no sistema) ou capacidade em unidades de medida que serão importantes para o cálculo de ocupação.
