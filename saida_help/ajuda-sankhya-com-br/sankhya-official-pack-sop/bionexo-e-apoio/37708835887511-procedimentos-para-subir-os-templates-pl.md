# Procedimentos para subir os templates (planilhas) na base de dados do site Bionexo

- **Baixar Templates:** O usuário deve realizar o download dos modelos de planilha (templates) separados por categoria.
- **Preenchimento:** Cada planilha deve ser preenchida com as especificações técnicas dos produtos, respeitando rigorosamente as orientações de cada arquivo.
- **Padronização:** É fundamental utilizar o template correto para cada categoria, visto que as colunas são específicas e não devem ser consolidadas em um único arquivo.
- **Atualização de Catálogo:** Antes de efetuar o upload, deve-se inativar os produtos existentes no portal Bionexo para evitar duplicidade com o sistema legado.
- **Upload e Validação:** O arquivo deve ser enviado com o nome original, pois o sistema Bionexo utiliza essa nomenclatura para validar a categoria correta.
- **Movimentação e Manutenção:** Após a importação, as cotações estarão disponíveis para movimentação. **Atenção:** Como não há integração automática para novos cadastros, cada produto novo inserido no Sankhya exige uma manutenção manual correspondente no portal Bionexo.
