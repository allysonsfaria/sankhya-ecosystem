# Tabelas de Frete

Nesta tela, é realizado o cadastro e a gestão das tabelas de frete que serão utilizadas para o cálculo de custos de transporte em diversas rotinas do sistema. Veja abaixo as particularidades dessa tela:

### Painel Principal

Primeiramente, realize as configurações dos campos abaixo:

(1)** Código:** número da nova tabela de frete. O preenchimento deste **campo é obrigatório**.

(1)** Descrição:** descrição da tabela de frete, por exemplo, "Tabela de Frete Nacional - Região Sudeste". O preenchimento deste campo é obrigatório.

(1)** Tipo Cálculo Frete:** este campo define a metodologia de cálculo do frete. As opções pré-definidas para seleção são:

- **Faixa de Distância e Peso:** cálculo considera tanto a distância quanto o peso da carga.
- **Tipo de Veículo e Distância:** cálculo é baseado no tipo de veículo utilizado e na distância percorrida.
- **Tipo de Veículo:** cálculo leva em conta apenas o tipo de veículo.
- **Faixa de Distância:** cálculo é feito por faixas de distância.
- **Faixa de Peso:** cálculo é realizado por faixas de peso.

![Imagem 1: Faixa de Peso: cálculo é realizado por faixas de peso.](https://ajuda.sankhya.com.br/hc/article_attachments/34050926121751)

### Aba Geral

Dentro do Painel Principal, a aba **"Geral"** contém o seguinte campo importante:

- **Tipo Vlr Frete:** este campo define a unidade de medida para o valor do frete. As opções pré-definidas para seleção são:

  - **Tonelada:** valor do frete é por tonelada.
  - **Distância:** valor do frete é por distância.
  - **Fixo/Lotação:** valor do frete é fixo ou por lotação.

![Imagem 2: Fixo/Lotação: valor do frete é fixo ou por lotação.](https://ajuda.sankhya.com.br/hc/article_attachments/34050926122903)

### Aba Valores

Nesta aba, é feito o detalhamento das faixas e valores específicos para o cálculo do frete, conforme o **"Tipo Cálculo Frete"** definido no Painel Principal.

####

#### Seção Superior da Aba Valores:

- **Sequência:** este campo indica a ordem ou a sequência de cada regra de frete cadastrada dentro desta tabela.

### Sub-aba Geral | Aba Valores:

Dentro da aba **"Valores"**, você encontrará uma sub-aba **"Geral"** com os seguintes campos:

- **Peso Inicial:** peso mínimo para que esta regra de frete seja aplicada.
- **Peso Final:** peso máximo para que esta regra de frete seja aplicada.
- **Distância Inicial:** distância mínima para que esta regra de frete seja aplicada.
- **Distância Final:** distância máxima para que esta regra de frete seja aplicada.
- **Vlr Frete Empresa:** valor do frete que será pago pela empresa para esta faixa ou condição.
- **Vlr Frete Motorista:** valor do frete destinado ao motorista para esta faixa ou condição (se aplicável).
- **Usuário:** este campo exibe o usuário que realizou a última alteração na regra de frete.
- **Data Alteração:** este campo exibe a data e hora da última alteração na regra de frete.
- **Tipo de Veículo:** se o **"Tipo Cálculo Frete"** envolver **"Tipo de Veículo"**, selecione o tipo de veículo para o qual esta regra se aplica.
- **Vlr Adicional:** campo para informar um valor adicional no frete, se houver.
- **Vlr Excedente por Kg:** campo para informar um valor adicional por quilograma excedente ao peso padrão, se aplicável.
