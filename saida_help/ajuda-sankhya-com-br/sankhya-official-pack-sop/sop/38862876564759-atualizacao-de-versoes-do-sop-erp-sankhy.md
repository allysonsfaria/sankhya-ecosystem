# Atualização de Versões do SOP – ERP Sankhya

Este documento tem como objetivo orientar a equipe técnica quanto ao procedimento correto para atualização das versões do **SOP** no ERP Sankhya, garantindo segurança, rastreabilidade e conformidade com as regras do sistema.

A atualização pode ser realizada sempre que o sistema apresentar a notificação no sino, localizado no canto superior da tela. O procedimento pode ser executado por qualquer usuário.

#### 1. Pré-requisitos

**(1)** Permissão de acesso à tela **“Minhas Soluções”** (Comercial » Arquivo » Cadastros » Minhas Soluções).

**(1)** Credenciais válidas (usuário e senha).

**(1)** Usuário líder cadastrado e com e-mail atualizado no sistema.

#### 2. Procedimento de Atualização

**2.1 Acesso ao Sistema**

**(1)** Acesse o **ERP Sankhya**.

**(2)** Acesse a tela ''Minhas Soluções'' (Comercial » Arquivo » Cadastros » Minhas Soluções).

**(3)** Faça o login com o usuário e senha.

**(4)** Confirme o login no sistema.

**2.2 Localização do SOP**

**(1)** Identifique o SOP que será atualizado.

**(2)** Verifique a versão disponível para atualização.

**(3)** Confirme se o ambiente está correto (Teste ou Produção).

![Imagem 1: (3) Confirme se o ambiente está correto (Teste ou Produção).](https://ajuda.sankhya.com.br/hc/article_attachments/38863432137623)![Imagem 2: (3) Confirme se o ambiente está correto (Teste ou Produção).](https://ajuda.sankhya.com.br/hc/article_attachments/38863410937111)

**2.3 Execução da Atualização**

**(1)** Clique no botão disponível para o SOP.

**(2)** Selecione a opção **''Iniciar Download''**.

**(3)** Aguarde a conclusão do processamento.

- Se o status apresentado for **“Ativo”**, significa que a atualização foi concluída com sucesso e o sistema encontra-se atualizado.

![Imagem 3: Se o status apresentado for “Ativo” , significa que a atualização foi concluída com sucesso e o sistema encontra-se…](https://ajuda.sankhya.com.br/hc/article_attachments/38863410938391)

#### 3. Procedimento de Liberação de Customização

Durante o processo de atualização, o sistema poderá solicitar uma validação de customização obrigatória. Esta é uma rotina de segurança padrão do Sankhya para garantir a integridade e a conformidade dos dados após a atualização.

**3.1 Geração do Código de Liberação**

**(1)** Clique no botão **“Gerar Código de Liberação”**.

- O sistema enviará automaticamente um código para o e-mail do usuário líder cadastrado.

![Imagem 4: O sistema enviará automaticamente um código para o e-mail do usuário líder cadastrado.](https://ajuda.sankhya.com.br/hc/article_attachments/38863410939287)
