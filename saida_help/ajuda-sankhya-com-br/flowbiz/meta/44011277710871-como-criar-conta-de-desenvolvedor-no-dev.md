# Como criar conta de Desenvolvedor no Developers - META

Para utilizar certas ferramentas e integrações, é necessário ter uma **conta de desenvolvedor na plataforma da Meta.** Siga o passo a passo abaixo para verificar se você já possui o acesso ou para criar uma nova conta.

## 🔍 Passo Inicial: Verificar se você já possui uma conta

Nem todos os usuários precisam criar uma nova conta. Antes de começar, faça a verificação:

1. Acesse o site do [Meta for Developers](https://developers.facebook.com/).
2. Olhe para o **menu superior direito** da tela:

   - **Se aparecer "Entrar", "Acessar" ou "Meus Apps":** Você já possui uma conta! **Pule este tutorial** e siga para a próxima etapa do seu procedimento.
   - **Se aparecer "Começar":** Você ainda não tem uma conta ativa. Siga o passo a passo abaixo para criá-la.

---

## 🚀 Passo a Passo para Criar a Conta

Caso o seu botão no menu superior direito seja o **"Começar"**, siga as instruções:

**1. Iniciar o Cadastro**

Clique no botão **"Começar"** no menu superior direito da página do Meta for Developers.

**![Imagem 1: 2. Vinculação com o Facebook](https://ajuda.sankhya.com.br/hc/article_attachments/44011238114839)2. Vinculação com o Facebook**

Se o sistema solicitar o login, entre com a sua conta do Facebook e clique em **"Continuar"** para autorizar a criação da conta de desenvolvedor.

**![Imagem 2: 3. Verificação de Telefone](https://ajuda.sankhya.com.br/hc/article_attachments/44011230868503)3. Verificação de Telefone**

- Insira o seu número de **telefone pessoal** (ele será utilizado apenas para a segurança e validação da conta).
- Clique no botão **"Enviar SMS para verificação"**.
- Insira o código recebido por mensagem no campo indicado para validar o número.

> ⚠️ **Nota:** É fundamental utilizar um número de telefone celular ativo e que esteja em mãos para receber o código SMS imediatamente.

**![Imagem 3: 4. Confirmação de E-mail](https://ajuda.sankhya.com.br/hc/article_attachments/44011246459287)4. Confirmação de E-mail**

- Confira se o endereço de e-mail exibido na tela é um e-mail ao qual você tem acesso.
- Se estiver correto, marque a opção de **concordância com os termos da plataforma**.
- Clique em **"Confirmar e-mail"**.

**![Imagem 4: 5. Seleção de Perfil](https://ajuda.sankhya.com.br/hc/article_attachments/44011246696599)5. Seleção de Perfil**

Na última etapa, o sistema perguntará qual opção melhor descreve a sua função:

- Selecione a opção **DESENVOLVEDOR**.
- Clique em **"Concluir Inscrição"**.

![Imagem 5: Clique em "Concluir Inscrição" .](https://ajuda.sankhya.com.br/hc/article_attachments/44011231626135)

**Pronto!** Sua conta de Desenvolvedor no Meta foi criada com sucesso. Agora você pode prosseguir para a próxima etapa de configuração.
