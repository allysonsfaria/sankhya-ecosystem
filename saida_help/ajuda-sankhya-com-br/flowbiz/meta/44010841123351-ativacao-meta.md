# Ativação Meta

Para realizar a **integração Meta**, é necessário garantir que toda a configuração inicial da conta esteja correta. Antes de iniciar o passo a passo, verifique se você possui os requisitos obrigatórios e acessos necessários.

## Requisitos essenciais:

- Cliente com conta empresarial na META
- Número de telefone **EXCLUSIVO** para o uso do WhatsApp Business API (Não pode ter conta Whatsapp Business, nem Whatsapp convencional, preferencialmente um número NOVO);
- Acesso ao painel gerenciador de negócios da META: <https://business.facebook.com/>

## Iniciando o Processo de Ativação!

**1.** Criar a conta no Gerenciador de negócios

**2.** Criar o aplicativo do WhatsApp para integração com o Jornadas: Acesse o [portal desenvolvedor do Facebook](https://developers.facebook.com/apps/)
