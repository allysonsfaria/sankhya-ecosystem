# Como inserir/trocar a foto de perfil no WhatsApp API

Siga este passo a passo para inserir ou trocar a foto de perfil no WhatsApp API.

1. Acesse o seu perfil <https://business.facebook.com/>
2. Clique na Engrenagem "Configurações do negócio"
