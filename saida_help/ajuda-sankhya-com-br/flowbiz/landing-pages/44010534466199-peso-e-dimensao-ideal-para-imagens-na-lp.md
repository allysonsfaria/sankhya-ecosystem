# Peso e dimensão ideal para imagens na LP

Confira o peso e as dimensões das imagens para sua LP

**1.** Acesse a edição da sua LP > Clique no ícone **adicionar imagem**

**2.** Irá abrir um PopUp onde você poderá adicionar as imagens

![Imagem 1: 2. Irá abrir um PopUp onde você poderá adicionar as imagens](https://ajuda.sankhya.com.br/hc/article_attachments/44010572255127)

![Imagem 2: 2. Irá abrir um PopUp onde você poderá adicionar as imagens](https://ajuda.sankhya.com.br/hc/article_attachments/44010556675607)

## Peso das imagens

- **Peso máximo:** aproximadamente 10MB
- **Peso indicado:** até 100KB

## Dimensão das imagens de fundo para Desktop

- **Proporção das imagens:** 16:9
- **Resolução mínima:** 1920x1080 pixels
- **Resolução ideal:** 2580x1080 pixels

## Dimensão das imagens de fundo para Mobile

- **Proporção das imagens:** 9:16
- **Resolução mínima:** 360 pixels de largura (altura varia de acordo com o tamanho do bloco)
- **Resolução ideal:** 720 pixels de largura (altura varia de acordo com o tamanho do bloco)

Caso restar alguma dúvida, não hesite em nos chamar no chat da ferramenta.
