# Como visualizar uma campanha enviada

Para visualizar qualquer campanha, basta clicar no menu **Campanhas** > Em **Categorias**, você pode escolher se deseja visualizar campanhas já **enviadas/rascunhos/agendadas/pausadas ou em Envio**.

No canto direito, você conseguirá ver o **Desempenho** de cada campanha, terá acesso a dados como abertura, cliques, bounces, entre outros:
