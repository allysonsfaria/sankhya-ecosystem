# Criação de campanha com o Editor Clássico HTML

O Editor HTML é recomendado para os usuários com conhecimentos técnicos, que já possuem uma campanha pronta em código HTML, possibilitando uma maior flexibilidade na customização do layout dos e-mails.

Para utilizar o editor HTML, é necessário acessar o menu Campanhas > Criar nova Campanha >  Ir para o editor do conteúdo > Selecionar **Editor HTML**

![Imagem 1: Para utilizar o editor HTML, é necessário acessar o menu Campanhas > Criar nova Campanha > Ir para o editor do conteúdo…](https://ajuda.sankhya.com.br/hc/article_attachments/44010471347991)

Após selecionado, irá abrir um PopUp onde você poderá inserir o código clicando no símbolo **<> Código-fonte**

![Imagem 2: Após selecionado, irá abrir um PopUp onde você poderá inserir o código clicando no símbolo <> Código-fonte](https://ajuda.sankhya.com.br/hc/article_attachments/44010456043415)

\*Antes de incluir o seu código, podes excluir o conteúdo atual. Este é apenas um exemplo. Com o código pronto, ao clicar em Salvar o conteúdo da campanha irá aparecer no espaço que antes estava em branco.

![Imagem 3: *Antes de incluir o seu código, podes excluir o conteúdo atual. Este é apenas um exemplo. Com o código pronto, ao…](https://ajuda.sankhya.com.br/hc/article_attachments/44010447380631)

![Imagem 4: *Antes de incluir o seu código, podes excluir o conteúdo atual. Este é apenas um exemplo. Com o código pronto, ao…](https://ajuda.sankhya.com.br/hc/article_attachments/44010447631255)

Lembrando que é necessário inserir a **variável de** **descadastro** no seu código. Acrescentar a variável **%Link:Unsubscribe%** dentro de **href**

**Exemplo:  [descadastre aqui](https://ajuda.sankhya.com.br/hc/pt-br/articles/%Link:Unsubscribe%) .**

Assim que a campanha estiver pronta, basta clicar em "Salvar Alterações". E continuar as configurações normais de Revisão e Agendamento!

Qualquer duvida, só nos acionar.
