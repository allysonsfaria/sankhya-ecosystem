# Como inserir o link de descadastramento

Todas as campanhas **devem incluir o link de descadastramento**. Além de manter sua lista de e-mails mais saudável e atualizada, essa prática ajuda a reduzir a taxa de reclamações por spam. Ao oferecer uma forma simples para que os destinatários deixem de receber suas mensagens, você melhora a experiência do usuário e contribui para a reputação dos seus envios. Para isso, basta adicionar um link de descadastramento em seus e-mails.

Para inserir o link, siga o passo a passo do editor que está usando:

## Editor Drag and Drop

No final da campanha, **selecione o texto** que mais se adapte para inserir o link → Com o texto selecionado **clique** no ícone **corrente** no menu superior:

![Imagem 1: No final da campanha, selecione o texto que mais se adapte para inserir o link → Com o texto selecionado clique no…](https://ajuda.sankhya.com.br/hc/article_attachments/44010670838167)

Feito isso, **dê um clique onde adicionou o link** e o **menu** a **esquerda** irá se abrir, em **links** → selecione **cancelar inscrição** → e adicione o **título para o seu link**.

![Imagem 2: Feito isso, dê um clique onde adicionou o link e o menu a esquerda irá se abrir, em links → selecione cancelar…](https://ajuda.sankhya.com.br/hc/article_attachments/44010712681111)

Agora está tudo pronto, seu link de descadastro foi inserido com sucesso no editor Drag and Drop.

## Editor Clássico HTML

Para o editor HTML é necessário somente **inserir a variáve**l de descadastro **no seu códig**o, se seu HTML já estiver pronto, você só precisa acrescentar a seguinte variável dentro de href:

- **%Link:Unsubscribe%**

## Editor a partir de uma URL

Segue o mesmo processo do editor HTML: é necessário inserir a variável de descadastro no código.

- **%Link:Unsubscribe%**

Caso ainda tenha alguma outra dúvida, só nos chamar no chat da plataforma.
