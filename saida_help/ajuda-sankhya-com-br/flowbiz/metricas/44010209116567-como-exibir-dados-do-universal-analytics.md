# Como exibir dados do Universal Analytics após a conexão com o GA4

Este recurso é aplicável apenas para aqueles que já tinham o Universal Analytics conectado à Flowbiz.

Com o GA4 já conectado na Flowbiz, vá em **Relatórios** >  **Analytics** > **Configurações**

![Imagem 1: Na sequência é só preencher o “ID da vista da propriedade UA” e a data do “Último mês de dados no UA”:](https://ajuda.sankhya.com.br/hc/article_attachments/44010255045783)Na sequência é só preencher o “ID da vista da propriedade UA” e a data do “Último mês de dados no UA”:

- Obtenha o ID da vista da propriedade: Para garantir a correta conexão, você precisará do ID da vista da propriedade do Universal Analytics que estava conectado anteriormente na Flowbiz. Para encontrá-lo, acesse sua conta do Google Analytics no perfil UA, vá para a seção "Administrador" e clique em "Configurações da vista da propriedade". Lá, você encontrará o ID da vista da propriedade necessário para a busca dos dados.

Lembre-se de que é essencial ter o Universal Analytics conectado à Flowbiz anteriormente para usar esse recurso de busca de dados históricos.
