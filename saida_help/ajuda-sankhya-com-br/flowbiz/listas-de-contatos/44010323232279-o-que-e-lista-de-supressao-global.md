# O que é lista de "Supressão Global"?

Esta é a lista para onde vão **todos os e-mails identificados como "Hard bounced"** nos envios das suas campanhas. Todos os e-mails que estão nesta lista não receberão mais nenhuma campanha, mesmo que tenham sido adicionados novamente em qualquer uma de suas listas.

**OBS:** O contato não é removido da lista original. Ele apenas permanece bloqueado para não receber novas campanhas. Caso você exporte os contatos, ele continuará aparecendo na lista.

## O que é "Hard Bounce"?

Hard Bounces são e-mails que um dia existiram, mas hoje não existem mais e podem estar em uma de suas listas comprometendo a entrega de suas campanhas. Ao receber um aviso do provedor dizendo que este e-mail é um Hard Bounce, automaticamente a ferramenta faz uma higienização e inclui este na lista de supressão global, assim, evitando que novas campanhas sejam enviadas para estes e-mails.

Para saber como adicionar contatos manualmente nesta lista, [clique aqui.](https://cloudchat5.cloudhumans.com/hc/central-de-ajuda-flowbiz/articles/1768495584-como-excluir-descadastrar-contatos)

Em caso de dúvidas, não hesite em nos acionar no chat da ferramenta!
