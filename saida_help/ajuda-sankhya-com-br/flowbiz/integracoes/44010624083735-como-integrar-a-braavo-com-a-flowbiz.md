# Como integrar a Braavo com a Flowbiz.

Para integrar a **Braavo** com a **Flowbiz**, precisamos de algumas **credenciais API.** Para gerá-las deverá acessar:
**Serviços ou transmissão > API Braavo > Adicionar**

![Imagem 1: Para integrar a Braavo com a Flowbiz , precisamos de algumas credenciais API. Para gerá-las deverá acessar: Serviços ou…](https://ajuda.sankhya.com.br/hc/article_attachments/44010620502935)

Após preencher os campos **(não precisará preencher a URL de Pedido)** e clicar em **Gravar**, terá em mãos os **Tokens API:** 
**API Key
API Token**
**Pronto 👏 Agora basta enviar as informações** pelo e-mail: [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)

Em caso de dúvidas, não hesite em nos acionar pelo chat da ferramenta
