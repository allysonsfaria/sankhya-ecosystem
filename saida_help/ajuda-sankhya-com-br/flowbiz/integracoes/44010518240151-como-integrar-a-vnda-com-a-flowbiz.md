# Como integrar a VNDA com a Flowbiz.

## Para integrar a VNDA com a Flowbiz, vamos precisar de alguns dados importantes: Como criar um token de acesso

Siga este passo a passo para gerar um token de acesso para um usuário:

1. Acesse o **painel administrativo** (Admin)
2. No canto inferior esquerdo, **clique no ícone ⚙ (engrenagem)** para acessar as **Configurações**.
3. Dentro das Configurações, localize a seção **Integrações** e clique na opção **API**.
4. **Clique no botão +** para iniciar a criação de um novo token.
5. **Preencha os dados do responsável:**

   Insira o **Nome** **(Flowbiz)** e o **E-mail:** [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)  que será responsável pelo uso do token.
6. Clique no botão **Continuar** para seguir para as opções de permissão.
7. **Conceda apenas as permissões** (escopos) estritamente necessárias:
   **Pedidos** (apenas ações obter, lista e listar)
   **Clientes** (apenas ações obter, lista e listar) 
   **Produtos** (apenas ações obter, lista e listar)
8. **Salve o token:**

Pronto! Sua chave API foi criada automaticamente.

**Basta encaminhar ao time de suporte técnico**, pelo e-mail: [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)

Agora é só aguardar o desenvolvimento da integração pelo time técnico da Flowbiz.
