# Como integrar a Linx com a Flowbiz.

## Confira o passo a passo de como gerar credenciais na plataforma Linx. Siga este guia para criar as credenciais de acesso de forma prática:

**1. No canto superior direito acesse a lupa de pesquisa**

**2. No campo de busca, digite "usuários". A opção que você precisa será a segunda na lista.**

![Imagem 1: 2. No campo de busca, digite "usuários". A opção que você precisa será a segunda na lista.](https://ajuda.sankhya.com.br/hc/article_attachments/44010464727063)

**3. Adicione um novo usuário:** Clique no botão azul com o texto **"Adicionar usuário"** para começar o processo de criação.

![Imagem 2: 3. Adicione um novo usuário: Clique no botão azul com o texto "Adicionar usuário" para começar o processo de criação.](https://ajuda.sankhya.com.br/hc/article_attachments/44010506931991)

**4. Preencha os dados solicitados:** Na nova tela que será aberta, insira as informações necessárias, como nome, e-mail e outras credenciais do usuário.

![Imagem 3: 4. Preencha os dados solicitados: Na nova tela que será aberta, insira as informações necessárias, como nome, e-mail e…](https://ajuda.sankhya.com.br/hc/article_attachments/44010465181335)

**5. Recupere as informações essenciais:** Após concluir, guarde apenas os **dados de usuário e senha**, pois são esses que serão utilizados posteriormente.

**OBS:** **O Web Site ID** é uma informação importante para podermos saber a origem de cada cadastro, por exemplo, a versão mobile **pode** ter o id 2 e site desktop o id 1.
É necessário confirmar com o cliente quais canais/sites recebem cadastros. Sem isso, a integração pode puxar apenas parte da base.

**6.** O **Web Site ID** pode ser encontrado diretamente no painel administrativo da Linx, no menu **Canais**.

![Imagem 4: 6. O Web Site ID pode ser encontrado diretamente no painel administrativo da Linx, no menu Canais .](https://ajuda.sankhya.com.br/hc/article_attachments/44010465511063)

Com as credenciais de acesso **(usuário e senha)** e o **Web Site ID** em mãos, basta encaminhar essas informações para o time de suporte técnico da Flowbiz pelo e-mail: [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)
