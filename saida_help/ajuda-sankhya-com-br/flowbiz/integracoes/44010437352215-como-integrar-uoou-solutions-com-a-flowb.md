# Como integrar Uoou Solutions com a Flowbiz.

Para integrar sua loja **Uoou Solutions** com a Flowbiz, vamos precisar de alguns dados importantes como:
**Channel Code e Token**
Para gerá-los basta acessar:
O menu **"API de Integração"**

![Imagem 1: Para integrar sua loja Uoou Solutions com a Flowbiz, vamos precisar de alguns dados importantes como: Channel Code e…](https://ajuda.sankhya.com.br/hc/article_attachments/44010422056599)

Clicar no botão **"Criar Token de Integração"**

![Imagem 2: Clicar no botão "Criar Token de Integração"](https://ajuda.sankhya.com.br/hc/article_attachments/44010417979287)

Quando o formulário aparecer, você verá alguns campos para preencher. Veja o que é necessário fazer em cada um deles:

- **Token de Integração:** Este código será gerado automaticamente, mas se você preferir, pode alterá-lo e colocar um valor personalizado. O token serve como chave para conectar sua aplicação à API de forma segura.
- **Selecione o Usuário:** Agora, é necessário escolher um "Usuário" para vincular a esse token. Além disso, os acessos aos **endpoints** da **API** de Integração serão liberados conforme as **permissões** desse **usuário**. Verifique as permissões do usuário selecionado para o sucesso da integração.
- ## Finalizando a Criação:

Depois de preencher todos os campos, clique em **"Criar"**. E pronto! O token de integração estará gerado e você já pode usá-lo para autenticar suas requisições na nossa API de Integração.

Para conseguir o **Channel Code**, **acesse Canais:**

![Imagem 3: Para conseguir o Channel Code , acesse Canais:](https://ajuda.sankhya.com.br/hc/article_attachments/44010437778199)

E na listagem de canais, você poderá verificar o "**Código**":

![Imagem 4: E na listagem de canais, você poderá verificar o " Código ":](https://ajuda.sankhya.com.br/hc/article_attachments/44010418439831)

## Prontinho! 👏

Tendo em mãos o **Token** e o **Channel\_Code**, basta encaminhar ao time de **suporte técnico**, pelo e-mail: [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)
