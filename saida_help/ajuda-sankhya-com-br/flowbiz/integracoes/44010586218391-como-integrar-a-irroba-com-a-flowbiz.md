# Como integrar a Irroba com a Flowbiz.

Confira como integrar a Irroba com a Flowbiz, para isso, você pode:

Acessar o menu **Usuários**, localizado na barra lateral, e selecione **Usuários API**.

![Imagem 1: Acessar o menu Usuários , localizado na barra lateral, e selecione Usuários API .](https://ajuda.sankhya.com.br/hc/article_attachments/44010586574615)

Em seguida, clique em **Adicionar** para criar um novo usuário.

Insira seu **e-mail** e **nome de usuário** no formulário correspondente.

![Imagem 2: Insira seu e-mail e nome de usuário no formulário correspondente.](https://ajuda.sankhya.com.br/hc/article_attachments/44010630957719)

Clique no botão **Gerar** para criar automaticamente uma senha segura para o novo usuário.

Para que os contatos sejam importados corretamente para a Flowbiz, é necessário que a opção **"Habilitar Newsletter no Cadastro"** esteja ativada na Irroba.
Para verificar:
**Configurações → Configurações da Loja → Configurações Gerais**
Pesquise por **"Habilitar Newsletter no Cadastro"** e confirme que a opção está marcada como **Ativado**.
⚠️ Caso esta configuração esteja desabilitada, os contatos serão retornados sem opt-in e não serão importados pela Flowbiz.

Após preencher os campos de Email, Usuário e Gerar a senha, clique em **Salvar**. Assim, você poderá copiar o **usuário** e a **senha gerada** para utilizar na integração aqui com a Flowbiz!

Prontinho! 👏
