# Como integrar a Flowbiz com a Loja Integrada.

Para integrar seu e-commerce na Loja Integrada conosco, precisamos de alguns dados importantes!

Para ter acesso a estes dados, primeiramente:

1. Abra o menu **Configurações** na sua loja e clique em **Chave para API**.
2. Clique no botão **Cadastrar nova chave**.

![Imagem 1: Clique no botão Cadastrar nova chave .](https://ajuda.sankhya.com.br/hc/article_attachments/44010610495255)

1. Digite um nome para sua chave no campo **Identificação da Chave**. Dica: use um nome que ajude você a lembrar para que serve essa chave. Exemplo: **Flowbiz** e clique em Salvar.
2. Pronto! Sua chave API foi criada automaticamente.

Basta encaminhar ao time de suporte técnico, pelo e-mail: [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br).
