# Como integrar a Flowbiz com a Yampi.

Para integrar a **Yampi** com a **Flowbiz**, vamos precisar de alguns dados API.
Para gerar as credenciais na **Yampi**, é bem simples, basta ir em:

- No **ícone** da conta, que fica no canto superior direito;
- Credenciais API;
- Nessa tela irá aparecer todas as informações no qual é preciso para ser feito a integração.

![Imagem 1: Nessa tela irá aparecer todas as informações no qual é preciso para ser feito a integração.](https://ajuda.sankhya.com.br/hc/article_attachments/44010479914391)

Pronto! Sua chave API foi criada automaticamente.

Basta encaminhar ao time de suporte técnico, pelo e-mail: [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)

Em caso de dúvidas, não hesite em nos acionar via chat da ferramenta
