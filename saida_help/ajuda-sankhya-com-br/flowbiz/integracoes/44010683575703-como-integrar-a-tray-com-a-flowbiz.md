# Como integrar a Tray com a Flowbiz.

Integrar a Flowbiz com a plataforma Tray otimiza o envio de campanhas de e-mail marketing, facilita a segmentação de clientes e aumenta a eficiência nas estratégias de vendas e engajamento.
Para integrar a sua plataforma **Tray** conosco, siga este passo a passo:

- Acesse o **painel de aplicativos** da **Tray**, e pesquisar por: **Flowbiz**.
- Após encontrar o aplicativo, clique em Instalar aplicativo.
- Após, instalar o aplicativo, precisará conceder as permissões necessárias para o envio dos tokens API para a realização da integração:

![Imagem 1: Após, instalar o aplicativo, precisará conceder as permissões necessárias para o envio dos tokens API para a realização…](https://ajuda.sankhya.com.br/hc/article_attachments/44010692276247)

Concluindo e autorizando o aplicativo, poderá habilitar a integração após clicar em **Enviar Credenciais**, onde nosso time de suporte técnico irá receber e prontamente integrar sua loja conosco 🙂.

**Pronto!** 👏

Agora basta aguardar nossa equipe realizar a integração!
