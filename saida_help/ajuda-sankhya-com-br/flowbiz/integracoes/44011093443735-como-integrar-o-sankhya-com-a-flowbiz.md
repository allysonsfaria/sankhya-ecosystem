# Como integrar o Sankhya com a Flowbiz

Este tutorial explica como habilitar a integração com a Flowbiz e gerar o token necessário para configuração.

## 🔐 Passo 1: Habilitar a integração com a Flowbiz

Você pode acessar essa opção por qualquer um dos caminhos abaixo:

## 👉 Opção 1 (acesso rápido)

1. Clique no ícone do usuário no canto superior da tela
2. Selecione "Integrar com produtos Sankhya"

## 👉 Opção 2 (menu do sistema)

1. Acesse:
   Comercial » Arquivo » Cadastros » Integrar com Produtos Sankhya

![Imagem 1: Acesse: Comercial » Arquivo » Cadastros » Integrar com Produtos Sankhya](https://ajuda.sankhya.com.br/hc/article_attachments/44011072276247)

## Após acessar a tela

1. Localize a opção **Flowbiz**
2. Clique em **"Habilitar Integração"**

🔑 Passo 2: Copiar o token de integração

1. Acesse a tela **"Configurações Gateway"**
2. Localize a aplicação:
3. **Aplicação:** MAILBIZ
4. **Parceiro/Fornecedor:** MAILBIZ TECNOLOGIA DA INFORMACAO LTDA
5. Selecione a aplicação
6. Copie o **token de integração**

![Imagem 2: Copie o token de integração](https://ajuda.sankhya.com.br/hc/article_attachments/44011072447639)

## Imagem 3: 📤 Passo 3: Enviar o token para a Flowbiz📤 Passo 3: Enviar o token para a Flowbiz

Após copiar o token, envie um e-mail para:

📧 [tokens@flowbiz.com.br](mailto:tokens@flowbiz.com.br)

## 📌 No e-mail, informe:

- Token de integração (copiado completo)
- Nome da empresa/conta
- CNPJ

## ⚠️ Importante

- O token deve ser enviado em formato de texto (não envie print)
- Certifique-se de copiar o token completo

## 🚀 Pronto!

Após o envio, nosso time irá finalizar a configuração da integração.
