# Analytics Studio

Você também pode criar painéis com inteligência artificial em segundos, usando um comando simples.

### Page Builder

O [Page Builder](https://ajuda.sankhya.com.br/hc/pt-br/articles/25648251050647-Analytics-Studio#PageBuilder) é a ferramenta principal para criar suas telas, sejam elas para computador ou celular. Com ele, você arrasta e solta elementos de forma fácil e rápida, montando suas aplicações de maneira eficiente.

O Page Builder está dividido nas seguintes seções principais:

#### Componentes

Aqui você encontra todos os elementos que pode usar para montar sua interface, como botões, gráficos, textos e tabelas. Eles são organizados em categorias, como Análise de Dados, Design, Processos, Navegação, Funcionalidades e Inputs.

Cada componente segue três passos principais:

- **VIEW**: defina de onde virão os dados que o componente vai usar. Esses dados podem ser das VIEWs do **Analytics AI** (uma forma de fazer consultas sem precisar de código) ou diretamente de consultas SQL.
- **Personalização**: ajuste o visual, o design e as funções específicas de cada componente.
- **Interações**: configure o que o componente faz, como abrir formulários, realizar ações no banco de dados, ou outras ações sem precisar de código.

Essas três etapas são a base para construir no **Analytics AI**. Ao entendê-las, você conseguirá configurar qualquer componente disponível na plataforma.

#### Configurações

Esta seção, localizada à direita da tela, permite que você faça ajustes que valem para toda a sua interface. As opções incluem:

- **Filtros**: configure seleções que afetam toda a tela que o usuário final não pode mudar.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=ZTruJDZM4ak)

- **Barra de Filtros**: adicione uma barra onde o usuário pode fazer seleções temporárias, que vêm depois das seleções principais.
- **Configurações da Tela**: permite que você publique ou despublique uma tela, mude seu tipo (para web, mobile ou painel), a cor de fundo e a altura da tela.
- **View da Tela**: uma visão centralizada cujos valores podem ser usados por outros componentes, como textos e botões.

#### Tela

A **Tela** é a área principal onde você organiza e configura os componentes. É o espaço onde você monta a interface final e vê em tempo real as mudanças que está fazendo.

Após arrastar um componente para a tela, você pode ajustá-lo de duas formas: usando os três ícones (View, Personalizar e Interações) que aparecem quando você passa o mouse sobre ele, ou pelo menu que aparece ao clicar com o botão direito no componente. As opções mais comuns são:

- **Configurações (VIEW, Personalizar, Interações)**: de onde vêm os dados, como é o visual e o que o componente faz.
- **Para Frente e Para Trás**: ajusta a ordem de camadas do componente, ou seja, se ele aparece na frente ou atrás de outro.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=2k5XytoUOZA)

- **Deletar, Duplicar e Copiar**: ferramentas para organizar seus componentes do jeito que precisar. Para mais informações, consulte a documentação de layouts de componentes.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=j6Qe1cEJHTw)

- **Agrupar, Desagrupar, Alinhar, Padronizar, Bloquear e Congelar**: mais ferramentas para organizar o layout dos componentes.

Além disso, você pode mudar o tamanho dos componentes arrastando os quadrados cinzas que aparecem em volta deles.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=4etRD6SwrxM)

### Barra de Filtros

A **Barra de Filtros** permite que os usuários criem, editem e usem filtros em suas telas de forma flexível, adaptando a aparência para o que for mais útil para o seu negócio.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=JuKejEx5RYk)

Para configurá-la, siga os seguintes passos:

1. No **Page Builder**, selecione a opção para criar ou editar uma Barra de Filtros. Você será levado para a tela de **Configurações**.
2. Clique em **"+Adicionar"** filtros e dê um nome a ele.
3. Em seguida, na coluna **Dimensões**, escolha quais informações disponíveis podem ser incluídas no filtro.
4. Pressione o botão **"Mover"** para levar essas informações para a coluna **Dimensões Escolhidas**. Elas serão os parâmetros que aparecerão como opções na Barra de Filtros.
5. Para mudar a aparência dos filtros na tela, clique no botão **"Configurações"** e determine:
   - **Cor Primária:** a cor de fundo do ícone exibido na tela do **Page Builder** e a cor dos ícones de calendário;
   - **Cor Secundária:** a cor do símbolo que aparece na barra no Page Builder;
   - **Botão aplicar seleção:** ative esta opção para que a seleção feita na Barra de Filtros só atualize a tela quando o botão **"Aplicar"** for acionado;
   - **Esperar seleção para mostrar componentes:** habilite esta opção para que os componentes só sejam exibidos após a seleção de um filtro.

Observe abaixo o exemplo de utilização da Barra de Filtros para filtrar dados de metas e vendas por data e vendedor:

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=OIBwDrwS3fM)

1. Acesse o Page Builder e vá em Configurações.
2. Selecione uma Barra de Filtro e crie uma nova, dando um nome como **"Filtro do Exemplo"**.
3. Depois, na tela de configuração de filtros, adicione os cadastros **"Calendário"** e **"Vendedor"** à coluna de Dimensões Escolhidas.
4. Em seguida, personalize a aparência:

- - defina a Cor Primária para um tom de roxo (#6a1b9a) e a Cor Secundária para cinza (#bdbdbd);
  - ative as opções **Botão aplicar seleção** e mantenha a opção **Esperar seleção para mostrar componentes** desativada para que os componentes sejam exibidos imediatamente.

5.  Por fim, selecione uma data inicial e uma data final e um vendedor, clique no botão **Aplicar** para filtrar os dados exibidos na tela.

### Responsividade

O **Analytics AI** utiliza percentuais para definir altura, largura e posições dos componentes na tela, ao invés de medidas fixas (pixels). Isso faz com que os elementos se ajustem automaticamente ao tamanho da tela. No entanto, pode causar problemas em componentes como textos e botões, onde o tamanho da fonte precisa ser ajustado para que o conteúdo seja lido bem em diferentes telas.

Por exemplo, um texto feito para uma tela de alta resolução pode parecer muito grande ou muito pequeno em uma tela com resolução diferente. Para resolver isso, o **Analytics AI** tem uma função chamada **pixel mínimo**, que impede que a fonte de textos e botões diminua além de um certo ponto, garantindo que o texto seja sempre legível.

Componentes como tabelas e "boards" (painéis de resumo) já mantêm o tamanho da fonte naturalmente, evitando que o texto fique muito pequeno.

Para facilitar a criação de telas que se ajustam a qualquer dispositivo, o **Analytics AI** inclui uma ferramenta no **Page Builder** que permite que os desenvolvedores mudem temporariamente a resolução da tela. Isso ajuda a ver como a interface vai aparecer em diferentes dispositivos e tamanhos de tela.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=-pqTCPGNcqE)

Boas práticas para criar telas responsivas no Analytics AI:

- **Definir Pixel mínimo:** utilize a funcionalidade de pixel mínimo para textos e botões, garantindo que o conteúdo seja lido bem em qualquer tamanho de tela;
- **Testar com resoluções diferentes:** use a ferramenta de alteração de resolução no Page Builder para verificar como a interface se adapta a diferentes tamanhos de tela;
- **Desenvolvimento para mobile:** se a tela for para celular, use o Page Builder Mobile para organizar os elementos na vertical, garantindo uma melhor experiência para o usuário em dispositivos móveis.

### Criação de painel manualmente com template

Para criar um painel usando um modelo pronto, siga estes passos:

1. Selecione a Skill desejada.
2. Clique em **"+ Novo"**.
3. Escolha entre **"Dashboard"** (para painel) e **"Tela Mobile"** (para celular).
4. Selecione o modelo que você quer usar.

#### Criação de VIEWs

No **Analytics AI**, a **"VIEW"** é a parte que define quais dados do seu banco de dados vão preencher os [Componentes](https://ajuda.sankhya.com.br/hc/pt-br/articles/25648251050647-Analytics-Studio#Componentes) da sua tela.

Para criar uma VIEW, siga estes passos:

1. Selecione um agrupador e uma coluna na seção [Database](https://ajuda.sankhya.com.br/hc/pt-br/articles/25648251050647-Analytics-Studio#Database).
2. Arraste-os para a área de trabalho (o "canvas").
3. Escolha o Componente de visualização em [Tela](https://ajuda.sankhya.com.br/hc/pt-br/articles/25648251050647-Analytics-Studio#Tela) para analisar os dados.
4. Configure as interações que você quer, como a opção de baixar os dados em formato XLSX.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=lBxM1xlhWAw)

Uma VIEW pode ser configurada de três maneiras: [VIEW de Análise de Dados](https://ajuda.sankhya.com.br/hc/pt-br/articles/28045340825239-VIEW-de-An%C3%A1lise-de-Dados-Analytics-AI), VIEW de Cadastro (ambas sem precisar de código), ou VIEW de SQL (usando código SQL).
