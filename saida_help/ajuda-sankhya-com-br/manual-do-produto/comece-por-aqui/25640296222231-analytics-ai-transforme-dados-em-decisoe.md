# Analytics AI: transforme dados em decisões

O **Analytics AI** é a solução de inteligência de dados da Sankhya que combina inteligência artificial, recursos de Self Service BI e uma interface intuitiva para ajudar sua empresa a transformar dados em decisões ágeis e inteligentes.

### Principais componentes

#### Self Service BI

Explore, analise e visualize dados de forma independente, sem precisar de suporte técnico. Com uma interface intuitiva, é possível criar dashboards personalizados com poucos cliques.

#### Inteligência Artificial para dashboards

Crie dashboards interativos em segundos com o recurso Drag and Drop e o apoio de uma IA avançada. O Analytics AI acelera a criação de visualizações, gerando insights rápidos e precisos.

#### Interação com dados via Converse com os Dados

Utilize processamento de linguagem natural para fazer perguntas diretas aos seus dados, como se estivesse conversando com um analista. A resposta é imediata, com base nos dados do seu negócio.

O Analytics AI é composto por duas áreas principais:

- **Analytics Studio** — para criação e personalização de dashboards;
- **Converse com os Dados** — assistente virtual integrada ao aplicativo mobile.

---

### Preparação de dados

O Analytics AI conta com um banco de dados próprio e gerenciável via interface visual. Você pode:

- criar tabelas e definir atributos;
- estabelecer conexões com bancos de dados internos (EIP Sankhya) e externos;
- importar arquivos CSV para enriquecer suas análises.

**Importante:** os dados devem ser tratados e importados para o banco do Analytics AI, pois ele é separado do banco do sistema Sankhya.

Além disso, é possível:

- escrever códigos SQL (procedures, triggers, queries e scripts);
- automatizar e personalizar a estrutura de dados conforme a necessidade.

### Lógica e Interações

O Analytics AI permite criar ações e interações com ou sem código:

- configure ações no-code e integre com serviços externos via IPaaS;
- use funções SQL para manipular dados e alimentar componentes (selects, inserts, updates, deletes);
- estabeleça interações entre componentes, como navegação entre telas, abertura de formulários ou detalhes em modal.

### Instalação do Analytics AI:

Para começar a usar o Analytics AI:

1. 1. contrate a solução com uma unidade Sankhya;
   2. garanta que o sistema esteja na versão **4.28b59 ou superior**;
   3. Instale o aplicativo pelo [Sankhya Place](http://place.sankhya.com.br/).
   4. Após a instalação, as telas Analytics Studio e Converse com os dados serão habilitadas no sistema.
   5. Instale uma Skill para começar a usar o Analytics AI.

**Importante:** durante a instalação, dois jobs serão adicionados ao sistema: MitraBuscaAcoesJob e MitraWorkersCleanerJob. Certifique-se de que ambos estejam ativados para o correto funcionamento do Analytics AI.
