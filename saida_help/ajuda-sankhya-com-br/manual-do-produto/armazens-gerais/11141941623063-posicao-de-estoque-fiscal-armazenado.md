# Posição de Estoque Fiscal Armazenado

```
![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42313167967255) Módulo: Armazéns Gerais > Relatórios           ![Versão](https://ajuda.sankhya.com.br/hc/article_attachments/42313198221719) Versão disponível: A partir da 4.17
```

---

Por meio dessa tela, você pode gerar um relatório com as informações do saldo fiscal armazenado em determinado período.

![Imagem 3: Por meio dessa tela, você pode gerar um relatório com as informações do saldo fiscal armazenado em determinado período.](https://ajuda.sankhya.com.br/hc/article_attachments/11222609817367)

Para isso, informe no campo **"Saldo até"** a data que deseja visualizar as informações das movimentações. Você também pode configurar para que os dados do relatório sejam exibidos para uma **"Empresa"**, **"Parceiro"** e/ou **"Produto"** especifico, neste caso, basta informar os respectivos campos.

Feito isso, acione a marcação **"Não mostrar saldo zerado"**, caso você queira que os lançamentos que estiverem com o campo **"Quantidade"** igual a zero não sejam apresentados no relatório.

Com os campos acima configurados, você pode acionar o botão ![Imagem 4: Com os campos acima configurados, você pode acionar o botão "Gerar Relatório" , assim, o relatório será apresentado no…](https://ajuda.sankhya.com.br/hc/article_attachments/16078056151575)**"Gerar Relatório"**, assim, o relatório será apresentado no **"Visualizador de arquivos"** com as informações do estoque fiscal armazenado conforme as definições dos filtros.

![Imagem 5: Com os campos acima configurados, você pode acionar o botão "Gerar Relatório" , assim, o relatório será apresentado no…](https://ajuda.sankhya.com.br/hc/article_attachments/11222747239191)

Caso você informe apenas o campo Saldo até e clique em Gerar relatório, o relatório será gerado para todas as empresas, parceiros e produtos que tenham lançamentos confirmados até a data informada e que estejam configurados na tela [Tipos de Operação-TOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114) com os Tipos de movimento **"NF de Depósito"** e/ou **"Saídas"** e que atualizem o Livro Fiscal de Entrada e/ou Saída.

Se você preferir analisar as informações do relatório no formato grade, acione o botão **"Visualizar na Grade"**.

[GIF animado: Imagem 6: Se você preferir analisar as informações do relatório no formato grade, acione o botão "Visualizar na Grade" .](https://ajuda.sankhya.com.br/hc/article_attachments/11222926656919)

Na parte superior da tela, temos o botão ![botao-exportar-grade-para-pdf](https://ajuda.sankhya.com.br/hc/article_attachments/16077962458263) **"Exportar grade para PDF"** que apresenta as opções de exportação das informações, sendo elas:

- Exportar para PDF;
- Exportar para planilha(xls);
- Exportar para planilha (xlsx);
- Exportar para cubo.
