# Como enviar o S-1010 com nova validade

Este procedimento deve ser utilizado quando for necessário **reenviar o evento S-1010** informando uma **nova data de início de validade** para rubricas já cadastradas no sistema e enviadas ao eSocial.

Esse cenário é comum quando há ajustes legais, correções de parametrização ou necessidade de alinhar a validade da rubrica às regras vigentes.

######

### Pré-requisitos

######

Antes de iniciar o procedimento, verifique se você possui:

- Permissão de acesso à **Central do eSocial**.

  Essa liberação é feita na tela **Acessos** (Configurações > Controle de Acesso), pelo administrador do sistema.
- Identificação prévia das **rubricas que precisam ser reenviadas** com nova validade.
- Acesso ao **ambiente de Produção**.

  Esse ambiente é configurado na tela **Empresas**, aba **Informações Gerais**, campo **Ambiente**.

######

### Jornada de Uso

######

**1.** Acesse a tela **Central do eSocial** (Pessoal+ > Rotinas Folha).

**2.** No menu lateral esquerdo:

- selecione a **Empresa**;
- informe a **Referência**;
- confirme o **Ambiente** como **Produção**.

**3.** Clique no botão **Carregar** para atualizar as informações.

**4.** No menu lateral, clique em **Geração** e depois em **Selecionar Eventos**.

**5.** Na lista de eventos disponíveis, localize o card **S-1010 – Tabela de Rubricas** e clique nele para selecioná-lo.

**6.** Clique em **Iniciar Geração**.

[GIF animado: Imagem 1: 6. Clique em Iniciar Geração .](https://ajuda.sankhya.com.br/hc/article_attachments/37825868608791)

**7.** Após a conclusão da geração, os eventos S-1010 serão exibidos no menu **Eventos Pendentes**.

**8.** Clique no botão **Habilitar/Desabilitar todos** para **desabilitar todos os eventos** gerados.

![Imagem 2: 8. Clique no botão Habilitar/Desabilitar todos para desabilitar todos os eventos gerados.](https://ajuda.sankhya.com.br/hc/article_attachments/37826074239255)

**9.** Em seguida, clique no card do **S-1010** para trabalhar apenas com esse evento.

**10.** Utilize o ícone da **lupa (pesquisa)** para localizar as rubricas pela descrição.

![Imagem 3: 10. Utilize o ícone da lupa (pesquisa) para localizar as rubricas pela descrição.](https://ajuda.sankhya.com.br/hc/article_attachments/37826456919703)

**11.** Para cada rubrica que precisa ser reenviada, ative a opção **Enviar**.

**12.** Repita o processo até selecionar todas as rubricas necessárias.

**13.** Após finalizar a seleção, clique na seta **Voltar** para retornar à tela anterior.

**14.** Desabilite a opção **Utilizar a data de início padrão do sistema**.

**15.** Clique em **Enviar Dados**.

O sistema exibirá um pop-up solicitando a nova data de início de validade.

**16.** Informe a data desejada.

**Exemplo:** 01/2025

**17.** Clique em **Enviar Dados** para confirmar.

[GIF animado: Imagem 4: 17. Clique em Enviar Dados para confirmar.](https://ajuda.sankhya.com.br/hc/article_attachments/37826456922007)

**18.** Após o envio, acompanhe o processamento do evento pelo menu **Acompanhamento**, onde é possível verificar:

- status do envio;
- retorno do eSocial;
- mensagens de erro ou rejeição, se houver.

![Imagem 5: mensagens de erro ou rejeição, se houver.](https://ajuda.sankhya.com.br/hc/article_attachments/37826606908951)

**Observações importantes**

- Envie **somente as rubricas que realmente precisam de nova validade**, evitando rejeições e retrabalho.
- Certifique-se de que a nova data de início:

  - esteja coerente com a legislação vigente;
  - respeite o histórico da rubrica no eSocial.
- Em caso de rejeição, analise o retorno apresentado na aba **Acompanhamento** e realize os ajustes necessários antes de reenviar.
