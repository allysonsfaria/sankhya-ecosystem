# Sankhya Pass – Login Unificado (SSO)

### Caminho de acesso

- Tela de login dos produtos Sankhya
- Portal do Cliente > Meu perfil
- Portal do Cliente  > Gestão de usuários (exclusivo para administradores)

### Visão geral

O Sankhya Pass é o login unificado da plataforma Sankhya. Ele centraliza a identidade do usuário em uma única conta, permitindo acesso seguro e contínuo a diferentes soluções do ecossistema, eliminando múltiplos logins e padronizando a experiência de autenticação em toda a plataforma.

### Descrição e Usabilidade

#### 1. Descrição

O Sankhya Pass permite que o usuário utilize uma única conta para acessar os produtos integrados da Sankhya. A plataforma centraliza autenticação, recuperação de senha e dados básicos de identidade, aumentando a segurança, reduzindo atritos no acesso e garantindo uma experiência consistente entre sistemas.

#### 2. Quem deve usar

- Todos os usuários das aplicações Sankhya
- Todos os colaboradores Sankhya

#### 3. Pré-requisitos

- Conta Sankhya Pass ativa ou convite válido
- E-mail acessível para validações e recuperação
- Permissões concedidas pela empresa

#### 4. Jornadas disponíveis no Sankhya Pass

**Visão geral**

O usuário acessa a tela de login, ativa sua conta no Sankhya Pass (necessário ter recebido um convite prévio da organização), realiza autenticação e passa a acessar os produtos autorizados. Administradores podem pesquisar usuários, reenviar convites, desbloquear usuários e realizar reset de senhas (via Portal do Cliente).

**Jornadas principais**

- Login de usuário
- Cadastro de novo usuário
- Vínculo de usuário à organização

**Jornadas administrativas**

- Pesquisa de usuários
- Reenvio de convite para usuário não ativado
- Desbloqueio de usuários

**Jornadas de recuperação**

- Reset de senha com e-mail
- Reset de senha sem e-mail
