# Relatório de Parceiros

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312069965719) Módulo: Comercial > Relatórios
```

---

**Importante:** Nesta documentação você irá visualizar a descrição das funcionalidades do Relatório de Parceiros que esta localizado nos menus **"Comercial > Relatórios > Parceiros"**e**"Financeiro > Relatórios > Ficha de Parceiros"**.

O relatório de Parceiros tem o objetivo de apresentar as informações que irão auxiliar na obtenção de dados ligados aos parceiros, como endereço de entrega, quantidade de dias em que não se realiza uma negociação com determinados parceiros, Razão Social, entre outras informações.

![Imagem 2: O relatório de Parceiros tem o objetivo de apresentar as informações que irão auxiliar na obtenção de dados ligados aos…](https://ajuda.sankhya.com.br/hc/article_attachments/360080363354)

Para dar início a criação de um relatório, aciona-se o botão **"Modo Edição"**. Os passos seguintes são descritos detalhadamente na documentação acessada pela tela [Relatórios Formatados](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597694-Relat%C3%B3rios-Formatados).

O campo **"Código ou Nome contendo"** localizado na parte superior da tela, está destinado a busca rápida de algum relatório que deseja-se visualizar ou reconfigurar. Pode-se informar o código, um trecho do nome do relatório, ou ainda clicar no ícone representado pela **"lupa"** localizado à frente do campo.

Depois de feita a criação de um relatório, o título definido para o mesmo será exibido na parte inferior da tela, onde os demais botões apresentados serão habilitados para utilização. São eles:

![Imagem 3: Visualizar Relatório: através deste botão, realiza-se a visualização dos dados gerados que serão posteriormente…](https://ajuda.sankhya.com.br/hc/article_attachments/16670255915031) **Visualizar Relatório:** através deste botão, realiza-se a visualização dos dados gerados que serão posteriormente impressos.

![Imagem 4: Modo Edição: além de ser o botão a ser acionado para início da criação de um relatório, este botão também deve ser…](https://ajuda.sankhya.com.br/hc/article_attachments/16670272972055) **Modo Edição:** além de ser o botão a ser acionado para início da criação de um relatório, este botão também deve ser acionado caso se possua o relatório já formatado, e deseja-se realizar no mesmo algum ajuste.

![Visualizar](https://ajuda.sankhya.com.br/hc/article_attachments/15646650379799) **Visualizar Grade:** acionando-se este botão, as informações geradas serão apresentadas em modo grade na tela.

![Imagem 6: Segurança: ao acionar-se este botão, será aberta a tela "Título de segurança" , onde configuram-se os acessos ao…](https://ajuda.sankhya.com.br/hc/article_attachments/20431251192343) **Segurança:** ao acionar-se este botão, será aberta a tela **"Título de segurança"**, onde configuram-se os acessos ao relatório. Será permitido aqui, ajustar o nível de acesso de cada grupo de usuários, ao relatório selecionado. Os usuários são anexados aos grupos de forma conveniente, não importando a qual grupo ele esteja vinculado no cadastro de usuários. Sendo este vínculo exclusivo por relatório, pode-se ter um usuário vinculado ao grupo "A" no relatório "X" e ao grupo "B" no relatório "Y". O acesso pode ser dado a todo o grupo ou a um usuário específico.

![Imagem 7: Baixar JRXML: através deste botão, é feita a baixa do relatório no formato "jrxml", onde este pode ser utilizado no…](https://ajuda.sankhya.com.br/hc/article_attachments/20761620388503) **Baixar JRXML:** através deste botão, é feita a baixa do relatório no formato "jrxml", onde este pode ser utilizado no "IReport".

![Imagem 8: Outras opções: este botão possui duas alternativas de uso. Assim, teremos:](https://ajuda.sankhya.com.br/hc/article_attachments/16670272987159) **Outras opções:** este botão possui duas alternativas de uso. Assim, teremos:

- Ao acionar a opção **"Adicionar lançador"**, será aberta uma tela, onde deve-se informar a descrição e a pasta de destino; a descrição é a identificação literal para o lançador; a pasta de destino, refere-se ao diretório do menu ao qual abrigará o lançador de um determinado item; a operação estará concluída após a confirmação, pressionando o botão **"Concluir"**, e poderá também ser abortada, acionando o botão **"Cancelar"**.
- A opção **"Localizar lançador"**, apresenta a listagem de todos os lançadores que apontam para o item que corresponde ao item atual de navegação. Por exemplo, se determinado usuário estiver navegando entre relatórios personalizados, ao acionar esta opção, será aberta uma lista de todos os lançadores que correspondem ao item "Relatório" atual de navegação. Nesta tela, além de visualizar os lançadores para um item, pode-se excluir um lançador do item e/ou alterar sua descrição.

**Descartar Cache:** Marcando-se esta opção, ao realizar a geração dos relatórios, os caches de impressão serão limpos.
