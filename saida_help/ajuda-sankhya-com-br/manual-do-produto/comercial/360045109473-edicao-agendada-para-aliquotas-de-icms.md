# Edição agendada para Alíquotas de ICMS

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312000501143) Módulo: Comercial > Arquivo > Cadastros > Alíquotas
```

---

Mudanças nas taxas de alíquotas, podem ser necessárias em determinados períodos, com um intervalo bastante curto entre uma modificação e outra; este fato implica em uma mudança de configurações nas alíquotas de ICMS, que na maioria dos casos, devido a grande quantidade de configurações existentes, se torna um tanto trabalhosa.

Visando agilizar este processo, temos no Sankhya Om a tela Edição agendada para Alíquotas de ICMS, que através de um agendamento previamente configurado, faz as alterações de alíquotas de acordo com as modificações desejadas.

![Imagem 2: Visando agilizar este processo, temos no Sankhya Om a tela Edição agendada para Alíquotas de ICMS , que através de um…](https://ajuda.sankhya.com.br/hc/article_attachments/4418004114071)

Para cadastrar um agendamento, clique no botão ![Imagem 3: Para cadastrar um agendamento, clique no botão "Cadastrar agendamento para Edição de cadastros" e efetue o…](https://ajuda.sankhya.com.br/hc/article_attachments/16117703381527) **"Cadastrar agendamento para Edição de cadastros"** e efetue o preenchimento do campo **"Nro. Único"**, sendo que este preenchimento pode ser realizado de forma manual ou automática; esta definição é feita através do botão ![Imagem 4: Para cadastrar um agendamento, clique no botão "Cadastrar agendamento para Edição de cadastros" e efetue o…](https://ajuda.sankhya.com.br/hc/article_attachments/16343664074647) **"Configuração da tela"** localizado no lado superior direito da tela, opção **"1 Numeração"**.

Informe uma **"Descrição"** para o agendamento que está sendo cadastrado, de modo a facilitar sua identificação.

No campo **"Dh. Agendamento"** preencha data e a hora em que o agendamento será realizado. Neste campo não poderá preencher um período inferior ao atual. À frente do campo, é apresentado um contador que exibe o período em dias para que o agendamento seja realizado.

### Aba Geral

Nesta aba, são apresentados os dados gerais relacionados a data e hora do agendamento.

Você poderá preencher no campo **"Observação"**, alguma informação relevante relacionada ao agendamento que está sendo cadastrado.

Logo abaixo, o campo **"Situação"** exibe o status do agendamento. São possíveis 5 (cinco) tipos de situação:

- **Não agendado (N):** Quando o agendamento é configurado, porém não é informada uma data de agendamento.
- **Agendado (A):** Esta situação significa que o agendamento foi criado juntamente com sua data de agendamento.
- **Executado com sucesso (E):** O campo assume esta situação, quando o agendamento foi executado sem problemas.
- **Desfeito (D):** Quando a opção **"Desfazer execução"** é utilizada.
- **Executado com erro (R):** Quando ocorre algum erro na execução do agendamento.

O campo **"Dh. Execução"** registra a data e a hora em que o agendamento programado foi executado.

Caso seja feita alguma alteração no registro, o campo **"Dh. Alteração"** grava a data e a hora desta modificação.

O botão ![Imagem 5: O botão " Desfazer execução" será apresentado habilitado, nos casos em que o agendamento é executado com sucesso e a…](https://ajuda.sankhya.com.br/hc/article_attachments/16117707056535) **"Desfazer execução"** será apresentado habilitado, nos casos em que o agendamento é executado com sucesso e a data de execução está preenchida. Clicando nesta opção, será exibida a seguinte mensagem de confirmação:

**"Esta operação irá desfazer as alterações realizadas por este agendamento retornando as configurações anteriores. Confirma esta ação?"**

### Aba Filtro

São realizadas aqui as configurações de filtragem das alíquotas a serem modificadas pelo agendamento.

![Imagem 6: São realizadas aqui as configurações de filtragem das alíquotas a serem modificadas pelo agendamento.](https://ajuda.sankhya.com.br/hc/article_attachments/4417997695127)

Acionando o botão ![Imagem 7: Acionando o botão "Configurar Filtro" será exibido o pop-up "Assistente para criação de Filtros" , onde irá selecionar…](https://ajuda.sankhya.com.br/hc/article_attachments/16117707059863) **"Configurar Filtro"** será exibido o pop-up **"Assistente para criação de Filtros"**, onde irá selecionar as alíquotas de ICMS que irão sofrer o impacto da edição do agendamento. Além disso, no espaço abaixo do botão, poderá informar filtros de forma manual.

Através do botão ![Imagem 8: Através do botão "Testar Filtro" é possível visualizar os resultados do filtro configurado.](https://ajuda.sankhya.com.br/hc/article_attachments/16117703403415) **"Testar Filtro"** é possível visualizar os resultados do filtro configurado.

### Aba Log de Erros

Durante a execução do agendamento, caso ocorra algum erro impedindo sua perfeita efetivação, será automaticamente gravado no campo **"Log de erros"** apresentado nesta aba, de modo a facilitar a identificação do problema, agilizando sua resolução.
