# Parâmetros de importação DIFACT

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311683523991) Módulo: Comercial > Rotinas > Integração DIFACT 
```

---

Através desta tela, você definirá as configurações dos financeiros e notas que serão importadas no sistema.

Importante: Para que esta tela seja habilitada, você deverá habilitar o parâmetro **"USAINTDIFACT -USAINTDIFACT"**.

**Observação:** Lembre-se de não configurar [Tipo de Operação - TOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP) que realiza impressão automática.

![Imagem 2: Observação: Lembre-se de não configurar Tipo de Operação - TOP que realiza impressão automática.](https://ajuda.sankhya.com.br/hc/article_attachments/360065979893)

Nesta rotina, você poderá configurar os Parâmetros de importação DIFACT para Geração do Financeiro de despesa para IOF, Geração da despesa da operação, poderá ainda Informar os serviços para geração dos itens da nota, para a Geração dos financeiros de receita e Tipo de Título.
