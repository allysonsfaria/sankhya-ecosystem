# Regras Gerais

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312089426327) Módulo: Comercial > Avançado > Certificações
```

---

Podemos entender que a Central de Certificação serve como uma base para configurar as regras desejadas. A aplicação dessas regras tem um foco direcionado aos usuários, podendo ser feita de duas formas:

Individualmente: Através dos cadastros de usuários, na aba Validação, onde as regras são aplicadas de maneira personalizada para cada usuário.

Coletivamente: Nesta tela, Regras Gerais, definem-se quais regras serão utilizadas nas rotinas do sistema, incluindo relatórios, independentemente do usuário, vendedor, entre outros. Isso permite a aplicação uniforme das Regras Gerais a todos os usuários e contextos do sistema."

![Regras](https://ajuda.sankhya.com.br/hc/article_attachments/15644995431703)

As regras informadas nesta tela deverão ser previamente cadastradas na tela [Central de Certificações](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110053-Central-de-Certifica%C3%A7%C3%B5es).

**Importante:** o opcional **"Central de Certificação"** precisará de liberação para que esta rotina seja habilitada.

A tela Regras Gerais possui os seguintes campos:

O campo **"Regra"** é de preenchimento obrigatório, onde deve-se informar uma regra que será geral no sistema.

A marcação **"Ativo"** definirá se a Regra Geral encontra-se ativa ou não.
