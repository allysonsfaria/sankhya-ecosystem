# Inclusão Facilitada de Itens pela Cópia do "Executante"

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311829213591) Módulo: Comercial > Rotinas
```

---

No lançamento dos itens nas Centrais, ao criar um novo item, o sistema copiará a informação  do campo **"Executante"** do último item incluído. A cópia sempre será feita do último item que foi incluído ou alterado.

Temos um exemplo:

Foi lançado um Produto X e preenchido o campo **"Executante"** dos Itens da Nota com o código 5.

![Imagem 2: Foi lançado um Produto X e preenchido o campo "Executante" dos Itens da Nota com o código 5 .](https://ajuda.sankhya.com.br/hc/article_attachments/360087193653)

Ao salvar o Item, você inclui outro item, através do botão ![Imagem 3: Ao salvar o Item , você inclui outro item , através do botão " Novo (F8)" .](https://ajuda.sankhya.com.br/hc/article_attachments/16277746949911) **"Novo [F8]"**.

Neste caso, automaticamente o campo Executante será preenchido com o código 5, que corresponde ao executante do último item lançado.

Já que, neste caso, só temos dois produtos lançados, caso você altere o executante do primeiro produto, lançando, por exemplo, do código 5 para o código 11, o mesmo poderá ser alterado normalmente mas, ao tentar incluir um terceiro item, o sistema preencherá o campo Executante com o código 11, porque este corresponderá ao último executante alterado.
