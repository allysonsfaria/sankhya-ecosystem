# Relatório de Descontos Promocionais

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312052845335) Módulo: Comercial > Relatórios
```

---

O relatório de Descontos Promocionais, visa apresentar os dados relacionados aos descontos configurados aos devidos grupos de parceiros, grupos de produtos, considerando seus respectivos percentuais.

![Imagem 2: O relatório de Descontos Promocionais , visa apresentar os dados relacionados aos descontos configurados aos devidos…](https://ajuda.sankhya.com.br/hc/article_attachments/4410466894359)

O campo **"Código ou Nome contendo"** localizado na parte superior da tela, está destinado a busca rápida de algum relatório, que deseja-se visualizar ou reconfigurar. Você pode informar o código, um trecho do nome do relatório, ou ainda clicar no ícone representado pela **"lupa"** localizado à frente do campo.

Para dar início a criação de um relatório, acione o botão ![Imagem 3: Para dar início a criação de um relatório, acione o botão "Modo Edição" .](https://ajuda.sankhya.com.br/hc/article_attachments/16664492548119) **"Modo Edição"**.

![Imagem 4: Para consultar os detalhes da edição/criação de um relatório, acesse o artigo Relatórios Formatados .](https://ajuda.sankhya.com.br/hc/article_attachments/20431107042199) Para consultar os detalhes da edição/criação de um relatório, acesse o artigo [Relatórios Formatados](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108573-Relat%C3%B3rios-Formatados-).

Depois de feita a criação de um relatório, o título definido para o mesmo será exibido na parte inferior da tela, onde os demais botões apresentados serão habilitados para utilização. São eles:

![Imagem 5: Visualizar Relatório: p or meio deste botão, você poderá visualizar os dados gerados que serão posteriormente impressos.](https://ajuda.sankhya.com.br/hc/article_attachments/16664492546839) **Visualizar Relatório:** por meio deste botão, você poderá visualizar os dados gerados que serão posteriormente impressos.

![Imagem 6: Modo Edição: você pode acionar este botão tanto para criar um relatório, quanto para realizar um ajuste num relatório…](https://ajuda.sankhya.com.br/hc/article_attachments/16664492548119) **Modo Edição:** você pode acionar este botão tanto para criar um relatório, quanto para realizar um ajuste num relatório já formatado.

![Imagem 7: Visualizar Grade: a cionando este botão, as informações geradas serão apresentadas em modo grade na tela.](https://ajuda.sankhya.com.br/hc/article_attachments/16664492549399) **Visualizar Grade:** acionando este botão, as informações geradas serão apresentadas em modo grade na tela.

![Imagem 8: Segurança: a o acionar este botão, s erá aberto o pop-up "Título de segurança" , no qual você pode configurar os…](https://ajuda.sankhya.com.br/hc/article_attachments/20431107044503) **Segurança:** ao acionar este botão, será aberto o pop-up **"Título de segurança"**, no qual você pode configurar os acessos ao relatório. Será permitido aqui, ajustar o nível de acesso de cada grupo de usuários, ao relatório selecionado. Os usuários são anexados aos grupos de forma conveniente, não importando a qual grupo ele esteja vinculado no cadastro de usuários. Sendo este vínculo exclusivo por relatório, podemos ter um usuário vinculado ao grupo "A" no relatório "X" e ao grupo "B" no relatório "Y". O acesso pode ser dado a todo o grupo ou a um usuário específico.

![Imagem 9: Baixar JRXML: p or meio deste botão, é feita a baixa do relatório no formato "jrxml" , na qual este pode ser utilizado…](https://ajuda.sankhya.com.br/hc/article_attachments/20761601517975) **Baixar JRXML:** por meio deste botão, é feita a baixa do relatório no formato "jrxml", na qual este pode ser utilizado no "IReport".

**Descartar Cache:** marcando esta opção, ao realizar a geração dos relatórios, os caches de impressão serão limpos.
