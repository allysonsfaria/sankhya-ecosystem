# Histórico de Utilização de Produto no Cliente

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311757542935) Módulo: Comercial > Arquivo > Cadastros > Históricos
```

---

Esta tela é utilizada para que sejam cadastrados os Históricos de Utilização dos Produtos no Cliente.

![HUP1](https://ajuda.sankhya.com.br/hc/article_attachments/360060983954)

No campo **"Código"** informe o código para cadastrar o histórico.

Insira no campo **"Descrição"** o nome do Histórico que se refere ao que for utilizado o produto no cliente.

Lembre-se que o botão ![Imagem 3: Lembre-se que o botão "Edição múltipla" permite a edição simultânea de vários registros a partir do modo grade. Ou…](https://lh4.googleusercontent.com/EPLpuzMhQ78bB7CFLWZI9_v6FVUMLMA3UNJTbFtPTpR7pSZx7vCGsukBdLtZofs4B8tJKnaKCJppF12Of9orTmAMmvmwhdQeW7NqNZ3lmGCYOSi45-2ltsDOMP6yneOw-Y_m47rKsS89BUwLXSbckNw) **"Edição múltipla"** permite a edição simultânea de vários registros a partir do modo grade. Ou seja, ao selecionar um conjunto de registros e clicar no botão, será possível editar os campos correspondentes de todos os registros de uma só vez. 

Por exemplo, com os históricos em modo grade na tela Históricos de Utilização dos Produtos no Cliente selecione-os e em seguida clique no botão Edição múltipla, assim os campos poderão ser editados simultaneamente para os selecionados.
