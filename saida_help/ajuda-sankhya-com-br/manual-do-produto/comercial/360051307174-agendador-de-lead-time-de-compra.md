# Agendador de Lead Time de Compra

```
![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42312136510231) Módulo: Comercial > Gerente
```

---

Esta rotina realizará as operações feitas na tela [Lead Time de Compra](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594134) de forma automática, ou seja, o sistema realizará consultas a partir dos filtros preenchidos e atualizará o lead time a partir das opções marcadas no agendamento.

![Imagem 2](https://ajuda.sankhya.com.br/hc/article_attachments/21043510435479)

Além das abas padrões de agendamentos, tem-se a aba **"Configurações"**, que possui filtros e opções encontrados na tela Lead Time de Compra, com o mesmo funcionamento.

O campo **"Período de Negociação"** tem as seguintes validações:

- Não deve ser selecionado períodos de datas para a busca dos produtos que terão lead time atualizado;
- Deverá ser escolhido quantos meses, retroativos à data atual, que o sistema considerará para filtrar os produtos que terão o lead time atualizado. Abaixo segue um exemplo:

Se for selecionado o número 3 neste campo, o sistema irá considerar na busca do produto, o período de hoje (21/07/2020) a 3 meses anteriores (21/04/2020).
