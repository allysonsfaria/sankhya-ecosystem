# Outras Interações - Analytics Studio

Outras interações são funcionalidades adicionais que podem ser aplicadas a componentes específicos. Essas interações incluem:

- Drill;
- Foco;
- Exportar para XLSX;
- Trocar Componente;
- Esconder Colunas.

Cada interação oferece uma maneira única de interagir e explorar os dados apresentados.

![Imagem 1: Cada interação oferece uma maneira única de interagir e explorar os dados apresentados.](https://ajuda.sankhya.com.br/hc/article_attachments/28077327272087)

### Como configurar

No menu de configurações do componente escolhido, acesse a seção **"Interações"** e ative a opção desejada.

### Drill

O Drill permite aos usuários explorar dados em outras perspectivas, navegando de um conjunto de dados mais amplo para detalhes específicos. Quando for possível explorar os dados por outras perspectivas, aparecerão as opções de escolha. Quando chegar no último nível possível, não aparecerá nenhuma opção. É útil para entender informações detalhadas sem perder o contexto da análise principal. Os componentes que permitem utilizar o Drill são:

- Barras;
- Tabela;
- Funil;
- Mapa;
- Pizza.

#### Exemplo de uso

- **Cenário:** Relatório de Metas e Vendas por Vendedor.

Um gráfico de barras exibe as vendas e as metas por vendedor. Ao habilitar a funcionalidade Drill, os usuários podem clicar com o botão direito em uma barra específica (por exemplo, vendas da vendedora Ana Beatriz) e selecionar **"Mês"**, para ver um detalhamento por mês das vendas da Ana Beatriz. 

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=0R7eq_ycYTg)

### Foco

A interação Foco destaca um componente específico, exibindo-o em um modal para análise detalhada. Os componentes que permitem utilizar o Foco são: 

- Barras;
- Tabela;
- Funil;
- Mapa;
- Pizza;
- Timeline.

#### Exemplo de uso

- **Cenário:** Relatório de Metas e Vendas por Vendedor.

Um gráfico de barras exibe as vendas e as metas por vendedor. Com a funcionalidade Foco, o usuário pode clicar no botão que fica na parte superior direita do gráfico, para abrir um modal em tela cheia com o gráfico, permitindo uma análise detalhada sem distrações de outros elementos na tela.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=dgvwBseTCc8)

### Exportar para XLSX

Permite exportar os dados de uma tabela ou gráfico para um arquivo .XLSX, facilitando a análise offline ou o compartilhamento de informações. Os componentes que permitem utilizar o Exportar para XLSX são:

- Barras;
- Tabela;
- Funil;
- Mapa;
- Pizza;
- Timeline.

#### Exemplo de uso

- **Cenário:** Relatório de Metas e Vendas por Vendedor.

Um gráfico de barras exibe as vendas e as metas por vendedor. A funcionalidade Exportar para XLSX permite que os usuários baixem esses dados em formato Excel.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=Ma3Zs8asW7I)

### Trocar Componente

Permite alternar a visualização de um conjunto de dados entre diferentes tipos de componentes, como de uma tabela para um gráfico de pizza ou de barras. Os componentes que permitem utilizar o Trocar componente são:

- Barras;
- Tabela;
- Funil;
- Mapa;
- Pizza;
- Timeline.

#### Exemplo de uso

- **Cenário:** Relatório de Metas e Vendas por Vendedor.

Um gráfico de barras exibe as vendas e as metas por vendedor. Com a funcionalidade Trocar Componente, os usuários podem alternar entre a visualização de gráfico de barras ou tabela, para diferentes perspectivas dos dados. 

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=cuA7vImRxvA)

### Esconder Colunas nas Tabelas

Permite aos usuários ocultar colunas de uma tabela, personalizando a visualização dos dados. 

#### Exemplo de uso

- **Cenário:** Relatório de Metas e Vendas por Vendedor.

Uma tabela exibe as vendas e as metas por mês e por vendedor. Para focar em informações específicas, a funcionalidade Esconder Colunas permite que os usuários ocultem colunas menos relevantes, simplificando a visualização e análise dos dados.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=2RKZFrMbrMQ)
