# Não consigo iniciar conversa com a BIA. O que fazer?

**SITUAÇÃO:**

Ao tentar iniciar uma conversa com a BIA usuário é impedido e não consegue executar a ação.

**SOLUÇÃO:**

**(1)** Verifique qual usuário foi utilizado para fazer login no Sankhya OM.

**(1)** Caso o login **não tenha sido feito com o Sankhya ID, saia do sistema e faça o login usando o Sankhya ID;**

**(1)**  Se o login tiver sido feito com o **Sankhya ID** entre em contato com o suporte.
