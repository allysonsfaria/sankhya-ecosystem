# Autorização de OS

```
![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42311276978583) Módulo: Contratos e Serviços > Rotinas
```

---

Nesta tela, você poderá realizar a autorização de um sub-item da OS para ser faturado, bem como negar este faturamento.

**Importante:** esta rotina apenas estará disponível para utilização quando o parâmetro **"Usa processo de autorização de faturamento de OS? - UTILIZAAUTFATOS"** encontrar-se habilitado.

![Imagem 2: Importante: esta rotina apenas estará disponível para utilização quando o parâmetro "Usa processo de autorização de…](https://ajuda.sankhya.com.br/hc/article_attachments/5146071896727)

**Observação:** quando o parâmetro **"Usa processo de autorização de faturamento de OS? - UTILIZAAUTFATOS"**, o processo de Faturamento de OS e [Fechamento de Comissão](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607034) passarão a necessitar de autorização para cada sub- item que desejar-se processar.

No campo **"Autorização"**, quando selecionada a opção **"Não autorizados"** informe o motivo do não faturamento; este motivo deverá ser cadastrado previamente na tela [Motivo de Exceção de Faturamento](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044604314).

Na tela acima mencionada, no campo **"Tipo"** tem-se duas opções: **"Exceção de faturamento"** e **"Não autorização de O.S."**.

**Nota:** a opção Exceção de faturamento refere-se à tela [Exceção de faturamento por SubOS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045113473), enquanto que a opção Não autorização de O.S refere-se à rotina de Autorização de OS.

Os itens da OS para os quais forem autorizados o faturamento serão exibidos na tela [Faturamento de Pedidos/OS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044604694) para serem faturados, já os itens que não foram autorizados, não serão exibidos na referida tela.
