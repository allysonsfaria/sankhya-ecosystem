# Lançamento de OS por Modelo

```
![módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42311225775639) Módulo: Contratos e Serviços > Ordem de Serviço
```

---

Para utilização desta tela, inicialmente, realize o lançamento de uma OS da forma convencional e, ao efetuar seu salvamento, será apresentada na parte superior da tela a opção **"Salvar como Modelo"**.

![Imagem 2: Para utilização desta tela, inicialmente, realize o lançamento de uma OS da forma convencional e, ao efetuar seu…](https://ajuda.sankhya.com.br/hc/article_attachments/8990414594455)

**Observação:** apenas Ordens de Serviços de **"Contrato"** podem ser utilizadas como modelo, isto é, não é possível salvar como modelo as OS do tipo **"FAP"** e **"Pedido"**.

Para que você consiga utilizar esta opção, é necessário que possua um acesso especial para criar os modelos. Este acesso é liberado através da tela [Acessos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596854-Acessos), onde seleciona-se a tela de Ordem de Serviço seguindo o seguinte caminho, **"Módulos > Contratos e Serviços > Ordem de Serviço"**; assim, escolhe-se o usuário desejado e concede-se a este a permissão para **"Criar Modelos"**.

Uma vez com o acesso liberado e a OS lançada da forma convencional, clique na opção Salvar como modelo; será aberta uma tela para configuração dos dados do Modelo de OS.

Informe o **"Nome do modelo"** que é um campo de preenchimento obrigatório, e defina a visibilidade do modelo, que poderá ser:

- Privado;
- Público;
- Definir.

![Imagem 3: Definir.](https://ajuda.sankhya.com.br/hc/article_attachments/8990016915095)

Feito isto, a OS lançada será fechada; acessando a tela de Lançamento de OS por Modelo para visualizar a OS modelo cadastrada, você pode clicar em **"Aplicar"** ou digitar o nome dado ao Modelo de OS, que no nosso exemplo foi **"Atendimento ao cliente"**.

![Imagem 4: Feito isto, a OS lançada será fechada; acessando a tela de Lançamento de OS por Modelo para visualizar a OS modelo…](https://ajuda.sankhya.com.br/hc/article_attachments/8990131150999)

Note a existência de dois botões na tela, que são **"Usar Modelo"** e **"Visualizar OS Modelo"** (esta opção exibe a OS cadastrada como modelo).

Acionando o botão Usar Modelo, será aberta uma nova tela com praticamente todos os dados informados no lançamento de uma OS convencional preenchidos.

![Imagem 5: Acionando o botão Usar Modelo , será aberta uma nova tela com praticamente todos os dados informados no lançamento de…](https://ajuda.sankhya.com.br/hc/article_attachments/8990155617303)

Nesta tela, efetue o preenchimento dos demais campos e, no campo **"Descrição"**, informe uma nova descrição para OS que será aberta, ou ainda, utilize do botão **"Carregar Descrição"**; acionando este, a descrição da OS utilizada como modelo será carregada na OS que está sendo lançada. Caso necessário, os campos **"Contato"**, **"Produto"**, **"Serviço"**, **"Classificação"**, **"Status"** e **"Motivo"** também poderão ser alterados nesta etapa do lançamento.

No campo **"Dt/Hr Limite da OS"** informe a data máxima em que a OS deverá ser executada.

**Observação:** A data informada neste campo somente será respeitada se não existir modelo de SLA vinculado ao contrato (Tela Contratos, [Aba SLA](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044604774-Contratos#abasla)). Caso exista um modelo de SLA vinculado ao Contrato, a Data será alterada para respeitar o acordo SLA vinculado ao Contrato que, é mandatório.

No campo **"Agendamento"** deverá ser informado a data de agendamento da OS, que normalmente será a Data e Hora Atual.

**Observação:** A data informada neste campo deverá ser respeitada já que ela interfere no campo **"Dt/Hr Limite"** quando existe SLA vinculado ao Contrato da OS, pois ela será utilizada na base de cálculo da OS.

Por fim, você pode clicar em **"Voltar"**, caso algum ajuste seja necessário, ou acionar o botão **"Salvar"**, para que a OS seja salva e uma tela contendo uma prévia dos dados desta nova OS seja exibida.

![Imagem 6: Por fim, você pode clicar em "Voltar" , caso algum ajuste seja necessário, ou acionar o botão "Salvar" , para que a OS…](https://ajuda.sankhya.com.br/hc/article_attachments/8990280629527)

Nesta etapa, você pode clicar em Voltar, onde será reaberta a tela para escolha do Modelo de OS, ou clicar em **"Visualizar OS"** para ser aberta a tela [Ordem de Serviço](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603834-Ordem-de-Servi%C3%A7o) contendo a OS recém lançada.
