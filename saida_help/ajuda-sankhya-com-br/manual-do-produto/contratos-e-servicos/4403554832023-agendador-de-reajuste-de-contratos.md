## Aba Configurações

Aqui, realize a definição dos filtros e parâmetros dos reajustes.

![Imagem 5: Aqui, realize a definição dos filtros e parâmetros dos reajustes.](https://ajuda.sankhya.com.br/hc/article_attachments/4407688226199)

No campo **"Ocorrência"**, informe a ocorrência que será utilizada para atualização do contrato com o reajuste.

O campo **"Ajuste de Valor"** apresenta as marcações **"Arredondar"**e **"Truncar"**.

No campo **"E-mail para notificação de erros"**, é possível inserir os endereços para os quais devem ser enviadas as notificações de erros ou problemas de execução dos agendamentos.
**Nota:** para adicionar mais de um e-mail, é necessário separá-los pelo sinal ortográfico "**;**" (ponto e vírgula).

O campo **"Qtd. dias para manter histórico"** será utilizado para configurar o tamanho do histórico de execução armazenado.

Na seção **"Filtros"** defina os filtros conforme suas preferências, uma vez que, se estes não forem configurados, todos os contratos serão filtrados na tela.
