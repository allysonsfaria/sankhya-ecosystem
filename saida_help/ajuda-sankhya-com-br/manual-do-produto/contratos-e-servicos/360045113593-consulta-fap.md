# Consulta - FAP

```
![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42311268789143) Módulo: Contratos e Serviços > Projetos
```

---

Por meio dessa rotina, você poderá efetuar simples consultas de projetos ou acessar novos projetos para configuração de suas etapas, antes de utilizá-los. Deste modo, os filtros aqui disponibilizados tornam esta rotina uma ferramenta de pesquisas sobre projetos.

![Imagem 2: Por meio dessa rotina, você poderá efetuar simples consultas de projetos ou acessar novos projetos para configuração de…](https://ajuda.sankhya.com.br/hc/article_attachments/4421519825175)

Para pesquisar um projeto, selecione o **"Centro Resultado"**, **"Parceiro"**, **"Coordenador"**, **"Colaborador"** ou **"Função"** pertencentes ao autor do mesmo. Ainda poderá pesquisá-lo utilizando o **"Número"**, **"Status"** e **"Período"** de realização, além de saber sobre aqueles que estão **"Com etapas em atraso"**. Após informar os filtros desejados, clique em ![Imagem 3: Para pesquisar um projeto, selecione o "Centro Resultado" , "Parceiro" , "Coordenador" , "Colaborador" ou "Função"…](https://ajuda.sankhya.com.br/hc/article_attachments/15449162203159) **"Aplicar"**.

Tendo sido efetuada a consulta, através de um duplo clique sobre o projeto escolhido, você será redirecionado para a tela [Projeto](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597194-Projetos), possibilitando assim a visualização de detalhes acerca do mesmo.

### Botões da tela

Por meio do botão ![Configurar](https://ajuda.sankhya.com.br/hc/article_attachments/15449248727831) **"Configurar grade"**, você poderá selecionar as colunas que deseja para apresentarem informações sobre o projeto na grade inferior da tela.

O botão ![Imagem 5: O botão "Exportar grade para PDF" apresenta opções de exportação e visualização das informações da tela. Você poderá…](https://ajuda.sankhya.com.br/hc/article_attachments/19275770900887) **"Exportar grade para PDF"** apresenta opções de exportação e visualização das informações da tela. Você poderá entre **"Exportar para PDF"**, **"Exportar para planilha"** ou **"Exportar para cubo"**.

Através do botão ![Imagem 6: Através do botão "Filtros" , você poderá configurar novos filtros personalizados para a tela.](https://ajuda.sankhya.com.br/hc/article_attachments/15449270087063) **"Filtros"**, você poderá configurar novos filtros personalizados para a tela.

Acionando o botão ![sankhya](https://ajuda.sankhya.com.br/hc/article_attachments/15449270090647) **"Sankhya Place"**, o sistema o redirecionará para a tela de mesmo nome, em que exibirá conteúdos e soluções referentes a tela estará inserido.
