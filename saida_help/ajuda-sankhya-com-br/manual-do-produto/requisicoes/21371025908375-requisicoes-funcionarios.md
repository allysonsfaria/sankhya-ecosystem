# Requisições Funcionários

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310388224151) Módulo: Pessoal+ > Rotinas Folha
```

---

Esta é uma tela gerencial destinada aos usuários que pertencem ao DP/RH. Através desta rotina é possível analisar, aprovar ou rejeitar as requisições recebidas originadas da tela [Requisições](https://ajuda.sankhya.com.br/hc/pt-br/articles/360059085273) e/ou [PortalRH](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108433) / App [Sankhya Pessoas+](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045176453).

![Imagem 2: Esta é uma tela gerencial destinada aos usuários que pertencem ao DP/RH. Através desta rotina é possível analisar,…](https://ajuda.sankhya.com.br/hc/article_attachments/21371339217303)

Utilize o campo **"Selecione uma empresa"** para escolher se quer visualizar as requisições de uma empresa específica ou de todas que estejam cadastradas no sistema.

Para facilitar ainda mais a busca dessas requisições tem-se ainda o botão **"Filtrar"** no qual pode-se escolher a visualização dos seguinte tipos: **"Todas"**, **"Cancelada"**, **"Aguardando aprovação DP/Líder"**, **"Aprovada"**, **"Rejeitada"**, **"Afastamento"**, **"Ajuste de Ponto"**, **"Alteração de Endereço"**, **"Benefício"**, **"Dependente"**, **"Rescisão"** e **"Solicitação de Férias"**.

Ao clicar no card da requisição será exibido um pop-up com as principais informações pertinentes a cada tipo. 

![Imagem 3: Ao clicar no card da requisição será exibido um pop-up com as principais informações pertinentes a cada tipo.](https://ajuda.sankhya.com.br/hc/article_attachments/21371870746263)

Para aprovar ou rejeitar, basta clicar nos botões correspondentes a ação desejada. 

Nessa tela também é possível disponibilizar o acesso ao Portal Rh dos funcionários que ainda não tem, para isso é só clicar no botão **"Atualizar usuários do Portal RH"** localizado no canto inferior direito da tela e confirmar a ação.
