# Componentes de Manufatura

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312767903767) Módulo: Produção > Cadastros
```

---

Pode-se entender como Componentes de Manufatura, as partes de um produto acabado, que possuem uma ligação estreita com o processo produtivo em si.

Em alguns casos, um componente pode conter uma estrutura, na qual é composto por outros componentes. Ele pode ainda, possuir um ou mais componentes, com suas respectivas quantidades.

Nesta tela, você tem a possibilidade de cadastrar Componentes de Manufatura, bem como vinculá-lo a outro componente, tornando o primeiro filho do segundo.

**Observação:** antes de acessar esta tela, é preciso realizar a definição da Máscara para Componentes de Manufatura; essa definição é feita na tela [Máscara para Componentes de Manufatura](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597354).

![Imagem 2: Observação: antes de acessar esta tela, é preciso realizar a definição da Máscara para Componentes de Manufatura ; essa…](https://ajuda.sankhya.com.br/hc/article_attachments/8823093260823)

O campo **"Cód. Componente"** identifica o código do componente, seguindo o cadastro previamente realizado na tela Máscara para Componentes de Manufatura.

Informe a **"Descrição"** do Componente de Manufatura.

No campo **"Analítico"**, defina se o componente é Analítico ou Sintético. Lembrando que um componente analítico, não admite nenhum componente filho; o componente é o cadastro feito no último nível.

Através da marcação **"Ativo"**, determine se o componente está ou não ativo.

Na aba **"Geral"**, informe a **"Quantidade"** necessária para compor seu componente pai. Caso não seja especificada nenhuma quantidade para este campo, o sistema automaticamente irá preenchê-lo com a quantidade **"1"**.
