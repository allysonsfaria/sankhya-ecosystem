# Repositório de PA

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312736731543) Módulo: Produção > Cadastros
```

---

Um repositório, trata-se de uma estrutura em que se deposita, guarda e organiza os estoques de Produtos Acabados (PA's) dentro de um [Processo Produtivo](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044611314). É uma estrutura independente do controle de estoque do sistema e pode ser utilizada por qualquer Processo Produtivo.

Através desta estrutura, você pode visualizar quanto de cada Produto Acabado (PA) está sendo processado e em qual fase do processo produtivo ele se encontra. Dentro da estrutura teórica, o Repositório de PA seria uma espécie de local para o processo de trabalho.

Nesta tela, nós realizamos o cadastro dos repositórios de produtos acabados.

![Imagem 2: Nesta tela, nós realizamos o cadastro dos repositórios de produtos acabados.](https://ajuda.sankhya.com.br/hc/article_attachments/1500000346282)

No campo **"Cód. Repositório"** temos o código identificador do repositório, que pode ser preenchido de forma automática pelo sistema, ou de forma manual, dependendo da configuração realizada na opção **"Numeração"** do botão ![Imagem 3: No campo "Cód. Repositório" temos o código identificador do repositório, que pode ser preenchido de forma automática…](https://ajuda.sankhya.com.br/hc/article_attachments/16843176324887) **"Configuração da tela"**.

Informe no campo **"Descrição"** o nome do repositório que você está sendo. Este campo é de preenchimento obrigatório.
