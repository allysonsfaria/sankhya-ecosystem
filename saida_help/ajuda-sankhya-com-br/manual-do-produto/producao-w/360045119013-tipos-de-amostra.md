# Tipos de Amostra

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312784140695) Módulo: Produção > Cadastros
```

---

Nesta tela são realizados os cadastros dos Tipos de Amostra que serão utilizados no [Processo Produtivo](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044611314).

Inicialmente, será informe o **"Cód. Tipo Amostra"** que equivale ao código identificador do Tipo de Amostra. Este campo poderá ser preenchido de forma automática pelo sistema, ou de forma manual, dependendo da configuração realizada na opção **"Numeração"**, botão ![Imagem 2: Inicialmente, será informe o "Cód. Tipo Amostra" que equivale ao código identificador do Tipo de Amostra . Este campo…](https://ajuda.sankhya.com.br/hc/article_attachments/16844804028823)**"Configuração da tela"**.

Aponte no campo **"Descrição"**, o nome do tipo de amostra que está sendo cadastrado.

A marcação **"Desmembrar"** tem como funcionalidade fragmentar a amostra em "N" novas amostras, conforme a necessidade. Sendo assim, as amostras cujo o tipo de amostra possuem esta opção acionada, permitiram o desmembramento na rotina [Registro de Amostras](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044611334).

Normalmente esta opção é utilizada em ambientes onde se colhe uma única amostra no local de armazenamento do produto (como, por exemplo no almoxarifado), e no laboratório essa amostra é desmembrada (fragmentada) em "N" novas amostras, conforme a quantidade de ensaios (testes) que serão realizados durante o processo de qualidade para aquele produto/lote. A seguir, teremos um exemplo:

A amostra recolhida no recebimento do produto é igual à 150ml. No laboratório está amostra é quebrada em 3 novas amostras:

- Amostra 1: 50ml para ensaio físico-químico;
- Amostra 2: 50ml para ensaio organoléptico;
- Amostra 3: 50ml para ensaio microbiológico.

![Imagem 3: Amostra 3: 50ml para ensaio microbiológico.](https://ajuda.sankhya.com.br/hc/article_attachments/8879372448791)

Dentro de cada tipo de amostra, você poderá definir os usuários que irão realizar cada amostra. Esta definição é realizada através da aba **"Usuário por Tipo de Amostra"**, na qual são apresentados os seguintes campos para preenchimento:

Defina no campo **"Usuário"**, o usuário que irá exercer determinada manipulação sobre a amostra.

No campo **"Tipo Manipulação"** é feita a determinação do tipo de manipulação que o usuário irá desempenhar sobre a amostra. São disponibilizadas as seguintes opções de escolha:

- Analista;
- Verificador;
- Amostrador.
