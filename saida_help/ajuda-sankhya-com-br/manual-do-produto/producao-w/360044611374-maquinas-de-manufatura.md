# Máquinas de Manufatura

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312707448215) Módulo: Produção > Cadastros
```

---

Nesta tela, você cadastra as Máquinas de Manufatura presentes em uma planta. As máquinas aqui cadastradas, são as que necessitam de controle de uso e manutenção.

![Imagem 2: Nesta tela, você cadastra as Máquinas de Manufatura presentes em uma planta. As máquinas aqui cadastradas, são as que…](https://ajuda.sankhya.com.br/hc/article_attachments/8840362786327)

**Cód. Máquina:** temos neste campo, o código identificador da máquina, que pode ser preenchido de forma automática pelo sistema, ou de forma manual, dependendo da configuração realizada na opção **"Numeração"** do botão ![Imagem 3: Cód. Máquina: temos neste campo, o código identificador da máquina, que pode ser preenchido de forma automática pelo…](https://ajuda.sankhya.com.br/hc/article_attachments/16676189287831) **"Configuração da tela"**.

**Nome:** utilize este campo para detalhar a descrição da máquina de manufatura que está sendo cadastrada.

**Planta de Manufatura:** informe aqui, a planta de manufatura a qual a máquina pertence.

**Categoria de Recurso:** neste campo, informe a categoria de recurso a qual a máquina de manufatura pertence. Serão apresentadas para escolha neste campo, os dados analíticos cadastrados na tela [Categorias de Recurso](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045119273) do tipo **"Máquina"**. Assim como os dois últimos campos apresentados, este também é de preenchimento obrigatório.
