# Grupo de Questionários

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42315006245271) Módulo: Pesquisa e Consulta > Cadastros
```

---

Os **"Questionários"** fazem parte de **"Grupos"**, por isto, antes de cadastrar um novo Questionário, é necessário configurar os grupos aos quais estes pertencerão.

Os códigos dos grupos, são formados em níveis, os quais estão pré-configurados com a Máscara (ou estrutura) dos níveis.

Antes de cadastrar um novo grupo de questionário, defina para ele uma máscara através do parâmetro **"Máscara para código de grupo de questionário - MASCGPTQUEST"**.

**Observação:** a máscara somente poderá ser definida, na primeira vez que é acessada, sendo que, uma vez configurada, não deverá ser alterada.

Na rotina de Grupo de Questionários, cadastre os grupos aos quais os questionários pertencerão.

![Imagem 2: Na rotina de Grupo de Questionários , cadastre os grupos aos quais os questionários pertencerão .](https://ajuda.sankhya.com.br/hc/article_attachments/360078322133)

Os cadastros são feitos de forma hierárquica. Para inserir um novo grupo, você deverá clicar no botão ![Imagem 3: Os cadastros são feitos de forma hierárquica . Para inserir um novo grupo, você deverá clicar no botão " Novo" e…](https://ajuda.sankhya.com.br/guide-media/01H3HR6FM69B07W9AW8ZTDNMH3) **"Novo"** e configurar:

O **"Código"** do grupo.

Na **"Descrição"**, o nome do grupo.

A marcação **"Ativo"** para determinar que o grupo está ativo (quando habilitada), ou inativo (quando desabilitada).

A marcação **"Analítico"** deve ser do último nível na hierarquia, visto que, não poderá ter filhos.

Feito isto, confirme o cadastro.
