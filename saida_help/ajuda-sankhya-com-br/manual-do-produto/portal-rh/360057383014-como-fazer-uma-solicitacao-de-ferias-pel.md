# Como fazer uma solicitação de férias pelo Portal RH

Para fazer uma requisição de férias, o funcionário deve acessar o [Portal RH](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108433). Para isso, seu acesso deve ter sido providenciado previamente pela equipe de Departamento Pessoal.

![Imagem 1: Para fazer uma requisição de férias, o funcionário deve acessar o Portal RH . Para isso, seu acesso deve ter sido…](https://ajuda.sankhya.com.br/hc/article_attachments/14599483143703)

Uma vez logado no Portal RH, entre as opções ao lado esquerdo da tela, será apresentado o ícone ‘Férias’. Clique sobre ele para solicitar as Férias ao Líder imediato e/ou Departamento Pessoal, que ficará encarregado pela Aprovação das Férias.

![Imagem 2: Uma vez logado no Portal RH, entre as opções ao lado esquerdo da tela, será apresentado o ícone ‘Férias’. Clique sobre…](https://ajuda.sankhya.com.br/hc/article_attachments/14599881584407)

Serão dispostas na tela as informações pré-definidas pelo sistema, como a data do ‘**Período aquisitivo**’ para o qual está pendente o agendamento das férias.

![Imagem 3: Serão dispostas na tela as informações pré-definidas pelo sistema, como a data do ‘ Período aquisitivo ’ para o qual…](https://ajuda.sankhya.com.br/hc/article_attachments/14599894297239)

Se tratando do primeiro agendamento de férias, o sistema traz um registro padrão, com status “Aguardando solicitação”, projetando por padrão que as férias aconteçam ao final do período concessivo, que é o prazo máximo para gozo das férias. Se desejar alterar a programação padrão para outra que melhor lhe convier, clique no ícone **‘Alterar Solicitação**’.

![Imagem 4: Se tratando do primeiro agendamento de férias, o sistema traz um registro padrão, com status “Aguardando solicitação”,…](https://ajuda.sankhya.com.br/hc/article_attachments/14600069636119)

Ao acionar esse botão, serão apresentados cards para que o funcionário indique o ‘Início das férias’, quantos são os ‘**Dias de férias’**, **‘Dias de abono’** pretendidos e se haverá ‘**Adiantamento 13**º’.

![Imagem 5: Ao acionar esse botão, serão apresentados cards para que o funcionário indique o ‘Início das férias’, quantos são os ‘…](https://ajuda.sankhya.com.br/hc/article_attachments/14600120636567)

Depois de realizar os ajustes, clique em **‘Confirmar alteração de solicitação’**.

![Imagem 6: Depois de realizar os ajustes, clique em ‘Confirmar alteração de solicitação’ .](https://ajuda.sankhya.com.br/hc/article_attachments/14600112041239)

Dessa forma, retornamos para a tela anterior, na qual podemos observar que o status da solicitação passará para ‘Pendente’ e as informações da ‘Data do pedido’, ‘Data de início’ e ‘Data de retorno’ serão apresentadas conforme requisitado pelo funcionário.

![Imagem 7: Dessa forma, retornamos para a tela anterior, na qual podemos observar que o status da solicitação passará para…](https://ajuda.sankhya.com.br/hc/article_attachments/14600164763159)

Na parte inferior da tela é apresentado o resumo da quantidade de dias solicitados e vendidos e, ainda, se o funcionário solicitou o adiantamento do 13º.

![Imagem 8: Na parte inferior da tela é apresentado o resumo da quantidade de dias solicitados e vendidos e, ainda, se o…](https://ajuda.sankhya.com.br/hc/article_attachments/14600216097431)

Ao acionar o botão “Timeline”, o portal exibirá a solicitação feita pelo colaborador, para acompanhamento do seu status. Caso queira excluir a requisição, passe o cursor do mouse sobre a requisição e acione o botão ‘Cancelar requisição’.

![Imagem 9: Ao acionar o botão “Timeline”, o portal exibirá a solicitação feita pelo colaborador, para acompanhamento do seu…](https://ajuda.sankhya.com.br/hc/article_attachments/14600299187863)

Se for necessária qualquer alteração na solicitação de férias, ela poderá ser feita da mesma forma que apresentamos, desde que a requisição ainda esteja Pendente.

Posteriormente, ao realizar a aprovação das férias, o sistema emitirá uma mensagem informando que as mesmas foram agendadas com sucesso.
