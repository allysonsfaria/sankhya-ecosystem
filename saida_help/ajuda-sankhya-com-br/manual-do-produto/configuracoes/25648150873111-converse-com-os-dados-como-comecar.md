# Converse com os Dados. Como começar?

Use a tela **Converse com os Dados** para interagir com seus dados de forma inovadora. Com o suporte de inteligência artificial e processamento avançado de linguagem natural, esse recurso permite que você faça perguntas diretas sobre os dados da empresa — como se estivesse conversando com um especialista em análise de dados.

### Como começar?

Para utilizar o **Converse com os Dados**, é necessário:

1. Instalar uma Skill.
2. Realizar as configurações iniciais (consulte o artigo [Analytics AI](https://ajuda.sankhya.com.br/hc/pt-br/articles/25640296222231-Analytics-AI)).

---

### Fazendo perguntas de negócio

Após instalar a Skill, siga os passos:

1. Acesse a tela **Converse com os Dados**. (Acesse [Instalação e Configuração das Skills](https://ajuda.sankhya.com.br/hc/pt-br/articles/25640296222231-Analytics-AI))
2. Selecione uma Skill.
3. Faça uma pergunta de negócio.

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=h7dhRMwekAg)

O **Converse com os Dados** vai interpretar sua pergunta e gerar automaticamente uma **visualização** (view) com a resposta mais adequada, combinando métricas, perspectivas e filtros com base nos dados disponíveis na Skill.

### Validando a resposta gerada

Após visualizada a resposta, você pode conferir como ela foi construída:

1. Clique em **Visualizar gráfico em tela cheia**.
2. Em seguida, selecione **Como cheguei nesse resultado?**.

Essa opção mostra as **regras de negócio**, dados, colunas, agrupadores e filtros usados para gerar o gráfico.

**Importante:** o **Converse com os Dados** usa apenas os dados disponíveis na Skill selecionada.
