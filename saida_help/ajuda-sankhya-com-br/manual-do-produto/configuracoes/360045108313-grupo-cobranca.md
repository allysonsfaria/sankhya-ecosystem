# Grupo Cobrança

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310871701783) Módulo: Configurações > Cadastros
```

---

Esta tela permite criar classificações que podem ser associadas aos Parceiros a fim de realizar a segmentação dos mesmos na [Régua de Cobrança](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044602534), conforme o nível de inadimplência de cada um. Sendo que, esta associação será realizada no [Cadastro de Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494-Parceiros), aba [Identificação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494-Parceiros#abaidentificao), campo **"Grupo Cobrança"**.

![Imagem 2: Esta tela permite criar classificações que podem ser associadas aos Parceiros a fim de realizar a segmentação dos…](https://ajuda.sankhya.com.br/hc/article_attachments/8983621586071)

O campo **"Código"** é alimentado de forma manual ou automática; esta definição é feita através do botão ![Imagem 3: O campo "Código" é alimentado de forma manual ou automática; esta definição é feita através do botão "Configuração da…](https://ajuda.sankhya.com.br/hc/article_attachments/16428291101079) **"Configuração da Tela"** localizado na parte superior direita da tela. Informa-se neste campo, a chave do grupo de cobrança no sistema, ou seja, esta numeração será responsável por identificá-lo em todas as rotinas em que ele estiver presente.

Por meio do campo **"Descrição"** aponta-se o nome do grupo que está sendo criado.
