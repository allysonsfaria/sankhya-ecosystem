# Máscara para Grupo de Relatórios

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310879091863) Módulo: Configurações > Avançado > Máscaras
```

---

![clip0504](https://ajuda.sankhya.com.br/hc/article_attachments/360060989014)

Através desta tela, é possível efetuar a configuração/criação de Máscaras para Grupo de Relatórios.

A tela bloqueia a alteração da máscara quando já houver Grupos de Relatórios cadastrados com a configuração realizada.

É possível definir quantos níveis terá a estrutura (máximo: 4) e quantos dígitos haverá em cada nível (máximo: 3). O tamanho máximo de código permitido é de nove dígitos válidos.

**Exemplo:** 9.99.999.999.
