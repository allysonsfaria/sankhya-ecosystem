# MGEScript

O MGE Script é um aplicativo para atualização de scripts da database para o Sankhya MGE que permite uma atualização de maneira simples e direta, com funcionalidades que se adequem às necessidades do usuário final.

Para baixar o aplicativo, acesse a [Central de Downloads Sankhya](http://downloads.sankhya.com.br/), aba **"Ferramentas"**, opção **"Outras Ferramentas"**:

[GIF animado: Imagem 1: Para baixar o aplicativo, acesse a Central de Downloads Sankhya , aba "Ferramentas" , opção "Outras Ferramentas" :](https://ajuda.sankhya.com.br/hc/article_attachments/9057660231575)

Abaixo demonstramos um fluxo completo de execução, apresentando as principais funcionalidades de cada passo do processo de atualização.

A tela de Conexões é a tela inicial da aplicação, e serve para gerenciar as conexões com as seguintes funcionalidades:

**1 -** Adicionar dados de conexão através do botão **"+Novo"**;

**2 -** Testar e salvar dados de conexão através dos botões **"Salvar"** e **"Testar Conexão"**:

[GIF animado: Imagem 2: 2 - Testar e salvar dados de conexão através dos botões "Salvar" e "Testar Conexão" :](https://ajuda.sankhya.com.br/hc/article_attachments/8840659640471)

**3 -** Iniciar o atualizador de script para a conexão selecionada;

[GIF animado: Imagem 3: 3 - Iniciar o atualizador de script para a conexão selecionada;](https://ajuda.sankhya.com.br/hc/article_attachments/8840669394583)

Observe acima que, após clicar no botão **"Atualizar Scripts"**, a aplicação detecta a sua versão atual de script no banco de dados e te questiona para qual versão você quer atualizar.

Durante a atualização, uma tela de registro de execução te mostra as informações do andamento das operações, como o **"Retorno textual de operações"**, a **"Barra de progresso com botão de cancelamento"** e o **"Possível aviso de limite de saída"**:
