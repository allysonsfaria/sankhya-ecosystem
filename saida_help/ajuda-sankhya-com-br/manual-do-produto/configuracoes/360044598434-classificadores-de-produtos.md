# Classificadores de Produtos

```
![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42310661683479) Módulo: Configurações > Cadastros > Produtos
```

---

Nesta tela, você configura os classificadores de produtos, ou seja, determina as categorias responsáveis por classificar os produtos. Assim, será possível filtrar estes produtos através de sua classificação, utilizando o [Painel Classificadores](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109353-Consulta-de-Produtos#painelclassificadores) da [Consulta de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109353-Consulta-de-Produtos).

Para realizar a criação das classificações, acione o botão ![Imagem 2: Para realizar a criação das classificações, acione o botão "Cadastrar classificação" e efetue a inserção da descrição…](https://ajuda.sankhya.com.br/hc/article_attachments/16108876239511) **"Cadastrar classificação"** e efetue a inserção da descrição do novo cadastro.

[GIF animado: Imagem 3: Para realizar a criação das classificações, acione o botão "Cadastrar classificação" e efetue a inserção da descrição…](https://ajuda.sankhya.com.br/hc/article_attachments/360086882474)

Ao finalizar as devidas inserções, no modo grade, é possível visualizar as classificações cadastradas:

[GIF animado: Imagem 4: Ao finalizar as devidas inserções, no modo grade, é possível visualizar as classificações cadastradas:](https://ajuda.sankhya.com.br/hc/article_attachments/360086881494)

O próximo passo, é criar a Estrutura dos classificadores. Essa estrutura será visualizada no Painel Classificadores da Consulta de Produtos. Para fazer, selecione na grade, a classificação que se deseja adicionar como estrutura e efetue uma das seguintes opções:

- Acione o botão ![Imagem 5: Acione o botão "Adicionar classificador na estrutura de classificadores" ou ;](https://ajuda.sankhya.com.br/hc/article_attachments/16108968965527) **"Adicionar classificador na estrutura de classificadores"**ou;
- Dê um duplo clique sobre a referida classificação.

Observe abaixo como o procedimento é facil:

[GIF animado: Imagem 6: Observe abaixo como o procedimento é facil:](https://ajuda.sankhya.com.br/hc/article_attachments/360088019573)

Para que uma classificação se torne um sub-item de outra, o item **"Pai"** deverá estar selecionado no painel Estrutura dos classificadores quando o item **"Filho"** for inserido na estrutura.

Para remover um item do painel Estrutura dos classificadores, basta que você selecione-o e clique no botão ![Imagem 7: Para remover um item do painel Estrutura dos classificadores , basta que você selecione-o e clique no botão "Remover…](https://ajuda.sankhya.com.br/hc/article_attachments/16109017010327) **"Remover classificador na estrutura de classificadores"** ou execute um duplo clique sobre o mesmo. Sendo que, ao selecionar um item Pai para exclusão, todos os itens Filhos serão eliminados juntamente.

[GIF animado: Imagem 8: Para remover um item do painel Estrutura dos classificadores , basta que você selecione-o e clique no botão "Remover…](https://ajuda.sankhya.com.br/hc/article_attachments/360088019653)

Ao final, teremos a concretização dos classificadores de produtos com suas devidas estruturas:

![Imagem 9: Ao final, teremos a concretização dos classificadores de produtos com suas devidas estruturas:](https://ajuda.sankhya.com.br/hc/article_attachments/360086881954)

Esta categorização dos produtos é efetuada através do campo **"Classificação"**, localizado na aba [Classificação por Produto](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Produtos-#abaclassificaoporproduto) do [Cadastro de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Produtos-), sendo que, um produto poderá receber mais de uma classificação.
