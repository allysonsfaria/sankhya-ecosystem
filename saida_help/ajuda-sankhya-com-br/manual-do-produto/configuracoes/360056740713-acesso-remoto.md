A funcionalidade desta tela consiste em permitir que os analistas da Sankhya tenham acesso à base de clientes para a realização de manutenções durante um determinado período. Assim, a identificação de impasses será mais ágil.

Para isso, atente-se que se o Sistema Operacional do servidor seja LINUX é necessário instalar o netstat, recurso essencial para obter informações sobre as conexões de rede. Este encontra-se disponível para download na [Central de downloads Sankhya](https://downloads.sankhya.com.br/downloads?app=outros&c=1).

![Imagem 3: O Acesso Remoto será permitido apenas em bases de teste, ou seja, aquelas com registro diferente de "Produção" . Além…](https://ajuda.sankhya.com.br/hc/article_attachments/18981545196439) O Acesso Remoto será permitido apenas em bases de teste, ou seja, aquelas com registro diferente de **"Produção"**. Além disso, as empresas precisam estar com o ambiente NFE diferente de Produção.

Sendo assim, para realizar a abertura da conexão remota acesse a tela Acesso Remoto, clique no botão ![Imagem 4: Sendo assim, para realizar a abertura da conexão remota acesse a tela Acesso Remoto , clique no botão "Cadastrar Acesso…](https://ajuda.sankhya.com.br/hc/article_attachments/16502385371671) **"Cadastrar Acesso Remoto"** e em seguida preencha os seguintes campos:

![Imagem 5: Sendo assim, para realizar a abertura da conexão remota acesse a tela Acesso Remoto , clique no botão "Cadastrar Acesso…](https://ajuda.sankhya.com.br/hc/article_attachments/24794801676695)

**Descrição:** deve-se inserir neste campo uma breve descrição da razão pela qual a sessão foi aberta.

**Núm. OS/Ticket:** campo destinado à inclusão dos dados do ticket aberto através da nossa central de atendimento.

**Limite da sessão**: neste campo define-se o prazo em que a sessão permanecerá aberta, sendo por padrão o período mínimo de 15 dias.

**Usuário do Banco de Dados** e **Senha do Banco de Dados**: estes campos são direcionados às credenciais de acesso ao banco de dados que o consultor de atendimento irá utilizar para prestação do suporte.

**Termo de Ciência:** através do hiperlink estará disponível o termo de ciência da conexão remota ao servidor de aplicação para manutenção.

Apenas uma sessão poderá estar aberta por ambiente, caso exista outra sessão aberta será emitido o seguinte alerta ao salvar as informações do formulário:

**"Apenas uma sessão de acesso remoto está permitida simultaneamente. Para iniciar uma nova conexão, encerre a sessão xxxx atual."**

Durante o processo de atendimento, as portas 2278 e 9999 devem estar liberadas para saída e conexão local. Adicionalmente, no caso de múltiplos links de internet ativos, é necessário criar uma rota fixa para o endereço IP 52.67.170.56 e assegurar que o tráfego para esse IP esteja devidamente liberado para entrada e saída.

**Observação:** para ambientes que utilizam como sistema operacional o Linux é necessário instalar o netstat, esse recurso é necessário para se obter informações sobre as conexões de rede, e está disponível no [Portal de Download](https://downloads.sankhya.com.br/downloads?app=outros&c=1).

Após criar a conexão, os campos referentes às senhas do Banco de Dados e do **Sankhya Om** serão submetidos a um processo de criptografia para garantir a segurança dos dados. Assim, será automaticamente gerada a **"Chave de Acesso"**. Essa chave deve ser encaminhada à Sankhya por meio do ticket aberto.

![Imagem 6: Devido à criptografia utilizada, a quantidade de caracteres apresentados no campo " Senha do Sankhya OM " será maior do…](https://ajuda.sankhya.com.br/hc/article_attachments/18981545196439) Devido à criptografia utilizada, a quantidade de caracteres apresentados no campo **"Senha do Sankhya OM"** será maior do que a que foi digitada inicialmente.

Após esse procedimento, inicia-se o período definido da sessão, durante o qual os campos **"Autorizado por"** e **"Sessão aberta em"** serão preenchidos automaticamente. 

**Nota:** para encerrar a sessão basta desabilitar o campo Ativo, assim o consultor de atendimento perderá o acesso à aplicação.
