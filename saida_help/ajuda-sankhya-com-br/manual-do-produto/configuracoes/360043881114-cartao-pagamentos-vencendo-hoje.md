# Cartão Pagamentos vencendo hoje

Veja de forma prática e rápida o que você tem a pagar hoje até o final do mês sem nenhuma surpresa. Além disto, é possível realizar filtros por Empresa através da opção **"Personalizar"** localizada no botão ![Imagem 1: Veja de forma prática e rápida o que você tem a pagar hoje até o final do mês sem nenhuma surpresa. **Sugestão automática de cartões:**

O sistema atualiza automaticamente os acessos dos cartões e isto acontece de forma dinâmica sem necessitar de uma intervenção humana, a partir dos acessos atuais de cada usuário. Logo, ao atualizar pela primeira vez para esta versão ou se o usuário for um recém configurado, o sistema irá liberar este cartão somente se o usuário possuir acesso a todas as respectivas telas:

- **Movimentação financeira**: Acesso a baixa de despesa;
- **Agenda financeira**: Acesso a pelo menos de Consulta;
- **Cadastro de Usuários:** Campo Acesso a baixa de despesas.

**Importante:**

- O sistema realizará a liberação destes acessos uma vez ao dia em um horário no qual não comprometa as execuções normais das rotinas do sistema.
- Caso a sugestão oferecida pelo sistema não corresponda a uma necessidade real do usuário, basta retirar o acesso ao card na tela de [Acessos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596854), e selecionar o módulo **"Configurações"**, e em seguida, [Cartões Inteligentes](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044355393), para que assim, o sistema não realize a sugestão de nenhum outro cartão.
