### Liberando Acessos Padrão

Os acessos padrão são de Inclusão, Alteração, Exclusão, Consulta, Configuração e Numeração nas rotinas do sistema. Além disso, caso o parâmetro **"Controla acesso de duplicação de registros? - CONTACESSDUPLIC"** esteja habilitado, será possível estabelecer permissões ao ato de Duplicar os registros em todas as telas do sistema.

Já o parâmetro **"Valida acesso alterações em notas não confirmadas - VALACESSONOTA"** define se o acesso **Alterar** é verificado nas notas não confirmadas das Centrais e dos Portais:

- **Ligado:** o usuário só altera a nota se tiver o acesso **Alterar** liberado. Incluir itens também conta como alteração, então o usuário precisa dos acessos **Incluir** e **Alterar**.
- **Desligado:** o acesso **Alterar** não é verificado, e o usuário consegue alterar a nota mesmo sem essa permissão.

Ao selecionar um módulo ou pasta para concessão de acesso, o sistema só permite que sejam configurados acessos padrão. As ações que necessitam de acessos especiais deverão ser realizadas diretamente para cada pessoa (usuário do sistema) desejado. Será apresentada a seguinte mensagem:

**"Você selecionou um Módulo ou Pasta que possui Filhos. Com esta seleção, será permitido alterar apenas acessos padrões (Alterar, Incluir, Excluir, Consultar, Configurar e Numeração). Caso queira definir acessos especiais, selecione individualmente itens analíticos."**

Por exemplo, para liberar um acesso aos **"Cadastros"** do módulo **"Configurações"**, o liberador deve acessar, primeiramente, o Módulo Configurações e, em seguida, selecionar a pasta Cadastros.

[GIF animado: Imagem 3: Por exemplo, para liberar um acesso aos " Cadastros " do módulo " Configurações " , o liberador deve acessar,…](https://ajuda.sankhya.com.br/hc/article_attachments/360071992374)

Então, serão apresentados todos que possuem algum tipo de acesso à qualquer uma das telas de Cadastro do Módulo Configurações, permitindo ao liberador adicionar ou remover estes usuários.

Ao clicar em um destes usuários, serão apresentados os acessos padrões disponíveis a ele.

![Imagem 4: Ao clicar em um destes usuários, serão apresentados os acessos padrões disponíveis a ele.](https://ajuda.sankhya.com.br/hc/article_attachments/23321765639831)

Observe que, como foi selecionada uma pasta (Cadastros) o sistema não apresenta os acessos específicos do usuário, pois, dentro do Módulo de Configurações existem várias telas de cadastros e, pode ser que este usuário não tenha permissão para acessar estas telas.

Neste nível são apresentadas as opções **"Padrão"** e não as **"Específicas"**, logo, estes acessos serão configurados para todo o conteúdo da pasta Cadastros.

![Imagem 5: Neste nível são apresentadas as opções " Padrão " e não as " Específicas " , logo, estes acessos serão configurados…](https://ajuda.sankhya.com.br/hc/article_attachments/360073254973)

No exemplo da imagem acima, o usuário Andrey terá acesso de Inclusão à todas as telas de Cadastro do módulo Configurações; em contrapartida, as Alterações serão possíveis somente nas telas configuradas para o grupo ao qual o usuário dela pertence.

Para marcar ou desmarcar todas as opções bastará um clique sobre os links: **"Permitido"**, **"Usar do Grupo"** e **"Repassar"**:

[GIF animado: Imagem 6: Para marcar ou desmarcar todas as opções bastará um clique sobre os links: " Permitido " , " Usar do Grupo " e "…](https://ajuda.sankhya.com.br/hc/article_attachments/360073255133)

O responsável por esta liberação, deverá configurar os acessos marcando as caixas de seleção das respectivas ações que serão permitidas para aquela tela.

Existem as seguintes opções:

- **Permitido:** Permite a ação, por exemplo, de incluir, alterar, etc. conforme o definido.
- **Repassar:** Marcando esta opção além de o usuário ter a liberação para executar a ação, ele também poderá repassar aquela ação para outro usuário.
- **Usar do Grupo:** Define que o acesso àquela ação será o acesso definido para o grupo.

As alterações feitas nesta tela são salvas automaticamente.

Caso o liberador selecione mais um item de menu, não será possível conceder a nenhum usuário, acessos especiais à rotina destes itens:

### Liberando Acessos Especiais

Os acessos especiais são visualizados, concedidos ou removidos a partir de uma rotina especifica e são destacados em itálico, logo abaixo dos acessos padrões.

![Imagem 8: Os acessos especiais são visualizados, concedidos ou removidos a partir de uma rotina especifica e são destacados em…](https://ajuda.sankhya.com.br/hc/article_attachments/23364711014935)

Por exemplo, em relação ao Cadastro de Parceiros, o usuário Andressa, além dos acessos padrões concedidos, poderá ter acesso às rotinas **"Especiais"** deste cadastro e podendo repassar **"Consultas Ocorrências EDZ"**.

Não é possível conceder ou remover acessos especiais a mais de uma tela por vez.

Ao selecionar duas telas distintas, os acessos especiais serão ocultados, permanecendo na tela apenas os acessos padrões do usuário indicado.

Contudo, é possível dar acessos a vários usuários de uma única tela, com um único movimento. Basta selecionar a tela e, pressionando a tecla **"Ctrl"**, ir clicando nos usuários desejados.

Os usuários poderão ser pesquisados pelo campo de busca no canto superior direito da tela.

![Imagem 9: Os usuários poderão ser pesquisados pelo campo de busca no canto superior direito da tela.](https://ajuda.sankhya.com.br/hc/article_attachments/23364711018647)

Se for digitado o nome de um usuário que não tenha acesso à tela em questão, nenhum usuário será apresentado, pois, somente os que possuem algum tipo de acesso à tela selecionada serão exibidos.

Para dar acessos a este usuário, basta clicar no botão **"Adicionar"** e então filtrá-lo na tela **"Adicionando novos membros"**.

> ⚠️ **Atenção**
> Se o grupo ou usuário que você quer adicionar não aparece na lista, verifique se você mesmo pertence a esse grupo ou se está buscando pelo seu próprio usuário. O sistema não permite que você conceda acessos ao seu próprio grupo nem a si mesmo — isso é uma restrição de segurança.
> Nesses casos, peça a outro usuário com permissão de repasse — que não pertença ao grupo em questão — para realizar a liberação.

[GIF animado: Imagem 10: ⚠️ Atenção Se o grupo ou usuário que você quer adicionar não aparece na lista, verifique se você mesmo pertence a esse…](https://ajuda.sankhya.com.br/hc/article_attachments/360073256093)

Selecionando o usuário e clicando em **"Avançar"**, o liberador poderá fornecer os acessos especiais a este.

Ao **"Finalizar"**, o novo usuário será automaticamente apresentado na consulta de usuário da tela.

Da mesma forma, proceda para retirar os acessos da tela de um determinado usuário.

Selecionando o usuário e clicando no botão **"Remover"**, o liberador estará eliminando todos os acessos deste usuário àquela rotina e o sistema apresentará a seguinte mensagem de confirmação:

**"Você está prestes a remover todos os acessos do usuário selecionado no item de menu marcado. Deseja realmente remover os acessos?"**

**Importante:** o botão Remover será exibido para utilização apenas para o usuário SUP. Além disso, ao marcar algum usuário e permitir que ele repasse os acessos, não fará com que este possa repassar acessos para todas as telas do sistema, e sim, apenas para a tela Acessos.

A liberação do repasse de acessos deve ser feita dentro da tela Acessos, mas será necessário selecionar as telas individualmente (vale ressaltar que também é possível selecionar uma pasta ou até mesmo o módulo todo).

#### Acessos do usuário

Esta opção imprime um relatório com todos os acessos de um determinado usuário.

![Imagem 12: Esta opção i mprime um relatório com todos os acessos de um determinado usuário.](https://ajuda.sankhya.com.br/hc/article_attachments/23364809793687)

É necessário selecionar um usuário antes de clicar na opção Acessos do usuário; caso contrário, ao fazê-lo, o sistema abrirá a tela para seleção de um usuário.

![Imagem 13: É necessário selecionar um usuário antes de clicar na opção Acessos do usuário ; caso contrário, ao fazê-lo, o sistema…](https://ajuda.sankhya.com.br/hc/article_attachments/360073256893)

Feito isto, será exibido o relatório de acessos daquele usuário, não apenas para a tela selecionada, mas todos os seus acessos, em todas as rotinas do sistema.

#### Acessos do Recurso

Esta opção imprime um relatório com todos os usuários que possuem algum tipo de acesso nas telas selecionadas.

Para acessar esta opção, é necessário haver pelo menos um item selecionado no menu esquerdo.

![Imagem 14: Para acessar esta opção, é necessário haver pelo menos um item selecionado no menu esquerdo.](https://ajuda.sankhya.com.br/hc/article_attachments/23364796050839)

Se nenhum item de menu for selecionado e a opção Acessos do Recurso for acionada, o sistema gerará a seguinte mensagem:

**"Selecione alguma tela para imprimir os acessos!".**

Se mais de uma tela for selecionada, o sistema irá gerar o relatório para todas as telas selecionadas.

Serão apresentados neste relatório apenas os **"Usuários Ativos"**, ou seja, aqueles com **"Data limite de acesso"** nula ou maior que a data atual.

**Observação:** a marcação **"Exclui com mov. Caixa"** da tela Acessos, disponível nos Portais de [Vendas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612654-Portal-de-Vendas), [Compras](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045111953-Portal-de-Compras) e [Mov. Interna](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109593-Portal-de-Mov-Internas), é uma opção obsoleta que atualmente não é utilizada no sistema. No entanto, não pode ser removida para garantir que personalizações existentes que possam depender dessa opção não sejam afetadas.
