# Questionário Pesquisa

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310610522263) Módulo: Configurações > Avançado > Pesquisa Simplificada
```

---

Nesta tela efetua-se o cadastro dos Questionários de Pesquisa, sendo que, os mesmos serão aplicados em [Projetos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109073-Projetos) para análise de satisfação.

![QP1](https://ajuda.sankhya.com.br/hc/article_attachments/360061913973)

Para cada pergunta existe o campo **"Texto"** para que seja descrito o conteúdo da pergunta.

O campo **"Tipo"** permite selecionar qual será a modalidade da resposta.

Por meio da marcação **"Pergunta Obrigatória"**, aponta-se se a pergunta em questão tem caractere obrigatório.
