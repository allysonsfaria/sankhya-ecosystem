# Máscara para Região

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310804743959) Módulo: Configurações > Avançado > Máscaras
```

---

![clip0509](https://ajuda.sankhya.com.br/hc/article_attachments/360061921853)

Através desta tela, é possível efetuar a configuração/criação de máscaras para Região.

A tela bloqueia a alteração da máscara quando já houver regiões cadastradas com a configuração realizada.

É possível definir quantos níveis terá a estrutura (máximo: 4) e quantos dígitos haverá em cada nível (máximo: 3). O tamanho máximo de código permitido é de nove dígitos válidos.

Exemplo: 9.99.999.999.
