# Máscara para Retorno Bancário

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310722493335) Módulo: Configurações > Avançado > Máscaras
```

---

![clip0511](https://ajuda.sankhya.com.br/hc/article_attachments/360060993494)

Através desta tela, é possível efetuar a configuração/criação de máscaras para Retorno Bancário.

A tela bloqueia a alteração da máscara quando já houver Retornos Bancários cadastrados com a configuração realizada.

É possível definir quantos níveis terá a estrutura (máximo: 4) e quantos dígitos haverá em cada nível (máximo: 3). O tamanho máximo de código permitido é de nove dígitos válidos.

Exemplo: 9.99.999.999.
