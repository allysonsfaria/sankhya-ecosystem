# Máscara para Grupos de Produtos

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310874496279) Módulo: Configurações > Avançado > Máscaras
```

---

![Imagem 2](https://ajuda.sankhya.com.br/hc/article_attachments/360077277793)

Através desta tela, é possível efetuar a configuração/criação de Máscaras para Grupos de Produtos.

A tela bloqueia a alteração da máscara quando já houver Grupos de Produtos cadastrados com a configuração realizada.

É possível definir quantos níveis terá a estrutura (máximo: 4) e quantos dígitos haverá em cada nível (máximo: 3). O tamanho máximo de código permitido é de nove dígitos válidos.

**Exemplo:** 9.99.999.999.
