# Controle de Jobs

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310566267927) Módulo: Configurações > Avançado
```

---

Esta tela fornece as informações e permite o controle das ações que estão sendo executadas no servidor. Deste modo, você poderá pausar ou reiniciar uma tarefa que estiver sendo executada.

![Imagem 2: Esta tela fornece as informações e permite o controle das ações que estão sendo executadas no servidor. Deste modo,…](https://ajuda.sankhya.com.br/hc/article_attachments/360061910353)

Observe que na lateral esquerda da tela você encontrará os filtros que lhe permitiram localizar um Job específico com maior facilidade e rapidez. Levando em consideração o Código do Job, sua Descrição, seu Tipo, se o mesmo está Ativo ou não, bem como, seu Status atual.

Além disso, na parte superior da tela são disponibilizados alguns botões que influenciam diretamente no seu funcionamento. Vejamos sobre os mesmos:

 ![Imagem 3: - Este botão permite que você atualize o status dos Jobs naquele momento.](https://ajuda.sankhya.com.br/hc/article_attachments/16845281266071) - Este botão permite que você atualize o status dos Jobs naquele momento.

![Imagem 4: - Utilize este botão quando desejar iniciar o Job imediatamente.](https://ajuda.sankhya.com.br/hc/article_attachments/360060980154) - Utilize este botão quando desejar iniciar o Job imediatamente.

![Imagem 5: - Através deste botão, efetue a pausa do agendamento dos Jobs.](https://ajuda.sankhya.com.br/hc/article_attachments/360060980174) - Através deste botão, efetue a pausa do agendamento dos Jobs.

![Imagem 6: - Caso seja necessário desativar algum Job, clique neste botão.](https://ajuda.sankhya.com.br/hc/article_attachments/360061910373) - Caso seja necessário desativar algum Job, clique neste botão.

![Imagem 7: - Ao acionar este botão, será possível visualizar em um pop-up o resumo do erro que ocorreu durante a execução do Job.](https://ajuda.sankhya.com.br/hc/article_attachments/360060980194) - Ao acionar este botão, será possível visualizar em um pop-up o resumo do erro que ocorreu durante a execução do Job.

![Imagem 8: - Este campo permite que você configure a cor dos Jobs quando os mesmos estiverem com erro ou com o tempo acima da…](https://ajuda.sankhya.com.br/hc/article_attachments/360061910393) - Este campo permite que você configure a cor dos Jobs quando os mesmos estiverem com erro ou com o tempo acima da média. Além disso, poderá indicar qual será o tempo (minutos) de atualização dos Jobs.
