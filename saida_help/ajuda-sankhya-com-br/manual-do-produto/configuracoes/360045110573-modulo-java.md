# Módulo Java

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42310964730007) Módulo: Configurações > Avançado
```

---

Por meio desta tela, você pode fazer a codificação de uma rotina Java que irá "rodar" dentro do sistema.

**Importante:** as configurações realizadas aqui devem ser executadas por desenvolvedores específicos que tenham conhecimentos nas rotinas Java.

Uma ação do tipo [Rotina Java](http://code.sankhya.com.br/?p=4000), consiste em uma classe java que deve ser implementada e disponibilizada em um JAR (do inglês, Java Archive ou Arquivo Java, comumente denominado ".jar"), o qual será inserido no Sankhya Om através da tela Módulos Java. Esse cadastro tem a finalidade de incluir classes personalizadas dentro de nosso sistema, tornando possível usar essas classes em conjunto com as do próprio sistema em pontos específicos.

![Imagem 2: Uma ação do tipo Rotina Java , consiste em uma classe java que deve ser implementada e disponibilizada em um JAR (do…](https://ajuda.sankhya.com.br/hc/article_attachments/360100963574)

As configurações realizadas nessa tela, são trabalhadas posteriormente nas telas [Construtor de Telas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045111773-Construtor-de-Telas) e [Dicionário de Dados](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597294-Dicion%C3%A1rio-de-Dados), na aba [Ações - Rotina Java](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597294-Dicion%C3%A1rio-de-Dados#abaaes).
