# Como cadastrar Tipos de Benefício

```
 Módulo: Pessoal+ > Cadastros
```

---

Antes de iniciar a configuração da rotina de benefícios, é necessário cadastrar os tipos de benefícios. Estes serão posteriormente vinculados aos cadastros e as requisições de benefícios.

Acesse a tela Tipo de Benefício e clique no botão ![Imagem 1: Acesse a tela Tipo de Benefício e clique no botão " + Novo Registro" ou "Cadastrar Tipo de Benefício (F8)" .](https://ajuda.sankhya.com.br/hc/article_attachments/20943250954775) **"+ Novo** **Registro"** ou ![Botão](https://ajuda.sankhya.com.br/hc/article_attachments/15992232566295) **"Cadastrar Tipo de Benefício [F8]"**.

![Imagem 3: Acesse a tela Tipo de Benefício e clique no botão " + Novo Registro" ou "Cadastrar Tipo de Benefício (F8)" .](https://ajuda.sankhya.com.br/hc/article_attachments/6931400902039)

Informe a **"Descrição"** do benefício, sendo ele o nome do tipo de benefício apresentado nas telas de cadastro das rotinas de benefícios.

No campo **"Tipo"**, escolha uma das opções de benefícios listadas abaixo:

- Vale Alimentação;
- Vale Refeição;
- Vale Transporte;
- Vale Combustível;
- Plano de Saúde;
- Outros Benefícios.

Após isso, clique no botão ![Imagem 4: Após isso, clique no botão "Salvar (F7)" para gravar as informações.](https://ajuda.sankhya.com.br/hc/article_attachments/20943318427415) **"Salvar [F7]"** para gravar as informações.
