# Nova interface Sankhya

| ``` ![Imagem 1: Versão disponível: A partir da 4.21](https://ajuda.sankhya.com.br/hc/article_attachments/42312849252759) Versão disponível: A partir da 4.21 ``` |

---

Visando oferecer a melhor experiência do usuário aos clientes Sankhya, foi criada uma nova interface para ajudá-los a dar um novo salto de produtividade em sua rotina. 

A ideia da nova interface veio após uma minuciosa investigação e escuta ativa das necessidades dos usuários para entender as principais dores em sua rotina de trabalho.

Em suma, foram encontradas as seguintes dificuldades:

- **Telas e jornadas complexas:** alto volume de abertura de chamados para resolução de dúvidas, ocupando o tempo de usuários em suas rotinas;
- **Interface ultrapassada:** padrões de interação pouco intuitivas, o que aumentava a quantidade de tempo na aprendizagem da solução;
- **Baixo desempenho:** tempo excessivo de carregamento de tela, impactando nas ações do dia a dia.

A nova interface proporciona benefícios significativos e simplifica a rotina dos usuários, oferecendo:

- **Navegação fluida e facilitada:** melhora na eficiência durante a realização de tarefas;
- **Interface moderna e jornada autoguiada:** facilidade de aprendizado e redução da necessidade de treinamentos.

Com uma navegação mais fluida, uma interface moderna e tecnologia voltada para aumentar a eficiência do sistema, esta nova interface melhora a produtividade e otimiza o tempo dos usuários, facilitando sua rotina de trabalho.

### Movimentação Financeira e Bancária

As telas [Movimentação Financeira](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045114753-Movimenta%C3%A7%C3%A3o-Financeira) e [Movimentação Bancária](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115653-Movimenta%C3%A7%C3%A3o-Banc%C3%A1ria) estão integradas na nova interface para todos os usuários a partir do dia 15/04/2024 nas seguintes versões, ou superiores:

- 4.22b240
- 4.23b225
- 4.24b148
- 4.25b92

As telas [Portal de Vendas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612654-Portal-de-Vendas), [Central de Vendas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612414-Central-de-Vendas), [Liberação de Limites](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601034-Libera%C3%A7%C3%A3o-de-Limites), [Consulta de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109353-Consulta-de-Produtos) e [Ficha de Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601934-Ficha-de-Parceiros) estarão incorporadas na nova interface para todos os usuários em fases de implementação progressiva na segunda quinzena de agosto de 2024, a partir da versão 4.25b92, ou superior.

### Atualização dos Módulos

No menu do sistema, é possível verificar a versão atual dos módulos por meio da opção **"Versão"**.

![Imagem 3: No menu do sistema, é possível verificar a versão atual dos módulos por meio da opção "Versão" .](https://ajuda.sankhya.com.br/hc/article_attachments/24753350730519)

Ao acionar essa opção, um pop-up será aberto com as informações dos módulos disponíveis para interação, suas versões e data de liberação.

![Imagem 4: Ao acionar essa opção, um pop-up será aberto com as informações dos módulos disponíveis para interação, suas versões e…](https://ajuda.sankhya.com.br/hc/article_attachments/24753350731415)

![Imagem 5: Mensalmente, novas versões que comportam telas na nova interface são disponibilizadas.](https://ajuda.sankhya.com.br/hc/article_attachments/24752400666647) Mensalmente, novas versões que comportam telas na nova interface são disponibilizadas.

Neste mesmo menu, ao acessar uma tela na nova interface, é possível selecionar a opção **"Atualizar telas do Design System"** para que o sistema verifique a existência de uma versão mais recente.

![Imagem 6: Neste mesmo menu, ao acessar uma tela na nova interface, é possível selecionar a opção "Atualizar telas do Design…](https://ajuda.sankhya.com.br/hc/article_attachments/24753335432343)

A atualização a partir desta opção impactará apenas as telas do mesmo módulo já migradas para a nova interface.

**Importante:** a opção Atualizar telas do Design System será apresentada somente a usuários com permissão para atualizar o sistema.

Caso uma nova versão esteja disponível, após o processamento do sistema, o seguinte aviso será apresentado:

**"Todas as telas do novo Design System serão atualizadas.**

**Deseja continuar?**

**[Sim] [Não]"**

Clicando em **"Sim"**, o módulo será atualizado e uma nova mensagem será apresentada:

**"Módulo atualizado! Deseja recarregar o navegador?**

**O módulo foi atualizado com sucesso!**

**Antes de prosseguir com a recarga, observe que qualquer trabalho em andamento que não tenha sido salvo será perdido! Tem certeza que deseja continuar com a recarga?**

**Recomendamos salvar seu trabalho antes de prosseguir.**

**[Sim] [Não]"**

Caso a versão mais atual já esteja instalada, o sistema informará:

**"O módulo já se encontra atualizado com a última versão disponível."**
