# Relatório de Notas Canceladas

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311861169815) Módulo: Comercial > Relatórios
```

---

O relatório Notas Canceladas está destinado a apresentar as informações relacionadas aos cancelamentos de notas realizados, bem como a data de cancelamento, o motivo de tal procedimento, entre outros dados.

![Imagem 2: O relatório Notas Canceladas está destinado a apresentar as informações relacionadas aos cancelamentos de notas…](https://ajuda.sankhya.com.br/hc/article_attachments/4410471026839)

O campo **"Código ou Nome contendo"** localizado na parte superior da tela, está destinado a busca rápida de algum relatório que deseja-se visualizar ou reconfigurar. Você pode informar o código, um trecho do nome do relatório, ou ainda clicar no ícone representado pela **"lupa"** localizado à frente do campo.

Para dar início a criação de um relatório, acione o botão **"Modo Edição"**. Os passos seguintes são descritos detalhadamente no artigo [Relatórios Formatados](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108573-Relat%C3%B3rios-Formatados-).

Depois de feita a criação de um relatório, o título definido para o mesmo será exibido na parte inferior da tela, onde os demais botões apresentados serão habilitados para utilização. São eles:

![Imagem 3: Visualizar Relatório: por meio deste botão, você poderá visualizar os dados gerados que serão posteriormente impressos.](https://ajuda.sankhya.com.br/hc/article_attachments/16670004956951) **Visualizar Relatório:** por meio deste botão, você poderá visualizar os dados gerados que serão posteriormente impressos.

![Imagem 4: Modo Edição: você pode acionar este botão tanto para criar um relatório, quanto para realizar um ajuste num relatório…](https://ajuda.sankhya.com.br/hc/article_attachments/16670004960279) **Modo Edição:** você pode acionar este botão tanto para criar um relatório, quanto para realizar um ajuste num relatório já formatado.

![Imagem 5: Visualizar Grade: acionando este botão, as informações geradas serão apresentadas em modo grade na tela.](https://ajuda.sankhya.com.br/hc/article_attachments/16670004962071) **Visualizar Grade:** acionando este botão, as informações geradas serão apresentadas em modo grade na tela.

![Imagem 6: Segurança: a o acionar este botão, será aberto o pop-up "Título de segurança" , no qual você pode configurar os acessos…](https://ajuda.sankhya.com.br/hc/article_attachments/20761897101335) **Segurança:** ao acionar este botão, será aberto o pop-up **"Título de segurança"**, no qual você pode configurar os acessos ao relatório. Será permitido aqui, ajustar o nível de acesso de cada grupo de usuários, ao relatório selecionado. Os usuários são anexados aos grupos de forma conveniente, não importando a qual grupo ele esteja vinculado no cadastro de usuários. Sendo este vínculo exclusivo por relatório, podemos ter um usuário vinculado ao grupo "A" no relatório "X" e ao grupo "B" no relatório "Y". O acesso pode ser dado a todo o grupo ou a um usuário específico.

![Imagem 7: Baixar JRXML: por meio deste botão, é feita a baixa do relatório no formato "jrxml" , na qual pode ser utilizado no…](https://ajuda.sankhya.com.br/hc/article_attachments/20761897115799) **Baixar JRXML:** por meio deste botão, é feita a baixa do relatório no formato "jrxml", na qual pode ser utilizado no "IReport".

**Descartar Cache:** Marcando esta opção, ao realizar a geração dos relatórios, os caches de impressão serão limpos.
