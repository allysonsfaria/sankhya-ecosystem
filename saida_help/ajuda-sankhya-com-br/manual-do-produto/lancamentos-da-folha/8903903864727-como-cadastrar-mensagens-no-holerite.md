# Como cadastrar mensagens no holerite

```
 Módulo: Pessoal+ > Cadastros
```

Esta tela é utilizada para cadastrar mensagens personalizadas no holerite dos funcionários.

![Imagem 1: Esta tela é utilizada para cadastrar mensagens personalizadas no holerite dos funcionários.](https://ajuda.sankhya.com.br/hc/article_attachments/18727640565271)

O campo **"Cód. Mensagem"** pode ser preenchido automaticamente pelo sistema ou manualmente, conforme a configuração realizada na opção **"Numeração"** do botão ![Imagem 2: O campo "Cód. Mensagem" pode ser preenchido automaticamente pelo sistema ou manualmente, conforme a configuração…](https://ajuda.sankhya.com.br/hc/article_attachments/18669193393815) **"Configuração da Tela"**.

Na **"Descrição"**, insira a mensagem desejada. Cada linha da mensagem suporta até 36 caracteres; ao atingir esse limite, quebre a mensagem manualmente, conforme o exemplo citado na imagem acima.

A marcação **"Utilizada mensagem no Sankhya-W"** deve ser ativada para liberar os dados do holerite no [Portal RH](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108433).

Em seguida, salve o cadastro clicando no botão ![Imagem 3: Em seguida, salve o cadastro clicando no botão "Salvar (F7)" .](https://ajuda.sankhya.com.br/hc/article_attachments/23967496493079) **"Salvar [F7]"**.
