# Importação de Lotes com base no ECD

```
![módulo](https://ajuda.sankhya.com.br/guide-media/01H3C9G020AV01JKDGF8151E4C) Módulo: Contabilidade > Rotinas
```

---

Esta tela tem o objetivo de efetuar a importação de lotes contábeis tendo como base o arquivo do ECD gerado pelas filiais.

![Imagem 2: Esta tela tem o objetivo de efetuar a importação de lotes contábeis tendo como base o arquivo do ECD gerado pelas…](https://ajuda.sankhya.com.br/hc/article_attachments/1500003642641)

Inicialmente, informe a **"Empresa"** da contabilidade.

A marcação **"Substituir lotes já existentes"**, por padrão, é apresentada desabilitada e, quando marcada, se existirem lançamentos no sistema para a empresa selecionada cujo número de lote seja 1 (um) para todo o período do arquivo da ECD, os mesmos serão excluídos para inserção dos novos lotes conforme o arquivo. Se essa marcação estiver desabilitada e existir lotes nesse período, será apresentada uma mensagem alertando sobre essa ocorrência.

A marcação **"Importar Código de Histórico de Contas Externas"** determina se o campo **"Histórico Padrão"** será alimentado na importação/inserção de registros.

Ao acionar o botão ![Imagem 3: Ao acionar o botão "Importar" será apresentado um pop-up para realização do upload do arquivo da ECD externo da outra…](https://ajuda.sankhya.com.br/hc/article_attachments/15437958210455) **"Importar"** será apresentado um pop-up para realização do upload do arquivo da ECD externo da outra empresa:

![Imagem 4: Ao acionar o botão "Importar" será apresentado um pop-up para realização do upload do arquivo da ECD externo da outra…](https://ajuda.sankhya.com.br/hc/article_attachments/360102474334)

Através do botão ![Histórico](https://ajuda.sankhya.com.br/hc/article_attachments/15437944412695) **"Histórico de importação"** você poderá acompanhar a importação bem como visualizar todo o seu histórico:

![Imagem 6: Através do botão "Histórico de importação" você poderá acompanhar a importação bem como visualizar todo o seu histórico:](https://ajuda.sankhya.com.br/hc/article_attachments/360102474414)

**Observação:** Caso ocorram erros durante a importação, eles serão gravados em um arquivo **".txt"** no Repositório de Arquivos; você pode proceder com o download desse arquivo, se for necessário, através do botão **"Baixar Arquivo"**, que estará habilitado nessas situações.

**Nota:** A importação dos arquivos suporta os layouts **4.00**, **5.00**, **6.00**, **7.00**, **8.00** e **9.00**.
