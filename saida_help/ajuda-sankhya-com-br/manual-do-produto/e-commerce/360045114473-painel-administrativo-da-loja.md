# Painel Administrativo da loja

O painel administrativo da loja é o local onde você, como lojista poderá parametrizar vários aspectos do seu site. Nesse tópico será possível conhecer o funcionamento geral do painel.

## Acessando o painel administrativo da loja

Para acessar o painel administrativo da loja, entre no link enviado pelo nosso responsável pela implantação do site juntamente com a senha.

Teremos abaixo, a imagem da tela inicial de login:

![Imagem 1: Teremos abaixo, a imagem da tela inicial de login:](https://ajuda.sankhya.com.br/hc/article_attachments/360061934033)

Após realizar o login, sugerimos que você troque a senha de acesso. Para isso, vá ao seguinte caminho, **Usuário> Alterar senha.**

![Imagem 2: Após realizar o login, sugerimos que você troque a senha de acesso. Para isso, vá ao seguinte caminho, Usuário >…](https://ajuda.sankhya.com.br/hc/article_attachments/360061934053)

Caso mais de uma pessoa irá utilizar painel, é possível incluir os usuários em **Usuário » Ver usuários.**

![Imagem 3: Caso mais de uma pessoa irá utilizar painel, é possível incluir os usuários em Usuário » Ver usuários.](https://ajuda.sankhya.com.br/hc/article_attachments/360061011854)

Para cada usuário do sistema é possível cadastrar um **perfil de acesso**, diferenciado pelas tarefas que cada um irá executar dentro da Loja ou Vitrine.

![Imagem 4: Para cada usuário do sistema é possível cadastrar um perfil de acesso , diferenciado pelas tarefas que cada um irá…](https://ajuda.sankhya.com.br/hc/article_attachments/360061934093)

Cada perfil de acesso possui sua peculiaridade no acesso do painel, são elas:

**Administrador:** É o único que tem acesso a todas as funcionalidades, este poderá realizar todas as tarefas.

**Gerente:** Este terá acesso aos produtos, clientes, pedidos, modelos de e-mail, relatórios e ainda às funcionalidades do Designer.

**Designer:** O Designer terá acesso somente às funcionalidades relacionadas ao design, e a textos e produtos em destaque.

**Operacional:** Este terá acesso à visualização dos produtos, clientes e pedidos. Este perfil só é disponível para Loja Virtual.

### Conhecendo melhor o painel administrativo

Logo no primeiro contato com o painel, é possível acessar as configurações primordiais da loja tais como, configurações da loja, formas de pagamento, formas de envio, cadastro de produtos, entre outras. Na verticais temos as configurações de aparência (Banners, logotipo, temas etc), produtos (produtos cadastrados/integrados no site), entre outras. 

No botão de configurações, você terá acesso às configurações primordiais da loja: configurações gerais, cadastro de seções, formas de pagamento, formas de envio e etc.
