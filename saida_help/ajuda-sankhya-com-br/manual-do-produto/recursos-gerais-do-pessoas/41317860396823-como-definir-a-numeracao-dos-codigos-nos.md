# Como definir a numeração dos códigos nos cadastros

### Descrição e Usabilidade

Algumas telas de cadastro do módulo Pessoal+ possuem um campo **Código**, utilizado para identificar os registros cadastrados no sistema.

Esse código pode ser gerado automaticamente pelo sistema ou informado manualmente, conforme a configuração definida para a tela.

### Jornada de Uso

#### Numeração automática

[GIF animado: Imagem 1: Numeração automática](https://ajuda.sankhya.com.br/hc/article_attachments/41318627367703)

1. Acesse a tela de cadastro desejada;
2. Clique no botão **Configuração da Tela**, localizado na parte superior da rotina;
3. Selecione a opção **Numeração**;
4. Marque **Numeração automática;**
5. Preencha o **Número inicial**;
6. Clique em **Salvar**.

A partir desse momento, o campo será desabilitado para edição e todos os novos registros da rotina seguirão a forma de numeração configurada.

#### Numeração manual

[GIF animado: Imagem 2: Numeração manual](https://ajuda.sankhya.com.br/hc/article_attachments/41318812080663)

1. Acesse a tela de cadastro desejada;
2. Clique no botão **Configuração da Tela**, localizado na parte superior da rotina;
3. Selecione a opção **Numeração**;
4. Delete o **Número inicial**;
5. Desative **Numeração automática;**
6. Clique em **Salvar**.

A partir desse momento, o campo será habilitado para edição e para todos os cadastros seguintes será necessário informar o código do registro.

### Ponto de Atenção

- A configuração de numeração é específica para cada tela de cadastro. Portanto, uma alteração realizada em determinada rotina não impacta os demais cadastros do sistema.
- Ao utilizar numeração manual, é responsabilidade do usuário informar códigos válidos e evitar duplicidades.

### Dicas de Usabilidade

- Utilize a numeração automática para reduzir erros de cadastro e evitar conflitos de códigos.
- Utilize a numeração manual apenas quando houver necessidade de seguir uma identificação interna da empresa.
- Antes de alterar a configuração, verifique se existem processos internos que dependem de uma sequência específica de códigos.
