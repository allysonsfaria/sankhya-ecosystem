# Quais são as siglas dos tipos de folha no sistema

No sistema Sankhya, ao trabalhar com a tela **"Relação de Líquidos" ,''Relatórios Formatados''**, é necessário informar o **"Tipo de Folha"** através de uma sigla específica. Cada tipo de processamento de folha possui uma letra correspondente que identifica sua natureza.

Embora não exista uma tabela oficial consolidada no sistema que apresente todas as siglas disponíveis, as principais siglas utilizadas para os tipos de folha são documentadas e aplicadas conforme a necessidade de cada processamento.

### Principais Siglas de Tipos de Folha

As siglas mais utilizadas no sistema para identificar os diferentes tipos de folha são:

**N** - Folha Normal (mensal)
**F** - Folha de Férias
**D** - Folha de Décimo Terceiro Salário
**O** - Folha de Dissídio

### Quando Utilizar Cada Tipo de Folha

**Folha Normal (N):** utilize esta sigla para processar a folha de pagamento mensal regular dos colaboradores, incluindo salários, horas extras, descontos e demais eventos recorrentes.

**Folha de Férias (F):** utilize esta sigla ao calcular e processar o pagamento de férias dos funcionários, incluindo o adicional de um terço constitucional.

**Folha de Décimo Terceiro (D):** utilize esta sigla para processar tanto a primeira quanto a segunda parcela do décimo terceiro salário. Para visualizar o líquido do 13º no relatório, preencha o campo **"Tipo de Folha"** com a letra **"D"**.

**Folha de Dissídio (O):** utilize esta sigla quando houver reajuste salarial definido em acordo sindical cuja data de reajuste não coincide com a data-base. É necessário calcular a folha de dissídio para que o sistema apure e traga corretamente as diferenças salariais retroativas.

### Observações Importantes sobre Dissídio

As diferenças salariais de dissídio **não são automaticamente incorporadas à folha mensal**. Sempre que houver um reajuste salarial definido em acordo sindical, é necessário realizar o cálculo específico da folha de dissídio utilizando a sigla **"O"**.

O procedimento correto consiste em calcular primeiro a folha de dissídio e, posteriormente, processar a folha mensal. Dessa forma, o sistema consegue apurar corretamente todas as diferenças salariais devidas aos colaboradores.

**Caso a folha mensal já tenha sido calculada antes do processamento do dissídio, será necessário excluí-la,** calcular a folha de dissídio e, em seguida, recalcular a folha mensal para que todas as diferenças sejam geradas corretamente.
