# Perfil

```
![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42310431390103) Módulo: BI Móvel > Cadastro
```

---

O BI Móvel é um poderoso recurso para Gestão Estratégica e Gerencial utilizando a telefonia celular, computação móvel e WEB, apresentando informações em tempo real sobre a evolução dos negócios, possibilitando a gestão dos mesmos à distância.

Em um mundo globalizado, que exige a presença das pessoas em diversos lugares ao mesmo tempo, contar com um recurso que permite o acesso às informações cruciais sobre seus negócios, em qualquer lugar do planeta, é fundamental. O BI Móvel possibilita que as informações gerenciais extraídas do sistema sejam enviadas aos destinatários por meio de mensagens, via celular ou e-mail.

Com essa solução, os diretores e os gerentes conseguirão obter informações, que lhes permitirão tomar decisões de negócio oportunamente.

O **"Perfil"** é utilizado para separar os destinatários segundo as mensagens de interesse. Mais adiante será analisado, cada mensagem deve ser associada a pelo menos um perfil. Assim, todos os destinatários que possuírem um determinado perfil estão automaticamente cadastrados para receber todas as mensagens registradas para o perfil.

### Preenchimentos iniciais

Na realização do cadastro de um novo Perfil, inicialmente, informe os seguintes campos:

O campo **"Código do Perfil"** se refere ao código único para o perfil. Pode ser configurado para ser gerado automaticamente pelo sistema ou ser informado manualmente; essa definição é feita pela opção **"Numeração"** do botão ![Imagem 3: O campo "Código do Perfil" se refere ao código único para o perfil. Pode ser configurado para ser gerado…](https://ajuda.sankhya.com.br/hc/article_attachments/16343591395735)**"Configuração da Tela"**.

Informe no campo **"Descrição do Perfil"** a descrição para o perfil que está sendo cadastrado.

Ao efetuar a marcação **"Lista Destinatários** **Variável"**, fará com que seja habilitada para uso a aba [Destinatários por Lista Variável](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044593414-Perfil#abadestinatriosporlistavarivel), a qual será detalhada logo abaixo nessa documentação; e desabilitará, automaticamente, a aba [Destinatários por Perfil](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044593414-Perfil#abadestinatriosporperfil).

### Aba Geral

Preencha o campo **"Nome do Perfil"** com o nome do Perfil que está sendo cadastrado, sendo que este é de preenchimento obrigatório.

Caso a marcação **"Enviar Somente Última"** esteja efetuada, fará com que o sistema ignore as mensagens mais antigas correspondentes ao perfil, que continuam na fila de envio e não puderam ser encaminhadas. Com essa marcação efetuada, será possível evitar o envio de mensagens parecidas para uma mesma pessoa em um curto intervalo de tempo.

Informe no campo **"Intervalo Mínimo"** o intervalo mínimo entre o envio de uma mensagem e outra.

**Observação:** nesse caso, a unidade de medida referente ao intervalo mínimo é considerada pelo sistema em minutos.

### Aba Mensagens por Perfil

Informe no campo **"Código da Mensagem"** o código das mensagens que serão encaminhadas aos destinatários.

### Aba Destinatários por Perfil

Preencha o campo **"Código do destinatário"** com os destinatários que serão vinculados ao perfil que está sendo cadastrado. O cadastro desses destinatários é realizado previamente na tela [Destinatários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044593394-Destinat%C3%A1rios).

![Imagem 5: Preencha o campo "Código do destinatário" com os destinatários que serão vinculados ao perfil que está sendo…](https://ajuda.sankhya.com.br/hc/article_attachments/1500006610381)

**Observação:** alternando-se o modo de visualização dessa tela para o modo grade, serão exibidos todos os destinatários já vinculados ao perfil em questão.

### Botão Edição múltipla

O botão ![Edição](https://ajuda.sankhya.com.br/hc/article_attachments/15992531142679)**"Edição múltipla"** permite a edição simultânea de vários registros a partir do modo grade. Ou seja, ao selecionar um conjunto de registros e clicar no botão, será possível editar os campos correspondentes de todos os registros de uma só vez. 

Por exemplo, com os perfis em modo grade na tela Perfil selecione-os e em seguida clique no botão Edição múltipla, assim os campos poderão ser editados simultaneamente para todos os selecionados.
