# Cadastro de PDV

```
 Módulo: Comercial > Arquivo                Versão disponível: a partir da 4.29
```

---

Nesta tela, efetue o **cadastro dos usuários** que poderão trabalhar com o [**PDV Web**](https://ajuda.sankhya.com.br/hc/pt-br/articles/8046603009047).

**IMPORTANTE**

Antes de vincular um usuário ao PDV Web:

❌ O usuário não pode estar marcado como **"Caixa"** na aba [Identificação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#abaidentificao).

Isso geralmente se refere à marcação de perfil operador de caixa **"tradicional"**.

Como o PDV Web tem sua própria lógica de abertura/fechamento de caixa, essa marcação conflita com ele.

❌ O usuário não pode ter um caixa já aberto.

Se existir um caixa vinculado a ele em aberto (via ECF ou módulo de frente de loja anterior), isso precisa ser encerrado primeiro.

✅ O caixa será aberto automaticamente ao acessar a tela de PDV Web.

Ao acessar o PDV Web pela primeira vez, o sistema abre o caixa para aquele usuário, respeitando as regras de inicialização.

✅ O parâmetro **VALAPRRECPDV** deverá estar **desligado**.

✅ O parâmetro **BETACADPDV** deverá estar **habilitado**.

### Painel Principal

![Imagem 2: Painel Principal](https://ajuda.sankhya.com.br/hc/article_attachments/32388403266455)

O campo **"Código do PDV"** pode ser preenchido de forma manual ou automática; essa configuração é realizada por meio do botão ![Imagem 3: O campo "Código do PDV" pode ser preenchido de forma manual ou automática; essa configuração é realizada por meio do…](https://ajuda.sankhya.com.br/hc/article_attachments/20060926184983) **"Configuração da tela"** opção **"Numeração"**. Se optar pela configuração manual, é necessário informar um número no campo Código do PDV que será utilizado para identificá-lo em todas as rotinas em que estiver presente.

No campo **"Descrição"** insira uma nomenclatura para o registro.

Busque no campo **"Empresa"** a empresa que será vinculada a esse cadastro.

Para que o registro fique disponível para busca nas demais telas, acione a marcação **"Ativo"**.

Ative a marcação **"PDV Terceiro"** para habilitar o campo **"Identificação PDV"** ([aba Geral](https://ajuda.sankhya.com.br/hc/pt-br/articles/20060894293399-Cadastro-de-PDV#AbaGeral)), onde é possível inserir uma descrição de identificação do PDV de Terceiros.

### Aba Geral

Nesta aba, informe os seguintes campos:

![Imagem 4: Nesta aba, informe os seguintes campos:](https://ajuda.sankhya.com.br/hc/article_attachments/32388403266711)

No campo **"Conta PDV"**, informe uma conta configurada na tela [Contas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115113), aba [Cadastros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115113-Contas#abacadastros), campo **"Tipo de Conta"** como **"Caixa (PDV)".**

Os campos **"Data da Inclusão do ID da estação"** e **"Identificação PDV"** serão preenchidos automaticamente quando for realizado o vínculo do PDV a uma estação física por meio da opção **"Vincular o PDV a estação física de trabalho"** localizada no botão Outras Opções. 

O campo Identificação PDV poderá ser editado se a marcação **"PDV Terceiro"** localizada no [Painel Principal](https://ajuda.sankhya.com.br/hc/pt-br/articles/20060894293399-Cadastro-de-PDV#PainelPrincipal), estiver ligada. Nele, é possível inserir uma descrição de identificação do PDV de Terceiros.

Para usuários que utilizam o PDV identificado, a conta a ser utilizada é a informada nesta tela, no campo **Conta PDV**. Isso significa que as configurações de conta nas abas do cadastro de Usuários se tornam desnecessárias para essa finalidade.

![Imagem 5: Para usuários que utilizam o PDV identificado, a conta a ser utilizada é a informada nesta tela, no campo Conta PDV .…](https://ajuda.sankhya.com.br/hc/article_attachments/32388403266967)

**Observação:** caso não seja possível identificar o ID da placa-mãe do computador, o sistema irá utilizar o nome do host (HOST\_NAME) da máquina como identificador no cadastro do PDV.

#### Definição de conta por identificação do PDV Web

O sistema seguirá as seguintes validações para determinar qual conta será utilizada no PDV Web:

- **1ª prioridade — Conta Fintech PIX (quando ativa):** se o recurso de PIX via Fintech estiver ativo, o sistema utilizará obrigatoriamente a conta cadastrada e credenciada na Fintech. Essa conta tem precedência sobre todas as demais configurações.

  **Observação:** se o título financeiro estiver vinculado a uma conta diferente da que foi credenciada na Fintech, o sistema não conseguirá criar a cobrança e exibirá um erro de vínculo de conta. Para resolver, verifique se a conta informada no título é exatamente a mesma cadastrada no wizard de configuração da Fintech/PIX.
- **2ª prioridade — Conta do PDV identificado:** se a Fintech não estiver ativa e o PDV estiver identificado (vinculado nesta tela de Cadastro de PDV), o sistema utilizará a conta configurada especificamente para esse PDV.

  Sendo que, para PDVs identificados, se o usuário logado possuir uma regra configurada na tela [Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios), aba [Validações](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#abavalidaes), será necessário que a tela de [Central de Certificações](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110053-Central-de-Certifica%C3%A7%C3%B5es) seja configurada para utilizar a conta correspondente ao registro do cadastro do PDV.
- **3ª prioridade — Conta do caixa aberto do operador:** se nenhuma das opções anteriores se aplicar, o sistema utilizará a conta bancária vinculada ao caixa que está aberto para o usuário que está operando o PDV.

  **Observação:** se o operador não tiver nenhum caixa aberto no momento, o sistema exibirá a seguinte mensagem: "Erro ao vincular a conta do caixa no financeiro, verifique se o usuário possui caixa aberto!"

Para usuários que utilizam o PDV identificado, não é necessário configurar a conta na tela **Usuários**. A conta a ser utilizada será a informada na tela **Cadastro de PDV**, aba **Geral**, no campo **Conta PDV**.

Isso significa que **não** é necessário:

- Configurar a aba **Contas p/ Baixa** na tela **Usuários**.
- Informar um valor no campo **Número da conta padrão na baixa** (disponível em **Outras Opções** > **Configurações do Usuário**).

### Botões da tela

#### Botão Outras Opções

Por meio do botão ![Imagem 7: Por meio do botão Outras Opções , tem-se a opção "Vincular o PDV a estação física de trabalho" , que permite associar o…](https://ajuda.sankhya.com.br/hc/article_attachments/20253697944983) Outras Opções, tem-se a opção **"Vincular o PDV a estação física de trabalho"**, que permite associar o PDV no sistema a um PDV físico, proporcionando um controle mais eficaz sobre cada ponto de venda.

Caso o ID da máquina local já esteja vinculado a outro PDV, o sistema exibirá a seguinte mensagem:

**"O ID da máquina já cadastrado em um outro PDV(Cod. PDV.).**

**Deseja cadastrar este ambiente (ID da máquina cadastrada) mesmo assim?"**

Ao clicar em **"Sim"**, o ambiente será substituído, e os campos **"Data da Inclusão do ID da estação"** e **"Identificação da Estação"** serão preenchidos automaticamente na aba Geral. Se optar por **"Não"**, o cadastro será cancelado, e o sistema retornará à tela para que as informações no campo possam ser alteradas.

**Observações:**

- Uma vez que o PDV for associado a uma estação de trabalho, esta não terá mais a capacidade de operar no antigo modelo de PDV por cadastro de conta, ou seja, a estação de trabalho funcionará exclusivamente na nova estrutura.
- Caso ocorra a substituição da placa-mãe da estação de trabalho, a **formatação da máquina**, a **atualização do sistema operacional** (como, por exemplo, para o Windows 11), ou a troca do computador, a identificação original do hardware pode ser perdida. Quando isso acontece, o sistema não reconhece mais a estação de trabalho. Por isso, **será necessário cadastrar um novo PDV** e realizar novamente a vinculação. Ao assinar um novo caixa, o sistema tentará primeiro identificar a máquina pelo hardware (placa-mãe). Se não for possível, ele usará o **hostname** do computador como identificador.

#### Botão Duplicar

Para duplicar o registro por meio do botão **"Duplicar"**, o usuário precisa ter a permissão para **"Duplicar"** na tela [Acessos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596854). Além disso, o parâmetro **"Controla acesso de duplicação de registros? - CONTACESSDUPLIC"** deve estar habilitado.
