# Consulta de Funcionários

**Módulo:** Pessoal+
**Caminho de Acesso:** Pessoal+ > Cadastros
**ID da Tela:** br.com.sankhya.cadastro.funcionarios

---

## Descrição e Usabilidade

### 1. Descrição da Funcionalidade

A tela **Funcionários** é destinada exclusivamente à consulta das informações cadastrais dos colaboradores registrados no sistema.

Ela consolida, em uma única interface, os principais dados pessoais, contratuais, documentais, históricos e trabalhistas do colaborador, permitindo uma visualização rápida das informações sem a necessidade de acessar diretamente o cadastro.

| ℹ️ **Nota**  Esta tela é apenas de consulta. Qualquer inclusão ou alteração cadastral deve ser realizada na tela **Configuração Funcionários** (Pessoal+ > Cadastros). |
| --- |

O acesso à tela é restrito ao usuário **SUP** e aos colaboradores pertencentes ao departamento de **DP/RH**, conforme as permissões definidas pelo administrador do sistema na tela **Painel de Configurações > Configuração de Permissões**.

### 2. Pré-requisitos

Para utilizar esta funcionalidade é necessário:

- possuir permissão de acesso à tela **Funcionários**;
- existir pelo menos um colaborador cadastrado na tela **Configuração Funcionários**;
- possuir permissão para consulta da empresa selecionada.

### 3. Jornada de Uso

#### 3.1 Consultar colaboradores

Ao acessar a tela:

1. selecione a **Empresa**;
2. utilize, se necessário, os filtros de:
   - **Departamento**;
   - **Situação do Funcionário**;
3. clique em **Pesquisar**;
4. localize o colaborador desejado e clique sobre o seu card para visualizar seus dados.

### 4. Pontos de Atenção

- Esta tela não permite alterar informações cadastrais.
- Todas as alterações devem ser realizadas na tela **Configuração Funcionários**.
- Alguns menus são exibidos apenas quando existirem informações correspondentes (como Estagiário, Transferência e Afastamento).
- A visualização dos relatórios depende da configuração do parâmetro **FPRELATFUNC** e dos relatórios cadastrados na tela **Relatórios Formatados**.
- O acesso às informações depende das permissões configuradas para o usuário.

### 5. Dicas de Usabilidade

- Utilize os filtros de Empresa, Departamento e Situação para localizar colaboradores com mais rapidez.
- Consulte esta tela antes de acessar o cadastro completo quando precisar apenas verificar informações.
- Utilize o menu Histórico para acompanhar alterações salariais e contratuais.
- Sempre valide as permissões de acesso dos usuários para garantir a segurança das informações cadastrais.

### Perguntas Frequentes (FAQ)

**1. Posso alterar os dados do colaborador nesta tela?**

Não. A tela **Funcionários** é destinada apenas à consulta. As alterações devem ser realizadas na tela **Configuração Funcionários**.

**2. Quem pode acessar esta tela?**

O usuário **SUP** e os usuários pertencentes ao departamento de DP/RH, desde que possuam as permissões de acesso configuradas.

**3. Por que alguns menus não aparecem para determinado colaborador?**

Alguns menus são exibidos somente quando existem informações relacionadas, como Estagiário, Transferência ou Afastamento.

**4. Como visualizar os relatórios do colaborador?**

Acesse o menu **Relatórios**. Os documentos exibidos dependem da configuração realizada no parâmetro **FPRELATFUNC** e dos relatórios cadastrados na tela **Relatórios Formatados**.

**5. Posso consultar o histórico de alterações do colaborador?**

Sim. O menu **Histórico** apresenta as alterações salariais, de carga horária e outras movimentações registradas durante o vínculo empregatício.
