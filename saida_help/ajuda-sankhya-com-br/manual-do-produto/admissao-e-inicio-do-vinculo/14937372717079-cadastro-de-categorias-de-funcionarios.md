# Cadastro de Categorias de Funcionários

```
 Módulo: Pessoal+ > Cadastros
```

---

O cadastro das Categorias pode ser utilizado para segregar os funcionários conforme os interesses das organizações.

![Imagem 1: O cadastro das Categorias pode ser utilizado para segregar os funcionários conforme os interesses das organizações.](https://ajuda.sankhya.com.br/hc/article_attachments/17686661689495)

Para iniciar o cadastro, acione o botão ![Imagem 2: Para iniciar o cadastro, acione o botão "Cadastrar Categoria" e preencha a "Descricao da categoria" .](https://ajuda.sankhya.com.br/hc/article_attachments/16538332960663) **"Cadastrar Categoria"** e preencha a **"Descricao da categoria"**.

O **"Cód. Categoria"** pode ser preenchido de forma manual ou automática; esta definição é feita através da opção **"Numeração"** do botão ![Imagem 3: O "Cód. Categoria" pode ser preenchido de forma manual ou automática; esta definição é feita através da opção…](https://ajuda.sankhya.com.br/hc/article_attachments/16538348602519) **"Configuração da Tela"** localizado na parte superior da tela.

Finalizado o cadastro, clique em ![Imagem 4: Finalizado o cadastro, clique em "Salvar (F7)" .](https://ajuda.sankhya.com.br/hc/article_attachments/23966800839959) **"Salvar [F7]"**.
