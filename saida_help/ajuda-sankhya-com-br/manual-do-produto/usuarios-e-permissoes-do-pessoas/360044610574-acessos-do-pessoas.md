# Acessos do Pessoas+

```
 Módulo: Pessoal+ > Rotinas Folha           Versão disponível: A partir da 4.2
```

---

Esta tela tem a finalidade de gerenciar os funcionários da empresa, permitindo criar novos usuários, liberar os primeiros acessos e indicar quem é o líder responsável pelo recebimento de requisições de cada persona no sistema. Além de poder, ser aberta diretamente pelo menu Rotinas do módulo Pessoal+, também pode ser acessada pelo [Painel de Configurações](https://ajuda.sankhya.com.br/hc/pt-br/articles/14999187265559).

Uma vez aberta, pode-se utilizar o Painel de Filtros, ao lado esquerdo, para facilitar a busca de funcionários através da **"Empresa"**, **"Departamento"** ou pela **"Situação do Funcionário"**.
![Imagem 1: Uma vez aberta, pode-se utilizar o Painel de Filtros , ao lado esquerdo, para facilitar a busca de funcionários através…](https://ajuda.sankhya.com.br/hc/article_attachments/16443745060247)

![Imagem 2: Caso deseje procurar diretamente pelo nome do funcionário é disponibilizado o campo de pesquisa, indicado pela lupa, na…](https://ajuda.sankhya.com.br/hc/article_attachments/17111266831127) Caso deseje procurar diretamente pelo nome do funcionário é disponibilizado o campo de pesquisa, indicado pela lupa, na parte superior da tela.

Definidos os filtros, os funcionários serão listados na tela em cards, identificados de acordo com sua situação: **"Atividade Normal"**, **"Demitido"**, **"Transferido"** ou **"Outros"**.
Selecionando um funcionário ou mais, serão habilitados no canto inferior direito da tela os botões: **"Criar Usuário OM"**, **"Liberar Acesso PortalRH"** e **"Remover Acesso PortalRH"**.

Lembrando que as funcionalidades desses botões podem ser realizadas diretamente no cadastro funcionário por meio do botão [Outras Opções...](https://ajuda.sankhya.com.br/hc/pt-br/articles/21069685487639-Configura%C3%A7%C3%A3o-Funcion%C3%A1rios#botooutrasopes...) da tela [Configuração Funcionários](https://ajuda.sankhya.com.br/hc/pt-br/articles/21069685487639).

![Imagem 3: Lembrando que as funcionalidades desses botões podem ser realizadas diretamente no cadastro funcionário por meio do…](https://ajuda.sankhya.com.br/hc/article_attachments/35137194774935)

Confira abaixo a função de cada um deles:

### Imagem 4: Criar Usuário OM Criar Usuário OM

Este botão é utilizado para criação de usuários para os funcionários selecionados a partir das informações do cadastro de cada um, vinculados automaticamente seus dados. Dessa forma, basta acionar o referido botão e confirmar a criação do usuário.

Observe que, uma vez criado um usuário do **Sankhya Om** para determinado funcionário é apresentado no respectivo card o ícone **"Tem usuário Sankhya"**.

![Imagem 5: Observe que, uma vez criado um usuário do Sankhya Om para determinado funcionário é apresentado no respectivo card o…](https://ajuda.sankhya.com.br/hc/article_attachments/16443724125463)

### Imagem 6: Atribuir/Remover Líder Atribuir/Remover Líder

A rotina **"Atribuir/Remover Líder"** não está mais disponível nesta tela. Realize esta ação na tela Configuração Funcionários > Outras Opções... > Gestão de Liderança.

[GIF animado: Imagem 7: A rotina "Atribuir/Remover Líder" não está mais disponível nesta tela. Realize esta ação na tela Configuração…](https://ajuda.sankhya.com.br/hc/article_attachments/35137222549655)

Para mais informações, consulte o artigo [Gestão de Liderança](https://ajuda.sankhya.com.br/hc/pt-br/articles/32988307114903).

### Liberar Acesso PortalRH

O botão Liberar acesso PortalRH dá acesso ao funcionário ao [Portal RH](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108433). Para utilizá-lo, primeiramente, selecione o card do funcionário para o qual deseja liberar o acesso. Logo em seguida, acione o referido botão e será apresentada na tela uma mensagem para confirmar se deseja realmente liberar o acesso ao funcionário selecionado. Clique em **"SIM"**.

Após liberado o acesso ao Portal RH, no card do funcionário será apresentado um ícone de identificação de que esse funcionário **"Tem acesso ao PortalRH"**.

### Remover Acesso PortalRH

Se for necessário a remoção de acessos de qualquer funcionário ao Portal RH, basta selecionar o respectivo card e clicar no botão **"Remover Acesso PortalRH"**.
