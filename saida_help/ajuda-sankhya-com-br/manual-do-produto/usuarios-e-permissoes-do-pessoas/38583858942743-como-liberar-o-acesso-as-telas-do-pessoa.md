# Como liberar o acesso às telas do Pessoas+ para novos colaboradores

Para conceder acesso ao módulo **Pessoal+**, é necessário utilizar o usuário administrador do sistema (**SUP**) no Sankhya Om para ele dar **permissões** aos usuários chaves do sistema (DP/RH e Líderes).

O processo envolve três etapas: [criação do usuário](https://ajuda.sankhya.com.br/hc/pt-br/articles/38583858942743-Como-liberar-o-acesso-%C3%A0s-telas-do-Pessoas-para-novos-colaboradores#h_01KQ800BKK3NKQ6HCM9AM8P5QD), [definição de permissões](https://ajuda.sankhya.com.br/hc/pt-br/articles/38583858942743-Como-liberar-o-acesso-%C3%A0s-telas-do-Pessoas-para-novos-colaboradores#h_01KQ803R04M9VG5HJP6Q1JP4VZ) e [liberação de acesso às telas](https://ajuda.sankhya.com.br/hc/pt-br/articles/38583858942743-Como-liberar-o-acesso-%C3%A0s-telas-do-Pessoas-para-novos-colaboradores#h_01KQ803FF3A5FFJSAS3BCBNJ8Q).

#### **(1)** Criar e configurar o usuário

Na tela **Configuração Funcionários** (Pessoal+ > Cadastros)

- Aba **Configurações**: marque a opção **Pertence ao DP/RH** para os usuários DP;

  ![Imagem 1: Aba Configurações : marque a opção Pertence ao DP/RH para os usuários DP;](https://ajuda.sankhya.com.br/hc/article_attachments/38583852149527)
- Botão **Outras Opções...** > **Criar Usuário Om** para todos os usuários.

  [GIF animado: Imagem 2: Botão Outras Opções... > Criar Usuário Om para todos os usuários.](https://ajuda.sankhya.com.br/hc/article_attachments/38583858925847)

#### **(2)** Definir permissões no Pessoal+

Na tela **Painel de Configurações** (Pessoal+ > Configurações):

- **Grupo de Decisores:** acesse o respectivo card e crie um grupo de decisores ou inclua o usuário num grupo já existente;

  [GIF animado: Imagem 3: Grupo de Decisores: acesse o respectivo card e crie um grupo de decisores ou inclua o usuário num grupo já existente;](https://ajuda.sankhya.com.br/hc/article_attachments/38583858930583)
- **Configuração de permissões**: clique no respectivo card e libere as operações que o usuário poderá executar em cada tela, ou, libere todas as funcionalidades de todas as telas por meio do botão **Atribuir todas as telas**;

  [GIF animado: Imagem 4: Configuração de permissões : clique no respectivo card e libere as operações que o usuário poderá executar em cada…](https://ajuda.sankhya.com.br/hc/article_attachments/38583852157207)
- **Configuração de processos**: clique no respectivo card e defina quais requisições o usuário poderá realizar e/ou aprovar.

  [GIF animado: Imagem 5: Configuração de processos : clique no respectivo card e defina quais requisições o usuário poderá realizar e/ou aprovar.](https://ajuda.sankhya.com.br/hc/article_attachments/38583858932759)

#### **(3)** Liberar acesso às telas

Libere o acesso às telas do módulo **Pessoal+** aos usuários que irão executar as rotinas do sistema por meio da tela **Acessos** (Configurações > Controle de Acesso).

[GIF animado: Imagem 6: Libere o acesso às telas do módulo Pessoal+ aos usuários que irão executar as rotinas do sistema por meio da tela…](https://ajuda.sankhya.com.br/hc/article_attachments/38583858935191)

#### Pontos de Atenção

- O usuário só conseguirá acessar as telas se:

  - Estiver criado no Om;
  - Estiver vinculado a um Grupo de Decisores;
  - Possuir permissões configuradas;
  - Tiver as telas liberadas no Controle de Acesso.
- Caso algum acesso não apareça, revise cada uma das etapas acima.
