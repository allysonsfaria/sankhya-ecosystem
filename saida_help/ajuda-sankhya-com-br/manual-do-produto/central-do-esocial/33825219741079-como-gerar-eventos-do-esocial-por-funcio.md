# Como gerar eventos do eSocial por funcionário ou por evento específico

O sistema permite realizar a geração dos eventos do eSocial de forma **segmentada**, possibilitando selecionar **funcionários** ou **eventos específicos**, em vez de gerar todos de uma única vez. Para realizar esse procedimento, siga os passos abaixo:

**(1)** Acesse a tela **“Central do eSocial”** (Pessoal+ » Rotinas Folha » Central do eSocial). 

**(2)** Marque a opção **“Habilitar seleção de eventos”**. 
  • Em seguida, clique em **“Selecionar os Eventos para geração”** e escolha quais eventos deseja gerar (ex.: S-2200, S-1200, S-2299 etc.). 

**(3)** Clique no ícone de **"Boneco"** para **"Selecionar Funcionários para Geração"**, aplique no filtro os colaboradores para os quais deseja gerar os eventos.

![Imagem 1: Após selecionar os eventos e os funcionários, clique no botão “Ir para Resumo” . Confirme a geração clicando em…](https://ajuda.sankhya.com.br/hc/article_attachments/33825252478615) 

**(4)** Após selecionar os eventos e os funcionários, clique no botão **“Ir para Resumo”**. 

**(5)** Confirme a geração clicando em **“Iniciar Geração”**.
