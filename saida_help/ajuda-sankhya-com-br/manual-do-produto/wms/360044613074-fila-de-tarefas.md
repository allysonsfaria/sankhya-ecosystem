# Fila de Tarefas

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311546082199) Módulo: WMS > Consultas
```

---

Esta tela está destinada à realização de consultas ao andamento das tarefas que estão sendo realizadas; é uma tela de acompanhamento do progresso das tarefas e suas respectivas priorizações.

![Imagem 2: Esta tela está destinada à realização de consultas ao andamento das tarefas que estão sendo realizadas; é uma tela de…](https://ajuda.sankhya.com.br/hc/article_attachments/360086310253)

A filtragem para apresentação das tarefas nesta tela, ocorre por meio do preenchimento de alguns campos obrigatórios; a saber:

Escolha o **"Código do Equipamento"** ao qual a tarefa está relacionada.

Informe a **"Tarefa"** que você deseja acompanhar, podendo esta ser:

- Separação;
- Separação de Balcão;
- Armazenagem;
- Reabastecimento;
- Reabastecimento Corretivo;
- Transferência.

**Nota:** caso um Reabastecimento Corretivo seja gerado com mais de um item do mesmo produto em endereços diferentes, sendo que a quantidade do primeiro endereço atenda a quantidade do pedido, os demais itens da tarefa não são enviados para execução. Sendo assim, para continuar nesse processo é necessário que a referida tarefa seja priorizada, caso contrário, poderá executá-la somente após a finalização das outras tarefas.

A última informação obrigatória a ser definida é o **"Usuário Logado"**, relacionado à tarefa definida.

**Observação:** ao realizar um armazenamento, o sistema ordena as tarefas de armazenagem de acordo com campo **"Ordem"** configurado na tela [Endereço de Armazenamento](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045120313).
