# Histórico de Ajuste de Estoque

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311605417751)  Módulo: WMS > Inventário
```

---

Através dessa tela temos o histórico de todos os ajustes já realizados. Podemos trabalhar nela, com os ajustes para os inventários Rotativo e Global.

**Observação:** no inventário de Implantação não é registrado ajuste, logo, não é possível utilizar esta tela.

![Imagem 2: Observação: no inventário de I mplantação não é registrado ajuste, logo, não é possível utilizar esta tela.](https://ajuda.sankhya.com.br/hc/article_attachments/360088013293)

O botão **"Desfazer Ajuste de Estoque"** localizado no alto da tela, só poderá ser utilizado para desfazer o último ajuste feito. Ao ser executado, o ajuste retornará para a tela [Ajuste de Estoque por Inventário](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044609594-Ajuste-de-Estoque-por-Invent%C3%A1rio), onde você poderá gerar recontagem do produto ou um novo ajuste.

**Importante:** será permitido desfazer os ajustes apenas se não tiverem sido geradas as notas de ajuste.
