# Exibição e liberação do ID do aparelho no Coletor WMS (TotalCross)

## Descrição da funcionalidade

Esta funcionalidade permite que o usuário visualize o ID exclusivo do aparelho diretamente no coletor WMS (TotalCross). Esse ID é utilizado para identificar qual dispositivo está pendente para liberação de licença e quais já foram liberados, facilitando o controle e a administração das licenças de uso.

## Como utilizar

### 1. Visualizar o ID do aparelho no primeiro acesso

Ao instalar e acessar o coletor WMS pela primeira vez, o sistema exibirá automaticamente o ID do aparelho na tela inicial.

### 4. Confirmação da liberação do ID

Após a liberação da licença, o ID do coletor é exibido na tela de “Administração de Licenças”, confirmando que o dispositivo pendente foi liberado corretamente.

## Resumo

- O ID do aparelho é exibido automaticamente no coletor após a instalação.
- O mesmo ID é utilizado para liberar a licença na tela de Administração de Licenças.
- Após a liberação, o ID é exibido como liberado, confirmando o processo.
