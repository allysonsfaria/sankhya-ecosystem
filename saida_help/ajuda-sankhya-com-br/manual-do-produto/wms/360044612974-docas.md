# Docas

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311512385431) Módulo: WMS > Cadastros 
```

---

É possível cadastrar nesta rotina, docas de saída, entrada ou ambos.

![Imagem 2: É possível cadastrar nesta rotina, docas de saída, entrada ou ambos.](https://ajuda.sankhya.com.br/hc/article_attachments/360085116474)

O campo **"Endereço"** é um endereço criado na tela [Endereço de Armazenagem](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045120313-Endere%C3%A7o-de-Armazenamento); este endereço deve estar ativo para ser possível utilizá-lo no Cadastro da Doca.

O campo **"Situação"** é modificado pelo sistema, de acordo com as movimentações realizadas no WMS.

No campo **"Impressora da doca"** é possível inserir o nome da impressora que aquela doca vai utilizar para a impressão as etiquetas de paletes. Para que o referido campo seja exibido, o parâmetro **"Usa etiqueta de palete. - WMSUSAETIQPAL"** deve estar ligado.
