# Motivos de Corte

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311606293911) Módulo: WMS > Cadastros
```

---

Nesta tela você cadastra os Motivos de Corte, visando a obtenção de dados estatísticos.

**Importante:** esta tela será apresentada para utilização apenas se o parâmetro **"Motivo de corte obrigatório - MOTCORTEOBRIG"** esteja ativado.

![Imagem 2: Importante: esta tela será apresentada para utilização apenas se o parâmetro "Motivo de corte obrigatório -…](https://ajuda.sankhya.com.br/hc/article_attachments/360086474613)

Para realização do cadastro de um novo motivo de corte, inicialmente, efetue o preenchimento do campo **"Código"**, que pode ser realizado de forma manual ou automática. Esta configuração é realizada na opção **"Numeração"** do botão ![Imagem 3: Para realização do cadastro de um novo motivo de corte, inicialmente, efetue o preenchimento do campo "Código" , que…](https://ajuda.sankhya.com.br/hc/article_attachments/16922137932695) **"Configuração da Tela"**.

Depois de preenchido o código, informe a **"Descrição"** do motivo da corte, ou seja, o título que identificará, de forma rápida e clara, o motivo de corte.

A marcação **"Ativo"** define se o motivo cadastrado poderá ser utilizado ou não nas demais rotinas. Quando desmarcado, o motivo não estará apto para uso, pois se encontrará inativo.
