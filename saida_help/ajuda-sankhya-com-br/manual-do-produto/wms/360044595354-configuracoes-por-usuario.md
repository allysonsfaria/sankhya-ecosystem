# Configurações por Usuário

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42311500753175) Módulo: WMS > Rotinas
```

---

Esta tela tem o objetivo de vincular tarefas e unidades permitidas aos usuários do [Módulo WMS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360025233694-WMS), podendo vincular também, validações para os mesmos.

![Imagem 2: Esta tela tem o objetivo de vincular tarefas e unidades permitidas aos usuários do Módulo WMS , podendo vincular…](https://ajuda.sankhya.com.br/hc/article_attachments/27759955003415)

No lado esquerdo da tela, através dos **"Filtros de Usuários"**, será possível visualizar todas as pessoas que existem para executarem as rotinas do WMS.

Na aba **"Unidades Permitidas"** defina quais são as unidades permitidas para uma determinada pessoa selecionada.

**Nota:** o cadastro destas unidades deverá ser realizado na tela [Unidades](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597094-Unidades).

![Imagem 3: Nota: o cadastro destas unidades deverá ser realizado na tela Unidades .](https://ajuda.sankhya.com.br/hc/article_attachments/27759938779415)

Vincule na aba **"Tarefas Permitidas"** as tarefas que o usuário possui permissão para executar.

![Imagem 4: Vincule na aba "Tarefas Permitidas" as tarefas que o usuário possui permissão para executar.](https://ajuda.sankhya.com.br/hc/article_attachments/27759955004823)

**Observação:** será possível neste campo, selecionar a opção de **"Definir Vínculo de Produto"**, a qual será utilizada para atribuir a um usuário de operação no [Coletor Android](https://ajuda.sankhya.com.br/hc/pt-br/articles/28043610014871-Coletor-Android-WMS).

A aba **"Validações"** tem a finalidade de definir algumas regras para a pessoa/usuário selecionado, sendo que poderá ser definida quais as empresas este poderá visualizar, bem como se ele poderá executar recontagem.

**Observação:** é possível copiar as permissões de acessos de uma pessoa para outra, através do botão ![Imagem 5: Observação: é possível copiar as permissões de acessos de uma pessoa para outra, através do botão "Copiar Permissões" ,…](https://ajuda.sankhya.com.br/hc/article_attachments/16841083958039) **"Copiar Permissões"**, localizado no alto da tela; assim, no lado esquerdo da tela, através dos Filtros de Usuários, selecione o usuário com os acessos desejados para que, então, estes acessos possam ser espelhados ao novo usuário ou grupo de usuários.

![Imagem 6: Observação: é possível copiar as permissões de acessos de uma pessoa para outra, através do botão "Copiar Permissões" ,…](https://ajuda.sankhya.com.br/hc/article_attachments/27759955005847)

Você pode adicionar um ou mais usuários na Cópia de Configurações; desta forma, após selecioná-los e acionar o botão **"Próximo"**, será exibido o pop-up a seguir para definir as permissões a serem copiadas:

![Imagem 7: Você pode adicionar um ou mais usuários na Cópia de Configurações ; desta forma, após selecioná-los e acionar o botão…](https://ajuda.sankhya.com.br/hc/article_attachments/27759938782487)
