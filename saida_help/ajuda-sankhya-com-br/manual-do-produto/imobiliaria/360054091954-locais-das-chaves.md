---

Esta tela tem o objetivo de cadastrar os Locais das Chaves, para controlar a disponibilidade das mesmas.

![Imagem 3: Esta tela tem o objetivo de cadastrar os Locais das Chaves , para controlar a disponibilidade das mesmas.](https://ajuda.sankhya.com.br/hc/article_attachments/360091105354)

Informe no campo **"Descrição"** o nome do Local da Chave.

Efetue a marcação **"Disponível"** para informar que este Local da Chave está disponível.
