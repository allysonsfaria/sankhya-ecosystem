### Filtro para Levantar Saldo

![Imagem 4: Filtro para Levantar Saldo](https://ajuda.sankhya.com.br/hc/article_attachments/360093845013)

Na grade Filtro para Levantar Saldo, temos os seguintes campos e botões:

Clique no botão ![Imagem 5: Clique no botão "Informar Saldo" para informar os dados e realizar o levantamento de saldo.](https://ajuda.sankhya.com.br/hc/article_attachments/360093844393) **"Informar Saldo"** para informar os dados e realizar o levantamento de saldo.

Informe no campo **"Dt. Aproveitamento"** a data base para o cálculo de Aproveitamento de Saldo.

**Observação:** você deverá informar no campo acima, a data atual ou uma data superior à atual; caso contrário, será exibida a seguinte mensagem:

**"A data do aproveitamento de saldo deve ser igual ou maior que a data de hoje".**

No campo **"Cliente"** selecione o comprador, para que seja levantado o saldo a ser aproveitado.

Após informar os dados, clique no botão ![Imagem 6: Após informar os dados, clique no botão "Levantar Dados" para que seja feito o levantamento de saldo. Acionando esse…](https://ajuda.sankhya.com.br/hc/article_attachments/360091685174) **"Levantar Dados"** para que seja feito o levantamento de saldo. Acionando esse botão, todos os campos mencionados acima ficarão indisponíveis para edição.

### Contratos cancelados

Nesta grade, são gerados automaticamente os dados de saldos a serem aproveitados dos contratos que estão cancelados.

![Imagem 7: O campo "Vlr. Total Cancelado" exibe o valor de saldo a ser aproveitado dos contratos cancelados.](https://ajuda.sankhya.com.br/hc/article_attachments/360093845293)O campo **"Vlr. Total Cancelado"** exibe o valor de saldo a ser aproveitado dos contratos cancelados.

No campo **"Vlr. Total Aproveitar"** é exibido o saldo à aproveitar do comprador que não é proveniente de contrato cancelado.

### Contratos Abertos

![Imagem 8: Nesta grade, serão carregados automaticamente os contratos com todos os levantamentos em aberto que o comprador possua…](https://ajuda.sankhya.com.br/hc/article_attachments/360093846393)Nesta grade, serão carregados automaticamente os contratos com todos os levantamentos em aberto que o comprador possua e todos serão inseridos nesta tela, para que possa ser feito o aproveitamento e abatimento do saldo em aberto.

No rodapé da grade, temos os seguintes campos:

![Imagem 9: No rodapé da grade, temos os seguintes campos:](https://ajuda.sankhya.com.br/hc/article_attachments/360093846713)

O campo **"Vlr. Total Aberto"** exibirá o valor total que o comprador possui em aberto.

Caso o comprador possua algum valor pendente, será exibido no campo **"Vlr. Total Pendente"**.

O campo **"Vlr. Total Aproveitado"** é preenchido de acordo com o valor que você informar no campo **"Vlr. Aproveitado"**, sendo que, não será permitido que você informe um valor maior do que o saldo a aproveitar.

Caso o comprador ainda possua limite, será exibido todo o valor restante que poderá ser aproveitado no campo **"Vlr. Total Restante"**.

Por fim, caso tenha valor à restituir, este será exibido no campo **"Vlr. Total Restituir"**.
