Esta tela tem o objetivo de vincular todos os documentos escaneados em uma pasta pré-definida, para salvá-las em uma pasta padrão.

![Imagem 3: Esta tela tem o objetivo de vincular todos os documentos escaneados em uma pasta pré-definida, para salvá-las em uma…](https://ajuda.sankhya.com.br/hc/article_attachments/360093481513)

Caso deseje, informe a **"Descrição"** que seja coerente para os documentos vinculados.

No campo **"Pasta Documentos"** será carregado o diretório onde encontram-se os documentos.

Selecione a **"Origem"** de acordo com o cadastro na pasta de documentos para selecionar a pasta de destino.

No campo **"Pasta"**, informe a pasta de destino cadastrada na tela [Pasta de Documentos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045938753-Pasta-de-Documentos).

Após processados os documentos, o sistema efetuará a marcação **"Processado"**.

Os campos **"Usuário Incluiu"**, **"Usuário Alterou"**, **"Dh. Inclusão"** e **"Dh. Alteração"** são preenchidos automaticamente, conforme inclusão/alteração do Vínculo de Documentos.

Depois de selecionar as pastas com as imagens escaneadas, clique no botão ![Imagem 4: Depois de selecionar as pastas com as imagens escaneadas, clique no botão "Vincular Scaneadas" para que o sistema…](https://ajuda.sankhya.com.br/hc/article_attachments/360093481973) **"Vincular Scaneadas"** para que o sistema vincule os scanners na pasta de destino informada.

O botão ![Imagem 5: O botão "Buscar Path" quando acionado, irá localizar o Path da Impressora .](https://ajuda.sankhya.com.br/hc/article_attachments/360091327914) **"Buscar Path"** quando acionado, irá localizar o Path da Impressora.
