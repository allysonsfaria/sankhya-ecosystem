# Configuração de Tipos de Títulos p/ Acerto

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312377573655) Módulo: Financeiro > Rotinas > Acertos
```

---

Nesta tela, você efetua a configuração dos [Tipos de Títulos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044606494-Tipos-de-T%C3%ADtulo) que serão utilizados na rotina de [Acerto de Ordem de Carga](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607014).

![Imagem 2: Nesta tela, você efetua a configuração dos Tipos de Títulos que serão utilizados na rotina de Acerto de Ordem de Carga .](https://ajuda.sankhya.com.br/hc/article_attachments/360093856053)

No quadrante **"Tipos de Títulos Disponíveis"** estão os Tipos de Títulos disponíveis para seleção. Para facilitar a localização dos Tipos de Título Disponíveis, você pode utilizar o campo de busca existente sobre este campo.

Para o quadrante **"Tipos de Títulos escolhidos"** devem ser transferidos os Tipos de Título a serem utilizados na rotina de Acerto de Ordem de Carga.

Para a transferência dos Tipos de Título entre os quadrantes, você pode selecionar a linha desejada e utilizar os botões de transferência posicionados entre as duas áreas, ou simplesmente dar um duplo clique com cursor do mouse sobre o item desejado. Por fim, efetue o salvamento da configuração, ou seu cancelamento em caso de equívoco.

Os Tipos de Título presentes no espaço **"Tipos de Títulos Escolhidos"** ficarão disponíveis na tela [Acerto de Ordem de Carga](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607014), aba [Resumo do Acerto](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607014#rel.resumoacerto).
