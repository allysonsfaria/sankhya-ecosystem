# Implantação dos Saldos de Contas

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312421860247) Módulo: Financeiro > Arquivos > Cadastros
```

---

Depois de realizado o cadastro de uma Conta Bancária, utiliza-se desta opção para implantar o seu saldo. Através do ícone representado pela **"lupa"** identifique a conta recém cadastrada, e logo abaixo, os campos **"Conta"** e **"Descrição"** serão exibidos preenchidos com os respectivos dados.

![Imagem 2: Depois de realizado o cadastro de uma Conta Bancária, utiliza-se desta opção para implantar o seu saldo. Através do…](https://ajuda.sankhya.com.br/hc/article_attachments/360096282094)

No campo **"Referência p/ Aceitar Lançamentos"** informe a data de referência para que sejam aceitos lançamentos, ou seja, a data a partir da qual, pode-se realizar movimentações na conta bancária; baixa de títulos por exemplo.

**Observação:** será aceita uma data retroativa de no máximo 12 meses em relação à data atual.

O preenchimento do campo **"Referência p/ Aceitar Lançamentos"** ativa os campos **"Saldo do Banco na Referência"** e **"Saldo Real na Referência"**.

Em **"Saldo do Banco na Referência"** informe o saldo do banco na data de referência.

Já no campo **"Saldo Real na Referência"** efetue o preenchimento do saldo real da conta na data de referência.

Uma vez efetuado o preenchimento dos campos citados, realiza-se o salvamento dos dados, finalizando o procedimento de implantação dos saldos.

**Observação:** caso seja necessário ajustar o saldo bancário, deve-se inserir uma data de referência anterior e, desta forma, reprocessar os saldos contidos nos campos Saldo do Banco na Referência e Saldo Real na Referência, para que o sistema atualize os registros.

**Importante:** uma vez implantado o saldo, os campos destinados a esta informação, serão bloqueados para edição, o que indisponibiliza sua posterior modificação.

![Imagem 3: Importante: uma vez implantado o saldo, os campos destinados a esta informação, serão bloqueados para edição, o que…](https://ajuda.sankhya.com.br/hc/article_attachments/360083734833)

No cadastro de contas bancárias realizado na tela **"Configurações > Cadastros > Bancários > Contas"**, os campos **"Referência p/ Aceitar Lançamentos"**, **"Saldo do Banco na Referência"** e **"Saldo Real na Referência"** estarão sempre desabilitados, servindo apenas para visualização.  Na aba **"Saldos"** serão apresentados os saldos a partir da data de **"Referência p/ Aceitar Lançamentos"**. Na inclusão da conta, esses campos terão valores nulos.

**Importante:** também é possível implantar o saldo bancário diretamente no cadastro da conta bancária. Pode-se visualizar como este procedimento é possível, através da tela [Contas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115113-Contas), [Botão Outras Opções](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115113-Contas#botooutrasopes).
