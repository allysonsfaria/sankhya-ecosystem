# Impr. de Cheques pelo Mov. Bancário

```
![Imagem 1](https://ajuda.sankhya.com.br/hc/article_attachments/42312487386391) Módulo: Financeiro> Relatórios
```

---

Esta tela permite efetuar a visualização e a impressão de cheques referentes a movimentações bancárias realizadas através da rotina de [Movimentação Bancária](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115653), cujo tipo de movimento deve ser diferente de Financeiro. Isso implica que movimentações originadas da baixa de um título não serão apresentadas aqui.

![Imagem 2: Esta tela permite efetuar a visualização e a impressão de cheques referentes a movimentações bancárias realizadas…](https://ajuda.sankhya.com.br/hc/article_attachments/8745607489559)

No painel principal, teremos os filtros responsáveis pela busca das movimentações bancárias. Sendo que, além destes filtros pode-se criar através do ![Imagem 3: No painel principal, teremos os filtros responsáveis pela busca das movimentações bancárias. Sendo que, além destes…](https://ajuda.sankhya.com.br/hc/article_attachments/16343169381655) **"Assistente de Filtros"** um Filtro Personalizado destinado à busca de uma movimentação específica.

O link **"Ver modelos de cheques"**, só ficará habilitado quando o filtro **"Conta de Origem"** estiver preenchido. Ao clicar sobre o mesmo, a tela [Modelos de cheques](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607074) é aberta posicionada no modelo vinculado a conta. Caso seja selecionada uma conta que não contém um modelo vinculado, a tela se posicionará no primeiro registro.

**Nota:** o modelo de cheque empregado, necessita ter um modelo vinculado ao mesmo no campo **"Cópia (mov. Bancário)"**, aba **"Cheque"**, na tela Modelos de cheques.

Após aplicar os filtros necessários, pode-se selecionar as movimentações desejadas para realizar a visualização/impressão dos cheques através dos botões ![Imagem 4: Após aplicar os filtros necessários, pode-se selecionar as movimentações desejadas para realizar a…](https://ajuda.sankhya.com.br/hc/article_attachments/16510828409879) **"Pré-visualiza cheques p/ os movimentos selecionados"** e ![Imagem 5: Após aplicar os filtros necessários, pode-se selecionar as movimentações desejadas para realizar a…](https://ajuda.sankhya.com.br/hc/article_attachments/16510828412311) **"Imprime cheques p/ os movimentos selecionados"**, respectivamente. Ambos os botões quando acionados, exibem o pop-up **"Numeração dos cheques"** com as seguintes opções:

- Gravar numeração dos cheques?;
- Número do próximo cheque;
- Gerar Cópia.

A opção **"Gravar numeração dos cheques?"**, no modo de Visualização não efetuará nenhuma ação. A mesma só será respeitada no caso de Impressão, quando fará com que a opção **"Número do próximo cheque"** seja preenchida de acordo com a sequência das próximas impressões efetuadas.

Caso você seja um caixa, na impressão do cheque se a opção Gravar numeração dos cheques? estiver marcada, não será possível concluir a impressão. O sistema irá emitir a mensagem:

**"Este lançamento possui movimentações de caixa. Não pode ser alterado."**
