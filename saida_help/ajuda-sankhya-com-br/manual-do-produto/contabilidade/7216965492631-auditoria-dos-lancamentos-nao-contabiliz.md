# Auditoria dos Lançamentos Não Contabilizados

```
![módulo](https://ajuda.sankhya.com.br/guide-media/01H3C7R251XDNMEGRCCRV7P1QZ) Módulo: Contabilidade > Consultas > Conciliação Contábil ![Versão](https://ajuda.sankhya.com.br/guide-media/01H3C7RCC14APZRSA1ZSY49VCP) Versão: A partir da 4.13
```

---

Por meio desta auditoria é possível validar se todos os registros configurados para contabilização estão devidamente escriturados na Contabilidade.

Aqui serão apresentados todos os tipos de movimentações, sendo assim para consultá-los, preencha as informações obrigatórias no Painel de Filtros:

![Imagem 3: Aqui serão apresentados todos os tipos de movimentações, sendo assim para consultá-los, preencha as informações…](https://ajuda.sankhya.com.br/hc/article_attachments/7217249436439)

Indique nos campos **"Data Inicial"** e **"Data Final"** o período a ser consultado.

Realize a marcação **"Empresa"** para selecionar uma empresa específica ou um grupo considerando matriz e filiais.

Ao **"Atualizar"** o filtro configurado, será apresentada uma lista com os registros não contabilizados demonstrando sua origem.

![Imagem 4: Ao "Atualizar" o filtro configurado, será apresentada uma lista com os registros não contabilizados demonstrando sua…](https://ajuda.sankhya.com.br/hc/article_attachments/7217292278679)

**Importante:** Caso utilize a opção **"Liberar lançamentos sem integração com a contabilidade?"** na confirmação do [Agendamento](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044608294), esses lançamentos permanecerão pendentes de contabilização no dashbord.
