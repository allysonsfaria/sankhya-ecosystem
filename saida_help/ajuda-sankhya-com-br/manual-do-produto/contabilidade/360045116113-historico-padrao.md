# Histórico Padrão

**Importante:** Nesta documentação você irá visualizar a descrição das funcionalidades da tela Histórico Padrão que está localizada nos menus **"Contabilidade > Cadastros"** e **"Contabilização > Cadastros "**.

Através desta tela será possível realizar o cadastro de Históricos Padrão para lançamentos contábeis e realizar a utilização destes nos lançamentos, de modo a facilitar sua interpretação e suas respectivas partidas.

![Imagem 1: Através desta tela será possível realizar o cadastro de Históricos Padrão para lançamentos contábeis e realizar a…](https://ajuda.sankhya.com.br/hc/article_attachments/5316416278423)

Para realizar o cadastro de um histórico, clicando-se no botão ![Imagem 2: Para realizar o cadastro de um histórico, clicando-se no botão para inserção de um novo registro, informa-se…](https://ajuda.sankhya.com.br/hc/article_attachments/5316414238359) para inserção de um novo registro, informa-se inicialmente o código do histórico; este dado pode ser incluído de forma manual ou automática, dependendo da configuração realizada na opção **"Numeração"** presente no botão**![Imagem 3: Para realizar o cadastro de um histórico, clicando-se no botão para inserção de um novo registro, informa-se…](https://ajuda.sankhya.com.br/hc/article_attachments/5316439807255) "Configuração da tela"** localizado na parte superior direita da tela.

Depois de informado o código, preenche-se a **"Descrição"** do histórico, ou seja, a informação que será utilizada nos lançamentos, por exemplo, **"Valor ref. aquisição via NF"**. Tem-se neste espaço, um limite de 255 caracteres para digitação.
