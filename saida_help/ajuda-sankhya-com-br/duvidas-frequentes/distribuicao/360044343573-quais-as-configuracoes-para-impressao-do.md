# Quais as configurações para impressão do DACTE com QR Code

O novo modelo de impressão já esta disponível para ser baixado na tela Comercial » Arquivo » Cadastros » Modelo de Impressão (Nota/Pedido). Dessa forma, recomenda-se o download dos arquivos de impressão atualizados que se adequem a necessidade da empresa:

![Imagem 1: O novo modelo de impressão já esta disponível para ser baixado na tela Comercial » Arquivo » Cadastros » Modelo de…](https://ajuda.sankhya.com.br/hc/article_attachments/15070114365335)

**(1)** Realizado o download, adicione seus arquivos na tela Modelo de Impressão (Nota/Pedido), conforme exemplo abaixo:

![Imagem 2: (1) Realizado o download, adicione seus arquivos na tela Modelo de Impressão (Nota/Pedido), conforme exemplo abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/15070141477527)

**(2)** O modelo criado deverá ser vinculado na tela 'Modelos de Nota Fiscal/Duplicatas/Boleto(s)' (Configurações » Avançado):

![Imagem 3: (2) O modelo criado deverá ser vinculado na tela 'Modelos de Nota Fiscal/Duplicatas/Boleto(s)' (Configurações »…](https://ajuda.sankhya.com.br/hc/article_attachments/15070188243735)

**(3)** O código modelo gerado no item anterior deverá ser vinculado na aba 'Impressão' do Tipo de Operação utilizado na emissão do respectivo CT-e:

![Imagem 4: (3) O código modelo gerado no item anterior deverá ser vinculado na aba 'Impressão' do Tipo de Operação utilizado na…](https://ajuda.sankhya.com.br/hc/article_attachments/15070229612055)

**(4)** Realize os devidos testes de impressão.
