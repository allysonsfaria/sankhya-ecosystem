# Rateio de Fretes

**![Mensagem](https://ajuda.sankhya.com.br/hc/article_attachments/15947974496919) MENSAGEM**:

Frete para Múltiplas notas.

**![Causa](https://ajuda.sankhya.com.br/hc/article_attachments/15947967153943) CAUSA:**

Quando fornecedor do cliente emite mais de uma nota e a transportadora manifesta todas em um único CTE.

**![Solução](https://ajuda.sankhya.com.br/hc/article_attachments/15947974505111) SOLUÇÃO:**

Esta opção permite lançar o financeiro de um frete correspondente a várias notas, com possibilidade de se distribuir manualmente ou com rateio pelo valor ou peso. A opção é habilitada ao selecionar mais de uma Nota e os valores distribuídos serão inseridos, automaticamente, na aba **"Transporte"** dos totais. É importante que se tenha um parceiro transportador comum, lançado nas notas para as quais o frete será rateado.
Quando o valor do 'Frete de uma Nota' for gerado por esta opção, se o usuário tentar alterar o valor direto na 'Nota', o sistema travará a alteração no momento de 'Salvar' esta Nota. ..."
Selecione as **notas no portal >> Botão Outras Opções >> Diversos >> Frete para múltiplas notas.**
