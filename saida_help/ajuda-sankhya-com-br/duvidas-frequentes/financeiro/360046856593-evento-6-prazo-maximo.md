# Evento 6 - Prazo Máximo

**(1)** Para este evento, tem-se as seguintes configurações:

![Imagem 1: No cadastro de "Tipos de Negociação" (Caminho de acesso: Comercial » Arquivo » Cadastros), aba "Características"…](https://ajuda.sankhya.com.br/hc/article_attachments/16537105431063) No cadastro de **"Tipos de Negociação"** (Caminho de acesso: Comercial » Arquivo » Cadastros), aba **"Características"** estipule o **"Prazo Máximo"**:

- No campo Prazo máximo determine um prazo máximo em dias para realização de vendas utilizando o Tipo de Negociação. Caso o prazo seja ultrapassado, o sistema barra a venda e solicita liberação para o evento '6-Prazo Máximo'.

![Imagem 2: No campo Prazo máximo determine um prazo máximo em dias para realização de vendas utilizando o Tipo de Negociação. Caso…](https://ajuda.sankhya.com.br/hc/article_attachments/15523080868247)

![Imagem 3: Informe em quantidade de dias, até quando poderão se estender os parcelamentos para aquele Tipo de Negociação. Esta…](https://ajuda.sankhya.com.br/hc/article_attachments/16537105433495) Informe em quantidade de dias, até quando poderão se estender os parcelamentos para aquele Tipo de Negociação. Esta informação também é utilizada no caso de alguma alteração manual nas parcelas de uma Venda.

**Exemplo:**

Ao lançar uma nota, se for modificada uma alteração nas parcelas de modo que seja  ultrapassado o Prazo Máximo, será aberto o pop-up de Solicitação de Liberação de Limites para o evento 6 - Prazo Máximo.
