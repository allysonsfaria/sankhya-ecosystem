# Existe uma lista de Impressora de Cheque Homologadas pela Sankhya?

(1)** Não** existe uma lista de impressoras **homologadas**, o que o Sankhya-W precisa é que a impressora seja reconhecida pelo Windows e a mesma possua comandos de impressão de '**Text Plain**' (driver para TXT), ou seja, ela deve ser capaz de interpretar um arquivo txt.
