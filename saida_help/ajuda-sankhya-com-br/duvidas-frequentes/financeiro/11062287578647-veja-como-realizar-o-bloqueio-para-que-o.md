# Veja como realizar o bloqueio para que o sistema não permita alterações nos títulos após conciliação

(1)** 1ª Alternativa:**

**Rotina da contabilidade:**pela qual, através da tela [Configuração Fechamento Contábil/Fiscal](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044595654-Configura%C3%A7%C3%A3o-Fechamento-Cont%C3%A1bil-Fiscal?source=search&auth_token=eyJhbGciOiJIUzI1NiJ9.eyJhY2NvdW50X2lkIjo5NjE4MTY4LCJ1c2VyX2lkIjo4NzM2MTg3NDAxMTExLCJ0aWNrZXRfaWQiOjIzNjE2MywiY2hhbm5lbF9pZCI6NjMsInR5cGUiOiJTRUFSQ0giLCJleHAiOjE2NzA1ODY5NTF9.l66z0zOLilv6gcqQzEqUG3N6-8Bsk-Yyo_WZfkFAhH4) (Livros Fiscais > Contabilidade) se realiza o bloqueio das movimentações em datas retroativas. **Para saber mais sobre esse processo clique [aqui](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044595654).**

(1)** 2ª Alternativa:**

 Tela usuários ["Usuários"](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios?source=search&auth_token=eyJhbGciOiJIUzI1NiJ9.eyJhY2NvdW50X2lkIjo5NjE4MTY4LCJ1c2VyX2lkIjo4NzM2MTg3NDAxMTExLCJ0aWNrZXRfaWQiOjIzNjE2MywiY2hhbm5lbF9pZCI6NjMsInR5cGUiOiJTRUFSQ0giLCJleHAiOjE2NzA1ODY5NTF9.l66z0zOLilv6gcqQzEqUG3N6-8Bsk-Yyo_WZfkFAhH4)
