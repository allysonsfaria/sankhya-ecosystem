# Como realizar a compensação financeira para parceiros diferentes

Quando o parâmetro**"PERMFILPARCVAZ - Permite parceiro vazio no filtro da compensação financeira"**estiver desligado, o sistema não permitirá que os filtros estáticos **"Parceiro Matriz"** e **"Parceiro"** não sejam informados, exibindo mensagem de erro ao aplicar o filtro de busca para os títulos sem estas marcações.

Quando **LIGADO**, mesmo que não se preencha os campos Parceiro ou Parceiro Matriz, será possível realizar a busca de títulos pelo filtros na tela de **"Compensação Financeira"**, permitindo assim visualizar títulos de parceiros diferentes, para que a compensação aconteça como desejado:
