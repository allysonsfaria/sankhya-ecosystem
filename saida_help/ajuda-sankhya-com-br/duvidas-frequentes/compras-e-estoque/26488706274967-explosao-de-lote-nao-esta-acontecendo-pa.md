# Explosão de lote não está acontecendo para os componentes do kit independente

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/26488706259223) **MENSAGEM:**

Explosão de lote não está acontecendo para os componentes do kit independente.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26488694558615)SOLUÇÃO:**

Se desejar trabalhar com explosão de lote para o kit, não é possível usar o kit independente. Pois, o mesmo não trabalha com explosão de lotes.

Assim, é necessário usar o kit convencional, cuja configuração é feita por parâmetros.

Mais informações, acesse: [Suporte a Venda de Kits de Produtos – Sankhya Gestão de Negócios](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045111433-Suporte-a-Venda-de-Kits-de-Produtos)

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26488694560279)CAUSA:**

Kit independente não está preparado para trabalhar com explosão de lotes.
