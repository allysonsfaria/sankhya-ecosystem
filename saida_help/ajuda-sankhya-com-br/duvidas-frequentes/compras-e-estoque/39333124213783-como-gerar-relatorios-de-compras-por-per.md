# Como gerar relatórios de compras por período no sistema Sankhya?

O sistema Sankhya oferece diferentes recursos para gerar relatórios de compras em períodos específicos, permitindo análises detalhadas das aquisições realizadas pela empresa. Este artigo apresenta as principais opções disponíveis para extrair essas informações.

### Gerente Online - Análises de Compras

O **"Gerente Online"** (Comercial » Gerente » Gerente On-Line - GOL) disponibiliza análises prontas que podem atender à necessidade de relatórios de compras por período. Acesse esta funcionalidade para verificar os dashboards disponíveis relacionados a compras.

Nesta tela, é possível filtrar as informações por período, visualizar dados consolidados e exportar os resultados conforme a necessidade da análise.

### Relatório Kardex

O relatório **"Kardex"** (Comercial » Relatórios » Kardex) permite verificar tanto lançamentos de vendas quanto de compras, incluindo os custos dos produtos. Este relatório é uma ferramenta completa para análise de movimentações.

Para utilizar o Kardex de forma eficiente, selecione o período desejado e aplique os filtros necessários para visualizar especificamente as compras realizadas.

### Relatórios Personalizados via Place

Caso as opções nativas não atendam completamente à sua necessidade, consulte o **"Place"** para verificar se existe algum relatório pronto desenvolvido pela comunidade que se enquadre na sua demanda específica.

Se ainda assim não encontrar uma opção adequada, é possível solicitar à unidade a criação de um relatório personalizado, desenvolvido conforme as necessidades específicas da empresa.
