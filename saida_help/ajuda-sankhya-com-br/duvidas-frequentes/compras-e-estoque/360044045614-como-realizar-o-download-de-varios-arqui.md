# Como realizar o download de vários arquivos XML do CT-e?

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18943267584919) SOLUÇÃO:**

Quando o cliente deseja realizar o download agrupado de todos os arquivos de CTe para uma possível entrega a um contador, departamento fiscal ou até mesmo para o fisco, o passo a passo abaixo poderá ser utilizado:

![Imagem 2: Acesse ' Gerar Arquivo XML de CTe ' (Comercial » Rotinas).](https://ajuda.sankhya.com.br/hc/article_attachments/18943267596951) Acesse '**Gerar Arquivo XML de CTe**' (Comercial » Rotinas).

O objetivo desta rotina é de permitir que seja possível o download de vários arquivos XML do CT-e a partir de filtros previamente definidos, semelhante à forma que existe para o download da NF-e.

![Imagem 3: Realize os filtros conforme desejado:](https://ajuda.sankhya.com.br/hc/article_attachments/18943261476631) Realize os filtros conforme desejado:

![Imagem 4: Clique em 'Download'.](https://ajuda.sankhya.com.br/hc/article_attachments/18943267612439) Clique em 'Download'.

![Imagem 5: Os arquivos serão baixados conforme filtros executados,em formato '.zip'.](https://ajuda.sankhya.com.br/hc/article_attachments/18943267619735) Os arquivos serão baixados conforme filtros executados,em formato '.zip'.
