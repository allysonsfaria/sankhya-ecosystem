# Como destacar os valores de ICMS para empresas optantes pelo simples nacional?

**(1)** Para Empresas Optantes pelo Simples Nacional, o destaque desse imposto acontecerá diante utilização do CSOSN **900 - Outros.**

Para conferir essa informação, siga as orientações:

![Imagem 1: Identifique na grande de itens, para todos os produtos, a informação que está sendo apresentada no campo "Cód.situação…](https://ajuda.sankhya.com.br/hc/article_attachments/17005120958103) Identifique na grande de itens, para todos os produtos, a informação que está sendo apresentada no campo **"Cód.situação op.Simples Nacional (CSOSN)**":

![Imagem 2: Se essa informação for diferente de 900, de fato o 'Vlr.ICMS' não terá seu valor destacado;](https://ajuda.sankhya.com.br/hc/article_attachments/17005120960407) Se essa informação for diferente de 900, de fato o 'Vlr.ICMS' não terá seu valor destacado;

![Imagem 3: Dessa forma, faça sintonias com o contador para avaliar o ajuste dessa informação e/ou validação do não destaque do…](https://ajuda.sankhya.com.br/hc/article_attachments/17005105806231) Dessa forma, faça sintonias com o contador para avaliar o ajuste dessa informação e/ou validação do não destaque do imposto, diante utilização de outro CSOSN.

![Imagem 4: Para efetuar o ajuste do CSOSN, acesse o cadastro de Alíquotas de ICMS (Caminho de acesso: Comercial » Arquivo »…](https://ajuda.sankhya.com.br/hc/article_attachments/17005120965399) Para efetuar o ajuste do CSOSN, acesse o cadastro de Alíquotas de ICMS (Caminho de acesso: Comercial » Arquivo » Cadastros » Alíquotas), identifique a regra de ICMS que a NF-e se enquadrou e, na aba **"Simples Nacional"**, efetue os ajustes devidos.

**![Imagem 5: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17005120971927) OBSERVAÇÃO:**

Só tem destaque quando a operação for devolução de compra, nas demais operações destaca o valor cabeçalho e itens da nota, porém não é levado para nenhuma tag do xml da nota.

Para mais informações de como localizar a regra de ICMS que está sendo utilizada, consulte: [Como identificar qual a alíquota/exceção de ICMS utilizada no lançamento?](https://ajuda.sankhya.com.br/hc/pt-br/articles/360043874154)
