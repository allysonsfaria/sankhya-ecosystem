# Posso ter vários agendamentos para Análise de Giro?

**(1)** Não recomendamos ter vários agendamentos para Análise de Giro, pois ela é gerada para gravar informações na tabela 'TGFGIR1, ou seja, são gravados os dados da movimentação dos produtos.

Posteriormente, quando se 'Processa a Matriz', de acordo com as 'Configurações da Matriz de Analise de Giro', o comprador receberá esses dados na tela.

Os dados gerados podem ficar incoerentes caso se tenha mais de um agendamento configurado.

Então, recomenda-se criar um Agendamento de acordo com o 'Agrupamento de Período' que a Empresa achar mais relevante, se 'Diário, Mensal ou Semanal'.

Depois, pode-se criar varias Matrizes com diferentes filtros, períodos e etc, para atender as diferentes análises, de acordo com o Mix de Produtos da Empresa.
