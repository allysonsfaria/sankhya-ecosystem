# Como adicionar produtos na seção de 'Lançamentos' do site?

![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17799887699479) **SITUAÇÃO:**

A seção de Lançamentos, situada dentro do site, é usada para apresentação de produtos inéditos, recém chagados no estoque da empresa.

**![Imagem 2: A seção de Lançamentos, situada dentro do site, é usada para apresentação de produtos inéditos, recém chagados no…](https://ajuda.sankhya.com.br/hc/article_attachments/17799887706775) SOLUÇÃO:**

Para que o produto seja apresentado na seção de lançamentos, realize os seguintes passos:

![Imagem 3: A seção de Lançamentos, situada dentro do site, é usada para apresentação de produtos inéditos, recém chagados no…](https://ajuda.sankhya.com.br/hc/article_attachments/17799914716823) No ERP, na tela de Cadastro de Produtos aba E-commerce, marque a opção 'Lançamento':

![Imagem 4: A seção de Lançamentos, situada dentro do site, é usada para apresentação de produtos inéditos, recém chagados no…](https://ajuda.sankhya.com.br/hc/article_attachments/17799887722903) Realizando a marcação do campo, o produto irá ser integrado automaticamente na seção 'Lançamentos' do site. (O tempo de integração pode variar entre 5-10 minutos).

![Imagem 5: A seção de Lançamentos, situada dentro do site, é usada para apresentação de produtos inéditos, recém chagados no…](https://ajuda.sankhya.com.br/hc/article_attachments/17799914740887) **OBSERVAÇÃO:**

A seção de Lançamentos é nativa da plataforma.
