# Como configurar para que somente o Gerente faça o fechamento e conferência de caixa?

![Imagem 1: Acesse: Configurações » Avançado » Preferências](https://ajuda.sankhya.com.br/hc/article_attachments/17122994223127) Acesse: Configurações » Avançado » Preferências

Ligue o parâmetro: **"FECHACXGERENTE- Fechamento de caixa pelo gerente"**

![Imagem 2: Ligue o parâmetro: "FECHACXGERENTE- Fechamento de caixa pelo gerente"](https://ajuda.sankhya.com.br/hc/article_attachments/13421899621271)

![Imagem 3: Acesse: Configurações » Controle de Acesso » Usuários](https://ajuda.sankhya.com.br/hc/article_attachments/17123023037975) Acesse: Configurações » Controle de Acesso » Usuários

Aba: **"Segurança"**

Marque a opção **"Gerente de Caixa"**, para o Usuário simbolizado como Gerente.

![Imagem 4: Marque a opção "Gerente de Caixa" , para o Usuário simbolizado como Gerente.](https://ajuda.sankhya.com.br/hc/article_attachments/13421902673943)

![Imagem 5: Feito isto, somente os gerentes de caixas estarão habilitados para Fechamento de Caixa e Conferência de caixa.…](https://ajuda.sankhya.com.br/hc/article_attachments/17123023040279) Feito isto, somente os gerentes de caixas estarão habilitados para Fechamento de Caixa e Conferência de caixa. Portanto, o usuário caixa perderá estes acessos.
