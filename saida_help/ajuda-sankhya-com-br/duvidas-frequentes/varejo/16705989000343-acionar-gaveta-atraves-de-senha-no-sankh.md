# Acionar Gaveta através de senha  no Sankhya Checkout

**![Imagem 1: SITUAÇÃO::](https://ajuda.sankhya.com.br/hc/article_attachments/16749611812631)  SITUAÇÃO::**

Para que consiga acionar a gaveta com senha no Sankhya  Checkout é necessário que se realize configurações no perfil do usuário.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16705966187031) CAUSA:**

Não está solicitando senha no momento da abertura da gaveta

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16705981174039) SOLUÇÃO:**

**Passo a passo para configuração :**

Menu > Cadastros > Perfis > Perfis e Acessos

Escolher o Perfil  : Caixa

Aba Venda : "Acionar a gaveta " > **Este não poderá estar flegado**

![Imagem 4: Aba Venda : "Acionar a gaveta " > Este não poderá estar flegado](https://ajuda.sankhya.com.br/hc/article_attachments/16749595266071)

É necessário que o **"Acionar a gaveta"** esteja flegado no perfil do usuário Gerente pra que solicite a senha do mesmo no momento de abertura da gaveta

Atalho para Acionar a gaveta : CTRL + G

![Imagem 5: Atalho para Acionar a gaveta : CTRL + G](https://ajuda.sankhya.com.br/hc/article_attachments/16749609696919)
