# Como incluir/alterar certificado no Sankhya Checkout

Para incluir ou alterar o certificado no Sankhya Checkout, siga os passos abaixo:

![Imagem 1: Faça login com usuário SUP ou outro que possua permissão para esse tipo de alteração.](https://ajuda.sankhya.com.br/hc/article_attachments/16202912396823)  Faça login com usuário SUP ou outro que possua permissão para esse tipo de alteração.

![Imagem 2: Acesse a opção conforme print abaixo.](https://ajuda.sankhya.com.br/hc/article_attachments/16202898579735) Acesse a opção conforme print abaixo.

![Imagem 3: Acesse a opção conforme print abaixo.](https://ajuda.sankhya.com.br/hc/article_attachments/15696843655319)

![Imagem 4: Acesse a opção preferências da empresa.](https://ajuda.sankhya.com.br/hc/article_attachments/16202912399511) Acesse a opção preferências da empresa.

![Imagem 5: Acesse a opção preferências da empresa.](https://ajuda.sankhya.com.br/hc/article_attachments/15696845955479)

![Imagem 6: Clique na opção Gerenciar Certificados (0).](https://ajuda.sankhya.com.br/hc/article_attachments/16202912400663) Clique na opção Gerenciar Certificados (0).

![Imagem 7: Digite primeiramente a senha para que habilite a opção de carregar certificado.](https://ajuda.sankhya.com.br/hc/article_attachments/16202898586519) Digite primeiramente a senha para que habilite a opção de carregar certificado.

![Imagem 8: Digite primeiramente a senha para que habilite a opção de carregar certificado.](https://ajuda.sankhya.com.br/hc/article_attachments/4414035709975)

![Imagem 9: Após isso, localize no seu computador e por último clique no botão "Salvar" .](https://ajuda.sankhya.com.br/hc/article_attachments/16202898588567) Após isso, localize no seu computador e por último clique no botão **"Salvar"**.
