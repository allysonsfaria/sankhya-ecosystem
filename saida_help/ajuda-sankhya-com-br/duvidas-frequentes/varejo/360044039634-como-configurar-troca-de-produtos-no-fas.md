# Como configurar TROCA de Produtos no Fast Service

#### Para efetuar troca de produtos no FAST Service siga os procedimentos conforme abaixo:

![Imagem 1: Acesse a tela Tipos de Operação - TOP (Comercial » Arquivo » Cadastros » Tipos de Operação - TOP)](https://ajuda.sankhya.com.br/hc/article_attachments/18849762778135) Acesse a tela **Tipos de Operação - TOP** (Comercial » Arquivo » Cadastros » Tipos de Operação - TOP)

cadastre uma TOP especifica para este lançamento onde será definido as movimentações realizadas pelo sistema.

Tipo de Movimento= 'D- Devolução de Venda'

**Observação:** Inserindo o processo desejado em (FISCAL/ESTOQUE/FINANCEIRO/CONTROLE DE NUMERAÇÃO)

![Imagem 2: Acesse a tela Modelo de Notas e Pedidos (Comercial » Consulta » Modelo de Notas e Pedidos) cadastre um modelo de…](https://ajuda.sankhya.com.br/hc/article_attachments/18849777229719) Acesse a tela **Modelo de Notas e Pedidos** (Comercial » Consulta » Modelo de Notas e Pedidos) cadastre um modelo de documento para o registro dos produtos trocados nos Portais. Vincule a TOP anteriormente criado no modelo.

![Imagem 3: Acesse a tela Preferências (Configurações » Avançado » Preferências), com o modelo criado acima, informe o número único…](https://ajuda.sankhya.com.br/hc/article_attachments/18849762782743) Acesse a tela **Preferências** (Configurações » Avançado » Preferências), com o modelo criado acima, informe o número único no parâmetro **'CODMODTROCA-Código do modelo de cabeçalho para troca**'.

![Imagem 4: Acesse a tela Preferências (Configurações » Avançado » Preferências) e informe um código de tipo de título, no…](https://ajuda.sankhya.com.br/hc/article_attachments/18849777234327) Acesse a tela **Preferências** (Configurações » Avançado » Preferências) e informe um código de tipo de título, no parâmetro '**TIPTITCREDCLI-Tipo de título para compensação de Crédito.**

**Observação:** Este tipo de título citado neste parâmetro, será o utilizado caso haja compensação.

![Imagem 5: Acesse a tela Preferências (Configurações » Avançado » Preferências) e habilite o parâmetro 'AVISARCREDCLI-Avisar que o…](https://ajuda.sankhya.com.br/hc/article_attachments/18849762790039) Acesse a tela **Preferências** (Configurações » Avançado » Preferências) e habilite o parâmetro **'AVISARCREDCLI-Avisar que o cliente possui Crédito?**', este parâmetro criará uma caixa de diálogo no FAST, informando que o parceiro informado, tem crédito, caso deseja compensar.

![Imagem 6: Feito estes passos, as configurações para efetuar o processo de troca pelo FAST Service, já esta finalizado, e será…](https://ajuda.sankhya.com.br/hc/article_attachments/18849762792087) Feito estes passos, as configurações para efetuar o processo de troca pelo FAST Service, já esta finalizado, e será dado da seguinte forma:

Ao registrar o cupom e inserir o item que deseja trocar, aperte 'CTRL+T' ou com botão direito e 'Troca de Produto'

![Imagem 7: Ao registrar o cupom e inserir o item que deseja trocar, aperte 'CTRL+T' ou com botão direito e 'Troca de Produto'](https://ajuda.sankhya.com.br/hc/article_attachments/360062955933)

Após selecionado, aparecerá uma caixa de diálogo, pedindo para selecionar o cupom de origem com qual deseja efetuar a troca, ao selecionar, clique no item que deseja trocar e selecione 'TROCAR'.

![Imagem 8: Após selecionado, aparecerá uma caixa de diálogo, pedindo para selecionar o cupom de origem com qual deseja efetuar a…](https://ajuda.sankhya.com.br/hc/article_attachments/360062955913)

Após selecionado o produto para troca, e habilitado 'TROCAR', o processo de troca já será realizado com sucesso, podendo ser consultado no Portal de Vendas, através de devolução.
