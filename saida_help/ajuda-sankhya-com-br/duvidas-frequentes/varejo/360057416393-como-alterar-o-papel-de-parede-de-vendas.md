# Como alterar o papel de parede de vendas do Sankhya checkout?

![Imagem 1: Selecione o Menu (superior esquerdo da tela), escolha o atalho "Preferencias":](https://ajuda.sankhya.com.br/hc/article_attachments/17283829191447) Selecione o Menu (superior esquerdo da tela), escolha o atalho **"Preferencias":**

![Imagem 2: Selecione o Menu (superior esquerdo da tela), escolha o atalho "Preferencias":](https://ajuda.sankhya.com.br/hc/article_attachments/17283819142295)

![Imagem 3: Dentro de "Preferências" selecione a opção/aba : "Venda" ;](https://ajuda.sankhya.com.br/hc/article_attachments/17283829202711) Dentro de **"Preferências"** selecione a opção/aba : **"Venda"**;

![Imagem 4: Localize o campo "Imagem Padrão do caixa":](https://ajuda.sankhya.com.br/hc/article_attachments/17283896314519) Localize o campo **"Imagem Padrão do caixa":**

![Imagem 5: Localize o campo "Imagem Padrão do caixa":](https://ajuda.sankhya.com.br/hc/article_attachments/360094831294)

- Neste campo, se informar  um caminho local, ficará a configuração somente para o PDV que está acessando;
- Se informar  um caminho da rede onde todos os PDVs tenham acesso, todos os PDV vão conseguir "ler" essa imagem.

![Imagem 6: Após alteração, saia do sistema, realize um novo acesso e verifique se a imagem foi apresentada conforme desejado.](https://ajuda.sankhya.com.br/hc/article_attachments/17283896319895) Após alteração, saia do sistema, realize um novo acesso e verifique se a imagem foi apresentada conforme desejado.
