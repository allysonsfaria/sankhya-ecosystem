# Quais são os requisitos mínimos para instalação do Fast e Datasync - Estação do Servidor

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19575254877463) SOLUÇÃO:**

Considerando que a instalação do Fast Service com DataSync será uma Estação Servidor, temos os seguintes requisitos mínimos:

- Processador i5
- 8 GB de RAM
- HD de 500 GB/ SSD 240 GB
- Placa de rede 100Mb
- Placa mãe e placa de vídeo, assim como marcas e modelos ficam a critério de cada adquirente.
