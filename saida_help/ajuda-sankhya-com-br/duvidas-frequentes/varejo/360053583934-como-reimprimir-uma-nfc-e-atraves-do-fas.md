# Como reimprimir uma NFC-e através do Fast Service

Para reimpressão de uma segunda via de NFC-e:

- Através do Fast Service, acessar o Menu 'Consultas' -> 'Consulta NFC-e';
- Nesta tela, selecionar o período e o documento desejado;
- Clicar no botão **'Imprimir DANFE'**, conforme mostrado no print abaixo:
