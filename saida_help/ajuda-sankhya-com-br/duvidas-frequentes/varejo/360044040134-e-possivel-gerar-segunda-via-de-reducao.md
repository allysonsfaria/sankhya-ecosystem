# É possível gerar segunda via de Redução Z ou Cupom Fiscal no Fast Service?

Imprimir uma segunda via não é possível, mas visualizar as informações contidas na que foi impressa, SIM. Através do FastService » Menu » Utilitários » Impressora Fiscal » Gerar Espelho MFD.

MFD significa **Memória Fita Detalhe**e é a tecnologia que armazena os dados fiscais das vendas na impressora. Em outras palavras, a impressora guarda tudo que é impresso de forma que é possível recuperar depois uma cópia (“espelho”) em formato de arquivo texto.

O arquivo gerado sera no formato \*.txt, e ficará salvo no diretório/pasta do Fast Service.

Este processo gera toda movimentação de emissão de documentos(cupom) da Impressora fiscal, feita no dia, então o processo é demorado e enquanto o sistema estiver gerando o arquivo, não será possível emitir cupom fiscal e recomenda-se não desligar a impressora.
