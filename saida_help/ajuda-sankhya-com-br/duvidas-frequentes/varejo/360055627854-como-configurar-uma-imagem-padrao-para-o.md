# Como configurar uma imagem padrão para os produtos sem imagem, no Checkout? 

![Imagem 1: Clique no menu superior esquerdo;](https://ajuda.sankhya.com.br/hc/article_attachments/17283591134103) Clique no menu superior esquerdo;

![Imagem 2: Selecione a opção " Preferências";](https://ajuda.sankhya.com.br/hc/article_attachments/17283591143447) Selecione a opção "**Preferências";**

![Imagem 3: Em Preferências , selecione a aba " Venda";](https://ajuda.sankhya.com.br/hc/article_attachments/17283591146903) Em Preferências, selecione a aba "**Venda";**

![Imagem 4: Em Preferências , selecione a aba " Venda";](https://ajuda.sankhya.com.br/hc/article_attachments/360097123573)

![Imagem 5: Nesta tela localize o campo "Imagem padrão para produtos sem imagem":](https://ajuda.sankhya.com.br/hc/article_attachments/17283601409815) Nesta tela localize o campo **"Imagem padrão para produtos sem imagem":**

![Imagem 6: Nesta tela localize o campo "Imagem padrão para produtos sem imagem":](https://ajuda.sankhya.com.br/hc/article_attachments/360094822094)

![Imagem 7: Clique sobre a descrição do campo Imagem padrão para produtos sem imagem :](https://ajuda.sankhya.com.br/hc/article_attachments/17283591158551) Clique sobre a descrição do campo Imagem padrão para produtos sem imagem:

- Irá apresentar a tela de **"Manutenção de Parâmetros";**
- Clique na pasta apresentada à frente como mostrado no exemplo abaixo;
- Sistema irá abrir a tela para que seja **localizado o diretório** e o arquivo da imagem.

![Imagem 8: Sistema irá abrir a tela para que seja localizado o diretório e o arquivo da imagem.](https://ajuda.sankhya.com.br/hc/article_attachments/360097126933)

- Nesse exemplo, foi colocada a imagem na pasta do checkout: C:\Program Files (x86)\Sankhya Checkout\produtos.

![Imagem 9: Nesse exemplo, foi colocada a imagem na pasta do checkout: C:\Program Files (x86)\Sankhya Checkout\produtos.](https://ajuda.sankhya.com.br/hc/article_attachments/360094825634)

![Imagem 10: Selecione a imagem e clique no botão "Abrir";](https://ajuda.sankhya.com.br/hc/article_attachments/17283601416471) Selecione a imagem e clique no botão **"Abrir";**

![Imagem 11: Na tela que será apresenta a seguir clique no botão (F10). Salve o Registro;](https://ajuda.sankhya.com.br/hc/article_attachments/17283601423383) Na tela que será apresenta a seguir clique no botão (F10). Salve o Registro;

![Imagem 12: Na tela que será apresenta a seguir clique no botão (F10). Salve o Registro;](https://ajuda.sankhya.com.br/hc/article_attachments/360097128633)

- Irá apresentar a mensagem no canto superior direito da tela: **"Sucesso' Atualizado com sucesso!"**

![Imagem 13: Irá apresentar a mensagem no canto superior direito da tela: "Sucesso' Atualizado com sucesso!"](https://ajuda.sankhya.com.br/hc/article_attachments/17283591171735)

![Imagem 14: Efetuadas todas as configurações, clique no botão "(ESC) Fechar".](https://ajuda.sankhya.com.br/hc/article_attachments/17283591176599) Efetuadas todas as configurações, clique no botão **"(ESC) Fechar".**

**![Imagem 15: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/17283591177239) IMPORTANTE:**

Vale a pena ressaltar que para efetuar estas configurações é necessário que o checkout esteja conectado com o ERP, caso não esteja será apresentada a mensagem: **"Não é possível prosseguir.' 'Esta tela requer conexão com o ERP."**
