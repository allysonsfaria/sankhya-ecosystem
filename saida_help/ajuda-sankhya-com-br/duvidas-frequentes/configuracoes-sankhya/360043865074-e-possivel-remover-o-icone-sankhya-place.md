# É possível remover o Ícone 'Sankhya Place' da tela inicial para os usuários do sistema?

**(1)** Não. O Ícone 'Sankhya Place' faz parte do layout do sistema. As permissões para conceder ou não acesso ao download dos pacotes é feito através da opção: **"Permite instalar pacote Sankhya Place?"**, no cadastro de Usuários (Caminho de acesso: Configurações » Controle de Acesso » Usuários).
