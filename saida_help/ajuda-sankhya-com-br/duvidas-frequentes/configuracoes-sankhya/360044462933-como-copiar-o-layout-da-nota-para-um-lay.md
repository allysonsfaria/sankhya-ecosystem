# Como copiar o layout da nota para um layout pedido web?

![Imagem 1: Para executar esse procedimento, siga as etapas abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/16832439936023) Para executar esse procedimento, siga as etapas abaixo:

![Imagem 2: Acesse a tela "Configurador de Layout da Nota" (Comercial » Configuração);](https://ajuda.sankhya.com.br/hc/article_attachments/16832499764247)Acesse a tela **"Configurador de Layout da Nota"** (Comercial » Configuração);

![Imagem 3: Selecione o layout que deseja copiar;](https://ajuda.sankhya.com.br/hc/article_attachments/16832499765783) Selecione o layout que deseja copiar;

![Imagem 4: Clique no botão "Visualizar layout em XML";](https://ajuda.sankhya.com.br/hc/article_attachments/16832499768343) Clique no botão **"Visualizar layout em XML";**

![Imagem 5: Clique na opção "Copiar XML para área de transferência";](https://ajuda.sankhya.com.br/hc/article_attachments/16832439947799) Clique na opção **"Copiar XML para área de transferência";**

![Imagem 6: Acesse a tela "Layout de Pedidos" (Pedido Web » Configurações);](https://ajuda.sankhya.com.br/hc/article_attachments/16832439952919) Acesse a tela **"Layout de Pedidos"** (Pedido Web » Configurações);

![Imagem 7: Selecione o layout desejado ou crie o cabeçalho de um layout vazio;](https://ajuda.sankhya.com.br/hc/article_attachments/16832499778071) Selecione o layout desejado ou crie o cabeçalho de um layout vazio;

![Imagem 8: Clique no botão "Carregar layout em XML" ;](https://ajuda.sankhya.com.br/hc/article_attachments/16832439962647) Clique no botão **"Carregar layout em XML"**;

![Imagem 9: Com o botão direito do mouse, cole: Colar o XML copiado do Layout de notas;](https://ajuda.sankhya.com.br/hc/article_attachments/16832439963799) Com o botão direito do mouse, cole: Colar o XML copiado do Layout de notas;

![Imagem 10: Clique no botão "Carregar XML".](https://ajuda.sankhya.com.br/hc/article_attachments/16832439965847) Clique no botão **"Carregar XML".**

Após seguir os passos acima, verifique se o layout foi carregado conforme esperado.
