# Como Identificar telas personalizadas

#### O que é uma tela personalizada?

Uma tela personalizada é quando o cliente necessita de algum processo específico e é criada uma funcionalidade que o sistema não possui em sua forma nativa. Ressaltamos que, rotinas personalizadas tem como matriz de responsabilidade que o **suporte seja prestado pela Unidade** responsável ao parceiro, visto não ser uma alçada do Service Desk.
