Em caso positivo, a alíquota foi…](https://ajuda.sankhya.com.br/hc/article_attachments/16315376444055) Certifique-se que o Código apresentado na grade é o mesmo código digitado na busca. Em caso positivo, a alíquota foi localizada e esses são os dados de ICMS buscados para o respectivo produto/lançamento.
