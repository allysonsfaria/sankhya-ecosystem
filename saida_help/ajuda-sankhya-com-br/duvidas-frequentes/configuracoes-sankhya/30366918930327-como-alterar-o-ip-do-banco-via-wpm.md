# Como alterar o IP do banco via WPM?

#### Procedimento:

##### **(1)** Abra o ''WPM''.

**(1)** Na aba **''Configurações''**, clique em **''Editar dados de conexão''**.

![Imagem 1: (1) Na aba ''Configurações'' , clique em ''Editar dados de conexão'' .](https://ajuda.sankhya.com.br/hc/article_attachments/36911155040919)

**(1)** No pop-up aberto informe no campo **''Host/IP''** o novo **IP** desejado.

**(1)** Salve.

![Imagem 2: (1) Salve.](https://ajuda.sankhya.com.br/hc/article_attachments/36911155041687)

**(1)** O sistema irá reinicializar de forma automática, e o novo IP ficará salvo.
