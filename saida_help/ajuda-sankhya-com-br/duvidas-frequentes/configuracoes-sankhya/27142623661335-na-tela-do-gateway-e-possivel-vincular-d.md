# Na tela do Gateway é  possível vincular duas bases diferentes de produção na mesma appkey?

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/27142623640087) **MENSAGEM:**

Na tela do Gateway é possível vincular duas bases diferentes de produção na mesma appkey?

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/27142614531735)SOLUÇÃO:**

A appkey é uma só. Nesse caso, gere um token para cada instância do SkOm

**Exemplo:** appkeyA -> token1
                 appkeyA -> token2
                 appkeyA -> token3

![Imagem 3: Exemplo: appkeyA -> token1 appkeyA -> token2 appkeyA -> token3](https://ajuda.sankhya.com.br/hc/article_attachments/27164929586199)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/27142623645847)CAUSA:**

Só é necessário gerar uma appkey diferente quando a solução integradora for diferente.
