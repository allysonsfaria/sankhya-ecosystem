# Ficha de Parceiros sem o quadrante 'Financeiros' para certos usuários, o que fazer?

Na tela **"Ficha de Parceiros",** a exibição do quadrante **Financeiro** é controlada através do botão **"Configurar painéis".**

![Imagem 1: Na tela "Ficha de Parceiros", a exibição do quadrante Financeiro é controlada através do botão "Configurar painéis".](https://ajuda.sankhya.com.br/hc/article_attachments/32293842684311)

No entanto, para que o usuário logado tenha permissão para  liberar o quadrante Financeiro, é necessário que pelo menos uma das opções abaixo esteja **desmarcada,** na tela **"Usuários"** (Configurações » Controle de Acesso » Usuários), aba **"Segurança":**

- **Inibe acesso às receitas**
- **Inibe acesso às despesas**
