# Como importar tabelas de preço para o sistema Sankhya?

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16595248964375)SOLUÇÃO:**

É possível realizar a importação de tabelas de preço para o sistema, utilizando a rotina **["Importador de Dados](https://ajuda.sankhya.com.br/hc/pt-br/articles/5874837664023)"**

**Importante:**

A utilização/execução do Importador de dados são direcionados para a equipe de Implantação da Sankhya, dessa forma, diante necessidade de configurações e validações dessa rotina um consultor de sua Unidade deve ser acionado.

O Importador de dados disponibiliza os templates dos cadastros e movimentações suportados no processo. Através desses templates, com os dados do cliente provenientes do seu sistema legado, será possível submetê-los na importação, populando a base do Sankhya Om com as informações do cliente que está sendo implantado.

Para mais detalhes, acesse: [Importador de Dados](https://ajuda.sankhya.com.br/hc/pt-br/articles/5874837664023)
