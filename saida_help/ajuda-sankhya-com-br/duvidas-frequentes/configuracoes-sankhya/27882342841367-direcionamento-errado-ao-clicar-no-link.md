**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/27882342817047)SOLUÇÃO:**

O sistema está implementado para direcionar somente para a tela de relatório formatado,

as outras opções ainda não estão implementadas no SankhyaW.

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/27882351313943)CAUSA:**

Tela de Relatório e de Modelo de Boletos são baseadas na mesma entidade (Relatório). Porém possuem resourcesIDs diferentes.
