# Logomarca da página de login não é alterada

**SITUAÇÃO**

Ao tentar alterar a **logomarca da página de login**, a imagem é vinculada corretamente no sistema, mas não é exibida na tela de login, permanecendo a logomarca padrão.

**SOLUÇÃO**

Atualmente, não existe uma tratativa sistêmica que permita o uso de logomarca personalizada na tela de login quando o **Sankhya ID** está habilitado. Dessa forma, a funcionalidade de imagem personalizada no login não opera enquanto a configuração do Sankhya ID estiver ativa no ambiente.
**Importante:** não é recomendada a desativação dessa configuração, pois ela está relacionada a funcionalidades essenciais do sistema.

**Impactos ao desabilitar o Sankhya ID**

Ao desabilitar o **Sankhya ID**, o ambiente passará a apresentar as seguintes limitações:

- Não será possível abrir chamados via **chat** na Central de Ajuda;
- Os **cards do Maha** não estarão visíveis;
- O login no **Sankhya Om** utilizando credenciais do Sankhya ID (e-mail ou CPF) não estará disponível;
- O botão **Colmeia** ficará indisponível;
- O acesso direto ao **Sankhya Place** pelo Sankhya Om não será possível.

**Recomendação**

Devido aos impactos funcionais gerados, **não é recomendado desabilitar o Sankhya ID** apenas para personalizar a logomarca da tela de login. A orientação é manter o **Sankhya ID habilitado**

Quando o ambiente está configurado para utilizar o **Sankhya ID**, não é possível personalizar a logomarca da página de login. Atualmente, o projeto Sankhya ID encontra-se em **reestruturação**, e, por esse motivo, **a personalização visual da tela de login, incluindo a logomarca**, **não é suportada enquanto essa funcionalidade estiver ativa**.
