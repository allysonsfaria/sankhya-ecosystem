# Importação de dados de cadastro do Parceiro na SEFAZ

**![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16345065581847) SITUAÇÃO:**

Quando se realiza o cadastro de um parceiro é colocado o CNPJ respectivo para se importar os dados da Sefaz. Porém, em alguns casos é verificado que o endereço que foi importado pelo cadastro da Sefaz, está divergente do que é apresentado na receita e também no site do Sintegra. Isto ocorre pois tal comportamento se trata de um "acelerador". O sistema não é responsável pelos dados que importa. Sendo assim, realize manualmente os ajustes dessa rotina.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16345065584407) CAUSA:**

Não se trata de um erro ou inconsistência, tal situação é um comportamento do sistema. A API de retorno não é nativa do sistema, ela é pública. Portanto, os dados importados deverão ser revisados e ajustados manualmente.
