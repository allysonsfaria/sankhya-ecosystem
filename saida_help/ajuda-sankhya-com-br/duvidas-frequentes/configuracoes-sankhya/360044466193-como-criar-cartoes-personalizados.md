# Como criar cartões personalizados?

**(1)** O card tem a função de guiar e chamar a atenção dos seus usuários para as principais rotinas que ele executa no seu dia a dia. Como cada negócio possui necessidades específicas e precisa de uma gestão eficiente e integrada que combine praticidade, evolução gerencial e tecnologia, é possível também criar cartões personalizados no sistema. Para isto, siga os seguintes procedimentos:

![Imagem 1: Da mesma maneira que um dashboard , para construir um cartão acesse a tela de "Construtor de componente de BI" e…](https://ajuda.sankhya.com.br/hc/article_attachments/16834405560471) Da mesma maneira que um dashboard, para construir um cartão acesse a tela de **"Construtor de componente de BI"** e configure o. Existem algumas regras que precisam ser observadas na criação destes indicadores da área de trabalho, são eles:

- O dashboard não pode possuir filtros variáveis (aba **"Parâmetro"**) preenchidos;
- Ele deve possuir apenas um tipo de gráfico (exceto se for Valor).

Ao marcar o campo **"Respectivo tamanho"**, ele estará disponível na área de trabalho para que possa validar as informações.

**![Imagem 2: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/16834405562391) IMPORTANTE:**

- É preciso ter o módulo "30616 - EDITOR DE DASHBOARD /W" liberado para ter acesso a tela de Construtor de Componente de BI.
- Cada cartão consumirá uma licença do '30647 - DASHVIEWER/W'

![Imagem 3: Após a construção do card, libere o acesso para os usuários que irão utilizá-lo. Para isto, acesse a tela de "Acessos",…](https://ajuda.sankhya.com.br/hc/article_attachments/16834427838359) Após a construção do card, libere o acesso para os usuários que irão utilizá-lo. Para isto, acesse a tela de **"Acessos",** no caminho: Módulos » Configurações » Cartões Inteligentes e insira os respectivos responsáveis.

Cada cartão consumirá uma licença do '30647 - DASHVIEWER/W'. Atualmente, esse consumo de licença ainda não está sendo realizado pelo sistema, porém será ajustado em versões futuras.

**![Imagem 4: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/16834405562391) IMPORTANTE:**

Esta funcionalidade estará disponível apenas após o lançamento da versão **Sankhya OM** disponibilizada a partir do dia 30/10/2019.
