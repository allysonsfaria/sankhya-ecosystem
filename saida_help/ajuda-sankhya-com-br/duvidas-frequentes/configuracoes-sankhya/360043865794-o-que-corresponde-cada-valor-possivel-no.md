# O que corresponde cada valor possível no campo Tipo do Anexo (TSIATA.TIPO)?

**(1)** O Campo **Tipo** do Anexo na TSIATA mostra o valor correspondente a origem do anexo lá inserido. Confira a seguir o valor definido para cada um:

| Valor | Descrição |
| --- | --- |
| P - | Parceiro |
| C - | Contrato |
| O - | Ordem de Serviço |
| R - | Produto |
| A - | Agenda Telemarketing |
| N - | Nota |
| F - | E-mail para formatador de relatório |
| T - | Cotação |
| W - | O.S Web |
| I - | Dados de cache para impressão de notas (Por se tratar de dados de cache, podem ser eliminados automaticamente por pelo job LimpadorTabelasJob, do Sankhya-W, ativado pelo parâmetro **"DIASVENCTFILE"**) |
