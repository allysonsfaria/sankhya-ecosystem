# Como inutilizar a numeração de uma nota fiscal eletrônica?

**(1)** Inutilizar uma nota fiscal pressupõe que a numeração não foi usada. Como os documentos devem ser emitidos em numeração sequencial e cronológica, caso hajam saltos nesses números, o contribuinte não poderá fazer uso do algarismo pulado. Dessa forma, a inutilização de numeração consiste em informar para a SEFAZ que a numeração, ou o conjunto delas, não terá servidão para uso do estabelecimento.

(1)** Em quais circunstâncias inutilizar a numeração de uma nota?**

Esse procedimento deve ser realizado quando existe algum contratempo que impede que o documento fiscal eletrônico seja enviado ou recebido pela SEFAZ. Lembrando que para tal é importante se certificar de que esse documento de fato não consta na base de dados da SEFAZ Nacional/Estadual.

(1)** Como realizar a inutilização no sistema?**

Para inutilizar a numeração de uma NF-e você precisa ter os dados abaixo referente a mesma, dessa forma é indicado que a inutilização seja realizada antes da exclusão da nota de seu sistema.
