# Sankhya Developer - API Integração

**O que é uma integração?**

Pode ser interpretado como como uma espécie de ponte, que vai conectar sistemas de parceiros ao EIP Sankhya, transmitindo dados de um lado ao outro, de forma segura e ágil.

Permite a customização de operações entre empresas a automatização de processos internos de uma corporação, as integrações também são necessárias em casos onde se personaliza algum fluxo para atender as necessidades do negócio.

Podemos considerar 3 tipos de integrações legadas:

- Extensão;
- Personalização;
- API de serviços.

**Quem pode desenvolver uma integração?**

As Unidades, empresas especializadas, Hubs de integração e o Cliente, podendo ser integrações e personalizações. Cabe destacar que com este processo ela será a responsável direta pelo suporte e manutenção dos serviços desenvolvidos.

**Como indico um parceiro para homologação?**

As indicações devem ser direcionadas através do email **parceiros@sankhya.com.br** com o nome do parceiro, CNPJ (preferencialmente), e-mail e telefone para contato.
