# Veja onde ficam salvos os links dos servidores cadastrados no Navegador Sankhya

Quando é inserido o link de um servidor na tela de configurações do Navegador Sankhya, o sistema registra esse dado no arquivo webclient.db.

Esse arquivo fica na pasta do usuário, ex: C:\Users\<USER>\AppData\Roaming\Navegador\Sankhya\db.

![Imagem 1: Esse arquivo fica na pasta do usuário, ex: C:\Users\<USER>\AppData\Roaming\Navegador\Sankhya\db.](https://ajuda.sankhya.com.br/hc/article_attachments/27632147628183)

Assim, por meio desse arquivo é possível fazer o uso e gerenciamento dos links cadastrados, seja aproveitando-os para replicá-los numa outra máquina ou mesmo excluindo aqueles que não são necessários.
