# Loja de soluções - Cliente 

A Loja de Soluções é uma plataforma desenvolvida para promover a colaboração e multiplicação das soluções adicionais ao ERP nativo Sankhya. A loja permite que os usuários naveguem e realizem a instalação de diversas soluções disponíveis para acompanhá-los no processo de evolução da sua empresa.

#### Atendimento a Loja de Soluções

O acolhimento do parceiro é iniciado pelo time de Service Desk, onde é realizada uma análise para verificar se a dúvida que o cliente trouxe pode ser sanada através das documentações disponibilizadas na Central de Ajuda. O SLA para atendimento a fila de **soluções é de 7 dias**. Todas as OS abertas para a Loja de Soluções são prioridade 3, pois nenhuma solução paralisa o processo do cliente ou a base de produção.

Quando houver algum incidente em uma  **degustação** ou **trial** nos **pacotes pagos**, o Service Desk direciona uma OS para a fila da Loja de soluções, para que o caso receba as devidas tratativas pelo time.  Caso o cliente baixe um pacote pago e tenha algum problema para providenciar a devolução do valor, o parceiro deverá  acionar a Unidade que abrirá um flow para o financeiro. 

#### Atuação do Service Desk

A atuação do Service Desk se resume em abrir uma OS e direcionar para a Loja de Soluções, sendo de responsabilidade da Unidade atender a demanda do cliente.

| **Atenção:**   - Todos os pacotes antes de serem disponibilizados na Plataforma **são testados em base interna** padrão nativa da Sankhya. Os Pacotes que estivem na Loja de soluções com o status de " Aguardando revisão", o cliente poderá solicitar a revisão do pacote, em que o mesmo irá aguardar o pacote passar por um cheklist e ser disponibilizado. O prazo para essa revisão é de 15 dias; - Se um pacote foi baixado pelo parceiro e não está funcionando**, é direcionada uma OS para a Unidade**, para que a mesma atue em um pacote que não está funcionando. |
