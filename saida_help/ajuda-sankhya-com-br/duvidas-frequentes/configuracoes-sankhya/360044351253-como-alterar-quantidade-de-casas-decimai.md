# Como alterar quantidade de casas decimais para valor?

**![Imagem 1: Para configurar casas decimais para venda:](https://ajuda.sankhya.com.br/hc/article_attachments/16832272108439) Para configurar casas decimais para venda:**

O sistema sempre utiliza a configuração efetuada no campo **"Decimais para o valor"** para lançar o item na venda;

- Tela **"Produtos"** (Caminho de acesso: Configurações » Cadastros » Produtos), aba **"Medidas e Estoque",** campo **"Decimais para o valor"**:

![Imagem 2: Tela "Produtos" (Caminho de acesso: Configurações » Cadastros » Produtos), aba "Medidas e Estoque", campo "Decimais…](https://ajuda.sankhya.com.br/hc/article_attachments/14660094587031)

O parâmetro "DECVLRVOLALT - Decimais p/ cálculo de Volume Alternativo" deve ser configurado com a quantidade de casas decimais que serão utilizadas no cálculo de conversão de valor quando o lançamento for feito com unidade alternativa do produto. Essa configuração visa aumentar a precisão nos casos em que o resultado do cálculo apresenta dízimas.

**![Imagem 3: Para configurar casas decimais para compra:](https://ajuda.sankhya.com.br/hc/article_attachments/16832282440599) Para configurar casas decimais para compra:**

Informe no parâmetro **"Decimais para Custo - CUSTODEC"** a quantidade de casas desejadas.

- Tela **"Preferências"** (Caminho de acesso: Configurações » Avançado) » Chave CUSTODEC:

![Imagem 4: Tela "Preferências" (Caminho de acesso: Configurações » Avançado) » Chave CUSTODEC :](https://ajuda.sankhya.com.br/hc/article_attachments/14660112576535)

Feitas estas configurações, ao lançar o item o sistema assumirá a quantidade de casas definidas nos cadastros/parâmetros.
