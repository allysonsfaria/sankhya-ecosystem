# Download de pacotes 'pagos' no Place 

**Seguem os detalhes referente a aquisição de pacotes no Place:**

- O usuário LOGADO no sistema [Sankhya OM/Jiva Evo], no momento que a tela 'Jiva Place' ou 'Sankhya Place' for aberta, será o responsável pela "aquisição do respectivo pacote".
- Através desse usuário, o sistema identificará quem é o parceiro/CNPJ responsável por essa aquisição.
- Assim que a aquisição/download é realizado, será disparado um BI para o mesmo e-mail cadastrado para recebimento de boletos de cobrança mensal de uso do sistema Jiva/Sankhya.
- Nesse e-mail serão enviados o **boleto e NFS-e** referentes ao valor do pacote adquirido. O boleto, em sua maioria, é gerado com o vencimento até 7 dias após a data do download do pacote.

**IMPORTANTE:**

Diante detalhes acima, é de extrema importância atentar-se aos usuários que terão permissão para executar o download de pacotes no Place. Para tal acesse a tela 'Usuários' e revise a marcação abaixo:

- Aba Segurança : '**Permite instalar pacote Sankhya Place?**'
