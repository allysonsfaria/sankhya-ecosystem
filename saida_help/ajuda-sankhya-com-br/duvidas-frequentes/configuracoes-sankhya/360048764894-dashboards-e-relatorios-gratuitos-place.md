# Dashboards e relatórios gratuitos Place Sankhya

| O Sankhya Place é um espaço virtual criado especialmente para compartilhar e multiplicar conhecimento, unificando em uma única plataforma toda a rede de conteúdo da empresa.  Para facilitar a análise, agrupamos nesse documento, uma lista com vários relatórios e dashboards, disponibilizados sem custo, através de nossa plataforma colaborativa Sankhya Place: |

**Dúvidas Frequentes:**

**![Imagem 4: Como baixar uma solução no Place?](https://ajuda.sankhya.com.br/hc/article_attachments/18741674881815) Como baixar uma solução no Place?**

Através da busca no Place, identificar qual solução deseja instalar, verificar se a solução é gratuita ou paga, clicar no botão instalar e automaticamente é instalado e gerado um lançador no menu do sistema.

**![Imagem 5: Existe suporte técnico das soluções do Place?](https://ajuda.sankhya.com.br/hc/article_attachments/18741674892951)Existe suporte técnico das soluções do Place?**

As soluções publicadas foram validadas em uma base nativa do SankhyaOm garantindo o seu funcionamento integral. No caso de erros pontuais é necessário acionar a Unidade de Negócios para verificação. No caso de uma solução paga, o autor da solução é responsável pelo suporte.

**![Imagem 6: É possível adicionar ou alterar alguma informação de uma solução do Place?](https://ajuda.sankhya.com.br/hc/article_attachments/18741674911511) É possível adicionar ou alterar alguma informação de uma solução do Place?**

Para inserir ou alterar alguma informação das soluções instaladas é necessário acionar a Unidade de Negócios para esta personalização.

**![Imagem 7: No caso de soluções pagas como é efetuada a cobrança?](https://ajuda.sankhya.com.br/hc/article_attachments/18741722578967) No caso de soluções pagas como é efetuada a cobrança?**

Ao baixar uma solução paga automaticamente é gerado NF e Boleto com o valor do pacote que deverá ser paga apenas uma vez. Ao baixar o pacote novamente não é cobrado.

**![Imagem 8: É possível testar uma solução paga antes de adquirir?](https://ajuda.sankhya.com.br/hc/article_attachments/18741674919575) É possível testar uma solução paga antes de adquirir?**

Atualmente não temos degustação de soluções pagas e no momento deverá ser acionado a Unidade de Negócios para demonstração.

**![Imagem 9: Encontrei uma solução não homologada no Place, qual procedimento devo fazer?](https://ajuda.sankhya.com.br/hc/article_attachments/18741674927127) Encontrei uma solução não homologada no Place, qual procedimento devo fazer?**

No caso das soluções não homologadas é necessário clicar no botão “Solicitar homologação” e aguardar o prazo de liberação. As solicitações serão tratadas por data de solicitação e as mais solicitadas primeiro.

**![Imagem 10: Estou com problemas para acessar o Sankhya Place,o que devo fazer?](https://ajuda.sankhya.com.br/hc/article_attachments/18741722596759) Estou com problemas para acessar o Sankhya Place,o que devo fazer?**

O acesso ao Sankhya Place é efetuado através do SankhyaID. Para obter ajuda com o seu SankhyaID clique no artigo a seguir: [Sankhya ID](https://ajuda.sankhya.com.br/hc/pt-br/articles/360050259413-Sankhya-ID)
