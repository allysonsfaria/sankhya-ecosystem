# Parâmetro EMAILPEDCOP não possui funcionalidade no Sankhya OM

O parâmetro **EMAILPEDCOP**, que era utilizado no sistema MGE para configuração de cópia de envio de e-mail relacionado a Pedidos, **está visível/cadastrado** no **Sankhya OM**, **porém não executa nenhuma ação**.

Ao configurá-lo, **o sistema não realiza o disparo de e-mails conforme o comportamento esperado que existia no MGE**.

O parâmetro **EMAILPEDCOP é um legado do sistema MGE e suas funcionalidades não foram migradas para o Sankhya OM**. Ou seja, embora o parâmetro ainda exista na base de dados, **não há implementação no código do Sankhya OM que o utilize**, tornando-o inoperante.
