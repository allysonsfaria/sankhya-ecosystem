# Usuários desligados, inativados da empresa, como remover acessos ao Zendesk/Sankhya ID?

**(1)** O Administrador do Place/RH, poderá efetuar a desvinculação do usuário inativo ou desligado, acessando o Place.

![Imagem 1: Logue no Sankhya ID, selecione a opção 'PLACE'](https://ajuda.sankhya.com.br/hc/article_attachments/16302808312343) Logue no Sankhya ID, selecione a opção 'PLACE'

![Imagem 2: Logue no Sankhya ID, selecione a opção 'PLACE'](https://ajuda.sankhya.com.br/hc/article_attachments/360101390834)

![Imagem 3: Ao abrir o Sankhya Jiva Place, acesse: Menu » Informações Cadastrais » Dados Cadastrais Na Guia de Contatos, faça a…](https://ajuda.sankhya.com.br/hc/article_attachments/16302778214423) Ao abrir o Sankhya Jiva Place, acesse: Menu » Informações Cadastrais » Dados Cadastrais
Na Guia de Contatos, faça a pesquisa pelo usuário, ao encontrar o usuário clique no ícone 'lápis' para Editar.
Clique no botão 'Remover Acessos' do lado direito do perfil do usuário em edição.

![Imagem 4: Ao abrir o Sankhya Jiva Place, acesse: Menu » Informações Cadastrais » Dados Cadastrais Na Guia de Contatos, faça a…](https://ajuda.sankhya.com.br/hc/article_attachments/360101392814)

Esta ação remove o acesso do usuário ao Place, Chat e Zendesk, porém o perfil do mesmo ainda ficará ativo no Sankhya ID, mas não vinculado a nenhum Parceiro. Pois, o perfil no Sankhya ID é único e intransferível, tornando assim, fácil o vínculo deste usuário em outro Parceiro, futuramente, salvando também dados como as Certificações.

![Imagem 5: Perfil, desligado e removido acessos via place.](https://ajuda.sankhya.com.br/hc/article_attachments/1500002550641)
Perfil, desligado e removido acessos via place.

Quando a empresa faz o primeiro cadastro do usuário, o status do mesmo fica como Convidado para que ele possa terminar de efetuar o cadastro.
