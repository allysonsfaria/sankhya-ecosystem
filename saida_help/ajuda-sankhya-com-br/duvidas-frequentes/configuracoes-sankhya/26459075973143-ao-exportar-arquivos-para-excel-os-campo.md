# Ao exportar arquivos para  excel os campos de valores são apresentados na planilha  de forma incorreta. Veja como resolver

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26459097906711)SOLUÇÃO:**

Verifique configuração do parâmetro **"TEMMILHARNTDEC- Verifica se tem milhar e no tem decimal"**.
Com este parâmetro ligado, ao exportar o relatório no formato Excel, os dados não serão apresentados com casa decimal, mas terão o ponto separador de milhar.

**![Imagem 2: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26459097907863)CAUSA:**

Ao exportar relatórios para planilhas em  EXCELL, o sistema não utiliza as separação dos valores. Para sanar este tipo de problema, o parâmetro foi criado e deverá esta **ligado**.
