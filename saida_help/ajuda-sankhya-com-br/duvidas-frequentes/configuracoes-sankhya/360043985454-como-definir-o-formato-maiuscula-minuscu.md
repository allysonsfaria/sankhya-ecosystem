# Como definir o formato 'Maiúscula', 'Minúscula' ou 'Normal' na inserção de cadastros

**(1)** O parâmetro **"Padrão para descrição dos Cadastros - PADRAOENTRDADOS"**, configurado na tela **"Preferências",** poderá ser utilizado para auxiliar na padronização dos cadastros realizados no sistema. Se trata de um parâmetro que indicará a forma com que a informação pertinente ao campo de descrição dos cadastros será salvo no banco de dados, se em caixa alta, caixa baixa ou da forma que for efetuada a digitação.

**(1)** Este parâmetro pode ser definido dentre três opções:

![Imagem 1: (1) Este parâmetro pode ser definido dentre três opções:](https://ajuda.sankhya.com.br/hc/article_attachments/14659335735575)

- **Maiúscula:** por esta opção, o sistema gravará os dados informados no campo **"Descrição"** sempre em caixa alta (todas as letras maiúsculas), mesmo que a tecla Caps Lock do teclado não esteja acionada;
- **Minúscula:** através desta opção, o sistema grava os dados informados no campo Descrição sempre em caixa baixa (todas as letras minúsculas), mesmo que a tecla Caps Lock do teclado esteja acionada;
- **Normal:** se selecionada esta opção, o sistema gravará os dados informados da forma que forem digitados, ou seja, pode-se mesclar letras maiúsculas e minúsculas ao proceder com o cadastro.

**![Imagem 2: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16833540219799) OBSERVAÇÃO:**

Essa padronização ocorrerá somente para os campos de Descrição dos cadastros, ou seja, campos de **"Apresentação"**; os demais campos não serão afetados por este parâmetro. Caso o parâmetro seja uma vez definido e seja modificado posteriormente, os dados gravados antes da alteração do parâmetro não serão afetados.

![Imagem 3: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/16833533574551) **IMPORTANTE:**

A funcionalidade do parâmetro Padrão para descrição dos Cadastros - PADRAOENTRDADOS não funciona nas telas do módulo Pessoal +.
