# Não esta apresentando o CMV na analise de Rentabilidade das Notas de Vendas

![Imagem 1: Acesse o Gerente ON Line ( Comercial » Gerente » Gerente On-Line - GOL ) Botão: Configurações Selecione 'Margem de…](https://ajuda.sankhya.com.br/hc/article_attachments/18589112428951) Acesse o Gerente ON Line (Comercial » Gerente » Gerente On-Line - GOL)
Botão: Configurações
Selecione 'Margem de Contribuição' no menu esquerdo.

Verifique o campo: Custo a ser considerado [Verifique qual é o custo que foi configurado para respresentar o CMV]
![Imagem 2: Verifique o campo: Custo a ser considerado (Verifique qual é o custo que foi configurado para respresentar o CMV)](https://ajuda.sankhya.com.br/hc/article_attachments/18589112433047)

![Imagem 3: Acesse a Variação de Custo de Produtos ( Comercial » Consulta » Variação de Custos de Produtos ) Verifique para os…](https://ajuda.sankhya.com.br/hc/article_attachments/18589112442775) Acesse a Variação de Custo de Produtos (Comercial » Consulta » Variação de Custos de Produtos)
Verifique para os produtos envolvido na Nota de Venda, se existe valor de custo, de acordo com o tipo de custo que sera considerado.
Exemplo: Se no Custo a ser Considerado do GOL, estiver selecionado 'Gerencial', o(s) produto(s), deve conter custo 'Custo Gerencial'.

\*CMV = Custo da Mercadoria Vendida
