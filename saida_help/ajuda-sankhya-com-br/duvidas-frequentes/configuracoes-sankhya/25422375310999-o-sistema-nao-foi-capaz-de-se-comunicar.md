![Imagem 5: Selecione o botão "Configurações do Sankhya" ; Ao abrir a tela de Configurações, clique no botão "Iniciar Web…](https://ajuda.sankhya.com.br/hc/article_attachments/25452413099287) Ao abrir a tela de Configurações, clique no botão **"Iniciar Web Connection junto com o Navegador"**. Essa função irá funcionar quando parâmetro USAAPPIMPRESSAO estiver desligado, pois

se o mesmo estiver ligado o sistema vai usar o web Connection externo. Para saber mais sobre o Web

Connection externo olhar o manual [Sankhya Web Connection – Sankhya Gestão de Negócios](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596394-Sankhya-Web-Connection)
