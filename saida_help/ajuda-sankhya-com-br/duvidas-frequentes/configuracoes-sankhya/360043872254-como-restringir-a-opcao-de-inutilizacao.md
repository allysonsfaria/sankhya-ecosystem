# Como restringir a opção de Inutilização de Numeração de Nota Fiscal Eletrônica para os usuários?

**(1)** Para conceder ou não a utilização de 'Inutilização de Numeração de Nota' no Portal, acesse o cadastro de usuários 'Configurações » Controle de Acesso » Usuários, aba: Segurança', opção: Inibe acesso à inutilização de nota.

Quando marcado, usuário não terá permissão, desmarcado o usuário terá acesso.
