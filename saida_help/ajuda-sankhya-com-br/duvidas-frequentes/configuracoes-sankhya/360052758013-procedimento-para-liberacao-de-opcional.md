# Procedimento para liberação de opcional linha DELPHI

**O procedimento para Liberação de opcional na linha DELPHI, para a linha JAVA, basta ter na licença.**

1. Acesse o sistema com o usuário SUP;
2. No controle de acesso do usuário, coloque o cursor, no código do usuário SUP;
3. Desative a tecla NUM LOCK;
4. Em seguida pressione as seguintes teclas, Todas Juntas: CTRL + ALT + SHIFT + NUM LOCK;
5. Após pressionar essa combinação de teclar, já digite a Primeira senha **(senha gerada pelo Service Desk);**
6. Após digitar a primeira senha, irá apresentar uma telinha para informar a segunda senha... aí você informa a segunda senha **(código do opcional);**
7. Saia do sistema e entre novamente;

| **Senha 1:** Gerado pelo Service Desk, Para que consiga pegar as senhas necessário abertura de chamado no SERVICE DESK;  **Senha 2:** código do opcional, solicitar também será necessário abertura de chamado no SERVICE DESK. |
