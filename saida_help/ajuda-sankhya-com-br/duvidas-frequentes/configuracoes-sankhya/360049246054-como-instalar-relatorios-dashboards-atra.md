# Como instalar relatórios/dashboards através do Place Sankhya 

| O Sankhya Place é um espaço virtual criado especialmente para compartilhar e multiplicar conhecimento, unificando em uma única plataforma toda a rede de conteúdo da empresa.  Nesse documento constam as principais orientações para realizar a instalação de relatórios/dashboards através de nossa plataforma colaborativa Sankhya Place: |
| --- |

![Imagem 1: O usuário logado no sistema, responsável pela instalação dos pacotes, deverá ter os seguintes acessos:](https://ajuda.sankhya.com.br/hc/article_attachments/18741942094871) O usuário logado no sistema, responsável pela instalação dos pacotes, deverá ter os seguintes acessos:

- Na tela 'Usuários', aba Segurança, a opção '**Permite instalar pacote Sankhya Place?**' deve estar marcada.
- Na tela **'Acessos'** (Configurações » Controle de Acesso » Acessos) o usuário deverá receber os acessos da tela 'Sankhya Place'.

![Imagem 2: Tal usuário deverá logar no Sankhya OM, selecionar a tela 'Sankhya Place';](https://ajuda.sankhya.com.br/hc/article_attachments/18741942103319) Tal usuário deverá logar no Sankhya OM, selecionar a tela 'Sankhya Place';

![Imagem 3: No Sankhya Place, realizar a busca pelo relatório/dashboard desejado ( Loja de Soluções>>Pacotes ) . Verifique as…](https://ajuda.sankhya.com.br/hc/article_attachments/18741948359959) No Sankhya Place, realizar a busca pelo relatório/dashboard desejado [Loja de Soluções>>Pacotes]. Verifique as informações principais, em seguida clique em Instalar.

**Importante:**

![Imagem 4: O relatório/dash instalado ficará salvo no caminho: Sankhya Place >> Instalações.](https://ajuda.sankhya.com.br/hc/article_attachments/18741942094871) O relatório/dash instalado ficará salvo no caminho: **Sankhya** **Place >> Instalações.**
