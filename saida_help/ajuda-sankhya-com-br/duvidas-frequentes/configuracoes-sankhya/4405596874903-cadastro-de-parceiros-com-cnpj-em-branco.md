# Cadastro de  parceiros com CNPJ em branco

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16369951237271) MENSAGEM**:

Caso seja necessário realizar o cadastro de um parceiro com o CNPJ em branco existe um parâmetro que possibilita isso.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16369951240855) SOLUÇÃO:**

Para realizar o cadastro de parceiros com o CNPJ em branco, siga os passos abaixo:

![Imagem 3: Acesse a tela " Preferências" e localize o parâmetro " ACEITACGCBRANCO".](https://ajuda.sankhya.com.br/hc/article_attachments/16369896894231) Acesse a tela **"Preferências"** e localize o parâmetro **"ACEITACGCBRANCO".**

![Imagem 4: Ative o parâmetro para permitir ao usuário cadastrar parceiros com CNPJ/ CPF em branco.](https://ajuda.sankhya.com.br/hc/article_attachments/16369951248023) Ative o parâmetro para permitir ao usuário cadastrar parceiros com CNPJ/ CPF em branco.

![Imagem 5: Ative o parâmetro para permitir ao usuário cadastrar parceiros com CNPJ/ CPF em branco.](https://ajuda.sankhya.com.br/hc/article_attachments/15695127945623)

**![Imagem 6: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16369951251607) CAUSA:**

Por configuração nativa o parâmetro vem com a opção desligada, para que todos os cadastros sejam obrigatórios.
