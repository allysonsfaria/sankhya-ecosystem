# Configurar o sistema para responder o e-mail ao usuário logado

#### Como configurar o sistema para responder o e-mail ao usuário logado?

A possibilidade atual é que através do parâmetro **"RESPUSALOG"** o sistema tenha o seguinte comportamento:

**(1)**Com o parâmetro Responder e-mail p/ usuário logado - RESPUSALOG ligado o sistema insere "Responder a" utilizando o e-mail configurado no cadastro do usuário logado. Quando o mesmo estiver desligado (default) o sistema não informa pra quem responder e ao responder o e-mail o mesmo será respondido ao remetente.

**Observação:** O parâmetro **RESPUSALOG funciona** **somente** nas rotinas do **módulo Comercial.**

#### É possível que o sistema envie o e-mail através do remetente do usuário logado?

Não é possível que o sistema envie o e-mail através do remetente do usuário logado, o sistema usa o remetente da aba **"Servidor de smtp"** ou  **"Contas smtp"**.
