# O arquivo TSIREG.csv não é suportado para importação, favor verificar nomenclatura correta na aba Baixar Templates

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/27133824737815) **MENSAGEM:**

O arquivo TSIREG.csv não é suportado para importação, favor verificar nomenclatura correta na aba Baixar Templates.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/27133824739607)SOLUÇÃO:**

Ao importar o arquivo no formato zip, descompactar o arquivo e tentar importar, o erro acima será apresentado.

Nesse caso, crie o conteúdo, edite o TSIREG.csv  dentro do zip  e cole os dados.

![Imagem 3: Nesse caso, crie o conteúdo, edite o TSIREG.csv dentro do zip e cole os dados.](https://ajuda.sankhya.com.br/hc/article_attachments/27133824739863)

![Imagem 4: Nesse caso, crie o conteúdo, edite o TSIREG.csv dentro do zip e cole os dados.](https://ajuda.sankhya.com.br/hc/article_attachments/27133824740375)

**![Imagem 5: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/27133884353175)CAUSA:**

No caso dos templates de entidade, os arquivos **csv** preenchidos podem ser mantidos dentro do zip que também é gerado pelo sistema para que, dessa forma, seja possível fazer um único upload de arquivo.
