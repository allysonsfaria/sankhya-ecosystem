# Como Inutilizar numeração de uma NFCE no Fast Service

Inutilizar uma nota fiscal pressupõe que a numeração não foi usada. Como os documentos devem ser emitidos em numeração sequencial e cronológica, caso hajam saltos nesses números o contribuinte não poderá fazer uso do algarismo pulado. Dessa forma, a inutilização de numeração consiste em informar para a SEFAZ que a numeração, ou o conjunto delas, não terá servidão para uso do estabelecimento.

**Em quais circunstâncias inutilizar a numeração de uma nota?**

Esse procedimento deve ser realizado quando existe algum contratempo que impede que o documento fiscal eletrônico seja enviado ou recebido pela SEFAZ. Lembrando que para tal é importante se certificar de que esse documento de fato não consta na base de dados da SEFAZ Nacional/Estadual.

**Vejamos o procedimento via Fast Service.**

- Como realizar a inutilização no Fast Service

Para inutilizar a numeração de uma NFC-e você precisa ter os dados abaixo referente a mesma, dessa forma é indicado que a inutilização seja realizada antes da exclusão da nota de seu sistema.

![Imagem 2: Clicar no botão Inutilizar Nro .](https://ajuda.sankhya.com.br/hc/article_attachments/18942587924119) Clicar no botão **Inutilizar Nro**.

![Imagem 3: Clicar no botão Inutilizar Nro .](https://ajuda.sankhya.com.br/hc/article_attachments/360085283374)

Abrirá a caixa para preencher os dados da Empresa, data, modelo, numero de nota

![Imagem 4: Abrirá a caixa para preencher os dados da Empresa, data, modelo, numero de nota](https://ajuda.sankhya.com.br/hc/article_attachments/360086476673)

Preencher o dados e clicar em OK

**Importante:**

A informação a ser preenchida no campo '**Modelo de Doc.Fiscal**'  pode ser confirmada no cadastro da TOP utilizada no lançamento >> aba Livro Fiscal >> Campo "Modelo do Documento".
