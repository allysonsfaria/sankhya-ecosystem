# Saiba como fazer a gestão de presença

(1)** Para o que serve a gestão de presença?**

Para fazer uma gestão da equipe, onde poderá ser visualizado quem está trabalhando no dia, no intervalo, se já chegou ao trabalho ou até mesmo se está de férias, o líder de uma equipe tem uma tela de Gestão de Presença. 

![Imagem 1: Acesse a tela “Gestão de Presença” (Caminho de acesso: Ponto Web » Rotinas Ponto » Gestão de presença ). Ao acessar,…](https://ajuda.sankhya.com.br/hc/article_attachments/16305679242519) Acesse a tela **“Gestão de Presença”** (Caminho de acesso: Ponto Web »  Rotinas Ponto » Gestão de presença). Ao acessar, temos filtros para localização dos funcionários desejados, como informar a **“Empresa”**, **“Departamento”**, **“Situação do Funcionário”** e **“Dispensado do Ponto”.** Esses filtros não são obrigatórios, são apenas recursos de apoio à seleção.

Aqui também podemos fazer os filtros para visualizar: 

- Todas;
- Horas extras realizadas sem requisição;
- Horas extras realizadas com requisição pendente;
- Horas extras além do aprovado;
- Horas extras realizadas sem aprovação;
- Batida de ponto feita offline;
- Batida fora do raio de localização permitida;
- Batida de ponto sem localização ativada.
