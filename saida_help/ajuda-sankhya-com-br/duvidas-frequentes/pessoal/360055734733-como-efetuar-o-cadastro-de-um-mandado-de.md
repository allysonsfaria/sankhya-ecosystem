# Como efetuar o cadastro de um Mandado de Segurança, Medida Cautelar, Tutela, Acordão e outros?

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18856944917783) SOLUÇÃO:**

Nessa tela o usuário deverá inserir os **Processos Judiciais** ou **Administrativos** nos quais a Empresa faz parte. O sistema não dispõe de guias específicas para tal recolhimento, devendo assim verificar o acordo entre as partes para pagamento, usualmente feito via deposito judicial.

**Para clientes do MGE Pessoal**
Acesse: MGEPEssoal>>Arquivos>>Cadastros>>Processos.
