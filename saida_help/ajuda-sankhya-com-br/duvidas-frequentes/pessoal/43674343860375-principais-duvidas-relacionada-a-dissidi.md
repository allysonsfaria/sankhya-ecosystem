# Principais dúvidas relacionada a dissidio

### 1. O que é dissídio salarial?

É o reajuste salarial decorrente de negociações coletivas entre sindicatos ou de decisão da Justiça do Trabalho. Na prática, as condições de reajuste podem ser definidas por convenção coletiva de trabalho (CCT), acordo coletivo de trabalho (ACT) ou sentença normativa.

### 2. Como saber qual percentual de reajuste aplicar?

O percentual deve ser consultado no acordo ou na convenção coletiva aplicável à categoria, considerando a data-base, as regras de enquadramento e as condições estabelecidas no documento.

### 3. O que é data-base?

É a data definida para a revisão das condições salariais de uma categoria profissional, normalmente estabelecida nas negociações coletivas. Ela serve como referência para a aplicação dos reajustes previstos no instrumento coletivo.

### 4. É possível realizar a antecipação do reajuste salarial da CCT?

Sim. A antecipação permite aplicar o reajuste salarial antes do prazo previsto para a negociação coletiva, conforme as condições estabelecidas para a categoria.

Para realizar o procedimento no sistema, siga as orientações do artigo:

[Veja como realizar a antecipação de reajuste salarial CCT](https://ajuda.sankhya.com.br/hc/pt-br/articles/30948418365975-Veja-como-realizar-a-antecipa%C3%A7%C3%A3o-de-reajuste-salarial-CCT).

### 5. Como realizar o reajuste salarial?

Para realizar o reajuste salarial conforme a Convenção Coletiva de Trabalho (CCT), siga o passo a passo disponível no artigo:

[Como fazer o reajuste salarial](https://ajuda.sankhya.com.br/hc/pt-br/articles/4424998383767-Como-fazer-o-reajuste-salarial).

### 6. Por que o funcionário desligado não é apresentado na tela de reajuste salarial?

Para que funcionários desligados sejam apresentados na tela de reajuste salarial, é necessário verificar os seguintes pontos:

- **Data de assinatura da CCT:** deve ser posterior à data de desligamento do funcionário. Caso contrário, o colaborador poderá não ser apresentado na lista para reajuste.
- **Tela Reajuste Salarial:** devem estar marcadas as opções:
  - **Aplicar reajuste p/ demitidos entre data base e assinatura**;
  - **Considera projeção do aviso prévio indenizado dentro do mês data base**.

Verifique essas informações antes de realizar o reajuste.

### 7. Por que os funcionários admitidos na data-base ou após ela não estão recebendo o reajuste salarial da CCT?

Em geral, o sistema considera que os funcionários admitidos na data-base ou após ela já deveriam ter sido contratados com o salário atualizado conforme as condições da categoria.

Entretanto, se o salário do colaborador estiver abaixo do piso salarial da categoria, o sistema poderá realizar a adequação para o valor informado no campo **Qual salário mínimo da classe?**

Para isso, na tela de reajuste salarial, verifique o preenchimento desse campo e marque a opção:

**Readequar o salário dos colaboradores admitidos após data base ao piso do sindicato?**

Essa opção permite adequar o salário dos colaboradores admitidos após a data-base ao piso informado para a categoria, conforme as regras aplicáveis.
