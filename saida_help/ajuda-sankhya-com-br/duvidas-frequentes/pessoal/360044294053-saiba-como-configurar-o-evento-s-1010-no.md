# Saiba como configurar o evento S-1010 no sistema

O evento **S-1010** é “o detalhamento das informações das rubricas constantes da folha de pagamento do empregador/órgão público, permitindo a correlação destas com as constantes da tabela 3 – “Natureza das Rubricas da Folha de Pagamento” do eSocial.”

O [**Manual de Orientação do Esocial**](https://www.gov.br/esocial/pt-br/documentacao-tecnica/manuais/mos-s-1-3-consolidada-ate-a-no-s-1-3-03-2025.pdf) deve ser consultado pelo responsável de cada empresa para a correta realização dos cadastros no sistema.
No CAPÍTULO III – ORIENTAÇÃO ESPECÍFICA POR EVENTO, o responsável terá acesso a todas as informações do evento S-1010 para preparar o sistema para o eSocial.

(1)** Para configurar no sistema siga as instruções abaixo:**

**MGEPessoal**: Acesse a tela **"Eventos"** (Caminho de acesso: Arquivos » Eventos) e preencha os campos nas abas **Propriedades** e **Incidência**.

![Imagem 2: MGEPessoal : Acesse a tela "Eventos" (Caminho de acesso: Arquivos » Eventos ) e preencha os campos nas abas…](https://ajuda.sankhya.com.br/hc/article_attachments/14439076458391)

**Pessoal +**: Acesse a tela **"Eventos"** (Caminho de acesso: Pessoal+ » Cadastros » Eventos) e preencha os campos nas abas **Básico** e **ESocial**.

(2)** Aba: Propriedades/Básico:**

- Compõem eSocial: Deve estar marcado para que o usuário possa definir o tipo de rubrica. **Ou crie um Filtro dos eventos que irão compor o eSocial e depois clique no botão: 'Compõe E-Social', esse procedimento marcará todos os eventos de uma vez.**
- Identificação do Evento: [Efetuar a correta configuração deste campo, conforme o Evento]

(2)**Aba: Incidência/eSocial:**

- Natureza da Rubrica: [Campo Obrigatório, preenchê-lo corretamente]
