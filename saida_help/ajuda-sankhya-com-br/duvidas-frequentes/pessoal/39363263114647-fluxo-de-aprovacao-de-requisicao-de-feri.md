# Fluxo de Aprovação de Requisição de Férias

**Mensagem**

Saldo insuficiente para solicitação de férias

**Situação**

Ao tentar aprovar uma **"Requisição de Férias"** (Pessoal+ >> Rotinas Folha >> Requisições) criada pelo departamento pessoal, o sistema apresenta a mensagem de **"Saldo insuficiente"**, impedindo a aprovação. Esse problema ocorre quando o usuário do departamento pessoal gera a requisição para o funcionário, mas não consegue aprová-la posteriormente, bloqueando também novas solicitações de férias pelo colaborador.

**Solução**

Para resolver o problema de aprovação de requisição de férias, execute os passos abaixo:

**(1)** Acesse a tela **"Requisição"** (Pessoal+ >> Rotinas Folha >> Requisições) e localize a requisição do funcionário que apresenta o erro.
**(2)** Verifique o **"Período Aquisitivo"** vinculado à requisição. 
**(3)** A requisição de férias precisa ser feita pelo botão **"Alterar Solicitação"** para realizar a solicitação corretamente.

**Causa**

O problema ocorre devido a inconsistências no **"Período Aquisitivo"** do funcionário, geralmente causadas por requisições anteriores criadas incorretamente ou períodos duplicados no sistema. Além disso, o uso incorreto do fluxo de aprovação, quando o usuário não utiliza o botão **"Alterar Solicitação"**, também pode gerar o erro de saldo insuficiente.
