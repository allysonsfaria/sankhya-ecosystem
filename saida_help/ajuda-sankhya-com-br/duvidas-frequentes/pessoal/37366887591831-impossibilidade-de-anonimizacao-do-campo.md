# Impossibilidade de Anonimização do Campo Salário Base no Sistema Sankhya

Atualmente, o sistema Sankhya **não permite anonimizar ou restringir** o acesso ao campo **Salário Base** de forma individual para um usuário específico.

O controle de acesso disponível no sistema aplica-se de maneira geral, de acordo com as permissões definidas para o módulo, sem possibilidade de configurações granulares por usuário.

####

#### Localização do Campo

##### **(1)** Acesse a tela [''Configuração Funcionários''](https://ajuda.sankhya.com.br/hc/pt-br/articles/21069685487639-Configura%C3%A7%C3%A3o-Funcion%C3%A1rios) (Pessoal+ » Cadastros » Configuração Funcionários).

**(1)** Campo **''Salário Base''**.

####

#### Comportamento do Sistema

- O campo ''Salário Base'' não possui parametrização nativa para anonimização.
- Não é possível ocultar ou mascarar o valor apenas para um usuário específico.
- As permissões de acesso seguem o perfil definido para o módulo **Pessoal+**, sendo aplicadas de forma padronizada para todos os usuários.
