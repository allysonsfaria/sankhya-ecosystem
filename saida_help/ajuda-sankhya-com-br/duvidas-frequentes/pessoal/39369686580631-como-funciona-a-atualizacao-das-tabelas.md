# Como funciona a atualização das tabelas de IRRF 2026 no Sankhya?

A partir da **"Versão 5.72.4 ou superior"** do módulo Pessoal, o sistema Sankhya já aplica automaticamente o novo cálculo de imposto de renda conforme a **"Lei nº 15.270/2025"**, que estabelece novas regras de isenção e redução do imposto para rendimentos tributáveis.

Para folhas com pagamento em janeiro de 2026, o sistema já realiza os cálculos corretamente, aplicando a nova faixa de isenção prevista na legislação. Atualize o executável do módulo Pessoal para a versão indicada.

### Atualização automática das tabelas de faixas

As tabelas de faixas de IRRF, salário mínimo e INSS serão internalizadas automaticamente pelo sistema. O time de produto aguarda a oficialização por parte do governo para disponibilizar as atualizações através de novas versões do módulo Pessoal.
 
Quando as tabelas forem disponibilizadas, todos os clientes serão notificados. Acompanhe as novidades através da **"Comunidade Sankhya"** <https://community.sankhya.com.br/sugestoes>

### Cálculo da nova isenção de IRRF

De acordo com a **"Lei nº 15.270/2025"**  o valor de isenção é calculado sobre os rendimentos tributáveis. A lei prevê a redução total ou parcial do imposto devido para rendimentos tributáveis de até **"R$ 7.350,00"**.
Para rendimentos de até **"R$ 5.000,00"**, o imposto é integralmente reduzido a zero. A fórmula aplicada pelo sistema é:

**"Redução = 978,61 - (0,133145 × Rendimento Tributável)"**

O sistema Sankhya aplica automaticamente essa fórmula no cálculo da folha de pagamento e adiantamento salarial, desde que esteja na versão adequada.

### Versão necessária para utilização

Para atender às novas regras de IRRF 2026, atualize o executável do módulo Pessoal para a **"Versão 5.72.4 ou superior"**. Nessa versão, o sistema já realiza os cálculos corretamente para folhas com competência de pagamento a partir de janeiro de 2026.
