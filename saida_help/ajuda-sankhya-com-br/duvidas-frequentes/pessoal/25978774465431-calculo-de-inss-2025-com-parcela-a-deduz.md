# Cálculo de INSS 2025 com parcela a deduzir

Até o começo desse ano ao calcular o valor de INSS descontado em folha de pagamento era necessário fazer o cálculo mediante as faixas salariais, aplicando nas tabelas conforme exemplo abaixo:

| **Tabela de salário de contribuição à partir de 01/2024** | |
| --- | --- |
| Até R$1.518,00 | 7,50% |
| De R$1.518,00 até R$2.793,88 | 9% |
| De R$2.793,88 até R$4.190,83 | 12% |
| De R$4.190,83 até R$8.157,41 | 14% |

Utilizando como exemplo o salário de R$ 3.000,00, em 2024, veja como calcular o INSS e como fica o desconto INSS:

**(1)** **1ª faixa salarial:** R$1.518,00 x 0,075 = 105,9
**(1)** **2ª faixa salarial:** [2.793,88 – 1.518,00] x 0,09 = 1.275,88 x 0,09 = 114,82
**(1)** **Faixa que atinge o salário:** [3.000,00 – 2.666.68] x 0,12 = 333,32 x 0,12 = 39,99
**(1)** **Total a recolher:** 105,9 + 112,92 + 39,99 = R$ 258,81

Agora com a **nova tabela com parcela a deduzir** esse cálculo ficou muito mais fácil de entender. Assim, utilizando o mesmo exemplo de salário de R$ 3.000,00, com a nova tabela o cálculo ficará da seguinte forma:

| **Tabela de salário de contribuição à partir de 01/2024** | | |
| --- | --- | --- |
| **Salário (R$)** | **Alíquota** | **Parcela a deduzir (R$)** |
| Até R$1.518,00 | 7,5% | - |
| De R$1.518,00 até R$2.793,88 | 9% | R$22,77 |
| De R$2.793,88 até R$4.190,83 | 12% | R$106,59 |
| De R$4.190,83 até R$8.157,41 | 14% | R$190,40 |

**(1)** 3000 \* 0,12 = 360 - 101,18 (parcela a deduzir) = 258,81

Nota -se que nas 2 situações chegamos ao mesmo valor de desconto, apenas utilizando de um método mais prático para o cálculo do INSS mensal.
