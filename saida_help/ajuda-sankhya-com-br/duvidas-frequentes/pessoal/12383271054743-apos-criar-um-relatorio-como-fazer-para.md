# Após criar um relatório, como fazer para o mesmo ser apresentado na Tela do Cadastro do Funcionário

O parâmetro **"FPRELATFUNC"** tem a funcionalidade de vincular os códigos de relatórios formatados para os mesmos ficarem disponíveis na tela de Funcionários, conforme imagem abaixo:

![Após](https://ajuda.sankhya.com.br/hc/article_attachments/15791537187095)

Para habilitar o relatório, faça o seguinte procedimento:
Acesse a tela **"Preferências"** (caso não tenha acesso com o usuário em questão, acesse com o usuário SUP) e pesquise o parâmetro **"FPRELATFUNC"**.

![Imagem 2: Para habilitar o relatório, faça o seguinte procedimento: Acesse a tela "Preferências" (caso não tenha acesso com o…](https://ajuda.sankhya.com.br/hc/article_attachments/12409379453207)

Após localizar o parâmetro em questão, inclua o número do relatório no campo **"TEXTO"** e salve.

#### Como pegar o número do relatório formatado?

Vá até a tela **"Relatórios formatados"** e pegue o número na parte superior da tela.

![Após](https://ajuda.sankhya.com.br/hc/article_attachments/15791511872151)

Após realizar a vinculação do número, salve, saia da tela **"Funcionários",** atualize o painel de configurações e entre novamente para verificar se o mesmo está disponível.
