# Divergências no KARDEX causadas por notas de complemento de custos sendo apresentadas antes das notas de saída, como corrigir?

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/31044381576343) **MENSAGEM:**

A nota fiscal **Complementar** existe para corrigir ou adicionar informações a uma nota fiscal original que está incompleta ou com erros. Ela é uma solução prática para manter a precisão das informações fiscais.

(1)** Geralmente é utilizada nas seguintes situações:**

- Quando a nota fiscal original está incompleta ou com erros;
- Quando não é possível cancelar a nota original;
- Quando é necessário corrigir informações como preço, quantidade de produtos ou cálculo de impostos;
- Quando é necessário suplementar informações e valores de impostos.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/31044381576471)SOLUÇÃO:**

Quando em uma mesma data existem **notas de compra, notas de saída e notas de complemento,** a ordem de apresentação pode apresentar **linhas vermelhas** no relatório KARDEX.
Para que isso não ocorra, verifique a seguinte informação:

Na top utilizada para o lançamento da nota de complemento, o campo **"Tipo de complemento de custo"** deve estar configurado com uma opção diferente de **"Não se aplica"** conforme print abaixo:
