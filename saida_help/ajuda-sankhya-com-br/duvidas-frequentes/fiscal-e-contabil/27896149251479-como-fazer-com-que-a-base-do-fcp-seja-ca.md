# Como fazer com que a Base do FCP seja calculado pela Base do ICMS?

A configuração deve ser selecionada na regra de alíquota do ICMS.

![Imagem 3: Após identificar a alíquota, acesse a tela de "Alíquotas de ICMS" e localize o campo: "Base para cálculo do FCP interno"](https://ajuda.sankhya.com.br/hc/article_attachments/27915871321111) Após identificar a alíquota, acesse a tela de **"Alíquotas de ICMS"** e localize o campo: **"Base para cálculo do FCP interno"**

![Imagem 4: Após identificar a alíquota, acesse a tela de "Alíquotas de ICMS" e localize o campo: "Base para cálculo do FCP interno"](https://ajuda.sankhya.com.br/hc/article_attachments/27915816967319)

O campo Base para cálculo do FCP interno permite configurar a forma de cálculo do FCP em operações internas, de acordo com as seguintes opções:

- Ao selecionar esta opção, o sistema calculará a base do FCP interno considerando os valores dos produtos;

- **Base do ICMS:** ao optar por esta alternativa, o sistema utilizará a base do ICMS para o cálculo do FCP interno.

Essa dúvida pode surgir no momento da emissão de notas fiscais que contenham o imposto FCP, caso o cálculo não esteja sendo realizado conforme o esperado.
