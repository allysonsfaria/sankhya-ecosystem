# Atualizei a Versão do sistema o layout do EFD ICMS/IPI não mudou, o que fazer?

Mesmo depois de atualizar a versão do sistema para as últimas versões disponíveis, pode acontecer de o layout não ficar visível na tela. Segue orientações.

**Mensagem**

[ORA-02290] Restrição de verificação (SANKHYA.CKC\_VERSAOLAYOUT\_TGFEFDF) violada.

![Imagem 1: Digite na tela de geração a data. Como o layout é por ano, cada data que você digitar em anos diferentes será mostrado…](https://ajuda.sankhya.com.br/hc/article_attachments/16427116745239) Digite na tela de geração a data. Como o layout é por ano, cada data que você digitar em anos diferentes será mostrado o layout vigente para aquele ano.

Exemplo:

Para gerar com o layout 16, digite a data a partir de 01/01/2022

Para gerar com o layout 17, digite a data a partir de 01/01/2023

Para gerar com o layout 18, digite a data a partir de 01/01/2024

Para gerar com o layout 19, digite a data a partir de 01/01/2025

Para gerar com o layout 20, digite a data a partir de 01/01/2026

Lembrando que o Layout do EFD - Fiscal ICMS/IPI é anual, então o layout do sistema irá identificar de acordo com a data digitada, seja em anos anteriores, seja no ano atual.

A importância de limpar o cache se dá ao fato de que o Browser dos navegadores às vezes sequestram algumas informações que depois não sobrepõe para visualização

Após Isso, tente novamente. Se o problema persistir entre em contato com o suporte.
