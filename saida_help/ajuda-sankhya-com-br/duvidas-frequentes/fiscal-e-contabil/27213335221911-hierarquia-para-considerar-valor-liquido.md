# Hierarquia para Considerar valor líquido do item na NF-e - DANFE

No sistema **Sankhya** existem três cadastros que trabalham a questão de apresentar ou não os descontos concedidos na emissão do documento, situação essa que o sistema irá considerar o valor líquido dos itens no Danfe e XML, não imprimindo valor de descontos dos itens. Se essa marcação estiver desmarcada, o sistema imprimirá o valor dos descontos dos itens.
