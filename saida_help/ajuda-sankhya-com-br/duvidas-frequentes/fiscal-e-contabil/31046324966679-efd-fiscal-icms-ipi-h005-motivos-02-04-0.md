# EFD FISCAL (ICMS/IPI) - H005 Motivos: 02, 04, 05 e 06 | Produto Com Mudança de Tributação

Para garantir a correta geração dos registros H005, H010 e H020, é essencial observar a seguinte característica na tela [Produtos com Mudança de Tributação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597614-Produtos-com-Mudan%C3%A7a-de-Tributa%C3%A7%C3%A3o)

**(1)** Na **Cópia de estoque**(Inventário » Arquivo » Cópia de Estoque) realizada (para a finalidade de uso na referida tela) os campos Agrupar por **"Controle"** e **"Local"** devem estar marcados:

![Imagem 1: (1) Na Cópia de estoque (Inventário » Arquivo » Cópia de Estoque) realizada (para a finalidade de uso na referida tela)…](https://ajuda.sankhya.com.br/hc/article_attachments/31046324963863)

Caso contrário, os produtos não serão importados para a tela **"Produto Com Mudança de Tributação".** Uma vez que para os fins dos registros citados, não há necessidade de uma cópia/contagem de estoque tão detalhada, Também há uma validação para impedir que esses produtos sejam apresentados caso tenham controle de estoque por controle e/ou local.
