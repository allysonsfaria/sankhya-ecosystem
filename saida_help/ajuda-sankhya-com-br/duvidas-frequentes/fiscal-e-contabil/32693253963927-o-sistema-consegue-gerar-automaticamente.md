# O sistema consegue gerar automaticamente os códigos dos bens, a cada nota de entrada?

O sistema **padroniza e gera o código automático de bens quando os itens forem lançados em uma mesma nota.** Veja abaixo como fazer esse processo:

####

**(1)**  **Configure o produto como "Imobilizado"** na tela de **"Produtos"** (Configurações » Cadastros » Produtos » Produtos).

**(2)**  Realize o lançamento do item na tela de **"Portal de Compras"** (Comercial » Consulta » Portal de Compras), informando as quantidades desejadas.

**(3)**  Acesse **outras opções** e selecione **"Gerar Bens Automaticamente"**.

![Imagem 1: (1) Configure o produto como "Imobilizado" na tela de "Produtos" (Configurações » Cadastros » Produtos » Produtos). (2)…](https://ajuda.sankhya.com.br/hc/article_attachments/34107243264919)

**(4)**  Clique em **"Salvar"** para concluir o processo.

![Imagem 2: (4) Clique em "Salvar" para concluir o processo.](https://ajuda.sankhya.com.br/hc/article_attachments/33173476908055)

**(5)**  Repita o procedimento para cada novo lançamento. **O sistema buscará o último número gerado e dará sequência à numeração apenas quando os itens forem lançados em uma mesma nota**.

**Observação:** ao lançar uma nova nota de entrada, o sistema reprocessa o sufixo e altera as decimais finais, reiniciando a sequência. Portanto, **a continuação automática dos números ocorre somente dentro de uma mesma nota.**

**EM RESUMO**

O sistema foi projetado para gerar a numeração sequencial do código do Bem apenas dentro de um mesmo lançamento de nota. Ao iniciar um novo lançamento, a sequência é reiniciada, exigindo nova configuração manual caso se deseje manter a padronização.
