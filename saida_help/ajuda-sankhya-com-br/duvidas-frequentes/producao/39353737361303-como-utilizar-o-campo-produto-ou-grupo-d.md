# Como utilizar o campo Produto ou Grupo de Produtos, na tela de Padrões de Classificação?

Na tela de **"Padrões de Classificação" (Configurações » Cadastros » Padrões de Classificação)**, é possível fazer o vínculo com o código do produto ou o código do grupo de produtos para aquele padrão configurado.

Por padrão do sistema, já vem configurado para utilizar Grupo de Produtos. Porém, para alterar para Produto, é necessário ligar o parâmetro **USAPRODPADCLASS**, desta forma o campo Produto é apresentado, ao invés do campo Grupo de Produtos.

**Sempre indicamos que, para realizar alterações de configurações já existentes, faça-as em base de testes para verificar o comportamento do sistema antes de reproduzir em base de produção.**

#### **(1)** Utilizando Grupo de Produtos:

Acessando a tela, é possível visualizar os campos **"Grupo de Produtos" e "Descrição (Grupo Produto)"**, desta forma é possível realizar a configuração, vinculando este cadastro.

#### **(2)** Utilizando Produto:

Primeiro, acesse a tela **"Preferências" (Configurações » Avançado » Preferências)** e ligue o parâmetro **USAPRODPADCLASS**

![Imagem 3: Primeiro, acesse a tela "Preferências" (Configurações » Avançado » Preferências) e ligue o parâmetro USAPRODPADCLASS](https://ajuda.sankhya.com.br/hc/article_attachments/41831138694167)

**(3)** Retorne à tela **"Padrões de Classificação" (Configurações » Cadastros » Padrões de Classificação)**, o campo **"Produto"** liberado para realizar a configuração.

**Modo Grade:**

#### Observação:

Não é possível utilizar as duas configurações em conjunto, somente Produto ou Grupo de Produtos.
