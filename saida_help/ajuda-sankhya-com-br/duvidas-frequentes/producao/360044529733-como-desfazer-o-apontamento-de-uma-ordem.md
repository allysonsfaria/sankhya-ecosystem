# Como desfazer o apontamento de uma 'Ordem de Produção' já finalizada?

**(1)** Considerando uma 'Ordem de Produção' com status finalizada, não é possível desfazer o apontamento dessa OP. Para essa situação, o recomendado é utilizar o processo de desmonte, para dar baixa no Produto Acabado e entrada nas Matérias Primas. Para mais detalhes verifique o artigo "[Processo de Desmonte](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045111693) ".
