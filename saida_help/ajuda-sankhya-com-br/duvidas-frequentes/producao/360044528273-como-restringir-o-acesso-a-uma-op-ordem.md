# Como restringir o acesso a uma OP (Ordem de Produção) na rotina de Operações de Produção?

**(1)** É possível através das configurações de Candidatos Executantes, na rotina: Produção » Cadastros » Processo Produtivo, botão **"Roteiro"**, selecione as etapas e acesse a aba **Candidatos Executantes.**
