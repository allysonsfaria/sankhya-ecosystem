# Como fazer o Importador de Fórmulas de Composição sempre manter o mesmo processo produtivo para as fórmulas importadas?

Para o sistema levar o mesmo Processo Produtivo para as fórmulas importadas, estas fórmulas devem ter o mesmo cadastro de Etapa de Produção, na tela **"Etapas de produção"** (Caminho: Comercial » Arquivo » Cadastros » Etapas de Produção), onde pode-se verificar as etapas cadastradas.

![Imagem 1: Para o sistema levar o mesmo Processo Produtivo para as fórmulas importadas, estas fórmulas devem ter o mesmo cadastro…](https://ajuda.sankhya.com.br/hc/article_attachments/29393657393943)

Todos os produtos que tiverem a necessidade de ter o mesmo processo produtivo ao ser importado, necessita ter em seu cadastro o mesmo cód. da Etapa de Produção em sua fórmula de composição do produto, na tela **"Fórmula de composição do produto"** (Caminho: Comercial » Arquivo » Cadastros » Fórmula de Composição do Produto).

Veja abaixo onde encontrar e realizar esse cadastro:

![Imagem 2: Veja abaixo onde encontrar e realizar esse cadastro:](https://ajuda.sankhya.com.br/hc/article_attachments/29393650549399)

No momento de realizar a importação das fórmulas na tela **"Importador Fórmula de Composição"** (Caminho: Produção » Rotinas » Importador Fórmula de Composição), pode-se verificar que as fórmulas que estão com a mesma etapa de produção em seus cadastros estão também com o mesmo código de processo produtivo ao serem importadas.
