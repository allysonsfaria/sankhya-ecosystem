# Empresa cadastrada, porém não apresentada para iniciar os cadastros de "Pessoal" [Funcionários, etc]

**![Imagem 1: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/18610751559831) CAUSA:**

Problema ocorre quando a empresa foi cadastrada, porém não foi marcada como 'Ativa'.

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/18610773768343) SOLUÇÃO:**

No cadastro da empresa tem um campo "Ativa" que precisa estar marcado para que consiga selecionar a empresa para os funcionários.

Acesse Arquivos / Empresas / selecione a empresa criada/ marque o campo **'Ativa'**, saia do sistema e entre novamente.
