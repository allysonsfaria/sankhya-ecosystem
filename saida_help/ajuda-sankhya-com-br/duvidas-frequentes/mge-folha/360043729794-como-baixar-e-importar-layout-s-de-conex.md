# Como baixar e importar Layout's de Conexão (RAIS, SEFIP, DIRF-Pessoa Física, CAGED, GRRF) para o MGEPessoal?

Para baixar os layout's siga as orientações abaixo:

![Imagem 1: Acesse o Sankhya ID https://login.sankhya.com.br/](https://ajuda.sankhya.com.br/hc/article_attachments/16201144028823) Acesse o Sankhya ID <https://login.sankhya.com.br/>

- Efetue o login com usuário e senha e, no menu superior direito, selecione 'PLACE'.

- Pesquise pelo layout. Exemplo: **SEFIP**

- Escolha a SEFIP do Ano Base que deseja. Exemplo: **Layout SEFIP/GRRF.**

O arquivo será salvo em um diretório da máquina local. Extraia os arquivos em um diretório/pasta e acesse o MGEConfigurações com o usuário SUP.

- Acesse Utilitários » Exportação/Importação de tabelas

No campo **"Diretório"**, pesquise e selecione a pasta onde foi extraído os arquivos conforme item 1.

No campo **"Opção"**, informe a opção **"Do Diretório para o BD".**

Selecione a aba **CNAB** e no canto esquerdo selecione a opção **"Remessa"**. Clique em **"Carregar Árvore de Formatadores de Bancos-CNAB-Remessa"**, marque **"Remessa"** e clique em **"Executar"**.

![Imagem 2: Acesse o MGEPessoal » Conexão » Arquivo para SEFIP » Processamento](https://ajuda.sankhya.com.br/hc/article_attachments/16201170460823) Acesse o MGEPessoal » Conexão » Arquivo para SEFIP » Processamento

No campo **"Arquivo de Layout"**, ao pesquisar e solicitar para carregar o Layout, será apresentado o layout importado.

**![Imagem 3: OBSERVAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16201170462999) OBSERVAÇÃO:**

O processo acima descrito é o mesmo utilizado para importar todos os layouts do MGE Pessoal da rotina **Conexão.**
