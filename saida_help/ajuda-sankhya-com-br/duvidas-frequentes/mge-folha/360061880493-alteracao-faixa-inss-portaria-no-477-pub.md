# Alteração Faixa INSS - PORTARIA Nº 477-Publicada 13/01/2021

A partir de Janeiro de 2021, de acordo com a PORTARIA SEPRT Nº 477, o salário mínimo passa a ser R$1.100,00 reais. Com isso, haverá alteração nas tabelas de faixa de INSS,  salário-família e salário mínimo, ficando da seguinte forma:   

(1)**Salário Mínimo: R$1.100,00**

**(1)** **Tabela da INSS:**

| Salário de contribuição (R$) | Alíquota progressiva para fins de recolhimento ao INSS |
| --- | --- |
| até 1.100,00 | 7,5% |
| de 1.100,01 até 2.203,48 | 9% |
| de 2.203,49 até 3.305,22 | 12% |
| de 3.305,23 até 6.433,57 | 14% |

**Apuração do teto:**

1ª faixa salarial: 1100 x 7,5% = 82,50.

2ª faixa salarial: (2203,49- 1.100,00) x 9% = 1.103,49 x 9% = 99,31

3ª faixa salarial: (3.305,23 - 2.203,49) x 12% = 1.101,74 x 12% = 132,20

4ª faixa salarial: (6433,57 - 3305,23) x 14% = 3.128,34 x 14% = 437,96  

Total: R$751,97

**Vejamos as configurações a ser feita no sistema:**

Acessar o MGEPessoal>>Arquivos>>Tabelas>>Tabelas de Faixa,  selecionar a tabela de INSS (código 1 por padrão), alterar os valores conforme coluna, Salário de Contribuição:
