# Replicar eventos para a próxima competência

**![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16422000163479) SITUAÇÃO:**

Considere o lançamento de eventos fixos na competência X para determinado funcionário e para a próxima competência existe a necessidade de manter os mesmos eventos.

 

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16422000165527) SOLUÇÃO:**

Acesse a tela **"Eventos Fixos por funcionários"** (Caminho de acesso: Arquivos » Eventos Fixos por funcionários), para os eventos desejados, será necessário que a opção "**Mantém Próxima Ref."** esteja marcada:
