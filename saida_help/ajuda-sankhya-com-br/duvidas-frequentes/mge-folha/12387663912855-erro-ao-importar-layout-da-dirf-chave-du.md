# Erro ao importar layout da DIRF - Chave duplicada na tabela :'Formatador de Master'

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16361820923543) MENSAGEM:**

Chave duplicada na tabela: 'Formatador de Master'.

**![Imagem 2: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16361820925079) SITUAÇÃO:**

Ao importar o layout da DIRF no módulo MGE Configurações, apresenta o erro abaixo:

Chave duplicada na tabela: **"Formatador de Master".**

![Imagem 3: Chave duplicada na tabela: "Formatador de Master".](https://ajuda.sankhya.com.br/hc/article_attachments/12387563903383)

**![Imagem 4: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16361820927383)SOLUÇÃO:**

Nesse caso, verifique no módulo MGE Pessoal na tela **"Conexão", "Arquivo para DIRF", "Configuração"**, se existe um arquivo com o mesmo código do que está tentando importar.

![Imagem 5: Nesse caso, verifique no módulo MGE Pessoal na tela "Conexão", "Arquivo para DIRF", "Configuração" , se existe um…](https://ajuda.sankhya.com.br/hc/article_attachments/12391153415319)

Selecione o layout com o código igual ao que está tentando importar:

![Erro](https://ajuda.sankhya.com.br/hc/article_attachments/15754894821271)

**![Imagem 7: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16361798506135)CAUSA:**

Caso já exista um arquivo com o mesmo código, deverá excluir o layout anterior para conseguir importar o novo, pois o sistema não aceita com a mesma descrição ocasionando o erro.

![Erro](https://ajuda.sankhya.com.br/hc/article_attachments/15754887433623)
