# Natureza do Estabelecimento Errada na DIRF - MGE

A Natureza do Declarante puxa do cadastro da empresa no sistema.
Para consultar qual é o código que está cadastrado vá até a tela **"Empresas"** (Caminho de acesso: Arquivos  »  Cadastros  »  Empresas (Dados Básicos)), aba **"Naturezas"**.

![Natureza](https://ajuda.sankhya.com.br/hc/article_attachments/15818062862615)

Verifique qual é o código que está preenchido, pois deve estar preenchido de acordo com algum código da tabela abaixo conforme a natureza de sua empresa.

![Imagem 3: Verifique qual é o código que está preenchido, pois deve estar preenchido de acordo com algum código da tabela abaixo…](https://ajuda.sankhya.com.br/hc/article_attachments/12659149202455)

Caso esteja com alguma informações diferente da acima, realize o ajuste. Após os ajustes gere novamente o arquivo e importe para verificação.
