# Ao gerar a SEFIP, foi gerado uma guia de pagamento para cada empresa, mesmo a Matriz sendo empresa Centralizadora. Como gerar apenas 1(uma) guia para empresa Matriz?

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17123990831639) SOLUÇÃO:**

Para gerar apenas 1 (uma) guia para empresa Matriz siga os passos abaixo:

![Imagem 2: Acesse: MGEPessoal>>Arquivos>>Cadastro>>Empresa(Dados Básicos)](https://ajuda.sankhya.com.br/hc/article_attachments/17123990837911) Acesse: MGEPessoal>>Arquivos>>Cadastro>>Empresa(Dados Básicos)

Aba: **"Cadastro"**
Campo **"Empresa Matriz":** identifique nas empresa Filial, o código da empresa Matriz-Centralizadora

![Imagem 3: Acesse: MGEPessoal>>Arquivos>>Empresa Aba: "Informações Gerais"](https://ajuda.sankhya.com.br/hc/article_attachments/17123981201431) Acesse: MGEPessoal>>Arquivos>>Empresa
Aba: **"Informações Gerais"**

Opção: **"Centralização"**

**Centralizadora:** Marcado - empresa matriz deverá estar marcada esta opção as demais Centralizada.

Aba: **"Informações Fiscais"**
Campo **"Lotado na Empresa":** deverá conter caso a empresa se enquadre como Lotação, o código da empresa.

**(1)** **Confira explicação:**
**Tipo de Lotação**: contém a lista determinada pelo E-Social, que identificará para este as '**Lotações**' que cada **Empresa** possui. A '**Empresa' que se enquadrou como 'Lotação**' deverá inserir seu código (cód.Empresa) para que as informações sejam **centralizadas** no campo Lotado na Empresa.

**Exemplo:** a **Empresa 02** é considerada como **Lotação.** Portanto, no campo Lotado na Empresa, a **Empresa 02** deverá inserir a **Empresa 01** e na **Empresa 01** esse campo não deverá ser preenchido e o campo Tipo de Lotação estará como ‘Não é Lotação’.
