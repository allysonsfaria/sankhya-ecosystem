# 136 - Valor do dissídio deve ser informado pois a data do dissidio está preenchida na GRRF

**![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/16621578823319) MENSAGEM:**

136 - Valor do dissídio deve ser informado pois a data do dissidio está preenchida na GRRF

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16621578827031) SOLUÇÃO:**

Acesse o menu **"Conexão/Arquivo para GRRF/Processamento"** e delete a data que está no campo "**Data Homologação Dissídio Coletivo"**

![Imagem 3: Acesse o menu "Conexão/Arquivo para GRRF/Processamento" e delete a data que está no campo " Data Homologação Dissídio…](https://ajuda.sankhya.com.br/hc/article_attachments/14864213067927)

Após ajuste, gere novamente o arquivo e faça  a importação no sistema SEFIP.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16621583730967) CAUSA:**

Ocorre quando preenche indevidamente o campo Data Homologação Dissídio Coletivo.
