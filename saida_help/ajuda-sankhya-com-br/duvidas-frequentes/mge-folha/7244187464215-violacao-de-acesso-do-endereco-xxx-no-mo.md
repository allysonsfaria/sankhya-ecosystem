# Violação de acesso do endereço 'xxx' no módulo 'MGEPess.exe'. Lendo do endereço 00000000. Como resolver?

**![Imagem 1: MENSAGEM :](https://ajuda.sankhya.com.br/hc/article_attachments/16505308776599) MENSAGEM**:

Violação de acesso do endereço 'xxx' no módulo 'MGEPess.exe'. Lendo do endereço 00000000

**![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16505308779287) SOLUÇÃO:**

Utilize uma versão do executável na mesma versão em que se encontra o banco de dados.

**![Imagem 3: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/16505304901399)CAUSA:**

Esse erro pode ocorrer em diversos momentos quando a versão do banco de dados está diferente do executável do sistema.

Para conferir acesse: Ajuda->Auditoria
