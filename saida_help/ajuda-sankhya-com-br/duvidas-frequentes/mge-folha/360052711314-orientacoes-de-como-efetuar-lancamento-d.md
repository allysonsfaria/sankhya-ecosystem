# Orientações de como efetuar lançamento de honorários para cálculo de RPA (Recibo de profissional autônomo).

Orientação sobre como efetuar lançamento de Honorários para cálculo de RPA.

![Imagem 1: Acesse MGEPessoal>>Avançado>>Preferências>>Todas as preferências Pesquise pelo parâmetro FPCALAUTONOMOS - Libera…](https://ajuda.sankhya.com.br/hc/article_attachments/19480957973271) Acesse MGEPessoal>>Avançado>>Preferências>>Todas as preferências
Pesquise pelo parâmetro FPCALAUTONOMOS - Libera cálculo de Autônomos = SIM

![Imagem 2: Acesse MGEPessoal>>Avançado>>Preferências>>Todas as preferências Pesquise pelo parâmetro FPCALAUTONOMOS - Libera…](https://ajuda.sankhya.com.br/hc/article_attachments/360091942913)
Após ativar o parâmetro, saia e entre novamente no sistema.

![Imagem 3: Acesse MGEPessoal>>Cálculos>>Autônomos Preencha os campos obrigatórios (Empresa, Funcionário, Referência, etc). Clique…](https://ajuda.sankhya.com.br/hc/article_attachments/19480958000151) Acesse MGEPessoal>>Cálculos>>Autônomos
Preencha os campos obrigatórios (Empresa, Funcionário, Referência, etc).
Clique no botão 'Honorários', selecione o evento e preencha os demais campos.

[GIF animado: Imagem 4: Acesse MGEPessoal>>Cálculos>>Autônomos Preencha os campos obrigatórios (Empresa, Funcionário, Referência, etc). Clique…](https://ajuda.sankhya.com.br/hc/article_attachments/360089797614)

![Imagem 5: Após efetuar todos os lançamentos de Honorários que serão pagos na referência para o autônomo, acessar o menu…](https://ajuda.sankhya.com.br/hc/article_attachments/19480955603351) Após efetuar todos os lançamentos de Honorários que serão pagos na referência para o autônomo, acessar o menu MGEPessoal>>Cálculos>>Individual ou Automático>>Folha Normal, selecionar o Autônomo e gerar o cálculo, conferir os valores e confirmar.

[GIF animado: Imagem 6: Após efetuar todos os lançamentos de Honorários que serão pagos na referência para o autônomo, acessar o menu…](https://ajuda.sankhya.com.br/hc/article_attachments/360089799694)
