# Como configurar para considerar na média, 12 avos sobre Parcela do 13º sálario?

![Imagem 1: Acesse o Menu do MGEPessoal>>Avançado>>Regras para Cálculos. Aba: "Médias" Opção: "Médias 13º salário"](https://ajuda.sankhya.com.br/hc/article_attachments/17123821058839) Acesse o Menu do **MGEPessoal>>Avançado>>Regras para Cálculos.**
Aba: **"Médias"**
Opção: **"Médias 13º salário"**

**Médias Aritméticas:** quando este estiver marcado, o sistema irá fazer o cálculo com base na quantidade de meses de direito adquirido ou o estipulado no campo **"Quantidade de Meses"**.
**Observação:** Lembre-se da marcação Forma de Calculo de médias (se todos os meses ou apenas meses com valores).

**Médias Duodecimais:** quando estiver marcada esta opção, o sistema irá fazer o cálculo referente a 12 avos.
