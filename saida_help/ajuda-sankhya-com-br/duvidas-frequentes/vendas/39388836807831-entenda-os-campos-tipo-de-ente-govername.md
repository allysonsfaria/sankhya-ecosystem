# Entenda os campos Tipo de Ente Governamental e Estado Civil no cadastro de Parceiros

O cadastro de Parceiros do Sankhya permite filtrar registros por dois campos: **Tipo de Ente Governamental** e **Estado Civil**. Veja o que cada um representa e como usá-los.

### Visão Geral dos Filtros Disponíveis

O sistema Sankhya permite **"filtrar parceiros fornecedores"** utilizando diversos critérios, incluindo **"tipo de ente governamental"** e **"estado civil"**. Esses filtros estão disponíveis em diferentes telas de cadastro de parceiros, facilitando a localização e organização dos registros.

Os principais tipos de parceiros que podem ser filtrados incluem: **"Parceiro Fornecedor"**, **"Fornecedor Aprovado"**, **"Melhor Fornecedor"**, **"Parceiro Pagante"**, **"Parceiro Transportadora"**, entre outros.

### Filtro por Tipo de Ente Governamental

Classifica o parceiro conforme a esfera administrativa, quando se trata de um órgão público:

| Código | Esfera |
| --- | --- |
| 1 | União |
| 2 | Estado |
| 3 | Distrito Federal (DF) |
| 4 | Município |

Esse campo é usado para identificar corretamente o parceiro em documentos fiscais emitidos para órgãos públicos.

Disponível nos cadastros de parceiro vinculados a operações fiscais, como Parceiro Fornecedor, Parceiro Remetente, Parceiro Destinatário CT-e e Parceiro Transportadora NF-e.

Este filtro está disponível para diversos tipos de parceiros, como **"Parceiro Fornecedor"**, **"Parceiro Remetente"**, **"Parceiro Destinatário CT-e"**, **"Parceiro Transportadora NF-e"**, entre outros.

### Filtro por Estado Civil

Filtra parceiros **pessoa física** pelo estado civil informado no cadastro (Solteiro(a), Casado(a), Viúvo(a), Divorciado(a), União Estável, Outros(as)). Não se aplica a parceiros pessoa jurídica.

Disponível nos mesmos cadastros que envolvem parceiro pessoa física, como Fornecedor Aprovado, Melhor Fornecedor, Parceiro Coleta CT-e, Parceiro Entrega CT-e, Parceiro Pagante, Parceiro Fabricante e Parceiro Retirada.

### Como Aplicar os Filtros

Para filtrar parceiros fornecedores por estado e tipo, siga os passos abaixo:

**(1)** Acesse o cadastro de **Parceiros**.

**(2)** Localize o campo **Tipo de Ente Governamental** ou **Estado Civil** na área de filtros da tela.

**(3)** Selecione o valor desejado (ex.: "2 - Estado" para órgãos estaduais).

**(4)** Aplique o filtro para exibir apenas os parceiros que atendem ao critério escolhido.
