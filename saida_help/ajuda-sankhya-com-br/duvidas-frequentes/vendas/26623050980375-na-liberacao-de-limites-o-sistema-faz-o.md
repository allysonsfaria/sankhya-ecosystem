# Na liberação de Limites o sistema faz o envio do e-mail apenas se for informado o usuário liberador

![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26671533839383) **SITUAÇÃO:**

Na liberação de Limites, o sistema faz o envio do e-mail apenas se for informado qual o usuário será o liberador.

![Imagem 2: Na liberação de Limites, o sistema faz o envio do e-mail apenas se for informado qual o usuário será o liberador.](https://ajuda.sankhya.com.br/hc/article_attachments/26623069329303)

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26623069331351)SOLUÇÃO:**

Só será enviado o e-mail quando for selecionado o Liberador. Caso não seja informado, o sistema permite a liberação do evento por qualquer usuário, mas não envia o e-mail.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26623069335831)CAUSA:**

Não informando o liberador, o sistema não chama o serviço de Liberação pelo fonte caso seja informado o liberador, o serviço de Liberação é chamado enviando o e-mail.
