# Como configurar uma natureza padrão para devolução de vendas?

Para assegurar que o sistema utilize um tipo específico para devoluções, siga as etapas abaixo:

**(1)** Acesse tela **''Preferências''** (Configurações» Avançado» Preferências) e localize o parâmetro **''NATPADDEV - Natureza padrão p/Devolução de Vendas''.**

**(2)** Preencha com o **código da natureza de operação** que deve ser considerada como padrão para devoluções.

- Ao efetuar uma devolução, se o **Tipo de Negociação** não tiver natureza informada ou estiver diferente do parâmetro, no ato da devolução irá assumir a natureza informada no parâmetro.

**(3)** Após configurar o parâmetro NATPADDEV corretamente, o sistema começará a usar a **natureza de operação definida** para todas as devoluções de vendas. Essa configuração proporciona um controle fiscal melhor e ajuda a evitar erros na operação.
