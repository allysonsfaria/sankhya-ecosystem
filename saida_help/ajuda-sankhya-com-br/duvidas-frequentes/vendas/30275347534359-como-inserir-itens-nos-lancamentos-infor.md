# Como inserir itens nos lançamentos informando o  'código do produto', 'Referência do produto' ou ambos?

No menu de pesquisa, acesse as **"Preferências"** (Configurações » Avançado » Preferências), localize o parâmetro **CODPROREF - Código e/ou referência nos tens?** e escolha a opção desejada: **referência, código ou ambas.**

**Observação:** caso não esteja sendo apresentada a opção **ambas**, ainda na tela Preferências exclua o parâmetro CODPROREF. Após esse procedimento, o sistema irá reiniciar o parâmetro de forma automática, disponibilizando três opções para a escolha.
