# Como habilitar o campo percentual de desconto no rodapé da nota?

![Imagem 1: Para que o campo Percentual de Desconto fique disponível para digitação, ligue o parâmetro "DESCTOT-Aceita desconto no…](https://ajuda.sankhya.com.br/hc/article_attachments/17144449168151) Para que o campo Percentual de Desconto fique disponível para digitação, ligue o parâmetro **"DESCTOT-Aceita desconto no pé da nota",** nas Preferências (Caminho de acesso: Configurações » Avançado » Preferências):

- Parâmetro DESCTOT:  ligado

![Imagem 2: Parâmetro DESCTOT: ligado](https://ajuda.sankhya.com.br/hc/article_attachments/4409387021463)

- Parâmetro DESCTOT: desligado

![Imagem 3: Parâmetro DESCTOT: desligado](https://ajuda.sankhya.com.br/hc/article_attachments/4409392313111)

**![Imagem 4: IMPORTANTE:](https://ajuda.sankhya.com.br/hc/article_attachments/17144471303447)IMPORTANTE:**

Para que o desconto no rodapé seja rateado entre os itens, considere ativar os parâmetros **"DISTJDCONF"** e **"DISTDESCNFE"**.

**Observação:** atualmente, o sistema não está preparado para realizar o rateio de descontos que aparecem no rodapé da nota após a confirmação, especialmente quando o item é um serviço (CODUSOPROD = S). Isso resulta na impossibilidade de aplicar os descontos de maneira adequada nos valores.
