# Código do erro: 1430 Mensagem: Contribuinte nao credenciado. Faça o credenciamento no site da NFSe. Prefeitura Uberlandia-MG

O erro acima é apresentado quando se trata da **primeira emissão de NFSe via Web Service para prefeitura de Uberlândia-MG**, na qual se faz necessário que o contribuinte realize primeiramente o credenciamento junto a prefeitura para que seja liberado o processo de emissão de NFSe via Web Service.

Esse processo de **liberação do credenciamento** poder ser **realizado através do Portal da Prefeitura** pelo endereço: <https://nfse.uberlandia.mg.gov.br/#/>

**Após realizado o devido credenciamento, tente gerar o lote da NFSe novamente.**
