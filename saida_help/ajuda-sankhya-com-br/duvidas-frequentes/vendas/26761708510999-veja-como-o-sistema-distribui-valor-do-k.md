# Veja como o sistema distribui valor do kit nos componentes

O sistema usa a regra de 3 para distribuir o  valor do kit nos componentes.

**Exemplo:** Valor do kit 150,00

**Soma dos componentes:** 100,50

#### Valor de tabela dos componentes

**Componente 'A'** = R$ 30,00

![Imagem 1: 44,78](https://ajuda.sankhya.com.br/hc/article_attachments/26761708478103)44,78

**Componente 'B'** = R$ 45,00

![Imagem 2: 67,16](https://ajuda.sankhya.com.br/hc/article_attachments/26761708481047)67,16

**Componente 'C'** = R$ 25,50

![Imagem 3: 38,06](https://ajuda.sankhya.com.br/hc/article_attachments/26761733215511)38,06

Essa distribuição será feita quando é lançado um pedido/nota que tem kit e o parâmetro **"EDITMPSOMPRECO"** está desligado. Se estiver ligado, a soma dos componentes será somada no kit. Quando o parâmetro **"CONFKITIND"** está ligado, o sistema observa a marcação na tela de **"Configuração de kit.", "Distribuir preço do kit nos componentes".**
