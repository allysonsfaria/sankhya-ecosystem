# É possível deixar os itens dos pedidos pendentes, quando uma NF-e é denegada?

**(1)** Sim, é possível configurando o parâmetro **"DENEGDEIXAPEND-Nota Denegada deixa pedido pendente?"**,  que tem a finalidade de deixar novamente o pedido com os itens disponíveis.
