# Como funciona a confirmação múltipla de notas pelos portais?

**(1)** Foi disponibilizado no sistema a opção de **confirmação em massa de notas**. Isto ajudará muito o processo de clientes que agrupam os lançamentos e precisam confirmar todas de uma vez só, devido o alto número de informações.
