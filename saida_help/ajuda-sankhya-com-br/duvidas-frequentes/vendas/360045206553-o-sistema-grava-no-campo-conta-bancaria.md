# O sistema grava no campo 'Conta Bancária' do financeiro da Nota de Venda, a conta do usuário Caixa PDV

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/19357570666263) SOLUÇÃO:**

Não. No campo 'Conta Bancaria', será gravado a conta seguindo o padrão do sistema, olhando conta bancaria do Tipo de negociação.

O único comportamento do sistema e alterar para a Conta Caixa do Usuário, quando se efetua **baixa** com o usuário Caixa Logado.
