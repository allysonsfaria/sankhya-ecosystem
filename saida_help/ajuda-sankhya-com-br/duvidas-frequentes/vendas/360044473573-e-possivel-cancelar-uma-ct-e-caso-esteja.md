# É possível cancelar uma CT-e, caso esteja vinculado a um MDF-e 'Autorizado' ou 'Encerrado'?

Não é possível realizar o cancelamento se a CT-e estiver vinculada a um MDF-e 'Autorizado ou Encerrado', apresentando então a rejeição:  '528-Vedado o cancelamento se existir evento de MDF-e Autorizado para o CT-e'.

**Boa Prática:**

Verifique se a MDF-e pode ser cancelada, caso não haja registro de passagem e/ou caso não haja a entrega das mercadorias.
