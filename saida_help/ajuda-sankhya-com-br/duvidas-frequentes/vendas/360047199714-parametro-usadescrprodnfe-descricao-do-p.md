# Parâmetro USADESCRPRODNFE - Descrição do produto para NF-e

**(1)** Foi disponibilizado no sistema a possibilidade de **informar uma descrição do produto para NF-e,** essa acontecerá através do parâmetro **"Utiliza descrição do produto para NFE? - USADESCRPRODNFE."** Com este parâmetro habilitado o sistema disponibilizará no cadastro do produto o campo **"Descrição para NFe"** e este quem valerá na emissão de NF-e, referente a descrição do produto [<xProd>].

![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/16531863641623)**SOLUÇÃO:**

Para realizar a configuração, siga os passos abaixo:

![Imagem 2: Acesse a tela "Preferências" (Caminho de acesso: Configurações » Avançado » Preferências ) e habilite o parâmetro…](https://ajuda.sankhya.com.br/hc/article_attachments/16531863642391) Acesse a tela **"Preferências"** (Caminho de acesso: Configurações » Avançado » Preferências) e habilite o parâmetro **"Utiliza descrição do produto para NFE? - USADESCRPRODNFE".**

![Imagem 3: Acesse a tela "Preferências" (Caminho de acesso: Configurações » Avançado » Preferências ) e habilite o parâmetro…](https://ajuda.sankhya.com.br/hc/article_attachments/15604734484375)

**![Imagem 4: "Utiliza descrição do produto para NFE? - USADESCRPRODNFE" com este parâmetro habilitado o sistema disponibilizará no…](https://ajuda.sankhya.com.br/hc/article_attachments/16531901806103) "Utiliza descrição do produto para NFE? - USADESCRPRODNFE"** com este parâmetro habilitado o sistema disponibilizará no cadastro do produto o campo **"Descrição para NFe"** e este quem valerá na emissão de NF-e, referente a descrição do produto.

- **Ligado:** se o campo do produto DESCRPRODNFE (Descrição para NFE) estiver preenchido é esse que irá compor a tag xProd.
- **Desligado:** será enviada a informação inserida no campo DESCRPROD [Descrição].
