# Sistema está incluindo o desconto promocional no saldo flex do vendedor

![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26561438957975) **SITUAÇÃO:**

Sistema está incluindo o desconto promocional no saldo flex do vendedor, conforme imagem abaixo:

![Imagem 2: Sistema está incluindo o desconto promocional no saldo flex do vendedor, conforme imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/26518436437271)

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26518452521879)SOLUÇÃO:**

Todo valor do campo **"Desconto"** irá afetar o saldo flex do vendedor. Independente de ser uma promoção ou não.

Nesse caso, uma solução é embutir o desconto no preço de tabela do produto ao invés de destacá-lo no campo de desconto.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26518452523159)CAUSA:**

Quando é feito um lançamento de um item que tem desconto promocional e a empresa trabalha com Saldo Flex.
