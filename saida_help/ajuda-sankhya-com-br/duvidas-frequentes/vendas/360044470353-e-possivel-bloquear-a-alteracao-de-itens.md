# É possivel bloquear a alteração de itens no pedido que está vinculado a uma OC (Ordem de Carga)?

**(1)** Não é possível bloquear alteração. Pois, atualmente o sistema permite a alteração nos pedidos, mesmo com uma Ordem de Carga vinculada, em exceção quando o pedido é enviado para o Módulo [WMS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044602114-WMS), no qual a validação não permite alteração do pedido, somente quando o envio é cancelado.
