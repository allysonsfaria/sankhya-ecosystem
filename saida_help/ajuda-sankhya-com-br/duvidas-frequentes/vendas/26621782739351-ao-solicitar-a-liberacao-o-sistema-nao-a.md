# Ao solicitar a liberação, o sistema não avisa o usuário liberador pelas notificações do sistema via Sankhya OM

![Imagem 1: SITUAÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26671234532887) **SITUAÇÃO:**

Ao solicitar a liberação, o sistema não avisa o usuário liberador pelas notificações do sistema via Sankhya OM.

![Imagem 2: Ao solicitar a liberação, o sistema não avisa o usuário liberador pelas notificações do sistema via Sankhya OM.](https://ajuda.sankhya.com.br/hc/article_attachments/26671299259287)

**![Imagem 3: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/26621782721943)SOLUÇÃO:**

O sistema não envia a notificação via Sankhya OM para o usuário Liberador com a informação de que existe liberações pendentes, somente irá enviar as notificações para o usuário solicitante depois de aprovada a liberação. 
Ao processar uma liberação de limites, é possível enviar uma mensagem ao solicitante informando-o via e-mail ou notificação no Sankhya Om que o evento foi liberado, liberado parcialmente, negado, ou ainda, quando a liberação for removida.

Para tal ação, é necessário que na aba **"Identificação do Cadastro do Usuário do solicitante"**, da tela **"Usuários",** o campo **"Notificar solicitante de Liberações"** esteja preenchido com uma das opções disponíveis, sendo elas: **"Por e-mail", "Por notificação no SankhyaOm" ou "Ambos"**.

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/26621782724247)CAUSA:**

Sistema só envia a notificação para o Solicitante e não para o liberador.
