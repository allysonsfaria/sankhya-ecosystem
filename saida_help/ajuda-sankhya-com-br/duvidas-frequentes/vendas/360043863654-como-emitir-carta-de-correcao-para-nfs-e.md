# Como emitir carta de correção para NFS-e?

**(1)** Até a data de publicação desse artigo não identificamos Prefeituras que disponibilizam "WebServices" para geração de carta de correção por sistemas terceiros.

Dessa forma, o sistema Sankhya não fornece essa possibilidade.

Avalie junto ao Contador da empresa e/ou Prefeitura quais opções são recomendados para a necessidade reportada.
