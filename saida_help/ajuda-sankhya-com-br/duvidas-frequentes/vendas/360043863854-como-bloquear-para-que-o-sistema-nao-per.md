# Como bloquear para que o sistema não permita lançamentos com o valor do item zerado?

**![Imagem 1: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/17151272829207) SOLUÇÃO:**

![Imagem 2: Para que esse bloqueio aconteça, desligue o parâmetro "ACEITARUNITZERO" .](https://ajuda.sankhya.com.br/hc/article_attachments/17151260512535) Para que esse bloqueio aconteça, desligue o parâmetro **"ACEITARUNITZERO"**.

- Tela **"Preferências"** (Caminho de acesso: Configurações » Avançado):
- Chave ACEITARUNITZERO - Aceitar valor unitário igual a zero na venda?

![Imagem 3: Quando o parâmetro Aceitar valor unitário igual a zero na venda estiver "Sim", o sistema aceitará o lançamento de…](https://ajuda.sankhya.com.br/hc/article_attachments/17151272835863) Quando o parâmetro Aceitar valor unitário igual a zero na venda estiver "Sim", o sistema aceitará o lançamento de produtos com valor zero (0), se "Não", o sistema não aceitará, mesmo se o produto for considerado como brinde.
