# Como visualizar notas "antigas"?

Ao tentar visualizar nos respectivos portais, pedidos/notas anteriores a determinada data, essas não são apresentadas.

**(1)** Acesse a tela **"Preferências"** (Configurações » Avançado)

**(2)** Chave **"NRODIASNOTA**": ajuste conforme necessidade;

**(2)** Parâmetro para informar **número de dias anteriores** que o sistema considerará para mostrar notas na ficha de parceiros e telas de seleção dos portais de atendimento.

**Exemplo:** Usuário quer que o sistema apresente notas de no máximo 200 dias atrás, então informa 200 neste parâmetro. Mesmo se não tiver filtro algum na central, o sistema só apresentará estas notas.
