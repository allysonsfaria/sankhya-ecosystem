# Evento 23 - Bonificação

Para este evento, tem-se as seguintes configurações:

![Imagem 1: Tela 'Preferências' (Configurações » Avançado):](https://ajuda.sankhya.com.br/hc/article_attachments/19034401382551) Tela 'Preferências' (Configurações » Avançado):

- **"O parâmetro "Usa Desc. Bonificação? - DESCBONIF**" deve estar ativado;

![Imagem 2: "O parâmetro "Usa Desc. Bonificação? - DESCBONIF " deve estar ativado;](https://ajuda.sankhya.com.br/hc/article_attachments/19034417218583)

![Imagem 3: A tela Limites de Bonificação deve estar configurada;](https://ajuda.sankhya.com.br/hc/article_attachments/19034417226391) A tela [Limites de Bonificação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044599894-Limites-de-Bonifica%C3%A7%C3%A3o) deve estar configurada;

![Imagem 4: No cadastro de Tipos de Operação - TOP , na aba Geral , efetua-se a marcação "Bonificação":](https://ajuda.sankhya.com.br/hc/article_attachments/19034417231255) No cadastro de [Tipos de Operação - TOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP), na aba Geral, efetua-se a marcação **"Bonificação":**

![Imagem 5: No cadastro de Tipos de Operação - TOP , na aba Geral , efetua-se a marcação "Bonificação":](https://ajuda.sankhya.com.br/hc/article_attachments/19034417242775)

**Considerações:**

- Se a marcação Bonificação presente na TOP estiver realizada, ao proceder com uma Venda a utilizando, é aberto o pop-up de solicitação de Liberação de Limites para o evento 23 - Bonificação, no valor total da nota.
- Com a marcação Bonificação **não realizada**, será solicitada a liberação para o evento 23 - Bonificação com base na somatória dos valores informados no campo **"Bonificação"** dos itens.

Na tela de solicitação de liberação de limites para bonificação, será sugerido pelo sistema o Gerente do Vendedor para liberação.

- Para isso deve-se fazer a ligação pelos campos Funcionário e Empresa presentes no Cadastro de [Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios) (aba Identificação) e no Cadastro de [Vendedores/Compradores](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045111133-Vendedores-Compradores) (aba Geral). Faz-se a associação informando os mesmos códigos nos campos Funcionário e Empresa em ambos os cadastros.
- Na tela de liberação, quando o evento for de Bonificação e o Usuário Liberador possuir mais de um período, é aberta uma tela para que o usuário escolha qual dos períodos será utilizado. Para validar o limite do Liberador no Período, será utilizado o somatório das notas liberadas pelo mesmo.

### Imagem 6: Liberação de Pedidos com Bonificação (Evento 23) Liberação de Pedidos com Bonificação (Evento 23)

Ao confirmar um pedido de venda que exige a liberação por bonificação (Evento 23), o sistema exibirá uma tela para que você informe o responsável pela liberação.

**Para liberar um pedido com bonificação:**

1. **Aguarde o pop-up de liberação:** Após confirmar o pedido na Central de Vendas, um pop-up de liberação será exibido.
2. **Informe o usuário liberador:** No campo "Usuário Liberador", você deverá **digitar ou selecionar manualmente o usuário responsável** por aprovar a bonificação. O sistema não preencherá esse campo automaticamente.
3. **Prossiga com a liberação:** Após informar o usuário liberador, siga as instruções na tela para concluir o processo de liberação do pedido.

![e5e88f84-26c0-4fef-b3bb-ac623583c4d0](https://ajuda.sankhya.com.br/hc/article_attachments/32553137877143) Porém, se não fizer nenhuma ação, o sistema vai incluir a solicitação de liberação que ficará disponível para qualquer usuário que tenha acesso de liberação ao evento.
