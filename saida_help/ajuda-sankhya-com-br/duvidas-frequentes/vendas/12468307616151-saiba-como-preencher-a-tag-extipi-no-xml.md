# Saiba como preencher a tag <EXTIPI> no XML

Para que a tag <EXTIPI> seja preenchida no XML, é necessário que o campo **"Cód. Exceção NCM"** do Cadastro de Produtos (Caminho de acesso: Configurações » Cadastros » Produtos » Produtos), esteja devidamente configurado, conforme imagem abaixo:

#### **(1)** O que é ex TIPI na nota fiscal?

Classificação Fiscal (NCM) com TAG EXTIPI refere-se a NCM listados na Tabela de Incidência do IPI (TIPI - Decreto nº 7.660/2011) - O "EX" **significa exceção, com alíquota diferenciada, que pode ser maior ou menor do que a alíquota fixada na tabela**.
