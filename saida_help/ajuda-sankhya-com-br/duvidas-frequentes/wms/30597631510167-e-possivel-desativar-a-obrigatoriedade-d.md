# É possível desativar a obrigatoriedade de colocar a data de validade na  tarefa movimentação pró-ativa no coletor WMS?

Não é possível desativar essa obrigatoriedade de forma nativa.

Se o produto estiver configurado para controle de validade (SHELFLIFE) no WMS, a data de validade **deve obrigatoriamente ser informada** no coletor durante a movimentação do estoque.

O sistema pede que a data de validade seja informada para que o estoque de produtos com prazo de validade seja controlado corretamente. Isso ajuda a saber exatamente quando os produtos vão vencer, evitando erros, perdas e garantindo que o estoque seja gerenciado de forma organizada e segura.
