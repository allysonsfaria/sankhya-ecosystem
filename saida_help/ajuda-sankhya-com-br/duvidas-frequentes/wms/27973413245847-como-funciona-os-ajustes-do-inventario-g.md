# Como funciona os ajustes do Inventário Global?

A diferença entre o inventário Rotativo e o Global é que, nesse último, no pop-up Contagem de Estoque são apresentadas as marcações **"Apenas produto com no mínimo X contagens dentro do inventário"** e **"Apenas produto com as X últimas contagens iguais"**.

**Observação:** caso o parâmetro **"Permite contagem de estoque com pendências - PERMCONTESTPEND"** esteja habilitado, será possível realizar a contagem e ajuste de estoque de endereços que possuam tarefas de saída pendentes, na realização do processo de inventário Rotativo.

**Sobre as marcações citadas acima:**

(1)** Apenas produto com no mínimo X contagens dentro do inventário:**
Se configurado para exigir ao menos duas contagens, o sistema apenas realizará o ajuste, caso seja feito a recontagem do produto / endereço.

(1)** Apenas produto com as X últimas contagens iguais:**
Se essa opção estiver marcada junto à anterior, o ajuste será realizado somente se as últimas X contagens do produto ou endereço forem idênticas. Caso haja divergências entre as contagens, o sistema não realizará o ajuste.
