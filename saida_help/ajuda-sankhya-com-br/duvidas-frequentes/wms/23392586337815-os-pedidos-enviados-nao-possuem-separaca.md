# Os pedidos enviados não possuem separação por pedido, deve ser utilizado a opção 'Enviar para Expedição por OC'

![Imagem 1: MENSAGEM:](https://ajuda.sankhya.com.br/hc/article_attachments/23392614182167) **MENSAGEM:**

[WMS\_E00682] Os pedidos enviados não possuem separação por pedido, deve ser utilizado a opção 'Enviar para Expedição por OC'.

![Imagem 2: SOLUÇÃO:](https://ajuda.sankhya.com.br/hc/article_attachments/23392614188183) **SOLUÇÃO:**

Acesse a tela [**"Formação de carga"**](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612274-Forma%C3%A7%C3%A3o-de-Carga) depois em **"Outras opções"** utilize a opção **"Enviar para Expedição por OC".**

[GIF animado: Imagem 3: Acesse a tela "Formação de carga" depois em "Outras opções" utilize a opção "Enviar para Expedição por OC".](https://ajuda.sankhya.com.br/hc/article_attachments/23399398572311)

**![Imagem 4: CAUSA:](https://ajuda.sankhya.com.br/hc/article_attachments/23392614184855)CAUSA:**

Ocorre quando os produtos do pedido pertencem a uma área de separação do tipo por produto, não sendo possível enviar apenas pela opção "Enviar para Expedição".
