# Como configurar as faixas de desconto?

## O módulo de "Autorização de Desconto" é utilizado para estabelecer limites de desconto e controlar o percentual máximo de desconto que cada usuário pode conceder no sistema.

Imagine a seguinte situação: durante uma venda, um vendedor deseja aplicar um desconto de 50% no valor total, porém, sua permissão de desconto permite apenas um máximo de 10%. Nesse caso, será aberta uma janela no PDV solicitando que um usuário com uma permissão de desconto superior insira sua senha para autorizar o desconto excedente.

Esse processo de autorização de desconto tem como objetivo garantir que as políticas de desconto estabelecidas pela empresa sejam seguidas adequadamente. Ao restringir o limite de desconto de cada usuário, a empresa mantém o controle sobre as concessões de desconto e evita práticas inadequadas ou abusivas.

---

Para configurar as faixas de desconto, na barra de menus, clique em: Configurações → Desconto - Autorização de Descontos:

![Imagem 1: Para configurar as faixas de desconto, na barra de menus, clique em: Configurações → Desconto - Autorização de…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-10-1024x162.png)

Clique em “Nova Faixa”:

![Imagem 2: Clique em “Nova Faixa”:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-313.png)

- Em “Desconto até (%)”, informe a faixa de desconto que este usuário poderá autorizar.

- Em (+) informe qual usuário poderá utilizar este desconto, lembrando que pode-se ter mais de um usuário liberado para essa mesma faixa de desconto.

![Imagem 3: Em (+) informe qual usuário poderá utilizar este desconto, lembrando que pode-se ter mais de um usuário liberado para…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-311.png)

Após selecionar os usuários, clique em “Salvar”.

Observação: Cada usuário só poderá pertencer a uma faixa de desconto.
