# Como cadastrar um novo usuário no Magis5 ERP?

## Entende como realizar o cadastro de um novo usuário dentro no Magis5 ERP

---

O módulo "**Cadastro de Usuários"** do **Magis5 ERP** desempenha um papel essencial no controle de acesso e na gestão dos usuários vinculados aos empreendimentos. Ele permite registrar e gerenciar perfis de forma completa, possibilitando a criação de usuários individuais para cada membro da equipe, com níveis de acesso e permissões totalmente personalizáveis.

Dessa forma, é possível garantir que apenas pessoas autorizadas tenham acesso às informações e funcionalidades específicas da plataforma, promovendo maior segurança, organização e eficiência na administração dos dados.

Feito login no Magis5 ERP vá até "Configurações" e depois **" Usuários - Cadastro"**

![Imagem 1: Feito login no Magis5 ERP vá até "Configurações" e depois " Usuários - Cadastro"](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-May-23-2025-11-59-48-5267-AM.png?width=291&height=658&name=image-png-May-23-2025-11-59-48-5267-AM.png)

Na tela de **Cadastro de Usuários**, clique no botão "**Cadastrar Novo"** para iniciar o registro de um novo usuário no sistema.

![Imagem 2: Na tela de Cadastro de Usuários , clique no botão " Cadastrar Novo" para iniciar o registro de um novo usuário no…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Nov-07-2025-02-26-28-2930-PM.png?width=589&height=131&name=image-png-Nov-07-2025-02-26-28-2930-PM.png)

### Dados de Acesso

Neste campo, devem ser informados o **nome do usuário** e o **login** que serão utilizados para acessar o empreendimento.
Também é possível **inserir uma foto** para facilitar a identificação do usuário.

💡 **Recomendação:** utilize um **endereço de e-mail** como login, garantindo maior padronização e facilidade no processo de autenticação.

A **senha padrão Artemis5#@** será atribuída automaticamente ao novo usuário.

Por motivos de segurança, ele deverá **alterar essa senha no primeiro acesso** ao sistema.

![Imagem 3: A senha padrão Artemis5#@ será atribuída automaticamente ao novo usuário. Por motivos de segurança, ele deverá alterar…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-May-23-2025-12-00-37-5664-PM.png?width=605&height=662&name=image-png-May-23-2025-12-00-37-5664-PM.png)

### Informações de Contato

Neste campo, deve ser inserida uma **forma de contato** do usuário, que pode ser um **e-mail**, **telefone fixo** ou **celular**.

![Imagem 4: Neste campo, deve ser inserida uma forma de contato do usuário, que pode ser um e-mail , telefone fixo ou celular .](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-May-23-2025-12-01-59-7441-PM.png?width=688&height=92&name=image-png-May-23-2025-12-01-59-7441-PM.png)

### Informações Complementares

O preenchimento das informações deste campo não são obrigatórias, mas complementarão o cadastro do usuário.

![Imagem 5: O preenchimento das informações deste campo não são obrigatórias, mas complementarão o cadastro do usuário.](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-May-23-2025-12-01-48-1279-PM.png?width=688&height=268&name=image-png-May-23-2025-12-01-48-1279-PM.png)

1. **Tornar este usuário um cliente?** Caso este usuário também seja um cliente, marque **"Sim"**;
2. **Representante de Vendas:** Caso este cadastro seja de um “Representante de Vendas”, selecione **“Sim”**;
3. **Grupo de Comissionamento:** Selecione o grupo de comissionamento, caso este cadastro seja de um **“Representante de Vendas”**;

### Empreendimentos

É possível **compartilhar um cadastro de usuário entre diferentes empreendimentos**.
Para isso, clique em **"(+) Incluir"** e selecione os **empreendimentos** com os quais o cadastro será compartilhado.

![Imagem 6: É possível compartilhar um cadastro de usuário entre diferentes empreendimentos . Para isso, clique em "(+) Incluir" e…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-May-23-2025-12-02-30-3344-PM.png?width=688&height=86&name=image-png-May-23-2025-12-02-30-3344-PM.png)

- **ID Caixa Padrão:** Utilizado **exclusivamente para o cadastro de representantes comerciais.**
  Neste campo, insira o **ID do terminal de atendimento vinculado ao usuário**.
  Essa configuração permite que o representante acesse o PDV em modo representante a partir de qualquer dispositivo, possibilitando o registro de vendas.
- **Metas de Vendas:** Informe qual será a meta que este usuário terá que atingir por empreendimento.
- **Perfil**: Selecione qual perfil este usuário terá no empreendimento selecionado. Para criar novos perfis, [clique aqui](https://sankhya.zendesk.com/hc/pt-br/articles/44011902111127).

  Para inserir ou remover acessos (módulos), clique em **"ver módulos"** e insira ou remova a seleção no checkbox:

  ![Imagem 7: Perfil : Selecione qual perfil este usuário terá no empreendimento selecionado. Para criar novos perfis, clique aqui .…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Nov-07-2025-03-04-00-5973-PM.png?width=1374&height=101&name=image-png-Nov-07-2025-03-04-00-5973-PM.png)
  ![Imagem 8: Perfil : Selecione qual perfil este usuário terá no empreendimento selecionado. Para criar novos perfis, clique aqui .…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-May-23-2025-12-02-52-1871-PM.png?width=389&height=287&name=image-png-May-23-2025-12-02-52-1871-PM.png)

Após finalizar todos os preenchimentos, clique em **“Salvar”**, e o usuário será salvo

![Imagem 9: Após finalizar todos os preenchimentos, clique em “Salvar” , e o usuário será salvo](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Nov-07-2025-03-06-51-2912-PM.png?width=461&height=119&name=image-png-Nov-07-2025-03-06-51-2912-PM.png)

### Bloquear Usuário

Caso seja necessário **bloquear um usuário**, basta **alterar a seleção** do campo **“Bloquear Usuário”**.
Essa ação impede o acesso do usuário ao sistema, sem que seja necessário excluir seu cadastro.
