# Como cadastrar uma conta bancária?

## No Artemis5, as contas bancárias desempenham um papel importante no controle do fluxo de caixa do empreendimento.

Elas são utilizadas para registrar todas as entradas e saídas de dinheiro, garantindo uma gestão financeira precisa e organizada.

Ao criar uma conta bancária no sistema, é possível atribuir um nome, número e outras informações relevantes a ela. A partir desse momento, todas as transações financeiras, como recebimentos de vendas, pagamentos a fornecedores, despesas operacionais e outras movimentações de dinheiro, são registradas nessa conta.

É importante ressaltar que as contas bancárias no **Artemis5** não possuem conciliação bancária, ou seja, elas não estão diretamente conectadas aos sistemas bancários para importar automaticamente as informações das transações. Essa funcionalidade é realizada externamente, fora do sistema **Artemis5**.

---

Para criar uma nova conta bancária, na barra de menus, clique em: Financeiro → Cadastro - Contas Bancárias:

![Imagem 1: Para criar uma nova conta bancária, na barra de menus, clique em: Financeiro → Cadastro - Contas Bancárias:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-27-1024x204.png)

No módulo “Contas Bancárias”, clique em “Nova Conta” e preencha as informações solicitadas:

![Imagem 2: No módulo “Contas Bancárias”, clique em “Nova Conta” e preencha as informações solicitadas:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-539-1024x256.png)

- **Descrição:** Informe o nome das Conta Bancária. É o único campo obrigatório.

- **Tipo:** Informe qual o tipo de conta bancária;

- **Banco:** Informe qual o banco referente à conta bancária. Caso o banco desejado não esteja listado, entre em contato com a nossa equipe de suporte;

- **Agência:** Informe a agência;

- **C/C:** Informe o número da conta corrente.

![Imagem 3: C/C: Informe o número da conta corrente.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-540-1024x254.png)

Após preencher todos os campos, clique em “Salvar” para finalizar a criação de sua conta bancária.
