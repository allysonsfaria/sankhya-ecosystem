# Como configurar uma nova base tributária?

## A base tributária é um conceito fundamental quando se trata da tributação de produtos, principalmente quando há a necessidade de aplicar regras específicas, como descontos em ICMS ou a aplicação da Substituição Tributária.

A base tributária refere-se ao valor sobre o qual os impostos são calculados. É o montante que serve de referência para determinar a carga tributária aplicável a um determinado produto. Em outras palavras, é o valor que serve como base para a aplicação dos percentuais de impostos, como ICMS, IPI, PIS, COFINS, entre outros.

No contexto do Magis5 ERP, a base tributária desempenha um papel importante na definição do valor dos impostos a serem pagos em cada transação. É através desse valor que o sistema aplica as regras fiscais pertinentes, como alíquotas, benefícios fiscais, incentivos, entre outros, a fim de calcular os impostos corretamente.

É comum que haja diferentes bases tributárias para diferentes tipos de produtos, considerando suas particularidades e as regras tributárias aplicáveis a cada um. Por exemplo, um produto sujeito à Substituição Tributária pode ter uma base tributária específica, enquanto outro produto pode ter uma base tributária diferente por estar sujeito a descontos em ICMS.

---

Para configurar uma nova base tributária, na barra de menus, clique em: Configurações → NF-e - Base Tributária:

![Imagem 1: Para configurar uma nova base tributária, na barra de menus, clique em: Configurações → NF-e - Base Tributária:](https://ajuda.sankhya.com.br/hc/article_attachments/44012196366999)

Em seguida, clique em “Nova Base Tributária”:

![Imagem 2: Em seguida, clique em “Nova Base Tributária”:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-254-1024x214.png)

Preencha os dados solicitados de acordo com a nova regra.
No exemplo abaixo, vemos que o produto selecionado teve um desconto em ICMS:

![Imagem 3: Preencha os dados solicitados de acordo com a nova regra. No exemplo abaixo, vemos que o produto selecionado teve um…](https://ajuda.sankhya.com.br/hc/article_attachments/44012200728471)

Caso haja outro produto com o mesmo tipo de desconto, é possível selecioná-lo clicando em "(+) Incluir":

![Imagem 4: Caso haja outro produto com o mesmo tipo de desconto, é possível selecioná-lo clicando em "(+) Incluir":](https://ajuda.sankhya.com.br/hc/article_attachments/44012218713239)

Feito isso, selecione um novo produto e insira o novo desconto. Após finalizar a inserção dos dados, clique em salvar.
