# Através dos filtros de busca

Para realizar a conferência de pedidos utilizando os filtros, na barra de menus, clique em: Vendas → Consulta de Vendas:

![Imagem 1: Para realizar a conferência de pedidos utilizando os filtros, na barra de menus, clique em: Vendas → Consulta de Vendas:](https://ajuda.sankhya.com.br/hc/article_attachments/44012098552343)

Os pedidos que necessitam de conferência devem estar no status “Aguardando Conferência”.

É possível realizar várias combinações de filtros para chegar ao resultado desejado, para isso, é necessário que selecione no mínimo dois filtros. Segue alguns exemplo:

1. Status, data inicial, data final:

![Imagem 2: 1. Status, data inicial, data final:](https://ajuda.sankhya.com.br/hc/article_attachments/44012098670487)

2. Status e Vendedor:

![Imagem 3: 2. Status e Vendedor:](https://ajuda.sankhya.com.br/hc/article_attachments/44012098749335)

3. Status, Forma de Pagamento e UTM Source:

![Imagem 4: 3. Status, Forma de Pagamento e UTM Source:](https://ajuda.sankhya.com.br/hc/article_attachments/44012078681879)

Após filtrar o pedido desejado, clique no botão “Iniciar/Continuar Conferência”:

![Imagem 5: Após filtrar o pedido desejado, clique no botão “Iniciar/Continuar Conferência”:](https://ajuda.sankhya.com.br/hc/article_attachments/44012083061783)

Será aberta a tela com os itens da venda. Para iniciar a conferência, clique no botão “Iniciar”:

![Imagem 6: Será aberta a tela com os itens da venda. Para iniciar a conferência, clique no botão “Iniciar”:](https://ajuda.sankhya.com.br/hc/article_attachments/44012095780375)

A contagem poderá ser realizada de forma manual, clicando em (+) ou (-) ou através de um leitor de código de barras. Para ativá-lo, aperte a letra  “L” no teclado (a mensagem “Leitor Ativo” será exibida).

Também é necessário informar com precisão quantas caixas estão sendo utilizadas durante o processo de conferência, visto que esta informação é imprescindível na emissão da nota fiscal e também, no despacho junto as transportadoras.

![Imagem 7: Também é necessário informar com precisão quantas caixas estão sendo utilizadas durante o processo de conferência,…](https://ajuda.sankhya.com.br/hc/article_attachments/44012099126679)

A tela de conferência é separada em dois blocos: Conferir e Conferidos. Conforme os itens são checados, mudam para o bloco “Conferidos”, como é o exemplo da imagem acima.

Após finalizar a conferência dos itens e a contagem de quantas caixas foram necessárias, clique em “Finalizar”.

![Imagem 8: Após finalizar a conferência dos itens e a contagem de quantas caixas foram necessárias, clique em “Finalizar”.](https://ajuda.sankhya.com.br/hc/article_attachments/44012099206039)

O status da venda será atualizado para “Conferido” automaticamente e a contagem desta venda está pronta para o próximo passo.

![Imagem 9: O status da venda será atualizado para “Conferido” automaticamente e a contagem desta venda está pronta para o próximo…](https://ajuda.sankhya.com.br/hc/article_attachments/44012107333911)
