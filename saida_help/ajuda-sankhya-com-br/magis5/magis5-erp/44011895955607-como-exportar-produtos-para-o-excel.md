# Como exportar produtos para o Excel?

## O módulo "Exportação de Produtos" no Magis5 ERP foi desenvolvido para permitir a exportação dos produtos para o Excel, levando em consideração os filtros selecionados.

O módulo "Exportação de Produtos" no **Magis5 ERP** foi desenvolvido para permitir a exportação dos produtos para o Excel, levando em consideração os filtros selecionados. Essa funcionalidade é útil quando você deseja ter um arquivo contendo informações específicas dos produtos para análise, relatórios ou outros fins.

---

Na barra de menus, clique em: Cadastros → Exportação - Produtos:

![Imagem 1: Na barra de menus, clique em: Cadastros → Exportação - Produtos:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-51-1024x332.png)

Em “Filtro”, informe quais serão os campos utilizados para filtragem de produtos:

![Imagem 2: Em “Filtro”, informe quais serão os campos utilizados para filtragem de produtos:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-148-1024x293.png)

- **Palavra Chave:** Caso queira filtrar todos os produtos que contenham uma palavra no nome, insira-a neste campo. Por exemplo: Morango. Todos os produtos que tiverem “Morango” no nome serão exibidos;

- **Exportar Produtos:** Informe se os produtos importados serão “Com Estoque”, “Sem Estoque” ou “Ambos”;

- **Categoria:** Caso deseje que os produtos de uma única categoria sejam exportados, selecione neste campo;

- **Fabricante:** Caso deseje que os produtos de um único fabricante sejam exportados, selecione neste campo;

- **Campanha:** Caso deseje que os produtos de uma única campanha sejam exportados, selecione neste campo;

- **Depósito:** Selecione qual o depósito será exportados os produtos;

- **Enviar cópia por e-mail?** Caso deseje receber uma cópia do arquivo por e-mail, selecione “Sim”.

Observação: Não é necessário preencher todos os campos.

Após preencher os filtros desejados, clique em “Aplicar Filtro”.

No exemplo abaixo foi utilizado a união de dois filtros: “Categoria” (Creatina) e “Palavra Chave” (Monohydrate):

![Imagem 3: No exemplo abaixo foi utilizado a união de dois filtros: “Categoria” (Creatina) e “Palavra Chave” (Monohydrate):](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-149-1024x427.png)

Clicando em “Colunas p/ Exibir” é possível determinar quais serão as colunas que serão exibidas na exportação. Selecione-as clicando no checkbox:

![Imagem 4: Clicando em “Colunas p/ Exibir” é possível determinar quais serão as colunas que serão exibidas na exportação.…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-150-1024x367.png)

Após configurar todas as colunas e filtrar os produtos desejados, clique em “Exportar p/ Excel”:

![Imagem 5: Após configurar todas as colunas e filtrar os produtos desejados, clique em “Exportar p/ Excel”:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-152-1024x319.png)

Para visualizar os arquivos já gerados, clique em “Arquivos”. É possível baixá-los novamente:

![Imagem 6: Para visualizar os arquivos já gerados, clique em “Arquivos”. É possível baixá-los novamente:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-151-1024x390.png)
