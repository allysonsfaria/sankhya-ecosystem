# Como configurar uma nova situação especial?

## A situação especial dentro de um grupo é utilizada em situações em que é necessário aplicar uma tributação diferenciada com base na combinação específica de cliente e produto.

Ao configurar essa tributação especial, é possível estabelecer regras tributárias personalizadas que levam em consideração tanto o cliente quanto o produto envolvido na transação. Isso permite uma abordagem mais granular na determinação dos impostos a serem aplicados, levando em conta as particularidades de cada caso.

Essa configuração especial é útil em cenários onde certos clientes possuem condições tributárias diferenciadas para determinados produtos, como descontos específicos ou isenções fiscais. Ao considerar essa combinação cliente versus produto, o sistema é capaz de aplicar as regras tributárias corretas de forma precisa e automática.

---

Para criar uma nova situação especial, na barra de menus, clique em: Configurações → NF-e Situação Especial:

![Imagem 1: Para criar uma nova situação especial, na barra de menus, clique em: Configurações → NF-e Situação Especial:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-30-1024x382.png)

Em seguida, clique em “Nova Situação Especial”, insira o nome da regra, selecione o cliente e o produto e clique em incluir. Em Texto Legal, pode-se inserir um texto explicativo:
