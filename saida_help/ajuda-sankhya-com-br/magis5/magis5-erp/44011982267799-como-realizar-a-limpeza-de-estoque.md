# Como realizar a limpeza de estoque?

## O módulo "Limpeza de Estoque" é utilizado para a exclusão em massa de produtos do estoque de determinados depósitos.

Essa opção é útil quando há a necessidade de remover permanentemente os registros de produtos de um estoque específico, por motivos como produtos obsoletos, vencidos ou indisponíveis para venda.

No entanto, é importante ressaltar que o uso do módulo de "Limpeza de Estoque" requer extrema cautela, pois **todas as ações realizadas são irreversíveis**. Uma vez que os produtos são excluídos do estoque, não é possível recuperá-los posteriormente. Portanto, é fundamental ter certeza de que a exclusão em massa é realmente necessária e que todos os produtos a serem removidos estão corretamente identificados.

---

Para realizar este procedimento, na barra de menus, clique em: Suprimentos → Limpeza de Estoque:

![Imagem 1: Para realizar este procedimento, na barra de menus, clique em: Suprimentos → Limpeza de Estoque:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-13-1024x324.png)

Com a ajuda dos filtros, busque pelo depósito desejado, pelo produto ou fabricante:

![Imagem 2: Com a ajuda dos filtros, busque pelo depósito desejado, pelo produto ou fabricante:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-390-1024x255.png)

No exemplo abaixo, foi realizada uma busca por um depósito específico. Após aplicar o filtro desejado, os produtos que compõem o depósito serão exibidos:

![Imagem 3: No exemplo abaixo, foi realizada uma busca por um depósito específico. Após aplicar o filtro desejado, os produtos que…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-388-1024x396.png)

Para excluir o estoque dos produtos, clique no checkbox na linha correspondente ao produto desejado ou, caso queira limpar o estoque todo, em “Marcar Todos”. Após realizar a seleção, clique em “Excluir Selecionados”:

![Imagem 4: Para excluir o estoque dos produtos, clique no checkbox na linha correspondente ao produto desejado ou, caso queira…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-391-1024x482.png)

O estoque será limpo e os produtos ficarão com saldo zerado.

**Atenção: Uma vez excluídos, não possuímos backup dos produtos.**
