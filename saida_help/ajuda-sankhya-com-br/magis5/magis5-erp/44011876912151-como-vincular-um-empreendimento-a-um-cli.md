# Como vincular um empreendimento a um cliente

## Ao utilizar o módulo de reposição de lojas, um pedido é gerado em nome do empreendimento selecionado no momento da finalização da venda.

Ao utilizar o módulo de reposição de lojas, um pedido é gerado em nome do empreendimento selecionado no momento da finalização da venda. Este procedimento é essencial para garantir que o empreendimento recebedor dos produtos seja devidamente faturado.

### Exemplo Prático:

Imagine que você está logado no empreendimento "Artemis5 Distribuição" e deseja gerar uma reposição para o empreendimento "Artemis5 Varejo". Ao concluir o processo de reposição, o sistema lançará automaticamente um pedido para o cliente "Artemis5 Varejo". Isso ocorre porque "Artemis Varejo" é o empreendimento que receberá os produtos e, consequentemente, arcará com os custos dos itens enviados.

Para que esse processo ocorra corretamente, é necessário cadastrar o empreendimento destinatário (neste caso, "Artemis5 Varejo") como um cliente no sistema. Em seguida, é fundamental informar a qual empreendimento esse cadastro pertence, garantindo que o pedido seja gerado de forma precisa e que a transação seja realizada sem contratempos.

---

Para cadastrar um novo cliente, na barra de menus, clique em: Cadastros → Clientes:

![Imagem 1: Para cadastrar um novo cliente, na barra de menus, clique em: Cadastros → Clientes:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/06/image-11-1024x133.png)

No módulo Clientes, clique em: Cadastrar Novo:

![Imagem 2: No módulo Clientes, clique em: Cadastrar Novo:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-99-1024x153.png)

**INFORMAÇÕES BÁSICAS**

![Imagem 3: INFORMAÇÕES BÁSICAS](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-100-1024x194.png)

- **Tipo de Cadastro**: Selecione "Pessoa Jurídica";

- **Cadastro Aprovado**: Selecione "Sim";

- **Tipo de Cliente**: Selecione "Loja física";

- **Tornar esse Cliente um Usuário**: Selecione "Não";

Após preencher os campos acima, prossiga com as informações solicitadas:

![Imagem 4: Após preencher os campos acima, prossiga com as informações solicitadas:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-101.png)

- **CPF** **ou CNPJ**: Insira o CNPJ do empreendimento destinatário;

- **RG ou IE**: Insira a Inscrição Estadual do empreendimento destinatário;

- **R.E ou I.M:** Preenchimento optativo. Caso possua, preencha a Inscrição Municipal do empreendimento destinatário;

- **Razão Social**: Insira a razão social do empreendimento;

- **Nome Fantasia**: Insira o nome fantasia do empreendimento ;

- **Dados de Contato**: Informe os telefones e e-mail de contato;

- **Endereço Principal**: Informe o endereço do cliente.

![Imagem 5: Endereço Principal : Informe o endereço do cliente.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-102-1024x139.png)

**INFORMAÇÕES COMPLEMENTARES**

O preenchimento das informações deste campo complementarão o cadastro do cliente:

![Imagem 6: O preenchimento das informações deste campo complementarão o cadastro do cliente:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-104-1024x460.png)

Para este tipo de cadastro, todos os campos nesta aba são opcionais, exceto o campo "**Empreendimento/Cliente**". Neste campo, deve-se realizar o vínculo do cliente ao empreendimento correspondente. Para isso, informe o empreendimento ao qual o cliente se refere. Por exemplo, no caso mencionado na introdução, o empreendimento "Artemis5 - Varejo" corresponde ao ID 398. Portanto, neste campo, deve-se inserir o número 398, referenciando o empreendimento corretamente.

![Imagem 7: Para este tipo de cadastro, todos os campos nesta aba são opcionais, exceto o campo " Empreendimento/Cliente ". Neste…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2024/07/image.png)

No empreendimento de cadastro, só é possível ter um cliente com o ID do empreendimento destinatário.

**EMPREENDIMENTOS**

Não é recomendado o compartilhamento do cadastro deste cliente para outros empreendimentos. Neste caso, é recomendado que cada empreendimento tenha seu próprio cadastro.

![Imagem 8: Não é recomendado o compartilhamento do cadastro deste cliente para outros empreendimentos. Neste caso, é recomendado…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2024/07/image-1.png)

É necessário informar qual será o perfil que este cliente/empreendimento terá no empreendimento logado. Cada perfil corresponde a uma tabela de preço.

**DADOS FISCAIS**

Não é necessário o preenchimento.

Após finalizar os dados, basta clicar em salvar e o cadastro estará realizado.
