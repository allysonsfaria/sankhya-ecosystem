# Complemento destinatário é muito longo (não mais do que 60 caracteres)

## Este erro indica que o complemento do endereço do destinatário fornecido na NF-e excede o limite de 60 caracteres (incluindo espaços) estabelecido pelas normas fiscais.

Para resolver esse erro, você pode considerar as seguintes etapas:

**REDUZA O COMPLEMENTO DO ENDEREÇO DO CLIENTE**

Verifique complemento do endereço do cliente na NF-e e, se for muito longo, reduza-o para que não exceda os 60 caracteres, incluindo espaços. Isso pode envolver a abreviação de partes do nome, caso necessário.

O primeiro passo para essa validação é acessar o cadastro do cliente. Para isso, clique em: Menu → Cadastros → Clientes, insira o nome do cliente no campo de buscas e clique em: Aplicar Filtro:

![Imagem 1: O primeiro passo para essa validação é acessar o cadastro do cliente. Para isso, clique em: Menu → Cadastros →…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-21.png)

Clique em: Editar:

![Imagem 2: Clique em: Editar:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-22-1024x367.png)

Em "Endereço Principal", identifique o complemento do endereço do cliente:

![Imagem 3: Em "Endereço Principal", identifique o complemento do endereço do cliente:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-23-1024x291.png)

Agora, para facilitar, utilizando um [contador de caracteres](https://meuredator.com.br/contador-de-palavras/), veja quantos caracteres o complemento contém:

![Imagem 4: Agora, para facilitar, utilizando um contador de caracteres , veja quantos caracteres o complemento contém:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-80-1024x175.png)

Apague (ou abrevie) partes do complemento para que atinja menos de 60 caracteres:

![Imagem 5: Apague (ou abrevie) partes do complemento para que atinja menos de 60 caracteres:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-81.png)

Feito isso, altere-o no cadastro do cliente e clique em: Salvar:

![Imagem 6: Feito isso, altere-o no cadastro do cliente e clique em: Salvar:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-26-1024x373.png)

**CORRIJA O ENDEREÇO DO CLIENTE NA VENDA**

Após a adequação do complemento do endereço, é necessário "informar" para o Artemis5 que o problema foi corrigido.

Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:

![Imagem 7: Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-27-1024x85.png)

Selecione "Endereço Principal" e clique em: Salvar.

![Imagem 8: Selecione "Endereço Principal" e clique em: Salvar.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-13-1024x387.png)

Aguarde aproximadamente cinco minutos para a venda ser reprocessada e faturada.

Atenção: **Mantenha a informação precisa:** Certifique-se de que, mesmo ao reduzir o complemento, a informação permaneça precisa e identificável. O complemento deve ainda ser capaz de identificar claramente o endereço da nota fiscal.
