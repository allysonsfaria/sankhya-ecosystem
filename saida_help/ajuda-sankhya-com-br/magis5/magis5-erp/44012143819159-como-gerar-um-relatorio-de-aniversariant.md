# Como gerar um relatório de aniversariantes do mês?

## O relatório de aniversariantes do mês é uma ferramenta útil para identificar e acompanhar os aniversariantes dentro de um determinado mês.

Seu principal objetivo é fornecer uma lista completa e organizada dos colaboradores e clientes que estão comemorando seus aniversários durante esse período.

Além disso, o relatório de aniversariantes do mês oferece a opção de exportar os dados para o Excel, o que permite uma maior flexibilidade no gerenciamento dessas informações. Com a exportação para o Excel, você pode personalizar ainda mais os dados, realizar análises adicionais e utilizá-los de acordo com as necessidades específicas do seu empreendimento.

---

Para gerar um Relatório de Aniversariantes, na barra de menus, clique em: Relatórios → Relatórios Padrão:

![Imagem 1: Para gerar um Relatório de Aniversariantes, na barra de menus, clique em: Relatórios → Relatórios Padrão:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-71-1024x143.png)

Na coluna “Relatórios Financeiros”, clique em “Aniversariantes”:

![Imagem 2: Na coluna “Relatórios Financeiros”, clique em “Aniversariantes”:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-112-1024x201.png)

No exemplo abaixo, o mês da consulta do relatório é janeiro, logo, o **Artemis5** traz todos os usuário cadastrados na plataforma cujo aniversário é no mês correspondente:

![Imagem 3: No exemplo abaixo, o mês da consulta do relatório é janeiro, logo, o Artemis5 traz todos os usuário cadastrados na…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-761-1024x403.png)

Para exportar esses dados para o Excel, basta clicar em “Exportar p/ Excel” e o relatório será baixado.

Observação: Para que seja exibido o cliente e a data de nascimento, é preciso que o campo “Data de Nascimento” esteja preenchido no cadastro do cliente.
