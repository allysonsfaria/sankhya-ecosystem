# Como localizar um inventário?

## Com o auxílio dos filtros, é possível utilizar diversos critérios de filtragem para encontrar um inventário específico, personalizando a pesquisa de acordo com as necessidades do seu empreendimento.

Um dos filtros disponíveis é a busca por data, que permite selecionar um período específico para identificar inventários realizados nesse intervalo de tempo. Isso facilita a localização de inventários passados e a análise do histórico de contagens de estoque.

---

Para acessar o módulo “Inventário”, na barra de menus, clique em: Suprimentos → Inventário:

![Imagem 1: Para acessar o módulo “Inventário”, na barra de menus, clique em: Suprimentos → Inventário:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-118-1024x300.png)

Com a ajuda dos filtros, preencha os dados desejados:

![Imagem 2: Com a ajuda dos filtros, preencha os dados desejados:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-380-1024x145.png)

Após localizar o inventário desejado, clique no botão “Visualizar Inventário” para verificar os itens inventariados.

![Imagem 3: Após localizar o inventário desejado, clique no botão “Visualizar Inventário” para verificar os itens inventariados.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-381-1024x191.png)

Na listagem de inventário é possível verificar qual a quantidade anterior do item, a diferença atual e o quanto isso difere em preço de custo, por exemplo:

![Imagem 4: Na listagem de inventário é possível verificar qual a quantidade anterior do item, a diferença atual e o quanto isso…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-382-1024x196.png)

Observação: Se no empreendimento tiver dois produtos reservados, ao realizar a atualização do estoque pelo inventário, esses dois produtos serão descontados da quantidade final. Por exemplo: Foi dado entrada de 10 itens, porém, 2 estão reservados. A disponibilidade será de 8 itens.
