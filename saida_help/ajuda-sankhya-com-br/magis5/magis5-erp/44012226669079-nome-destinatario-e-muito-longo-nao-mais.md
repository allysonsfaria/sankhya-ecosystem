# Nome destinatário é muito longo (não mais do que 60 caracteres)

## Este erro indica que o nome do destinatário fornecido na NF-e excede o limite de 60 caracteres (incluindo espaços) estabelecido pelas normas fiscais.

Para resolver esse erro, você pode considerar as seguintes etapas:

- **Reduza o nome do cliente:** Verifique o nome do cliente na NF-e e, se for muito longo, reduza-o para que não exceda os 60 caracteres, incluindo espaços. Isso pode envolver a abreviação de partes do nome, caso necessário.

O primeiro passo para essa validação é acessar o cadastro do cliente. Para isso, clique em: Menu → Cadastros → Clientes, insira o nome do cliente no campo de buscas e clique em: Aplicar Filtro:

![Imagem 1: O primeiro passo para essa validação é acessar o cadastro do cliente. Para isso, clique em: Menu → Cadastros →…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-14.png)

Clique em: Editar:

![Imagem 2: Clique em: Editar:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-15-1024x309.png)

Em "Informações Principais", identifique a razão social e nome fantasia (caso PJ) ou nome do cliente (caso PF):

![Imagem 3: Em "Informações Principais", identifique a razão social e nome fantasia (caso PJ) ou nome do cliente (caso PF):](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-16-1024x215.png)

Agora, para facilitar, utilizando um [contador de caracteres](https://meuredator.com.br/contador-de-palavras/), veja quantos caracteres o nome contém:

![Imagem 4: Agora, para facilitar, utilizando um contador de caracteres , veja quantos caracteres o nome contém:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-82.png)

Apague (ou abrevie) partes do nome para que atinja menos de 60 caracteres:

![Imagem 5: Apague (ou abrevie) partes do nome para que atinja menos de 60 caracteres:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-83.png)

Feito isso, altere-o no cadastro do cliente e clique em: Salvar:

![Imagem 6: Feito isso, altere-o no cadastro do cliente e clique em: Salvar:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-19-1024x98.png)

**CORRIJA O ENDEREÇO DO CLIENTE NA VENDA**

Após a adequação do nome do cliente, é necessário "informar" para o Artemis5 que o nome está corrigido.

Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:

![Imagem 7: Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-20-1024x95.png)

Selecione "Endereço Principal" e clique em: Salvar.

![Imagem 8: Selecione "Endereço Principal" e clique em: Salvar.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-13-1024x387.png)

Aguarde aproximadamente cinco minutos para a venda ser reprocessada e faturada.

Atenção: **Mantenha a informação precisa:** Certifique-se de que, mesmo ao reduzir o nome, a informação permaneça precisa e identificável. O nome deve ainda ser capaz de identificar claramente o destinatário da nota fiscal.
