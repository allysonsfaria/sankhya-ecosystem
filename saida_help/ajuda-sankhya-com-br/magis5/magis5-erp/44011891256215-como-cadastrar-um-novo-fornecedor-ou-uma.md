# Como cadastrar um novo fornecedor ou uma nova transportadora?

## O módulo "Fornecedores / Transportadoras" é utilizado para o cadastro e controle de todos os fornecedores e/ou transportadoras do empreendimento.

É essencial ter os fornecedores cadastrados, pois ao registrar uma despesa no lançamento financeiro, é necessário selecionar o fornecedor correspondente. Este recurso permite que você registre todas as informações relevantes de cada fornecedor, como nome, endereço, contato, informações fiscais e outros detalhes pertinentes. Isso garante que todas as despesas relacionadas a esses fornecedores possam ser adequadamente categorizadas e rastreadas dentro do sistema.

É importante ressaltar que o conceito de "fornecedores" no **Artemis5** não se limita apenas a entidades comerciais tradicionais. Ele abrange uma ampla gama de despesas, incluindo pagamentos a funcionários, contas de serviços públicos, aluguel e outros tipos de despesas que envolvem terceiros. Ao agrupar todas essas despesas sob o módulo de fornecedores, você pode ter um controle abrangente de todos os gastos do empreendimento.

Em contrapartida, as transportadoras são obrigatórias para a emissão de notas fiscais, uma vez que cada veículo e cada viagem precisarão garantir a chegada correta das mercadorias ao destino. Além disso, é possível proporcionar uma gestão fiscal mais assertiva para a economia do negócio

Por outro lado, quando se trata de receitas, o **Artemis5** utiliza o módulo de "Cadastro de Clientes (Clientes/Usuários)" para diferenciar e gerenciar as informações relacionadas a receitas. O cadastro de clientes é utilizado para registrar e controlar todos os clientes ou usuários do empreendimento que geram receitas por meio de suas transações. Isso permite que você tenha uma visão clara das receitas geradas por cada cliente e facilite a geração de relatórios financeiros precisos.

Para realizar o cadastro de um novo fornecedor ou uma nova transportadora, na barra de menus, clique em: Cadastros → Fornecedores / Transportadoras:

![Imagem 1: Para realizar o cadastro de um novo fornecedor ou uma nova transportadora, na barra de menus, clique em: Cadastros →…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-1024x180.png)

No módulo "Fornecedores" preencha as informações solicitadas:

![Imagem 2: No módulo "Fornecedores" preencha as informações solicitadas:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-360.png)

Observação: Para cadastro de transportadora, é obrigatório o preenchimento da Razão Social, CNPJ, IE e Endereço.

Em "Contas a Pagar/Receber" informe, em "Natureza Padrão" para classificação do plano de contas para o lançamento financeiro (caso deseje cadastrar uma nova Natureza Padrão, [siga esses passos](https://ajuda.artemis5.com.br/como-configurar-um-plano-de-contas/)).

![Imagem 3: Em "Contas a Pagar/Receber" informe, em "Natureza Padrão" para classificação do plano de contas para o lançamento…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-361.png)

**ID Empreendimento Ref.** é utilizado para informar em qual empreendimento será realizada a consulta de produtos em uma reposição de lojas. Para isso, insira o ID do empreendimento a qual este fornecedor se refere. Por exemplo: Se a consulta de estoque for no empreendimento 339, insira o número 339 neste campo.

Após preencher todos os dados solicitados em "Produtos", clique na aba "Empreendimentos".

É possível compartilhar este cadastro com outros empreendimentos clicando em "(+) Incluir". Após selecionar os empreendimentos desejados, clique em "Salvar".

![Imagem 4: É possível compartilhar este cadastro com outros empreendimentos clicando em "(+) Incluir". Após selecionar os…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-363.png)

Observação: Caso esteja realizando um lançamento financeiro, é possível criar um cadastro rápido de fornecedores para não parar o processo no meio do procedimento.
