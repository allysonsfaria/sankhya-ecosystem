# Integrações - Correios

## Integrações - Correios

**SIGEP WEB**

Para realizar a integração de sistemas com o Web Services SIGEP Web, o cliente necessita ter contrato com os Correios. Nesse caso, poderá solicitar ao representante comercial dos Correios a autorização de acesso (usuário e senha) para o contrato e cartão de postagem (mesmo CNPJ).

- **Ambiente:** O “Ambiente de Homologação'' é um ambiente de testes, usado durante a integração. O “Ambiente de Produção'' é o ambiente real, onde a integração já está concluída e pronta para uso.

- **Cód. Administrativo:** É o Código Administrativo do contrato do Cliente com os Correios;

- **Serviço Padrão:** Após a inserção do número do contrato, os serviços contratados são exibidos neste campo;

- **Nº Contrato:** É o número do contrato junto aos Correios;

- **Usuário:** É o login do usuário para autenticação. (Fornecido pelo Representante Comercial dos Correios mediante carta de solicitação.);

- **Senha:** É a senha de autenticação. (Fornecida pelo Representante Comercial dos Correios mediante carta de solicitação);

- **Cartão:** É o cartão de postagem vinculado ao contrato;

- **Cod. Diretoria:** É o número da Diretoria Regional do contrato do cliente;

- **Altura Padrão:** É a altura padrão utilizada no pacote para cotação;

- **Largura Padrão:** É a largura padrão utilizada no pacote para cotação;

- **Comprimento Padrão:** É o comprimento padrão utilizado no pacote para cotação;

- **Diâmetro Padrão:** É o diâmetro padrão utilizado no pacote para cotação;

- **Pacotes:** Insira neste campo uma lista com modelos de embalagens disponíveis para ser utilizadas nas cotações. Caso não haja nenhum outro pacote configurado, serão utilizadas as medidas padrão informadas acima;

- **Gerar Etiquetas:** Para gerar um estoque de etiquetas, informe qual serviço será utilizado bem como a quantidade de etiquetas que serão geradas.

**SRO**
Utilizado para rastreamento de objetos

- **Ambiente:** O “Ambiente de Homologação'' é um ambiente de testes, usado durante a integração. O “Ambiente de Produção'' é o ambiente real, onde a integração já está concluída e pronta para uso.

- **Usuário:** É o login do usuário para autenticação. (Fornecido pelo Representante Comercial dos Correios mediante carta de solicitação.)

- **Senha:** É a senha de autenticação. (Fornecida pelo Representante Comercial dos Correios mediante carta de solicitação)
