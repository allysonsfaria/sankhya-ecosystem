# Como realizar uma baixa manual no estoque?

## O módulo de "Baixa Manual" é utilizado para registrar a retirada de produtos do estoque de forma manual, sem a necessidade de uma venda registrada.

Essa opção é útil em situações específicas em que é preciso indicar um motivo para essa ação, como perdas, quebras, amostras grátis, doações ou qualquer outra circunstância que justifique a saída dos produtos do estoque.

Antes de realizar uma “Baixa Manual” é preciso configurar os motivos antecipadamente. Para isso, [clique aqui](https://ajuda.artemis5.com.br/estoque/) e veja quais os procedimentos

---

Com os motivos configurados, na barra de menus, clique em: Suprimentos → Baixa Manual:

![Imagem 1: Com os motivos configurados, na barra de menus, clique em: Suprimentos → Baixa Manual:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-14-1024x278.png)

Para realizar uma nova baixa, clique aqui:

![Imagem 2: Para realizar uma nova baixa, clique aqui:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-384-1024x109.png)

Em seguida, informe os seguintes dados:

![Imagem 3: Em seguida, informe os seguintes dados:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-385-1024x367.png)

- **Usuário Responsável:** Usuário responsável pelo registro;

- **Depósito**: Depósito que este produto está localizado;

- **Motivo:** Motivo pelo qual está realizando a baixa do(s) produto(s).

Caso queira inserir alguma informação, utilize o campo “Descrição”.

Em “Produtos”, clique em (+) para selecionar quais produtos farão parte desta baixa:

![Imagem 4: Em “Produtos”, clique em (+) para selecionar quais produtos farão parte desta baixa:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-387-1024x455.png)

É possível informar a quantidade no campo “Qtd Saída” ou, pode-se clicar em “Selecionar” e informar a quantidade de itens removidos na listagem de produtos:

![Imagem 5: É possível informar a quantidade no campo “Qtd Saída” ou, pode-se clicar em “Selecionar” e informar a quantidade de…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-386-1024x146.png)

Após finalizar a inserção dos produtos, clique em “Salvar”.
