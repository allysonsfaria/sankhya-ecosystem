# Como importar uma planilha de Plano de Contas?

## Neste tutorial, você aprenderá a formatar sua planilha de plano de contas para importá-la com sucesso no Magis5 ERP.

#### Passo 1: Preparando a Planilha

### 1.1 Estrutura da Planilha

- **Coluna A**: ID Empreendimento
- **Coluna B**: Código
- **Coluna C**: Descrição
- **Coluna D**: Tipo Lançamento
- **Coluna E**: ID Modelo DRE
- **Coluna F**: Código Plano PAI

![Imagem 1: Coluna F : Código Plano PAI](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2024/08/image-3.png)

### 1.2 Formato dos Dados

Certifique-se de que cada coluna contenha apenas os dados correspondentes:

- **ID Empreendimento:** ID do empreendimento de cadastro (inserir apenas um empreendimento por planilha)
- **Código**: Deve ser o número identificador do Plano de Contas (exemplo: 1000.01)
- **Descrição:** Nome do Plano de Contas
- **Tipo Lançamento:** Não Preencher
- **ID Modelo DRE:** Não Preencher
- **Código Plano PAI:** Caso o Plano de Contas seja um 'filho", deve-se informar o ID do plano de contas Pai:

![Imagem 2: Código Plano PAI: Caso o Plano de Contas seja um 'filho", deve-se informar o ID do plano de contas Pai:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2024/08/image-4.png)

#### Passo 2: Salvando a Planilha

Após organizar e revisar os dados, salve a planilha no formato **XLSX**:

1. Clique em **Arquivo**.
2. Selecione **Salvar Como**.
3. Escolha o formato **XLSX.**
4. Nomeie o arquivo e clique em **Salvar.**

#### Dicas Adicionais

- Quantidade média de itens por planilha: 20 mil
