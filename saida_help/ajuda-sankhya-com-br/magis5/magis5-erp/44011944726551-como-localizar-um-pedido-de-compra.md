# Como localizar um pedido de compra?

## Os filtros dos pedidos realizados são utilizados para localizar os pedidos de compra realizados no Magis5 ERP, tanto aqueles feitos manualmente quanto por meio do módulo de sugestão de compras.

Com esses filtros, você tem a capacidade de refinar sua pesquisa e encontrar rapidamente os pedidos específicos que precisa analisar ou gerenciar. Você pode aplicar diferentes critérios de filtragem para segmentar os pedidos com base em diversas características, como data de realização, status do pedido, fornecedor, categoria de produtos, valor total e muito mais.

---

Para localizar um pedido de compras, na barra de menus, clique em: Suprimentos → Pedido de Compras:

![Imagem 1: Para localizar um pedido de compras, na barra de menus, clique em: Suprimentos → Pedido de Compras:](https://ajuda.sankhya.com.br/hc/article_attachments/44011962354967)

É possível utilizar os filtros de forma individual ou criando uma combinação entre eles:

![Imagem 2: É possível utilizar os filtros de forma individual ou criando uma combinação entre eles:](https://ajuda.sankhya.com.br/hc/article_attachments/44011945082263)

- Data Inicial + Data Final + Fornecedor (trará todos os pedidos realizados no período informado de um determinado fornecedor);
- Data Inicial + Responsável (trará todos os pedidos a partir da data informada realizada pelo usuário selecionado);
- Data Prevista + Fornecedor + Responsável (trará todos os pedidos de um determinado fornecedor com a data prevista informada realizados pelo usuário selecionado).

Entre outras combinações...
