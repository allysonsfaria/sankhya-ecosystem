# Integrações - Zenvia

Para realizar a integração junto ao Zenvia, informe:

- **Ambiente de Envio**: O “Ambiente de Homologação'' é um ambiente de testes, usado durante a integração. O “Ambiente de Produção'' é o ambiente real, onde a integração já está concluída e pronta para uso;

- **API Token Development:** Informe o código do Token API fornecido pelo Zenvia;

- **Sender Number Development:** Informe o número do remetente para envio de mensagens.
