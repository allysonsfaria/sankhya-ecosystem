# Logradouro destinatario é muito curto (não menos do que 2 caracteres)

## Este erro significa que o endereço (logradouro) do destinatário da NF-e foi preenchido com um valor que tem menos de 2 caracteres.

Para resolver esse erro, você pode considerar as seguintes etapas:

**CORRIJA O LOGRADOURO DO ENDEREÇO DO CLIENTE**

Verifique o logradouro do endereço do cliente na NF-e e, se tiver menos que dois caracteres, será necessário editar o cadastro do cliente para inserir mais informações.

O primeiro passo para essa validação é acessar o cadastro do cliente. Para isso, clique em: Menu → Cadastros → Clientes, insira o nome do cliente no campo de buscas, clique em: Aplicar Filtro e em seguida, em "Editar":

![Imagem 1: O primeiro passo para essa validação é acessar o cadastro do cliente. Para isso, clique em: Menu → Cadastros →…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-16-1024x230.png)

Em "Endereço Principal", identifique o logradouro do endereço do cliente:

![Imagem 2: Em "Endereço Principal", identifique o logradouro do endereço do cliente:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-19-1024x218.png)

Altere o endereço do cliente inserindo alguma informação complementar, por exemplo, antes era apenas "C", inserimos "Rua C":

![Imagem 3: Altere o endereço do cliente inserindo alguma informação complementar, por exemplo, antes era apenas "C", inserimos…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-20-1024x220.png)

**CORRIJA O ENDEREÇO DO CLIENTE NA VENDA**

Após a adequação do endereço, é necessário "informar" para o Artemis5 que o problema foi corrigido.

Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:

![Imagem 4: Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-21-1024x107.png)

Selecione "Endereço Principal" e clique em: Salvar.

![Imagem 5: Selecione "Endereço Principal" e clique em: Salvar.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-23.png)

Aguarde aproximadamente cinco minutos para a venda ser reprocessada e faturada.

Atenção: **Mantenha a informação precisa:** Certifique-se de que, mesmo após alterar o endereço, a informação permaneça precisa e identificável.
