# Como configurar uma nova especialização NCM?

O NCM (Nomenclatura Comum do Mercosul) é um código utilizado para identificar e classificar produtos em âmbito internacional. No **Magis5 ERP**, a utilização do NCM em produtos raros permite uma especificação diferenciada em relação à tributação.

Quando um produto é considerado raro ou possui características específicas que requerem uma tributação especial, o código NCM associado a esse produto pode ser utilizado para indicar as particularidades tributárias relacionadas a ele. Essa especificação diferenciada no NCM permite que o sistema aplique corretamente as regras tributárias específicas ao realizar vendas, emitir documentos fiscais e calcular os impostos correspondentes.

---

Para configurar uma nova Especialização NCM, na barra de menus, clique em: Configurações → NF-e - Especialização NCM:

![Imagem 1: Para configurar uma nova Especialização NCM, na barra de menus, clique em: Configurações → NF-e - Especialização NCM:](https://ajuda.sankhya.com.br/hc/article_attachments/44012186730135)

Para criar uma nova regra, clique em “Nova Especialização NCM”:

![Imagem 2: Para criar uma nova regra, clique em “Nova Especialização NCM”:](https://ajuda.sankhya.com.br/hc/article_attachments/44012211843735)

Dê um nome à essa especialização, informe qual o NCM e em EX Tipi, o código que será utilizado. Após finalizar o preenchimento, clique em Salvar.

**EX TIPI** (Exceção da Tabela do IPI): É um número utilizado para identificar produtos que possuem uma alíquota de Imposto sobre Produtos Industrializados (IPI) diferente daquela estabelecida na tabela para a classificação fiscal dos demais produtos. Essas exceções podem resultar em uma alíquota maior ou menor do que a prevista para a respectiva classificação fiscal.
No contexto do **Magis5 ERP**, o uso do EX TIPI permite uma especificação diferenciada da alíquota de IPI aplicável a determinados produtos. Essa diferenciação ocorre quando esses produtos são enquadrados em uma categoria específica de classificação fiscal, que possui uma alíquota de IPI diferente daquela estabelecida para a classificação fiscal geral.

Ao associar o EX TIPI a um produto, o sistema reconhece a exceção aplicável e aplica a alíquota de IPI correspondente durante as operações comerciais que envolvem esse produto. Isso garante o cumprimento correto das obrigações fiscais relacionadas ao IPI e evita erros na tributação.
