# Como configurar uma nova regra de tributos (NFS-e)?

## A regra de tributos (NFS-e) é utilizada para a criação de regras de tributação específicas para a prestação de serviços.

A regra de tributos (NFS-e) é utilizada para a criação de regras de tributação específicas para a prestação de serviços. Essa funcionalidade é especialmente útil quando se trata da tributação de serviços prestados em diferentes cidades ou estados. Embora o "Cód. Serviço Municipal" possa ser o mesmo, a tributação pode variar de acordo com a localidade.

Ao configurar uma regra de tributos para NFS-e, é possível definir as alíquotas e os impostos específicos que se aplicam a determinado serviço em cada cidade. Essas regras são criadas com base nos parâmetros tributários estabelecidos pelos órgãos municipais e estaduais competentes.

---

Para criar uma nova regra, na barra de menus, clique em: Configurações → NFS-e - Regras de Serviços:

![Imagem 2: Para criar uma nova regra, na barra de menus, clique em: Configurações → NFS-e - Regras de Serviços:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-31-1024x426.png)

Clique em "Nova Regra":

![Imagem 3: Clique em "Nova Regra":](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-903-1024x104.png)

Insira o nome da Regra, bem como o estado e município a qual essa regra irá abranger e preencha os dados referente à regra. Após preencher todas as informações, clique em "Salvar".
