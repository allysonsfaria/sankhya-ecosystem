# Como gerar um pedido de compras manual?

## Existem duas opções para realizar pedidos de compra. A primeira é por meio do módulo de "Sugestão de Compras", que utiliza informações das vendas realizadas para sugerir a quantidade de itens a serem adquiridos dos produtos selecionados.

No **Artemis5**, existem duas opções para realizar pedidos de compra. A primeira é por meio do módulo de "Sugestão de Compras", que utiliza informações das vendas realizadas para sugerir a quantidade de itens a serem adquiridos dos produtos selecionados. Essa opção automatizada leva em consideração o histórico de vendas, o estoque disponível e o tempo médio de recebimento dos produtos dos fornecedores (leadtime).

Essa funcionalidade de Sugestão de Compras é extremamente útil, pois ajuda a otimizar o processo de reposição de estoque, evitando excessos ou faltas de produtos. Com base nas informações fornecidas, o sistema oferece uma visão clara das movimentações dos produtos no período determinado, indicando a quantidade sugerida para atender à demanda durante o mesmo período. Para saber mais, [clique aqui](https://ajuda.artemis5.com.br/como-utilizar-o-sugestao-de-compras/)

A segunda opção é o método manual, no qual o usuário pode selecionar individualmente os itens e especificar a quantidade desejada para cada um. Essa abordagem é mais flexível e permite uma intervenção direta no processo de compra, sendo útil em situações específicas em que é necessário ajustar as quantidades de acordo com circunstâncias particulares, como promoções, demanda sazonal ou informações específicas do mercado.

---

Para realizar um pedido de compras manual, na barra de menus, clique em: Suprimentos → Pedido de Compras:

![Imagem 1: Para realizar um pedido de compras manual, na barra de menus, clique em: Suprimentos → Pedido de Compras:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/06/image-15-1024x159.png)

Clique em "Novo Pedido":

![Imagem 2: Clique em "Novo Pedido":](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-425-1024x287.png)

Clique no botão apontado pela seta abaixo e selecione qual será o fornecedor:

![Imagem 3: Clique no botão apontado pela seta abaixo e selecione qual será o fornecedor:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-426-1024x265.png)

Na lista de fornecedores, clique em “Selecionar” no fornecedor desejado e veja se ele será exibido no campo “Fornecedor”:

![Imagem 4: Na lista de fornecedores, clique em “Selecionar” no fornecedor desejado e veja se ele será exibido no campo…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-427-1024x297.png)

Para exibir os produtos deste fornecedor, clique em “Adicionar Produtos”:

![Imagem 5: Para exibir os produtos deste fornecedor, clique em “Adicionar Produtos”:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-428-1024x266.png)

Uma listagem com os produtos será exibida. Clique em “Selecionar” para selecionar quais produtos serão incluídos no pedido:

![Imagem 6: Uma listagem com os produtos será exibida. Clique em “Selecionar” para selecionar quais produtos serão incluídos no…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-429-1024x394.png)

Após selecionar todos os produtos, informe a quantidade de cada item que irá pedir em “Quantidade” e clique em “Salvar”:

![Imagem 7: Após selecionar todos os produtos, informe a quantidade de cada item que irá pedir em “Quantidade” e clique em “Salvar”:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-430-1024x301.png)

Prontinho! O pedido foi realizado com sucesso!

![Imagem 8: Prontinho! O pedido foi realizado com sucesso!](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-431-1024x147.png)
