# Como localizar uma nota fiscal eletrônica (NF-e) emitida?

Para localizar uma nota fiscal emitida, na barra de menus, clique em: Vendas → Notas Fiscais:

![Imagem 1: Para localizar uma nota fiscal emitida, na barra de menus, clique em: Vendas → Notas Fiscais:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-45-1024x182.png)

Com a ajuda dos filtros, localize a Nota Fiscal desejada.

No exemplo abaixo, foram utilizados os filtros “De” e  “Até”, para que fossem exibidas todas as notas fiscais emitidas em um determinado período:

![Imagem 2: No exemplo abaixo, foram utilizados os filtros “De” e “Até”, para que fossem exibidas todas as notas fiscais emitidas…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-591-1024x565.png)

O campo de exibição de Notas Fiscais possui abas e sub-abas, onde é possível utilizá-los para filtrar e localizar as notas:

![Imagem 3: O campo de exibição de Notas Fiscais possui abas e sub-abas, onde é possível utilizá-los para filtrar e localizar as…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-592-1024x326.png)

As abas:

- **NF-e:** São exibidas todas as Notas Fiscais Eletrônicas;

- **NFS-e:** São exibidas todas as Notas Fiscais de Serviço Eletrônicas;

- **SAT:** São exibidas todas as Notas Fiscais emitidas pelo SAT;

- **NFC-e:** São exibidas todas as Notas Fiscais de Consumidor Eletrônica;

As sub-abas:

- **Emitidas:** Exibe todas as notas fiscais emitidas;

- **Canceladas:** Exibe todas as notas fiscais canceladas;

- **Inutilizadas:** Exibe todas as notas fiscais inutilizadas;

- **Romaneios:** Exibe todos os romaneios gerados.

Na imagem acima, está selecionado “NF-e” e “Emitidas”, consequente, serão exibidas todas as notas fiscais eletrônicas emitidas.
