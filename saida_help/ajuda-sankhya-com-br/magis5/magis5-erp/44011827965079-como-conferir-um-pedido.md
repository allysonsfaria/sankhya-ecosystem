# Como conferir um pedido?

## A conferência de pedidos é uma etapa fundamental que ocorre após a separação dos itens por meio do romaneio de separação.

Esse processo tem como objetivo verificar e confirmar os itens que foram faturados, garantindo a precisão e a qualidade no processo de expedição.

Existem três maneiras de localizar os pedidos que estão aguardando conferência:

1. Busca manual pelo ID do pedido: Nessa opção, é possível inserir o ID do pedido diretamente na ferramenta de busca, o que permite localizá-lo de forma rápida e direta. Assim que o ID do pedido é inserido, a tela correspondente será exibida, facilitando a conferência dos itens.
2. Utilizando o romaneio de separação: O romaneio de separação também oferece a opção de localizar os pedidos que estão aguardando conferência. Ao acessar o romaneio, você poderá identificar imediatamente os pedidos que precisam ser conferidos.
3. Utilizando filtros selecionados: Através das opções de filtros disponíveis, é possível definir critérios específicos para encontrar os pedidos que aguardam conferência. Isso permite uma busca mais refinada, considerando diferentes parâmetros, como data do pedido, status, clientes específicos, entre outros. Dessa forma, é possível encontrar os pedidos de forma precisa, de acordo com as preferências e necessidades do processo de conferência.
