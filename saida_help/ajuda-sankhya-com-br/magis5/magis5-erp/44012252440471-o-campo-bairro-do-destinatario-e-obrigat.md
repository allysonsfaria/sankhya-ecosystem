# O campo bairro do destinatário é obrigatório

## Este erro indica que, de acordo com as normas e regulamentos fiscais, é necessário fornecer o nome do bairro do destinatário da NF-e. Este é um requisito importante para garantir que a NF-e esteja completa e em conformidade com as exigências legais.

Para resolver esse erro, você pode considerar as seguintes etapas:

**VERIFIQUE OS DADOS DO CLIENTE**

Certifique-se de que os dados do cliente, incluindo o campo "bairro", estejam preenchidos corretamente na NF-e. Verifique se não há erros de digitação ou informações em falta.

O primeiro passo para essa validação é identificar o CEP informado no cadastro do cliente, para isso, clique em: Menu → Cadastros → Clientes, insira o nome do cliente no campo de buscas e clique em: Aplicar Filtro:

![Imagem 1: O primeiro passo para essa validação é identificar o CEP informado no cadastro do cliente, para isso, clique em: Menu →…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-8.png)

Clique em: Editar:

![Imagem 2: Clique em: Editar:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-9-1024x294.png)

Em "Endereço Principal", identifique o CEP:

![Imagem 3: Em "Endereço Principal", identifique o CEP:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-10.png)

Agora, utilizando o Google ou o próprio site dos [Correios](https://buscacepinter.correios.com.br/app/endereco/index.php), busque o CEP e verifique se o bairro informado pelo cliente coincide com o resultado obtido.

Após localizar o bairro correto, altere-o no cadastro do cliente e clique em: Salvar:

![Imagem 4: Após localizar o bairro correto, altere-o no cadastro do cliente e clique em: Salvar:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-11-1024x371.png)

**CORRIJA O ENDEREÇO DO CLIENTE NA VENDA**

Após a validação do endereço, é necessário "informar" para o Artemis5 que o endereço está corrigido.

Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:

![Imagem 5: Para isso, localize o pedido com erro na tela de vendas e clique em: Corrigir Endereço:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-12-1024x77.png)

Selecione "Endereço Principal" e clique em: Salvar.

![Imagem 6: Selecione "Endereço Principal" e clique em: Salvar.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-13-1024x387.png)

Aguarde aproximadamente cinco minutos para a venda ser reprocessada e faturada.
