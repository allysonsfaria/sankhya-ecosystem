# Notificações

Este campo é para configurar as notificações do **Artemis5,** sendo:

## INFORMAÇÕES BÁSICAS DE E-MAIL

- **E-mails para notificações:** Informe quais serão os e-mails utilizados para receber as notificações;

- **Ativar Notificações por E-mail:** Ao selecionar “Sim”, os e-mails acima inseridos receberão notificações;

- **Alerta Cadastro Externo?** Ao selecionar “Sim”, será enviado um e-mail informando a cada novo cadastro de representante comercial;

## INFORMAÇÕES BÁSICAS PEDIDOS DE COMPRA

- **Telefone Padrão Pedido Compras** e **E-mail Padrão Pedido Compras:** Informe esses dados para realização de pedidos de compra;

## INFORMAÇÕES BÁSICAS SMS

- **SMS Alerta de Pagamento:** Escreva o texto de alerta para pagamentos prestes a vencer.

- **SMS Cobrança de Atraso:** Escreva o texto para cobrar os clientes com pagamento em atraso.
