# Como cadastrar um novo produto?

## No Magis5 Hub, existem diferentes tipos de produtos que podem ser criados de forma simples. Vamos entender cada um deles:

No **Magis5 Hub**, existem diferentes tipos de produtos que podem ser criados de forma simples. Vamos entender cada um deles:

1. Produtos Sem Variação: São produtos simples e únicos, que não possuem variações de modelos, cor tamanho ou qualquer outra característica. Existem dois tipos de produtos sem variação:

- Produto Acabado: Essa opção é ideal para produtos prontos para venda, como uma garrafa de água, por exemplo.
- Insumo: Essa opção é usada para materiais de embalagem ou matérias-primas que são utilizados na fabricação de outros produtos. Por exemplo, você pode criar um insumo para representar o plástico utilizado nas embalagens.

1. Produtos Com Variação: São produtos que possuem mais de uma variação do mesmo item. As variações podem ser relacionadas à cor, sabor, tamanho ou qualquer outra característica que você queira diferenciar. Por exemplo, se você vende camisetas, pode ter variações de cores ou tamanhos disponíveis.
2. Produtos Compostos": Os produtos compostos são usados para criar kits ou para a montagem de produtos de fabricação própria que possuem variações. Isso significa que você pode agrupar diferentes produtos ou componentes em um único kit. Por exemplo, se você vende um kit de pintura que inclui pincéis, tintas e tela, pode criar um produto composto para representar esse kit.

Essa variedade de tipos de produtos permite que você organize e gerencie seu inventário de forma mais eficiente no **Magis5 Hub**.
