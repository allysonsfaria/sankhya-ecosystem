# Rejeição: Data de vencimento da parcela não informada ou menor que Data de Emissão [nOcor: 001]

## Este erro significa que ocorreu um problema relacionado ao preenchimento das informações de pagamento na NF-e.

Para resolver esse erro, será necessário emitir a nota fiscal manual para que seja atualizada a data de vencimento da fatura.

Para isso, na tela de vendas, clique em: Emitir NF-e Manual:

![Imagem 1: Para isso, na tela de vendas, clique em: Emitir NF-e Manual:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-24-1024x65.png)

Confira a data de emissão da nota fiscal:

![Imagem 2: Confira a data de emissão da nota fiscal:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-26-1024x249.png)

Na aba Duplicatas/Faturas, confira a data de vencimento informada:

![Imagem 3: Na aba Duplicatas/Faturas, confira a data de vencimento informada:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-27-1024x163.png)

Atualize a data para uma data igual ou posterior à data de emissão da Nota Fiscal:

![Imagem 4: Atualize a data para uma data igual ou posterior à data de emissão da Nota Fiscal:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/10/image-28-1024x162.png)

Após validar as informações, clique em: Atualizar Informações e Recalcular Impostos:

![Imagem 5: Após validar as informações, clique em: Atualizar Informações e Recalcular Impostos:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-37.png)

Caso haja alguma inconsistência, será exibido um pop-up com uma mensagem de erro.

Caso esteja correto, não será exibida nenhuma mensagem. Clique em: Transmitir NF-e:

![Imagem 6: Caso esteja correto, não será exibida nenhuma mensagem. Clique em: Transmitir NF-e:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-38.png)

Pronto, a nota está corrigida.

**ATUALIZE O STATUS DA NOTA FISCAL**

O processo para atualização da nota fiscal é de aproximadamente cinco minutos.

Para adiantar este processo, é possível atualizar o status da nota fiscal de forma manual. Para isso, acesse: Menu → Vendas → Notas Fiscais, insira o número do pedido em: ID Pedido/Venda e clique em: Aplicar Filtro:

![Imagem 7: Para adiantar este processo, é possível atualizar o status da nota fiscal de forma manual. Para isso, acesse: Menu →…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-39.png)

A nota estará processando autorização:

![Imagem 8: A nota estará processando autorização:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-41.png)

Neste caso, clique em: Ações → Atualizar Status:

![Imagem 9: Neste caso, clique em: Ações → Atualizar Status:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-43-1024x170.png)

Se a correção estiver correta, a nota fiscal irá sumir da tela e será necessário localizar pelo número do pedido novamente:

![Imagem 10: Se a correção estiver correta, a nota fiscal irá sumir da tela e será necessário localizar pelo número do pedido…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-45-1024x294.png)
![Imagem 11: Se a correção estiver correta, a nota fiscal irá sumir da tela e será necessário localizar pelo número do pedido…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-46-1024x65.png)

Se estiver errada, voltará a mensagem de erro de autorização.

![Imagem 12: Se estiver errada, voltará a mensagem de erro de autorização.](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/09/image-44-1024x144.png)

Neste caso, orientamos que procure a equipe de suporte.3
