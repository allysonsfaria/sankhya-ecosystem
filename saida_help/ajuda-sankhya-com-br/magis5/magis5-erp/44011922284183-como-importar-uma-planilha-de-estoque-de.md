# Como importar uma planilha de Estoque de Recompra?

## Neste tutorial, você aprenderá a formatar sua planilha de estoque de recompra para importá-la com sucesso no Magis5 ERP.

**Passo 1: Preparando a Planilha**

**1.1 Estrutura da Planilha**

- **Coluna A**: ID do Produto
- **Coluna B**: Estoque de Recompra

![Imagem 1: Coluna B : Estoque de Recompra](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2024/08/image-5.png)

### 1.2 Formato dos Dados

Certifique-se de que cada coluna contenha apenas os dados correspondentes:

- **ID do Produto:** ID do produto que será alimentado com estoque de recompra
- **Estoque de Recompra:** Quantidade de itens. Não será aceito quantidade negativa. Itens com casas decimais deverão ter vírgula (,).

#### Passo 2: Salvando a Planilha

Após organizar e revisar os dados, salve a planilha no formato **XLSX**:

1. Clique em **Arquivo**.
2. Selecione **Salvar Como**.
3. Escolha o formato **XLSX.**
4. Nomeie o arquivo e clique em **Salvar**.

#### Dicas Adicionais

- Quantidade média de produtos por planilha: até 20 mil linhas
