# Como configurar um novo regime especial?

O regime especial é uma configuração utilizada para categorizar um grupo específico de tributos. Essa funcionalidade é especialmente útil em situações em que um cliente possui um regime tributário diferenciado, como um desconto especial no ICMS, por exemplo. Nesses casos, é necessário distinguir esse cliente dos demais ao emitir a Nota Fiscal.

Ao selecionar o regime especial para um cliente, é possível associar as configurações tributárias específicas que se aplicam a ele. Essas configurações podem incluir alíquotas diferenciadas, isenções ou benefícios fiscais específicos. Essa diferenciação é fundamental para garantir a correta aplicação dos tributos e a precisão nas obrigações fiscais do cliente em questão.
