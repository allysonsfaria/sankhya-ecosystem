# Como configurar um novo zoneamento?

## O zoneamento é utilizado para a criação de grupos que serão incluídos em uma zona específica sujeita a uma tributação especial.

Ao utilizar o zoneamento, é possível definir áreas geográficas delimitadas que receberão um tratamento tributário diferenciado. Essas zonas podem ser configuradas com base em critérios como localização geográfica, legislação específica ou outras características relevantes.

Dentro de uma zona específica, é possível criar grupos de itens ou clientes que estarão sujeitos a uma tributação especial. Essa tributação diferenciada pode incluir alíquotas específicas, benefícios fiscais ou outras condições tributárias personalizadas.

---

Para criar um novo zoneamento, na barra de menus, clique em: Configurações → NF-e - Zoneamento:

![Imagem 1: Para criar um novo zoneamento, na barra de menus, clique em: Configurações → NF-e - Zoneamento:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-29-1024x400.png)

Em seguida, clique em “Novo Zoneamento”, informe qual será o nome do grupo em “Descrição” e clique em "Salvar" para concluir a operação:
