# Gerando um inventário

Para acessar o módulo “Inventário”, na barra de menus, clique em: Suprimentos → Inventário:

![L1-2](https://ajuda.sankhya.com.br/hc/article_attachments/44011960147095)

Para iniciar uma nova contagem, clique em “Nova Contagem”:

![L2](https://ajuda.sankhya.com.br/hc/article_attachments/44011976478871)

Na tela seguinte, preencha os dados solicitados, sendo:

- **Data da Contagem:** Informe a data que está realizando a contagem;

- **Responsável:** Por padrão, este campo virá preenchido com o nome do usuário logado na plataforma;

- **Depósito:** Caso o empreendimento possua mais de um depósito, selecione em qual depósito será realizada a contagem;

- **Especificar Endereço:** Caso o empreendimento trabalhe com endereço de depósito, selecione essa opção para especificar;![L3](https://ajuda.sankhya.com.br/hc/article_attachments/44011990393879)

- **Gerar Valorização do Estoque:** Caso queira valorizar o estoque, selecione essa opção e preencha os seguintes campos, informando o início e o fim da data de competência bem como a base do preço de custo: : ![L4](https://ajuda.sankhya.com.br/hc/article_attachments/44011976698135)

- **Arquivo CSV:** Para facilitar a contagem, temos uma planilha padrão (com ID e quantidade) onde é possível preenchê-la e importá-la para o **Artemis5**;

![L5](https://ajuda.sankhya.com.br/hc/article_attachments/44011990606103)

![L6-1](https://ajuda.sankhya.com.br/hc/article_attachments/44011968973079)

- **Agrupar por:** Selecione a forma de agrupamento dos itens: Categoria, Natureza ou Fabricante. 
  ![L7-1](https://ajuda.sankhya.com.br/hc/article_attachments/44011976970647)

Após preencher todos os campos, é necessário informar quais serão os itens inventariados (caso não utilize a planilha). Para isso, clique em (+) e selecione os produtos, sendo possível buscá-los por id, ean, nome, categoria ou fabricante:

![d1](https://ajuda.sankhya.com.br/hc/article_attachments/44011981160087)

Os produtos selecionados serão adicionados à listagem de itens.

Caso não tenha selecionado a opção “Especificar Endereço”, basta informar a quantidade de itens no campo “Quantidade”:

![d2](https://ajuda.sankhya.com.br/hc/article_attachments/44011961049239)

Caso selecione a opção “Especificar Endereço”, a listagem de itens será exibida dessa maneira. Ao clicar no botão apontado pela seta, abrirá uma nova tela onde será possível informar o endereço, bem como a quantidade de itens:

![d3](https://ajuda.sankhya.com.br/hc/article_attachments/44011969405719)

![d3.1](https://ajuda.sankhya.com.br/hc/article_attachments/44011943778967)

Na barra de Itens Inventariados, há alguns botões, sendo:

| ![d4-1](https://ajuda.sankhya.com.br/hc/article_attachments/44011943902871) | Abre a listagem de produtos para inseri-los no inventário. |
| --- | --- |
| ![d4.2](https://ajuda.sankhya.com.br/hc/article_attachments/44011981633303) | Ativa a busca pelo código de barras. |
| ![d4.1](https://ajuda.sankhya.com.br/hc/article_attachments/44011944091287) | Exibe os modelos de inventário disponíveis |
