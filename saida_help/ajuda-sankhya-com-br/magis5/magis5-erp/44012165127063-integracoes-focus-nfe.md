# Integrações - Focus NFe

- **Ambiente de Emissão da NF-e:** O “Ambiente de Homologação'' serve para envio de notas fiscais com a finalidade de teste. As notas emitidas aqui não possuem validade fiscal/tributária.
  O “Ambiente de Produção'' é o ambiente com validade fiscal e tributária, pois isso, recomendamos que utilize este ambiente apenas quando for iniciar o processo de envio de notas válidas.

- **ID Empresa Focus:** É o ID referente ao cadastro do empreendimento dentro da Focus, localizado na URL.

- **Ativar atualização de status automática NF-e? (EMITIDA):** Selecione “Sim” caso deseje que a atualização de status seja automática ao emitir uma Nota Fiscal;;

- **Ativar atualização de status automática NF-e? (RECEBIDA):** Selecione “Sim” caso deseje que a atualização de status seja automática ao ter uma NF-e emitida contra o CNPJ do empreendimento;

- **Token Produção** e **Token Homologação:** Fornecido pela Focus, os tokens são necessários para que, tanto o ambiente de produção quanto o ambiente de homologação possam emitir documento fiscal.
