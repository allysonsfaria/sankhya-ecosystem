# Como consultar suas vendas?

## O módulo "Consulta de Vendas" desempenha um papel fundamental ao fornecer um panorama completo de todas as vendas realizadas no empreendimento, independentemente de terem ocorrido no "PDV - Modo Loja" ou no modo "Representante".

Através desse módulo, é possível acessar informações detalhadas sobre todas as transações de venda efetuadas, permitindo uma análise abrangente do desempenho das vendas. Isso inclui a visualização de datas, horários, produtos vendidos, quantidades, preços e quaisquer outros detalhes relevantes relacionados às transações de venda.

Seja a venda realizada no ambiente físico da loja ou por meio de representantes externos, o módulo "Consulta de Vendas" centraliza essas informações em um só lugar, proporcionando uma visão unificada do panorama de vendas do empreendimento como um todo.

---

Para visualizar as vendas realizadas no empreendimento, basta logar no **Artemis5** e selecionar o empreendimento desejado. Na barra de menus, clique em: Vendas e, em seguida, “Consulta de Vendas”:

![Imagem 1: Para visualizar as vendas realizadas no empreendimento, basta logar no Artemis5 e selecionar o empreendimento desejado.…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-187-1024x147.png)

A tela de vendas é uma tela muito simples de manusear, onde, através dos filtros é possível visualizar todas as vendas desejadas. Para isso, selecione os filtros e clique em “Aplicar Filtro”.

![Imagem 2: A tela de vendas é uma tela muito simples de manusear, onde, através dos filtros é possível visualizar todas as vendas…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-188-1024x462.png)

Os campos a seguir, se preenchidos individualmente ou em conjunto, trarão as informações das vendas de acordo com o filtro utilizado:

- **ID (Artemis5):** É o ID da venda;

- **Nº NF-e:** É o número da NF-e;

- **Status:** São os status das vendas. Se selecionado individualmente, trará todas as vendas com o status informado;

- **UTM Source:** É a origem do pedido. Se selecionado individualmente, trará todas as vendas com a origem informada;

- **Data Inicial (Pedido/Venda):** É a data inicial das vendas que, quando selecionada, trará vendas a partir da data escolhida;

- **Hora Inicial:** A hora informada neste campo trará vendas a partir do horário informado;

- **Data Final (Pedido/Vendas):** É a data final das vendas que, quando selecionada, trará vendas até aquela data.

- **Hora Final:** A hora informada neste campo trará vendas até o horário informado;

- **Data Inicial (NF-e):** É a data de emissão do documento fiscal (NF-e), que, quando selecionada, trará as vendas a partir da data escolhida;

- **Data Final (NF-e):** É a data de emissão do documento fiscal (NF-e), que, quando selecionada, trará as vendas até a data escolhida;

- **Chave de Acesso NF-e:** É a chave de acesso da NF-e, que quando inserida, trará a venda correspondente à ela;

- **Vendedor:** Utilizado para exibir as vendas de um determinado vendedor;

- **Cliente:** Utilizado para exibir todas as vendas de um determinado cliente;

- **Tipo de Entrega:** O tipo de entrega selecionado trará todas as vendas desta seleção;

- **Serviço Correios:** A opção informada neste campo trará todas as vendas que serão enviadas com este serviço;

- **Itens por Página:** Informe a quantidade de vendas que deseja visualizar por página;

- **Tipo de Vendas:** Utilizado frequentemente em atacados e distribuidoras. Vendas no modo “Balcão” são vendas realizadas em lojas que começam e terminam no mesmo dia feitas no PDV - modo loja. Vendas no modo “Comercial” são as vendas que passaram pelo processo de validação, logística e expedição, são as vendas no modo Representante.

- **Forma de Pagamento:** A forma de pagamento selecionada trará todas as vendas desta seleção;

- **Estado:** O estado selecionado trará todas as vendas desta seleção;

- **Cidade:** A cidade selecionada trará todas as vendas desta seleção.;

- **NF-e Emitida:** Se selecionado, trará todas as vendas que tiveram a NF-e emitida;

- **Atacado/Distribuição:** As vendas selecionadas trarão a marcação referente ao campo. Se a venda teve uma tabela de preço diferenciada ou se o cliente está em um grupo diferenciado, será exibido “distribuição”.

**COLUNAS**

Também é possível, na própria tela de vendas, incluir mais colunas para visualização das informações dos vendas ou remover colunas, clicando no botão “Colunas”

![Imagem 5: Também é possível, na própria tela de vendas, incluir mais colunas para visualização das informações dos vendas ou…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-191-1024x156.png)

Será exibida uma tela chamada “Coluna para Exibição” onde, as colunas selecionadas no checkbox serão exibidas, como no exemplo abaixo:

![Imagem 6: Será exibida uma tela chamada “Coluna para Exibição” onde, as colunas selecionadas no checkbox serão exibidas, como no…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-192-1024x426.png)

As colunas ID (#), Vendedor, Cliente, Status, Total e Ações são padrão e não é possível removê-las.

**STATUS DOS PEDIDOS**

Os status das vendas indicam a real situação do pedido dentro do **Artemis5.** Cada estabelecimento tem o fluxo dos status configurado de maneira independente, o que significa que os processos não serão os mesmos nos empreendimentos.

Além dos status, também é possível configurar botões de ação por status. Botões de ação, como o próprio nome diz, servem para executar alguma ação na venda dentro da tela de consulta de vendas.
