# Como visualizar o PDF ou XML de uma nota fiscal eletrônica (NF-e) emitida?

Para localizar uma nota fiscal emitida, na barra de menus, clique em: Vendas → Notas Fiscais:

![Imagem 1: Para localizar uma nota fiscal emitida, na barra de menus, clique em: Vendas → Notas Fiscais:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/07/image-44-1024x182.png)

Com a ajuda dos filtros, localize a Nota Fiscal desejada.

No exemplo abaixo, foram utilizados os filtros “De” e  “Até”, para que fossem exibidas todas as notas fiscais emitidas em um determinado período:

![Imagem 2: No exemplo abaixo, foram utilizados os filtros “De” e “Até”, para que fossem exibidas todas as notas fiscais emitidas…](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-591-1024x565.png)

Ao localizar a nota fiscal desejada, clique em "Ações" e selecione uma das opções demarcadas abaixo:

![Imagem 3: Ao localizar a nota fiscal desejada, clique em "Ações" e selecione uma das opções demarcadas abaixo:](https://ajuda.artemis5.com.br/wp-content/uploads/sites/2/2023/05/image-593-1024x251.png)

Caso a opção escolhida seja o XML, será aberta uma nova aba com os dados;

Caso a opção escolhida seja Danfe (PDF), será exibida uma janela com os dados da nota fiscal.
