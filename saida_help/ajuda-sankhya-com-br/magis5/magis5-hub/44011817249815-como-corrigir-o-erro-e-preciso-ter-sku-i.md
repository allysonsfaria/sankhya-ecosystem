# Como corrigir o erro "É preciso ter SKU informado para ser importado" no Magis5 Hub?

## Este erro indica que falta a informação SKU na hora de importar o anúncio para dentro do Magis5 Hub.

---

Na tela de ["Importar anúncios"](https://sankhya.zendesk.com/hc/pt-br/articles/44010590626839), encontre o anúncio que apresenta o erro e siga os passos a seguir:

![adap](https://ajuda.magis5.com.br/hs-fs/hubfs/adap.png?width=688&height=214&name=adap.png)

É necessário vincular a informação **"SKU"** nos produtos. O erro acontece pois o sistema tentou importar um anúncio que possui produto sem SKU cadastrado.

Lembre-se que sempre que o produto for o mesmo para vários anúncios, é necessário vincular o mesmo SKU. Por exemplo, se você possui os anúncios:

- iPhone 7 Plus 32GB Preto Tela Retina;
- iPhone 7 Plus Preto Apple 32GB Tela 5,5";
- iPhone 7 Plus Câmera Dupla Promoção Apple;

São anúncios diferentes, porém se tratam de apenas um produto, logo, todos eles precisam ter o mesmo SKU inserido.

Certifique-se também de que os seguintes campos estão preenchidos:

- **EAN:** código de barras do seu produto.
- **Quantidade KIT:** campo para informar se este produto é um kit de quantidade. Por exemplo: Se você possui o anúncio "2 x iPhone 7 Plus 32GB Preto Tela Retina, ele necessita ter o SKU do produto unitário e disposto a quantidade "2" no campo **"Quantidade kit"**.
- **Marca:** marca do produto.

Após isto, tente realizar a importação do mesmo anúncio novamente. **Se você está encontrando algum erro diferente do informado nesta página, [nos informe através do nosso chat de suporte](https://ajuda.magis5.com.br/como-abrir-um-suporte-por-bate-papo-na-magis5?hsLang=pt-br).**[![Universidade Magis5](https://ajuda.magis5.com.br/hs-fs/hubfs/Banner%20Universidade%20Magis5.png?width=688&height=68&name=Banner%20Universidade%20Magis5.png)](https://download.magis5.com.br/universidade-magis5?utm_source=central_de_ajuda&utm_medium=link&utm_campaign=central_de_ajuda&hsLang=pt-br)
