# Qual tipo de etiqueta comprar para minhas impressões?

## Em resumo: etiqueta Térmica 10cm x 15cm. Veja a explicação abaixo.

---

Este artigo é direcionado para sellers que utilizam o **[Magis5](https://magis5.com.br/)** como hub de integração.

Para utilizar as impressoras Zebra GC420t ou Zebra ZD220 de forma otimizada, é recomendado utilizar **rolos de etiquetas térmicas** com dimensões de 10cm x 15cm.

É importante **evitar o uso** de etiquetas "Couche". Embora tenham um preço mais baixo ou acessivel, elas exigem o uso de Ribbon, enquanto as etiquetas térmicas não necessitam desse componente adicional, proporcionando maior praticidade e possíveis economias no custo total.

Além disso, as etiquetas térmicas são mais indicadas para uso com as impressoras Zebra GC420t e Zebra ZD220, que são as impressoras [recomendas para compra.](https://ajuda.magis5.com.br/faq/qual-impressora-termica-comprar?hsLang=pt-br)
