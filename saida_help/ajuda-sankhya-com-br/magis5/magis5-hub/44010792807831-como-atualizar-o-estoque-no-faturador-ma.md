# Como atualizar o estoque no Faturador Magis5 Hub?

## Entenda nesse artigo como acrescentar, atualizar ou corrigir o estoque no Faturador Magis5 HUB

---

**Este guia é direcionado a sellers que utilizam o faturador Magis5 Hub.**

💡 Após criar os códigos dos produtos, sincronizar os anúncios e organizar os cadastros, a realização da contagem de estoque torna-se mais simples, rápida e eficiente.

### Como atualizar o estoque dos meus produtos no Faturador Magis5 Hub?

Feito login no Magis5 HUB, vá até **"Estoque"** e depois clique em **"Controle de estoque".**

![Captura de tela 2025-12-29 170123](https://ajuda.sankhya.com.br/hc/article_attachments/44010754435223)

Utilize os **filtros de busca** localizados no topo da página para refinar sua pesquisa e localizar o produto que deseja atualizar.

![Imagem 2: Utilize os filtros de busca localizados no topo da página para refinar sua pesquisa e localizar o produto que deseja…](https://ajuda.sankhya.com.br/hc/article_attachments/44010764257303)

1. **Fornecedor/Catálogo:** filtra pelo fornecedor/catálogo do item
2. **SKU:** filtra pelo SKU
3. **EAN:** filtra pelo EAN do produto
4. **Título do produto:** filtra pelo título do produto
5. **Estoque infinito:** filtra pelo estoque infinito, é possível utilizar os filtros de mínimo e máximo
6. **Estoque:** filtra pelos estoques, é possível utilizar os filtros de mínimo e máximo
7. **Preço de custo:** filtra pelo preço de custo, é possível utilizar os filtros de mínimo e máximo
8. **Status do produto:** filtra pelo status do produto, "excluído" ou "ativo"
   ![Imagem 3: Status do produto: filtra pelo status do produto, "excluído" ou "ativo"](https://ajuda.sankhya.com.br/hc/article_attachments/44010768529687)

Após utilizar os filtros acima para localizar o produto desejado, prossiga com a atualização do estoque.

![Sem título-Dec-29-2025-08-21-57-2860-PM](https://ajuda.sankhya.com.br/hc/article_attachments/44010754871831)

- Campo **"Entrada":** utilize este campo para adicionar itens ao estoque. Digite o valor numérico que deseja somar ao saldo atual.
- Campo **"Saída":** utilize este campo para registrar a retirada de itens. Digite a quantidade que deseja subtrair do saldo atual.
- Campo **"Balanço":** utilize este campo para atualizar o saldo total de forma direta (ajuste absoluto), ignorando os cálculos de entrada e saída. Digite o número exato de produtos disponíveis.
- Campo **"Preço de Custo":** utilize este campo para atualizar o valor unitário pago pelo produto. Digite o novo preço de aquisição.

Ao digitar a alteração desejada, clique fora da caixa e o produto será atualizado.
