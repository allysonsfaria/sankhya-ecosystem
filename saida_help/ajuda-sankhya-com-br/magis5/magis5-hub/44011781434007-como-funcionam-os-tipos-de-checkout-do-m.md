# Como funcionam os tipos de checkout do Magis5 Hub e qual escolher para a sua operação?

## Para facilitar o processo de expedição do cliente, o Magis5 conta com diferentes tipos de "checkouts".

---

**[Checkout pelo pedido:](https://sankhya.zendesk.com/hc/pt-br/articles/44010946573079)** A funcionalidade de checkout por pedido é indicado para o Seller que tenha um leitor de código de barras. Nesse processo, o sistema irá exibir as informações do(s) produto(s) referente(s) ao pedido para que ele possa ser liberado, e o Seller precisa bipar o código de barras de todos os itens do pedido, seja por EAN ou SKU do produto. Serão liberados na impressora os arquivos para impressão e o sistema passará para o próximo pedido a ser expedido.

[Checkout pelo produto:](https://sankhya.zendesk.com/hc/pt-br/articles/44011188433047) Para efetuar o checkout pelo produto é preciso que o seller tenha um leitor de código de barras. Nesse processo, o sistema irá exibir as informações do(s) produto(s) referente(s) ao pedido para que ele possa ser liberado, e será preciso efetuar a bipagem do produto, seja por código de barras ou SKU. Serão liberados na impressora os arquivos para impressão e o sistema passará para o próximo pedido a ser expedido.

[Checkout pela etiqueta:](https://sankhya.zendesk.com/hc/pt-br/articles/44010947229207) É feita a bipagem a partir do código da etiqueta. Quando a etiqueta é bipada, o sistema irá exibir as informações do(s) produto(s) referente(s) ao pedido para que ele possa ser liberado. Serão liberados na impressora os arquivos para impressão e o sistema passará para o próximo pedido a ser expedido.
