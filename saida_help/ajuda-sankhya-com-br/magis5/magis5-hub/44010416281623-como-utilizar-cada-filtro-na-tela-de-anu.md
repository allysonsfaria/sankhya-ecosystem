# Como utilizar cada filtro na tela de "Anúncios Publicados" no Magis5 Hub?

## Os filtros são utilizados na busca de anúncios já publicados no Magis5 Hub.

---

A Magis5 dispõe diversos filtros para refinar a busca por anúncios que já foram publicados em seus canais de venda. Neste guia, mostraremos para que serve e como utilizar cada um deles.

Para começar, vá até **"Produtos e anúncios" -> "Produtos e anúncios"** e depois clique em **"Anúncios publicados"**.

![Imagem 1: A Magis5 dispõe diversos filtros para refinar a busca por anúncios que já foram publicados em seus canais de venda.…](https://ajuda.sankhya.com.br/hc/article_attachments/44010410499351)

A partir disto, o sistema disponibilizará os filtros para auxiliar na busca de um anúncio específico.

**Confira abaixo os filtros numerados e para que serve cada um deles:**

![filtros1](https://ajuda.sankhya.com.br/hc/article_attachments/44010416546199)

**1 - Canal de venda:** É usado para selecionar o canal de venda em que o anúncio foi publicado. (Ex: Mercado Livre, Shopee, Magazine Luiza, etc.)

**2 - SKU/ID do Canal de venda:** Campo onde é possível buscar pelo SKU quando a caixa está habilitada e buscar pelo ID do Canal de venda quando desabilitada.

**3 - Tipo do Produto:** Para exibir produtos do tipo "Simples", "Simples (KIT)" ou "Composto (KIT)".

**4 - Status:** Para buscar pelo status do anúncio no Magis5 Hub.

**5 - Com variação:** Para exibir anúncios que possuem ou não variação.

**6 - Compatibilidade pendente:** Para exibir anúncios onde se falta definir compatibilidade do produto no Marketplace.

**7 - Fornecedor/Catálogo:** Usado para selecionar o fornecedor que foi cadastrado anteriormente no seu produto do Magis5 Hub.

**8 - Título no catálogo:** Para buscar pelo título do produto no cadastro interno de produtos simples/compostos, exibindo nome também das diferentes variações.

**9 - Tipo frete:** Para buscar por tipo de frete no marketplace.

**10 - Tipo Anúncio:** Para buscar pelo tipo de anúncio no marketplace.

**11 - Preço fixo até o fim estoque físico:** Para verificar se a tag de "Preço Fixo" está habilitada no anúncio.

**12 - Ordenação:** Para filtrar por tipo de ordenação.

![filtros2](https://ajuda.sankhya.com.br/hc/article_attachments/44010410767255)

**13 - Código de Barras:** Para buscar pelo código de barras.

**14 - Título no marketplace:** Para buscar pelo título do anúncio no marketplace.

**15 - Frete Grátis:** Para buscar por anúncios que possuem ou não frete grátis.

**16 - Pausados recentemente:** Para exibir anúncios pausados recentemente.

**17 - Quantidade de Vendas:** Para filtrar por uma quantidade mínima e máxima de vendas.

**18 - Preço:** Para filtrar por anúncios que estão entre um preço mínimo e um preço máximo definido.

**19 - Anúncio de Catálogo/Buybox:** Para exibir ou não anúncios publicados no Catálogo do Mercado Livre e Buybox da Amazon.

**20 - Tipo de logística:** Para buscar por tipo específico de logística.

**21 - Anúncio Flex:** Para exibir ou não anúncios Flex.

**22 - Tipo de Oferta:** Para buscar por tipo de oferta no marketplace.

É possível nesta tela utilizar vários filtros para a mesma busca desde que as funcionalidades dos filtros selecionados existam no marketplace ou canal de venda selecionado.

Por exemplo, se é feita uma busca por anúncios de catálogo ou buybox em canais de venda do Magazine Luiza, nenhum resultado será exibido.
