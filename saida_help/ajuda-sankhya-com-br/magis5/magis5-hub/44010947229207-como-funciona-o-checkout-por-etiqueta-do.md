# Como funciona o "Checkout por Etiqueta" do Magis5 Hub?

## Para facilitar o processo de expedição, o Magis5 Hub conta com diferentes tipos de "checkouts". Este é o "Checkout por Etiqueta".

---

É feita a bipagem a partir do código da etiqueta. Nesse processo, o sistema irá exibir as informações do(s) produto(s) referente(s) ao pedido para que ele possa ser liberado.

### Como funciona o "Checkout por Etiqueta" do Magis5 Hub

No menu superior dentro do Magis5 Hub, vá para**"Expedição" > "Separar pedidos" >  "Checkout por etiqueta"**.

A partir desta tela será possível bipar a etiqueta com o número do pedido, chave de acesso, código de rastreio ou nota fiscal para que o pedido seja encontrado.
