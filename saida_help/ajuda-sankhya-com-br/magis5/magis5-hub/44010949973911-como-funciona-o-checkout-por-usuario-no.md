# Como funciona o Checkout por usuário no Magis5 Hub?

## O relatório é feito para acompanhar como está a expedição dos seus produtos.

---

O relatório de checkout por usuário é o relatório disponível para acompanhar a expedição dos produtos em tempo real.

Nele é possível acompanhar o horário de entrada do pedido, canal de venda e o horário que foi liberada a etiqueta, além do horário que foi feito o registro de coleta do pedido.

### Como utilizar o relatório de Checkout por usuário

No menu da parte superior, leve o mouse até **"Expedição"**, depois até **"Relatórios de expedição"** e por último clique em **"Checkout por usuário".**

![Imagem 1: No menu da parte superior, leve o mouse até "Expedição" , depois até "Relatórios de expedição" e por último clique em…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Feb-29-2024-04-51-45-0501-PM.png?width=601&height=539&name=image-png-Feb-29-2024-04-51-45-0501-PM.png)

Aqui, a partir dos filtros, é possível verificar os horários que foram feito os checkouts e verificar as informações dos pedidos. 

![Imagem 2: Aqui, a partir dos filtros, é possível verificar os horários que foram feito os checkouts e verificar as informações…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Feb-29-2024-05-00-34-2282-PM.png?width=688&height=130&name=image-png-Feb-29-2024-05-00-34-2282-PM.png)

Para que o dado "Data registro coleta" seja exibido é necessário antes registrar a coleta. Para quaisquer dúvidas sobre como registrar coletas, confira o nosso artigo: [O que é e como funciona o registro de coletas.](https://sankhya.zendesk.com/hc/pt-br/articles/44010960560407)
