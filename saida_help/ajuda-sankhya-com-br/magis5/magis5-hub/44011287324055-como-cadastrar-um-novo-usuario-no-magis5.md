Caso haja mais de um **usuário** ou **colaborador** acessando o Magis5 HUB, é possível criar usuarios individuais para cada um.

Feito login no Magis5 HUB vá em **"Configurações"**, **"Cadastros"** e, por último, clique em **"Usuários"**.

![Captura de tela 2026-03-25 113442](https://ajuda.sankhya.com.br/hc/article_attachments/44011256245399)

Dentro da tela **Usuários**, clique em **“Novo”**, disponível à direita.

![Captura de tela 2026-03-25 120204](https://ajuda.sankhya.com.br/hc/article_attachments/44011288231703)

### Como preencher a aba Geral

Na aba **"Geral"** preencha as informações do **novo usuário.**

![Captura de tela 2026-03-25 120407](https://ajuda.sankhya.com.br/hc/article_attachments/44011288365207)

- **Nome:** Informe o nome do usuário. **(Obrigatório)**
- **Sobrenome:** Informe o sobrenome do usuário ou outra identificação complementar. **(Obrigatório)**
- **E-mail:** Insira o e-mail que será utilizado para acesso ao Magis5 HUB, o email precisar ser um e-mail **valido**. **(Obrigatório)**
- **Tipo de usuário:** Selecione o tipo de usuário desejado. **(Obrigatório)**

  ![Imagem 11: Tipo de usuário: Selecione o tipo de usuário desejado. (Obrigatório)](https://ajuda.sankhya.com.br/hc/article_attachments/44011288475159)
- **Subusuario:** Neste campo, vincule o subusuário que deseja associar a este usuário.
- **Permitir expedição de pedidos:**  quando esta opção estiver desabilitada, não será possível clicar no botão **"O produto não tem código de barras"** e nem realizar a expedição pelo Bloco de separação. O usuário perde a permissão.

  ![Imagem 13: Permitir expedição de pedidos: quando esta opção estiver desabilitada, não será possível clicar no botão "O produto não…](https://ajuda.sankhya.com.br/hc/article_attachments/44011306246295)
- **Visualizar ean na expedição:** quando esta opção estiver desabilitada, o usuário não consegue visualizar o campo **EAN** nos itens no Checkout

![Imagem 14: Visualizar ean na expedição: quando esta opção estiver desabilitada, o usuário não consegue visualizar o campo EAN nos…](https://ajuda.sankhya.com.br/hc/article_attachments/44011306342423)

![Imagem 15: Visualizar ean na expedição: quando esta opção estiver desabilitada, o usuário não consegue visualizar o campo EAN nos…](https://ajuda.sankhya.com.br/hc/article_attachments/44011306246295)

- **Visualizar valores do dashboard:** quando esta opção estiver habilitada, o usuário não consegue visualizar os valores de faturamento na dashboard

  ![Imagem 16: Visualizar valores do dashboard: quando esta opção estiver habilitada, o usuário não consegue visualizar os valores de…](https://ajuda.sankhya.com.br/hc/article_attachments/44011288972311)
  ![Imagem 17: Visualizar valores do dashboard: quando esta opção estiver habilitada, o usuário não consegue visualizar os valores de…](https://ajuda.sankhya.com.br/hc/article_attachments/44011257110295)
- **Centros de distribuição:** nessa opção, é possível selecionar de quais depósitos o usuário terá permissão para visualizar pedidos relacionados a esses depósitos.

  ![Imagem 18: Centros de distribuição: nessa opção, é possível selecionar de quais depósitos o usuário terá permissão para visualizar…](https://ajuda.sankhya.com.br/hc/article_attachments/44011257229463)

⚠️ **Atenção:**

**Configuração de visualização por depósito**

- **Nenhum depósito selecionado:**
  O usuário poderá visualizar todos os pedidos, independentemente do depósito.
- **Todos os depósitos selecionados:**
  O usuário poderá visualizar apenas os pedidos dos depósitos selecionados.
- **Apenas um depósito selecionado:**
  O usuário poderá visualizar somente os pedidos do depósito escolhido.

### Como preencher a aba Permissões

Em **“Permissões”**, selecione os acessos desejados. Itens marcados indicam que o usuário terá permissão para visualizar essas telas, quando alguma permissão estiver desmarcada o usuário ficá sem acesso aquela determinada tela.

![Captura de tela 2026-03-25 164730](https://ajuda.sankhya.com.br/hc/article_attachments/44011298766615)

### Como preencher a aba Impressoras

Configure, na seção **“Impressoras”**, qual impressora será utilizada por este usuário durante a expedição de pedidos. [[clique aqui para ver como configurar]](https://ajuda.sankhya.com.br/magis5-hub-como-configurar-a-impressora-para-imprimir-etiqueta?hsLang=pt-br).

![Imagem 20: Configure, na seção “Impressoras” , qual impressora será utilizada por este usuário durante a expedição de pedidos.…](https://ajuda.sankhya.com.br/hc/article_attachments/44011320230295)

Após finalizar todo o processo de criação do usuário, clique em **“Salvar”** no canto superior da tela.

![Imagem 21: Após finalizar todo o processo de criação do usuário, clique em “Salvar” no canto superior da tela.](https://ajuda.sankhya.com.br/hc/article_attachments/44011289584663)

💡 Após a criação do usuário, será enviada ao e-mail cadastrado uma senha provisória, que deverá ser utilizada para definir uma nova senha de acesso.
