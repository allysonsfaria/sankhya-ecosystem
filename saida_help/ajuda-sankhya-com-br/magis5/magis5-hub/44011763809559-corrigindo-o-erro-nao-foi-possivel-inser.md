# Corrigindo o Erro: "Não foi possível inserir o produto" no Magis5 Hub ao Publicar no Magazine Luiza

## Resolvendo o Erro do GTIN: Inserção de Produtos no Magazine Luiza.

---

**"Não foi possível inserir o produto. Erro: {"status\_code": 400, "detail": {"gtin": ["This field is required."]}}"**

Este erro ocorre no Magazine Luiza quando há uma tentativa de cadastrar um produto sem fornecer o código GTIN (Global Trade Item Number), também conhecido como código de barras. O GTIN é um identificador único e essencial.

Para corrigir esse erro e conseguir cadastrar o produto com sucesso no Magazine Luiza, prossiga com os passos demonstrados neste guia.

---

### Verifique o código GTIN/EAN

Verifique se o código de barras foi preenchido da forma correta na tela de CADASTRO de produtos.

Ao editar o produto para fazer as correções necessárias, verifique se os seguintes campos estão vazios:

1. **Código de barras (EAN)** localizado na aba **Dados Gerais.**
   ![Imagem 1: Código de barras (EAN) localizado na aba Dados Gerais. Veja como é exibido o campo na imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011743513751)
   Veja como é exibido o campo na imagem abaixo:
   ![Imagem 2: Código de barras (EAN) localizado na aba Dados Gerais. Veja como é exibido o campo na imagem abaixo:](https://ajuda.sankhya.com.br/hc/article_attachments/44011754584471)
2. **Código universal de produto (GTIN)** localizado na aba **Ficha Técnica**.
   ![Imagem 3: Código universal de produto (GTIN) localizado na aba Ficha Técnica . Veja como é exibido o campo na imagem abaixo: Caso…](https://ajuda.sankhya.com.br/hc/article_attachments/44011772358679)
   Veja como é exibido o campo na imagem abaixo:
   ![Imagem 4: Código universal de produto (GTIN) localizado na aba Ficha Técnica . Veja como é exibido o campo na imagem abaixo: Caso…](https://ajuda.sankhya.com.br/hc/article_attachments/44011743802903)
   Caso o produto não possua GTIN, você deverá **clicar no campo N/A** e justificar no campo **Motivo de GTIN vazio (EMPTY\_GTIN\_REASON)**, localizado na mesma aba:
