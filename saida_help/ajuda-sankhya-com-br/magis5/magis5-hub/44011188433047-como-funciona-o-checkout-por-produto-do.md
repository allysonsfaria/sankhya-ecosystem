# Como funciona o "Checkout por Produto" do Magis5 Hub?

## Para facilitar o processo de expedição, o Magis5 Hub conta com diferentes tipos de "checkouts". Este é o "Checkout por Produto".

---

Para efetuar o checkout pelo produto é preciso que o seller tenha um leitor de código de barras. Nesse processo, o sistema exibirá as informações referentes ao pedido e produto em tela para que ele possa ser liberado. Será preciso efetuar a bipagem do produto seja por código de barras ou SKU e então os arquivos serão liberados para impressão. O sistema então prosseguirá para o próximo pedido.

### Como funciona o "Checkout por Produto" do Magis5 Hub?

No menu superior dentro do Magis5 Hub, vá para**"Expedição" > "Separar pedidos" >  "Checkout por produto"**.

![Imagem 1: No menu superior dentro do Magis5 Hub, vá para "Expedição" > "Separar pedidos" > "Checkout por produto" .](https://ajuda.sankhya.com.br/hc/article_attachments/44011206143127)

A partir disto o sistema exibirá todos os pedidos a serem separados disponibilizando filtros opcionais. Será possível bipar o produto sem a necessidade do número do pedido, pois o Magis5 Hub irá encontrar o mesmo de forma automática. Ao bipar, será validado o EAN/SKU para impressão.
