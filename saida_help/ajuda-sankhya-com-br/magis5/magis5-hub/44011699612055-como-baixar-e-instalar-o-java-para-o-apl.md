# Como baixar e instalar o Java para o Aplicativo Impressora Magis5 Hub?

## O Aplicativo de Impressora requer que o Java esteja instalado no seu computador para funcionar corretamente.

---

**Antes de tudo, é necessário fazer o download do instalador do Java.**
[Clique aqui](https://www.java.com/pt-BR/download/manual.jsp) para ser redirecionado ao site oficial e iniciar o download.

**Role a página até encontrar a tabela de downloads, conforme mostrado na imagem abaixo.**
Em seguida, selecione e clique na opção de download correspondente ao sistema operacional do seu computador **(Windows ou macOS).**

![Imagem 1: Role a página até encontrar a tabela de downloads, conforme mostrado na imagem abaixo. Em seguida, selecione e clique…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Jul-15-2025-09-08-57-7719-PM.png?width=688&height=459&name=image-png-Jul-15-2025-09-08-57-7719-PM.png)

**Após clicar na opção de download do Java, acesse a aba de downloads do seu navegador e execute o arquivo baixado.**
O nome do arquivo geralmente contém os termos **"JavaSetup"** ou **"jre"** em seu nome.

![Imagem 2: Após clicar na opção de download do Java, acesse a aba de downloads do seu navegador e execute o arquivo baixado. O…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Jul-15-2025-09-13-56-6493-PM.png?width=489&height=210&name=image-png-Jul-15-2025-09-13-56-6493-PM.png)

Após clicar para executar o **instalador do Java**, seu computador solicitará permissão para prosseguir. **Clique no botão “Sim”** para continuar com a instalação

Na janela de instalação que será aberta, clique no botão **“Instalar”** para iniciar o processo

![Imagem 3: Na janela de instalação que será aberta, clique no botão “Instalar” para iniciar o processo](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Jan-11-2024-06-31-30-7047-PM.png?width=688&height=379&name=image-png-Jan-11-2024-06-31-30-7047-PM.png)

Aguarde até que a instalação do **Java** seja concluída. O andamento pode ser acompanhado pela barra de progresso **verde exibida na tela**.

![Imagem 4: Aguarde até que a instalação do Java seja concluída. O andamento pode ser acompanhado pela barra de progresso verde…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Jan-11-2024-06-34-07-8960-PM.png?width=688&height=381&name=image-png-Jan-11-2024-06-34-07-8960-PM.png)

**Pronto!** O Java foi instalado com sucesso no seu computador, e agora o **Aplicativo de Impressora do Magis5 Hub** já pode ser executado.

Para fechar o instalador do Java, clique no botão **"Fechar"**.

![Imagem 5: Para fechar o instalador do Java, clique no botão "Fechar" .](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Jan-11-2024-06-35-56-5791-PM.png?width=688&height=380&name=image-png-Jan-11-2024-06-35-56-5791-PM.png)

**Em seguida, retorne à sua Área de Trabalho (ou à pasta onde está localizado o Aplicativo de Impressora) e abra-o dando um duplo clique no ícone.**
Se ainda não possui o aplicativo, [**clique aqui**](https://sankhya.zendesk.com/hc/pt-br/articles/44011240301847) para aprender como baixá-lo.
