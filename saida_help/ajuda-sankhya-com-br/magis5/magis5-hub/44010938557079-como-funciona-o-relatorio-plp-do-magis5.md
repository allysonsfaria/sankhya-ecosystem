# Como funciona o "Relatório PLP" do Magis5 Hub?

## Um relatório para você acompanhar o fechamento e abertura das suas PLPs.

---

A PLP (pré lista de postagem) é um documento a ser entregue quando a mercadoria é enviada. A Magis5 possui uma funcionalidade para gerar um relatório para você acompanhar isto.

### Como utilizar o Relatório PLP do Magis5 Hub?

No menu superior, vá para **"Expedição" > "Relatórios de expedição"** e clique em **"PLP"**.

![Imagem 1: No menu superior, vá para "Expedição" > "Relatórios de expedição" e clique em "PLP" .](https://ajuda.sankhya.com.br/hc/article_attachments/44010964027287)

A partir daí será gerado um relatório de todos os seus pedidos com PLP. Observe que é possível verificar o status da mesma.
