# Como clonar um produto dentro do Magis5 Hub?

## É possível clonar um produto, facilitando a criação de outro semelhante.

---

A partir do Magis5 Hub é possível fazer a clonagem de um produto já cadastrado, a fim de modificar informações básicas do mesmo como Imagens e descrições.

Para começar, no Magis5 Hub, vá para a tela de **"Produtos simples e compostos"**.

![Imagem 1: Para começar, no Magis5 Hub, vá para a tela de "Produtos simples e compostos" .](https://ajuda.sankhya.com.br/hc/article_attachments/44010532773655)

Após isso, utilize os filtros na parte de cima da página como desejar e encontre o produto no qual você deseja realizar a clonagem.

Clique no botão de Opções **(três pontinhos)** à direita do mesmo e clique em **"Clonar"**.

![Imagem 2: Clique no botão de Opções (três pontinhos) à direita do mesmo e clique em "Clonar" .](https://ajuda.sankhya.com.br/hc/article_attachments/44010470001559)

Você será redirecionado para o novo produto. Será necessário informar um novo SKU. **Ele deve ser diferente do produto anterior, do qual foi clonado.**

![Imagem 3: Você será redirecionado para o novo produto. Será necessário informar um novo SKU. Ele deve ser diferente do produto…](https://ajuda.sankhya.com.br/hc/article_attachments/44010520040727)
