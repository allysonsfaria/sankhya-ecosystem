# Como atualizar Token Expirado no Magis5 Hub?

## Entenda como atualizar o token expirado das suas integrações de marketplaces.

### Antes de começar:

---

**Importante:** Para reativar um **token expirado**, é necessário estar logado, no mesmo navegador, tanto na conta do marketplace e da loja virtual correspondente (utilizando o usuário **Master**, ou seja, com todas as permissões da conta), no mesmo navegador em que estiver logado com o **Magis5 Hub.**

O procedimento de atualização de **token** descrito a seguir é válido apenas para os seguintes marketplaces: **Mercado Livre, Shopee, AliExpress, Amazon,  Nuvemshop, Olist e Tik Tok**

Feito o login no Magis5, vá para**"Configurações",**depois até**"Integrações"** e por último clique em **"Marketplaces"**
![Imagem 1: Feito o login no Magis5, vá para "Configurações", depois até "Integrações" e por último clique em "Marketplaces"](https://ajuda.sankhya.com.br/hc/article_attachments/44011131446551)

Na aba de **"Integrações"** clique na opção **"Ativar token expirado".**

![Imagem 2: Na aba de "Integrações" clique na opção "Ativar token expirado".](https://ajuda.sankhya.com.br/hc/article_attachments/44011164848151)

**ATENÇÃO ao aviso exibido na nova janela:** conforme já informado, você deve estar logado com a conta **Master** do marketplace em que o [token](https://ajuda.sankhya.com.br/hc/pt-br/articles/44011152655383-Como-atualizar-Token-Expirado-no-Magis5-Hub#token) será reativado, utilizando o mesmo navegador.

![Imagem 3: ATENÇÃO ao aviso exibido na nova janela: conforme já informado, você deve estar logado com a conta Master do…](https://ajuda.sankhya.com.br/hc/article_attachments/44011152954647)

Clique para selecionar o **marketplace** para o qual deseja realizar a atualização do token.

![Imagem 4: Clique para selecionar o marketplace para o qual deseja realizar a atualização do token.](https://ajuda.sankhya.com.br/hc/article_attachments/44011165062295)

Após selecionar o marketplace no qual deseja atualizar o token, clique em **"SIM"** para confirmar.

![Imagem 5: Após selecionar o marketplace no qual deseja atualizar o token, clique em "SIM" para confirmar.](https://ajuda.sankhya.com.br/hc/article_attachments/44011140287767)

Se você estiver logado na conta correta, conforme instruído no início do passo a passo, a **atualização do token será realizada automaticamente.**

Caso contrário, você será redirecionado para a página de login do marketplace para prosseguir com a reativação.

Se, mesmo seguindo o processo indicado, você ainda não conseguir reativar o token expirado, [entre em contato com nosso suporte.](https://ajuda.magis5.com.br/como-abrir-um-suporte-por-bate-papo-na-magis5?hsLang=pt-br)
