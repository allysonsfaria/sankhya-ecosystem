# Como funciona o "Checkout por Pedido" do Magis5 Hub?

## Para facilitar o processo de expedição, o Magis5 Hub conta com diferentes tipos de "checkouts". Este é o "Checkout por Pedido".

---

A funcionalidade de checkout por pedido é indicada para o Seller que tenha um leitor de código de barras. Nesse processo, o sistema irá exibir as informações do(s) produto(s) referente(s) ao pedido para que ele possa ser liberado.

### Como funciona o "Checkout por Pedido" do Magis5

No menu superior dentro do Magis5, vá para **"Expedição" > "Separar pedidos" >  "Checkout por pedido"**.

![Imagem 1: No menu superior dentro do Magis5, vá para "Expedição" > "Separar pedidos" > "Checkout por pedido" .](https://ajuda.sankhya.com.br/hc/article_attachments/44010946695575)

A partir daí será possível bipar pedido a pedido, facilitando assim a sua expedição e evitando quaisquer tipos de erros.

![hh](https://ajuda.sankhya.com.br/hc/article_attachments/44010951224343)

São exibidos os botões para problemas situacionais:

- Caso o produto a ser bipado não possui código de barras, basta apertar o botão em verde;
  ![Imagem 3: Caso o produto a ser bipado não possui código de barras, basta apertar o botão em verde;](https://ajuda.sankhya.com.br/hc/article_attachments/44010951293207)
- Caso encontre algum problema com a leitura do código de barras, basta apertar o botão em amarelo;
  ![Imagem 4: Caso encontre algum problema com a leitura do código de barras, basta apertar o botão em amarelo;](https://ajuda.sankhya.com.br/hc/article_attachments/44010962398871)
- Caso o produto não possuir estoque e isto ainda não tiver sido atualizado dentro do sistema antes da tentativa de bipagem, basta apertar o botão em vermelho.
  ![Imagem 5: Caso o produto não possuir estoque e isto ainda não tiver sido atualizado dentro do sistema antes da tentativa de…](https://ajuda.sankhya.com.br/hc/article_attachments/44010966787479)
