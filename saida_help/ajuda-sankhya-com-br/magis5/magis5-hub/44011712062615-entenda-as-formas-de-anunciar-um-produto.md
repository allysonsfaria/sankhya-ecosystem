# Entenda as formas de anunciar um produto na Amazon

## A Amazon oferece duas formas para adicionar produtos. A escolha de como fazer a inserção irá depender se o produto já está registrado na Amazon ou não. Saiba abaixo quais são as diferenças entre ambas as formas.

---

**⚠️** A funcionalidade **Catálogo do Mercado livre** funciona da mesma forma que a **Buybox da Amazon** - os anúncios de um mesmo produto competem entre si para terem destaque como a melhor oferta desse produto nos primeiros resultados de busca do Marketplace.

### Relacionar seu produto a um anúncio já existente na Amazon

Popularmente conhecido como Buybox, essa estratégia é utilizada quando o item que você deseja vender já está listado na Amazon, permitindo que você adicione seu produto à listagem existente, compartilhando a página do produto com outros vendedores.

Veja abaixo um exemplo de um anúncio buybox na Amazon:

![exemplo1-1](https://ajuda.magis5.com.br/hs-fs/hubfs/exemplo1-1.png?width=688&height=600&name=exemplo1-1.png)

É importante notar que:

- Para anunciar neste modelo, você precisa localizar o item usando a ID do produto (como ISBN, JAN, UPC ou EAN) para vinculá-lo à listagem existente.
- É útil para evitar a duplicação de listagens para o mesmo item.
- As informações principais, como título, descrição marca e imagens, já estão preenchidas na página do produto e caso deseja alterar precisa solicitar alterações para Amazon através de chamado através [deste link](https://sellercentral.amazon.com/help/hub/reference/G200335450?mons_sel_mkid=amzn1.mp.o.A2Q3Y263D00KWC&mons_sel_mcid=amzn1.merchant.o.A2ZPJ4TLUOSWY8&mons_sel_persist=true&stck=NA).
- Você pode especificar seu próprio preço, quantidade disponível e opções de envio.

Para entender como criar um anúncio buybox na Amazon pelo Magis5, **[clique aqui](https://sankhya.zendesk.com/hc/pt-br/articles/44010600881047)**.

### Criar um novo anúncio

Diferente da buybox, esse modelo é usado quando o item que você deseja vender ainda não está cadastrado na Amazon.

É importante notar que:

- Para criar o anúncio nesse modo, é necessário criar uma nova listagem para o produto.
- Você deve escolher a categoria apropriada para o item, o que ajuda os clientes a encontrá-lo nas pesquisas.
- É necessário inserir informações detalhadas do produto, incluindo ID do produto (como UPC, EAN/GTIN, ISBN ou JAN), detalhes da oferta (preço, opções de envio, quantidade disponível, condição do produto), detalhes do produto (nome, marca, descrição, imagens, atributos) e palavras-chave para pesquisa.
- Se o item não possui uma ID, como um código EAN ou GTIN, você pode [solicitar uma isenção](https://sellercentral.amazon.com.br/help/hub/reference/G200426310) para a Amazon.
- A isenção é útil para produtos artesanais, de marca própria, peças automotivas, acessórios para celulares ou kits de produtos.
- A solicitação de isenção envolve verificar a elegibilidade e fornecer comprovante, se necessário.

Para criar um anúncio novo na Amazon pelo Magis5, [clique aqui](https://ajuda.magis5.com.br/como-criar-um-an%C3%BAncio-novo-na-amazon?hsLang=pt-br).

Sendo assim, relacionar a uma oferta existente é apropriado quando o item já está na Amazon, enquanto criar uma nova oferta é necessário quando o item ainda não foi cadastrado e exige a criação de uma nova listagem detalhada. Ambas as opções têm suas vantagens e são usadas com base na situação do produto que você deseja vender.
