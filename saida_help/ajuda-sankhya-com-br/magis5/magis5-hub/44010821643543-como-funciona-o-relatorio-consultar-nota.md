# Como funciona o relatório "Consultar notas fiscais" no Magis5 Hub?

## Acompanhe aqui o histórico completo das notas fiscais emitidas pelo nosso faturador.

---

Para acessar o relatório vá para **"Pedidos"**  e depois clique em **"Consultar notas fiscais"**.

![Imagem 1: Para acessar o relatório vá para "Pedidos" e depois clique em "Consultar notas fiscais" .](https://ajuda.sankhya.com.br/hc/article_attachments/44010843668375)

Nesta tela, serão apresentados os dados das Notas Fiscais emitidas pelo nosso **faturador**. Utilize os filtros no topo da página para localizar registros específicos.

![Imagem 2: Nesta tela, serão apresentados os dados das Notas Fiscais emitidas pelo nosso faturador . Utilize os filtros no topo da…](https://ajuda.sankhya.com.br/hc/article_attachments/44010859564183)

1. **Canal de venda:** filtra as NF emitidas pelo canal de venda
2. **Status:** filtra pelo status da Nota Fiscal 
   ![Imagem 3: Status: filtra pelo status da Nota Fiscal](https://ajuda.sankhya.com.br/hc/article_attachments/44010843906839)
3. **Data Inicial de Emissão:** filtra pela data inicial da emissão
4. **Data final de Emissão:** filtra pela data final da emissão
5. **ERP:** filtra pelo faturador que foram emitidas as Notas Fiscais
6. **Tipo de nota:** filtra pelo tipo de nota 
   ![Imagem 4: Tipo de nota: filtra pelo tipo de nota](https://ajuda.sankhya.com.br/hc/article_attachments/44010831354263)
7. **Numero do pedido:** filtra Notas pelo numero do pedido
8. **N° Nota Fiscal:** filtra pelo numero da Nota Fiscal
9. **Chave da Nota Fiscal:** filtra pela chave de acesso da Nota Fiscal

![wqh](https://ajuda.sankhya.com.br/hc/article_attachments/44010836578199)

No menu de **Opções (⋮)** ao lado do status da nota, você encontrará as ações disponíveis. Note que as funções exibidas variam conforme o status atual da Nota Fiscal.

Listamos alguns exemplo abaixo:

**Autorizada**

- Baixar XML : Essa opção permite baixar o XML na Nota Fiscal
- Baixar PDF : Essa opção permite baixar o PDF na Nota Fiscal
- Devolver NF: Caso precise devolver a Nota Fiscal
- Cancelar NF: Caso precise cancelar a Nota Fiscal emitida
- Ver chave NF: Você consegue visualizar a chave de acesso da Nota Fiscal
- Atualizar NF: Atualiza o status da Nota Fiscal
- Emitir carta de correção: Utilize esta opção para corrigir informações da NF-e já emitida.
  ⚠️Nota: A visualização ou download do documento deve ser realizado diretamente no [Portal Nacional da NF-e.](https://www.nfe.fazenda.gov.br/portal/principal.aspx)

![Imagem 6: Cancelada](https://ajuda.sankhya.com.br/hc/article_attachments/44010844267927)

**Cancelada**

- Baixar XML : Essa opção permite baixar o XML na Nota Fiscal
- Baixar PDF : Essa opção permite baixar o PDF na Nota Fiscal
- Atualizar NF: Atualiza o status da Nota Fiscal

![Imagem 7: Atualizar NF: Atualiza o status da Nota Fiscal](https://ajuda.sankhya.com.br/hc/article_attachments/44010849241879)

**Negada**

- Ver Motivo Rejeição: Permite visualizar o motivo pela qual a NF foi negada
- Atualizar NF: Atualiza o status da Nota Fiscal
- Baixar XML (Negado): Essa opção permite baixar o XML negado da Nota Fiscal

  ![Imagem 8: Baixar XML (Negado): Essa opção permite baixar o XML negado da Nota Fiscal](https://ajuda.sankhya.com.br/hc/article_attachments/44010860139031)

Estes são os status mais frequentes. Lembre-se que, conforme mencionado, as ações disponíveis mudam de acordo com a situação de cada nota.
