# O que quer dizer o erro "A categoria selecionada para este produto não permite variação" ao tentar publicar um anúncio

## O erro pode ocorrer ao publicar anúncio e/ou criar a variação no Magis5 Hub.

---

Segue abaixo uma lista das causas mais comuns referentes a este erro:

1. **O Magis5 Hub não possui funcionalidade para publicação de anúncios com variação no marketplace escolhido.**
   No momento, o Magis5 Hub permite publicação de anúncios com variação de produto apenas pelos marketplaces Shopee e Mercado Livre.
2. **Os produtos internos da variação estão com categoria diferente.**
   Ao criar uma variação, é importante se atentar às categorias dos produtos, deixando todos com a mesma categoria mapeada. Para entender como criar variação para anúncios do **Mercado Livre**, confira [este artigo](https://ajuda.magis5.com.br/criar-an%C3%BAncio-com-varia%C3%A7%C3%A3o-mercado-livre?hsLang=pt-br). Para entender como criar anúncios com variação para a **Shopee**, confira [este artigo](https://sankhya.zendesk.com/hc/pt-br/articles/44010647266327).
