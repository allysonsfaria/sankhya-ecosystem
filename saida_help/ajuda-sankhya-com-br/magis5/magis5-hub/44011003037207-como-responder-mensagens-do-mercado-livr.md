# Como responder mensagens do Mercado Livre dentro do Magis5 Hub?

## O Magis5 Hub permite que você responda as mensagens dos seus clientes dentro do Hub.

---

Para começar, no Magis5 Hub, vá para **"Atendimento"** e depois clique em **"Mensagens"**.

![Imagem 1: Para começar, no Magis5 Hub, vá para "Atendimento" e depois clique em "Mensagens" .](https://ajuda.sankhya.com.br/hc/article_attachments/44011017152407)

Utilize os filtros de busca como preferir.

![Imagem 2: Utilize os filtros de busca como preferir.](https://ajuda.sankhya.com.br/hc/article_attachments/44010994178967)

Perceba que o sistema irá mostrar as mensagens pendentes de resposta. Basta clicar em uma que o sistema exibirá a caixa de texto para respondê-la.

Digite sua mensagem e clique no botão **"Enviar"**.
