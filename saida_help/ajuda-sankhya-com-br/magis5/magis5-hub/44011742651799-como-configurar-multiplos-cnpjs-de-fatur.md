# Como configurar múltiplos CNPJs de faturamento no Magis5 Hub?

## Entenda como integrar múltiplos CNPJs/ERPs no Magis5 hub.

---

No Magis5 Hub, você pode integrar vários ERPs para gerenciar seus marketplaces entre os CNPJs cadastrados de diferentes formas.

Para configurar múltiplos CNPJs de faturamento, crie uma nova conta no ERP de sua preferência para cada CNPJ e adicione-os como ERPs secundários procurando o manual de como integrar seu ERP ao Magis5 Hub. Veja a lista dos manuais de integração de ERPs [clicando aqui](https://ajuda.magis5.com.br/configura%C3%A7%C3%B5es?hsLang=pt-br#integra%C3%A7%C3%B5es-erps-e-faturador).

Sua conta no Magis5 hub possui, por padrão, uma integração disponível para cada ERP. **Para integrar mais de uma conta do mesmo ERP**, você deve ir para a aba de aplicativos dentro do Magis5 Hub para contratar uma integração adicional. Ela está localizada no menu da parte superior da tela.
