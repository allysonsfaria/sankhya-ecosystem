# Como realizar o reset de senha para usuários do Magis5 Hub?

## O reset é necessário quando o usuário esquece a sua senha

### Antes de começar:

---

Esse procedimento precisa ser realizado pelo usuário **proprietário**

Para começar, vá para **"Configurações"**no menu na parte superior, depois até **"Cadastros"** e, por último, clique em **"Usuários"**.

![Imagem 1: Para começar, vá para "Configurações" no menu na parte superior, depois até "Cadastros" e, por último, clique em…](https://ajuda.sankhya.com.br/hc/article_attachments/44011681230615)

Procure nesta lista o usuário para que deseja alterar a senha e clique em **"Editar".**

![edit](https://ajuda.sankhya.com.br/hc/article_attachments/44011688684183)

Clique em **"Resetar Senha"** e depois clique em **"Salvar"**.

![senha](https://ajuda.sankhya.com.br/hc/article_attachments/44011657557655)

Feito este processo, **uma nova senha será enviada ao email do usuário**.

**Para poder atualizar a senha do usuário "proprietário" é necessário abrir um [chamado por chat com o suporte.](https://ajuda.magis5.com.br/como-abrir-um-suporte-por-bate-papo-na-magis5?hsLang=pt-br)**
