# Como solucionar o problema de ausência de anúncios na tela de publicação do Magis5 Hub?

## Veja por que o seu produto não foi para a publicação de anúncios.

---

1. Verifique se o produto tem informações completas, como **fotos, descrição e categoria**.
2. Caso já tenha completado o cadastro, verifique se já foram definidas as opções iniciais de anúncios para este produto.
   1. O Magis5 Hub oferece duas opções de publicação para cada conta do Mercado Livre (clássico e premium).
   2. Uma única opção para cada um dos outros marketplaces.Esta informação pode ser alterada no campo **"Tipo do anúncio"** enquanto ele ainda estiver na tela de **Anúncios a publicar**.
   ![Imagem 1: Uma única opção para cada um dos outros marketplaces.](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Apr-26-2024-02-22-26-3489-PM.png?width=688&height=264&name=image-png-Apr-26-2024-02-22-26-3489-PM.png)
3. Se todas as configurações acima já foram definidas, use a funcionalidade ["Novos anúncios a partir de um produto"](https://sankhya.zendesk.com/hc/pt-br/articles/44010613934359) na tela de Anúncios a publicar.

Caso ainda esteja encontrando problemas, [entre em contato com nosso suporte](https://ajuda.magis5.com.br/como-abrir-um-suporte-por-bate-papo-na-magis5?hsLang=pt-br).
