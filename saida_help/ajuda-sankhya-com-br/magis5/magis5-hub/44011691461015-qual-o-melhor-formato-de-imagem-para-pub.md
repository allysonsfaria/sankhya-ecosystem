Antes de publicar anúncios, é importante saber os tamanhos das imagens a serem publicadas e as regras dos marketplaces nesta publicação. 

Abaixo você confere algumas dicas para aplicar no cadastro de novas imagens.

- Utilize imagens no formato RGB ao invés de de CMYK. Imagens no esquema de cores RGB são mais compatíveis com a maioria dos dispositivos e navegadores e geralmente possuem menor tamanho de arquivo.
- Utilize imagens com resolução de 1200 x 1200 pixels. Caso sejam maiores ou menores que este tamanho, serão automaticamente redimensionadas para este afim de garantir uma boa performance para a página.
- O tamanho máximo aceito é 1920 x 1920 pixels e o mínimo é 40 x 40.
- É possível carregar imagens de até 10 MB nos formatos JPG, JPEG e PNG.
