# Como imprimir lista dos produtos vendidos utilizando a "Picking List" do Magis5 Hub?

## Tenha uma lista com todos os produtos que precisam ser separados para envio e pare de ficar indo e voltando no estoque para buscar produtos.

---

Já se deparou com a situação onde você faz "bolinhos" de etiquetas separando por produtos para que quando for buscar no estoque já traga todas as unidades vendidas do produto de uma vez?

Na Magis5 Hub, isto não é necessário - com apenas alguns cliques você terá uma lista com tudo que precisa buscar, dividida por produtos!

### Como ver os produtos vendidos utilizando a "Picking List" do Magis5 Hub

No menu na parte superior, vá até **"Expedição",** depois até **"Picking"** e por último clique em **"Relatório de picking list".**

![Imagem 1: No menu na parte superior, vá até "Expedição", depois até "Picking" e por último clique em "Relatório de picking list".](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Feb-29-2024-03-51-01-9562-PM.png?width=603&height=383&name=image-png-Feb-29-2024-03-51-01-9562-PM.png)

A partir disto, pode-se usar os filtros para selecionar os produtos e clicar em "Exportar" para gerar um arquivo em PDF ou XLS para impressão.

![Imagem 2: A partir disto, pode-se usar os filtros para selecionar os produtos e clicar em "Exportar" para gerar um arquivo em PDF…](https://ajuda.magis5.com.br/hs-fs/hubfs/image-png-Feb-29-2024-03-55-45-7257-PM.png?width=688&height=274&name=image-png-Feb-29-2024-03-55-45-7257-PM.png)

📝 No relatório de picking list serão listados somente os pedidos que estão no Status "Ag. Separação". [Descubra aqui como funciona este status no nosso "Dashboard".](https://sankhya.zendesk.com/hc/pt-br/articles/44010338051863)
