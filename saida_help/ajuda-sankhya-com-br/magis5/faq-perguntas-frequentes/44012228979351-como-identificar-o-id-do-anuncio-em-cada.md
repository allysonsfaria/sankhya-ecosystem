# Como identificar o ID do anúncio em cada marketplace?

## O ID é uma identificação única para o anúncio nos marketplaces.

Nos marketplaces, cada anúncio geralmente possui um identificador exclusivo, conhecido como "ID do anúncio". Esse ID é usado para rastrear, identificar e gerenciar os produtos ou anúncios dentro da plataforma.

A forma de encontrar o ID do anúncio varia de acordo com cada marketplace, pois cada um possui uma interface e estrutura de dados próprias. No entanto, aqui estão notadas algumas maneiras gerais de identificar o ID do anúncio em diferentes marketplaces.

Dentro da Magis5, em seus anúncios publicados, você pode observar que o campo "Código" é exibido. Este campo contém o ID do anúncio.

![Imagem 1: Dentro da Magis5, em seus anúncios publicados, você pode observar que o campo "Código" é exibido. Este campo contém o…](https://ajuda.sankhya.com.br/hc/article_attachments/44012259047703)

A maneira pela qual o ID é determinado difere em cada marketplace:

- **Mercado Livre**: No Mercado Livre, o ID do anúncio é exibido na URL da página do produto. Geralmente, o ID é um número que aparece após "ID" ou "MLB" na URL. Por exemplo, na URL "https://produto.mercadolivre.com.br/MLB-123456789-produto-exemplo", o ID do anúncio é "123456789"
- **Amazon**: Na Amazon, o ID do anúncio é o SKU do produto.
- **Americanas Marketplace**: Na Americanas Marketplace, o ID do anúncio é o SKU do produto.
- **Magazine Luiza**: No Magazine Luiza, o ID do anúncio é o SKU do produto.
- **Shopee**: Na Shopee, o ID do anúncio pode ser encontrado na URL da página do produto. É o segundo número que aparece após o "/product/" na URL. Por exemplo, na URL "https://shopee.com.br/product/123456789/987654321", o ID do anúncio é "987654321".

A partir destas informações, você conseguirá identificar o ID do seu anúncio.
