# Como criar códigos SKU e EAN para meus produtos?

## Se você precisa organizar o seu controle de produtos por códigos, siga estas dicas!

### EAN

O **código EAN** é um **código de barras definido** pela GS1, amplamente utilizado em todo o mundo para identificar individualmente produtos.

O **EAN-13**, um tipo de código EAN, é composto por treze números divididos em quatro partes. O código contém informações relevantes do produto divididas em país de origem, empresa fabricante, produto fabricado e um dígito verificador.

**Caso um produto não tenha um código de barras impresso**, é recomendável pesquisar EANs, pois pode ser que já existam cadastros (utilize o Google e pesquise por "EAN-13" acompanhado pelo produto e marca a que ele pertence).

Para produtos **sem códigos de barras**, como por exemplo produtos de fabricação própria, remanufaturados ou montados, é indicada a criação dos EANs através da plataforma [CNP (Cadastro Nacional de Produtos) da GS1](https://cnp.gs1br.org/login). É importante que os códigos sejam criados para que haja uma melhor identificação dos produtos e para que seja possível controlar os cadastros de produtos dentro do Magis5.

### SKU

O **SKU, ou "Stock Keeping Unit"** (Unidade de Controle de Estoque), é um código identificador único de um produto, utilizado para controle de estoque, permitindo identificar itens por suas características, como fabricante, tamanho, peso, cor, forma, etc. Um SKU representa qualquer diferença na mercadoria (tamanho, cor, sabor), mesmo sendo de uma mesma marca. **Ele é criado pelo próprio vendedor/seller** para quesitos de controle interno.

Para criar códigos SKU, recomenda-se que os códigos sejam únicos para cada produto, e que não sejam criados números de itens com significado, nem que sejam usados números de série ou código do fabricante. É indicado que se mantenha os números dos itens curtos, mas não tão curtos que possam ser confundidos com outros números, e que sejam usadas algumas letras. **É importante evitar o uso de caracteres especiais que possam confundir pessoas ou softwares (@, #, $, entre outros)!** Existem diversos métodos para criar códigos SKU, incluindo o sequencial.
