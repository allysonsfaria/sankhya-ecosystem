# Benefícios e características do produto Sankhya Cloud

#### 1. O que é o Sankhya Cloud?

EIP Sankhya em ambiente de nuvem com garantia de disponibilidade e segurança em uma única solução.

**Ambiente virtual (nuvem):**

- armazenamento
- processamento
- serviços

**Sankhya Cloud:**

- Sankhya OM - basta ter conectividade com a Internet;
- licenças;
- infraestrutura;
- bancos de dados;
- rede;
- segurança;
- gerenciamento dos recursos;

#### 2. Como o sistema é disponibilizado e mantido?

- Equipe Sankhya Cloud;
- Administradores de Banco de Dados especializados (conformidade com a LGPD);

#### 3. Diferenciação tecnológica

**Acesso fácil:** Basta ter conexão com Internet;

**Segurança:** Sistemas e processos de detecção e prevenção a ataques hackers;

**Monitoramento:** Sistemas de alertas, para que possamos agir de forma preventiva;

**Suporte:** Feito pela Sankhya de forma centralizada, mais fácil e rápido para o cliente;

**Backup:** Realizado várias vezes ao dia;

#### 5. Como funciona a “implantação” desse módulo?

**Vendas novas:**o ambiente Sankhya Cloud é criado e disponibilizado pelo time Cloud em até 3 dias úteis.

![Imagem 3: Vendas novas: o ambiente Sankhya Cloud é criado e disponibilizado pelo time Cloud em até 3 dias úteis.](https://ajuda.sankhya.com.br/hc/article_attachments/4611878384663)

**Vendas na base:** o ambiente Sankhya Cloud é criado e disponibilizado em até 13 dias úteis e logo após as configurações e/ou testes realizados, é feito o agendamento para a migração do ambiente de testes para produção.

Após a liberação do ambiente, inicia-se o processo da implantação. Nesta etapa, podem ser realizadas configurações, importações de cadastros etc; após preparar e configurar o ambiente conforme o cliente deseja, é agendado o processo de migração para produção, que é quando, de fato, o cliente começa a utilizar o ambiente Sankhya Cloud.
