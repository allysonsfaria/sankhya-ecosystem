# Webhooks

O módulo de Webhooks dentro do Omnichannel permite que a plataforma se integre com sistemas externos, enviando notificações e dados em tempo real sobre eventos importantes. Esse módulo é essencial para manter a comunicação entre diferentes sistemas, garantindo que todos os dados necessários sejam transmitidos instantaneamente e de forma segura.

Para acessar o módulo de Webhooks, siga as etapas:

**Buscar Menu > Webhooks**

![Imagem 1: Buscar Menu > Webhooks](https://ajuda.sankhya.com.br/hc/article_attachments/42637022797079)

## Objetivo de negócio

O principal objetivo do módulo de Webhooks é permitir a automação e a integração eficiente com outras plataformas e serviços externos. Isso é crucial para negócios que precisam manter sistemas sincronizados em tempo real, como CRMs, ERPs, sistemas de atendimento ao cliente e outros. Com Webhooks, a empresa pode responder rapidamente a eventos, como mensagens recebidas, atividades de agentes, sessões de voz, interações com bots, e outros, automatizando ações e facilitando a gestão de dados entre sistemas.

## Passo a passo para configuração de Webhooks

### Passo 1: Acessando o módulo de Webhooks

- No menu principal, busque pelo termo "Webhooks" na barra de pesquisa para acessar o módulo específico.
- Na tela de Webhooks, você verá uma mensagem indicando que "Nenhum dado disponível" caso não haja Webhooks configurados.
- ![Imagem 2: Na tela de Webhooks, você verá uma mensagem indicando que "Nenhum dado disponível" caso não haja Webhooks configurados.](https://ajuda.sankhya.com.br/hc/article_attachments/42637007792535)

### Passo 2: Criando um Novo Webhook

1. **Clique no botão "+Criar novo"** para iniciar a criação de um novo webhook.

![Imagem 3: Clique no botão "+Criar novo" para iniciar a criação de um novo webhook.](https://ajuda.sankhya.com.br/hc/article_attachments/42637002674327)

2. **Ativar Webhook:**

   - Certifique-se de que o botão "Ativo" esteja ativado para que o webhook seja funcional.
3. **Selecionar tipo de Webhook:**

   - No campo "Tipo do webhook", selecione o tipo de evento para o qual o webhook será configurado. As opções incluem:

     - Mensagem
     - Atividade do agente
     - Voz
     - Sessão
     - Bot
     - Chat API
   - ![Imagem 4: Chat API](https://ajuda.sankhya.com.br/hc/article_attachments/42637013838871)
4. **Inserir URL:**

   - No campo "URL", adicione o endpoint da URL para onde os dados do evento serão enviados.
5. **Configurar cabeçalho da requisição:**

   - Se necessário, adicione chave e valor para os cabeçalhos da requisição no campo apropriado. Isso é útil para autenticação e configuração de headers customizados.
6. **Salvar configuração:**

   - Após preencher todas as informações, clique no botão "Salvar" para finalizar a criação do webhook.

### Passo 3: Gerenciamento de Webhooks

- Todos os webhooks configurados aparecerão listados com as seguintes colunas:

  - **Tipo:** Indica o tipo de evento associado ao webhook.
  - **URL:** Exibe o endpoint de destino configurado.
  - **Ativo:** Mostra o status do webhook (ativo ou inativo).
  - **Ação:** Permite ações adicionais como editar ou remover o webhook.

Essa configuração permite que o sistema se comunique automaticamente com outras plataformas e serviços, acionando eventos em tempo real conforme necessário.
