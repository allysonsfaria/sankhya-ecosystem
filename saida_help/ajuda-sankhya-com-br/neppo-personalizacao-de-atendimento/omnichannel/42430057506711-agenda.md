# Agenda

Este manual descreve a funcionalidade de **Agenda** da plataforma Neppo, uma ferramenta projetada para **programar, automatizar e gerenciar o envio de comunicações ativas** com os clientes. O objetivo é permitir que o administrador configure o disparo de mensagens (como templates de WhatsApp ou e-mails) para datas e horários específicos, com opções de recorrência.

### Nova tarefa no Calendário

Menu >> Agenda >> Calendário >> Nova Tarefa

Para criar uma nova tarefa no calendário, basta clicar na opção ![Imagem 4: Para criar uma nova tarefa no calendário, basta clicar na opção , localizado no canto esquerdo e superior do…](https://ajuda.sankhya.com.br/hc/article_attachments/42637518835351) , localizado no canto esquerdo e superior do Calendário.
Após isto aparecerá uma tela com a criação dessa tarefa, para criá-la, siga o passo a passo:

● Configurações Básicas.

![Imagem 5: ● Configurações Básicas.](https://ajuda.sankhya.com.br/hc/article_attachments/42637488420631)

● Digite o título da nova tarefa.

![Imagem 6: ● Digite o título da nova tarefa.](https://ajuda.sankhya.com.br/hc/article_attachments/42637505792663)

● Digite a descrição da Tarefa.

![Imagem 7: ● Digite a descrição da Tarefa.](https://ajuda.sankhya.com.br/hc/article_attachments/42637544642327)

● Selecione a data da Tarefa

![Imagem 8: ● Selecione a data da Tarefa](https://ajuda.sankhya.com.br/hc/article_attachments/42637529144343)

● Selecione a hora da Tarefa.

![Imagem 9: ● Selecione a hora da Tarefa.](https://ajuda.sankhya.com.br/hc/article_attachments/42637489065879)

● Selecione a opção de repetir ou não a tarefa.
Caso queira repeti-la, pode realizar A cada ano, A cada mês, A cada semana e Todos os Dias.

![Imagem 10: ● Selecione a opção de repetir ou não a tarefa. Caso queira repeti-la, pode realizar A cada ano, A cada mês, A cada…](https://ajuda.sankhya.com.br/hc/article_attachments/42637529541783)

● Programação da Tarefa.

![Imagem 11: ● Programação da Tarefa.](https://ajuda.sankhya.com.br/hc/article_attachments/42637545383319)

● Coloque o Nome do Grupo.

![Imagem 12: ● Coloque o Nome do Grupo.](https://ajuda.sankhya.com.br/hc/article_attachments/42637489576855)

● Selecione o Canal de Comunicação.

![Imagem 13: ● Selecione o Canal de Comunicação.](https://ajuda.sankhya.com.br/hc/article_attachments/42637507118615)

Caso seja **WhatsApp** é necessário informar o Template WhatsApp.

![Imagem 14: Caso seja WhatsApp é necessário informar o Template WhatsApp.](https://ajuda.sankhya.com.br/hc/article_attachments/42637507289879)

Caso seja **E-mail** informe os dados para envio.

**Em Tipo de Tarefa:** Image ou Message
(Ao selecionar a opção Image, a opção Message será desabilitada, e vice-versa).
**Assunto:** Assunto do e-mail
**Mensagem:** Conteúdo do e-mail

![Imagem 15: Caso seja E-mail informe os dados para envio. Em Tipo de Tarefa: Image ou Message ( Ao selecionar a opção Image, a…](https://ajuda.sankhya.com.br/hc/article_attachments/42637536032791)

Caso seja **Telegram** informe os dados para envio:
**Em Tipo de Tarefa:** Image ou Message
(Ao selecionar a opção Image, a opção Message será desabilitada, e vice-versa).
**Mensagem:** Conteúdo da mensagem de envio

![Imagem 16: Caso seja Telegram informe os dados para envio: Em Tipo de Tarefa: Image ou Message (Ao selecionar a opção Image, a…](https://ajuda.sankhya.com.br/hc/article_attachments/42637507675415)

● Para finalizar, basta clicar na opção de Salvar e, caso contrário, clique na opção

Cancelar.
