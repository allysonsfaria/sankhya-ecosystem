# Comandos Neppo Voz

Este manual apresenta uma lista de referência dos **códigos de atendimento (feature codes)** para o canal de **Voz** da plataforma Neppo.

O objetivo desta funcionalidade é fornecer atalhos de discagem que permitem aos agentes e supervisores executar ações de forma rápida e direta, otimizando o fluxo de trabalho durante e entre as chamadas.

Lista de códigos de atendimento, para atividades como transferência de chamadas etc.

| **Código** | **Nome Descrição** |
| --- | --- |
| \*1 | Transfere para outro ramal |
| \*2 | Grava ligação |
| \*4 | Transfere para outro ramal e mantém o atendimento.  Depois de  digitado o ramal pressione # |
| \*67<Número> | Faz uma ligação privada |
| \*69 | Retorna ligação do último número discado |
| \*870 | Rediscar um número |
| \*9171 | Data atual do servidor |
| \*9170 | Hora atual do servidor |
| \*9172 | Data e hora do servidor |
| \*925 | Agendar alerta |
| \*78 | Não perturbe |
| \*79 | Desativa não perturbe |
| \*33<Número> | Ouvir ligação do ramal |
| \*0[ramal] | Ligação rápida ramal |
| \*21 | Configurar siga-me |
| \*72 | Habilitar encaminhamento de chamada |
| \*73 | Desabilitar encaminhamento de chamada |
| \*74 | Habilita/desabilita encaminhamento |
