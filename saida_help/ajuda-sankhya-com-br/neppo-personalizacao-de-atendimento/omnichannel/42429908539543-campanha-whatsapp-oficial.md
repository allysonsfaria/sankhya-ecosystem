# Campanha - WhatsApp Oficial

Este manual detalha o processo de **Criação de Campanhas** e **Disparo Ativo** na plataforma Neppo. O objetivo é permitir o envio proativo de mensagens em massa pelo WhatsApp, de forma estruturada, agendada e mensurável, utilizando templates pré-aprovados.

- [CRIAÇÃO DA CAMPANHA](https://ajuda.sankhya.com.br/hc/pt-br/articles/42429908539543-Campanha-WhatsApp-Oficial#CRIACAO-DA-CAMPANHA)

**Grupo de Envio:** Grupo que foi selecionado para realizar o envio, o correto é que esse grupo seja onde está inserido o gateway do WhatsApp.
**Cliente:** Nome do cliente para o qual o envio foi realizado.
**Telefone:** Número para o qual o envio foi realizado.
**Mensagem:** Texto enviado.
**Campanha:** Caso o envio da mensagem tenha se dado através de uma campanha aparecerá o nome da mesma.
**Status:** Demonstrará em que situação está o envio (ENVIADA/RECEBIDA/LIDA/ERRO).
**Erro:** Descrição do motivo de erro no envio da mensagem ativa.
**Enviado por:** Agente ou ADM que realizou o envio.
**Criado em:** Data e hora que o envio foi disparado.
**Protocolo:** Só será gerado caso o envio tenha se tornado um atendimento.
