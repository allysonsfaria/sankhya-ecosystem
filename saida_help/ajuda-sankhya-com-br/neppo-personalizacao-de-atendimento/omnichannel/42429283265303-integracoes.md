# Integrações

O objetivo principal desta tela é facilitar a integração entre sistemas utilizando a API Token da Neppo. Isso permite a criação de tokens de acesso que possibilitam a comunicação segura e autorizada entre os serviços de atendimento e os sistemas das empresas, como ERP e CRMs. Com isso, é possível automatizar processos de atendimento e comunicação, aumentando a eficiência operacional e melhorando a experiência do cliente.

Para acessar o módulo de integrações, siga as etapas:

**Buscar Menu > Integrações**

## Fluxo de uso da tela - Integração com Neppo Token API

### 1. Tela principal de integrações

Objetivo: Visualizar todas as integrações disponíveis com os parceiros da Neppo.
Ação Disponível: O usuário pode buscar integrações específicas e acessar a integração da API Token da Neppo clicando no botão 'Acessar' abaixo do ícone correspondente.

### 2. Tela de gestão de tokens - Neppo Token API

Objetivo: Visualizar os tokens de acesso já gerados e gerenciar essas credenciais de forma segura.
Ações Disponíveis:
- Buscar Tokens: O usuário pode buscar tokens previamente gerados utilizando filtros como a data de criação ou o nome do usuário.
- Revogar Tokens: Cada token gerado pode ser revogado caso não seja mais necessário.
- Visualizar Detalhes: O usuário pode visualizar os detalhes dos tokens de acesso gerados.

Objetivo: Permitir ao usuário gerar novos tokens de acesso, fornecendo as credenciais (chave do consumidor, senha do consumidor, usuário e senha) necessárias para a autenticação.
Ação Disponível: O usuário pode copiar as credenciais geradas e fazer uma requisição HTTP utilizando o comando curl, conforme as instruções fornecidas na tela.

Ação Disponível: O usuário pode copiar os tokens e utilizá-los diretamente nas integrações, bem como baixar as informações em formato JSON.

## Considerações de segurança

Após a geração do token de acesso, ele concede acesso total aos dados da conta vinculada. Portanto, é crucial que esses tokens sejam armazenados de maneira segura e sigam práticas recomendadas de segurança para evitar acessos não autorizados.

## Possíveis aplicações

- Automatização de atendimento: Uso em integrações com ERPs, CRMs e sistemas de e-commerce para envio automático de mensagens e suporte.
- Monitoramento e controle: A API pode ser utilizada para criar painéis de controle e monitoramento das interações entre clientes e empresas via WhatsApp.
- Segurança e flexibilidade: Com a possibilidade de revogar e criar tokens, as empresas têm maior controle sobre quem pode acessar seus dados e por quanto tempo.
