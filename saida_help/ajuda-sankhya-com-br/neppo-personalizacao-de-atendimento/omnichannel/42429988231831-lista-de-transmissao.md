# Lista de transmissão

Este manual descreve a funcionalidade de **Listas de Transmissão** na plataforma Neppo. O objetivo é permitir que o administrador crie grupos segmentados de clientes para facilitar o envio de comunicações em massa (como campanhas) no futuro.

- [CRIAÇÃO DA LISTA](https://ajuda.sankhya.com.br/hc/pt-br/articles/42429988231831-Lista-de-transmiss%C3%A3o#CRIACAO-DA-LISTA)

## CRIAÇÃO DA LISTA

Para realizar a criação de uma lista de transmissão basta seguir o passo-a-passo abaixo:

**Menu > Mensagens > Listas de Transmissão**

Na tela **Listas de Transmissão** clique no +.

![Imagem 1: Para realizar a criação de uma lista de transmissão basta seguir o passo-a-passo abaixo: Menu > Mensagens > Listas de…](https://ajuda.sankhya.com.br/hc/article_attachments/42637491511191)

Informe o Nome da lista, selecione o grupo onde estão inseridos os contatos e um agente.

![Imagem 2: Informe o Nome da lista, selecione o grupo onde estão inseridos os contatos e um agente.](https://ajuda.sankhya.com.br/hc/article_attachments/42637491713303)![Imagem 3: Informe o Nome da lista, selecione o grupo onde estão inseridos os contatos e um agente.](https://ajuda.sankhya.com.br/hc/article_attachments/42637492065687)

Ao selecionar o grupo aparecerão os contatos vinculados àquele grupo, você pode pesquisar os contatos e utilizar os botões para incluir ou retirar os clientes da lista:

![Imagem 4: Incluir um ou mais contatos.](https://ajuda.sankhya.com.br/hc/article_attachments/42637439223447) Incluir um ou mais contatos.

![Imagem 5: Incluir todos os contatos de forma massiva.](https://ajuda.sankhya.com.br/hc/article_attachments/42637478011799) Incluir todos os contatos de forma massiva.

![Imagem 6: Retirar um ou mais contatos.](https://ajuda.sankhya.com.br/hc/article_attachments/42637492560663) Retirar um ou mais contatos.

![Imagem 7: Retirar todos os contatos de forma massiva.](https://ajuda.sankhya.com.br/hc/article_attachments/42637478325015) Retirar todos os contatos de forma massiva.

![Imagem 8: Retirar todos os contatos de forma massiva.](https://ajuda.sankhya.com.br/hc/article_attachments/42637439911447)

Após incluir os clientes na lista clique em **SALVAR**.
