# Envio Ativo

Este manual detalha as funcionalidades de **Envio Ativo de Mensagem** da plataforma Neppo, um conjunto de ferramentas para administradores e agentes iniciarem conversas proativas com os clientes usando templates do WhatsApp. O objetivo é explicar os diferentes métodos de disparo, desde envios individuais até em massa.

- [ENVIO INDIVIDUAL - CLIENTE CADASTRADO](https://ajuda.sankhya.com.br/hc/pt-br/articles/42429944134295-Envio-Ativo#ENVIO-INDIVIDUAL---CLIENTE-CADASTRADO)

## ENVIO DE MENSAGEM ATIVA

Para realizar o envio de mensagem ativa ao cliente basta seguir o passo-a-passo abaixo:
Obs. Alguns prints das telas são relacionados ao usuário ADM, mas basta realizar o passo a passo que será possível realizar os envios pelo usuário Agente também.

1 Em **Buscar Menu** digite “Envio Ativo de Mensagem”.

![Imagem 1: 1 Em Buscar Menu digite “Envio Ativo de Mensagem”.](https://ajuda.sankhya.com.br/hc/article_attachments/42637441384727)

2Na tela de **Envio Ativo de Mensagem**

**Grupo de Atendimento:** Grupo no qual estão inseridos os contatos que receberão o envio, e também para onde serão direcionados os atendimentos abertos em decorrência das respostas a esse envio. Isso porque, ao responderem a um envio ativo, um novo atendimento será automaticamente aberto.
**Grupo de Envio:** Grupo onde está o Gateway do WhatsApp.
**Agente:** Quem normalmente receberá o retorno, caso o cliente responda.

![Imagem 2: 2 Na tela de Envio Ativo de Mensagem Grupo de Atendimento: Grupo no qual estão inseridos os contatos que receberão o…](https://ajuda.sankhya.com.br/hc/article_attachments/42637387609239)

**Selecione um canal de envio:** WHATSAPP
**Template Whatsapp**: Selecione o template que enviará ao cliente.

![Imagem 3: Selecione um canal de envio: WHATSAPP Template Whatsapp : Selecione o template que enviará ao cliente.](https://ajuda.sankhya.com.br/hc/article_attachments/42637441701655)

Em **Pesquisar usuários** busque por um ou mais clientes específicos.

Utilize os botões para incluir ou retirar os clientes:

![Imagem 4: Incluir um ou mais clientes.](https://ajuda.sankhya.com.br/hc/article_attachments/42637441865111) Incluir um ou mais clientes.

![Imagem 5: Incluir todos os clientes de forma massiva.](https://ajuda.sankhya.com.br/hc/article_attachments/42637415405207) Incluir todos os clientes de forma massiva.

![Imagem 6: Retirar um ou mais clientes.](https://ajuda.sankhya.com.br/hc/article_attachments/42637403860375) Retirar um ou mais clientes.

![Imagem 7: Incluir todos os clientes de forma massiva.](https://ajuda.sankhya.com.br/hc/article_attachments/42637388449431) Incluir todos os clientes de forma massiva.

![Imagem 8: Incluir todos os clientes de forma massiva.](https://ajuda.sankhya.com.br/hc/article_attachments/42637404274327)

Preencha os parâmetros contidos no template escolhido.

**Cabeçalho:** Selecione a mídia para envio (Imagem, documento ou vídeo).
**Corpo:** Inclua as informações variáveis cadastradas no corpo da mensagem.
**Botão:** Inclua a URL.

Para realizar o envio ativo via planilha, clique no ícone ![Imagem 12: Para realizar o envio ativo via planilha, clique no ícone dentro da tela Envio Ativo de Mensagem.](https://ajuda.sankhya.com.br/hc/article_attachments/42637433511959) dentro da tela Envio Ativo de Mensagem.

![Imagem 13: Para realizar o envio ativo via planilha, clique no ícone dentro da tela Envio Ativo de Mensagem.](https://ajuda.sankhya.com.br/hc/article_attachments/42637420213655)

Após baixar a planilha preencha as informações solicitadas nas colunas:

![Imagem 14: Após baixar a planilha preencha as informações solicitadas nas colunas:](https://ajuda.sankhya.com.br/hc/article_attachments/42637433917591)

As colunas são:

**COUNTRY CODE**: Código do país (Brasil 55)

**CHANNEL ID:** número de telefone do cliente com DDD

**ELEMENT NAME:** nome do elemento - copie o mesmo da tela Templates Whatsapp

**SPACE NAME:** nome do espaço - copie o mesmo da tela Templates Whatsapp

**GROUP:** Grupo onde está o gateway do Whatsapp.
Os campos abaixo só devem ser preenchidos se os parâmetros tiverem sido cadastrados no template.
**HEADER:** cabeçalho - inclua a URL da mídia que você deseja enviar
**BODY**: Se o texto cadastrado tiver parâmetros inclua as informações
Caso você tenha adicionado mais de dois parâmetros no texto, adicione mais colunas ao lado de BODY 2.
**FOOTER:** Esse item não tem parâmetro, portanto não será preenchido.
**BUTTON:** Preencha caso o botão tenha uma URL como variável.

Após o preenchimento dos dados importar a planilha para a plataforma usando a seguinte opção da Tela de Envio Ativo de Mensagem:

![Imagem 15: GROUP: Grupo onde está o gateway do Whatsapp. Os campos abaixo só devem ser preenchidos se os parâmetros tiverem sido…](https://ajuda.sankhya.com.br/hc/article_attachments/42637428366999)

Após clicar, basta importar a planilha.

![Imagem 16: Após clicar, basta importar a planilha.](https://ajuda.sankhya.com.br/hc/article_attachments/42637405739799)

Após realizar o envio da mensagem ativa acompanhe o status na tela **Status de Envio Ativo Mensagem**:

Os filtros que podem ser aplicados são:

**Data Inicial e data final**
**Status**
**Telefone**
**E-mail**
**Canal**
**Grupo de Atendimento**
**Agente**
**Campanha**
**Template**

![Imagem 17: Após realizar o envio da mensagem ativa acompanhe o status na tela Status de Envio Ativo Mensagem : Os filtros que…](https://ajuda.sankhya.com.br/hc/article_attachments/42637405986583)

E as informações trazidas no relatório serão:

**Grupo de Envio:** Grupo que foi selecionado para realizar o envio, o correto é que esse grupo seja onde está inserido o gateway do WhatsApp.
**Cliente:** Nome do cliente para o qual o envio foi realizado.
**Telefone:** Número para o qual o envio foi realizado.
**Mensagem:** Texto enviado.
**Campanha:** Caso o envio da mensagem tenha se dado através de uma campanha aparecerá o nome da mesma.
**Template:** Template que foi utilizado no envio ativo.
**Status:** Demonstrará em que situação está o envio (PROCESSANDO/ENVIADA/RECEBIDA/LIDA/ERRO).
**Erro:** Descrição do motivo de erro no envio da mensagem ativa.
**Enviado por:** Agente ou ADM que realizou o envio.
**Criado em:** Data e hora que o envio foi disparado.
**Protocolo:** Só será gerado caso o envio tenha se tornado um atendimento.
