# Click-to-call

- Para fazer um click-to-call, clicando em um telefone e desejando-se que ele seja copiado para o discador do chat embarcado é necessário lançar o seguinte evento JS:

  ```
  window.dispatchEvent(
    new CustomEvent("neppo-receive-contact", {
      detail: { contact: "5534999999999", channel: "voice" },
    })
  );
  ```

  - note que o telefone precisa ter País+DDD de prefixo
  - se nao tiver o ramal configurado corretamente a aba não funciona

- Para o Whatsapp, o mesmo evento é utilizado, apenas alterando a prop channel para ‘whatsapp’
