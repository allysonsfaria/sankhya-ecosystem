# Componente Playback

## Visão Geral

Este documento tem como finalidade orientar a utilização do componente Playback para fins de criação de bot de voz na funcionalidade Construtor de bot.

## Usabilidade

O componente de Playback é responsável por reproduzir o áudio disponibilizado para o usuário. É possível informar o áudio a ser reproduzido anexando ou informando a URL do arquivo, também poderemos definir o encerramento da reprodução do playback quando o usuário digitar um número durante a chamada ou for detectado uma voz.

É recomendado informar o período de inatividade uma vez que a confirmação do encerramento da reprodução poderá não ser reconhecida pelo bot.
