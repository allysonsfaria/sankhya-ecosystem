# Criar um Chatbot

Este documento orienta o usuário sobre como configurar e inicializar um novo bot para interações automatizadas utilizando o módulo "Construtor de Bots".

## Passo a Passo

### 1. Acessar a Criação

No painel principal (tabela de Chatbots), localize o botão verde no canto superior direito da tela e clique em:

- **+ Novo Chatbot**

### 2. Selecionar o Modelo (Template)

Uma janela se abrirá com opções para iniciar o seu projeto. Você verá um menu lateral com filtros (Todos, Em branco, Sem categorias, etc.).

- Para iniciar um fluxo do zero, selecione a opção **Em branco**.
- Nota: Se houver templates pré-configurados pela sua organização, eles aparecerão nesta lista para seleção.

### 3. Configurar Informações Básicas

Após selecionar o modelo, você será direcionado para a tela **Configurar Chatbot**. Preencha os campos conforme descrito abaixo:

| **Campo** | **Descrição** | **Obrigatório?** |
| --- | --- | --- |
| **Avatar do Bot** | Clique na área tracejada ou arraste uma imagem (PNG, JPG, GIF ou WebP, máx. 5MB) para definir a "cara" do seu bot. | Não |
| **Nome do Bot** | Defina um nome identificador para o bot (ex: "Atendimento N1", "Bot Vendas"). | **Sim** |
| **Descrição** | Insira um breve resumo sobre a função deste bot. Isso ajuda outros administradores a entenderem o propósito do fluxo. | Não |
| **Categoria** | Selecione uma categoria no menu suspenso para organizar seus bots no painel principal. | Não |

Visualização do Fluxo:

No lado esquerdo desta tela, o sistema mostra uma prévia da estrutura que será criada (ex: Fluxo em branco e Fluxo de erro).

### 4. Finalizar Criação

Após preencher as informações necessárias, verifique os dados e clique no botão verde localizado no canto inferior direito:

- **Criar Chatbot**
