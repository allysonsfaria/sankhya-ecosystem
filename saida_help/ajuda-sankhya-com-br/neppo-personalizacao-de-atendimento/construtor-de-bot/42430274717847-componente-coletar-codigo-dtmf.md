# Componente Coletar código DTMF

## Visão Geral

Este documento tem como finalidade orientar a utilização do componente Coletar código DTMF para fins de criação de bot de voz na funcionalidade Construtor de bot.

## Usabilidade

No componente Coletar código DTMF, poderá ser definido a quantidade de dígitos informados pelo usuário, a variável responsável pelo armazenamentos dos dígitos coletados e o tempo de inatividade para aguardar a inserção de dígitos.

DTMF significa Dual-Tone Multi-Frequency, ou Multifrequência de Duplo Tom, em português. É o sistema utilizado para transmitir sinais de teclas pressionadas em um telefone, como os números de 0 a 9, \* e #, por meio de tons audíveis. Cada tecla gera dois tons simultâneos (um de alta frequência e um de baixa frequência), permitindo que sistemas automáticos (como URAs e centrais de atendimento) reconheçam qual tecla foi pressionada.
