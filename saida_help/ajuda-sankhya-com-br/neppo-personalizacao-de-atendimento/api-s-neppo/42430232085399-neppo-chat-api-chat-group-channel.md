**O que é este módulo?**

Gerencia grupos de canais, permitindo organizar canais em conjuntos lógicos para roteamento e relatórios.

| Quem usa | Administradores, gestores de operação. |
| --- | --- |
| Problema que resolve | Sem agrupamento, canais são gerenciados individualmente, dificultando regras de roteamento e relatórios por unidade de negócio. |
| Impacto na experiência do cliente | O atendimento é roteado para o canal correto do grupo certo, garantindo que o cliente fale com a equipe especializada. |

## O que você pode fazer com este módulo

| Operação | O que faz (em linguagem simples) |
| --- | --- |
| **Listar grupos de canais** | Retorna todos os grupos de canais configurados. |
| **Criar grupo** | Cria um novo agrupamento de canais. |
| **Atualizar grupo** | Modifica os canais pertencentes a um grupo. |
| **Remover grupo** | Exclui um agrupamento de canais. |
