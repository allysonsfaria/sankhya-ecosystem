# Status de ticket

A tela de status de ticket tem o objetivo de permitir a criação, edição, ativação e visualização de todos os status disponíveis para o ciclo de vida de um ticket no sistema. Esta tela é essencial para personalização dos fluxos de atendimento conforme a necessidade da operação.

![Imagem 1: A tela de status de ticket tem o objetivo de permitir a criação, edição, ativação e visualização de todos os status…](https://ajuda.sankhya.com.br/hc/article_attachments/42637260451863)

---

### Barra de busca e ações

- **Campo de busca:** Permite buscar status existentes pelo nome.
- **Botão "Criar Status":** Localizado ao lado direito da barra de busca. Abre o formulário para cadastro de novo status.

---

## Tabela de status

| Coluna | Descrição |
| --- | --- |
| **Nome** | Nome do status definido pelo usuário (ex: Começar, Para Fazer, etc.). |
| **Categoria** | Classificação do status: `Status pendente`, `Status andamento`, `Status concluído`. |
| **Ativo** | Indica se o status está ativo ou desativado (com toggle de ativação). |
| **Ações** | Ícone de lápis para editar o status correspondente. |

---

## Categorias de status disponíveis

| Categoria | Descrição |
| --- | --- |
| Status aberto | Estado inicial do ticket (ex: Começar). |
| Status pendente | Indica que o ticket aguarda ação (ex: Para Fazer). |
| Status andamento | Representa que o ticket está em execução (ex: Em Progresso). |
| Status concluído | Indica que o ticket foi finalizado (ex: Concluído). |

---

## Criação de status

### Drawer "Criar status de ticket"

Campos disponíveis:

- **Nome do status de ticket**\* (obrigatório)
- **Categoria de status**\* (dropdown com as opções listadas das categorias)
- **Descrição** (campo opcional)
- **Ativo** (toggle de ativação, padrão ligado)

Botões:

- `Cancelar` (fecha o drawer)
- `+ Criar Status` (salva o novo status)

---

## Edição de status

### Drawer "Alterar status de ticket"

Mesmo layout do modal de criação, mas com dados pré-preenchidos do status selecionado.

Botões:

- `Cancelar`
- `+ Alterar Status`

---

## Funcionalidades adicionais

- **Paginação:** Controle do número de linhas por página no canto inferior direito.
- **Validação de campos:** Campos obrigatórios impedem submissão caso estejam em branco.
