# Chat Interno

O chat interno é uma funcionalidade que tem como finalidade permitir que os usuários internos do sistema interajam entre si de forma rápida e centralizada. O acesso é feito clicando no ícone de balão de diálogo localizado na barra superior do sistema.

![Imagem 1: O chat interno é uma funcionalidade que tem como finalidade permitir que os usuários internos do sistema interajam…](https://ajuda.sankhya.com.br/hc/article_attachments/42639572626967)

O recurso está disponível para as seguintes visões de usuário:

- Visão ADM/Supervisor
- Visão Agente
- Visão Supervisor/Agente

## Navegação e Abas

Ao abrir o Chat Interno, o usuário terá duas abas principais na parte inferior da janela:

### Aba "Conversas"

- Dentro desta aba estarão listadas todas as conversas individuais e em grupo que já foram realizadas.

### Aba "Contatos"

- Nesta aba estarão visíveis todos os usuários que estão cadastrados e ativos na plataforma.
- Para iniciar uma nova conversa, basta clicar sobre o nome do usuário desejado.

## Recursos de Interação

Ao clicar em um contato e iniciar uma conversa, ou ao entrar em uma interação que já está em curso, o usuário conta com diversas ferramentas:

- **Status do Usuário:** Na barra superior da conversa, será exibido o status em tempo real (Online ou Offline) do usuário com o qual está sendo realizada a interação.
- **Envio de Emojis:** É possível utilizar a função de envio de emojis para tornar a comunicação mais dinâmica.
- **Envio de Anexos:** O chat permite o compartilhamento de arquivos. Para anexar, o usuário pode clicar no ícone de clipe e selecionar os arquivos a partir das pastas do computador, ou simplesmente arrastar os arquivos para a tela do chat.
- **Responder a Mensagens Específicas:** Com o botão de reply (ícone de seta ao lado da mensagem), será possível responder diretamente a mensagens específicas dentro do fluxo da conversa.

## Criação de Grupos

Além de conversas individuais (1:1), o sistema permite a criação de grupos de usuários para conversação.

**Passo a passo para criar um grupo:**

1. Acesse a aba **Contatos** e clique em **+ Novo Grupo**.
2. Utilize o campo de busca ("Buscar") para procurar pelos contatos que farão parte do grupo.
3. Marque as caixas de seleção ao lado dos usuários que deseja adicionar.
4. Informe o nome desejado para o grupo no campo correspondente.
5. Clique no botão **SALVAR** para concluir a criação.
6. Os grupos criados ficarão disponíveis e poderão ser acessados na aba **Conversas**.
