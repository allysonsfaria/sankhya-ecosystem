## Visão Geral

Este documento descreve a usabilidade do NEPPO Vault, uma solução integrada que permite armazenar e gerenciar credenciais, valores, chaves de API e outros dados sensíveis de forma **100% segura**, compartilhando de forma segura com usuários ou chatbots, eliminando a necessidade de expor informações confidenciais em códigos ou configurações.

Os tokens gerados através da funcionalidade “Integrações” serão exibidos automaticamente no Neppo Vault e poderão ser acessados no diretório “chatapi”.

A funcionalidade só poderá ser acessada por usuários logados.

## Usabilidade

### Novo diretório

O Neppo Vault já possui um diretório pré-parametrizado, mas é possível criar outros diretórios através do botão “Criar diretório”.

Ao acionar o botão “Criar diretório” será exibido um novo registro onde O usuário poderá definir uma nomenclatura. Ao definir a nomenclatura, O usuário deverá acionar o comando “Salvar” ou, caso deseje cancelar, acione o comando “Cancelar”.

Ao acionar o ícone “Novo diretório” será exibido um novo registro vinculado ao diretório onde O usuário poderá definir uma nomenclatura. Ao definir a nomenclatura, O usuário deverá acionar o comando “Salvar” ou, caso deseje cancelar, acione o comando “Cancelar”.

### Novo valor

O usuário poderá adicionar o valor a ser armazenado acionando o ícone “Novo Item” diretamente em um diretório criado anteriormente.

![Imagem 5: O usuário poderá adicionar o valor a ser armazenado acionando o ícone “Novo Item” diretamente em um diretório criado…](https://ajuda.sankhya.com.br/hc/article_attachments/42639310518423)

Ao acionar o ícone “Novo Item” será exibido uma interface para preenchimento dos campos de Nome do valor, descrição, formato e o valor. Os campos “Nome do valor” e “Valor” são de preenchimento obrigatório, o que não permite que seja salvo sem preencher os campos. Ao finalizar o preenchimento, O usuário deverá acionar o comando “Salvar” ou, caso deseje cancelar, acione o comando “Fechar”.

O registro de valor não permite a alteração do campo “Nome do valor” posteriormente, dito isso, pense previamente no nome que deseja.

![Imagem 6: O registro de valor não permite a alteração do campo “Nome do valor” posteriormente, dito isso, pense previamente no…](https://ajuda.sankhya.com.br/hc/article_attachments/42639314082583)

### Excluir Diretório

O usuário poderá excluir um diretório acionando o ícone “Remover” diretamente no registro desejado.

![Imagem 7: O usuário poderá excluir um diretório acionando o ícone “Remover” diretamente no registro desejado.](https://ajuda.sankhya.com.br/hc/article_attachments/42639314271511)

Ao acionar o ícone “Remover”, uma mensagem de exceção será exibida via pop-up para que confirme a exclusão do diretório.

O usuário deverá ter certeza da ação, pois é irreversível e poderá afetar fluxos já existentes.

![Imagem 8: O usuário deverá ter certeza da ação, pois é irreversível e poderá afetar fluxos já existentes.](https://ajuda.sankhya.com.br/hc/article_attachments/42639300046359)

### Compartilhar

O usuário poderá compartilhar a URL acionando o botão “Compartilhar” na visualização do registro de valor. Ao acionar o botão a URL será copiada para área de transferência e poderá ser enviada ou copiada utilizando o atalho do teclado “CTRL+V” ou acionando o botão direito do mouse e clicando na opção “Colar”.

### Editar valor

O usuário poderá alterar o registro de valor acionando o ícone “Editar Item” diretamente no registro desejado.

![Imagem 12: O usuário poderá alterar o registro de valor acionando o ícone “Editar Item” diretamente no registro desejado.](https://ajuda.sankhya.com.br/hc/article_attachments/42639345505047)

Ao acionar o ícone “Editar Item” será exibido o “modal” para alteração dos campos, com exceção do campo “Nome do valor” que não permite edição. Ao finalizar a alteração, O usuário deverá acionar o comando “Salvar” ou, caso deseje cancelar, acione o comando “Fechar”.

![Imagem 13: Ao acionar o ícone “Editar Item” será exibido o “modal” para alteração dos campos, com exceção do campo “Nome do valor”…](https://ajuda.sankhya.com.br/hc/article_attachments/42639345770135)

### Copiar TAG

O usuário poderá copiar a TAG do registro de valor acionando o ícone “Copiar para área de transferência”. Ao copiar, a TAG ficará disponível para ser copiada ou enviada utilizando o atalho do teclado “CTRL+V” ou acionando o botão direito do mouse e clicando na opção “Colar”. Essa TAG poderá ser utilizada para pesquisar o registro no filtro de pesquisa.

![Imagem 14: O usuário poderá copiar a TAG do registro de valor acionando o ícone “Copiar para área de transferência”. Ao copiar, a…](https://ajuda.sankhya.com.br/hc/article_attachments/42639316049175)

### Filtro de Pesquisa

O usuário poderá pesquisar por um diretório ou valor diretamente pelo filtro de pesquisa disponível na interface, apenas informando o nome ou a TAG do valor copiada a partir do ícone “Copiar TAG para área de transferência”.

Para visualizar novamente todos os diretórios, O usuário deverá apagar os dados informados no filtro de pesquisa.

![Imagem 15: Para visualizar novamente todos os diretórios, O usuário deverá apagar os dados informados no filtro de pesquisa.](https://ajuda.sankhya.com.br/hc/article_attachments/42639316235287)
