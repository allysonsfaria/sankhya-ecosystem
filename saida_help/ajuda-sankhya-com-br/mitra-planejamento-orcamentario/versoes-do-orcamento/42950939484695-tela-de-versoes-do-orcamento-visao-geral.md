# Tela de versões do orçamento: visão geral e utilização

## Tela de versões do orçamento: visão geral e utilização

**Módulo:** Versões do orçamento

### O que é e para que serve

A tela de versões lista todos os ciclos orçamentários já criados e concentra as operações de ciclo: criar, duplicar e fechar versões. Cada versão carrega seu ano, status, último mês realizado e marcações especiais.

### Informações exibidas

| Informação | O que significa |
| --- | --- |
| Nome e ano | Identificação da versão (ex.: `Orçamento 2026: 0+12`, `Forecast 2026 (5+7)`) |
| Status | **Iniciada** (aberta para preenchimento) ou **Fechada** |
| Último mês realizado | Quantos meses ficam travados como realizado no preenchimento |
| Versão atual | Marca a versão vigente do processo |
| Versão de controle | Versão usada como referência de comparação no preenchimento |
| Origem | Em duplicações, indica de qual versão os dados foram copiados |

### Ações e controles

| Ação | O que faz |
| --- | --- |
| Criar versão | Abre um novo ciclo copiando as premissas da versão anterior |
| Duplicar versão | Novo ciclo copiando também os dados preenchidos da origem |
| Fechar versão | Encerra o ciclo: congela o total de modelos e desativa os links dos gestores |

### Comportamentos e pontos de atenção

- Criar uma versão **fecha automaticamente as abertas** — só existe um ciclo em preenchimento por vez.
- Versões fechadas permanecem consultáveis nos comparativos e na DRE.
- Para o passo a passo seguro da criação, consulte o artigo de melhores práticas relacionado.

### Resultado esperado

Histórico de versões organizado, com a versão vigente identificada, as fechadas preservadas para comparação e a versão de controle definida.
