# Erro na primeira etapa de importação

## O que posso fazer quando o Ploomes não aceita a minha planilha?

Planilhas muito estilizadas podem gerar algum tipo de erro na hora da importação. Uma solução comum e fácil é copiar apenas os dados da sua planilha, colá-los em uma nova e importá-la.

Passo 1: copiar os dados

[![Imagem 1: Passo 1: copiar os dados](https://ploomes-52ceb6b026db.intercom-attachments-7.com/i/o/369328744/3be99d0f231a82db7e4b8c11/image.png-expires%3D1619463600-signature%3D38f7eb99950d4c3e76d560c5e986b9569768c733e49fef93235ac0bdc65cd79f?expires=1786536000&signature=4f651c63835a2cb07202e70f6c1d373acf775e080713296e07265620f7b9cd7f&req=dyYuFct2moVbFb4V1XW4gW8zCZzn6WWd9EYdYCGOO8WlX5xxBFU%2BJAPRg1O7%0A8tvRgDm5cnS4bGrrBsZN3RNQiQ%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/115601206/5eaa9cdd10c0ffc49dfdfde7/image.png?expires=1619463600&signature=38f7eb99950d4c3e76d560c5e986b9569768c733e49fef93235ac0bdc65cd79f)

Selecione seus dados e aperte ctrl + C.

Passo 2: Criar uma nova planilha
Abra uma nova planilha e nela cole os dados que acabou de copiar, clicando com o botão direito colando apenas valores. Use essa nova planilha para importar seus dados para o Ploomes e exclua a planilha antiga.

Será preciso verificar as considerações abaixo:

- O arquivo precisa estar no formato .xlsx;
- Não podem haver filtros ou fórmulas;
- Não podem haver colunas, linhas ou planilhas ocultas.

Caso o erro permaneça favor entrar em contato com o suporte.
