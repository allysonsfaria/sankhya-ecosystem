# Integração com Pluga

## O que é a Pluga?

A Pluga é uma plataforma de integração que conecta as ferramentas que você usa na sua empresa. E o melhor: sem você precisar ter nenhum tipo de conhecimento técnico.

Ou seja, através das integrações da Pluga você consegue eliminar aquele trabalho manual (e até chato) de ficar copiando e colando dados de uma ferramenta para a outra, e sem precisar desenvolver uma única linha de código. 🤖

E isso acontece da seguinte forma:

**Quando algo acontecer na Ferramenta A** → **gerar uma ação na Ferramenta B.**

O vídeo abaixo ilustra um pouco mais sobre o que é a Pluga:

[Vídeo: tutorial do artigo](https://www.youtube.com/watch?v=mAr3cMXRbBM)

## Como funciona a Pluga?

Para criar uma automatização da Pluga com o Ploomes, você precisa seguir basicamente 3 passos:

1. Acessar a **[página de ferramentas](https://pluga.co/ferramentas/ploomes/integracao/)** e escolha a ferramenta que deseja integrar ao Ploomes e quais processos automatizar;
2. Autenticar as ferramentas, permitindo que a Pluga possa receber e enviar informações entre as ferramentas;
3. Configurar a sua automatização, definindo quais informações serão enviadas de uma ferramenta para a outra.

## Não encontrei a ferramenta que gostaria de integrar com o Ploomes, o que fazer?

O **Pluga Webhooks** é a alternativa desenvolvida para criar automatizações com ferramentas ainda não integradas.

Para isso, a ferramenta não integrada precisa:

- Fazer integrações via webhook;
- Possuir um JSON pronto;
- Ter uma área para configurar o webhook.

Para saber mais sobre o Pluga Webhooks, clique **[aqui](https://pluga.co/webhooks)**.

Para conhecer as automatizações possíveis com Pluga Webhooks e Ploomes, clique **[aqui](https://pluga.co/ferramentas/ploomes/integracao/pluga_webhooks/)**.
