# Como integrar o Ploomes com o Gmail (via Pluga)

**Observação:**

Essa integração foi desenvolvida pelo nosso parceiro Pluga. Caso tenha ficado com alguma dúvida, o time da Pluga estará à disposição para te ajudar.

É só enviar um e-mail para [suporte@pluga.co](mailto:suporte@pluga.co).

## Pluga | Como integrar o Ploomes com o Gmail

## O que esta integração faz?

A cada **e-mail recebido** no Gmail com um **marcador ou filtro específico**, **criar** ou **atualizar** automaticamente um **cliente**, **oportunidade** ou **atividade** no Ploomes.

**OU**

Quando um **card, cliente ou proposta** forem atualizados, **enviar um e-mail** automaticamente pelo Gmail.

## Requisitos

- Uma conta no Ploomes;
- Uma conta no Gmail;
- Uma conta na [Pluga](https://pluga.co/).

É obrigatório que selecione qual a guia ou marcador que, aplicado a um e-mail, irá disparar a integração. Defina se você deseja captar todos os emails, somente os emails já lidos ou somente os emails não lidos e, após isso, clique em “**Continuar**”.
