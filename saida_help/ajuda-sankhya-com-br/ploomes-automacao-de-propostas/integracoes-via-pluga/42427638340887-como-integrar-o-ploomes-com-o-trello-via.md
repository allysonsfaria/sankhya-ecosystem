# Como integrar o Ploomes com o Trello (via Pluga)

**Observação:**

Essa integração foi desenvolvida pelo nosso parceiro Pluga. Caso tenha ficado com alguma dúvida, o time da Pluga estará à disposição para te ajudar.

É só enviar um e-mail para [suporte@pluga.co](mailto:suporte@pluga.co).

## Pluga | Como integrar o Ploomes com o Trello

## O que esta integração faz?

Quando um **novo cliente for criado** no Ploomes, criar um card no Trello.

**OU**

A cada proposta ou card **ganho**, **perdido**, **criado** **ou quando um card alcançar determinada etapa** no Ploomes, criar um card no Trello.

**OU**

Quando um **card for movido** para uma determinada lista do Trello, **criar/atualizar um cliente ou um card** no Ploomes.

## Requisitos

- Uma conta no Ploomes;
- Uma conta no Trello;
- Uma conta na [Pluga](https://pluga.co/).
