# Como integrar o Ploomes com a Zendesk (via Pluga)

**Observação:**

Essa integração foi desenvolvida pelo nosso parceiro Pluga. Caso tenha ficado com alguma dúvida, o time da Pluga estará à disposição para te ajudar.

É só enviar um e-mail para [suporte@pluga.co](mailto:suporte@pluga.co).

## Pluga | Como integrar o Ploomes com a Zendesk

## O que esta integração faz?

Quando um **novo cliente for criado** no Ploomes, criar um ticket no Zendesk.

**OU**

A cada proposta ou card **ganho**, **perdido**, **criado** **ou quando um card alcançar determinada etapa** no Ploomes, criar um ticket no Zendesk.

**OU**

A cada **novo usuário** criado no Zendesk, **criar/atualizar um cliente ou um card** no Ploomes.

## Requisitos

- Uma conta no Ploomes;
- Uma conta no Zendesk;
- Uma conta na [Pluga](https://pluga.co/).
