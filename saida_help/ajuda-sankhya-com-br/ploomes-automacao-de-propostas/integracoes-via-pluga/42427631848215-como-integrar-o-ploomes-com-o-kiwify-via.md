# Como integrar o Ploomes com o Kiwify (via Pluga)

**Observação:**

Essa integração foi desenvolvida pelo nosso parceiro Pluga. Caso tenha ficado com alguma dúvida, o time da Pluga estará à disposição para te ajudar.

É só enviar um e-mail para [suporte@pluga.co](mailto:suporte@pluga.co).

## Pluga | Como integrar o Ploomes com o Kiwify

## O que esta integração faz?

A cada **carrinho abandonado** no Kiwify, criar automaticamente uma **oportunidade de venda** no Ploomes.

**OU**

Ou então, a cada **compra finalizada** no Kiwify, criar automaticamente uma **oportunidade de venda** no Ploomes.

## Requisitos

- Uma conta no Ploomes;
- Uma conta no Kiwify;
- Uma conta na [Pluga](https://pluga.co/).
