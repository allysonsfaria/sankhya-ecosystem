# Como integrar o Ploomes com o Conta Azul (via Pluga)

**Observação:**

Essa integração foi desenvolvida pelo nosso parceiro Pluga. Caso tenha ficado com alguma dúvida, o time da Pluga estará à disposição para te ajudar.

É só enviar um e-mail para [suporte@pluga.co](mailto:suporte@pluga.co).

## Pluga | Como integrar o Ploomes com o Conta Azul

## O que esta integração faz?

Quando um **novo cliente for criado** no Ploomes, criar/ atualizar um cliente no Conta Azul.

**OU**

A cada proposta ou card **ganho**, **perdido**, **criado** **ou quando um card alcançar determinada etapa** no Ploomes, criar/atualizar um cliente no Conta Azul. Além disso, a cada proposta ou card **ganho** no Ploomes também há a opção de criar uma venda no Conta Azul.

**OU**

A cada **venda criada** no Conta Azul, **criar/atualizar um cliente ou um card** no Ploomes.

## Requisitos

- Uma conta no Ploomes;
- Uma conta no Conta Azul;
- Uma conta na [Pluga](https://pluga.co/).
