# Como integrar o Ploomes com o ClickUp (via Pluga)

**Observação:**

Essa integração foi desenvolvida pelo nosso parceiro Pluga. Caso tenha ficado com alguma dúvida, o time da Pluga estará à disposição para te ajudar.

É só enviar um e-mail para [suporte@pluga.co](mailto:suporte@pluga.co).

---

## O que esta integração faz?

Com a integração entre o Ploomes e o ClickUp, você conecta o seu CRM à sua ferramenta de gestão de projetos e tarefas — garantindo que cada avanço comercial gere automaticamente as ações operacionais correspondentes, sem nenhum passo manual.

A cada card criado no Ploomes, criar ou atualizar uma tarefa no ClickUp para o responsável comercial. Ou então, quando um card alcançar uma etapa específica do funil, gerar automaticamente uma nova tarefa no ClickUp com os dados do negócio. A cada card ganho, criar uma tarefa de onboarding ou pós-venda. A cada card perdido, registrar uma tarefa de análise de perda. A cada proposta criada ou ganha no Ploomes, criar uma tarefa correspondente no ClickUp para acompanhamento de entregas.

No sentido contrário, a cada tarefa criada no ClickUp, criar ou atualizar um card ou cliente no Ploomes — mantendo o CRM sempre atualizado a partir de ações que partem da sua ferramenta de projetos.

Dentre outras opções.

Dessa forma, os times comercial e operacional trabalham de forma mais coordenada, com visibilidade em tempo real sobre o andamento das oportunidades e sem depender de atualizações manuais entre ferramentas.

## Requisitos

- Uma conta no Ploomes;
- Uma conta no ClickUp;
- Uma conta na Pluga.

Nota: Os gatilhos Proposta criada, Proposta ganha e Proposta perdida do Ploomes são recursos Premium e estão disponíveis nos planos pagos da Pluga.
