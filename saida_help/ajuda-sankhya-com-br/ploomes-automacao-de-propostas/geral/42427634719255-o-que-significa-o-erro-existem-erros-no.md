# O que significa o erro "Existem erros no formulário!"?

## O que fazer quando não consegue salvar o formulário?

![Imagem 1: O que fazer quando não consegue salvar o formulário?](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329054/79aa47884c9ff4024544121b/mceclip0.png?expires=1786536000&signature=2586567fa5f87ad55482fc1e732819ff292ff702c531b1865a43f0e70a2586cf&req=dyYuFct3nYRbFb4V1XW4gbJbNRBK3id810t3JVDklKWiye7fetPCGETC9EGl%0AYLJ68JJDDpexy%2FLoQMur4RWjkQ%3D%3D%0A)

Quando você tenta salvar um formulário e isso aparece, três coisas podem estar acontecendo:

1. Um campo obrigatório não foi preenchido

[![Imagem 2: Um campo obrigatório não foi preenchido](https://ploomes-52ceb6b026db.intercom-attachments-7.com/i/o/369329057/c41d38c35ca3f65728fa74dc/image.png-expires%3D1619409600-signature%3D79ee8afa5e8e9ff0e6e41cfc50df0f90848029c471383036e71e27b072ad06d7?expires=1786536000&signature=57785c4132f638a596cdf3857a202c107b32912e058da434314d59d143eba930&req=dyYuFct3nYRYFb4V1XW4gVTGAMH0ZjyvWYoDJJwVqhN9MziiEo5tJRwvnp%2Fl%0AFyw930fKZtyO2h1pN8mgLELrXg%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/117948417/032806c22b44824e4f5c8003/image.png?expires=1619409600&signature=79ee8afa5e8e9ff0e6e41cfc50df0f90848029c471383036e71e27b072ad06d7)

Quando esse ícone aparece, significa que um campo obrigatório não foi preenchido. O formulário só salva se você preenche todos os campos obrigatórios.

 2. Um campo chave está em conflito

[![Imagem 3: Quando esse ícone aparece, significa que um campo obrigatório não foi preenchido. O formulário só salva se você…](https://ploomes-52ceb6b026db.intercom-attachments-7.com/i/o/369329062/73f1048a6345c17fcd32debf/image.png-expires%3D1619409600-signature%3Df3336f2b715bd7413a0078012560056fee97ec153bbc56e86e26b11b41a77c63?expires=1786536000&signature=7c0b16bac34b5b5808b4c22385baf427277d3f45a6ac2058acf76a56cc94adf6&req=dyYuFct3nYddFb4V1XW4gX9obUky7atDKm%2F2cWpXcp%2BXYemiAIX57ynCb8aA%0AkFqIdM%2BP8FdBf8YhykAJUJCNug%3D%3D%0A)](https://downloads.intercomcdn.com/i/o/252755058/385b799f8d94c47185173946/image.png?expires=1619409600&signature=f3336f2b715bd7413a0078012560056fee97ec153bbc56e86e26b11b41a77c63)

Esse ícone significa que o campo é chave: não podem haver dois iguais no sistema. Seja um CNPJ, Email ou telefone, serve para evitar duplicidade.

 3. O campo tem uma máscara

![Imagem 4: Esse ícone significa que o campo é chave: não podem haver dois iguais no sistema. Seja um CNPJ, Email ou telefone,…](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329068/36cb91499500ad1484191a2d/mceclip1.png?expires=1786536000&signature=69609eb0a1ca57ee40ce3cd973275aebe75bed946a1919bc96c05ee32497946d&req=dyYuFct3nYdXFb4V1XW4gSLk3fGFlXiumQlgCGMXEozZQTHw0hPOncF3J3O3%0AX%2B0%2FlhbiKZLnT7uuGSU%2Fi3JTxQ%3D%3D%0A)

Comum em CPF, CNPJ e telefones, a máscara dita como o campo será preenchido. Se eu não colocar todos os números, inserir uma letra ou inserir o dígito verificador incorreto, o campo fica vermelho e impede o usuário de salvar.
