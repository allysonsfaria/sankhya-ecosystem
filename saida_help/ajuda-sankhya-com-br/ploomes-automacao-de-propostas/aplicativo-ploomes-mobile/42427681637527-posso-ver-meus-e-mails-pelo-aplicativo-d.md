# Posso ver meus e-mails pelo aplicativo do Ploomes?

É possível visualizar e-mails vinculados a clientes pelo aplicativo, como atividades no módulo 'atividades' ou no histórico de um cliente ou negócio.

Não é possível enviar e-mails ou visualizar uma lista de e-mails recebidos pelo app do Ploomes; para isso, recomenda-se usar o gerenciador de e-mails padrão do celular.
