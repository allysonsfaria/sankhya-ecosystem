# Assinatura pelo aplicativo

O campo de assinatura, quando adicionado dentro de um modelo de proposta, venda ou documento,
permite a assinatura manual do usuário por meio do aplicativo da Ploomes. O cliente vai
abrir o documento no aplicativo e escrever com o dedo ou uma caneta própria de celular as
assinaturas solicitadas. As escritas serão utilizadas como imagens no PDF do documento.

## Como configurar a assinatura

1. Acesse o ploomes pelo computador.
2. Em Administração - modelos de documento; selecione um modelo ou crie um novo.
3. Escolha a seção do modelo onde será inserido o campo, e clique em 'Campos' - 'Proposta' - 'Criar campo'
4. À esquerda, selecione o **tipo** do campo "Assinatura". Dê um nome e crie o campo.
5. O campo aparecerá como uma imagem no modelo ao gerar o PDF.

## Assinando um campo

1. 1. No aplicativo do Ploomes, selecione no menu inferior o modelo criado com a assinatura.
   2. Ao clicar na visualização do documento, no menu inferior aparece a opção 'Assinar'.
   3. O contador mostra quantas assinaturas faltam - nele, abre-se uma lista com todas as assinaturas do modelo, mostrando se foram assinadas ou não.
   4. Selecione o campo desejado, e clique em 'Assinar'.
   5. A tela de assinatura possui três botões:
      ● Apagar: Vai apagar o desenho feito pelo usuário. Antes disso, vai aparecer
      uma janela de confirmação.
      ● Voltar: Irá voltar para a tela anterior. Antes disso vai aparecer uma janela de
      confirmação se tiver algum desenho feito, pois ele será apagado ao voltar.
      ● Salvar: Irá enviar a assinatura para a API e retornar para a tela de
      visualização, carregando o documento novamente para que a assinatura seja
      visível no PDF.
