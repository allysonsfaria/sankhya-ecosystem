# Analytics no App

## 1) Sobre a funcionalidade

A funcionalidade de Analytics no aplicativo foi desenhada para que você leve seus indicadores de performance para onde for. Agora, é possível visualizar os mesmos gráficos configurados na versão Web diretamente no seu dispositivo móvel, garantindo que a tomada de decisão baseada em dados esteja sempre ao alcance das suas mãos. Com uma interface otimizada, você acompanha o desempenho da sua operação com rapidez e mobilidade.

---

## 2) Pré-requisitos

- Possuir permissão de visualização de painéis (configurada na versão Web).
- Ter ao menos um painel de relatórios criado e compartilhado com seu usuário.

---

### 3.3) Widget de Relatórios na Home:

Para facilitar o acompanhamento rápido, a tela inicial do app apresenta um widget em formato de carrossel.

- **O que ele mostra:** Até 3 gráficos do último painel que você visualizou.
- **Acesso rápido:** Clique no botão "Ver Mais" para ser direcionado imediatamente à tela completa de relatórios.
- **Inteligência de exibição:** Se você perder o acesso a um painel, o widget se ajustará automaticamente para exibir os dados do próximo painel disponível.

Para analisar um gráfico com mais detalhes, você pode expandir a visualização:

- Clique no ícone de expansão localizado no **canto superior direito** de cada card de gráfico.
- Com a tela expandida, utilize os dedos para dar **zoom** ou realizar o **scroll** lateral e vertical para visualizar tabelas ou eixos mais extensos.

### 3.5) Atualizando as informações:

É possível solicitar manualmente a atualização dos gráficos de um painel de duas formas:

- **Atualização individual:** Clique no ícone de **relógio** em um gráfico específico para recarregar apenas aquele dado.
- **Atualização em massa:** Se você possui a funcionalidade de Atualizar painel no Ploomes Web (incluso principalmente para contas com **módulo de Analytics** **na versão PRO**), basta arrastar a tela para baixo para atualizar todos os gráficos do painel simultaneamente.

Caso queira saber mais sobre os benefícios da versão PRO do módulo de **Analytics**, entre em contato com o time de suporte ou com o seu Gerente de Conta.

## 4) Limitações do Analytics no App

- **Criação e Edição:** Não é possível criar novos relatórios, filtros ou editar a estrutura dos gráficos existentes pelo aplicativo. Essas ações devem ser realizadas exclusivamente na versão Web.
- **Atualização em massa:** A função de "puxar para atualizar" todos os gráficos de uma vez é restrita a usuários com módulo Pro ou permissões específicas.
- **Uso no Modo Offline:** Não é possível visualizar os gráficos quando o aplicativo estiver no Modo Offline/Sem conexão com a internet
- **Limite de dados:** Gráficos com filtros que retornem mais de 10.000 dados não são exibidos no aplicativo, e uma mensagem informativa será exibida.

## 5) F.A.Q.

### 5.1) Posso editar permissões de acesso a painéis pelo celular?

Não. Para realizar qualquer tipo de alteração em gráficos e painéis, acesso o relatórios na versão Web.

### 5.2) Posso criar ou alterar gráficos pelo celular?

O aplicativo permite visualizar gráficos que foram pré-configurados na versão Web. Para criar novos gráficos ou realizar alterações estruturais em gráficos já criados, utilize o navegador.

---

## 6) Glossário

- **Analytics:** Módulo do Ploomes que permite realizar análise de dados e indicadores através das funcionalidades de Relatórios e Metas.
- **Widget:** Pequeno bloco de informações na tela inicial que resume dados sem precisar abrir o módulo completo.
