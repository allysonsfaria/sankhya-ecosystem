# Metas - Negócios ganhos em um funil

## Como criar uma meta de negócios ganhos em um funil específico.

Para criarmos uma meta, clique em início - metas - nova meta

Vou fazer uma contagem dos negócios:

![Imagem 1: Vou fazer uma contagem dos negócios:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369325744/3285c9920e653878cc094504/1.png?expires=1786536000&signature=64183d75ca822946790f3525b99240ded44781f03366aacf059dbf28860d9156&req=dyYuFct7moVbFb4V1XW4gYOVm2J3xpBeeB%2BOnCNLGH2hvik1uuPgZ%2FCwFQ%2Bx%0AeLMf3ErU4ZLcB%2BuQs65%2BbDb4sg%3D%3D%0A)

Para fazer a somatória dos valores, use o campo 'Valor' no Campo, e 'Soma' na agregação.

Adiciono um filtro para negócios ganhos:

![Imagem 2: Adiciono um filtro para negócios ganhos:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369325750/40aa5a90572f0622ebf9d44a/2.png?expires=1786536000&signature=6f9a991e1cae29a02e95bf13516cdf86b48ff9dc1f36675948ea29990e1b8096&req=dyYuFct7moRfFb4V1XW4gbKrYs63kiOfw9X9%2BKLFPTIoffI59nZ9887NXsns%0AzXkGa%2BhKzRyxYZHhLvJXQt1Rhg%3D%3D%0A)

Posso adicionar também um filtro sobre o funil:

![Imagem 3: Posso adicionar também um filtro sobre o funil:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369325753/74601f723fed040c22fccd40/3.png?expires=1786536000&signature=de9a216f3aae83984b2a9d08b9769c5d6f724d16c507509e26225d181221f35f&req=dyYuFct7moRcFb4V1XW4gc%2FMJLcPuJKmxV3IEkY4p83LpkFxaNpMASmQPgvK%0A5jvFF00M%2FdgiVZfVMUUvwXiFzg%3D%3D%0A)
