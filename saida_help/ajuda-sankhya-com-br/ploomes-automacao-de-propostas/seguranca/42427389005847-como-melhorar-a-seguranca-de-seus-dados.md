# Como melhorar a segurança de seus dados

A Ploomes preza muito pela segurança dos dados de nossos clientes. Por isso, recomendamos que sejam utilizados todos os meios possíveis para evitar invasões ou vazamento de dados. Alguns deles são:

## Limite quem pode visualizar ou exportar dados

Você pode definir nos perfis dos usuários quais colaboradores podem ver quais negócios ou clientes, e se podem exportar planilhas para um arquivo Excel.

## Como configurar a autenticação multifator (MFA)?

No módulo de **Administração > Configurações do sistema > Seção de Configurações** **de segurança**, você poderá habilitar essa funcionalidade que envia um código ao seu e-mail cadastrado quando é feito o login em um novo computador. Isso evita invasões remotas, considerando que o invasor não tenha a senha de seu e-mail.

## Tenha uma senha segura

Pode parecer óbvio, mas, uma senha comprida e com caracteres especiais é uma das maiores paredes que se pode erguer contra invasores. Senhas como '1234', 'Senha123', 'admin' ou seu nome não oferecem resistência contra qualquer invasor, pois são muito comuns e, provavelmente, o primeiro palpite de um hacker.

São recomendadas senhas com mais de 8 caracteres, letras maiúsculas, números e caracteres especiais como !@#$%&. Veja aqui [como mudar sua senha do Ploomes](https://sankhya.zendesk.com/hc/pt-br/articles/42427488394647)

É possível forçar os usuários a cadastrar uma senha mais segura em **Administração > Configurações do sistema:**

![Imagem 9: É possível forçar os usuários a cadastrar uma senha mais segura em Administração > Configurações do sistema:](https://downloads.intercomcdn.com/i/o/376950582/829224e1c5ec316851c451c1/image.png?expires=1786536000&signature=991282c81e34672d2decd5e609281b77d2b7d3a9f91cdc043aafd3a1e3cd4adc&req=dychH8x%2BmIldFb4V1XW4gbbygIcqIFVHne90f8RtoQN5ESNheW0zODM75vxu%0A570c1cJBdPyEXbdU5v63qoAPLw%3D%3D%0A)

## Não faça login em uma rede pública

O dono da rede tem acesso aos sites visitados e talvez até a dados inputados. Outros usuários da rede podem também ver seus dados caso esteja com compartilhamento ligado.

## Quando usar um computador compartilhado, use a guia anônima

A guia anônima não salva seus dados em cache nem senhas. Assim, mesmo que se esqueça de fazer logout, seus dados não serão salvos.

## Nunca compartilhe dados sensíveis

O time de suporte da Ploomes **nunca** vai pedir a sua senha pessoal, dados de cartão ou quaisquer informações sensíveis. Acessamos as contas dos clientes com um usuário próprio, cujo acesso é liberado pelos administradores da conta.

Tenha ciência dos dados que aparecem em prints screens enviados. A página de **Conta bloqueada** após inadimplência, por exemplo, contém campos para preenchimento de dados do cartão. Se for tirar um print, apague os dados ou borre-os usando uma ferramenta de edição.

**💡 Dica:** a ferramenta de captura de tela [Greenshot](https://getgreenshot.org/) tem uma opção de pixelização chamada "Ofuscate".
