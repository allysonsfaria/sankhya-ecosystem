# Propostas - Como criar uma assinatura

Nesse artigo ensino a editar seu modelo de propostas para adicionar uma assinatura pessoal no final.

Primeiro, vamos abrir o modelo:
Administração - Modelos de documentos - selecione o modelo

Agora escolhemos onde vai nossa assinatura. Vou inserir a minha logo abaixo da tabela de produtos. Para escolher os campos do criador, clico em campos - proposta - Criador>
