# Por que não consigo gerar uma venda automática?

## Nesse artigo você encontrará os principais motivos que podem acarretar na impossibilidade de gerar uma venda automática.

Ao ativar a opção no funil de negócios: "**Criar venda automaticamente ao ganhar negócio**" é necessário se atentar a alguns pontos:

**1 - Certifique-se que o módulo de vendas está ativo:**

![Imagem 1: 1 - Certifique-se que o módulo de vendas está ativo:](https://downloads.intercomcdn.com/i/o/kg4ewnrl/1855093522/79c439c8b34ec31a20213534ed9d/image.png?expires=1786536000&signature=b71c2cb15ca59ca91e22372f37ff9b92dbff4a8d5924a3f4a13148214bda5b30&req=dSgiE8l3noRdW%2FMW3nq%2BgTVcRlnUjpn9PUr4mNzkJhAnJi4BS%2BKDT2Ouhyxl%0AMtwtr7U0vgP197qZNZwjhADmY1c%3D%0A)

Para verificar é necessário acessar: **Administração** > **Módulos do Sistema** > **Vendas** > **Ativar Módulo**

**2 - É preciso ter um modelo de venda padrão:**

![Imagem 2: 2 - É preciso ter um modelo de venda padrão:](https://downloads.intercomcdn.com/i/o/kg4ewnrl/1427175124/fa276141a34b4d0ad18c53d94885/image.png?expires=1786536000&signature=5a25485599edc3fb35fa80169068e7ed048aea8e134cdd4f5033558920534524&req=dSQlEch5mIBdXfMW3nq%2BgVyY%2FUAnyEQiXibUxwGSxNgwoYrmRTzUtAbeKxe%2F%0ARVnpg%2Fs3CBdaw3pgeGlkxPHZ1yE%3D%0A)

Para a venda ser gerada automaticamente é necessário ter, no mínimo, **1 modelo de venda.** Caso contrário, a venda não será gerada.

**3 - O usuário que 'ganhou' o negócio precisa ter as permissões necessárias:**

Atente-se as permissões do perfil de usuário de quem 'ganhou' o negócio, é necessário que ele possua permissão para **visualizar o cliente** que faz parte do negócio e para **cadastrar novas vendas.**

![Imagem 3: Atente-se as permissões do perfil de usuário de quem 'ganhou' o negócio, é necessário que ele possua permissão para…](https://downloads.intercomcdn.com/i/o/kg4ewnrl/1427176379/0a1499ad5db799b580354b55b1bf/image.png?expires=1786536000&signature=7767952a7c9e1309a7ce18eff1c50e57bef60323d87d371025d83074309dcf8b&req=dSQlEch5m4JYUPMW3nq%2BgSJHA90mSxE7VHxvjTV72YU0kBCNtCd0UJ018oKr%0AbkfD7HtR8PUKbbTWMoB8%2FhmzQaE%3D%0A)

![Imagem 4: Atente-se as permissões do perfil de usuário de quem 'ganhou' o negócio, é necessário que ele possua permissão para…](https://downloads.intercomcdn.com/i/o/kg4ewnrl/1427176874/e7b8cd092d12d6a6bedcaeaa2b50/image.png?expires=1786536000&signature=94664d8bf1cc7ade293a1e693106a035124131af2edb7fdb57dd13f117de7346&req=dSQlEch5m4lYXfMW3nq%2BgWGnJ6lWXJD0YwcXQNmBzGDkezkI5Cy%2F4fnljDX6%0AIy1ivaezfSCGOQi6LcnOWR4LP2E%3D%0A)

Para configurar essas permissões acesse: **Administração > Perfis de usuário > Perfil** (Ex.: Vendedor)
