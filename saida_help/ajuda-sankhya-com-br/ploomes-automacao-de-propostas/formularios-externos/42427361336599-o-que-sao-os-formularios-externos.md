# O que são os formulários externos?

⚠️ O módulo de Formulários externos **não faz parte do plano Ploomes Básico**. Ele é um **módulo adicional**, que pode ser contratado à parte.

O **Formulário Externo** é um recurso que permite coletar informações diretamente de clientes, prospects ou parceiros sem que eles precisem acessar a plataforma do Ploomes.

Você pode tornar o formulário publicamente acessível via:

- Uma URL compartilhável que leva os usuários para uma página customizada;
- Um código embedado (iframe) que pode ser adicionado a uma página do seu website (como um formulário de contato).

As respostas preenchidas são automaticamente registradas dentro da conta, seja em **Clientes** ou **Negócios**, agilizando cadastros, atualizações e processos de entrada de dados.

Um caso de uso comum é uma consultoria que envia um formulário para potenciais clientes preencherem dados. As informações caem diretamente em um funil de serviços, já com negócio e cliente criados.

## Onde os formulários podem ser usados?

Os formulários podem ser configurados para duas **entidades** no Ploomes:

- **Cliente**: inclui tanto **empresas** quanto **pessoas (contatos)**.
- **Negócio**: permite usar campos do **card**, do **cliente vinculado** e até do **contato**.

## Como acessar?

Existem duas formas de acessar o módulo:

1. Acesse Administração > Formulários externos.
2. Acesse a entidade de Clientes ou Negócios > clique em "Menu" > clique em "Configurar formulários externos".

## Como criar um formulário externo?

Após acessar a tela de Formulários externos (por Administração > Formulários externos ou pela entidade de Clientes ou Negócios > "Menu" > "Configurar formulários externos"), clique em "Novo formulário" na entidade desejada (negócios ou clientes).

![Imagem 3: Após acessar a tela de Formulários externos (por Administração > Formulários externos ou pela entidade de Clientes ou…](https://downloads.intercomcdn.com/i/o/kg4ewnrl/1831673888/f30b8071916e3a05c2105281428d/mceclip1.png?expires=1786536000&signature=24806da618d6bfab44ebc84611045e91c4f945decd2daf587745df16470b2f52&req=dSgkF895nolXUfMW3nq%2BgQdtoBDvegNFxnOrC2hEg%2Fdt3wsXxN%2BbPLkGyXDP%0Ae0WJk2hkRmuyRxHOSyD88KsSRMs%3D%0A)

## Configurações disponíveis

Ao criar um novo formulário externo, você pode configurar:

1. **Identificação**

   - Nome do formulário
   - Descrição
   - Cor de fundo
   - Inclusão de logotipo

     ![Imagem 4: Inclusão de logotipo](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329951/6cca1baa9440b7d7bf368c36/mceclip2.png?expires=1786536000&signature=76f84f610f0e798725ffdeac016769e13435c7f95d6b872646de94f90e89dc17&req=dyYuFct3lIReFb4V1XW4gSeQtjSGIQL62h0F18SC84ytkTfCFHxCwOM%2FIL3H%0AVC8mvdcy4PDAgavwG5azgyVO1A%3D%3D%0A)
2. **Finalidade**

   - **Criar ou atualizar registros** (gera um link único e iframe para embed em sites).
   - **Apenas atualizar registros existentes** (gera links individuais para cada cliente ou negócio).

     ![Imagem 5: Apenas atualizar registros existentes (gera links individuais para cada cliente ou negócio).](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329957/0e13f14953a60b2aec89638d/mceclip3.png?expires=1786536000&signature=c5b54c875835ed25360f868be21dacf787ad79daf8f727c6706d7a9b99492485&req=dyYuFct3lIRYFb4V1XW4gQjgkAFyDNigDpYfb3ASUsarNk7r3ZLGsR64IYWg%0AJzXIFWcR2aRhTpzmdYkwEEtwCg%3D%3D%0A)
3. **Campos do Formulário**

   - Campos nativos ou personalizados das entidades (ex.: `CNPJ`, `Telefone`, `Pipeline`, etc.).
   - Marcar campos como **obrigatórios**.
   - Editar rótulos e descrições para melhor entendimento no preenchimento das informações.
   - Definir **campos-chave** (ex: se um registro preenchido tiver o mesmo valor de um campo-chave já existente, como exemplo, o CNPJ, o sistema atualiza o registro existente em vez de criar um novo).

     💡Dica: use campos-chave para **evitar duplicidade** de registros.

     ![Imagem 6: 💡Dica: use campos-chave para evitar duplicidade de registros.](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329960/0553af84ccca2b1da6d3f78c/mceclip4.png?expires=1786536000&signature=b6aebc7588f93390872a5b98fe00cd8e9b500a58a204329227c0010d6a038869&req=dyYuFct3lIdfFb4V1XW4gQXFW%2FQ0mqjiUm%2FsPRawIlQalDefogoZNZ8S4rBn%0Aa1HBiYUDLJoNP9FW18j5YWr%2FPg%3D%3D%0A)
   - Mapear **valores padrão**, preenchendo automaticamente certos campos.

     ![Imagem 7: Mapear valores padrão , preenchendo automaticamente certos campos.](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329967/6404198ad5e73c5778a9982c/mceclip5.png?expires=1786536000&signature=8af00a3f0b20e042d89470606094a8d9d6527e6fa53db2a4d523031bee1a288a&req=dyYuFct3lIdYFb4V1XW4gZHuL9by9IUtqZNk7DQPL66HimuCtkbXtdJFrixw%0AXDyeNYV9z%2FVwp1pgQsSq33J24Q%3D%3D%0A)
4. **Compartilhamento**

   Após salvar o formulário, será possível compartilhar.

   ![Imagem 8: Após salvar o formulário, será possível compartilhar.](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329972/443edd4efb78c0a6caeba226/mceclip6.png?expires=1786536000&signature=759a7ae1b71aa3d626bc670c33616e49f2d30757ac4648d5d00be18ecb0812ce&req=dyYuFct3lIZdFb4V1XW4gSjNshIy%2BNL25uMWsUYxKs7bdfa1yYBaeXEtRFix%0AHKTI41ISrxkAEw8iI8qW1okqVw%3D%3D%0A)

   - Link público pronto para enviar aos clientes.
   - Código em **iframe** para incorporar diretamente em um site (gerados somente em formulários de criação).
   - Em caso de formulário de atualização, os links são gerados individuais por registro, localizados dentro de cada negócio na aba de **Formulários externos**.

## 💡 Boas práticas

- Utilize **campos-chave** para evitar duplicidade de registros.
- Personalize com logotipo e cores para passar credibilidade ao cliente.
- Em formulários de atualização, sempre valide o link antes de enviar.
- Teste o formulário com dados fictícios para garantir que a informação seja registrada corretamente.

## Como contratar o módulo?

Para contratar o módulo **Formulários externos**, entre em contato com:

- a pessoa responsável pelo seu relacionamento com o Ploomes (**CS**).

  ou
- nosso time de suporte (para ter direcionamentos).
