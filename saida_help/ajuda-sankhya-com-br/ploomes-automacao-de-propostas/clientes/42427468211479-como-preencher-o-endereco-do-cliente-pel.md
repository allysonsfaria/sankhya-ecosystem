# Como preencher o endereço do cliente pelo CEP?

No momento da criação do cliente, é possível inserir o **CEP** para que as demais informações de localização sejam preenchidas automaticamente.

## Como fazer?

Insira o **CEP** no campo **Endereço**, selecione a sugestão exibida e os demais campos serão preenchidos automaticamente.
