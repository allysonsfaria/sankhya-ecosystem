# Como gerar uma lista de clientes que compraram neste ano?

Neste artigo, consideraremos como compra uma venda gerada no sistema. Além disso, embora seja possível utilizar outros campos de data personalizados, utilizaremos o campo de **Data** nativo do sistema.

## Como configurar?

- Acesse a aba **Clientes** > **Nova aba**;
- Defina o título da aba e quem poderá visualizá-la;
- Como critério de filtro, utilize: **Última venda > Data > Igual a > Data relativa > Este ano**.
