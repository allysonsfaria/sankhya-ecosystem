# Como filtrar dados de usuários inativos?

Quando um usuário é inativado, ele deixa de aparecer nas listas dos campos do tipo Usuário (como **Responsável**, **Usuários colaboradores** e **Usuários em tarefas**).

Se o objetivo for localizar clientes que pertenciam à carteira de um vendedor inativo, é necessário filtrar pelo **nome do responsável**, e não apenas pelo campo **Responsável**.

## Como configurar?

- Acesse **Clientes** > **Filtros** > **Novo filtro**;
- Selecione **Filtro avançado;**
- Adicione como filtro:

  - **Responsável** > **Nome** > **Igual a;**
- Informe o nome do usuário inativado.

Após isso, você pode **Aplicar** o filtro ou **Salvar**, caso queira utilizá-lo no futuro.

[GIF animado: Exemplo de filtro](https://downloads.intercomcdn.com/i/o/kg4ewnrl/2036907651/d2915eb70c171e2589141530b4f1/artigo.gif?expires=1786536000&signature=04464cac5c728a4ed0feea5fee87c3791fe1c9666f390e2163d130495b4c4443&req=diAkEMB%2BmodaWPMW3nq%2BgfORnRJ37EaCXRhm0%2B4XqJqofO%2FPPjb%2F1zfEJ2fQ%0Adod0R7cVX3F54f%2F8u1tU%2FbDfqS8%3D%0A)

Também é possível filtrar os clientes utilizando usuários inativos como critério.

- Acesse **Clientes** > **Filtros** > **Novo filtro**;
- Selecione **Filtro avançado;**
- Adicione como filtro:

  - **Responsável** > **Inativo** > **Igual a** > **Sim;**

Após isso, você pode **Aplicar** o filtro ou **Salvar**, caso queira utilizá-lo no futuro.
