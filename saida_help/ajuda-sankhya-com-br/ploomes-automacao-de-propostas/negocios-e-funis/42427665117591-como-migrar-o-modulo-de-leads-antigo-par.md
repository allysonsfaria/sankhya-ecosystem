# Como migrar o módulo de Leads (antigo) para Workflow

O módulo de Leads no Ploomes foi descontinuado - portanto, não recebe mais atualizações e melhorias. Em contrapartida, o módulo de Workflows (negócios) tem sido constantemente aprimorado e hoje é uma ótima solução para se gerenciar processos de qualificação de leads de várias maneiras, com base na realidade de cada empresa.

Clique no link abaixo para acessar o case completo da Universidade Ploomes e entender tudo sobre essa migração.

Case: [Migração do módulo de Leads para Workflow](https://universidade.ploomes.com/courses/migracao-do-modulo-de-leads-para-workflow)

Caso deseje contratar um de nossos parceiros de configuração, acesse <https://servicos.ploomes.com/> para solicitar o contato.
