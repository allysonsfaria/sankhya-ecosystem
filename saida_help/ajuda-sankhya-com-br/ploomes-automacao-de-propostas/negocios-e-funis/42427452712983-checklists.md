# Checklists

## O que são checklists?

Checklists são atalhos para o preenchimento de um campo dentro de uma etapa do funil, podendo obrigar o usuário a preenchê-los para avançar de etapa.

![Imagem 1: Checklists são atalhos para o preenchimento de um campo dentro de uma etapa do funil, podendo obrigar o usuário a…](https://downloads.intercomcdn.com/i/o/962240760/a9b758f224340ad6585f42bb/image.png?expires=1786536000&signature=61e31b3b3bdb41f07c09cc01f95eceaed5a730359ce7bfb50da47924d518eca7&req=fSYlFM1%2BmodfFb4V1XW4gaggP1nngMsr4AfSCOtLUmjISd5a6i1ACX50en4%2F%0AIpVwkOg%2Fa3dY1oAig1kQeUSORA%3D%3D%0A)

Na imagem acima o usuário tentou avançar o negócio de etapa, porém os checklists pendentes o impediram.

O check verde indica que o checklist está preenchido corretamente.

O x vermelho indica que o checklist está preenchido incorretamente.

O check cinza indica que o checklist não está preenchido, mas não é obrigatório.

O triângulo com exclamação indica um checklist obrigatório não preenchido.

## Como configurar checklists

Na configuração das etapas do funil, clique em 'Configurar checklists' na etapa desejada.

![Imagem 2: Na configuração das etapas do funil, clique em 'Configurar checklists' na etapa desejada.](https://downloads.intercomcdn.com/i/o/428063861/24b35a4ab9c3990fea1920fc/image.png?expires=1786536000&signature=f6960779934fc15b078f0d68578df480366570f22a704f532f026eac3f21ae40&req=cCIvFs99lYdeFb4V1XW4gYnlp%2BaJXqorpjscrdqpuLQv8cam%2B2xPhFylJH3U%0AuOPVO7GMxjW7hntwnnvuE2b9PA%3D%3D%0A)

Primeiro, preencha o nome do checklist. O nome será exibido aqui:

![Imagem 3: Primeiro, preencha o nome do checklist. O nome será exibido aqui:](https://downloads.intercomcdn.com/i/o/428067796/b50f804b6a0afc198b13c817/image.png?expires=1786536000&signature=fa8dbbc6a91df5567dc9aeda4668c9580e82645cac740bf3fac3f01c85ffa021&req=cCIvFs95mohZFb4V1XW4gfkRITANPryzcedManEs6L1w6GnIC6sgrt3obdlF%0Acg6HCLt4c4YBSH4tewT74YrdbQ%3D%3D%0A)

No "+" insira, caso necessário, um filtro para a exibição do checklist.

Como estou configurando um checklist onde serão preenchidos dados do **contato**, vou ditar que só vai aparecer caso o cliente for do tipo empresa:

[GIF animado: Imagem 4: Como estou configurando um checklist onde serão preenchidos dados do contato , vou ditar que só vai aparecer caso o…](https://downloads.intercomcdn.com/i/o/428069520/0870e6d490d020628fdf5c86/checkcond.gif?expires=1786536000&signature=10a7ad59d80143fa8be637fb1e7b8d9a7d808a036dbe77071586b3b2683796c5&req=cCIvFs93mINfFb4V1XW4gZfAIjf1pHXcZJvcV71Zi7mHwTrSClLznsrsB5%2B6%0Ao616LIj3LqVYJmGy28w0N%2FGUHw%3D%3D%0A)

Isso define que este bloco só aparece (portanto só é obrigatório) quando meu cliente for uma empresa.

Mais tarde, posso configurar um novo bloco de checklists para os clientes de tipo pessoa.

Para adicionar os campos a serem preenchidos e suas condições, vamos ao passo 2:

![Imagem 5: Para adicionar os campos a serem preenchidos e suas condições, vamos ao passo 2:](https://downloads.intercomcdn.com/i/o/428070565/646ede4d04e721df67794948/image.png?expires=1786536000&signature=0a58715e2f3b12f43842e0aa6368592a68956c0068f43925f3f3c02e800c76d1&req=cCIvFs5%2BmIdaFb4V1XW4gb4TBs5B0ahvclXODAD%2FWN2kmFVIcD0GnoQzuwOB%0AEBMTYyMo1f3w2S0FwTEPTJD%2B%2BQ%3D%3D%0A)

A descrição do item aparece aqui:

![Imagem 6: A descrição do item aparece aqui:](https://downloads.intercomcdn.com/i/o/428070907/842ad0c877940410075870ef/image.png?expires=1786536000&signature=52060cd8f2a6f8e7a6c6a2b4244ddd6ac5a9f33c309815af6127913accf9fd56&req=cCIvFs5%2BlIFYFb4V1XW4gR33vbnfnqdv5u1Ix5pxHDs3Qc1IXYerE0Z7GGdb%0Aam3xVBd59mgv%2BLMbCn6NGumrXw%3D%3D%0A)

Vou configurar o campo "Segmento" do cliente.

Para que seja obrigatório, marco 'Adicionar condição para o avanço' e dito que o campo deve ser 'diferente de' vazio:

[GIF animado: Imagem 7: Para que seja obrigatório, marco 'Adicionar condição para o avanço' e dito que o campo deve ser 'diferente de' vazio:](https://downloads.intercomcdn.com/i/o/428072295/219474333b2e453d816ad67b/itemCheck.gif?expires=1786536000&signature=5a4852bc9cda11f2d3a9a98f81bc63044d0222b2bc7c9d8be5b7f5e70888d0b4&req=cCIvFs58n4haFb4V1XW4gTy08dbzt%2FQudFAx67f%2FgLl3wst6ECZzB5QcVnoT%0ATyOynYJutl5H%2BbHBXrCdCLDkhg%3D%3D%0A)

Para que um contato seja obrigatório, insiro o campo "Contato" de negócio.

Caso insira o campo "nome" da entidade contato, não poderei preencher - pois o negócio ainda não tem contato. Por isso usamos o campo de negócio que mencionei.

Também vou solicitar o preenchimento do e-mail do contato. Ao invés de 'diferente de vazio', vou usar 'contém @'. isso ajuda a garantir que é um e-mail válido sendo inserido.

[GIF animado: Imagem 8: Também vou solicitar o preenchimento do e-mail do contato. Ao invés de 'diferente de vazio', vou usar 'contém @'. isso…](https://downloads.intercomcdn.com/i/o/428074929/d503950f89163275f9bffcad/Checkcontato.gif?expires=1786536000&signature=0152de64ec4b5dab18e21ee0272c31211928b5e743d99254768041b5a7d68cd6&req=cCIvFs56lINWFb4V1XW4gVfoBDh5wDd%2FEvfqu2iF8rWmyWLGzY0kM1Pm5Bc%2B%0AAKAHpfxqOevjHnNXKEMKw76QoA%3D%3D%0A)

Por fim, vou pedir o CNPJ da empresa.

Como nessa etapa é um pouco mais difícil de obter o cnpj do lead, e não será necessário no momento, vou manter como não obrigatório - para isso, simplesmente não marco a opção 'Adicionar condição para avanço'.

![Imagem 9: Como nessa etapa é um pouco mais difícil de obter o cnpj do lead, e não será necessário no momento, vou manter como não…](https://downloads.intercomcdn.com/i/o/428076648/5550da587d381ef32b61044c/image.png?expires=1786536000&signature=b52031b5d16df832e23086cf053c010f3b6f9226e1a196779f7aea8480353bf6&req=cCIvFs54m4VXFb4V1XW4gWWB%2FiaB6wjBJvWH6%2BZXc65G0IdkvCMhqO9IYCLY%0A0S4UCiDXJ3WCMft7VJO4XMBOVQ%3D%3D%0A)

Lembrando que o CNPJ é da entidade Cliente, e não Contato.
