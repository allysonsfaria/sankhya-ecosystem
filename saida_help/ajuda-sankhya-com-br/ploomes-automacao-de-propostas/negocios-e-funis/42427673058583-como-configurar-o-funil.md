# Como configurar o funil

## Como criar um funil?

![Imagem 2: Para criar um novo funil, basta acessar seu módulo de Negócios e acessar a tela com todos os funis:](https://downloads.intercomcdn.com/i/o/757891984/5df0c95dc5a023935d2811e2/image.png?expires=1786536000&signature=8f7b226458a51ed0c18ac8a23ee607703b3e66b41c93ac09d0d25498d2f45af0&req=cyUgHsB%2FlIlbFb4V1XW4gYVVTE51XlRhNsPKqJKPo%2BaxLvN%2BREu%2FzyeHxU7p%0AFqbENiMJPahe9Gz4N5T2ruB2Fg%3D%3D%0A)

## Editando o funil

Agora, sobre as customizações e configurações, são válidas tanto para um funil já existente ou um recém criado.

É possível modificar o ícone, nome, cor e quem pode visualizar:

![Imagem 4: É possível modificar o ícone, nome, cor e quem pode visualizar:](https://downloads.intercomcdn.com/i/o/757897122/4e2a51d9178a8b886d6f1c0f/image.png?expires=1786536000&signature=cffda35c1cdca18d45c183314f58382764f09f4410fb56b8040a5c032ecbf224&req=cyUgHsB5nINdFb4V1XW4gYsknrFuv%2FWhe3441qwkcgF7lYFP16vnyWiSF52s%0APFO4KO7g4Ru3q2gQ5ejBX2XCMg%3D%3D%0A)

Seguindo as configurações, o print abaixo mostra como editar etapas. Preenchendo os campos de "Nova etapa" você adiciona um estágio ao funil.

Você pode editar o nome da etapa após a criação (marcação em verde).

Arrastando, é possível alterar a ordem das etapas inseridas (marcação em vermelho).

![Imagem 5: Arrastando, é possível alterar a ordem das etapas inseridas (marcação em vermelho).](https://downloads.intercomcdn.com/i/o/757908716/44b17faec8363e9905e737c0/image.png?expires=1786536000&signature=a743bef3d76b4de801b176eeb26c837c26468115c75e964c9a553eb010ab2fbb&req=cyUgH8l2moBZFb4V1XW4gZRuiS2WkVGelfAPHuaiNRgRlkSTFuYId6z3a%2FN6%0As1umyM%2FJqKQF7g9Co0qQURq56g%3D%3D%0A)

Dentro das etapas é possível configurar automações de funil e checklists, valido de acordo com a etapa que onde foi acrescentada.

Para entender sobre checklist, [clique aqui](https://sankhya.zendesk.com/hc/pt-br/articles/42427452712983).

Para aprender mais sobre automação de funil, [clique aqui](https://sankhya.zendesk.com/hc/pt-br/articles/42427574650391).
