# Qual a diferença entre início, data de criação e término

Os campos de **Início** e **Data de Criação** dentro de um **Negócio** podem trazer algumas confusões quando nos deparamos com o mesmo. Afinal, eles são a mesma coisa? A resposta é **não** e nesse artigo vamos entender o porquê.

## Início

A primeira principal diferença entre os dois campos é que, diferente do campo de Data de Criação, o campo de **Início é um campo editável**, ou seja, você pode definir a data de início de um Negócio para quando você quiser.

## Data de criação

Já o campo **Data de Criação** **de um Negócio** **é uma data fixa**, já que ela serve apenas para marcar a data em que um negócio foi criado. Então você pode ter um negócio criado hoje, mas que só se inicia no próximo mês, por exemplo.

## Término

O campo **Término do Negócio também é um campos editável** e você pode definir o término de um Negócio para quando você quiser, assim como editar após. Mas, caso ele esteja em branco o mesmo é preenchido automaticamente quando o negócio é ganho/perdido.

### Se você reabrir um negócio, a data de Início irá mudar?

Nesse caso, a resposta é **Não**.

Isso porque o Negócio já havia se iniciado em outro momento e a reabertura do mesmo é apenas uma nova etapa no processo do Negócio dentro do Funil.

### Se você reabrir um Negócio e então finalizá-lo novamente, a data de Término irá ser alterada?

A resposta para essa pergunta é **Sim**.

Quando você reabrir um Negócio e então finalizá-lo novamente, essa data irá ser alterada porque houve uma nova finalização do mesmo. O término dele já não abrange o período indicado entre o início e o término anterior e por isso ele ganha uma nova data de término.

## Barra azul no rodapé do Card

A linha azul representa o término do negócio, o mesmo é preenchido automaticamente quando o negócio é ganho/perdido. Então, se ele é reaberto fica com a linha azul.
O término também pode ser agendado, ou seja, na criação ou no decorrer do processo você agenda/preenche a data do término. Dessa forma, a barrinha vai se preenchendo conforme a data for se aproximando.
