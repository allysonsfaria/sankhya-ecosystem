# Como editar funis

Nesse artigo apresento como configurar um funil de acordo com sua necessidade. Também é possível customizar e configurar um funil, seja novo ou já existente.

Para criar um novo, basta clicar na opção abaixo:

![Imagem 1: Para criar um novo, basta clicar na opção abaixo:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323963/b8bed09c5bf8058a4aed5e7e/mceclip0.png?expires=1786536000&signature=3a68ed60537f232bc9c1de197405a52f79a75941980993afbb0f567f73b98944&req=dyYuFct9lIdcFb4V1XW4gWAdez%2Bq%2Bd80i4AHPGEHzo5a4Hu7lCSGkOK%2BHx5H%0Asf%2FQ81Scd2XMGDk1LkeSaAyXZg%3D%3D%0A)

Para editar um funil existente, basta passar o mouse em cima dele que irá habilitar um lápis, de acordo com o print abaixo:

![Imagem 2: Para editar um funil existente, basta passar o mouse em cima dele que irá habilitar um lápis, de acordo com o print…](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323966/95c7580acfa8478198d0848f/mceclip1.png?expires=1786536000&signature=8c8415e419a7cd831bfd1a302bede246a9e501d419558f89b98d0fcd395612df&req=dyYuFct9lIdZFb4V1XW4gVcrzUo4bHsoiE0VKRbigzpgm4OJKPyT6y5HWMM4%0ANaWTQna2VIvFaIsTCzCRlVKMuw%3D%3D%0A)

Agora, sobre as customizações e configurações, validas tanto para um funil já existente ou um recém criado.

É possível modificar o ícone, nome, cor e quem pode visualizar:

![Imagem 3: É possível modificar o ícone, nome, cor e quem pode visualizar:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323972/91f762504092557a0adf03c5/mceclip2.png?expires=1786536000&signature=3e59b7bb07386ead123b76e85e9ae17342487602365b99d6c8a2d8befeebdce5&req=dyYuFct9lIZdFb4V1XW4gRwvyIyDsJczH0rjD9D6Cfvh5pORxtRb3s418duW%0AgkZNKbIa7ae5beSkwxShVM2CPQ%3D%3D%0A)

Seguindo as configurações, o print abaixo mostra como editar etapas. Preenchendo os campos de "Nova etapa" você adiciona um estágio ao funil. Arrastando, é possível alterar a ordem das etapas inseridas.

![Imagem 4: Seguindo as configurações, o print abaixo mostra como editar etapas. Preenchendo os campos de "Nova etapa" você…](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323979/6590ab700b43baa3b611b14b/mceclip3.png?expires=1786536000&signature=1b09e606b76d0d0cc6a58a0c3af4241e43661d4536d5173970426173867a43ba&req=dyYuFct9lIZWFb4V1XW4gZz30uQfS8FnFf3fmLCehGGMxDr4uhIGSz9U2iOy%0AiI72SFsq1hHHOJiogJ%2BI5m3sBg%3D%3D%0A)

Nessa parte configuro as automações de funil e checklists, valido de acordo com a etapa que onde foi acrescentada.

Também é possível criar um formulário de cadastro de novo negócio que é único a este funil:

![Imagem 5: Também é possível criar um formulário de cadastro de novo negócio que é único a este funil:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323985/0ee029a6608a81a15e660181/mceclip4.png?expires=1786536000&signature=81bfa57fa6902bf3a268639c93e497aceed809c980a19ce656b8a2e1edf84bec&req=dyYuFct9lIlaFb4V1XW4gYfXvXfrXOC8CP25TsN1jb5hRbog0PF8Mv%2FfhUjD%0AqS0nrgt2BfruA1BNi6%2BImHCtBg%3D%3D%0A)

1 - Em "Adicionar Campo" é possível tanto criar um novo campo quanto adicionar ao formulário um campo já existente.

2- Em "Nova Seção" é criado uma nova divisão dentro do formulário.

3 - Exemplificando o que seria uma seção.

4 - Nesse botão é possível minimizar ou maximizar todas as seções presentes no formulário.

5 - Após todas as edições, é necessário salvar as alterações.

E é possível configurar também o formulário mini de novo negócio.

![Imagem 6: E é possível configurar também o formulário mini de novo negócio.](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323993/4c2e2545dad3466413cad09a/mceclip5.png?expires=1786536000&signature=b1965be9ba777376b23df577442923e495cbbb4d6997096983e20532be8bae54&req=dyYuFct9lIhcFb4V1XW4gWOrNrZFxpDjwZ%2BHIc2ABVfEFvzDmUVgMVoSmtG7%0A2E4zOr8BEdrMo0sA9IHDETvgkg%3D%3D%0A)

Onde pode-se acrescentar um novo campo criando um ou adicionando um já criado. Após as alterações feitas, é necessário salva-las.
