# Seletor de Funis

O Seletor de Funis oferece uma forma mais flexível e intuitiva para os usuários gerenciarem seus funis dentro do Ploomes. Agora, é possível visualizar todos os funis em uma lista customizável, favoritar os mais importantes, movê-los, arquivá-los e escolher entre a visualização em lista ou galeria. Com essas melhorias, a navegação fica mais fluida e personalizada, permitindo uma experiência mais eficiente e prática para os usuários.

## Configurando/Ativando o Seletor de Funis

O Seletor de Funis está disponível para todos os clientes do Ploomes com acesso ao **Módulo de Negócios**, e a configuração pode ser ajustada nas **Configurações de Usuário** ou na **Administração do Sistema**. Para configurar o seletor:

1. Acesse **Administração → Módulos do Sistema → Negócio (ou nome dinâmico da entidade)**.
2. Em **Usabilidade de múltiplos funis**, defina a configuração desejada:

   - **Decisão a ser tomada por cada usuário** (se essa opção for escolhida, o usuário, em suas configurações de perfil, terá de escolher entre uma das duas opções abaixo):
   - **Selecionar, por padrão, o último funil utilizado**.
   - **Sempre perguntar qual o funil desejado**.

## 2. Favoritar e Desfavoritar Funis

- **Favoritar Funis**: Clique na estrelinha ao lado do funil ou na opção de favoritar no menu de opções. Funis favoritados aparecerão no topo da lista ou galeria.
- **Desfavoritar Funis**: O processo de desfavoritar é clicando na estrelinha e confirmando o desejo de desfavoritar.

## 3. Buscar Funis pelo Nome

- A busca permite que você encontre funis usando a opção **"Contém"**, de forma similar à busca de contatos. Mesmo que você esteja usando a visualização de galeria, os resultados serão apresentados em lista.

## 4. Reordenar Funis

- **Ordenação Padrão**: Para contas existentes, a ordenação será mantida como está, e o usuário poderá alterá-la.
- **Reordenação Manual**: O usuário pode reordenar os funis tanto na visualização de lista quanto de galeria. A ordenação escolhida será salva para o próximo uso **para cada usuário**.

## 5. Funis Arquivados

- **Visualização**: Funis arquivados só podem ser visualizados em formato de lista.
- **Desarquivar**: Se um funil favoritado for arquivado e depois desarquivado, ele continuará favoritado.

## 6. Copiar Link do Funil

- Cada funil tem um ID único, permitindo copiar seu link para compartilhamento.
- Se o usuário não tiver permissão para visualizar um funil, ao tentar acessá-lo via link, verá uma tela de "empty state" indicando falta de acesso.

## Limitações do Seletor de Funis

1. **Permissões de Acesso**: O link para um funil só funcionará se o usuário tiver permissão para acessá-lo. Caso contrário, será exibido um aviso de acesso negado.

## F.A.Q.

## 1. Como alternar entre os formatos de visualização?

A alteração entre lista e galeria é salva automaticamente, e você pode mudar sempre que desejar. A configuração será mantida entre acessos para cada usuário.

## 2. Como favoritar ou desfavoritar um funil?

Você pode favoritar um funil clicando na estrelinha ao lado do funil ou nas opções do menu. Para desfavoritar, basta clicar novamente na estrelinha e confirmar o desejo de desfavoritar.

## 3. O que acontece quando eu arquivar um funil favoritado?

O funil continuará favoritado mesmo quando for arquivado. Ao desarquivar, ele permanecerá favoritado.

## 4. Como funciona a busca por funil?

A busca permite que você encontre funis pelo nome usando o filtro "Contém". Os resultados serão apresentados em lista, independentemente da visualização escolhida.

## Glossário

- **Funil**: Representa uma etapa de um processo ou negócio dentro do CRM.
- **Favorito**: Funil que foi marcado como importante pelo usuário, aparecendo no topo da lista ou galeria.
- **Galeria e Lista**: Dois tipos de visualização disponíveis para os funis, com diferentes modos de organização e visualização.
- **Empty State**: Tela exibida quando não há dados ou quando o usuário não tem permissão para visualizar um conteúdo.
