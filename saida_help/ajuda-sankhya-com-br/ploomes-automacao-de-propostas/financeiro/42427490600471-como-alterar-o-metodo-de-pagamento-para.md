# Como alterar o método de pagamento para Cartão de Crédito

Você pode alterar o método de pagamento da sua conta diretamente pelo menu de Administração do Ploomes.

⚠️ **Atenção**: apenas usuários com permissão de administrador conseguem realizar essa alteração.

## Como alterar

1. Acesse **Administração** no menu lateral esquerdo.
2. Vá até a seção **Pagamentos**.
3. Clique em **Dados de pagamento**.
4. Em **Método de pagamento**, selecione **Cartão de crédito**.
5. Preencha os dados do cartão:

   - Número do cartão
   - Nome no cartão
   - Mês de expiração
   - Ano de expiração
   - Código de segurança (CVV)
6. Clique em **Alterar para este método** para confirmar.

Após a confirmação, o novo método será utilizado a partir da próxima cobrança.
