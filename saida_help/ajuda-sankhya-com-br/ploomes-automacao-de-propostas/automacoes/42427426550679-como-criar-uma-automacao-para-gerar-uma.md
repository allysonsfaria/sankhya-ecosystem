# Como criar uma automação para gerar uma tarefa de envio de ata após uma reunião?

Garantir o envio da ata após reuniões é essencial para formalizar alinhamentos e manter um bom acompanhamento com o cliente. Com as automações do Ploomes, é possível criar tarefas automaticamente sempre que uma reunião for concluída, garantindo que esse envio não seja esquecido.

## Configuração

## 1. Criar uma nova automação

- Acesse **Administração > Automações**

- Selecione a entidade **Tarefa**

- Clique em **Nova automação**

[GIF animado: Imagem 1: Clique em Nova automação](https://downloads.intercomcdn.com/i/o/kg4ewnrl/2355137072/ad7e2bee3ab80e7bdc30a10e4413/vivaldi_F0mIQXA0Vk.gif?expires=1786536000&signature=f93b792729bb2eb6a2627e2813204c984fce36815a553d8998241e4f2e6cb187&req=diMiE8h9moFYW%2FMW3nq%2BgVM3uFSZ%2FZwvMPlhUER5d0zJti%2Bq0fJiDl1gzLKA%0ApscJ5XN9nW%2FDwaBG27V%2FqcqkLXs%3D%0A)

## 2. Configurar descrição, gatilho e filtro

- No campo **Descrição da automação**, informe um nome que identifique a ação
  Exemplo: Criar tarefa para envio de ata após reunião

- Em **Quando a automação deve ser disparada**, selecione:

  - **Quando a tarefa for finalizada**

- Em seguida, clique no ícone **+** para adicionar o filtro

  **Filtro**

  Tipo - igual a - Reunião

[GIF animado: Imagem 2: Tipo - igual a - Reunião](https://downloads.intercomcdn.com/i/o/kg4ewnrl/2355143749/5a02541eab091d0ec3f729e450e4/vivaldi_OtYAtw7g4b.gif?expires=1786536000&signature=3ea879dd6596e99157ad4a7ed167b8af3efc22a7d5be2e51a568fb77b96d9fbc&req=diMiE8h6noZbUPMW3nq%2BgZx8rBjoTVGu1UPTChzFnij6l7I0T0swTLI9DCvV%0AOfBgB30mvIxZqWjf4qQXd4nn828%3D%0A)

## 3. Definir a ação

- Em **Ao ser disparada, o que a automação deve fazer?**, selecione:

  - **Criar tarefa**

- Configure os campos da nova tarefa conforme sua necessidade:

  - **Usuários**
    Neste caso será configurado para os usuários da nova tarefa serem os mesmos da tarefa de reunião que foi finalizada.
  - **Tipo da tarefa**

    Exemplo: Simples
  - **Título**
    Exemplo: Enviar ata da reunião ao cliente
  - **Descrição**
    Exemplo: Reunião finalizada. Enviar a ata com os pontos discutidos para o cliente.

- Clique em **Salvar**
