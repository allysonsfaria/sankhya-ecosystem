# É possível restringir o acesso de um usuário por IP ou para acessar o Ploomes de um determinado local?

O Ploomes é um CRM que pode ser acessado tanto pelo navegador quanto pelo aplicativo. Por esse motivo, os usuários conseguem realizar login de diferentes dispositivos e localidades.

## É possível restringir o acesso por IP ou localidade específica?

Atualmente, não é possível configurar uma restrição de acesso por IP ou limitar o login a um local específico.

Usuários que possuem conta no Ploomes podem acessar o sistema de qualquer dispositivo e/ou local, desde que utilizem suas credenciais válidas.
