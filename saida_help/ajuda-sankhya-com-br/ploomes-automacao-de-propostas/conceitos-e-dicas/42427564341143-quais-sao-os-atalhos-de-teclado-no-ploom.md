# Quais são os atalhos de teclado no Ploomes?

O Ploomes possui alguns atalhos de teclado para facilitar a usabilidade do sistema no dia a dia.

Um deles é CTRL + K para abrir a busca geral.

Veja abaixo os atalhos disponíveis utilizando Shift + Letra:

- **SHIFT + T -** Criar uma nova Tarefa (Task)
- **SHIFT + D -** Criar um novo Negócio (Deal)
- **SHIFT + C -** Criar uma nova Empresa (Company)
- **SHIFT + P -** Criar uma nova Pessoa (Person)
- **SHIFT + O -** Criar uma nova Venda (Order)
- **SHIFT + I -** Criar um novo Registro de Interação (Interaction)
- **SHIFT + E -** Criar um novo E-mail

E os atalhos com **Shift + Número** para acessar os Módulos (do painel esquerdo) do Ploomes:

- **SHIFT + 1 -** Acessa a página de **Resumo;**
- **SHIFT + 2 -** Acessa a página de **Clientes;**
- **SHIFT + 4 -** Acessa a página de **Negócios;**
- **SHIFT + 5 -** Acessa a página de **Documentos;**
- **SHIFT + 6 -** Acessa a página de **Produtos;**
- **SHIFT + 8 -** Acessa a página de **Administração.**
