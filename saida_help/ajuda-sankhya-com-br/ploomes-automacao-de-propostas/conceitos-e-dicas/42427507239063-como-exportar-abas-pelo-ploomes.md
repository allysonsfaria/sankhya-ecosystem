# Como exportar abas pelo Ploomes

O bom uso da plataforma, isto é, a boa alimentação de dados em seu Ploomes, garante uma extração de informações completa e eficiente, pronta para ser trabalhada e transformada em diversos tipos de relatórios.

## Acessar e configurar a aba

Podemos exportar abas de clientes, negócios, vendas e produtos. Nesse artigo, você verá o passo a passo de como exportar dados no **módulo de clientes,** mas em todos os módulos o processo de exportação é análogo.

**Observação:** Para exportar abas de negócios, troque a visualização de 'Funil' para 'Tabela'.

- Acesse o módulo desejado > Clique na aba que gostaria de exportar (certifique-se que aba está filtrando com as informações que você deseja)

![Imagem 1: Acesse o módulo desejado > Clique na aba que gostaria de exportar (certifique-se que aba está filtrando com as…](https://downloads.intercomcdn.com/i/o/747298943/1b5f6db0ad78d0842b0f644f/exportar.png?expires=1786536000&signature=92df4e72adba1796fc3e34e0536668be6fec07a0f99d3172b12a0f8ea58c2b14&req=cyQgFMB2lIVcFb4V1XW4gZ3%2FNp%2BxSY4f5BnUe6f87crrMWTGthCbbdyFz2KE%0AmM5QJ87BkSztAWKSO0g%2BrWpAvA%3D%3D%0A)

- As colunas da visualização no Ploomes, são as mesmas colunas que estarão no Excel, ou seja, podemos editar no Ploomes para extrair somente os dados desejados. Para adicionar e remover colunas, devemos clicar no ícone de ⚙️ (engrenagem) (localizada no canto superior direito ao fim das colunas).
- Clique no campo desejado e selecione a coluna que deseja inserir. Depois disso, para validar, clique no "Check", localizado à direita. Você consegue ordenar os campos para a sequência da tabela ficar conforme o que precisar.

## Exportar a aba em excel

1. Passe o mouse sobre o nome da aba desejada;
2. Clique no ícone de ⚙️ (engrenagem) chamado "Ações da aba";
3. Selecione a opção "Exportar aba";
4. Leia atentamente às orientações e confirme;
5. Clique no ícone de progresso de exportação para verificar o andamento e fazer download para o seu computador.

[GIF animado: Imagem 5: Clique no ícone de progresso de exportação para verificar o andamento e fazer download para o seu computador.](https://downloads.intercomcdn.com/i/o/1116524238/4530a97524652f113a50deab/Como+exportar+aba+para+excel.gif?expires=1786536000&signature=f182073bd2674e4b5f8629266d0649e34ef395f75dc35b521f896b0c79dcf345&req=dSEmEMx8mYNcUfMW3nq%2BgWZKnlbxX8NoFie9KQkIxsfMUNGPjoyIJpBEP2TV%0AQL9y5PL7jOxTGm8JVevk79%2FLchs%3D%0A)

- Pronto! Dados exportados com sucesso!

⚠️ A exportação de aba para Excel possui um **limite** de, aproximadamente, **50 mil linhas** e **30 colunas** (podendo ser menos a depender dos tipos de campos).

Confira a seção "Dividir abas em ID para exportação" para saber como exportar caso ultrapasse esse limite.

No Excel podemos trabalhar de diversas formas com esses dados, um exemplo é utilizar a tabela dinâmica para saber quantos clientes estão em cada estado! É uma ótima forma para basear suas tomadas de decisão e ter novos insights sobre maneiras de atuação!

## Dividir abas em ID para exportação

A exportação por ID é viável de se utilizar caso sua base tenha mais de 50 mil itens (linhas).

Neste caso a exportação apenas pelo filtro não funciona, por isso, segmentamos os clientes também por ID, para exportar toda base.

- Para segmentar os clientes por **ID**, vamos primeiro adicionar a coluna pela engrenagem à direita:

![Imagem 6: Para segmentar os clientes por ID , vamos primeiro adicionar a coluna pela engrenagem à direita:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323820/45cac484026be82e6862e348/mceclip0.png?expires=1786536000&signature=79fb97e11ced006e22690b13763d40553a9e9f8b85b60bd13f1ca3b6baeb95e6&req=dyYuFct9lYNfFb4V1XW4gVH%2BrgI45bczPbhqMPoS%2FKoT6kIKk5Kawf8h7Y%2FQ%0ATtPs6nySr6VMo99rnK16dtisDQ%3D%3D%0A)

![Imagem 7: Para segmentar os clientes por ID , vamos primeiro adicionar a coluna pela engrenagem à direita:](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323826/d766271dc3c134d7ca4a9b29/mceclip1.png?expires=1786536000&signature=fa85f4dde95d6ec23b6343431ce9a7e744fc5ff7bf79b028d22f99bb87cea0d6&req=dyYuFct9lYNZFb4V1XW4gdKLza8V%2FMvipFqGkb7T4qGGQO3Ut95LQ9td7Xe1%0AgxFI6E8BRRZJ0KEwX3YZ%2BUklcg%3D%3D%0A)

- O próximo passo é ordenar meus clientes por seu id. Clique no cabeçalho da coluna para aparecer o ícone da ordenação.

![Imagem 8: O próximo passo é ordenar meus clientes por seu id. Clique no cabeçalho da coluna para aparecer o ícone da ordenação.](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323828/2b562eba0754e2c1016172bb/mceclip3.png?expires=1786536000&signature=ba476803976f42c8c6d659fa12e2fe97492d515c8039bb3078ad2c384ad06e4b&req=dyYuFct9lYNXFb4V1XW4gcpz7zncJUgWblYbOH56GJOIg9VycY5A8OZErnjn%0Av3xcW3d3wxVtr9BTwWWZeBq0Ng%3D%3D%0A)

- Registre o Id mais baixo - neste exemplo, é 4932776. Avance as páginas até encontrar o próximo Id a ser filtrado. (neste exemplo vamos utilizar o 9323280).

Agora, criamos uma nova aba (ou duplicamos a existente, para manter seus filtros e colunas) e **inserimos o filtro inferior:**

**ID > Maior ou igual a > 4932776**

**E o filtro superior:**

**ID > Menor que > 9323280**

![Imagem 9: ID > Menor que > 9323280](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323834/90abbe99869b09435b47e4cb/mceclip4.png?expires=1786536000&signature=a32ea5c93d0b5af21ecc5c0e4d88166ba0e04958ba665f11a25409c6a50dc82f&req=dyYuFct9lYJbFb4V1XW4gaqxL8PdirdtRqjg3o6RK97QcKrNezf%2BdS85hLon%0A%2F4TrtHUS9%2BuQMEGvsj%2FfsVnQJw%3D%3D%0A)

- Para a próxima etapa da segmentação, duplicamos a aba e substituímos o inferior pelo superior, e o superior por um novo superior:

Neste exemplo: **ID > Menor ou igual > 9323280**

**ID > maior que > 9587957**

![Imagem 10: ID > maior que > 9587957](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369323838/65cec6ae4ad630f5eea5512f/mceclip5.png?expires=1786536000&signature=80a2c15011aed1e8092698ee8b7d0d6f7cd3d452d00bb3d77c3c4f1ecaf15e98&req=dyYuFct9lYJXFb4V1XW4gVTHJabAOwqggvBisHmoYdnx3%2F9JWmMyJ43f0Ffh%0AXauD0ddvfoZ5nGm%2FsYdlOr%2FiHg%3D%3D%0A)

- Assim, segmentamos os clientes por ID para possibilitar exportações que excedem o limite de linhas. Basta exportar as duas abas, e caso veja necessidade, pode juntar as informações via excel.
