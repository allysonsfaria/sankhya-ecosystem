# Como navegar pela Biblioteca

## Busca e filtros

O módulo de biblioteca conta com duas funcionalidades para auxiliar na busca de itens e coleções. A busca fica no canto superior esquerdo do módulo e está presente em todas as suas páginas. O usuário pode pesquisar arquivos pelo nome e pelo formato (jpeg, pdf, ppt, etc.). Também é possível pesquisar pastas por nome.

Já os filtros se comportam igual aos componentes de filtros já existentes no Ploomes. Podemos filtrar os arquivos por nome, pelo tipo (item ou coleção), pelo formato (PDF, JPEG, etc.) ou pelos campos dinâmicos das coleções.

## Navegação lateral do sistema de pastas

O sistema de pastas criado pelo cliente pode ser visualizado pelo menu lateral esquerdo. Nele podemos observar as pastas-mãe e todas as suas subpastas associadas. Os usuários da conta conseguem ver somente as pastas as quais têm permissão para visualizar, mas os administradores vêm todas.

Os ícones em cada pasta indicam as suas propriedades. As setas que apontam para a direita (>) indicam que há subpastas abaixo daquela pasta. Ao clicar nessa seta, ela passa a apontar para baixo e apresenta todas as subpastas associadas Se clicar mais uma vez, as subpastas são escondidas. Já o traço (-) na frente de algumas pastas indica que não há subpastas embaixo daquela pasta, ou seja, chegou no final daquela hierarquia.
