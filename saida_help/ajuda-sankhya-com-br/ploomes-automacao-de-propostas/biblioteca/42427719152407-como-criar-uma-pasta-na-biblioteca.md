# Como criar uma pasta na Biblioteca

## Criação de pastas

- **Criação da pasta-mãe**

Para criar novas pastas-mãe, é necessário entrar na tela de “Início” e criar uma pasta nessa tela. Para criar uma pasta na tela de início, clique no botão “Criar” no canto superior direito da tela e depois em “Nova Pasta” [Criar > Nova pasta].

Ao fazer isso, o modal de criação de pastas vai aparecer no lado direito da tela. Nele, o nome e as permissões da pasta-mãe são configurados. Além disso, este modal também é utilizado para editar o formulário das coleções que serão subidas dentro da estrutura desta pasta-mãe.

- **Criação de subpastas**

As subpastas são criadas dentro da visualização da sua pasta diretamente superior. Ao criar a subpasta, o seu modal de configurações vai aparecer para confirmar a configuração dos filtros. Veja a seção sobre Permissões para entender como as permissões das pastas se comportam dentro da estrutura de uma árvore de pastas.

É possível ter até 8 níveis hierárquicos de pastas dentro da mesma árvore. Isso inclui uma pasta-mãe e sete níveis de subpastas associados a ela. O sistema impedirá a criação do nono nível hierárquico se o usuário tentar. Essa limitação foi imposta para preservar a performance do módulo de arquivos que fica mais pesado conforme as árvores de pastas ficam cada vez mais profundas e o sistema de propagação de permissões fica cada vez mais complexo.
