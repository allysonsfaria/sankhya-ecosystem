# Como ativar a Biblioteca

O módulo de arquivos é oferecido à parte; para contratá-lo, entre em contato com seu gerente de conta ou com o time de suporte.

Uma vez contratado, siga o caminho para a ativação:
Administração - Módulos do sistema - Arquivos - Ativar módulo

O módulo aparecerá acima de "Administração" no menu lateral. Após ativação, será inicializado em branco com a pasta chamada "Pasta de arquivos" criada. Esta pasta estará vazia e com todas as permissões sem restrições.
