# Consigo injetar um código no Formulário externo do Ploomes?

Não é possível injetar códigos no formulário externo (seja para mensuração com o Google Tag Manager, por exemplo, ou para fazer um direcionamento após o clique no botão de "Enviar").

As únicas configurações possíveis dos formulários são as disponíveis no módulo (logo, nome, descrição, cor, finalidade, campos, idioma).

Veja mais no artigo sobre [Formulário externo](https://sankhya.zendesk.com/hc/pt-br/articles/42427361336599)
