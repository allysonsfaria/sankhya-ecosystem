# Quais são os tipos de formatos de campos de numéricos?

Ao criar um campo, temos as opções de tipos numéricos:

"Número Inteiro": Um número inteiro é um número que pode ser escrito sem um componente fracional. Por exemplo: 2, 3, 7 e −11

"Moeda": Tem o formato de números decimais que são numerais onde se usa uma vírgula, indicando que o algarismo a seguir pertence à ordem das décimas, ou casas decimais. Por exemplo: 15,5 ; 6,50

"Número com casas decimais ilimitadas": Também é um tipo de número decimal entretanto, sem o limite de casas decimais após a vírgula. Por exemplo: 3,14159265358979323846…

"Porcentagem": É um campo usado para expressar uma proporção ou uma relação entre 2 valores a partir de uma fração cujo denominador é 100, ou seja, é dividir um número por 100. Por exemplo: 10%, 20%, 40%
