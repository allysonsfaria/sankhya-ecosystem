# Por que não consigo ordenar uma tabela utilizando um campo dinâmico?

## Nesse artigo você aprenderá quais campos é possível ordenar de forma crescente e decrescente.

O sistema só permite ordenação através dos campos nativos (padrões), não sendo possível fazer isso através dos campos dinâmicos (criados por algum usuário/personalizados).

Para conhecer as diferenças entre os campos nativos e os campos dinâmicos, clique [aqui](https://sankhya.zendesk.com/hc/pt-br/articles/42427522295319).
