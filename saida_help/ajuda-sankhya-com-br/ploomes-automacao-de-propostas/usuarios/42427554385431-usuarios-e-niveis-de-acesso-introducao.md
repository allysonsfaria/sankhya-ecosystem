# Usuários e Níveis de acesso: Introdução

## Considerações importantes para a criação de novos usuários

Para saber como criar um novo usuário, acesse [este artigo](https://sankhya.zendesk.com/hc/pt-br/articles/42427650853015).

- O valor total da sua mensalidade no Ploomes é calculado à partir dos módulos contratados e da quantidade de usuários ativos, obedecendo o piso mínimo definido no momento da contratação.
- O nome completo do usuário será utilizado para identificá-lo no Ploomes em diversas ocasiões, quando ele for responsável por um cliente dentro da plataforma, por exemplo, e poderá ser exibido nas propostas comerciais e outros documentos que gerar.
- O e-mail será utilizado para acesso ao Ploomes e também poderá ser exibido nas propostas geradas pelo usuário. Na criação de um novo usuário é importante utilizar um email verdadeiro para que o usuário receba a senha de primeiro acesso. Se encontrar dificuldades relacionadas a isso, acesse [esse artigo](https://sankhya.zendesk.com/hc/pt-br/articles/42427650853015#h_a131ef034d) para entender como prosseguir.
- O cargo e o telefone também podem ser exibidos nos documentos gerados pelo usuário.
- Os campos de Facebook e Linkedin existem apenas para exibição aos demais usuários da conta.
- O perfil de usuário define o que o usuário pode fazer ou visualizar no sistema. Explicamos [adiante](https://ajuda.sankhya.com.br/hc/pt-br/articles/42427554385431-Usu%C3%A1rios-e-N%C3%ADveis-de-acesso-Introdu%C3%A7%C3%A3o#h_a4758f0c14) como realizar a configuração dos perfis.
- Ao incluir usuários a uma equipe, é possível ajustar as permissões de acesso desse usuário, baseado na equipe em que está inserido. Por exemplo, impedir que um usuário visualize clientes sob responsabilidade de outra equipe.
- Ao atribuir uma equipe a usuários, é possível configurar suas permissões de acesso com base na equipe à qual pertencem. Por exemplo, a visualização de clientes que estão sob a responsabilidade de outra equipe pode ser restringida. Este tipo de nível de acesso é definido na configuração dos **perfis de usuário**.

## Como criar equipes

Crie equipes para ampliar as definições de níveis de acesso dos usuários.

É possível definir que um usuário só possa visualizar clientes pertencentes a outros membros de sua equipe além dos próprios, por exemplo, impedindo que ele visualize clientes de outras equipes.

Para criar uma nova equipe, siga os passos abaixo:

1. Clique no módulo de Administração à esquerda da tela;
2. Na seção de Usuários, clique na opção "Equipes de usuários";
3. Na nova janela, clique no botão "Nova equipe" no canto superior direito.

## Configurando níveis de acesso à partir de perfis de usuário

O perfil define a quais informações um certo usuário possui acesso dentro do sistema. É possível criar um perfil e aplicá-lo a diversos usuários. Isso significa que, a cada novo usuário criado, basta selecionar um dos perfis configurados anteriormente para definir seus níveis de acesso.

O Ploomes traz cinco perfis por padrão. Clique no perfil para visualizar com mais detalhes quais são suas permissões. É possível editar o nome ou as permissões de um perfil clicando no ícone de lápis ao seu lado.

Para criar um novo perfil, clique no botão azul localizado no canto superior direito da tela com o texto "Novo Perfil". Você pode criar quantos perfis desejar.

Saiba mais sobre perfis de usuários [neste artigo](https://sankhya.zendesk.com/hc/pt-br/articles/42427651167383).
