# Registros de modificação e de navegação

## Como acessar a tela de registros

Para acessar o módulo de registros, clique em Adminstração > Registros.

É necessário ter um perfil de administrador para obter acesso a este módulo.

![Imagem 1: É necessário ter um perfil de administrador para obter acesso a este módulo.](https://downloads.intercomcdn.com/i/o/823477473/4412b398f7d42a781dc0c7c1/image.png?expires=1786536000&signature=2b14d5f44f661605333e629d7ff145e9edfaddbbfb6f80765fe84ea5f31d5d66&req=fCIkEs55mYZcFb4V1XW4gQiwbGjdoPMRNGNI2l0Tm7e6uIokoG8tcxmjaWRY%0AFvHta7RB0nDLUlkI%2FrAZQtxZgQ%3D%3D%0A)

## Quais informações são registradas?

O módulo de registros mantém o histórico de cada edição de campos nas entidades - seja por automações, via importação ou manualmente.

![Imagem 2: O módulo de registros mantém o histórico de cada edição de campos nas entidades - seja por automações, via importação…](https://downloads.intercomcdn.com/i/o/823478849/76a541407697b3c102743990/image.png?expires=1786536000&signature=77cf3eef913a45bdfb6a664d4f03164fbf00c7335980af4a455100b2b955f4f9&req=fCIkEs52lYVWFb4V1XW4gYPFuz0aT6uogeW7fUI5XuT%2BoN32HrfKY9Nj4T2U%0A1AZbS6fWCwt29lxr91IDRDvL8Q%3D%3D%0A)

Os filtros disponíveis nessa tela são:

- Data de início: início do período a ser buscado
- Data final: fim do período a ser buscado
- Usuário: usuário que realizou a ação
- Id do item: Id do item modificado (por exemplo Id do negócio ou do cliente)

É possível verificar na tabela:

- Qual foi o usuário que efetuou a edição
- Qual a ação feita (Criação, Atualização, Deleção)
- Qual a entidade base onde a edição foi feita (Clientes, Negócios, Produtos, Venda...)
- Qual o ID do item alterado
- A data e a hora da modificação

Ao acessar um dos registros, podemos verificar quais campos foram alterados.

No exemplo abaixo, o campo de Data de uma Tarefa foi alterado:

![Imagem 3: No exemplo abaixo, o campo de Data de uma Tarefa foi alterado:](https://downloads.intercomcdn.com/i/o/823483319/0f2c837c0b357350268f1acb/image.png?expires=1786536000&signature=b76c6aa7e04df53416be70946fb78ae2db1ecc94b53cac1dd66d2b56f3eae2d0&req=fCIkEsF9noBWFb4V1XW4gWP%2BUQOI9DQ5%2F14oQTBmzZgfycsmHha%2BJgFEJDEQ%0Ag5jwtdnjijSTUL1ggzYKPczFMg%3D%3D%0A)

À esquerda, os campos originais.

À direita, os novos campos, com uma barra laranja marcando quais informações foram **alteradas**.

## Por quanto tempo o registro fica no sistema?

Os registros expiram dentro de 6 meses.

## Como verificar o nome de um campo customizado

Campos customizados possuem uma 'Field Key' única.

![Imagem 4: Campos customizados possuem uma 'Field Key' única.](https://downloads.intercomcdn.com/i/o/823487332/d0ca59d74f5b22483a50e6bb/image.png?expires=1786536000&signature=92707e32338bb9a6614b07157a2abef90c92307c5776b3bac494f4d938449593&req=fCIkEsF5noJdFb4V1XW4gVvvh4umfeDc1ETSAk6B4Eq3aJyuVMP5BAOv3OzR%0Ai9UZNXdG9X7uM%2B5eXbc3BFQcMg%3D%3D%0A)

Passando o mouse sobre o campo, verificamos seu nome.

## Como verificar um usuário ou cliente pelo seu ID

Campos do tipo usuário ou cliente trarão o ID da entidade ao invés do nome do usuário.

Para verificar qual é o usuário, a forma mais fácil e rápida é colar o ID na url do navegador.

Acesse a página de qualquer usuário e substitua o ID na URL pelo ID copiado dos registros.

## Como acessar os registros de navegação

Para alternar entre registros de modificação e registros de navegação, use o seletor no canto superior direito:
