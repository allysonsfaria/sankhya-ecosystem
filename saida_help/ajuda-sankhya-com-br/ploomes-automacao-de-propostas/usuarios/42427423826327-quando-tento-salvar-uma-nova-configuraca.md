# Quando tento salvar uma nova configuração de permissão da erro, o que pode ser?

Isso acontece quando as regras de permissão estão em conflito.

Por exemplo: Pode visualizar apenas negócios sob sua responsabilidade ou colaboração, mas está com o acesso para editar todos os negócios.

Nesse caso revise todas as configurações para evitar que isso aconteça.
