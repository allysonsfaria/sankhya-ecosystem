# Como editar as permissões de um perfil de usuário?

Acesse Administração, em seguida Perfis de usuário.

![Imagem 1: Acesse Administração, em seguida Perfis de usuário.](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329101/d5d502c58d77765c81ebb0bc/mceclip0.png?expires=1786536000&signature=9c3a9332068defbf5ac0622ae73d9db381162f2f294d700f06e6575109f82c1e&req=dyYuFct3nIFeFb4V1XW4gRLpSsRbOynVap8hWyc9irFSfiplvk6ioO%2BJCvu7%0AfCtP3OoHK10TprJ2AC3cfB9OaA%3D%3D%0A)

Escolha qual perfil você deseja editar as permissões ou você também pode criar um novo perfil personalizado. Para fins didáticos vou usar o perfil "Funcionário" como exemplo.

![Imagem 2: Escolha qual perfil você deseja editar as permissões ou você também pode criar um novo perfil personalizado. Para fins…](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329110/1355dfc610acb11e579a237b/mceclip1.png?expires=1786536000&signature=acfa47232fa65f46362dd7b952ede979ff0fdf852e788fd378c3c2c4190c37c0&req=dyYuFct3nIBfFb4V1XW4gRzERqO5UiN1UF2U6Ys%2FJ1IH05WJDLdWp6igrS%2Fq%0AMPpXq2SQj%2BKkqug6H40K4RgGhw%3D%3D%0A)

Dentro do Perfil você pode selecionar os módulos que deseja fazer alteração, no exemplo da imagem abaixo selecionei o Módulo "Metas" e dentro de "Tem acesso ao módulo de metas?", selecionei a opção de "Não".
O que vai acontecer é que quando um usuário abrir a Ploomes não aparecerá para ele o módulo de metas.

![Imagem 3: Dentro do Perfil você pode selecionar os módulos que deseja fazer alteração, no exemplo da imagem abaixo selecionei o…](https://ploomes-52ceb6b026db.intercom-attachments-1.com/i/o/369329119/dc373d538d4bdb31c003eadb/mceclip2.png?expires=1786536000&signature=1ce0de1e46ea67d09b7a104a87e8cd569b38cbf814c5f53db7db6abb8394dde0&req=dyYuFct3nIBWFb4V1XW4gTF3u7%2FG6ExWZjX98I5fgwwP0stLGgbyqy%2BPhbMM%0AklH1ry9NjEx9NqMyZ89XDqwFfA%3D%3D%0A)

Existem várias combinações de permissões e você pode utilizar o que for mais conveniente para o seu time.
