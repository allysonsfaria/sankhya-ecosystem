# Como trocar o e-mail de um usuário

Neste artigo, você aprende como alterar o e-mail de acesso no Ploomes, tanto **do próprio usuário** quanto **de outros usuários da conta**, entendendo quando essa ação é indicada, quem pode realizá-la e quais cuidados devem ser considerados para evitar problemas de acesso.

⚠️ **Atenção antes de começar**

- Apenas **administradores** podem alterar dados de usuários.
- O e-mail do usuário é utilizado como **identificador de login** no Ploomes.
- Cada usuário deve ter um **e-mail único** (não é permitido repetir o mesmo endereço).
- A troca de e-mail **impacta o login do usuário**, mas **não altera histórico, permissões ou registros vinculados**.
- Caso o usuário não tenha mais vínculo com a empresa, o recomendado é **desativar o usuário**, e não apenas trocar o e-mail.

## Quando trocar o e-mail de um usuário?

A alteração de e-mail é indicada principalmente quando:

- o usuário mudou de e-mail corporativo;
- houve erro de digitação no cadastro;
- a empresa alterou o domínio de e-mails.

Se o objetivo for substituir uma pessoa por outra, **não utilize a troca de e-mail**, crie um novo usuário.

## Como trocar o próprio e-mail

1. No canto superior direito do Ploomes, clique na sua **foto de perfil**.
2. Clique em **Perfil**.
3. Localize o campo **E-mail**.
4. Clique no ícone de ✏️ ao lado do campo para habilitar a edição.
5. Atualize o endereço de e-mail.
6. Clique em **Salvar**.

Após salvar, o próximo acesso ao Ploomes deverá ser feito com o **novo e-mail**.

## Como trocar o e-mail de outro usuário

Para alterar o e-mail de **outros usuários**, é necessário ter perfil de **administrador**.

1. No menu lateral esquerdo, acesse o módulo **Administração.**
2. Na seção Usuários, clique em **Tabela de Usuários**
3. Na lista de usuários, localize o usuário desejado.
4. Clique sobre o **nome do usuário** para abrir a tela de edição.
5. Localize o campo **E-mail**.
6. Clique no ícone de ✏️ ao lado do campo para habilitar a edição.
7. Atualize o endereço de e-mail.
8. Clique em **Salvar**.

A alteração é aplicada imediatamente e o usuário deverá utilizar o **novo e-mail** no próximo login.

## Como resolver conflito de e-mail duplicado

No Ploomes, não é permitido existir dois usuários com o mesmo e-mail, **mesmo em contas diferentes**, pois esse dado é utilizado como critério de identificação na plataforma.

Ao tentar salvar um e-mail que já existe no Ploomes, o sistema exibirá uma mensagem informando que o endereço já está em uso.

Existem algumas alternativas para resolver esse cenário:

## Opção 1: liberar o e-mail já existente

Se o e-mail estiver vinculado a outro usuário da **mesma conta**:

- acesse o cadastro desse usuário;
- altere o e-mail atual para outro endereço válido;
- após isso, utilize o e-mail desejado no usuário correto.

## Opção 2: utilizar extensão de e-mail (+)

Caso seja necessário manter o mesmo endereço base, é possível utilizar uma **extensão de e-mail** com o caractere `+`.

Essa técnica permite criar variações do mesmo e-mail sem comprometer o recebimento das mensagens.

**Exemplo:**

Se o e-mail `teste@teste.com` já existir no Ploomes, utilize `teste+empresa@teste.com`.

Tudo o que for enviado para `teste+empresa@teste.com` será entregue normalmente em `teste@teste.com`.

Essa prática também é recomendada na **criação de novos usuários**, pois o primeiro acesso ao Ploomes depende do recebimento do e-mail de definição de senha.
