# Como excluir grupos de produto?

No Ploomes, é possível criar grupos para organizar melhor a sua base de produtos. No entanto, pode ser necessário excluir um grupo criado incorretamente, esteja ele com ou sem produtos vinculados.

## Como realizar a exclusão?

Para visualizar os grupos de produtos já criados, acesse a tela de **Produtos** e, no canto superior direito, altere o modo de visualização para **Grupos**.

[GIF animado: Imagem 1: Para visualizar os grupos de produtos já criados, acesse a tela de Produtos e, no canto superior direito, altere o modo…](https://downloads.intercomcdn.com/i/o/kg4ewnrl/2062038659/c72c9e035f72d24498d3d62b67e9/grupos.gif?expires=1786536000&signature=a45c822784684cb4ca95961babc9f64800341575a7e82d7686550cf37ce154d4&req=diAhFMl9lYdaUPMW3nq%2BgW8OzbzN2wT1hBb2x9L7upMyjNe8C8nkMSIIgkUU%0AelhzdQmARvcf90M%2Bb7L5IU7nZ0g%3D%0A)

Clique no grupo que deseja excluir e, em seguida, selecione o ícone de **lixeira** localizado no canto inferior direito da tela.

![Imagem 2: Clique no grupo que deseja excluir e, em seguida, selecione o ícone de lixeira localizado no canto inferior direito da…](https://downloads.intercomcdn.com/i/o/kg4ewnrl/2062044576/b38ae7135cf95ac493ac21b2e5ef/image.png?expires=1786536000&signature=235b2c633bd2dfeb8456d42e9fba9d209e3d063bfd0a106200bda06526f2bb13&req=diAhFMl6mYRYX%2FMW3nq%2BgTosLOUvG6NUGrJLMjqP6kqn8CwhhVn4CvuGxJSy%0AAvv7tGbba2AubnxW8mnLvVGrec8%3D%0A)

Caso deseje manter os produtos vinculados ao grupo, selecione outro grupo para transferi-los antes de concluir a exclusão. Se nenhum grupo for selecionado, os produtos associados também serão excluídos.
