# Ao integrar o Ploomes com o RD Station, os leads entram como clientes. Cometi algum erro durante a integração?

Não há nenhum erro, na verdade esse é um comportamento esperado entre os sistemas. Segue abaixo algumas sugestões, para melhor identificação dos Leads que entraram como clientes:

1- Utilize o campo Status, o cliente criado pela integração estará com status de "Prospecção" até que a primeira venda seja realizada, só então ele se tornará ativo.

2- Crie um campo no modulo de clientes que seja preenchido pela integração e ajude a filtrar esses casos. Ex: lead, prospect, cliente, cliente ativo etc, esse campo irá servir pra criar abas, filtros ou relatórios que separem a base corretamente, de acordo com os critérios configurados.
