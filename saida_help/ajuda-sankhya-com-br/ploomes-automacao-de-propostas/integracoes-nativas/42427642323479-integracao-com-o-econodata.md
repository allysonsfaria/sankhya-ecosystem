# Integração com o Econodata

Essa integração permite que clientes em potencial selecionados no Econodata sejam enviados ao Ploomes, permitindo que clientes e negócios sejam criados de maneira personalizável.

## 01. Gerar o Token de integração na plataforma do Econodata:

Primeiramente, será preciso gerar o token de integração via plataforma da Econodata. Para isso, basta clicar no seu perfil e então selecionar **Integrações:**

Depois disso, basta clicar no botão **Nova integração:**

## 02. Ligando a integração com o Econodata no Ploomes:

Com o Token copiado, será necessário ligar a integração no Ploomes para gerarmos o vínculo entre as duas plataformas. Para isso, acesse o módulo de **Administração** no seu Ploomes e então selecione a opção **Integrações plug-and-play:**

![Imagem 4: Com o Token copiado, será necessário ligar a integração no Ploomes para gerarmos o vínculo entre as duas plataformas.…](https://downloads.intercomcdn.com/i/o/742237094/be28b93328ad984b8064920f/image.png?expires=1786536000&signature=0d3630e0db78c7aa22e47421a09ffec97d7d3ecaf566047c80b1f9c295bead9a&req=cyQlFMp5nYhbFb4V1XW4gc0MeLH3qXY9svThOcXPhsYl8imGsQGSsUWhoZpM%0A64fp%2BVF1FJSv5gYWlxWZMvbQ%2BA%3D%3D%0A)

Na janela aberta, procure pela integração com o **Econodata** e clique na opção:

![Imagem 5: Na janela aberta, procure pela integração com o Econodata e clique na opção:](https://downloads.intercomcdn.com/i/o/742237841/667e913da5e224bf08153bfe/image.png?expires=1786536000&signature=cada2671f7772f19ef8757f7450c7fa690d263da65617ca0d4296a08fb4fa04f&req=cyQlFMp5lYVeFb4V1XW4gay4bRUE1sfT2fP5gmDAftPHq8IiewVIGenrUOgN%0A%2FR0ptS28li1rm%2F1SneSlUmaUHA%3D%3D%0A)

Antes de ativarmos a integração é preciso que a mesma seja autorizada e será nessa autorização que utilizaremos o Token copiado. Clique, então, no botão **Autorizar Integração:**

![Imagem 6: Antes de ativarmos a integração é preciso que a mesma seja autorizada e será nessa autorização que utilizaremos o Token…](https://downloads.intercomcdn.com/i/o/742239087/98a551f3ad869b290d6e490f/image.png?expires=1786536000&signature=7fbd509d7d2b39435eeea33ea2b7bc8ab2fbf2a90caa8e42dd0d9f56c75c4049&req=cyQlFMp3nYlYFb4V1XW4ga%2FuHBzyHUqkD%2F9qaWZEEo5z6K3YQgwYW9nZZ0KI%0AuSuWZbJk1U%2B8K6nFc8b5vq7b6A%3D%3D%0A)

## 03. Configurando a integração:

Após habilitar a integração, será necessário configurá-la antes de ativá-la. Para isso, **selecione o tipo de comportamento** que você gostaria de ter com a integração:

![Imagem 8: Após habilitar a integração, será necessário configurá-la antes de ativá-la. Para isso, selecione o tipo de…](https://downloads.intercomcdn.com/i/o/742243315/435fd781b57a4382432b4aa2/image.png?expires=1786536000&signature=c6cb90aec6115187ff0e5787f0785e6cb558b27700bf4ac16c8f03e94e0ee3d1&req=cyQlFM19noBaFb4V1XW4gVVn3qPvHZT3irbdu%2BIOCLTD6LmK1Kdp4YI2MfEk%0A%2FcHkF4IdbJ4KOm5baDCaBWlSVg%3D%3D%0A)

Caso selecione que gostaria que a integração apenas crie Empresas e/ou Pessoas, sua integração já está pronta para ser ativada. 😉

Caso selecione que gostaria que a integração também crie Negócios no Ploomes, temos mais um passo na configuração. Será necessário, então, selecionar **em qual estágio de um dos funis que o Negócio será criado** no Ploomes:

![Imagem 9: Caso selecione que gostaria que a integração também crie Negócios no Ploomes, temos mais um passo na configuração. Será…](https://downloads.intercomcdn.com/i/o/742248061/18121a3508fb60fdc8ddf985/image.png?expires=1786536000&signature=4c2dd38b71c1c375a566d2784a068e673ba86c9079ee3e599e51173261db725d&req=cyQlFM12nYdeFb4V1XW4gcHigLyjPF7QZaxoFhgd4PT1WJ8s7%2B1nPSW%2BMZq5%0AitGiQkoACrNEm0MEbIZiYI8mIg%3D%3D%0A)

Após isso, você pode ou não ativar a opção **Não criar o negócio caso já exista um aberto para o cliente.** Essa opção irá fazer com que a integração verifique se o cliente em questão já possui uma negociação em aberto no Ploomes antes de prosseguir. Caso sim, ela não irá criar um novo Negócio. Caso não, será criado um novo Negócio para esse cliente.

Quando verificar que já está tudo configurado conforme o processo de vocês, sua integração já está pronta para uso.
