# Integração com Zapier

Zapier é uma das ferramentas de integração mais utilizadas no mundo. Por ela, você cria conectores entre seus aplicativos favoritos.

Com esta integração, você pode conectar gatilhos do Ploomes a outros aplicativos ou executar ações dentro do seu próprio Ploomes.

## Primeiro passo: Criar um usuário de integração

Crie um usuário de integração em Administração > Usuários Integração

O usuário criado precisa ter a permissão de **Administrador** e deverá possuir um e-mail exclusívo para sí.

### FAQ

- Erro "401 calling GET https://app-api2.ploomes.com/Self, expected 2xx." sendo exibido ao tentar conectar o Zapier com o Ploomes.

R: Este erro ocorre devido a falhar de comunicação com a API do Ploomes, assim indicando um possível erro na chave de api configurada. O aconselhado para este caso, seria resetar a chave de API seguindo o caminho "Administração > Usuários de integração > Usuário criado para integrar com o Zapier", clicar em "Resetar chave" e adicionar a nova chave de API no Zapier.
