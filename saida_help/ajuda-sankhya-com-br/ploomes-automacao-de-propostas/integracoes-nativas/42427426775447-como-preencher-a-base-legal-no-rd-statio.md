# Como preencher a base legal no RD Station

## O que é uma base legal?

A integração com o RD Station pode solicitar que seja definida a base legal para tratamento de dados em conformidade com a LGPD.

De acordo com o artigo na base do RD:

[https://ajuda.rdstation.com/s/article/O-que-são-Bases-Legais?language=pt\_BR](https://ajuda.rdstation.com/s/article/O-que-s%C3%A3o-Bases-Legais?language=pt_BR)

As bases legais são hipóteses da LGPD que autorizam o tratamento de dados pessoais. A lei estabelece que para que qualquer pessoa, física ou jurídica, possa realizar qualquer operação com um dado pessoal – seja coletar, transmitir ou processar –, é necessário possuir uma base legal presente na LGPD que justifique o tratamento desses dados. Como a LGPD já entrou em vigor, empresas que utilizarem dados pessoais sem uma base legal adequada, estarão tratando dados de forma ilegal.

## Como defino a base legal de minhas integrações no RD Station?

Em [app.rdstation.com.br/integracoes](http://app.rdstation.com.br/integracoes), é possível definir sob qual base legal a Ploomes trata os dados recebidos via RD Station.

## Qual base legal devo selecionar para a integração com o Ploomes?

Recebemos dados via RD Station, que são de propriedade do cliente, e tratamos na qualidade de Operadores para cumprimento do contrato. Portanto, a base legal que deve ser selecionada é a de **cumprimento de** contrato.
