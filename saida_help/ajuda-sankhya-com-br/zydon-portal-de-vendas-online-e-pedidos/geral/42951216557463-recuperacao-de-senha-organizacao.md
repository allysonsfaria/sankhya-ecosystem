# Recuperação de Senha - Organização

Caso o membro da loja tenha esquecido a senha, a recuperação é simples e rápida.

Como Recuperar sua Senha

Ao tentar acessar a organização com uma senha incorreta, será exibida uma mensagem de erro. Para criar uma nova senha, siga os passos abaixo:

1. Clique no botão **"Esqueci minha senha"** na página de login.
   ![Imagem 1: Clique no botão "Esqueci minha senha" na página de login.](https://ajuda.sankhya.com.br/hc/article_attachments/42951172395287)
2. Você será redirecionado para uma página onde deverá inserir o **e-mail cadastrado** na organização.
   ![Imagem 2: Você será redirecionado para uma página onde deverá inserir o e-mail cadastrado na organização.](https://ajuda.sankhya.com.br/hc/article_attachments/42951176484503)
3. Após preencher o e-mail, clique no botão **"Enviar e-mail para criar uma nova senha"**.

Em seguida, um **e-mail com um botão** será enviado para o endereço informado. Clique no botão para acessar a página de criação de nova senha. 

![Imagem 3: Em seguida, um e-mail com um botão será enviado para o endereço informado. Clique no botão para acessar a página de…](https://ajuda.sankhya.com.br/hc/article_attachments/42951186837655)

Na página de alteração de senha, siga as **regras de segurança** para criar sua nova senha e finalize o processo.

Após alterar, realize o login normalmente com a nova senha. 

Se precisar de assistência ou tiver qualquer dúvida sobre como recuperar sua senha, nossa equipe de suporte está à disposição.
