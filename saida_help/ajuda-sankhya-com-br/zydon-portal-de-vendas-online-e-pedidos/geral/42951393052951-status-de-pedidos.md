# Status de Pedidos

Como criar e personalizar seus próprios status de venda

**Na tela de "Status de Pedidos", os administradores podem criar e personalizar os status de venda para acompanhar o progresso de cada venda.**

## Acessando Status de Pedidos

Para acessar a tela de "Status de Pedidos" no Zydon Admin, siga os passos abaixo:

1. **Localize o menu lateral** na parte esquerda da tela principal.
2. Clique na opção **Pedidos**.
3. Um submenu com opções será exibido. Selecione **Status de Pedidos** para ir à tela principal.

![Imagem 1: Um submenu com opções será exibido. Selecione Status de Pedidos para ir à tela principal.](https://ajuda.sankhya.com.br/hc/article_attachments/42951374036887)

## Funcionalidades da Tela de Status de Pedidos

Assim que acessar a tela, será possível visualizar a lista completa de todos os status criados. As principais ações disponíveis são:

- **Deletar status**
- **Editar status** ao clicar em um status específico

## Criar um Novo Status

Para criar um novo status, clique em **"Novo Status"** e configure os campos solicitados:

- **Dados do Status:** Informações para identificação.
  - **Nome Interno:** Nome do status na plataforma.
  - **Subtipo:** Define o tipo ao qual o status pertence dentro do processo de venda.
  - **Nome do status para o comprador:** Nome exibido ao cliente no portal.
  - **Subtítulo:** Mensagem de informação adicional.
  - **Cores:** Personalize o status definindo uma cor de apresentação para facilitar a diferenciação.
  - **Configurações** - Defina como esse status irá se comportar na loja, seus fluxos e ativações.
  - **Status de Destino:** Defina o direcionamento de status, ou seja, qual será o próximo status em caso de atualização automática (via gateway, API ou usuário).

É possível importar os status através de uma planilha, facilitando a configuração em massa.
