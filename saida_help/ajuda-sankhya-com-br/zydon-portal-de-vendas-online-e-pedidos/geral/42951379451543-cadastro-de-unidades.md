# Cadastro de Unidades

No Zydon Admin, os membros da loja podem personalizar a gestão de suas unidades de medida de acordo com o tipo de venda. Isso inclui adicionar medidas como Quilograma, Caixa, Pallet, Litro e muitas outras. Cada unidade é completamente personalizável, permitindo que os administradores adaptem suas configurações conforme o estilo e as necessidades de seus negócios.

## Acessando a Página de Cadastro de Unidades

Para cadastrar unidades de medida, siga os passos abaixo:

1. No menu lateral esquerdo, localize e clique no ícone **Produtos**.
2. Um submenu será exibido com diversas opções.
3. No submenu, clique em **Unidades**. ![Imagem 1: No submenu, clique em Unidades .](https://ajuda.sankhya.com.br/hc/article_attachments/42951387982359)

## Importar Unidades

A função de **Importar** permite a migração de unidades já cadastradas anteriormente para dentro do portal Zydon Admin. Isso é útil para lojas que já possuem unidades definidas em outros sistemas e desejam integrá-las ao Zydon de maneira eficiente.

## Nova Unidade

Ao clicar no botão +**Adicionar**, você poderá criar uma nova unidade de medida conforme as preferências de venda do administrador. A criação de unidades é completamente personalizável e inclui os seguintes campos:

- **Sigla**: Insira uma sigla representativa da unidade. Exemplo: KG (Quilograma), CX (Caixa), PLT (Pallet).
- **Descrição**: Descreva a unidade. Exemplo: Quilograma, Caixa, Litro, etc.
- **Decimais de Quantidade**: Defina o número de casas decimais que a unidade deverá utilizar. Exemplo: para Quilograma (KG) com 2 decimais, 1,00 KG.![Imagem 2: Decimais de Quantidade : Defina o número de casas decimais que a unidade deverá utilizar. Exemplo: para Quilograma (KG)…](https://ajuda.sankhya.com.br/hc/article_attachments/42951388178199)

Após realizar o cadastro de sua primeira unidade, ela irá aparecer na página inicial de unidades com as informações cadastradas.

## Edição e Gerenciamento de Unidades

Além de criar novas unidades, também é possível **editar** as unidades existentes. Para fazer isso, siga os passos abaixo:

1. 1. Clique sobre a unidade que deseja alterar.
   2. Edite os campos conforme necessário.
   3. Clique no botão "Salvar" para confirmar as alterações.

## Inativar Unidade

Também é possível ativar ou inativar unidades de medida. A **inativação** impede que novos produtos sejam cadastrados com a unidade desativada, e também remove sua visibilidade dos produtos ativos que a utilizam.

## Exclusão de Unidades

Caso deseje excluir uma unidade de medida, é possível fazer isso utilizando o botão de 3 pontos localizado no final do componente correspondente à unidade.

![Imagem 3: Caso deseje excluir uma unidade de medida, é possível fazer isso utilizando o botão de 3 pontos localizado no final do…](https://ajuda.sankhya.com.br/hc/article_attachments/42951380203927)

## Atenção

A exclusão de unidades de medida é uma ação irreversível. Tenha certeza antes de concluir esta operação, pois as unidades excluídas não poderão ser recuperadas.
