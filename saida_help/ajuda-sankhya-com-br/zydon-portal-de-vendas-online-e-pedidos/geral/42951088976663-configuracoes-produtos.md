# Configurações - Produtos

No painel **Configurações → Produtos**, você define como os produtos são exibidos, organizados e buscados na sua loja B2B — layouts, filtros, campos de destaque e muito mais.

## Como acessar

No menu lateral, clique em **Configurações → Produtos**.

![Imagem 1: No menu lateral, clique em Configurações → Produtos .](https://ajuda.sankhya.com.br/hc/article_attachments/42951120676631)

## Categorias — Ordenação

Defina como as categorias aparecem na loja:

- **Manualmente** — drag and drop
- **Ordem alfabética** ℔ A-Z automático
- **Código** ℔ pelo código de cadastro

![Imagem 2: Código ℔ pelo código de cadastro](https://ajuda.sankhya.com.br/hc/article_attachments/42951108077335)

## Lista de Produtos — Layout

- **Modos:** Card, Lista ou Tabela
- **Informações adicionais:** descrição expandida, coluna de múltiplo, coluna de mínimo
