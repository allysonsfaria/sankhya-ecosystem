# Política de uso de API

Agradecemos por utilizar as interfaces de programação de aplicativos da Zydon ("APIs"). Ao acessar e utilizar nossas APIs, você concorda com esta Política de Uso da API (a "Política") e com nossos Termos. Nossas APIs estão disponíveis em https://developer.zydon.com.br para fornecer a oportunidade de construir e usufruir de nosso Serviço, criando software, serviços ou módulos que se conectem à nossa plataforma ou acessem dados dentro dela por meio de nossas APIs (uma "Integração"). Esta Política é considerada parte integrante de nossos Termos. Termos em maiúsculas, não definidos nesta Política, têm os significados atribuídos nos Termos.

1. ## Acesso à API:

   - Para acessar a API, é necessário utilizar o OAuth ou uma chave de API. Se você possui uma Integração, os usuários devem ter a opção de fazer login via OAuth ou utilizando a chave de API. Não solicitamos aos usuários informações como nome de usuário, senha ou perguntas de segurança.
2. ## Uso Permitido:

   - A API não deve ser utilizada para envio de spam ou qualquer atividade que viole nossas políticas. Os usuários devem cumprir todas as leis aplicáveis e seguir a documentação fornecida para as APIs. Monitoramos o uso das APIs e nos reservamos o direito de limitar ou negar o acesso em caso de violação desta Política.
3. ## Privacidade:

   - Respeitamos a privacidade dos usuários. A obtenção de permissão expressa é necessária antes de acessar a conta Zydon do usuário. As Integrações devem exibir uma política de privacidade detalhando as informações coletadas. O acesso aos dados do usuário deve ser feito conforme permissão e explicado na política de privacidade. A exclusão imediata dos dados do usuário é obrigatória mediante solicitação ou encerramento da conta.
4. ## Segurança:

   - Medidas de segurança devem ser implementadas e mantidas para proteger a segurança, integridade e confidencialidade dos dados do usuário. Incidentes de segurança devem ser comunicados e corrigidos em colaboração.
5. ## Licença:

   - Concedemos um direito limitado de acesso e uso das APIs para desenvolvimento e suporte à Integração, sujeito ao cumprimento desta Política e das leis aplicáveis. O acesso independente às APIs é proibido, e podemos encerrar o acesso a qualquer momento.
6. ## Propriedade:

   - Somos proprietários de todos os direitos nas APIs e no Serviço. Não é permitido infringir, fazer engenharia reversa ou copiar nosso código, design ou conteúdo.
7. ## Uso de Marcas:

   - O uso de nossas marcas está sujeito às Diretrizes de Marca. Não altere ou remova avisos de propriedade. O uso do nome ou marcas na Integração deve estar em conformidade com nossas diretrizes.
8. ## Observação:

   - Fornecemos as APIs "como estão", sem garantias expressas ou implícitas.
9. ## Atualizações:

   - Reservamo-nos o direito de atualizar as APIs e esta Política, notificando as alterações no site. Se uma alteração for inaceitável, a interrupção do uso das APIs é recomendada.
